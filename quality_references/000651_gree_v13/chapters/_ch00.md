
## 投资要点概览

### 一眼看懂

- **公司简介**：格力电器（000651.SZ）是中国最大的空调制造商，成立于1991年，1996年深交所上市，总部位于珠海。2025年营收1,704亿（YoY −9.89%），归母净利润290亿，员工约7万人，研发人员15,947人，拥有超3万家线下服务网点，空调年产能超6,000万台，全球累计销量超6亿台。无实控人，前十大股东以机构投资者为主，董明珠（71岁）自2012年起任董事长。[source: Ch1 + mda.json FY2025 营收1,704亿 净利润290亿 研发人员15,947人 + 2025_年报.md 董事信息]

- **这是什么生意**：一门"空调品牌制造+垂直整合"的生意。卖的是以空调为核心（占营收78%）的家电产品，通过经销商网络和电商平台卖给家庭和企业用户。赚钱靠品牌溢价（"好空调格力造"心智让消费者愿意多付钱，内销毛利率34.52%）和规模制造优势（自研自产压缩机、电机等核心零部件，2021年收购盾安环境强化上游控制）。净利率17.02%处于家电行业P93.4（行业中位4.25%）——格力的赚钱效率在全行业处于顶尖水平，远非"家电行业竞争激烈所以利润薄"的刻板印象所能解释。核心矛盾：空调品类高度集中带来了极高赚钱效率，但也意味着品类见顶时缺乏第二增长曲线。[source: Ch1 消费电器78.06% + segments.json FY2025 内销毛利率34.52% 外销毛利率24.54% + get_peer_comparison 净利率17.02% P93.4 行业中位4.25%]

- **定性决定**：**Continue（继续研究）**——品牌护城河可验证（毛利率35%+五年趋势上行，市占率~34%行业第一28年领跑），赚钱效率行业顶尖（ROE 19.87% P93.3，OCF/NP=1.49利润质量高），无一票否决项。三大风险——空调内销连续两年下滑（−5.45%→−10.67%）、董明珠接班人真空（71岁，2025年卸任总裁由张伟接任）、多元化战略持续消耗资本（格力钛亏损、手机/芯片无回报）——均为可跟踪的重大限制性风险，非否决项。PE 7.2x（行业15.4x，g_disc=53.3%）已充分反映市场的悲观预期。[source: Ch3 毛利率35.28% + Ch8 董明珠71岁 张伟接任 cap_alloc_score=差 + Ch9 否决门全部通过 + get_peer_comparison PE 7.2x vs 行业15.4x]

- **定量决定**：**Hold（持有/观望）**——两条正交安全边际冲突：价格安全边际+13.1%（V_final 42.99元 vs 现价37.34元），但回报安全边际−2.2pct（R_total 11.0%−r*10.0%−decay 3.2%）。按Ch12裁决规则，冲突时以回报安全边际优先→Hold。GG=7.4%>II=4.5%（+2.9pp超额）确认穿透回报能力——对于已在持仓中的投资者，当前估值下卖出并非最优选择；但对于新建仓，回报安全边际为负意味着当前价下年化净回报不足以补偿护城河衰减风险。[source: Ch12 V_final=42.99 价格MOS=+13.1% 回报safety_margin=−2.2pct + Ch11 GG=7.4% II=4.5% + get_market_data 现价37.34]

- **一致吗？** 基本一致但存在建设性张力。定性看"护城河有多深"——格力品牌没有消失，35%毛利率证明定价权稳固。定量看"衰减有多快+兑现有多慢"——decay 3.2%/年（护城河半衰期20-25年）和留存兑现折价λ=0.475（治理折价+增长萎靡）正在侵蚀表面的"便宜"。两者不矛盾——共同指向**Cautious Watch**：好生意，但当前价下回报安全边际不足，应建仓但保持克制。[source: Ch14 定性定量一致性分析 + Ch3 半衰期20-25年 + Ch12 decay=3.2% λ=0.475]

### 为什么现在是这个动作

- **最主要的理由**：回报安全边际为负（−2.2pct）——即使格力的赚钱效率行业顶尖（GG 7.4%>II 4.5%，超额2.9pp），但护城河衰减（decay 3.2%/年）和留存价值兑现折价（λ=0.475，cap_alloc_score=差+无分红硬承诺）共同侵蚀了表面上的"便宜"。当前价37.34元下预期年化总回报约11%（8%股息+3%有机增长），扣除10%要求回报和3.2%衰减后，净超额为负。这不是"不能买"——对于收入型投资者，8%股息率+GG 7.4%穿透回报仍有吸引力。但对于追求≥10%年化回报的投资者，需要在更低价格（≤30元）或基本面改善（内销企稳）后才值得重仓。2%起建是理性选择。[source: Ch12 R_total=11.0% r*=10% decay=3.2% + Ch13 P*=38.25 P*_zero=30.00 + Ch14 Cautious Watch + compute_ddm dps_fy=3.0 股息率~8%]

- **公司现在大致处在什么状态**：**成熟期晚期，经历周期性低谷，高利润+零增长+高分红**。2023年刚创历史最好业绩（营收2,050亿、净利润290亿），2024-2025连续两年下滑回到略低于2021年水平。毛利率维持35%高位说明品牌定价权仍在（竞争未"打垮"格力），但空调内销（占74%）需求见顶趋势明确。核心主业从"渗透率提升"切换到"更新换代+产品升级"。OCF/NP=1.49利润质量高，Capex/D&A≈1.0确认维持性投资属性（无需额外资本就能维持利润），FCF充裕（FY2025约447亿）。DPS五年从1.0→3.0元（股息率8%），但2022-2024年股东回报规划已到期，2025年未推出新长期规划——分红取决于董事会年度决议，非制度性承诺。多元化十年无一成功（格力钛亏损、手机/芯片零回报），智能装备收入仅6.8亿。[source: Ch4 营收-7.26%→-9.96% + Ch5 毛利率扩张 + Ch6 OCF/NP=1.49 Capex/D&A=1.0 FCF=447亿 + Ch7 DPS 1.0→3.0元 分红规划到期 + Ch10 g_sustain=0 + segments.json FY2025 智能装备6.8亿]

- **最该先盯哪个变量**：**FY2026 H1内销营收YoY**。这是所有假设的交汇点——它同时验证：(1)需求是周期性低谷（房地产竣工低谷+消费降级）还是结构性见顶（保有量饱和+人口拐点）；(2)毛利率能否在规模萎缩下继续维持35%+；(3)AA（可支配现金）是否会进一步恶化至威胁DPS 3.0元（AA已从347→176亿，仅比年分红168亿多8亿安全垫）。警戒线：FY2026 H1内销YoY≥0%（绿灯，加仓至3-4%）；-5%~0%（黄灯，维持2%）；<-5%（红灯，减至0-1%）。在2026年8月中报发布前，维持2%仓位不变。[source: Ch9 持续跟踪指标 + Ch11 AA=176亿 vs 分红168亿 + Ch14 监控触发器 + compute_aa aa_annual FY2023=347→FY2025=176]

- **现在最大的难点是什么**：**"便宜但可能还不够便宜"的价值陷阱边界**。PE 7.2x、股息率8%、净现金395亿——这些数字让任何价值投资者都难以忽视。但回报安全边际为负揭露了隐含风险：护城河衰减（3.2%/年）和留存兑现折价（λ=0.475）正在蚕食表面的"便宜"。更难的是，营收连续两年下滑（-7%→-10%）可能是周期性（房地产周期+消费降级），也可能是结构性（保有量饱和+人口拐点+年轻消费者品牌迁移）——两者的投资含义截然不同。如果是周期性（60%概率），当前价是"低估"；如果是结构性（25%概率），当前价是"合理"甚至"偏贵"。未来12个月的数据将给出决定性证据，但在那之前，2%仓位是对不确定性的诚实定价。[source: Ch9 魔鬼代言人 结构性下行概率25% + Ch14 竞争性解释 周期性60%/结构性25%/份额流失15% + compute_aa 净现金395亿 + get_market_data MC=2,091.56亿 PE≈7.2x]

- **下一步最该先验证什么**：FY2026年中报（2026年8月）的**内销营收YoY数据**。这是最低成本、最高信息量的验证点——一次数据更新即可同时验证需求性质（周期vs结构）、DPS可持续性、和毛利率韧性三个核心假设。同时关注两个年报披露信号：(1)FY2025年报（2026年4月）是否推出新一轮长期股东回报规划——如果有且承诺分红率≥50%，λ可能上调，V_final上升，当前价下安全边际自然增厚；(2)2026年股东大会董明珠是否连任董事长及张伟的独立决策表现。[source: Ch14 最小验证问题 + Ch7 分红规划到期 + Ch8 接班人 + 2025_年报.md 张伟接任总裁]
