# Phase 10 PIT Writer Policy

This static framework file defines the minimum structure for a point-in-time
engineering draft. It is not company evidence and cannot support a material
claim by itself.

The writer must use only admitted sources read in the active run, preserve
UNKNOWN where evidence is missing, and avoid investment return, entry-price,
selection, position, and post-cutoff conclusions. The resulting draft is not
a production frozen report until the separate acceptance, claim ledger, and
independent-review gates have completed.
