# VCF + 成长价值执行器

> **Phase 6 产出**。Greenwald 三价值来源里**最不可靠的一个**——只有护城河内的增长才创造价值。VCF = 增量ROIC/r* 判断增长是否增值；成长价值叠加在 EPV 之上。
> 上游：Factor1C（增量增长）、Phase1（r*）、Phase2（EPV）、Phase5（回报分解的积极投资项）。下游：Phase5 积极投资回报、Factor4 成长溢价上限。
> 母版 `_executor_template.md`；路线图 `docs/turtle_graham_deepening_roadmap.md`。单位百万元。
> **全局原则**：拿不到精确数据给近似估算 + 方法 + ⚠️，绝不空着。本执行器数据缺口最深（分部级并购回报），降级阶梯必须给出可算的重构算法，而非仅标⚠️。

---

## 定位与指令

> **定位**：量化"增长值不值钱"。VCF>1 增长创造价值、=1 中性、<1 毁灭价值。成长价值只在有护城河（franchise_value>0）、VCF>1 **且通过资本配置纪律闸门（关卡①a）** 时才叠加到 EPV 上。这是估值流水线的第三层（资产→EPV→成长），也给 Phase5 的积极投资回报项提供 VCF 输入。
> **管理层作为价值变量（书 ch8/9）**：VCF 是"增量回报够不够高"的客观测算；关卡①a 是"管理层过去把钱投到了哪"的历史行为闸门。二者独立，前者过、后者不过时，成长价值仍要归零或打折。
> **上游依赖**：Factor1C（B类营收/增量增长）、Phase1 r*、Phase2 EPV/franchise_value、§3+§4（NOPAT、投入资本、商誉变动）。
> **下游消费**：Phase5（积极投资回报 = (增量ROIC−r*)×留存×V/M）；Factor4（成长溢价上限，防止给无护城河增长付费）。

**指令**：VCF = 增量ROIC / r*。增量ROIC = ΔNOPAT / Δ投入资本。精确算需分部级并购回报（散户拿不到）→ 走降级重构算法从合并报表反推。成长价值仅护城河内计入。§6.5-C 经验规则作末级兜底。全程保守。

| 变量 | 含义 | 来源 §X | 单位 |

### VCF 主计算

```
增量ROIC = Δ投入资本产生的边际 NOPAT 回报
         = ΔNOPAT_近N年累计 / Δ投入资本_近N年累计   （N=3-5，跨足够周期）

VCF = 增量ROIC / r*
  VCF > 1   → 增长创造价值（增量资本回报 > 资本成本）
  VCF ≈ 1   → 增长中性（仅覆盖资本成本，不增值）
  VCF < 1   → 增长毁灭价值（越投越亏）
```

### §6.5-C 经验规则（末级兜底 + 交叉校验，已核原书）

```
以下规则用于：无法精确算增量ROIC 时兜底，或对算出的 VCF 做合理性校验：
  - 派息率 > 75%          → 留存太少，精确算 VCF 无意义（分母小、噪音大），VCF 用经验值
  - 留存≥1/3 盈利但盈利不增长 → VCF ≈ 0（钱投进去没产出增长）
  - 增长靠现金/低息债务融资  → VCF 系数 ≈ 0.8（融资成本低但仍需回报）
  - 明显毁灭价值（收购后利润率下滑） → VCF < 0.5
  - 高效再投资（利润率随规模升） → VCF 5+（罕见，强护城河特征）
  - 无护城河（franchise_value≤0） → VCF ≤ 1 封顶（无护城河增长不可能持续增值）
```

## 关卡 ② 数据缺失降级阶梯（分部并购重构算法 — 本执行器核心）

> 书的精确 VCF 需分部级并购回报（每笔收购投入多少、带来多少增量利润）。散户只有合并报表。**降级不是标⚠️了事，而是从合并数据反推增量ROIC。**

```
优先级1（有分部披露 + 并购明细）：
  逐分部：增量ROIC_i = 分部ΔNOPAT_i / 分部Δ投入资本_i
  加权 VCF = Σ(分部投入资本权重 × 分部增量ROIC) / r*
  （理想态，散户罕见）

优先级2（无分部，但能拆有机 vs 并购增长）：
  用商誉变动拆分投入资本来源：
    并购投入 ≈ Δ商誉 + 并购支付现金（§5 取得子公司支付现金净额）
    有机投入 ≈ (Capex − DA) + Δ营运资本
    Δ投入资本 = 并购投入 + 有机投入
  分别估回报：
    有机增量ROIC = 有机ΔNOPAT / 有机投入   （有机ΔNOPAT≈剔除并表利润后的内生增量）
    并购增量ROIC = 并购带来ΔNOPAT / 并购投入（并购ΔNOPAT≈并表当年贡献利润）
  加权 VCF = (有机投入×有机ROIC + 并购投入×并购ROIC) / Δ投入资本 / r*
  标"⚠️ 有机/并购拆分基于商誉变动近似，非分部实测"

优先级3（无法拆有机/并购）：
  混合增量ROIC = ΔNOPAT_累计 / Δ投入资本_累计（全部混算）
  VCF = 混合增量ROIC / r*
  标"⚠️ 未区分有机/并购，VCF 为混合口径"
  校验：若 Δ投入资本主要来自 Δ商誉（并购驱动）→ 标"增长主要靠收购，VCF 反映外延而非内生"

优先级4（ΔNOPAT 或 Δ投入资本 不稳定/为负）：
  转 §6.5-C 经验规则：
    读派息率与盈利增速：
      留存高(b>2/3)且盈利5年CAGR<2% → VCF≈0（留存未转化增长）
      留存中且盈利温和增长 → VCF≈0.8-1.0
    franchise_value≤0 → VCF≤1 封顶
  标"⚠️ VCF 基于派息率-增长经验规则，非增量ROIC 实测"
禁止：留空 VCF。四级降级保证任何数据条件下都落到一个 VCF 值。
```

## 关卡 ①a 资本配置纪律前置检验（书 ch8/9 · R5 入场前的治理闸门）

> **为什么前置**：VCF 只算"增量资本回报率够不够高"，但不管"管理层会不会真把留存利润投到高回报方向"。
> 一家主业 VCF>1 的公司，若管理层历史上系统性把现金流投向毁灭价值的非主业多元化（格力钛/银隆模式），
> 那么"未来增量资本"本身就不可信——再高的主业 VCF 也不该无条件叠加成长价值。
> 本关卡把管理层历史资本配置行为作为成长价值的**准入闸门**，先于 VCF 计算执行。
>
> **D2 升级（书第8/9章）**：优先读 `factor_管理层资本配置` 执行器的 `cap_alloc_score` 作为主要判据。
> 该执行器涵盖五年历史行为、并购回报、回购时机、趋势方向，比 c_ratio+imp 单点判断更全面。
> 若 D2 执行器未运行，退回原 c_ratio+imp 近似规则（标⚠️"D2 未执行，用 factor1C 近似"）。

```
前提：本关卡只对 R5（valuation_route=R5）执行。其余路由成长价值本就=0，跳过。

读输入（优先级顺序）：
  ① 若 factor_管理层资本配置 已执行 → 读 cap_alloc_score（主要判据）
  ② 若未执行 → 读 factor1.5 的 capital_discipline + factor1C 的「C类特征/毁灭价值历史」
                令 c_ratio = C类投资/Capex总额，imp = 是否有已证实的商誉减值/投资亏损

闸门 A（硬拦截 → 成长价值归零）：
  触发条件：
    ① cap_alloc_score=劣（D2 已执行时优先用）
    ② 或：capital_discipline=R4降级（factor1.5 传来）
    ③ 或：c_ratio≥20% 且 imp=有（D2 未执行时 fallback）
  → 成长价值强制 = 0，内在价值 = EPV
  → 写："⚠️ 资本配置纪律失守（[依据]），增量资本不可信，成长价值=0；
        回标 factor1.5 应已同步 R5→R4"
  → 跳过关卡①b 的 VCF→成长价值换算，直接转关卡③输出

闸门 B（软折价 → 成长价值打 κ 折）：
  触发条件：
    ① cap_alloc_score=差（D2 已执行时优先用）
    ② 或：capital_discipline=软折价（factor1.5 传来）
    ③ 或：c_ratio≥20% 且 imp=无（D2 未执行时 fallback）
  → 记 κ = factor1.5 传来的系数（默认 [0.5, 0.7]，C类越高/cap_alloc越差取越低）
    若 D2 已执行且 cap_alloc_score=差：κ 取 [0.5, 0.7] 区间，由 C类占比细定
  → 成长价值照关卡①b 正常算，最后乘 κ
  → 写："⚠️ 资本配置质量偏差（[依据]），成长价值×κ=X.X 反映未来错配风险"

闸门 通过（cap_alloc_score=优/中 or C类<20% or capital_discipline=合格）：
  → κ = 1.0，正常进入关卡①b

禁止：R5 标的在未经本关卡的情况下直接叠加成长价值。
```

## 关卡 ①b 成长价值计算（叠加在 EPV 上）

```
前提：仅当 franchise_value > 0（有护城河，Phase3）且 VCF > 1 且【关卡①a 未硬拦截】才计成长价值。
      无护城河 或 VCF≤1 或 关卡①a 闸门A → 成长价值 = 0，内在价值 = EPV（不给成长溢价）

成长价值（保守叠加，不做长期高增长外推）：
  年增值 = 留存利润 × (VCF − 1)          （每年留存资本创造的超额价值）
         = b × E_norm × (VCF − 1)
  成长价值_毛 ≈ 年增值 / (r* − g_sustain)  （戈登式，g_sustain 严格 ≤ min(名义GDP, 5%)）
    ⭐ 约束：g_sustain 封顶（§6.5-E），防永续高增长失真
    ⭐ 成长现实闸门（Magna 教训）：g_sustain ≤ min(名义GDP, 5%, max(0, 营收3-5年CAGR))
       营收 CAGR≤0（营收萎缩）→ g_sustain=0，成长价值退化为一次性 = b×E_norm×(VCF−1)（无 /(r*−g) 永续项），
                                标"营收负增长，成长价值仅计一次性超额回报，IV≈EPV"
       ——护城河保的是现有盈利能力，营收萎缩的生意不得凭高 ROIC 外推正永续 g
    若 g_sustain ≥ r* → 不用戈登式，成长价值改按"未来3-5年增值贴现"有限期估，标 ⚠️

  成长价值 = 成长价值_毛 × κ          （κ 来自关卡①a：合格=1.0 / 软折价∈[0.5,0.7] / 硬拦截=0）

内在价值（含成长）= EPV + 成长价值
  这是 R5 的估值上沿；Phase5 回报分解的"积极投资回报"项与此一致
```

## 关卡 ③ 边界情形

| 情形 | 触发 | 强制处理 |
|---|---|---|
| VCF<1 但公司在扩张 | 增量ROIC<r* | 成长价值=0 + 标"增长毁灭价值"，回标 Factor1.5 是否降 R4 |
| VCF>1 但营收萎缩 | 增量ROIC>r* 但营收3-5年CAGR≤0（格力型）| g_sustain=0，成长价值退化为一次性超额回报（无永续项），IV≈EPV 为主锚，标"Magna教训:护城河保盈利不保增长" |
| VCF>1 但管理层历史错配 | C类≥20%+已证实减值 | 关卡①a 硬拦截：成长价值=0（主业回报高不救场），回标 Factor1.5 R5→R4 |
| VCF>1 且 C类偏高无减值 | C类≥20% 无减值 | 关卡①a 软折价：成长价值×κ∈[0.5,0.7]，标监控 |
| 增长全靠并购 | Δ投入资本≈Δ商誉 | VCF 标外延口径 + 商誉减值风险提示 |
| 留存高但不增长 | b>2/3 且盈利平 | VCF≈0，标"留存资本沉淀未增值" |
| B类低毛利业务占比大 | Factor1C B类>15% | 增量ROIC 按 B类拖累下调（对齐 factor3 λ 的 B类修正）|
| franchise≤0 却 VCF>1 | 勾稽矛盾 | VCF 封顶1 + 回标 Phase3/Factor1B（无护城河不可能持续高增量回报）|
| g_sustain≥r* | 增长≥门槛 | 禁用戈登永续，改有限期，标 ⚠️ |

## 关卡 ④ 强制敏感性

```
VCF 三档（禁止单点）：
  悲观 = 增量ROIC(取近段低值 或 经验规则下沿) / r*_high
  基准 = 主算法 / r*_base
  乐观 = 增量ROIC(有机口径高值) / r*_low
成长价值三档 → 内在价值(含成长)区间 = [EPV+成长_低, EPV+成长_高]
裁决含义：
  VCF 三档均>1 → 成长确实增值，稳健
  VCF 跨1 → 成长价值不确定，内在价值以 EPV 为主锚，成长仅作上沿
  VCF 三档均<1 → 增长毁灭价值，确定性排除成长溢价
```

## 关卡 ⑤ 裁决联动

```
① 给 Phase5：VCF → 积极投资回报 = (增量ROIC−r*)×b×(V/M)
   VCF>1 该项为正（增长贡献回报）；VCF≤1 该项=0 或负
② 给 Factor4 成长溢价上限：
   内在价值(含成长) = EPV + 成长价值，作 R5 估值上沿
   VCF≤1 → 内在价值封顶=EPV，禁止任何成长溢价（防为无效增长付费）
③ 路由回标：VCF<1 且公司高投入 → 提示 Factor1.5 该标的可能是 R4 成长陷阱

传递字段：VCF三档、增量ROIC、有机/并购拆分、成长价值三档、内在价值(含成长)、g_sustain
```

*龟龟投资策略 · Graham 深化 Phase 6 · VCF + 成长价值*
