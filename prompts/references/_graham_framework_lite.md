# 格雷厄姆–格林沃尔德估值框架（精简执行版 · 综合派）

> 一句话定位：把一份财报压成 **三块价值（AV/EPV/成长）→ 定性分六路 → λ 兑现打折 → 一个裁决**。
> AI 拿到财报数据后照本流水线一路走到底，中途不得跳步。所有折现统一用 r\*（资金成本），
> II（穿透回报率门槛）只用于"GG 兑现闸门"，**绝不进任何折现分母**。
>
> **📖 渐进式披露**：本卡是执行主干。凡遇到 `细则见 factor_XXX.md` 的引用，用工具
> `read_framework_reference(name=...)` 拉取该执行器全文再动手，别凭印象编。短名映射：
> asset_value / epv / routing / growth / incremental_growth / cost_of_capital / r5_return。

## §0 输入 / 输出

**输入**：三大报表（≥5 年，越长越好覆盖一个完整周期）、股本、分红记录、行业资金成本区间。
**输出（固定字段）**：路由 / AV / EPV / 成长价值 / IV / 分红率 / V_cash / λ(①②③) / V_final / MOS / 裁决。

原则：**估算优先于空着**——任一输入缺失，用同业中值或历史均值补，并在该行标 `⚠️估算`，绝不留空跳过。

## §1 数据归一 · 正常化盈利 E_norm（地基，最费功夫的一步）

目标：把"当期会计利润"还原成"这门生意在中周期、正常竞争、正常税负下每年能持续赚到的归母利润"。

**逐项调整（按顺序做，每项留痕）：**

1. **去一次性损益** — 剔除资产处置损益、减值/转回、诉讼赔偿、一次性政府补贴、重组费用、公允价值变动等非经常项。判据：不会年年发生的，全去掉。
2. **去周期** — 对强周期业务（资源/化工/航运/地产），不用当期利润率，改用 **一个完整周期（通常 5–10 年）的平均营业利润率 × 当期收入**。弱周期业务可跳过。
3. **税率归一** — 用正常化有效税率（近 3–5 年均值）或法定税率重算税后，剔除税收优惠到期/一次性递延税的扰动。
4. **折旧 ↔ 维持性资本开支校正** — 账面折旧 ≠ 真实维持性 capex。若维持性 capex 明显高于折旧（重资产老化），用维持性 capex 替代折旧压低 E_norm；反之亦然。
5. **费用化 ↔ 资本化还原** — R&D、品牌广告若被当期全额费用化但实为长期资产（特许经营常见），按其经济寿命摊销回来，抬高 E_norm；反向的资本化滥用则费用化打回。
6. **归母口径** — 一律扣少数股东损益，落到**归母**；EPS 用归母 / 总股本。

> E_norm = 归母正常化利润。后续 EPV、λ 全部基于它，不用当期净利润。

> ⚠️ **营收口径一致性（防止全文数字打架）**：A股利润表有两个营收口径——**营业总收入**（含其他业务收入，mda.json/年报口径）与 **营业收入**（compute_bundle 的 `_income_raw.revenue` 口径），两者可差数亿至数十亿，同比%也不同。
> **全报告只锚定一个口径贯穿始终**，另一口径若必须出现，须在**首次出现处**并列标注差异，例：`营业总收入1,711亿(YoY-9.96%) / 营业收入1,704亿(YoY-9.89%)`。
> 严禁 Ch1 用 1,711、Ch2 用 1,704 却都不标口径——读者无法判断 YoY 到底几个百分点。**营收CAGR、临界营收、增长率等所有派生量必须声明用的是哪个口径**。

**关键利率（先定死，全程复用）：**
- **r\*** = 资金成本（WACC 或权益成本）。所有折现、所有价值分母都用它。
- **II** = 穿透回报率门槛（你要求的最低回报）。只用于 §6 的"GG 兑现闸门"，不进任何折现。

## §2 AV · 资产价值（从资产负债表出）· 逐项重估，不许一句带过

核心问题不是账面值，而是**"新进入者今天复制这盘生意要花多少钱"（重置成本）**。逐项调整、每项留痕，禁止用"净资产+品牌≈X亿"一句概括。
> 完整细则（Magna 三类无形案例、边界情形、置信区间）见 `factor_资产价值重置成本.md`。下面是执行主干。
>
> **⚠️ 数据来源铁律**：有形行项的原值**不在 compute_bundle 里**（bundle 只有 net_cash/现金结构），
> 必须用 `search_report(query="货币资金 应收账款 存货 固定资产 无形资产 商誉 负债合计")` 从年报全文抓（多词按 OR 命中，
> 返回带金额的行；也可 `read_section(section=STMT)` 读财务报表节），
> 逐行抄下这些科目的账面原值再做调整。
> **绝不允许**图省事直接取 bundle 或年报的"归属于母公司净资产"一坨当有形 AV——那是账面值不是重置成本，
> 且跳过了 应收坏账/存货过时/固资通胀 三处关键调整。有形侧至少留下 4 行 bridge（账面→重置）。

**A. 有形资产重置（逐项，每项一行）：**

| 资产项 | 重置口径（持续经营） | 清算口径（困境 R1） |
|---|---|---|
| 货币资金 | 账面 ×1.0 | ×1.0 |
| 应收账款 | 账面 − 额外坏账折扣（一年以上占比高→多扣 5–15%） | ×0.8 |
| 存货 | 账面 × 行业系数（快消 0.9–1.0 / 时尚科技易过时 0.5–0.7 / 大宗 0.9） | ×0.3–0.6 |
| 固定资产 | 原值 ×(1−累计折旧率)× 通胀因子(默认 1.1–1.3)；专用设备再打折 | ×0.3–0.5 |
| 投资性房地产 | 公允价值，否则账面 ×0.8 | 市值 |
| 长期股权投资 | 上市按市值 / 非上市按账面 | 可回收值 |
| 商誉 | **不直接计入**（重建成本另算），标"账面商誉≠重置价值" | 归零 |

**B. 隐性无形重建（散户最缺、也最不能省——护城河生意的品牌/客户/研发在账上几乎为零，但重建要真金白银）：**
- **客户关系**：达到当前收入所需累计获客投入 ≈ 销售费用获客部分 ×1–3 年（无明细→销售费用×50%×2年，标⚠️；再缺→收入×行业获客率 消费15%/工业5%）
- **品牌**：近 5 年广告/品宣费累加现值（无明细→收入×消费5-10%/工业1-2%×3年，标⚠️；代工/大宗型→品牌=0）
- **研发/牌照**：研发费近5年累加×仍有效比例（按半衰期衰减）；政府牌照按取得成本/行业交易价，标⚠️给区间
- ⚠️ 强制：本项是估算区间不是精确数，给 [低,高]。除非确认无品牌/无研发/无客户壁垒，**绝不设 0**。

**C. 两口径合成 —— 持续经营用「账面净资产 + 增量法」（铁律，防漏资产）：**
```
⚠️ 绝不用「Σ列出的资产 − 负债合计」——你永远列不全资产（交易性金融/预付/其他应收/合同资产/
   递延税/使用权… 几十行），漏几行再减全额负债 → AV 系统性腰斩。改用增量法从账面净资产起步：

AV_going = 归母净资产(账面)                     ← 已含全部资产且已减全部负债，完整、不漏
         − 账面商誉 − 账面无形(若按重建口径重算)   ← 剔除账面虚项
         + Σ有形重置增量(仅调整项，非全额)         ← 应收(−坏账) 存货(×系数−账面) 固资(×通胀−账面) 等，只加"重置−账面"的差额
         + 表外无形重建(客户/品牌/研发牌照)         ← 账上没有、重建要花钱的护城河资产
  即：账面净资产是地基，只把"重置≠账面"的差额和表外无形叠上去。

AV_liq   = 货币 + 应收×0.8 + 存货×0.3-0.6 + 固资×0.3-0.5 + 投资 − 负债全额，无形=商誉=0  （清算地板≈NCAV加严版）
```
> **完整性自检（强制）**：若坚持用"Σ资产−负债"全额重建法，则 Σ列出的有形资产必须 ≈ 资产总计（误差<10%），
> 否则说明漏了资产行项，结果作废、改用增量法。增量法天然对齐账面净资产，无此风险。

口径跟路由走：持续经营取 AV_going（AV_liq 作地板）；distress 取 AV_liq（对应 R1）。

**D. 三档区间（无形不确定性主导，数据越缺区间越宽）：** AV_low/base/high = 账面净资产 + 有形重置增量(保守/基准/足额) + 表外无形(下沿可能0/中值/上沿)。每股 AV = AV/总股本；必输 AV/市值 比。

**E. 输出必须是这个形状（增量法：账面净资产地基 + 逐行重置增量 + 表外无形，不许塌成一坨）：**
```
基地：归母净资产(账面) = 1459 亿                        ← 完整,已含全部资产减全部负债
有形重置增量（只记"重置−账面"的差额，单位亿元）：
  货币资金   1105 ×1.0            → 增量  0
  应收账款    160 −6%坏账追加     → 增量 −10
  存货        282 ×0.9(标准品)    → 增量 −28
  固定资产    344 ×1.15(重置通胀) → 增量 +52   ← 账面折旧后原值抬回重建成本
  有形重置增量合计 = Σ差额 = +14 亿             （小,因多数资产重置≈账面）
剔除账面虚项：− 账面商誉 13 − 账面无形(改重建) 90 = −103 亿
表外无形重建（估算区间⚠️,账上没有）：客户关系 X | 品牌 X | 研发/牌照 X → 小计 [低,高]
= AV_going = 1459 + 14 − 103 + 表外无形 = [low, base, high]
AV_liq（清算地板,独立算）= 货币 + 应收×0.8 + 存货×0.3-0.6 + 固资×0.3-0.5 + 投资 − 负债全额 = X
每股 AV = X 元 | AV/市值 = X.XX | EPV/AV = X.XX → 护城河情形[A/B/C] → 路由 R?
```
> ⚠️ **反例 A（经典漏资产）**：只列6行资产合计 1952 再减负债2416 → AV=267亿。
> 错：漏掉~1960亿非headline资产，但减了全额负债。
>
> ⚠️ **反例 B（新型变种，审计锁必捕）**：逐行列出6行资产 + 无形重建731，然后整体减负债：
> `AV_going = 1952 + 731 − 2416 = 267亿` ← **与反例A等价，仍然错！**
> 无论加了多少无形重建，只要公式里出现「有形合计 + 无形 − 负债合计」就是禁止的。
>
> ✅ **唯一正确写法**（增量法，归母净资产为基地）：
> `AV_going = 1459（归母净资产） − 103（虚项） + 14（重置增量） + 731（表外无形） = 2101亿`
> 基地里已含全部资产减全部负债，不需要也**不许**再减一遍负债。
>
> ⚠️ 若某行确实拿不到原值（附注缺失），写"账面 X ⚠️估算×系数"占位，**仍要留行**，不许合并省略。

## §3 EPV · 盈利能力价值（从利润表出）

```
EPV = E_norm / r*          （零增长永续，纯粹"现在的赚钱能力值多少"）
EPV(调整后) = EPV + 超额现金/非经营性资产 − 净有息负债
```
> EPV 假设**不增长**。增长价值单独在 §5 算，且只有 R5 才给。
> ⭐ **r\* 含投资者门槛地板 r_req（默认 10%，详见 `factor_资本成本与正常化盈利.md` 关卡④.5）**：
> `r* = max(业务风险分档 r*, r_req=10%)`。低风险优质股业务 r* 若<10% 会被地板抬到 10%，EPV/IV/V_final/回报安全边际全按 floor 后 r\* 算。
> **II 不受此地板**（穿透闸门用股息现金口径，floor 会失真）——floor 后 r\* 与未 floor 的 II 分裂是预期行为。
> 永续推导、r\* 与 E_norm 的选取细则见 `factor_EPV盈利能力价值.md`、`factor_资本成本与正常化盈利.md`。

> ⚠️ **当前 PE 必须引用工具真值，禁止自行推算（防幻觉）**：当前 PE 一律用 `compute_bundle.factor4.current_pe`（= MC归母口径 / NP归母，工具已算好）。
> **绝不允许**自己拿"股价 / EPS × 归母比例修正"之类的临时算式另推一个 PE——这类"修正"没有数据依据，会得出与工具真值矛盾的第二个数（如工具 7.2x 却手写 5.7x）。
> 全报告的"当前PE"只有一个值，就是 `current_pe`。行业PE、GG隐含PE(1/GG)、DDM隐含PE(公允价/EPS) 是**不同口径**，引用时必须写明是哪一种，不得与 current_pe 混用比较而不标注。

## §4 枢纽 · EPV↔AV 对比定护城河，选路由（六选一）

对比 EPV(调整后) 与 AV(归母)，这是全框架分叉点：

| 路由 | 触发条件 | 含义 | 取 IV |
|---|---|---|---|
| **R1 困境** | 持续亏损 / 资不抵债 / E_norm≤0 | 生意在毁灭价值，看能拆出多少 | **AV 清算** |
| **R2 可复制** | EPV ≈ AV（±20%），无壁垒 | 竞争把利润磨平到重置成本 | **AV 重置** |
| **R3 稳定无护城河** | EPV ≈ AV，经营稳定 | 赚合理回报但不超额 | **EPV** |
| **R4 毁灭价值** | EPV < AV（明显） | 管理层把好资产做亏 | **min(AV×折价, EPV)** |
| **R5 特许经营** | EPV ≫ AV（>20%）**且能说清壁垒来源** | 有护城河，超额回报可持续 | **EPV + 成长价值** |
| **R6 复杂/多业务** | 各板块商业模式异质 | 无法整体估 | **分部 SOTP**，每部各走 R1–R5 |

> 铁律：EPV≫AV 但**说不清壁垒从哪来**（是品牌？成本？网络？牌照？转换成本？），一律**不给 R5**，降级 R3。超额回报没有来源解释 = 会被竞争抹掉。
> EPV/AV 比值分档（情形 A/B/C）与护城河勾稽细则见 `factor1.5_估值路由.md`。

## §5 成长价值（仅 R5）

只有确认护城河，增长才创造价值（无护城河的增长只是烧钱扩张，NPV≤0，记 0）。

```
成长价值_毛 = 护城河内的增量投资 × (ROIC − r*)/r* 的折现   （或用两阶段 DCF 的成长段）
成长价值   = 成长价值_毛 × κ                              （κ = 资本配置纪律闸门系数）
IV(R5) = EPV(调整后) + 成长价值
```
其余路由：**成长价值 = 0**，IV 即路由取值。

> ⚠️ **成长现实闸门（书 · Magna 教训 · 增长不可凭 ROIC 空想）**：护城河保住的是**现有盈利能力**（EPV），不自动附送增长溢价。
> Greenwald 的麦格纳案例说的是：成熟/竞争性行业里，即便增量回报看着高，也不能外推一个正的永续 g——增长价值的上限由生意**真能以特许权回报再投的量**决定，而这被**真实营收轨迹**卡死。
> 一门营收在萎缩的生意，没有有机增长可供资本化；κ 再高、ROIC 再高，都不能凭空生出永续 g。
> ```
> g_sustain 硬顶：g_sustain ≤ min(名义GDP, 5%, max(0, 营收3-5年CAGR))
>   营收3-5年CAGR ≤ 0（如格力连续两年下滑）：
>     → g_sustain = 0。成长价值退化为"一次性资本化超额回报" = 留存利润 × (ROIC−r*)/r*（无永续增长项）
>     → 严禁用 年增值/(r*−g) 的戈登式（g>0 会把萎缩生意估成增长股）
>     → 标"营收负增长，g_sustain=0，成长价值仅计一次性超额回报，IV≈EPV 为主锚"
>   营收3-5年CAGR > 0：g_sustain 取 CAGR 与硬顶的较小值，正常戈登式
> ```
> 语义：护城河 + 营收萎缩 = R5 仍成立（EPV 有超额回报），但 IV 应贴近 EPV，成长价值近零。
> 把萎缩生意估出大额成长价值 = 典型的"好公司幻觉高估"，正是麦格纳教训要防的。

> ⚠️ **资本配置纪律闸门（书 ch8/9 · D2 · 管理层作为价值变量）**：R5 叠加成长价值前，必须先过管理层历史资本配置检验。VCF 说的是"增量回报够不够高"，闸门说的是"管理层过去把留存利润投到了哪里"。
>
> **cap_alloc_score 评定（读§4-§5 Capex/并购/回购/减值历史，5-10年）：**
> | 评级 | 判定标准 | κ | 路由影响 |
> |---|---|---|---|
> | 优 | C类（非主业）<10% Capex + 增量ROE>r*稳定 + 无已证实减值/并购亏损 + 分红随盈利提升 | 1.0 | 保 R5 |
> | 中 | C类10-20% 或回购时机一般，无已证实减值/并购亏损 | 1.0 | 保 R5 |
> | 差 | C类≥20% 或 ≥1次已证实并购亏损（商誉减值/投资亏损/**收购标的长期经营性亏损**），但非系统性 | [0.5,0.7] | 保 R5 软折价 |
> | 劣 | C类≥20%+已证实并购亏损，或≥2次大额并购持续亏损 | 0 → 成长价值归零 | R5→R4 降级 |
>
> ⚠️ **评级是「触发式」不是「加权平均」**：四档按"至少一条触发"就位取**较差**的那一档，**不得**用分红好、
> 商誉已减值、规模可控等正面项去"抵消/中和"已触发的负面档，把"差"拉回"中"。一旦命中"差"或"劣"的任一触发条件，
> 评级即锁定在该档（或更差），正面项只用于在"优/中"之间取舍，不能上翻已触发的负面档。禁止输出"中（边界偏差）"
> 这类骑墙表述——命中差就写差。
>
> ⚠️ **"并购亏损"的判定（防止窄读为"商誉减值计提"）**：判据看的是"资本配置错误是否已被现实证实"，
> **不是"账上是否有减值分录"**。收购标的持续经营性亏损、或收购后长期未证明正向回报，即使**未计提**商誉减值、
> 即使占总资产比例不大，也构成"已证实并购亏损"。"规模可控/暂无商誉减值/商誉已减值完毕"均**不足以**把已证实的持续亏损降级为"中"。
> 【示例 格力钛（银隆）】：司法拍卖取得、与空调主业协同度低、长期亏损至今未证明正向回报、管理层不剥离反而
> 继续推进手机/芯片/新能源多元化 → 命中"差"（≥1次已证实并购亏损+管理层继续多元化）；商誉仅剩少额不构成豁免理由。
>
> 若没有足够的5年 Capex/并购/减值数据 → fallback：c_ratio<20%+无并购亏损 → 优/中；c_ratio≥20%+有并购亏损 → 劣（标⚠️D2数据不足）。
>
> ⚠️ **一美元测试前置闸门（书 ch12 巴菲特 · 详见 `factor_管理层资本配置.md` 步骤2.5）**：定档前先过留存回报检验——
> 留存额_5y=Σ(归母净利润−分红)，拆经营/并购/**闲置现金**三桶算加权回报 R_dollar。**R_dollar<r\*（比率<1.0）→ cap_alloc_score 上限「差」**，
> 不得因叙事面尚可给"中/优"。补的是 VCF 看不见的分母（闲置现金趴低回报）。反混淆：分子禁用市值增量（避板块 de-rating）、
> 禁用 ΔE_norm 下降直接判负（避需求下行误伤），只惩罚管理层可控的闲置/毁值配置。
>
> **【强制输出·D2 诊断行】** 估值章必须显式写出一行，不得省略、不得只在 λ③ 里隐式带过：
> `cap_alloc_score=优/中/差/劣（依据：C类占Capex X% + 减值历史Y + 分红趋势Z），κ=数值，路由影响=保R5/降R4`
> 即使后续 λ③ 因 g_disc 已定价而豁免负档，该评级仍须先落地——κ（IV 层）与 λ③（兑现层）是两个独立结论，不可用其一替代另一。
>
> 增量投资 ROIC、两阶段 DCF 成长段算法见 `read_framework_reference(growth)`。

## §6 λ 兑现合成（综合派 · 唯一裁决哲学）

§1–§5 算出的 IV 是"这门生意内在值多少"。但内在值不等于**到小股东手里的值**——留存的价值要不要算数，取决于生意能不能持续兑现、护城河能撑多久、管理层会不会把钱截留。λ 就是这个"兑现信用折扣"。

**唯一合成公式：**
```
分红率  = min(dps_fy / EPS归母, 1.0)  —— dps 必用 dps_fy(全年分红预案:中期+年度末期合计)
          ⚠️ 绝不用 dps_ttm。dps_ttm 是"近12月滚动窗口碰巧落账"的取数假象，
             对中期+年末两次派息的公司会系统性腰斩分红率(如格力 dps_ttm=1.0 vs dps_fy=3.0)。
          ⚠️ 中期分红+年度分红是 A 股/港股蓝筹常规结构，不是"特别股息"，不得以此为由砍到常规口径；
             除非年报原文明写"特别股息/特别分红"字样，否则 dps_fy 全额计入。
          dps>EPS 记 1.0 并标"分红超盈利⚠️"
V_cash  = 分红率 × IV                  —— 已经变成现金到手的那部分（确定）
V_final = V_cash + λ × (IV − V_cash)
        = IV × [分红率 + λ × (1 − 分红率)]
```
语义：λ=1 → V_final=IV（留存全算数，纯格林沃尔德）；λ=0 → V_final=V_cash（留存全不算，纯 GG 只认分红）。

> ⚠️ 铁律：**V_cash 与 IV 必须同用 r\* 折现**。II 只进下面的兑现闸门，绝不作 V_cash 的折现率——用 II（<r\*）会把 V_cash 推高到超过 IV，令 λ 反号（护城河越强反而估越低）。

**λ 打分（基准 0.5，三项相加，clip 到 [0,1]）：**

| 因子 | +档 | −档 |
|---|---|---|
| **① VCF**（价值创造，≈(ROIC−r\*)相对强弱） | ≥1.3→+0.25；1.1–1.3→+0.15；0.9–1.1→0 | 0.7–0.9→−0.15；<0.7→−0.25 |
| **② 护城河半衰期** | ≥30 年 → +0.15；15–30 → +0.05 | 8–15 → −0.05；<8 年 → −0.15 |
| **③ 治理 / 资本配置（D2）** | cap_alloc_score=优→+0.10；中→0（基线） | 差→−0.15；劣→−0.25 |

```
λ = clip(0.5 + ① + ② + ③, 0, 1)
```

> ⚠️ **③ 取值必须两步链，不得跳步（书 ch8/9，防重复扣减）**：
> **第一步 · 定基线 ③_base**：从 §5 已落地的 `cap_alloc_score` 直接查表 —— 优→+0.10；中→0；差→−0.15；劣→−0.25。
> 这一步锚定"管理层资本配置本身值几分"，不看价格。禁止跳过 cap_alloc_score 直接下 ③ 值。
> **第二步 · 已定价豁免（限存量·不豁免流量）**：治理风险若**已反映在现价**（现价 PE/PB 显著低于同业中位），
> 在 λ③ 再扣一次 = 对同一问题罚两遍。但**低PE只能吸收"已发生/已停止"的治理损害（存量），吸收不了"仍在持续"的损害（流量）**——
> 因为 λ③ 管的正是"未来留存利润会不会被继续截留/浪费"，这恰恰是价格看不到的前瞻渗漏。故豁免**必须先分存量/流量**：
> ```
> 判定1：g_disc = 1 − 现价PE / 同业中位PE      （治理折价已定价程度）
> 判定2 · 持续破坏闸门（flow-destruction gate，三条全可从数据观测）：
>   (a) 已证实的亏损标的/并购是否仍在表内、未剥离、未止损？         [governance/risks.json]
>   (b) 近2年管理层是否仍在发起新的非主业多元化（新赛道/新收购）？   [mda.json strategy_changes]
>   (c) 增量留存利润是否【无】约束性返还承诺（无长期分红政策/无回购注销）？[governance.json 分红政策]
>   命中数 = (a)(b)(c) 中为"是"的条数
>
>   分支① g_disc ≥ 0.3 且 命中 ≤1（破坏已基本停止，损害是存量/历史）：
>     → ③_base<0：负档全豁免，③ 上调至 0（治理有改善迹象再给期权价值 0~+0.05）
>     → ③_base≥0：维持 ③_base
>   分支② g_disc ≥ 0.3 且 命中 ≥2（破坏仍在流动，未来留存利润将持续渗漏）：
>     → ③_base<0：**只豁免存量部分，负档保留一半** ③ = ③_base × 0.5
>        （λ 就近取到 0.05；因低PE定价了"已发生"、定不了"仍在发生"，而 λ③ 正是管后者）
>     → ③_base≥0：维持 ③_base
>   分支③ g_disc < 0.3（现价未明显折价，风险尚未被市场定价）：
>     → ③ = ③_base 原值（负档照扣，无论闸门）
>
>   标注格式："cap_alloc_score=X → ③_base=Y；g_disc=A%（PE B vs 同业 C）；持续破坏闸门命中 N/3 [列出命中项] → ③ 终值=Z"
> ```
> ⚠️ 这条"存量/流量拆分"是刻意的中间路线：既不像旧规则无差别豁免到0（放过了未来渗漏），也不像"负档照扣"重复计数过去。
> 因无法精确拆分低PE里"过去/未来"的占比，命中流量时取"保留一半"作为**可复现的规则值**（非个案裁量），谁来跑都得同一个数。
> 注意区分层次：**资本配置的毁灭价值**已在 §5 闸门（κ）/factor1.5（R5→R4）处理过——那是对"内在价值 IV"的调整；
> λ③ 处理的是"IV 到小股东手里的兑现折扣"里的治理维度。二者不同层、不同基数（κ 只缩放成长价值；λ③ 缩放留存部分），不构成重复计数。

**GG 兑现闸门（唯一用到 II 的地方）：**
```
GG_base = 分红率 × E_norm / II          （只做门槛判断，不进 V_final）
若 GG_base < II 对应的隐含价值门槛 → λ 封顶 0.3
```
含义：连穿透回报率门槛都够不着的兑现能力，留存价值最多只给 30% 信用。

> ⚠️ **反向压力测试的临界营收：只引用工具值，禁止自行另算（防前后矛盾）**：GG=II 时的临界营收一律用 `compute_bundle.factor3.lambda_sensitivity.critical_revenue`。
> **绝不允许**在工具值之外再用"AA与营收线性相关、每降1%降1.5%"之类的简化外推算第二个临界营收——那会得到两个互相打架的数（如工具 1,585亿 却手写 1,267亿）。
> 若工具挂 `critical_revenue_warning`（λ不稳定/符号翻转），照抄警示并标"临界营收粗略参考、可信度低"，**但仍只用工具那一个值**，不得因"不可靠"就用手算值替换。全报告临界营收有且只有一个数。

**特殊路由处理**：R1/R2/R4（AV 系）不走 λ——它们本就不承认盈利能力，IV 即终值，V_final=IV。R6 分部各自算 V_final 再加总。

## §7 安全边际 → 裁决

```
MOS = (V_final − 现价) / V_final
```
| MOS | 裁决 |
|---|---|
| ≥ 40% | 买入 |
| 15%–40% | 观察 / 逢低 |
| −15%–15% | 持有（合理定价） |
| < −15% | 卖出 / 排除 |

叠加：**单只个股最高仓位 5%**（硬约束）。R1/R4（价值毁灭系）即使 MOS 达标也降一级处理。

> ⚠️ **累计/合计值自检（防正文与分年表打架）**：凡在正文写"五年累计约X"这类合计（分红累计、Capex累计、并购累计等），
> **X 必须等于同章分年表逐行加总**，不得凭印象给一个偏离值（如分年表 112+56+112+168+168=616亿，正文却写"~560亿"）。
> 写下合计前，先把分年表各行显式相加验一遍；分年数据有区间(~)时，合计也用区间上下界，不得取一个表内推不出的点值。

## §8 心智模型（一句话记住全流程）

> **三块价值比大小定性质，一次分红率算到手，一层 λ 折兑现信用，最后一个 MOS 下裁决。**
> 全程 r\* 折现，II 只守闸门。说不清壁垒不给护城河，无护城河的增长记零。
