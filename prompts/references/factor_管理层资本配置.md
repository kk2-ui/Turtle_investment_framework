# 因子：管理层资本配置评估（D2 · 书第8/9章）

> **D2 产出**。书第8/9章核心主张：管理层的历史资本配置行为是成长价值的前提，不是装饰标签。
> 本执行器把管理层评估从"治理标注"升级为"价值变量"——不仅判断治理好坏，还量化它对成长价值的影响，并识别治理折扣是否已被市场定价。
>
> **两层产出**：
> 1. `cap_alloc_score`（优/中/差/劣）— 历史行为质量，直接影响成长价值闸门
> 2. `gov_priced_in`（已定价/未定价/部分）— 市场是否已反映治理折扣，影响仓位与催化剂判断
>
> **上游依赖**：factor1C（C类多元化特征/毁灭价值历史）、factor1B（护城河/franchise_type/治理）、
>   §4（资本结构逐年）、§5（现金流量表：Capex/收购/分红/回购）、§12（回购记录）。
> **下游传递**：factor_VCF 关卡①a（cap_alloc_score → 成长价值准入闸门）、
>   _graham_integration λ③（治理打分细化）、Factor4（gov_priced_in → 买点结论注释）。
>
> 母版 `_executor_template.md`；路线图 `docs/turtle_graham_deepening_roadmap.md`。
> **全局原则**：数据不足给近似判断 + ⚠️，绝不"无法评估"。

## 定位与指令

> **书第8章核心逻辑**：增长创造价值的前提是"管理层真的把留存利润投到高回报方向"。
> VCF（因子_VCF关卡①a）只检验"增量资本回报够不够高"——即**有没有高回报机会**。
> 本执行器检验"管理层历史上有没有把钱投对地方"——即**有没有执行能力与意愿**。
> 两者独立：主业ROIC极高 + 管理层把现金流系统性投向毁灭价值的非主业 → 成长价值为零。
>
> **书第9章核心逻辑**：管理层评估看行动，不看表态。
> 过去5-10年的资本配置记录（并购价格合理性、回购时机、资本返还纪律）比任何访谈更可信。
> 此外需判断"市场是否已定价这个治理问题"——若已定价，折扣是催化剂潜力；若未定价，是隐性下行风险。

**指令**：按步骤1-4逐步执行。步骤1-3 产出 cap_alloc_score；步骤4 产出 gov_priced_in。
数据来源优先§12回购/§5现金流量/§4资产负债，定性证据补充。

## 步骤1：历史资本部署梳理（5-10年）

```
目标：识别资本流向的结构性模式（不只是某一年的异常行为）

A. 主业再投资（有机扩张）
  规模：Capex − 折旧DA（有机净增投入，历年）
  质量：主业毛利率趋势 + 产能利用率（若有）
  判断：主业ROIC > r* 且趋势稳定 → 正面证据

B. 外延并购
  规模：并购支付现金 + Δ商誉（逐年）
  价格合理性：并购支付 / 被并购公司合理EPV（精确算难→定性比较，附原文披露）
  事后回报：收购后1-3年被并购子公司利润率趋势（§分部报告 或 合并口径对比）
  减值记录：是否出现过商誉减值、投资亏损（§4附注）
  主/非主业判断：与factor1C步骤2的A/B/C分类对齐

C. 资本返还（分红 + 回购）
  分红：DPS趋势 vs EPS趋势（是否随盈利增长同步提升，还是被压低）
  回购时机：回购年度对应P/B历史区间
    P/B < 历史中位数 → 时机合理（低价回购，利好留存股东）
    P/B > 历史中位数×1.5 → 时机不佳（高价回购，消耗价值）
    无回购 + 大量现金堆积 + 无好投资 → 不作为的机会成本

D. 其他：债务偿还、募资时机
  在无优质再投资机会时偿债/不融资 → 正面
  在项目回报存疑时高溢价定增/发债扩张 → 负面
```

## 步骤2：价值创造因子量化（书第8章）

```
核心公式（书ch8 §价值创造因子）：
  增量ROE = ΔNOPAT_近5年累计 / Δ投入资本_近5年累计   （与factor1C步骤1对齐，避免重复算）
  价值创造因子 VCF = 增量ROE / r*   （此值即 factor_VCF 的 VCF，复用，不重算）

补充维度：增量ROE趋势方向（比单点值更重要）
  上升趋势（近5年平均 > 早5年平均）→ 资本配置能力改善中
  下降趋势（反向）→ 护城河侵蚀或错配加剧，即使当前值 > r* 也要打折
  平稳但持续 > r* → 稳定的价值创造者

并购回报率校验（若并购占比>30% Capex）：
  并购增量ROE ≈ 并购带来ΔNOPAT / 并购支付现金（factor1C步骤1优先级2）
  对比主业增量ROE：
    并购增量ROE > 主业增量ROE → 收购能力强，正面
    并购增量ROE < r* → 外延持续毁灭价值，即使主业再好也要惩罚

回购价值检验（书ch8 §假设市值等于内在价值的影响）：
  回购合理性 = 回购时均P/B vs 估算账面价值倍数（粗判）
    P/B < 1.0 → 回购必然增值（低于净资产）
    P/B 1.0–1.5 → 取决于ROE > r*（若ROE远高于r*，回购仍合理）
    P/B > 2.0 × 历史平均 → 高价回购，损害留存股东
  数据不足时：用回购年份股价是否在历史高点附近作近似判断
```

## 步骤2.5：留存收益回报测试（巴菲特一美元测试 · 书 ch12）

> **书第12章巴菲特核心标尺**："每留存一美元利润，是否至少创造了一美元的市场价值？"
> 这是判断资本配置最客观的历史检验。本步把它落成**可复现的留存池加权回报**，
> 用来给 cap_alloc_score 一个**硬约束闸门**——堵住"运营ROIC很高、却把大量留存趴成低回报现金"的假象。
> VCF/增量ROE 的分母只含**已投入运营资本**，看不见闲置现金；一美元测试补的正是这个分母盲区。

```
第一步 · 5年留存额（从 compute_bundle 逐年数组）：
  留存额_5y = Σ(归母净利润 − 分红总额)  最近5年
              [归母净利润: income 逐年; 分红总额: dividends.dividends_paid 或 cash_div_tax 逐年]

第二步 · 留存去向拆桶 + 各桶回报 vs r*：
  桶① 经营投入资本增量 → 回报 = 增量ROIC（步骤2已算，复用不重算）
  桶② 外延并购净额     → 回报 = 并购增量ROE（步骤2已算，复用不重算）
  桶③ 闲置现金/金融资产增量（VCF 看不见的分母）：
        闲置现金 = 期末货币资金+交易性金融资产 − 合理经营所需现金(≈营收×经营现金系数, 默认2%) − 有息负债
        Δ闲置现金_5y = 期末闲置现金 − 5年前闲置现金（>0 即"留存被囤积未部署"）
        桶③回报 ≈ 理财/存款收益率（通常 2–3%，客观 < r*=8%）
  权重 = 各桶增量 / 留存额_5y

第三步 · 留存池加权回报与测试比率：
  留存池加权回报 R_dollar = Σ(桶i权重 × 桶i回报)
  测试比率 = R_dollar / r*     （≥1 即"每留存1元至少赚回资本成本、创造≥1元价值"）
```

**判档（喂步骤3闸门）：**

| 测试比率 R_dollar/r* | 含义 | 对 cap_alloc_score 的约束 |
|---|---|---|
| ≥ 1.0 | 留存至少赚回资本成本 | 通过，不设上限 |
| 0.5 – 1.0 | 留存部分兑现，闲置/低效拖累 | **cap_alloc_score 上限「差」**（即使叙事面尚可，不得给"中/优"） |
| < 0.5 或负 | 留存大量沉没/囤积/毁灭 | **上限「差」**；若同时增量ROE<0 → 「劣」 |

> ⚠️ **反混淆铁律（否则会把行业下行错记成管理层的错）**：
> 1. 分子**禁用"市值增量"**——全行业估值下杀（板块 de-rating）不是管理层资本配置的错，只看留存资本自身的经济回报。
> 2. **禁止用"ΔE_norm 下降"直接判负**——正常化盈利下降可能纯是需求下行（营收萎缩），非配置失败。
>    测试只惩罚**管理层可控的配置选择**：闲置现金趴低回报（桶③）、并购毁值（桶②回报<r*），
>    这两桶的回报是客观的、与需求周期无关。
> 3. 数据不足（不足5年 or 现金构成拆不出）→ 只用桶③闲置现金定性判断 + 标⚠️，不强行算比率。

**标注格式**：`一美元测试：留存额_5y=X亿，闲置现金桶占Y%（回报~Z%<r*），留存池加权回报 R_dollar=A%，比率 A%/8%=B → 测试[通过/上限差/上限差(劣)]`

【示例 格力电器】：主业增量ROIC 高（桶①过 VCF），但期末货币资金+金融资产约 1,100 亿闲置、理财回报 ~2% ≪ r*=8%（桶③权重大），留存池加权回报被拖至 <r* → 一美元测试**上限「差」**，与叙事面（格力钛亏损+多元化）共同锁定 `cap_alloc_score=差`。这是对"差"评级的客观佐证，非叙事拍脑袋。

## 步骤3：行为模式打分 → cap_alloc_score

```
综合步骤1-2的证据，按以下四档评级。

⚠️ 前置闸门（步骤2.5 一美元测试硬约束，先于四档判定）：
  · 一美元测试比率 <1.0（留存池加权回报 < r*）→ cap_alloc_score 上限「差」，
    即使下方"优/中"的叙事条件看似满足，也不得给"优/中"。
  · 比率 <0.5 且增量ROE<0 → 直接「劣」。
  · 仅当一美元测试 ≥1.0（通过）时，才按下方四档正常评定"优/中"。

★ 优（cap_alloc_score = 优）：
  所有条件同时满足：
  ① 主业有机扩张为主（C类<10%），增量ROE > r* 且趋势稳平或上升
  ② 回购时机合理（低P/B时期回购 or 无回购但现金有效配置）
  ③ 无已证实商誉减值 or 仅1次小额（<总商誉5%）且已止损
  ④ 分红随盈利同步提升 or 在无好投资时有效返还资本
  → 管理层是成长价值的放大器；传 factor_VCF 全额通过（κ=1.0）

★ 中（cap_alloc_score = 中）：
  满足主条件但有瑕疵：
  ① 增量ROE > r*，但有少量C类（10-20%）且暂无减值
  ② 或：回购时机一般（无明显高价回购），分红稳定不优秀
  ③ 整体无系统性错配记录，但无突出资本配置纪律
  → 成长价值不调整（κ=1.0），route_confidence 降一档
  ⚠️ 前置排除：若已命中下方"差②"（已证实并购亏损+继续多元化），
     不得因"规模可控/暂无商誉减值"回落到"中"——已证实的持续亏损优先判"差"。

★ 差（cap_alloc_score = 差）：
  至少一条触发：
  ① C类投资占比 ≥ 20%（factor1C 已识别）
  ② 或：有1次以上已证实商誉减值/并购亏损 + 管理层未止损/继续多元化
  ③ 或：增量ROE趋势明显下行（近5年均值 < 早5年均值超过30%）
  ④ 或：高价回购记录（P/B历史高点附近大规模回购）且对留存股东形成明显稀释
  → 传 factor_VCF 关卡①a 触发软折价闸门B，κ∈[0.5, 0.7]

  ⚠️ "并购亏损"的判定（防止窄读为"商誉减值计提"）：
    "并购亏损"= 并购标的持续经营性亏损，或收购后未证明能产生正向回报，
    即使账面**未计提**商誉减值，也构成"已证实并购亏损"。
    判据②看的是"资本配置错误是否已被现实证实"，不是"是否有会计减值分录"。
    典型：以司法拍卖/高溢价取得与主业协同度低的标的，标的长期亏损，
      管理层不剥离反而继续同类多元化 → 命中②，判"差"（而非"中"）。
    【示例 格力电器格力钛（银隆）】：新能源客车/储能，与空调主业协同度低，
      长期亏损至今未证明正向回报，管理层持续推进手机/芯片/新能源多元化
      → 即使商誉仅剩少额、无大额减值计提，仍命中②，cap_alloc_score=差，κ∈[0.5,0.7]。
    反例（仍可判"中"）：并购标的虽非主业但已实现盈利/已止损剥离/规模极小(<总资产2%)
      且无后续同类多元化行为。"规模可控"单独一项**不足以**把已证实的持续亏损降级为"中"。

★ 劣（cap_alloc_score = 劣）：
  系统性错配，满足以下任一：
  ① C类投资≥20% + 已证实商誉减值/投资亏损（对齐 factor1C 毁灭价值历史）
  ② 或：多次（≥2次）大额并购后利润率持续下滑 + 管理层继续同类行为
  ③ 或：增量ROE为负但仍大规模留存不分配（钱进去不创造价值也不返还）
  → 传 factor_VCF 关卡①a 触发硬拦截闸门A，成长价值强制=0

边界数据不足：
  步骤1数据不足覆盖5年 → 标⚠️，打分降一档（不确定性惩罚）
  仅有定性证据 → 以 factor1B 治理评级 + factor1C 结论组合推断，标⚠️"定性推断"
```

## 步骤4：治理折扣定价分析（书第9章 · 已定价 vs 未定价）

```
目标：判断市场是否已将治理风险折扣计入股价。
  · 已定价 → λ③惩罚与市场折扣可能重叠；治理改善是催化剂（上行空间）
  · 未定价 → λ③折扣是唯一下行保护；价格可能进一步下行

A. 横向比较（当前P/E 或 P/B vs 同行业中位数）：
  折价≥25% → 市场已给予明显治理折扣（若其他基本面相近）
  折价5-25% → 部分定价
  溢价 or 折价<5% → 未定价

B. 纵向比较（当前P/B vs 公司自身历史P/B区间）：
  处于历史低1/4分位且近3年无重大基本面恶化 → 折扣可能反映治理忧虑
  处于历史高位或中位 → 治理问题未在价格中体现

C. 定性交叉验证（书ch9 §管理层评估）：
  市场/媒体近年是否广泛讨论该公司治理问题？
    是 → 支持"已定价"；否 → 支持"未定价"

综合 → gov_priced_in：
  已定价：A+B均指向折扣且C支持
  部分：A或B指向折扣
  未定价：A+B无折扣

gov_priced_in 买点结论注释（传 Factor4，不改变IV/V_final计算）：
  已定价 → "治理折扣已定价。若管理层改善（继任/股东压力/政策），
             存在催化上行空间。λ惩罚与市场折扣可能重叠，
             安全边际要求可适当放宽（但不免除）。"
  未定价 → "市场尚未定价治理风险。λ③折扣是唯一下行保护；
             若治理问题被市场关注，价格有进一步下行风险，需更大安全边际。"
  部分  → 中性注释，分情景说明
```

## 步骤5：数据不足降级阶梯

```
优先级1（完整5年+ 财务数据 + §12回购记录）：
  → 步骤1-4完整执行，cap_alloc_score 基于量化+定性双验证

优先级2（3-5年财务数据，§12缺失）：
  → 步骤1-2执行；步骤3主靠 factor1C 结论；步骤4仅做横向比较
  → 标⚠️"回购时机评估数据不足，cap_alloc_score 基于C类特征+减值记录"

优先级3（仅 factor1B/1C 定性结论）：
  → cap_alloc_score 定性推断：
    factor1B 治理负面 + C类>20% + 减值=有 → 劣
    factor1B 治理负面 + C类>20% + 减值=无 → 差
```
