# 有限期限资产与法律现金流

## 适用范围

出现下列任一特征时必须加载本规则：REIT、合营期限、土地或特许经营到期、采矿权、牌照、PPP、租赁资产、到期移交、清算、注册资本返还、法定储备或跨境利润上划限制。

## 为什么必须单独处理

有限期限资产不能套永续 EPV，但“经营权或物业权益到期后归零”也不等于“到期日没有现金”。到期前后的债务清偿、注册资本返还、清算分配、押金释放、残值处置和税费都可能形成材料性现金流。任何一个被遗漏，都可能改变永久损失、内在价值和 XIRR。

## 强制证据范围

不要只从近年年报起步。必须同时读取：

1. 首次发行文件、招股书或上市通函；
2. 合营、土地、特许经营、租赁及终止条款摘要；
3. 最新年报和中报中的期限、注册资本、债务、分派及附属公司清单；
4. 后续法律、信托契约和分派定义修订；
5. 有材料性影响的提前终止、续期、清算及资产移交公告。

采集模块至少检索并结构化：`expiry`、`termination`、`liquidation`、`repatriation`、`early repayment`、`registered capital`、`distributable depreciation`、`capital nature`、`residual value`、`transfer for no consideration`、`statutory reserve`、`distributable income`及对应中文词。时间序列不能晚于首次发行文件；找到到期返还条款后，必须反向搜索上市以来所有提前返还和资本性质分派。

## 现金流身份

有限期限价值必须逐项闭合：

```text
到期前经营现金
+ 到期注册资本或股东贷款返还
+ 清算剩余资产与押金释放
+ 有证据的出售或续期价值
- 到期债务与优先索取权
- 清算、处置、续期和税费
- NCI及其他持有人权利
= 普通股或单位持有人有限期现金价值
```

每项只能进入一次。物业经营现金和到期清算收入可以并存；若经营 DCF 没有采用物业出售价值，到期处置现金不是重复计值。反之，若 NAV 或出售价值已经包含到期资产池，不得再次加注册资本返还。

“权益在到期后归零”只能说明持续产权为零。只有合同同时证明清偿、资本返还和清算分配均为零，才允许把到期现金设为零。

## 注册资本返还

- 区分资产池索取权与股东、政府或合营方担保。
- 先列法律顺位，再列当前资产覆盖、债务、清算成本和币种。
- 强制闭合`原始注资－累计提前返还－后续资本减少＝尚未返还索取权`。历史“可分派折旧”“资本性质分派”或类似项目若被发行人定义为投资资本提前返还，必须逐年进入这张桥；不得在XIRR中作为已收分派后又把同一本金按原合同额计入到期价值。
- 最新年报仍列原注册资本，可证明法律资本记录未减少，但不能单独证明尚未返还金额。经济性提前返还可能不减少法定注册资本；两者冲突时保留余额区间，不能用注册资本覆盖历史现金事实。
- 不为长期回收伪造精确概率。至少展示零回收、保守回收、覆盖支持参考和合同上限；主点必须由资产覆盖和顺位约束，不能只写“保守取50%”。

## 法定储备与上划限制

法定储备不是税，也通常不是现金支出。应拆成：

```text
子公司税后利润
- 法定储备计提
= 当期法律上可分配利润
再经董事会/管理人政策
= 实际上划或持有人分派
```

储备仍在子公司资产中。它可以限制近期股息，却不能在分派桥中扣除后又从 NAV、减债能力或清算资产中归零。若无法取得各子公司的累计储备、注册资本和税后利润，保留 `UNKNOWN`，用实际计提额和实际分派校准，不把集团 NPI 直接乘法定比例。

## 模型与审阅门槛

1. 必须保留“不计到期索取权”的旧路线，证明新增条款的边际影响。
2. 到期索取权必须同时进入 V0、VN 和候选买价反解，不能只抬今日价值。
3. 市场确认只处理价格相对价值，不能代替法律现金流。
4. 主结论必须展示到期现金的零/压力/基础/上限敏感性；若结论翻转，报告必须明说依赖哪条合同事实。
5. 审阅者必须回读首次发行文件和最新中报。仅复算年报数字、NCI、资本开支或终值公式，不足以签有限期限资产模型。
6. 审阅者必须搜索首次发行文件内所有`repatriation/repayment`命中，并将后续年报的资本性质分派与到期索取权勾稽；只核一段到期条款不得签字。
7. 任何合同出现`尚未返还`、`未偿付部分`或`to the extent not already repatriated/repaid`，报告和模型必须同时展示原始合同额、累计历史结算、估算未结余额和回收折价。仅有当前注册资本表、资产覆盖或任意折价，不得替代这张存量流量桥。

## 失败分类与修复

如果报告遗漏材料性到期现金，按以下根因处理：

- `DATA_COVERAGE`：研究起点晚于首次发行或底层合同；补齐源文件。
- `ACQUISITION_MODULE`：schema没有期限、终止、清算、资本返还和法定储备字段；先扩采集模块与validator。
- `REASONING`：把“到期后权益为零”误译成“到期现金为零”；重建法律顺位和现金身份。
- `MODEL`：有限期DCF没有终止现金桥；补入同一逐期价值与XIRR引擎。
- `WRITING`：没有区分经营终止、资本返还、清算和上划限制；按事实、机械计算、研究判断分别落文。

接受标准不是“已经写了到期风险”，而是每个到期或终止条款都已回答：谁先收钱、收多少、来自哪个资产池、何时收到、哪些事实仍未知，以及该现金如何进入普通持有人回报。
