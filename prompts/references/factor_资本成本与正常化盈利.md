# 共享输入执行器：资本成本 r* + 正常化盈利

> **Phase 1 产出**。EPV = 正常化盈利 / r*，两个输入都在这里算。下游：Factor_EPV（Phase 2）、Factor4 安全边际、VCF（除数 r*）。
> 母版见 `_executor_template.md`；现行方法权限见 `docs/turtle_valuation_routing_and_investor_styles.md`，迁移历史见 `docs/History/graham_migration/turtle_graham_deepening_roadmap.md`。金额单位百万元。
> **全局原则**：任何变量拿不到精确数据，给近似估算 + 方法 + ⚠️，绝不空着。

---

## 定位与指令

> **定位**：产出两个共享标量——① 资本成本 `r*`（EPV/VCF/安全边际的分母与门槛）；② 正常化盈利 `E_norm`（EPV 分子）。这是估值流水线的地基，先于 EPV 计算。
> **上游依赖**：Factor1B（moat_rating / 商业模式稳定性 / franchise_type）、Factor2/3（现金流序列、EBIT 序列）。
> **下游消费**：Factor_EPV（Phase 2，`EPV_norm = E_norm / r*`）、Factor4（安全边际门槛）、Factor1C/VCF（`VCF = 增量ROIC / r*`）。

**指令**：Greenwald 明确**拒绝 CAPM β**，主张按业务风险分档定权益成本。r* 取分档 + 实际债务成本加权。正常化盈利 = 穿越整个周期的可持续 EBIT 口径，剔除周期高峰/低谷与一次性项目。全程保守。

## 甲部：资本成本 r*

### 关卡 ① 数据源逐行锚定

| 变量 | 含义 | 数据源（§X 行项） | 单位 |
|---|---|---|---|
| Rf | 无风险利率（10Y 国债） | 外部宏观常量（当前锚 ~2.5% CN / ~4.3% US），标注取值日 | % |
| Kd_pretax | 税前债务成本 = 财务费用利息支出 / 有息负债均值 | §3 利润表财务费用 + §4 短期借款+长期借款+应付债券 | % |
| Q_tax | 实际税率 = 所得税 / 税前利润 | §3 利润表 | % |
| D_debt | 有息负债 | §4 短期借款 + 长期借款 + 应付债券 + 一年内到期非流动负债 | 百万元 |
| E_mktcap | 股权市值 | §11 市值 | 百万元 |
| moat_rating | 护城河评级 | Factor1B 输出 | 高/中/无 |
| 业务稳定性 | 收入 5 年 CV + 周期性 | Factor1B + Factor3 步骤11①收入CV | 高/中/低 |

### 关卡 ② 数据缺失降级阶梯（权益成本 Ke）

> Greenwald 拒绝 β。权益成本由**业务风险分档**决定——这是主方法，不是降级。分档即 §6.5-D 的 7/9/12。

```
主方法（分档，Greenwald 口径）：
  Ke 由业务风险档位直接给定，档位来自 moat_rating + 业务稳定性：
  ⭐ 分档 = Rf + 权益风险溢价（ERP），锚定当地无风险利率，不用绝对值（v2 校准修正）：
    低风险（强护城河 + 稳定收入 CV<10% + 弱周期）      → Ke = Rf + 3pct
    中风险（中护城河 或 CV 10-25% 或 中周期）           → Ke = Rf + 5pct
    高风险（无护城河 或 CV>25% 或 强周期/单一产品）     → Ke = Rf + 8pct
    （Rf≈4% 时 → 7/9/12，与原分档一致；Rf 变则整体平移。这解决"绝对分档在低利率区顶高门槛"的校准bug）
  ⭐ r* 与系统 II 是两个不同的率，r* > II 是正确的（v2 校准修正，轮2/3 更正轮1）：
    - II（系统穿透回报率门槛，≈Rf+1.5-2.5%）：分子是税后股息现金 GG=D×(1−tax)/M，故门槛低
    - r*（本执行器完整资本成本，≈Rf+3-8%）：分子是全额正常化盈利 EPV=E_norm/r*，故更高
    - 二者差 ≈ 派息率的口径差。不要把 r* 压到 II！那会让 EPV 系统性高估。
    - 实测锚：中国食品 II6.5%→r*≈9%(中风险)；中海物业 II5.5%→r*≈7%(低风险轻资产)；分众 II5.5%→r*≈7%(网络护城河)
    - EPV 流水线用 r*，GG/回报率流水线用 II，两条流水线在 Factor4 三视角汇总（不互相压门槛）
  边界：地板 Rf + 2pct（再稳的生意权益成本不低于此）；
        天花板 Rf + 9-10pct（类 VC 高不确定性，超过则该标的不适合本框架估值，转定性）
  微调（各 ±0.5-1pct，累计不超过档间距）：
    + 治理差/关联交易重 / 单一大客户 / 强金融杠杆
    − 长期分红稳定 / 多元化收入 / 央国企隐性背书（≤0.3pct）

降级（分档所需定性判断也缺时）：
  优先级2：仅有收入 CV → 按 CV 单指标套档（<10%→Rf+3, 10-25%→Rf+5, >25%→Rf+8）
  优先级3：连 CV 都算不出（数据<3年）→ 取中风险 Rf+5pct + 标注"⚠️ 为数据不足下的默认中档估算"
禁止：留空。末级永远落到一个档位值。
```

### 关卡 ②b 债务成本与加权

```
Kd_pretax = 利息支出 / 有息负债均值
  若利息支出无法拆分（财务费用含汇兑损益）→ 用 [短期借款利率基准 + 100bp] 估算，标 ⚠️
Kd_aftertax = Kd_pretax × (1 − Q_tax)
  若 Q_tax 异常（<0 或 >40%，如亏损年）→ 用 25%(CN法定) 或 16.5%(HK) 替代，标 ⚠️

资本结构权重（账面有息负债 + 股权市值）：
  w_d = D_debt / (D_debt + E_mktcap)
  w_e = 1 − w_d
  ⭐ 债务权重上限 30%：若 w_d > 30% → 强制截断为 30%（w_e=70%）
    理由：高杠杆压低 WACC 是虚假的低资本成本，Greenwald 对重债务生意要求更高门槛而非更低。
    标注"⚠️ 实际 w_d=X% 已截断至30%，原始 WACC=Y% 被上调至 Z%"

r* = w_e × Ke + w_d × Kd_aftertax
  最终地板 6%，天花板 13-14%（同 Ke 边界）
```

### 关卡 ③ 边界情形

| 情形 | 触发 | 强制处理 |
|---|---|---|
| 净现金公司（无有息负债） | D_debt ≈ 0 | r* = Ke，跳过加权，标"纯股权融资" |
| 高杠杆 | w_d > 30% | 截断 30%（见 ②b） |
| 亏损年税率失真 | Q_tax<0 或 >40% | 用法定税率替代 |
| 极高不确定性 | Ke 微调后 >14% | 标"⚠️ 超本框架估值适用域，建议转定性判断" |
| 强周期底部 | 当前处周期低谷 | Ke 用中枢档而非底部档，避免顺周期低估风险 |

### 关卡 ④ 强制敏感性

```
r* 三档（禁止单点）：
  低（乐观）= w_e×(Ke−1pct) + w_d×Kd_aftertax，地板 6%
  中（基准）= 上式主算法
  高（保守）= w_e×(Ke+1pct) + w_d×Kd_aftertax
  区间 = [低, 高]，宽度通常 ~2pct
传递：r* 三档全部传给 EPV，使 EPV 天然带区间（EPV=E_norm/r*，r* 越高 EPV 越低）
```

### 关卡 ④.5 投资者门槛地板 r_req（⭐ 用户个人要求回报率）

```
r_req = 投资者个人要求的最低年化回报率（机会成本），默认 10%。
        这是"我这笔钱不达到这个回报就不投"的主观门槛，与"这门生意风险该配多少折现率"
        （关卡①-④ 算出的业务风险分档 r*）是两个不同概念。

floor 规则（作用于三档全部）：
  r*_base = max(关卡③ 业务风险 r*_base, r_req)
  r*_low  = max(关卡④ 业务风险 r*_low,  r_req)   ← 低档也不得低于个人门槛
  r*_high = max(关卡④ 业务风险 r*_high, r_req)

语义：业务风险算出的 r* 若已 ≥ r_req（高风险周期股，如 12%）→ floor 不生效，用业务 r*；
      若 < r_req（低风险优质特许经营，如格力 8%）→ 被地板抬到 r_req=10%。
      即"用机会成本折现"，估值天然更保守：EPV/IV/V_final 全按 floor 后 r* 重算。

标注格式（估值章强制显式写）：
  "业务风险分档 r*=X%（低风险/中/高），投资者门槛 r_req=10% → r* 取 max = Y%"
  若 floor 生效（业务 r*<10%）必须写明"已被个人门槛 10% 抬高，估值按 10% 折现"。

⚠️ 要改门槛：只改本行 r_req 默认值（10%），全下游（EPV/IV/V_final/VCF/回报安全边际）自动重算。
```

### 关卡 ⑤ 裁决联动

```
r* 是门槛 II 的锚：II 默认 = r*（要求回报率 ≥ 资本成本才谈买入）
  → r* 直接决定 EPV 高低、GG/回报率是否达标、安全边际是否为正
  → r* 每高 1pct，EPV 约降 (1/r*) 比例（r*=9% 时约降 11%）
传递字段：r*_low / r*_base / r*_high（均已过 r_req floor）、Ke_档位、w_d(截断前后)、II_anchor=r*_base、r_req

⭐ II 不受 r_req floor（关键，别改错）：II 是"穿透回报率门槛"，分子是税后股息现金（GG 口径），
  天然低于 r*（≈Rf+1.5~2.5%）。若把 II 也 floor 到 10%，几乎所有股票 GG 都判不达标、失真。
  floor 后 r*（估值+回报安全边际门槛）与未 floor 的 II（穿透闸门）分裂是【预期行为】，不是 bug——
  这正是"穿透够门槛、但扣掉更高的个人要求+护城河衰减后回报不够"的格力式冲突信号。
```

## 乙部：正常化盈利 E_norm

> **口径声明**：EPV 分子是"穿越整个商业周期、可无限期维持的税后经营盈利"，非当期净利润、非 factor3 的现金收入。核心是**用正常化利润率 × 当前收入规模**，抹掉周期与一次性噪音。对应 Q1 定案的 `EPV_norm` 口径（与 `EPV_AA = AA/r*` 并列）。

### 关卡 ① 数据源逐行锚定

| 变量 | 含义 | 数据源（§X 行项） | 单位 |
|---|---|---|---|
| S_t | 逐年营业收入（≥5年，覆盖一个周期） | §3 利润表营业收入 | 百万元 |
| EBIT_t | 逐年营业利润 = 归母净利润 + 所得税 + 财务费用 | §3 利润表 | 百万元 |
| S_current | 当前 FY 收入（正常化利润率的乘数） | §3 最新年 | 百万元 |
| DA_t | 折旧摊销 | §5 现金流量表 / §3 附注 | 百万元 |
| Capex_t | 资本开支 | §5 购建固定无形长期资产支付现金 | 百万元 |
| Q_norm | 正常化税率 | §3 多年所得税/税前利润均值 | % |
| 一次性项目 | 资产处置/减值/补贴/公允变动 | §3 + §5（复用 factor3 步骤3 分类） | 百万元 |

### 关卡 ② 数据缺失降级阶梯

```
正常化 EBIT 利润率 margin_norm 的计算：
优先级1（≥5年 EBIT 可用）：
  margin_t = EBIT_t / S_t 逐年
  剔除异常年（疫情/一次性减值，同 factor3 λ 清洗规则），取剩余年中位数 = margin_norm
优先级2（3-4年）：
  取可用年中位数，标"⚠️ 仅N年，周期覆盖不足，margin_norm 可靠性中"
优先级3（<3年 或 EBIT 波动无法判断周期位置）：
  margin_norm = min(当前 margin, 行业保守 margin)
  行业保守值：消费 12% / 制造 6% / 重资产 4%（拿不到行业数据时用这组近似），标 ⚠️
禁止：直接用当前单年 margin（周期顶点会高估）。缺 → 给上述估算，不空。
```

### 关卡 ②b 正常化盈利主计算

```
① 正常化 EBIT = margin_norm × S_current
   （用当前收入规模 × 穿越周期的利润率——规模取当下，盈利能力取长期）
② 剔除一次性：正常化 EBIT 已用 margin 口径天然平滑；若某项一次性混入 EBIT
   （如大额资产处置计入营业外/其他收益并污染了历史 margin），在计算 margin_t 时先剔除
③ 维护性 Capex 调整（EPV 用维护性 Capex，非全额）：
   维护性Capex ≈ DA × 通胀因子(默认1.0，高通胀期1.05-1.1)
   若 Capex_current < DA → 用 Capex_current（企业实际投入更低，取低者保守）
   成长性Capex = max(0, Capex_current − 维护性Capex) → 不进 EPV（EPV 假设零增长）
   调整项 = DA − 维护性Capex（通常≈0；DA>维护Capex 时为正，加回）
④ 正常化税后经营盈利：
   E_norm_合并 = (正常化 EBIT + 调整项③) × (1 − Q_norm)
   Q_norm 异常（亏损年）→ 用法定税率，标 ⚠️
⑤ ⭐ 少数股东归母（v2 校准修正，强制）：
   若少数股东占比 >10%（读 factor3 minority_adjustment / §17.2）：
     E_norm = E_norm_合并 × 归母比例
     （EBIT 是合并口径，含少数股东经营利润；EPV=E_norm/r* 若用合并 EBIT 会高估归母股东价值。
       中国食品例：少数股东 39.7%，归母比例 0.603，E_norm 必须 ×0.603，
       与 factor3 AA×归母比例 同口径，否则 EPV_norm 与 EPV_AA 口径不一致无法并列）
   若 ≤10% → E_norm = E_norm_合并，标"少数股东占比小，合并≈归母"
```

### 关卡 ③ 边界情形

| 情形 | 触发 | 强制处理 |
|---|---|---|
| 强周期股 | 收入CV>25% 或明确周期行业 | margin_norm 必须用全周期中位数，禁用近2年；标"周期正常化" |
| 当前亏损但历史盈利 | EBIT_current<0, 历史>0 | 用历史正常化 margin，标"当前周期低谷，EPV 基于正常化盈利能力" |
| 结构性衰退 | 收入连续≥3年下滑 + margin 同步降 | margin_norm 取近段而非全期中位数 + 标"⚠️ 结构性衰退，正常化盈利可能仍高估" |
| 高成长期企业 | 收入高增 + 无稳定周期 | EPV 不适用（书明确 EPV 假设零增长），标"⚠️ 转 R5 回报率流水线，EPV 仅作资产下限参考" |
| 一次性主导利润 | 一次性项目/EBIT>30% | 剔除后重算 margin，标占比 |

### 关卡 ④ 强制敏感性

```
E_norm 三档（禁止单点）：
  悲观 = margin_norm(取历史 min 而非中位) × S_current × (1−Q)
  基准 = 主算法（中位 margin）
  乐观 = margin_norm(取历史 P75) × S_current × (1−Q)
  区间 = [悲观, 乐观]
两口径并列（Q1 定案）：
  E_norm（本执行器，规范化 EBIT 口径）
  AA（factor3 现金还原口径）
  → 二者都传给 EPV：EPV_norm = E_norm/r*，EPV_AA = AA/r*
  → 差异 = 规范化调整 vs 现金口径的口径差，在报告中解释
```

### 关卡 ⑤ 裁决联动

```
E_norm 是 EPV 分子，直接决定：
  EPV_norm 高低 → 与资产价值勾稽 → 护城河判定（Phase 4 路由输入）
  EPV_norm vs 市值 → 无增长下的价值锚，安全边际基准
若 E_norm << 当前净利润 → 标"当前盈利含周期/一次性成分，可持续盈利显著更低"
  → 裁决降级，禁止用当期高利润支撑买入
传递字段：E_norm_low/base/high、margin_norm、维护性Capex、成长性Capex、AA(并列口径)
```
