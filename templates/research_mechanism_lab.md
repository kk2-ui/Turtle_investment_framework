## 假设空间筛选（先生成，再配对）

H-A/H-B 是为可结算测试选出的**最有信息量的一对**，不是声称世界只有两种解释。先针对同一共同事实写出所有当前可信、且会材料性改变经营边界的机制；随后才可以合并或排除。

| candidate ID | 它如何解释共同事实（因果链摘要） | 与其他候选真正不同的箭头或顺序 | 若为真会位移的当前经济边界 / FJ / acquisition 动作 | 可分叉的未来观察 | 截止日前处置 | 处置理由与 cutoff 前 evidence / `UNKNOWN` |
|---|---|---|---|---|---|---|
|  |  |  |  |  | `PAIR_PRIMARY / PAIR_RIVAL / MERGE / DEFER_NO_PRIMARY / EXCLUDE / OUT_OF_SCOPE` |  |

- 候选只有同时解释**同一组**共同事实、包含不同的因果箭头或顺序，且若为真会改变本轮的经营边界、FJ、来源任务或选择资格，才是 material candidate。只改变措辞、估值、远期背景或另一个未声明问题，不得占用本轮 pair。
- `MERGE` 只适用于因果链和可观察顺序相同的候选；写明并入哪个 candidate。名称、语气或估值不同不是合并理由。
- `EXCLUDE` 必须由 cutoff 前事实直接矛盾；“还没有资料”“不喜欢该故事”或后来结果都不能排除。
- `OUT_OF_SCOPE` 不是“已被证伪”：它必须写明为什么不解释共同事实或不会位移本轮经济问题，以及若它对另一边界仍材料性，下一条独立问题/资料任务是什么。不能借 `OUT_OF_SCOPE` 删掉一个真正会改变本轮 FJ 的候选。
- 仍可解释共同事实、会材料性改变经营边界，却没有合格分叉观察的候选，只能是 `DEFER_NO_PRIMARY`。此时可保留一对机制做 `MECHANISM_SIGNAL_PROBE`，但不得把任何一方升为中心路径。
- 冻结后若观察落入 `NEITHER`，先回读本表：未列候选只能作为**新发现**，不得改称为“当时已经考虑过”。原 pair 保持 `MECHANISM_OR_MEASUREMENT_RESEARCH_REDIRECT`，不以第三机制的名字回写它。

## 适用环境与 regime break（只有会改变 pair 的条件才填写）

行业、政策、宏观和竞争结构不是结果不符后的万能解释。只有某个条件若变化会改变 H-A/H-B 的因果顺序、结果指标含义或两方可比较性，才可作为本 pair 的适用环境；正常周期波动本身仍是双方都要预测的共同状态。

| condition ID | cutoff 时的状态与一手来源 | 它约束的机制箭头 / FJ / critical assumption | 预先定义的 break observation、允许来源与窗口 | 触发后的不可回写动作 |
|---|---|---|---|---|
|  |  |  |  | `CONTINUE_AS_IN_SCOPE / CLOSE_AND_REFREEZE_NEW_EPISODE` |

- 只有已在 cutoff 前写入上表、并可用预先允许来源识别的 break 才能触发 `CLOSE_AND_REFREEZE_NEW_EPISODE`。后来出现的政策、宏观或竞争叙事只能成为新问题，不能改变原 episode 的解释。
- break 触发时，原始 observation 与 trigger 均照常保留；不得宣布 H-A/H-B 任一方正确或错误，也不得把该 raw result 用作原环境下的选择、迁移或 L3–L5 方法证据。新环境必须建立新的 cutoff、共同事实、pair 和 FJ。
- 若只是已冻结环境内的需求、价格、竞争或利率波动，行动是 `CONTINUE_AS_IN_SCOPE`：它由 H-A/H-B 结算，不能被事后称为 regime break。

## 可选：竞争回应过程（行业/对手为关键传导时）

只有当“对手如何回应”是主/反机制的必要箭头时填写。它复用本卡的 H-A/H-B 与 FJ，不建立另一个竞争评分。

| 项目 | 冻结内容 | 不能替代 |
|---|---|---|
| 竞争 arena | 发起方、回应方、产品/渠道/地区、客户和时间边界 | 泛行业或全公司数字 |
| 已发生行动 | 行动类型、实施状态、日期、范围及一手事实 | 意向、公告标题或事后效果 |
| H-A 预期回应 | awareness/motivation/capability → 对象、类别、最大时滞 | “竞争缓和” |
| H-B 预期回应 | awareness/motivation/capability → 对象、类别、最大时滞 | “竞争加剧” |
| 早期回应信号 | 0/1 或数量定义、窗口、允许来源、A-only/B-only | 宏观冲击、对手评论或无来源的沉默 |
| 终局经营信号 | 同 arena 的量价、让渡、营运资本或现金后果 | 全公司利润、股价或回报 |

来源覆盖不足时，“未观察到回应”只能是 `MISSING_OBSERVATION`，不得支持 H-A。行动真正发生只确认共同事实，不能判任一机制获胜。
