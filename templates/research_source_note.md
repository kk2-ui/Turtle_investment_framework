# 来源观察卡

## 来源身份

- 标题、作者/机构：
- 发布/可得时点、版本：
- 原始来源还是转述：
- `lineage_id`（同一最原始来源/生成过程使用同一 ID）：
- 最原始可追溯来源、release/query/访谈样本或事件链：
- 与既有观察是否独立；若是，独立性依据：
- 覆盖对象、交易点、单位、期间、渠道/样本边界：
- 证据上限：`CONTEXT_ONLY / MECHANISM_DISCOVERY / COMPARATIVE_CANDIDATE / SETTLEMENT_ELIGIBLE`
- 证据上限的原因及升级条件：

## 原文观察

- 可复读事实：
- 在机制中的角色：`STATE / ACTION / OUTCOME / CAUSAL_ATTRIBUTION / FORECAST`
- 作者或管理层的解释：
- 缺失字段、口径或版本：
- 来源身份：`FACT / SENSOR / HYPOTHESIS / UNKNOWN`
- 未知原因：`MISSING_OBSERVATION / MEASUREMENT_MISMATCH / MECHANISM_NONDIAGNOSTIC / NOT_YET_DUE / PIT_BLOCKED`
- 对竞争机制的诊断性：`COMMON / A_SPECIFIC / B_SPECIFIC / NONDIAGNOSTIC`

## 研究用途

- 它涉及哪条机制箭头：
- 最强替代解释：
- 它不能支持的结论：
- 下一项能提高诊断力的观察或资料请求：
- 与已读材料的共同来源谱系或冲突：

同一 `lineage_id` 的多次转述、不同页码或不同 agent 阅读只是一项观察；不得以篇数、机构名气或多数意见增加证据权重。

低于 `SETTLEMENT_ELIGIBLE` 的来源不得用于冻结前瞻判断或结果结算；它只能决定机制问题、红队或资料请求。

`ACTION` 只证明动作是否发生；`CAUSAL_ATTRIBUTION` 只生成待检验的解释。动作后出现结果不自动证明两者存在因果传导。
