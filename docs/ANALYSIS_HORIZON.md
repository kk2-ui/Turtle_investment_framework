# 自适应分析时域系统 V1.1 (Adaptive Analysis Horizon)

> 状态：✅ 已全部实现（P0-P3, V2, V4）
> 核心金句："全量存储做底仓，结构断点切新篇；周期长短看波动，边际增长只看近五年。"

---

## 0. 根因诊断

Turtle V8.3 框架在分析年限上用"一刀切"：

| 位置 | 硬编码 | 后果 |
|------|:---:|------|
| `compute_bundle.py` | `fcf_years[-5:]`, `avg_last_n(x, 3)` | 强周期股5年可能全是顶峰或谷底 |
| `zone_b_v8.py` | `["2021","2022","2023","2024","2025"]` | 不随上市年限变化 |
| `zone_c_chain.py` | `"10年PE中位"`, `FY2021\|FY2022\|...` | 上市3年的公司用不了 |
| `build_full_text.py` | `recent[-5:]`, `CV>0.15` | CV算了但只用于文本标注，不调整定量计算 |

已有但闲置的基础设施：`detect_cyclicality()`（CV检测）、`turtle_thresholds.py`（行业化II设定）。

## 1. 三规则体系

### Rule 1: 全量存储，不做截断

DB层存储所有可用年份。具体分析用多少年，由引擎根据标的特征动态决定。

```
MySQL: SELECT * FROM annual_financials WHERE ts_code=? ORDER BY fiscal_year
      → 返回全部年份，不截断
```

### Rule 2: 结构性断点检测（重置时钟）

企业"重生"时需要重置分析起点。

| 触发条件 | 公式 | 阈值 |
|------|------|:---:|
| 重大收购 | `abs(商誉_t - 商誉_{t-1}) / 总资产_{t-1}` | > 20% |
| 借壳/重组 | `abs(总资产_t - 总资产_{t-1}) / 总资产_{t-1}` | > 50% 且收入变动 < 30% |
| 业务转向 | 任一主营分部收入占比同比变动 | > ±30% |
| 注资/剥离 | 归母权益变动 > 100% 且非来自利润留存 | 人工标记 |

检测后：
```
analysis_start_year = max(IPO_year, last_break_year + 1)
```

### Rule 3: 双维度动态周期窗口 (V1.1)

#### 维度一：供给端波动（利润 CV）
- 高: 利润 CV > 0.40
- 低: 利润 CV ≤ 0.40

#### 维度二：需求驱动类型（行业关键词判定）

| 类型 | 判定标准 | 典型行业 |
|------|------|------|
| 大宗商品驱动 | 上游资源类，价格全球定价 | 石油、有色、化工、煤炭、钢铁 |
| 资本开支驱动 | 需求取决于企业扩产周期 | 工程机械、工业设备、机床 |
| 地产后周期 | 需求滞后于房地产销售6-18个月 | 空调、白电、建材、家居、五金 |
| 纯消费驱动 | 需求与可支配收入正相关 | 白酒、调味品、乳制品、医药 |
| 政策驱动 | 需求取决于补贴/监管 | 新能源车、光伏、风电 |

#### 判定矩阵

| 供给波动 | 需求驱动 | 最终分类 | 窗口N | 权重 |
|------|------|------|:---:|------|
| 高 | 大宗商品/资本开支 | **强周期** | 10 | 近3年40%, 前7年60% |
| 高 | 地产后周期 | **中周期偏强** | 8 | 近3年45%, 前5年55% |
| 高 | 纯消费驱动 | **中周期偏弱** | 7 | 近3年55%, 前4年45% |
| 低 | 大宗商品驱动 | **中周期偏强** | 8 | 近3年45%, 前5年55% |
| 低 | 地产后周期/政策/资本开支 | **中周期偏弱** | 7 | 近3年55%, 前4年45% |
| 低 | 纯消费驱动 | **弱周期** | 5 | 近3年60%, 前2年40% |

#### 利润平滑反证

```
利润平滑系数 = mean(|Δ营收% - Δ利润%|) 的近5年均值
```

| 条件 | 规则 |
|------|------|
| profit_cv < 1.0 且 平滑系数 > 10% | 自动降一档 |
| profit_cv ≥ 1.0 | 平滑系数无效（利润自身极度波动） |

实际采用年数：
```
effective_n = min(analysis_start_year以来年数, window_n, DB可用年数)
```

## 2. 三轨并行分析

| 轨道 | 窗口 | 用于 | 目的 |
|------|------|------|------|
| **A: 长期稳态** | 断点后全部年份 | 因子1B（护城河/ROE均值） | 判断长期平均赚钱能力 |
| **B: 周期定位** | 动态窗口 N 年 | 因子2（粗算估值锚） | 判断当前PE/PB在历史周期百分位 |
| **C: 边际动量** | 固定近5年 | 因子1C（增量ROIC） | 评估最近投入资本效率——无论什么周期，增量只看近5年 |

## 3. 架构

```
Phase 0 (NEW): pre_analysis_phase.py
  ├─ 全量数据读取（DB）
  ├─ 结构性断点检测 → analysis_start_year
  ├─ CV 计算 + 分级 → window_n
  ├─ 三轨年份列表
  ├─ 异常年份标记 → exclude_years
  └─ 输出: analysis_contract.json

Phase 1: Zone A（读取 contract，动态窗口）
Phase 2: Zone B（读取 contract，动态年份列表）
Phase 3: Zone J
Phase 4: Zone C（C1 Agent 引用 contract）
```

## 5. 案例

### 金茂服务 (00816.HK)
```
上市: 2022年3月 | DB: 2018-2025 (8年)
CV = 0.31 → 中周期, window_n=8
effective_n = min(4, 8, 8) = 4 (上市才4年)
→ 实际用全部 4 年
```

### 中国食品 (00506.HK)
```
上市: 1988年 | DB: 2005-2025 (21年)
2017年: 剥离葡萄酒+食用油 → 业务转向 → 标记断点 (V1需要segment数据验证)
analysis_start_year = 2018
CV = 0.29 → 中周期, window_n=8
effective_n = min(8, 8, 21) = 8
→ 有效窗口 2018-2025 (8年)
anomaly_flags: [2006, 2016] (收入崩溃年份)
```

### 紫金矿业 (601899.SH)
```
CV = 0.965 → 强周期, window_n=10
effective_n = 10 (DB有21年)
→ 权重: 近3年40%, 前7年60%
```

### 格力电器 (000651.SZ)
```
上市: 1996年 | DB: 2004-2025 (22年)
1断点 @ 2009 → 起点重置为2010
profit_cv = 0.784, demand = 地产后周期（空调行业）
→ 判定矩阵: 高CV × 地产后周期 → 中周期偏强, window_n=8
平滑系数 = 0.055 (中等，不触发降档)
→ 有效窗口: 2018-2025 (8年)
✅ 修正前: "强周期"10年 → 修正后: "中周期偏强"8年
```

## 7. V1 已知局限

1. **断点检测仅基于 DB 财务数据**（商誉跳涨、资产突变），无法检测纯业务结构变化（如中国食品的品类剥离），后者需要分部收入数据（Zone B 产出）
2. **CV分级无法区分"增长驱动的高CV"和"周期驱动的高CV"**——格力电器因早期高速增长被归入"强周期"
3. **上市年限 < 5 年的公司，三轨事实上退化为单轨**——所有年份同时用于 A/B/C 三个分析
4. **异常年份检测仅基于收入同比**（-30%阈值），未考虑利润率异常、一次性事件
