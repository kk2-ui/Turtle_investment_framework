- 后续 Agent 不得从本目录恢复项目状态或激活阶段；
- 当前执行只读仓库根 `AGENTS.md`、`GOALS.md`、`docs/CURRENT_DOCUMENTS.md` 和现行阶段/路线规范；
- 若历史文档与当前文件冲突，以当前文件、schema、代码和正式工件为准。
