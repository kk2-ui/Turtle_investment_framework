# Turtle 迁移底稿

> **ARCHIVED / NON_CANONICAL：**迁移底稿不是当前变量、模型、Prompt或执行顺序真源。

目标：用《价值投资：从格雷厄姆到巴菲特》的方法重写 Turtle，但保留 GG 原版的计算严谨性。

## 0. 设计原则

- 书内优先，不先套 Turtle 旧口径。
- 所有判断都要能落到变量。
- 所有变量都要能落到公式。
- 所有公式都要有保守默认值。
- 每个结论都要能回溯到 `reported / normalized / conservative / adjusted` 四层之一。
- 只要算不出来，就标 `⚠️ 数据不可用`，不许用口号补洞。

## 1. 映射表

| 书中观念 | Turtle 目标模块 | 关键变量 | 结论用途 |
|---|---|---|---|
| 资产价值 / EPV / 成长价值 | 估值分流 | `asset_value`, `epv`, `growth_value` | 先分流，再决定用哪条估值路 |
| 增长是否创造价值 | 增量检验 | `incremental_roic`, `capital_cost`, `incremental_capex` | 判定增长增值/中性/毁值 |
| 好生意 / 护城河 | 商业质量 | `moat_rating`, `moat_type`, `moat_flywheel` | 决定可持续性与风险折价 |
| 经济特许权衰减 | 折旧/衰减 | `decay_rate`, `half_life` | 给增长和安全边际做 haircut |
| 价值创造因子 | 资本配置 | `value_creation_factor`, `reinvestment_return` | 判断留存收益值不值钱 |
| 研究策略 | 证据层级 | `indirect_info`, `direct_info`, `management_signal` | 决定信息权重 |
| 风险管理 | 永久损失 | `leverage_risk`, `trap_rating`, `position_cap` | 决定是否排除/限仓 |
| 人物风格 | 策略模板 | `style_template` | 供 prompt 变体调用 |

## 2. 变量字典

| 变量 | 含义 | 单位 | 书内来源 | 保守默认 |
|---|---|---:|---|---|
| `V` | 内在价值 | 百万元 | 第8章 | 不直接硬算，先做基准假设 |
| `M` | 市值 | 百万元 | 第8章 | 直接读市值 |
| `g` | 有机增长率 | % | 第6/8章 | 取长期可持续值 |
| `D` | 当前现金回报 | % / 百万元 | 第8章 | 先按已分配现金算 |
| `b` | 分配率 | % | 第8章 | 若不稳，取历史保守值 |
| `r_b` | 基准回报率 | % | 第8章 | 先按 `V/M=1` 算 |
| `r*` | 资本成本 | % | 第6/8章 | 不用激进融资口径 |
| `s` | 衰减率 | % | 第8章 | 先按半衰期保守化 |
| `h` | 半衰期 | 年 | 第8章 | 无法量化时只给区间 |
| `vcf` | 价值创造因子 | 倍数 | 第8章 | `<=1` 先当常态 |
| `roic_i` | 增量回报率 | % | 第6章 | 先看是否高于资本成本 |
| `moat_rating` | 护城河评级 | 枚举 | 第7章 | 强证据才上调 |
| `moat_flywheel` | 复合护城河 | 布尔 | 第7章 | 需要两层互相强化 |
| `trap_rating` | 价值陷阱等级 | 枚举 | 第7/10章 | 不清楚时偏保守 |
| `cash_return` | 现金回报率 | % | 第8章 | 先看今天能拿到什么 |
| `reinvestment_return` | 再投资回报率 | % | 第8章 | 留存收益必须单独算 |
| `margin_of_safety` | 安全边际 | pct | 第8/10章 | 用回报差而非口号 |
| `position_cap` | 仓位上限 | % | 第10章 | 取最小约束 |

## 3. 公式清单

### 3.1 第8章主公式

```text
r_b = D/M + g
真实回报 = D/M + g(V/M)
安全边际 = 真实回报 - r*
```

### 3.2 增长是否增值

```text
增量价值 = 增量资本 × (roic_i - r*)
vcf = roic_i / r*
```

### 3.3 衰减

```text
年衰减率 ≈ 72 / 半衰期
净增长 = 有机增长 + 再投资增长 - 衰减
```

### 3.4 现金回报

```text
现金回报率 = 可分配现金 / M
```

### 3.5 组合风险

```text
position_cap = min(估值仓位, 护城河仓位, 陷阱仓位, 杠杆仓位)
```

## 4. GG 严谨性规则

- 先算 `reported`，再算 `normalized`，再算 `conservative`，最后才给 `adjusted`。
- 每个数字都要写公式。
- 每个公式都要写输入。
- 每个输入都要写来源或缺失原因。
- 不允许“看起来像”代替“算得出”。
- 不允许把增长叙事直接等价成回报。
- 不允许把资产价值和收益价值相加重复计算。

## 5. Prompt 骨架

### 5.1 商业判断

```text
1. 这是什么生意
2. 钱从哪里来
3. 护城河是什么
4. 这是不是经济特许权
5. 增长是否会增值
```

### 5.2 定量判断

```text
1. 当前现金回报
2. 有机增长回报
3. 再投资回报
4. 衰减
5. 与资本成本比较
```

### 5.3 风险判断

```text
1. 永久损失来源
2. 杠杆
3. 估值过高
4. 价值陷阱
5. 仓位上限
```

### 5.4 输出格式

```text
结论 = 通过 / 观察 / 排除
原因 = 1 条主因 + 1 条次因
关键变量 = 3 个
下一步 = 1 个最小验证问题
```

## 6. 改造顺序

1. 先把 Turtle 的“好公司”定义改成书里的“经济特许权 + 高于资本成本回报”。
2. 再把“增长”改成“增量资本回报是否超过资本成本”。
3. 再把“估值”改成“当前价格下的总回报分解”。
4. 最后把“安全边际”改成“回报差 + 衰减折价 + 价值陷阱折价”。
