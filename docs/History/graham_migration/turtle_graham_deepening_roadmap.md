## 一、书的可执行内核（钉死，勿再漂移）

Greenwald 三个价值来源，**按可靠性递减**：

1. **资产价值**（重置成本）— 最可靠。竞争均衡下无护城河公司，内在价值 ≈ 资产价值。
2. **EPV**（盈利能力价值）= 可持续盈利 / 资本成本，**假设零增长** — 次可靠。
3. **成长价值** — 只有护城河内的增长才创造价值，最不可靠、最难估。

三者差额即诊断信号：

| 关系 | 含义 | 路由归属 |
|---|---|---|
| EPV ≈ 资产价值 | 无护城河，竞争均衡（Magna 型） | R2 / R3 |
| EPV > 资产价值 | 有护城河，差额 = 特许经营价值 | R5 |
| EPV < 资产价值 | 管理层毁灭价值 / 行业衰退 | R4 |

两条到达"买点"的路径（= 系统"两条流水线"的书本出处）：

- **估值流水线**（Magna，第 1–5 章）：资产价值 → EPV → 成长价值 → 内在价值 → 对比价格 → 安全边际。
- **回报率流水线**（Intel，第 8 章）：当前价格下算预期回报 = 现金回报 D/M + 有机增长 + 积极投资，对比门槛。

> **核心诊断**：系统现有"穿透回报率" = 回报率流水线的一部分。**缺整整一半的估值流水线（EPV / 资产价值）**。EPV 是书头号锚点，却从未在系统中落地。深化第一优先级即补此缺口。

## 三、深化标准 — 每个执行器必过的 5 关

GG 精算能被 GPT 执行，靠的不是公式，是公式外的 5 层脚手架。**新建/升级的每个执行器都必须补齐这 5 关**，否则只是"公式表"、GPT 会即兴发挥。

| # | 关卡 | 达标判据 | GG 精算里的对应实例 |
|---|---|---|---|
| ① | **数据源逐行锚定** | 每个变量钉到 `data_pack §X` 具体行项；**拿不到精确数据则给近似估算+方法+⚠️，绝不空着**（全局原则，用户 2026-07-30 定案） | `§5 现金流量表 n_recp_disp_fiolta`、`c_recp_return_invest`、`§4 合同负债` |
| ② | **数据缺失降级阶梯** | 优先级 1→N，缺数知道怎么退、怎么标注 | AA 优先级 1–4（OCF→OCF缺→Capex缺→净利润×0.7 标"推测"） |
| ③ | **边界情形处理** | 负值/极端/结构突变有强制规则 | AA<0、CV>50% 取中位数、AP 超额融资、少数股东>10% |
| ④ | **强制敏感性 / 置信区间** | 禁止单点估计 | GG 三档置信区间、五参数联合误差表、λ 三档临界收入倍数 |
| ⑤ | **裁决联动** | 算出的数如何改买/卖/仓位 | AP-adjusted GG<II → 裁决不得高于观望；护城河 → position_cap |

**验收口径**：一个执行器"完成" ⟺ 5 关全过 + 能对一只真实标的从头跑到底不卡壳（Phase 7 校验）。

## 四·五、理念闭环（综合派 λ 合成，2026-07-30 定案）

**用户确认脊梁**：综合派——格林沃尔德估值定"生意值多少"(IV)，GG 定"价值能否变现金落小股东袋"(兑现)，VCF+护城河+治理 决定留存算不算数(λ)。

**闭环关键**：把原先"背离必须解释"的叙述要求，升级为**唯一确定性合成公式**（写入 `_graham_integration.md` §二理念脊梁 + §二合成块）：

```
IV      = 主估值（R3:EPV / R5:EPV+成长），折现率 r*
分红率   = min(dps/EPS归母, 1.0)
V_final = IV ×[分红率 + λ×(1−分红率)]          # λ 只裁决留存部分
λ = clip(0.5 + VCF档 + 半衰期档 + 治理档, 0,1)   # GG_base<II → λ 封顶 0.3
裁决锚   = V_final / 市值
```

**踩坑修正（本次 paper-test 抓出）**：初稿 `V_cash=E_norm×分红率/II` 用 II 折现，因 II<r* 令 V_cash 反超 IV、λ 方向颠倒。改为 `V_cash=分红率×IV`（同用 r*，干净地板）；II 只进"GG 兑现闸门"调 λ，绝不作 V_cash 折现率。

**双标的验证**：中国食品 EPV/市值=0.99(账面公允) 但 λ=0(弱护城河+侵占+GG<II) → V_final/市值=0.49 排除；分众超额分红→payout=1.0→V_final=IV，裁决只看 IV vs 市值。两例裁决确定且合理。

**结论**：理念层已闭环——不再是"两套哲学并列"，而是一条公式把 IV 与兑现质量合成单一 V_final。λ=1 退化为纯格林沃尔德，λ=0 退化为纯 GG，中间连续。剩余：真实 GPT 端到端跑一遍验证（所有校验仍是我 paper-based）。

### D1（书第4章·资产重估到"入场费"深度）
书第4章核心：资产价值不是账面值，是"**新进入者今天复制这盘生意要花多少钱**"（reproduction cost）。现状 AV 停在账面近似。深化点：
- **两口径分离落地**：持续经营=重置成本（含账面未体现的品牌/牌照/客户关系重建），清算=变现价值（仅有形、打折）。路由 R1 用清算、R2 用重置、R4 用资产地板——口径必须跟路由走，不能混用。
- **隐性无形从费用重建**（书里最反直觉、散户最缺的一步）：品牌价值≈近 N 年广告费累计×留存系数；研发资产≈研发费用累计×留存；客户关系≈获客成本×存量。这是把利润表的"费用"还原成资产负债表的"隐性资产"。
- **验收**：R2/R4 个股的 AV 出现"账面→重置"的逐项 bridge，隐性无形有重建算式而非拍脑袋系数。

### D2（书第8/9章·管理层作为价值变量，路由级）
书的硬结论（notes line 961）："**对竞争劣势或管理较差的企业，任何增长都可能破坏价值**"；以及反直觉点（line 679）："好管理的价值多已体现在当前现金流，差管理反而有改善期权"。现状：治理只是 λ 的③加减项（±0.10/−0.25），够不上书的分量。深化点：
- **成长价值的治理闸门**（比 λ 更前置）：R5 计入 franchise/成长价值前，先过"资本配置纪律"检验——若管理层历史上把留存利润投进破坏价值的多元化（增量 ROIC<r*），**成长价值直接归零或打折**，而不是靠 λ 事后微调。格力钛/银隆正是此例。
- **治理能触发路由降级**：R5→R4 的判据——好资产 + 系统性资本错配 = 价值毁灭型，按 R4 `min(AV折价, EPV)` 处理。这比现在"③治理−0.25"重得多。
- **区分"已定价"与"未定价"治理折价**：格力 PE 7.2x 已含治理折价（报告 line 1278 已识别），此时治理是**期权价值**（改善催化）而非扣分项——避免对已被市场惩罚的治理二次扣分。
- **验收**：出现资本配置纪律检验小节；R5 个股若有价值毁灭型再投资史，成长价值被显式打折并留痕。
