> 状态：`ACTIVE`

本文件只维护长期目标、阶段依赖和跨系统边界。当前案例状态、工作顺序和下一合法动作只由 `GOALS.md` 决定；历史检查点已移动到 `docs/History/roadmaps/`，不得从历史路线恢复状态。

## 1. 长期目标

Turtle 要自动形成可复核、完整且具有资深投资者判断深度的价值投资研究。报告把资产、安全边际、商业质量、护城河、治理、资本配置、正常利润、普通股现金、估值、回报、永久损失和行动条件连成一条连续主线。

成功不是章节齐全或机器分数较高，而是：

- 抓住少数决定企业价值和长期回报的经济机制；
- 重大事实可回到一手证据；
- 正常利润和经营驱动传播到普通股现金、价值与回报；
- 从竞争解释中选择有证据支持的中心路径，并把决定性判断冻结到可结算的未来节点；
- 最强反方、UNKNOWN、永久损失与翻转条件真实；
- 同一variant的事实、判断、模型、正文与HTML一致；
- 新公司和未来时期能够验证系统不是对既有样本的事后拟合。

## 2. 目标架构

```text
官方证据与时间身份
  → 公司事实、UNKNOWN与决定性问题
  → 公司原型、行业机制和估值路线
  → accepted judgments、中心路径与前瞻判断账本
  → 确定性正常利润、普通股现金、价值与回报
  → 连续黄金报告与render-only HTML
  → 追加式未来结算、校准与基准率
```

G1.5开始验证的双向层级扩展为：

```text
公司 × 时点黄金报告
  → 跨公司、跨时期行业机制
  → 多行业信号与官方统计形成有边界的宏观情景
  → 宏观经行业机制和公司具体暴露向下传播
  → 重新约束公司经营、现金、价值与回报
```

宏观不得直接生成目标价、评级或动作。行业知识库只能生成待验证问题，不得冒充公司证据或模型参数。

## 5. Phase 09与年糕边界

Phase 09只有G6完成后才能激活。它负责：

- 年报、半年报和季度节点的可比期间身份；
- 决定性问题逐题结算；
- 经营、行业、资本配置与价格变化桥；
- 通过版本化ResearchBundle向年糕投影研究状态。

Turtle拥有研究事实、判断、估值参考、反方和跟踪；年糕拥有账户、持仓、计划、成交、行情provider和市场真值。两者不得建立第二套相互冲突的真源。

## 6. Phase 10边界

当前只授权P10-A工程基础设施和G1.5登记矩阵的受限PIT报告：

- source package与`published_at`围栏；
- 冻结报告、预测和独立审阅身份；
- 走步结算账本和回归验证；
- 经营预测、报告覆盖和回报结算契约。

当前禁止：

- 把今天的报告倒灌为历史报告；
- 在G6前启动一般化多公司回测；
- 用后验结果调参数或重写冻结报告；
- 让外部执行sidecar选择证据、研究结论或投资动作；
- 把工程诊断宣称为严格无未来信息的模型能力证明。

## 8. 全局完成定义

Turtle长期路线完成至少要求：

1. Golden Set覆盖不同公司原型与价值路线；
2. 双向层级研究经V1/V2盲评、公司留出和时间留出证明有材料增量；
3. 历史PIT对象的冻结判断、追加结果和错误归因证明系统不只是事后解释；
4. 统一流水线复现证据、经济身份、模型和决定性结论；
5. Phase 09持续跟踪和ResearchBundle投影闭合；
6. Phase 10严格PIT报告、走步结算和基准比较能够区分研究质量、预测误差和投资结果；
7. 当前文档、代码、schema、dashboard和发布状态一致。

## 9. 文档与工作纪律

- 当前文档入口见 `docs/CURRENT_DOCUMENTS.md`；
- `docs/History/` 只用于追溯，不能决定状态或执行；
- 主树只用于集成，写任务使用linked worktree；
- 数据覆盖不足先修采集模块、schema或validator；
- 只有会改变投资结论、永久损失、估值、回报或中心论点的问题阻断；
- 真实模型运行是离线已验证变更的有界验收，不是在线调试循环；
- 不设置新的账号切换或阶段handoff作为恢复入口，中断统一回到 `GOALS.md` 和当前阶段文档。
