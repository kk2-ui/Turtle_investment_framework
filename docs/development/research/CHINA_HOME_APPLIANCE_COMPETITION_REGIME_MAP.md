# 中国家电竞争的时代状态图（研究准备稿）

**用途**：这不是“谁最后活下来”的公司史，也不是对海尔、美的、格力或任何公司管理层的排名。它是为企业家—行业专家训练建立的**案前状态语言**：先辨认当时约束、可行动作和可观察的经济后果，再选具体 decision episode。

**边界**：阶段只是筛选用的粗粒度环境变量。每个公司、品类和地区仍须以当期原件确认；不能用本图替代某个案例的事实、因果归因、结果合同或比较方案。年份交界也不是硬断点。

## 1. 为什么必须先有“时代状态”

同样是扩产、引进技术、降价或开渠道，在不同阶段含义完全不同：

```text
时代状态（需求、供给、政策、技术、渠道、资本）
→ 企业当时真正可选的行动与约束
→ 管理层的资源承诺和放弃的替代方案
→ 客户、渠道、竞争者、供应链的回应
→ 单位经济、现金转换和资本占用
```

因此，“早期家电竞争为什么只剩少数龙头”不是一个可直接训练的问题：它把不同品类、不同所有权与不同时间的路径，压缩成已知结局。可训练的问题应改写为：**在某一状态下，一项可观察决策怎样改变了哪一段传导；什么同时发生的条件会使同样决策失效？**

## 2. 五个研究状态

| 状态 | 环境的可用描述 | 当时最有信息量的企业问题 | 优先找的动作—结果链 | 不得从后见之明带入 |
|---|---|---|---|---|
| S1：扶持起步（约1979–1981） | 轻工业资源倾斜、鼓励引进技术和设备；家电尚处供给建立期。 | 引进的技术/设备是否真正变成可交付产品和本地组织能力，而非获得稀缺资源？ | `技术/设备权利 → 本地工艺、零件和质量控制 → 产品交付 → 现金与后续再投资` | 后来的品牌地位、市场份额或技术合作本身已证明能力。 |
| S2：控制下扩张（约1982–1988） | 需求快速增长；定点生产和行政控制并未消除地方进入、重复建设、产能过剩与组织分散。 | 稀缺需求下的扩线、引进和质量投入，是否留下可在供给转松后存活的质量/部件/现金能力？ | `资源承诺 → 产能/零件/质量能力 → 真实交付与返工/服务负荷 → 周转和资本占用` | 高增长、产量、牌照或引进线等于经营优势。 |
| S3：调整与竞争（约1989–2001） | 过剩与价格竞争形成；计划产品和多数优惠/保护取消；外资进入、融资与技改增加。同一引进平台在此时也会出现产品匹配、周转与核心资本配置的经营分化。 | 降价、渠道规则、售后、产品/部件投入、兼并或组织重构，究竟改变了客户选择、竞争反应或现金，还是只是行业共同消耗？ | `行动/合同权利 → 客户或渠道行为 + 对手回应 → 量价/成本 → 应收、库存、应付与资本占用` | 份额、规模、并购完成或短期利润已经证明护城河、优秀管理或 owner cash；共同平台、引进技术或早期热销已经解释后续分化。 |
| S4：全球化规模与产业链重构（约2002–2012） | WTO 后出口增长和全球产业转移；整机、压缩机、电机等产业链逐渐完备，国内企业与跨国公司同场竞争。 | 自制、供应链、出口、海外建厂或多品类扩张，是形成可吸收的成本/交付优势，还是把资本和营运资本风险放大？ | `资本/治理权利 → 产出吸收与外部客户 → 单位成本/价格实现 → 库存、应收、可得现金与资本回收` | 出口增速、垂直一体化、海外项目或行业集中已证明项目回报。 |
| S5：升级、数字渠道与服务化（约2013–至今） | 节能、变频、智能化等产品升级；线上线下融合、物流/服务和数据化运营改变渠道与服务边界。 | 产品、平台、服务网络和数字化投入，能否同时穿过客户采用、服务负担和产品/渠道经济，还是只是市场触达或收入确认变化？ | `问题/试点 → 可定义客户采用 → 价格、履约/服务成本和合同现金 → 基于反馈的下一次资源选择` | 专利、网点、客户数、总收入、线上份额、预收或“数字化战略”等于创新能力或 owner cash。 |

**S2 的已验证防错约束**：R-47 的同期报道显示，青岛、上菱和扬子均有较高起点的技术/设备引进与质量/效益报道，万宝也有质量整顿和技术人员补充。它们足以说明此类动作在 S2 并非只属于后来龙头；不能据后来存续从中挑选“唯一正确企业家”。下一段分叉必须落到 S3 的产品匹配、服务责任、渠道/信用或现金合同。

**S3 的需求侧补充**：R-48 的 1990–1993 消费者材料表明，售后服务已经会改变耐用品购买选择；它是全行业客户状态，不是任何品牌的护城河。具体企业仍必须把服务履约连至每台成本、渠道责任、价格/回款与现金，才可主张经营能力。

S1–S4 的阶段划分采用关于中国家电产业政策演化的学术归纳；S5 只作为当代训练入口，不宣称它是产业史唯一分期。中国家用电器协会的行业回顾也独立描述了：80年代技术/设备引进与供给扩张、90年代市场化及产能过剩/跨国进入、WTO 后出口与产业链完善，以及随后渠道与智能制造的变化。[吴骏（合肥工业大学）](https://som.hfut.edu.cn/info/1006/1960.htm)；[中国家用电器协会行业回顾](https://www.cheaa.org/contents/116/8685.html)。

## 3. 训练用的“状态 × 决策域”地图

| 决策域 | S1–S2 先问什么 | S3 先问什么 | S4–S5 先问什么 | 常见误判 |
|---|---|---|---|---|
| 技术与产品 | 引进能否被吸收为同厂的工艺、质量、零部件能力？ | 新品/性能是否改变客户选择且覆盖服务成本？ | 产品/软件/服务试点是否形成可定义采用和经济性？ | 技术来源、专利、获奖或新品发布等于能力。 |
| 产能与制造 | 扩张是否只是满足短缺，抑或降低失效、返工与部件依赖？ | 过剩下产能能否被真实订单/出货吸收？ | 自制、自动化、海外或柔性制造能否提高单位经济及资本回收？ | 产量、产能、固定资产或总 OCF等于资本回报。 |
| 渠道与服务 | 稀缺供给下，渠道安排的真实权利是什么？ | 合同、返利、维修资格和账期怎样改变价格、回款、库存与竞争回应？ | 线上线下、安装、履约和售后如何分担客户选择与服务成本？ | 网点、口号、排名或总服务收入等于渠道控制/质量护城河。 |
| 组织与治理 | 责任单元是否真的拥有决策权并可观察其结果？ | 并购/重组是否在同一经济单元形成成本、质量、周转与现金改善？ | 平台化/数字化是否把反馈转成下一次资源选择？ | KPI、内部审计、重组完成或法人利润等于管理能力。 |
| 资本与外部扩张 | 引进与建设付出的现金/控制权利是什么？ | 价格战、融资、兼并和扩线的现金来源、回款风险和替代成本是什么？ | 全球化、多品类与供应链投入的资本占用与治理权利是否可回收？ | 融资到位、销售增长、出口/并购公告或一个 OCF 数字等于创造价值。 |

## 4. 用于下一批案例的选择纪律

一张卡先写下面五件事，才允许读深：

1. **状态定位**：本案是哪个状态，且哪两个环境事实支持它；状态不明则 `QUESTION_ONLY`。
2. **实际决策与替代**：公司做了什么资源承诺；在当时至少一个可行替代是什么。
3. **竞争机制叉**：例如“可吸收的成本/服务优势”对“行业共同扩张/让利”；双方必须解释同一当期事实。
4. **时期匹配的结果合同**：S2 不用后来的市场份额代替质量/现金；S3 不用规模代替竞争/回款；S5 不用客户数代替 cohort 采用与服务经济。
5. **一个边界或近失效角色**：只改变上游条件或外部约束，不从后来成败倒推选择。

这使历史材料成为“不同状态下的企业判断练习”，而非为少数幸存者寻找单一成功秘诀。1999 年的彩电产业组织研究也描述了重复引进/建设、随后激烈竞争与逐步集中的过程，可作为 S2→S3 的品类级背景，而不是任何公司或管理层的结论。[夏大慰、陈代云、李太勇（1999）](https://qks.shufe.edu.cn/J/CJYJ/Article/Details/A160824005503/CN)

## 5. 对“早期家电为什么只剩少数龙头”的当前研究边界

截至目前，训练并未给出“哪三家为什么胜出”的结论；它已经把这个后见之明问题拆成四个可研究、但不可互相代替的命题：

| 已有可用认识 | 当前能说什么 | 仍缺什么，因而不能说什么 |
|---|---|---|
| S2 的技术/质量投入 | R-47 的同期多企业材料表明，先进线、标准、质量整顿和早期效益并不只属于后来龙头；它们至多是广泛可得或必要条件。 | 不能把“质量”从共同条件升级为某一家后来的客户黏性、现金优势或存续原因。 |
| S3 的产品匹配与扩散 | R-41/R-42 显示客户使用约束能先改变产品选择，但规格会扩散，且采用不自动等于产品经济。 | 不能把单一 SKU 热销、产品份额或集团利税写成长期竞争优势。 |
| 服务改变购买选择 | R-48 显示售后服务在 1990 年代初已经是客户选择变量；R-49 则显示服务网络规模没有形成可读的企业经济。 | 不能把服务口号、热线/网点、满意度或品牌直接写成服务护城河。 |
| 现金与资本纪律 | 后续彩电、空调、冰箱和跨境制造教学反复显示，收入/利润、库存释放、供应商融资、客户信用和资本回收必须拆开。 | 它们不能反推任一早期冰箱企业的完整现金史，更不能把后来集中度解释为管理/资本配置必然正确。 |

下一轮不是再选一个后来著名的冰箱厂，而是寻找一个能闭合下列最小链的 S3 `1+1+1`：

```text
focal：命名企业的非共同产品/服务/渠道动作
       → 同产品客户或履约观察 → 同一责任单元的成本/回款/现金

near-miss：相似状态和共同条件，只翻转一个上游中介事实

boundary：同一机制叉，改变地区、渠道制度、资本约束或竞争跟进条件之一
```

三者任何一方没有 cutoff 前的行动和同定义结果合同，就只做单卡状态训练；绝不用后来存续、市场份额、价格或回报补齐。

## 6. 这个准备图如何被验证

它不以“分期是否漂亮”验收，而以会否改变下一张卡的输入来验收：

- 若状态图使研究者把“技术引进”拆成权利、吸收、质量与现金的可结算箭头，保留；
- 若它使一个原本看似可比的案例因需求、供给、政策或渠道约束不同而退出 near-miss，保留该边界；
- 若具体公司原件推翻本图的状态假定，就以原件修订或放弃本案，绝不让时期标签压过证据；
- 不计算各状态的“胜率”，也不从后来存续、股价或回报反推哪个阶段的管理方法正确。

**下一步**：以 S3 的“过剩/竞争下的产品或服务决策”与 S5 的“服务化采用”各筛一个候选；只有在行动、同一客户/责任单元的结果与结果合同都齐备时，才升级为完整教学卡。
