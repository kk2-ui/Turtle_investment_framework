# ITER-105 — 先独立形成公司判断，再读取价格隐含路径

日期：2026-08-21

[Remus、O'Connor 与 Griggs（1996）](https://www.sciencedirect.com/science/article/pii/S0167923695000097) 的实验不是投资回报研究，但它给出一条与 Turtle 任务直接相关的边界：在多源信息预测任务中，独立准备初始预测的表现优于未独立准备。它不证明“忽略价格”会提高回报，更不授权把盲轨当作唯一真相；它只支持把公司机制判断和后续市场信息整合分成两个可审阅阶段。

[Sarafoglou、Hoogeveen 与 Wagenmakers（2023）](https://doi.org/10.1177/25152459221128319) 对 analysis blinding 与预注册的比较，补充了更窄的理由：可在不知结果的条件下检查数据结构并设计确认性分析，从而减少事后为结果改规格的空间。Turtle 不把公司研究伪装成实验，也不遮蔽公司经营事实；它只借用“将会改变结论的结果信息延后读取”的纪律。因此经营盲轨须排除价格、估值倍数和事后经营结果，仍允许读取 cutoff 前的公司、行业与现金事实；后续价格轨也保留为可审阅的独立对象。

这验证了格力的 `COMPANY_JUDGMENT_ONLY` 顺序：先以当期公司、行业和现金证据写出 H-A/H-B、四层 driver 与无价格 FJ；随后再让同一 cutoff 的股价、估值和回报要求形成另一条市场隐含轨，并把分歧转化为新的决定性问题。价格仍是进入安全边际与行动的材料输入，却不能替代公司事实、选择 H-A/H-B 或结算经营机制。

根因是 `REASONING + MODEL`。若两轨一开始混写，研究者容易把已知低 PE、股价走势或隐含回报倒灌为“经营判断”；经济影响是以市场叙事掩盖渠道、owner-cash 或资本配置的不确定性。禁止把 CJO 的无价格边界解释为永久排除市场，也禁止以未有估值/仓位作为拒绝冻结公司判断的理由。接纳条件是：CJO 产物严禁证券价格、估值、回报、仓位和交易动作；后续投资版本必须显式读取同一或可解释差异的公司判断版本，而非回写其中心路径。格力目前仅完成前一阶段的契约与事实编年，尚缺 P0 行业 release、cash bridge 和可冻结 FJ，故仍是 `PRE_FREEZE / UNDISCRIMINATED / NO_PROBABILITY`。
