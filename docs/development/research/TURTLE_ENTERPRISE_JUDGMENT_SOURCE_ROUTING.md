# 企业经营判断：按决策域取证路线

状态：`ACTIVE_PREPARATION / RESEARCH_FIRST / NO_PRICE_PROXY`。

关联：[企业经营判断训练方案](TURTLE_ENTERPRISE_JUDGMENT_TRAINING_BLUEPRINT.md)、[判断力飞轮](TURTLE_JUDGMENT_FLYWHEEL.md)、[中国家电 episode 队列](CHINA_APPLIANCE_DECISION_EPISODE_BACKLOG.md)。

## 1. 目的

这份路线不是“哪里能找到更多资料”的清单。它规定一个决策要被训练为企业家、行业专家和长期所有者式判断时，**每一条因果箭头需要什么类型的原件**。它解决的不是写得不够细，而是防止年报、企业史或后来结果让研究者跳过中间机制。

基本单位仍是：

```text
历史状态
→ 实际资源承诺（及真实替代）
→ 客户 / 员工 / 渠道 / 竞争者反应
→ 单位经济与营运资本
→ 资本回报或其 UNKNOWN 边界
```

每类资料只证明自己的位置；来源权威不自动跨越箭头。

## 2. 通用取证包

每个候选先建四格 source packet，未齐时停止深读：

| 包 | 必须回答 | 优先原件 | 不能替代成 |
|---|---|---|---|
| `ACTION` | 谁在何时实际承诺了什么资源、保留什么停止权？ | 董事会/股东会决议、合同、当期产品/服务公告、可定位的预算或项目进度。 | 后来年报、企业史、人物访谈的回顾。 |
| `STATE_AND_RIVAL` | 当时共同约束是什么？最强替代为什么可行？ | 同期行业统计/监管、同 arena 竞争事件、客户/供应链/政策原件。 | 后来的行业集中度、公司宣传。 |
| `MECHANISM_OUTCOME` | 哪些早期和终局经营观察能区分 H-A/H-B？ | 同主体的连续法定披露、结果前已定位的监管/客户/行业连续资料。 | 总收入、净利润或不相同 KPI 的拼接。 |
| `CAPITAL_AND_CASH` | 现金来自哪里，资本占用/回收由谁承担？ | 现金流调节、资产负债表、资本开支/固定资产、同一责任单元的经营资料。 | OCF 单值、期末现金或新借款。 |

`ACTION` 与 `MECHANISM_OUTCOME` 若只在同一份后验文件才出现，登记 `CONTEXT_SEPARATION_NOT_ASSURED`。它可以进入候选索引，却不能被写成结果前判断或正式回放。

## 3. 决策域的最小路线

进入任何路线前，先用[中国家电竞争时代状态图](CHINA_HOME_APPLIANCE_COMPETITION_REGIME_MAP.md)定位需求、供给、政策、渠道与资本约束；状态是选案边界，不替代企业原件或因果结论。

### 3.1 产品创新与客户采用

```text
用户痛点/现有替代
→ 新品或服务的实际资源承诺
→ 首批采用（订单、复购、退货、安装/服务负荷之一）
→ 单位价格、成本和服务负担
→ 营运资本与资本回报
```

| 箭头 | 最小可接受来源 | 典型误用 |
|---|---|---|
| 用户问题与替代 | 当期客户/渠道材料、监管标准变化、实际竞品/替代品价格或性能原件。 | “消费升级”、专利数或后来的品类地位。 |
| 实际承诺 | 研发/产品发布、试点合同、生产线/服务网络预算的当期材料。 | 后来招股书追述“当年推出”。 |
| 首批采用 | 同一产品的订单、可定义的 sell-out、复购/退货/安装/服务记录。 | 总公司收入、广告曝光、媒体称赞。 |
| 单位经济 | 同产品/责任单元的收入、成本、折扣/返利、服务成本。 | 总毛利率或销量。 |

R-26 的九阳候选正是缺少前两格的同期原件，因此停在 `NO_PRIMARY`。R-28 的华帝则证明仅通过前四格仍不够：产品级毛利观察还必须继续穿过渠道/服务费用、营运资本和资本回报，才能讨论长期所有者结果。

#### 3.1.1 创新能力不是一项新品：增加“学习闭环”但不跳过产品经济

一项新品在结果期卖得好，最多先支持一段产品经济传导；它并不自动证明公司拥有可迁移的创新能力。能力训练只在产品链之外多问一层：企业是否把一次市场反馈转化成下一次**可观察的**研发、设计、制造、渠道或服务选择。

```text
问题感知与现有替代
→ 可验证的试验/设计/资源承诺
→ 首批客户采用与使用反馈
→ 产品单位经济与服务负荷
→ 管理层据此保留、修正或停止的下一次选择
→ 在不同产品、客户段或时间窗的有限复现
```

| 需要区分的问题 | 最低可接受观察 | 不能偷换成 |
|---|---|---|
| 产品货币化规则有效 | 同产品的收费/合同规则、付费客户状态或 ARPU、同产品毛利/主要成本边界。 | 续费、客户价值、完整产品现金或创新能力。 |
| 一次产品有效 | 同产品的采用 + 单位经济/服务负担至少各一项。 | 专利数、获奖、总收入或管理层称“爆款”。 |
| 反馈真的进入组织选择 | 行动前或紧随其后的产品迭代、试点扩大/停止、资源再分配或明确的失败退出记录。 | 新一年度继续增加研发预算、企业史回顾或泛称“以用户为中心”。 |
| 能力具有有限重复性 | 第二个不同产品/客户段的**预先独立**链条，且保留首次案例的断裂条件。 | 同一产品连续季度、同一公司总增长或第一个产品的后验成功。 |
| 经济上值得保留 | 第二条链仍经由同口径的价格/成本/服务、营运资本和资本占用。 | 采用率、营收增速或品牌排名。 |

结算分层：一张卡只能回答“一次产品/过程在本案的哪一箭头成立”；同一公司第二次独立卡可测试 `repeatability`，但不构成跨公司样本；不同中国公司才可承担机制迁移或边界复验。若第一张只有收费/合同、ARPU与毛利，止于 `PRODUCT_MONETIZATION_MECHANICS_OBSERVED`；若已有采用与同产品经济但未观察管理层处理反馈，才止于 `PRODUCT_ECONOMICS_OBSERVED`；两者都不能称 `CAPABILITY_OBSERVED`。

这条分层受能力生命周期、刻意组织学习与探索/利用的研究启发：能力会形成、发展、分支或衰退，而不是静态标签；短期对既有做法的利用也不等于已建立新能力。[Helfat & Peteraf (2003)](https://doi.org/10.1002/smj.332) [Zollo & Winter (2002)](https://doi.org/10.1287/orsc.13.3.339) [March (1991)](https://doi.org/10.1287/orsc.2.1.71) 这些文献不替代某家公司的一手证据。

### 3.2 质量、保修与服务

两臂必须并存：

```text
质量/服务承诺 → field_reliability_or_service_demand → per_unit_service_cost_or_liability
质量/服务承诺 → customer_or_channel_choice → price_realization_or_retention
```

| 箭头 | 最小可接受来源 | 典型误用 |
|---|---|---|
| 承诺 | 当期保修条款、服务协议、质量体系/工艺变更、网点/备件资源承诺。 | 品牌口号或后来奖项。 |
| 可靠性/服务需求 | 同定义返修、故障、索赔、监管抽检/召回、服务工单或第三方投诉分类的连续观察。 | 一次新闻、认证或管理层“质量领先”。 |
| 成本/责任 | 同一保修期口径的每台服务成本、索赔率或连续的准备/实际支付。 | 把维修费、期末准备和 OCF 混为同一指标。 |
| 客户/渠道反应 | 同产品价格实现、复购、退换、可定义订单或渠道留存。 | 总销售、后来份额。 |

R-27 的格力筛查只满足承诺与总财务，故不能越级。

### 3.3 产能、关键部件与制造能力

```text
resource_commitment
→ output_absorption
→ unit_economics
→ working_capital_cash
→ capital_return
```

| 箭头 | 最小可接受来源 | 典型误用 |
|---|---|---|
| 资源承诺 | 项目批准、合同、资本支出、基地/设备投产与停止条件。 | 规划产能或竣工宣传。 |
| 吸收 | 同产品产量/销量/订单、产能利用或可定义 sell-out。 | 公司总收入。 |
| 单位经济 | 整机与部件、内供与外供、价格/成本/毛利的同一责任单元口径。 | 内部出货、技术合作或销量。 |
| 资本回报 | 项目/责任单元资本占用、维护资本开支与至少两期经营现金/利润观察。 | 总 OCF、固定资产增加、行业淘汰。 |

R-25 已展示：输出吸收与部件经济性可以给出相反结论，二者都不能替资本回报作答。

### 3.4 组织、授权与责任单元

```text
decision_right
→ accountability_unit
→ incentive_and_exit
→ operating_response
→ same_boundary_economics
```

| 箭头 | 最小可接受来源 | 典型误用 |
|---|---|---|
| 决策权 | 组织决议、授权范围、采购/定价/用工/资本权限。 | “实行事业部制”的公司回顾。 |
| 责任单元 | 明确 P&L、营运资本和负责人/退出权的边界。 | 集团收入或品牌时间线。 |
| 经营反应 | 同单元交付、质量、周转、客户或成本的连续资料。 | 并表后总增长。 |
| 经济后果 | 同一边界的利润、现金与资本占用。 | 集团利润、市场排名。 |

R-18 的美的事业部制已说明：主体边界不连续时，资料多也必须保留 `MEASUREMENT_MISMATCH`。R-31 的 TCL 制度筛选又说明：即使 KPI、内部审计和法人财务表同时存在，仍须有“责任书/负责人 → 决策权 → 同名责任单元经济结果”的映射，不能按名称拼接。

### 3.5 渠道、信用与现金

沿用既有两条链：

```text
counterparty_chain_identity
→ contractual_control
→ realized_collection
→ independent_verification
→ cash_conversion

collection_cash / inventory_cash / supplier_finance / external_financing
```

这部分不再以“保险、保理、票据或大客户名称”筛案。详见判断力飞轮和 R-21–R-24。

## 4. 候选分流，而非一刀切淘汰

| 身份 | 可做什么 | 不能声称什么 |
|---|---|---|
| `OUTCOME_CONTRACT_READY` | 冻结 H-A/H-B、早期/终局不同观察和后续读取边界；可进入历史自回放或真实前瞻。 | 单案形成通用规律、概率或投资结论。 |
| `RESULT_KNOWN_TEACHING` | 用已知结果训练机制拆分、遗漏变量、近失效和下一卡的输入变化。 | agent 当时预测正确，或管理者总决策正确。 |
| `SOURCE_SCREEN / NO_PRIMARY` | 记录路线、缺口与不能用的代理；转向下一 candidate。 | 没有资料就意味着能力不存在/存在。 |
| `MEASUREMENT_MISMATCH` | 保留可见事实并注明不能重建的指标；可改造未来合同。 | 以相近 KPI、累计数或公司解释补算。 |

早年中国家电的公开材料稀疏是正常约束，不是暂停研究的理由。正确动作是明确此卡的上限、将缺口转为下一轮 source route，再换一个 `决策域 × 状态 × 机制叉`；不是为同一公司加读二十份报告。

## 5. 执行顺序

1. 先用 15 分钟完成 `ACTION / STATE_AND_RIVAL / MECHANISM_OUTCOME / CAPITAL_AND_CASH` 四格；任意一格只有后验叙述，即降级，不开始公司史。
2. 只读填空所必需的原件；每新增文件必须改变一个缺口的状态，否则停止。
3. 结果前写出 H-A/H-B、简单基线、早期与终局不同的可观察结果，以及禁止代理。
4. 结果到期后按已冻结来源读取；从箭头结算回写到下一不同对象的 source route。
5. 只有重复出现同一种材料性缺口，才改公共 acquisition/contract；不要为单个缺口新建评分、schema 或长链脚手架。

## 6. 下一批优先入口

- `创新/产品采用`：优先查能将行动、首批采用、单位经济、反馈后的资源选择和第二个独立产品/客户段分开的公司、监管或行业原件；九阳与浙江美大等只作 source screen，不能用新品/专利/总增长凑成能力结论。
- `产品/质量`：优先查能够同时提供当期承诺、同产品客户采用/故障/服务成本与连续财务边界的公开公司、监管或行业原件；九阳与格力只保留为反向路标。
- `组织责任`：优先查有法律授权、同一责任单元经营资料和现金边界的单次制度改变；避免“集团改革后成长”的叙事。责任书、内部审计和法人利润齐备但没有映射时，按 R-31 停在 source screen。
- `产能`：只在存在项目级/责任单元的产能、单位经济和资本回收观察时进入自回放；R-25 不因美的材料多而延长。

根因的总体分类为 `REASONING + ACQUISITION_MODULE + DATA_COVERAGE`：报告倾向披露承诺和总财务，往往不披露中间客户、质量、责任单元与项目现金变量。经济影响是未经路线约束的研究会把故事当因果，高估正常盈利、owner cash和资本配置，或错误否定真实能力。禁止假设任何公开量都天然可归因；验收是每个新候选在深读前能被分流到上表之一，并明确它缺的哪条箭头与下一步会补什么。
