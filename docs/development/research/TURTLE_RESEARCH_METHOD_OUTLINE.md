# Turtle 研究方法大纲

状态：`DRAFT / RESEARCH_FIRST`  
定位：这是一套训练和积累公司判断的方法，不是一份报告生产流程。格力只是第一个实验对象，用来暴露方法的盲点；方法必须能迁移到别的公司和行业。

训练的总目标与正式研究前的准备出口见[企业经营判断训练方案](TURTLE_ENTERPRISE_JUDGMENT_TRAINING_BLUEPRINT.md)：每个方法对象最终服务于“经营者的决策、行业的反应、长期所有者的资本后果”这一条因果链，而不是把三种视角拆成三份报告。

整套方法的一个核心循环见[判断力飞轮](TURTLE_JUDGMENT_FLYWHEEL.md)：问题 → 竞争机制 → 可结算观察 → 冻结 → 经营结算 → 误差归因 → 跨对象复验。以下大纲与模板都只服务于这个循环；它们不是彼此独立的“研究要求”。

研究开始、停止、复验与沉淀的具体顺序见[研究操作流程](TURTLE_RESEARCH_OPERATING_PROTOCOL.md)。它配套轻量研究模板： [机制判断微演练](../../../templates/research_mechanism_micro_drill.md)、[迭代卡](../../../templates/research_iteration_card.md)、[来源观察卡](../../../templates/research_source_note.md)、[机制竞争实验](../../../templates/research_mechanism_lab.md) 和 [学习复盘](../../../templates/research_learning_review.md)。微演练训练一条箭头；只有需要正式冻结/结算的对象才进入完整迭代卡。这些是研究笔记，不是报告模板或机器发布门。

类比研究另使用[结构化类比与近失效卡](../../../templates/research_analogy_transfer_note.md)，确保案例迁移的是条件与失败模式，而非已知结局。

判断力不是凭感觉验收，而以[判断力验证与回测协议](TURTLE_JUDGMENT_VALIDATION_PROTOCOL.md)中的冻结经营判断、早期机制结算、终局经营结算和跨对象复验来检验；股价/回报仅在独立投资层结算。

公司经验如何从历史案例逐步积累、又如何避免被报告数量和已知结局伪造，见[公司经验积累协议](TURTLE_COMPANY_EXPERIENCE_ACCUMULATION_PROTOCOL.md)。

当前可执行的历史训练、严格留出与真实前瞻分工，见[历史 PIT cohort register](HISTORICAL_PIT_TRAINING_COHORT_REGISTER.md)。

## 1. 研究的目标

目标不是更快写出结论、预测股价或堆出更多资料，而是逐步获得下面三种能力：

1. **解释能力**：能说明公司所处行业中，客户选择、竞争、渠道、成本、资本配置如何共同决定经济结果。
2. **判断能力**：面对同一组事实，能提出最强的竞争机制，知道什么未来事实会改变判断。
3. **学习能力**：把当时的判断保留下来，事后分辨是机制错了、数据边界错了、还是信号本来就没有诊断力。

公司研究的第一性对象是经营现实，不是股价；估值、回报和行动只在公司判断相对成熟后，作为独立的第二层工作。

### 判断力是方法的第一验收对象

这里的“提升判断力”不是让研究者更自信，也不是以一次投资结果、报告文采或主观评分来证明自己进步。它指五种可观察、可复盘的能力：

| 判断能力 | 研究者能做出的更好动作 | 失败时的典型表现 |
|---|---|---|
| 问题界定 | 把模糊的好/坏公司问题压缩为会改变经济结果的决定性问题。 | 用“护城河强不强”“行业景气不景气”代替问题。 |
| 机制辨别 | 让最强替代机制与主机制解释同一事实，并找出不同后续顺序。 | 一条主叙事加一张风险清单。 |
| 测量辨别 | 知道每项数据观察了什么，何时不能比较或不能外推。 | 将份额、出货、收入、毛利或现金直接拼成单一真相。 |
| 校正能力 | 新事实到来时能判断该改机制、边界还是信号，而不改写过去。 | 用已知结果重写“当初判断正确”。 |
| 迁移能力 | 从案例中迁移条件和失败模式，并在不同公司发现断裂条件。 | 复制名家结论、终局或估值倍数。 |

每一轮方法实验只训练其中一到两项。实验结束时必须指出：它让研究者多获得了哪一种**原先无法作出的区分**，或者诚实地记录该方法没有提升判断力。没有新增区分、没有避免已知误判、也不能迁移复验的步骤，不因其复杂或漂亮而保留。

判断力的学习回路为：

```text
第一性原理的问题 → 竞争机制 → 有边界的观察 → 预先指定的反证
             ↑                                      ↓
       跨对象复验 ← 方法更新 ← 结果复盘与误判归因
```

其中结果复盘优先问“我当时为何没有分辨出另一种机制”，而不是“最后赚没赚钱”。

## 2. 研究的最小单位

研究不以“读了几份报告”或“写了几页正文”计量，而以以下六类可复用对象积累：

| 对象 | 回答什么 | 典型产出 |
|---|---|---|
| 行业机制图 | 价值通过哪些客户选择、接口、交易点和约束传导？ | `industry_mechanism_map` |
| 公司状态编年 | 公司在不同状态下做了什么、资源如何移动、后果为何仍不确定？ | `company_episode_trace` |
| 竞争机制实验 | 哪两种（或更多）解释都能解释当前事实，它们将如何分叉？ | `rival_mechanism_lab` |
| 数据分歧地图 | 每种数据实际看到了什么；背离时先重开哪一个边界？ | `sensor_discrepancy_map` |
| 结构化类比 | 哪个历史机制可迁移，在哪个条件下会断裂？ | `analogy_transfer_note` |
| 学习记录 | 已到期的信号教会了什么，下一次保留或放弃什么？ | `learning_note` |

研究报告、数据库、前瞻判断账本和回测都是这些对象的载体或冻结工具，不能反过来决定研究问题。

## 3. 核心工作流

### A. 先界定经济问题，而不是先选结论

为每一轮研究写一个单句问题：**哪个机制若为真，会材料性改变公司未来的盈利能力、现金转换或资本配置？**

例如不是“格力有没有护城河”，而是“线上相对位置转弱究竟是渠道/价格带重配，还是更广泛竞争恶化的早期表现？”问题要有明确的经济后果与时间尺度。

### B. 从行业和客户开始画机制

先画出客户替代、产品和服务交付、渠道交易点、库存/产能、成本与现金的顺序。每条箭头分为：已证实事实、合理但未证实机制、以及未知。

行业图的作用是发现需要研究的接口和约束，而不是把“规模大、排名第一、垂直整合”翻译成护城河。

### C. 重建公司状态与行动时间线

按结构变化而非按年报章节重建：当时状态、管理层动作/资源承诺、随后可观察的经营与资本后果、会计口径变化和未知事项。

管理层表达必须拆开：

- 行动承诺：是否实际发生；
- 可测预测：能否在当时定义结果；
- 因果归因：只是待检验解释；
- 愿望或自评：只生成问题。

“动作完成”不等于“经济判断正确”。

对资本配置、组织调整、渠道建设或产品投入，先过一个**行动—经济判断准入门**：行动链可单独记录授权、条件、交割、付款或控制权；经济链只有同时存在主/反机制、经营指标、比较基准、归属边界、观察窗口和允许的结果来源时，才允许冻结前瞻判断。缺任一项，正确输出是 `ACTION_SETTLED / NO_ELIGIBLE_ECONOMIC_FJ / NO_COMPANY_CONCLUSION`，不是把日后业绩或“动作完成”补成协同证据。

这条规则目前由 R-02 的真实 PIT 训练支持，仍须在有预定义经营传导的不同对象上复验；它防止过度归因，不替代对经济机制本身的验证。

### D. 让竞争机制争夺同一组事实

不写一份主叙事加一张风险清单。先生成当前可信的机制候选，并问“若它为真，当前决定性问题中的哪一条经营边界、FJ 或取证动作会改变？”；只有能解释共同事实并通过这一位移检验的候选，才进入本轮机制空间。再将因果顺序与可分叉观察真正相同者合并、与 cutoff 前事实直接矛盾者排除；不满足位移检验的事项只记录为另一问题的 `OUT_OF_SCOPE`，不被误写为已证伪。之后才选出主机制与最强替代机制。它们都必须解释当前已知事实，但对下一段经营顺序给出不同预期。

每一方都应明确：客户/竞争变化 → 渠道或产品 → 量价/费用 → 利润与现金，及它会被什么观察显著削弱。仍可解释共同事实、却没有可分叉观察的实质第三机制，会使中心路径退为 `NO_PRIMARY`；研究仍可保留为信号探针。若两方没有不同的可观察结果，正确状态是 `UNDIFFERENTIATED`，不是给一个主观概率。

机制还要声明自己的适用环境。只有会改变 H-A/H-B 因果顺序、结果指标含义或可比较性的政策、行业结构或制度断裂，才可作为预注册的 regime break；普通宏观波动仍属于两方需要解释的状态。break 必须有 cutoff 前状态、一手来源、未来可观察触发和事先动作；触发后保留原始结果，却在新 cutoff 重建机制，而不是把“环境变了”写成事后免责。

### E. 将数据视为不同层的观测，而非同一真值的投票

每项数据先标明交易点、对象、单位、渠道、期间、版本与遗漏部分。把它归入下列之一：

- `FACT`：可复读且边界明确的公司或外部事实；
- `SENSOR`：有方向信息但方法、覆盖或映射不足的资料；
- `HYPOTHESIS`：资料支持提出的机制解释；
- `UNKNOWN`：尚不能由现有材料回答的问题。

不同来源不一致时，不取平均、不按机构名气投票。先检查 sell-in/sell-out、金额/数量、线上/全渠道、自然年/冷年、会计分类、品牌映射和修订版本；不能化解时，保留分歧并提高相应取证优先级。

### F. 将经营机制传到财务，但不急于估值

只在机制链足够清楚时讨论它如何影响收入、单位经济性、营运资本、维护投入、现金可支配性和资本配置。会计现金流、毛利率或余额只是传导中的一层，不能独自替代经营判断。

此阶段的重点是找出：什么会令“表面盈利”与“正常盈利”、或“表面现金”与“owner cash”分离。估值在这一层之后才有输入基础。

### G. 用案例训练条件判断，而非复制结局

案例卡和书籍案例只迁移“在什么条件下，哪条机制可能成立”。每次援引一个支持类比，必须同时写：

1. 至少三个真正的匹配维度；
2. 一个会令类比断裂的结构差异；
3. 一个表面相似、但因该差异而失效的近失效案例。

在写上述匹配理由之前，先独立完成目标公司与 source case 的因果骨架（状态 → driver → intermediate → operating observation），再对齐两者。理由写作有时会反而放大可叙述的表面相似、降低结构差异的辨别，因此它不是结构匹配的证据。若不能隔离 source 详细材料或结果，类比仍可作问题路由，但不得作为 `STRUCTURE_FIRST` 干预的验证样本。

不迁移目标价、估值倍数、已实现回报或名家结论。案例的价值是更早发现失败路径。

### H. 预先指定少量有诊断力的后续观察

当且仅当数据边界清楚时，写下 6–12 个月的早期经营信号和较长期的经营结果：指标、方向或范围、比较基准、观察窗口、允许来源和它要区分的机制箭头。

早期信号只结算对应箭头；它不应因为股价、总利润或一条新闻而提前宣布整个判断胜负。

### I. 复盘并更新方法，而不是改写过去

结果到来后保留原判断，另写学习记录：

- 哪个机制得到支持、削弱或仍无诊断性？
- 偏差来自事实、测量边界、机制还是时点？
- 哪个信号应保留、改口径、提前观察或废弃？
- 哪个类比迁移成立或因何断裂？

一次结果不构成“经验”。跨公司、跨状态、彼此独立的 episode 才可能逐步形成参考类和校准信息。

## 4. 研究优先级

资料与时间按以下顺序投入：

1. 能让竞争机制出现不同结果的事实；
2. 能改变正常盈利、现金转换、资本配置或永久损失判断的事实；
3. 能揭示测量边界或推翻一个类比的事实；
4. 只补背景、排名、观点或目标价的材料。

第四类可读，但不应挤占前三类研究资源。数据缺失是常态：只要能明确它缺在哪条箭头、会误导什么，就已经推进了研究。

## 5. 质量纪律

每一项准备进入研究结论的材料，先回答五个问题：

1. 它究竟观测了什么，而不是作者说它代表什么？
2. 它更符合哪条机制；另一条机制能否同样解释？
3. 若它错了或口径不同，哪个经济结论会被错误改变？
4. 下一条什么观察能降低这项不确定性？
5. 若观察永远不可得，最保守、仍可诚实保留的结论是什么？

不能回答这些问题的材料只作背景，不升级为公司判断。

## 6. 阶段性产出与顺序

| 阶段 | 真正的交付物 | 不是交付物 |
|---|---|---|
| 研究启动 | 决定性问题、行业机制图、未知清单 | 公司结论、概率或目标价 |
| 公司深挖 | 状态编年、行动链、会计/数据边界 | 管理层能力评分、故事摘要 |
| 机制竞争 | 对立机制、分歧地图、反例与取证顺序 | 乐观/悲观情景投票 |
| 观察与学习 | 少量可结算信号、追加的学习记录 | 事后改写的“当初就知道” |
| 成熟后 | 可冻结的公司判断，再独立接估值/投资研究 | 用价格替代公司判断 |

## 7. 研究必须按迭代运行

对一个公司的持续阅读不是迭代。**迭代的单位是一项方法假设的受控小实验**；每轮都必须决定保留、修改或放弃某个研究方法，并留下可被下一家公司复验的结果。

每轮迭代固定包含六步：

1. **方法缺口**：现有方法在哪一种真实研究情境中会误导判断？
2. **可证伪假设**：加入或删除一个具体步骤，预计会避免什么错误、产生什么更有诊断力的对象？
3. **有界实验**：只选一个公司的一段状态、一个机制或一类数据；预先限定材料和问题。
4. **反证/对照**：寻找该方法仍会失败的材料、另一种解释，或以未使用该步骤的旧结论作对照。
5. **方法裁决**：标为 `RETAIN`、`MODIFY`、`REJECT` 或 `INSUFFICIENT_TEST`，并说明经济上避免或仍可能造成的错误。
6. **迁移复验**：下一轮优先换公司、行业、时期或机制；若暂时还在同一公司，必须换到足够不同的问题，不能只是多读几份同类材料。

每轮最多只允许改变一个主要方法部件。例如先测试“会计口径边界是否必须独立建事实”，而不能同时宣称已验证了行业机制、管理层能力和现金质量。

### 单轮迭代卡

| 字段 | 含义 |
|---|---|
| 方法假设 | 要测试的研究步骤及预期改进。 |
| 实验对象 | 公司、状态时期、机制问题及材料边界。 |
| 对照/反例 | 若不用该方法，或使用最强替代解释，会发生什么错误。 |
| 结果 | 新步骤是否产生更正确的事实边界、不同机制或可观察顺序。 |
| 方法更新 | 保留、修改、放弃什么；不得只增加备注。 |
| 迁移任务 | 用哪个不同对象复验，或明确为何尚不能复验。 |

### 停止与换样本规则

在以下任一情形出现时，停止继续深挖当前公司问题并切换样本：

- 新材料只让格力故事更完整，却不改变任何方法对象、竞争机制、测量边界或后续观察；
- 缺的资料已经明确，继续阅读同类公开材料不会改变 `UNKNOWN`；
- 同一方法已在当前公司得到一次正面发现，需要先在不同情境寻找断裂条件；
- 研究问题不再可能改变公司经营判断、现金质量、资本配置或永久损失边界。

这不是放弃格力，而是防止“公司资料越多 = 方法越好”的错觉。格力研究可在新问题或新数据出现时恢复，但不能占据整个方法计划。

### 第一组迭代实验

| 轮次 | 方法假设 | 当前实验台 | 现有结果 | 下一步迁移复验 |
|---|---|---|---|---|
| I-01：会计边界 | 将会计变化先区分为列报、确认/计量和混合未知，避免把不可比数字写成经营/渠道变化。 | 美的 FY2023–24 质保费列报边界；中国平安 FY2023 新保险合同准则切换。 | 美的验证了量化列报迁移；平安证明确认时点、计量基础和覆盖范围也会改变，规则已从 `RETAIN_NARROW` 升级为 `MODIFY` 的三分类门。 | 仅在出现会改变三分类准入动作的异类会计断点时再复验；否则转入前瞻机制学习。 |
| I-02：行动与判断分离 | 将“行动是否完成”与“经济判断是否正确”分成两条链，能避免用结果倒灌管理能力。 | 美的 2016 KUKA 要约。 | 交割和控制权可被行动链结算；截止日前没有指标、归属边界和窗口，经济路径为 `NO_ELIGIBLE_ECONOMIC_FJ`。方法暂定 `RETAIN_WITH_FAIL_FAST_GATE`。 | 选一宗在行动前已定义主/反机制、指标、基准、归属和观察窗口的不同产业事件，检验两条链是否可同时成立。 |
| I-03：噪声行业资料 | 将来源作为有边界的传感器而不平均，能产生更好的取证顺序。 | 格力的奥维/产业在线转引与公司会计资料。 | 已形成分歧地图，但还没有原始持牌 release，结论为 `INSUFFICIENT_TEST`，不能宣称方法已提高预测。 | 选择一个有原始、版本化行业面板的公司/行业，比较“先分交易点”是否真能区分竞争机制。 |
| I-04：结构化类比 | 每个支持类比都配近失效案例，且先分开抽取 target/source 因果骨架再写理由，能暴露表面相似的误导。 | 暂不以格力继续深挖。 | `BLOCKED_ON_QUALIFIED_EPISODE`：现有书籍案例卡只提供研究语法，缺少当时预测与独立结算，不能被误作近失效经验；P-51 已把“先理由”可能削弱结构辨别的风险写入两阶段卡。 | 先完成一个 source/target context 可隔离的前瞻冻结或泄漏控制的合格学习情节；再以该情节及其结构性反例检验迁移、断裂与 `STRUCTURE_FIRST` 的实际增量。 |
| I-05：实时跨行业前瞻复验 | 同口径的早期经营信号只有跨行业仍可结算，才可能训练迁移而非公司故事。 | Starbucks 北美交易量（R-05）与 Walmart U.S. 交易量（R-06）分别实时冻结。 | 两者均为 `LIVE_FORWARD / EARLY_PENDING`；共同使用两次独立季度的 `>0% / <=0%` 交易量分歧，但不互相共享公司结论。 | 等结果期逐条结算；比较信号是否保留、失去诊断性或需要按行业重写。 |
| I-06：外部历史判断档案 intake | 将书籍/名家案例拆成“当时原始判断—独立结果—结构断裂”链，能把问题路由与可检查经验分开。 | Berkshire/Coca-Cola 控制与 Trian/杜邦 2015 的结果隔离短窗试转。 | `RETAIN_WITH_METRIC_RECONSTRUCTION_GATE`：前者因只有行动/持有意图拒绝；后者具同期机制、反方与条件谓词，却在结果读取后发现原 `29%` 盈利桥无法以连续官方口径重建。农业弱势和成本节约都不能替代完整桥的结算。 | 未来原始档案在 outcome 前先冻结指标→官方映射、调整与连续性；缺失时关闭为 `MEASUREMENT_MISMATCH`，只迁移该断裂条件。 |
| I-08：竞争回应过程 | 把行业竞争从份额/公司动作描述，推进为“行动—对手 awareness/motivation/capability—有针对性回应—租金落点”的可结算链。 | 只建立方法协议，未选公司。 | `DESIGN_READY_NOT_LIVE_TESTED`：现有 pair、因果箭头与早期/终局 FJ 足以承载，不另建账本；对手行动是否发生和经济机制是否成立必须分开结算。 | 在不同公司、同一明确 arena 中冻结一对对手回应预测；只有预定义回应来源、范围、类别和时滞均可结算，才进入前瞻/历史 PIT 实验。 |
| I-07：主路径选择与信号预测分轨 | 一项可结算信号若没有选择依据和不同基线，不能被记为研究者“当时选对了机制”。 | R-05 的拟升级控制：Q3 交易改善仍为共同事实，H-A 与简单延续基线均预测下一期交易量为正。 | `RETAIN_WITH_SELECTION_GATE`：拒绝将 R-05 从 `NO_PRIMARY` 提升为选择 episode；冻结模板现在逐条记录选择证据、来源谱系、方向性与基线预测差异。 | 只在存在方向性选择依据、完整反方和不同基线预测的新对象启动 selection episode；单案到期仅结算案例，多个独立样本前不计算选择准确率。 |

I-01 至 I-03 只是方法实验的起点，不是对格力的最终结论，也不是“已经完成三次迭代”的宣称。真正完成一轮，至少还要有迁移复验或一个清楚的反例结果。

## 8. 格力在其中的角色

格力是当前的**方法压力测试**：它同时有渠道数据不完整、第三方数据有噪声、会计口径断点、现金质量问题、资本配置事件和管理层方向性表述，足以检验上述纪律会不会在现实中失效。

它不是这套方法的目的，也不应为了尽快产出一份格力报告而缩短任何研究步骤。格力实验结束后，保留的是可迁移的方法对象、反例和学习记录；格力本身的结论只属于格力。

## 9. 当前下一步

不再继续扩大格力材料范围。R-05 与 R-06 已经在结果未知时冻结，当前等待其经营信号；等待期间只做不会偷换为结论的研究准备：I-06 将已有案例卡筛成可审计的外部历史判断候选，或诚实保留 `QUESTION_ONLY`；I-07 只筛选在 cutoff 前已有方向性选择依据且可与简单基线产生不同预测的对象。每项冻结依据均须先经 PIT runner 的显式读取审计。格力只保留为对照样本，除非新数据能直接改变其现有机制分歧。这样每一步都在训练方法，而不是无止境完善一家公司。
