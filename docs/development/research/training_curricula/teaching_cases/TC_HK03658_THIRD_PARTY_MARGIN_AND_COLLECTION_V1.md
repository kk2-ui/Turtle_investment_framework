## 2. 一句话结论

新希望服务最重要的课程不是“第三方占比已经达到84%”，而是：**真正独立第三方物业收入由 FY2021 的0.42亿元增至 FY2025 的3.76亿元，证明外拓能力真实；同期物业管理收入和绝对毛利显著增长，但物业毛利率由30.1%降至24.3%，贸易应收和减值拨备持续上升，说明规模吸收、单位经济和现金质量并未同步。关联生态是现实分销优势，却不能用“第三方”重命名后消除依赖。**

## 4. 当前最重要的三项企业判断

### 判断一：独立第三方外拓真实，但“第三方全口径”高估了经济独立性

**明确判断：`REAL_INDEPENDENT_ACQUISITION / RELATED_ECOSYSTEM_STILL_MATERIAL`。** 真正独立第三方物业收入从 FY2021 的0.42亿元升至 FY2025 的3.76亿元，在管面积由465万平方米升至1,650万平方米，证明公司能够离开控股股东项目获取客户。FY2025 真正独立第三方仅占物业管理收入39.6%；新希望五新、其联营合营项目和实控人联系方合计仍占60.4%。年报所称84%的“第三方全口径收入”使用了更宽的定义，不代表完全独立客户。

**机制链：** 品牌与投标能力 -> 独立签约 -> 项目进场和续约 -> 收费面积 × 单价 -> 项目毛利 -> 收缴与现金。

**最强反方：** 新希望五新的联营合营公司并非上市公司控股开发商，项目也可能经过市场化竞争；集团供应链能降低获客成本并形成长期分销优势。因此关联来源不是低质量的同义词。正确处理是分别定价获客稳定性、项目利润和回款，不把所有生态项目自动剔除，也不把它们改名成完全独立。

### 判断二：规模和绝对毛利吸收成立，单位经济持续稀释

**明确判断：`SCALE_AND_GROSS_PROFIT_ABSORPTION / UNIT_ECONOMICS_DILUTED`。** 五年物业收入接近三倍、绝对毛利超过两倍，证明项目部署不是空转；物业毛利率从30.1%降至24.3%，集团毛利率从40.7%降至29.7%，说明住宅、车位和外拓项目的低毛利结构持续稀释组合。FY2024 归属利润增长主要还受行政费用下降支持，不能把利润增长全部归因于项目经济改善。

**机制链：** 在管面积和项目密度 -> 收入 -> 现场人员、外包、能源和维护成本 -> 项目毛利 -> 区域管理复用 -> 经常利润。

**最强反方：** 物业服务是低资本、长合同业务；只要绝对毛利、续约和现金增长，较低毛利率仍可创造价值。该反方成立，所以不因毛利率下降否定增长；但正常盈利必须使用新增项目的边际毛利和回款，而不是沿用早期高毛利率。

### 判断三：现金创造为正，回款质量却没有随规模同步改善

**明确判断：`POSITIVE_GROUP_CASH / COLLECTION_AND_CREDIT_QUALITY_WEAKENED`。** 五年 post-PPE 代理每年为正、期末无计息借款，证明公司不是靠外部债务维持增长。贸易应收净额由1.89亿元升至5.04亿元，拨备由0.05亿元升至0.51亿元；FY2024 应收增加约1.44亿元、OCF降至1.62亿元。FY2025 OCF回升，但应收和拨备继续增加。收入增长没有形成同强度的回款改善。

**机制链：** 物业费与项目结算 -> 应收账龄和收缴率 -> 信贷损失 -> 经营现金 -> 必要系统/设备投入 -> 可分配现金。

**最强反方：** 新项目进场和收入增长会机械增加应收，FY2023、FY2025 OCF改善且公司净现金，不能据余额增长认定坏账。正确处理是给已实现现金信用，同时用应收收入比、账龄、客户来源和拨备趋势限制正常化，不把缺少项目级现金写成整案 UNKNOWN。

## 5. 生活服务与商业服务的边界

FY2025 生活服务收入3.80亿元、毛利率35.0%，公司通过供应链优化和主动退出低毛利项目使毛利率提高1.9个百分点，说明关联食品供应链可以成为现实经营优势。与此同时，商业运营收入同比下降25.9%，非业主增值收入下降26.5%，反映房地产和商业项目周期仍在传导。

因此：生活服务的利润改善可获得局部经营信用；来自新希望集团的供应链、客户和采购必须与独立客户贡献分列；商业合同额或新项目在收入、毛利和收款出现前只算订单，不算经济吸收。

## 6. 管理层、Owner cash 与永久损失

**管理层评价：`MEDIUM_HIGH_MARKET_ACQUISITION / CONDITIONAL_UNIT_ECONOMICS_AND_COLLECTION`。** 独立第三方项目和收入增长证明市场获取与交付能力；主动退出低毛利生活服务项目也体现纪律。单位毛利下降、应收和拨备上升，使项目选择和回款能力只能给条件性信用。

**Owner cash：`POSITIVE_CROSS_CYCLE_GROUP_PROXY / NORMALIZATION_CONDITIONAL`。** 五年集团投入后现金约10.37亿元是实质正向，不因项目现金未拆而撤回；应收和租赁/项目营运资金、股息及母公司可分配性限制可持续区间。

**永久损失：`LOW_TO_MEDIUM_CONDITIONAL`。** 净现金、轻资产和分散项目降低融资损失；地产客户信用、关联生态依赖、项目低毛利、应收损失和错误收并购是主要载体。现金缓冲不能覆盖项目选择和客户信用轴。

## 7. 三种经营情景

- **乐观：** 独立第三方收入和项目密度继续增长，物业毛利率稳定，收缴和应收周转改善；生活服务保持高毛利，集团现金随利润增长。
- **基准：** 物业规模温和增长而毛利率维持约当前水平，关联生态仍占多数；应收增长与收入相近，集团现金为正但年度波动。
- **悲观：** 地产和商业客户恶化，低毛利项目扩张而收缴下降；应收拨备、项目退出和租赁负担吞噬现金，关联来源也停止输送项目。

## 8. 估值方向与翻转事实

本案不读取价格，不形成正式估值或 BuyBand。

- 成熟物业管理按可重复项目毛利和收缴后的现金，不按在管面积或合同额资本化。
- 真正独立第三方与关联生态项目分来源观察，但价值最终由续约、毛利和回款决定。
- 生活服务只按已发生的收入、毛利和现金；集团供应链协同不单独给平台价值。
- 净现金降低财务风险；应收和拨备趋势进入正常盈利与永久损失折价。

**向上翻转：** 真正独立第三方收入占比和绝对毛利共同上升；物业毛利率稳定；应收增速低于收入、拨备率和账龄改善；OCF随经常利润增长。

**向下翻转：** 外拓面积增长但收入、毛利或收缴下降；关联生态项目收缩且独立项目不能替代；应收和拨备持续快于收入；集团现金依赖一次性营运资本释放。

## 9. 局部 UNKNOWN，不撤回判断

- 单项目续约率、物业费单价、收缴率和项目利润：限制外拓单位经济精度，不取消独立第三方收入与物业毛利趋势。
- 关联生态项目是否经过完全市场化招标：限制独立性评价，不自动把收入剔除或视为完全独立。
- 项目级现金与母公司分配：限制 normalized owner cash，不取消五年集团 post-PPE 现金为正。
- 应收客户逐项风险：限制损失幅度，不取消应收和拨备上升带来的方向性约束。

## 10. 可迁移课程与近失误

**可迁移机制：** `CUSTOMER_ORIGIN -> CONTRACT -> PROJECT_ENTRY -> REVENUE -> PROJECT_MARGIN -> COLLECTION_AND_CREDIT_LOSS -> POST_INVESTMENT_CASH`。

**近失误：**

1. 把联营合营或实控人生态项目全部重命名为独立第三方；
2. 用在管面积、签约额或收入增长证明单位经济改善；
3. 因毛利率下降否定绝对毛利和现金增长；
4. 用净现金吞掉应收和拨备恶化，或因项目级收缴缺失撤回全部经营判断。

**下一家公司应问：** 新客户究竟来自何种责任边界，项目进入后贡献多少边际毛利，账款是否收回，现金是否在新增项目仍需投入后留存？
