# Kraft Heinz 品牌整合与减值教学案例｜独立审阅

## Verdict: ACCEPT

这份草案可作为 `RESULT_KNOWN_TEACHING / OUTCOME_EXPOSED / TEACHING_ONLY`
案例入库。审阅只回读了草案列出的三份 SEC 原件：2015-03-25 Rule 425、FY2015
Form 10-K（2016-03-03 filed）和最终重述 FY2018 Form 10-K（2019-06-07 filed）。
未使用新闻稿、卖方材料、后见之明价格资料或未列来源来补强事实；本裁决不形成
Blind、Holdout、transfer、估值、CJO、证券建议或投资权限。

## 材料性事实、边界与经济判断

- **管理意图、实施与节约被正确拆开。** Rule 425 支持约 `$1.5bn` 年度 run-rate
  cost savings 的意图、零基预算、制造足迹/分销网络整合、国际 go-to-market 的收入协同
  设想、约为 synergies `1.25` 倍的预期 cash cost，以及交易后至少两年不回购的资本选择。
  FY2015 10-K 则支持已经发生的交割、组织缩减、七座工厂关闭、分销整合、`$1.9bn`
  Integration Program、约 `$125m` 首年税前节约和相关资本开支。草案没有把前一类
  管理层承诺误写成后来结果，也没有将工厂/组织实施或部分节约升级为成熟品牌经济成功。
- **客户、品牌和渠道的判断既有观察基础，也没有伪造单因果。** 最终重述 FY2018
  10-K 明确披露竞争、private-label 竞争、消费者/品牌与分销约束，以及在第四季度结果与
  2019 plan 中出现的较高供应链成本、竞争、较低增长与利润率预期。草案正确把美国
  segment 销售、Adjusted EBITDA 与集团 Adjusted EBITDA 作为合并边界的经营信号；没有
  把它们写成品牌级复购、货架、私牌份额、某客户议价或某次裁员所造成的已证结果。
  私牌、消费者偏好、成本冲击、汇率/利率、资产出售及宏观/监管不确定性被保留为可叠加的
  竞争解释，故不把有限资料压成“削成本导致品牌衰退”的虚假因果。
- **现金、资本开支与减值没有混算。** FY2015 合并 CFO `$2.467bn`、取得业务净现金
  `$9.468bn` 与 capex `$0.648bn`，以及 FY2018 CFO `$2.574bn`、capex `$0.826bn`，在
  草案中均各自维持相应的合并/年度边界。FY2018 现金流量表将 goodwill 与 intangible
  impairment 加回，同时列出应收、存货及其他流动负债的变动；草案据此没有把 CFO 当成
  正常 owner cash，也没有把取得现金、Integration Program 费用、capex、融资和股利
  拼成一个伪精确的交易损失。
- **未来现金流重置与当期现金流出被正确区分。** 最终重述 FY2018 10-K 的最终金额为
  goodwill impairment `$7.008bn` 和 intangible-asset impairment `$8.928bn`，合计
  `$15.936bn`；其测试采用未来净现金流、税、折现率、增长率、royalty rate 与
  contributory-asset-charge 等假设。草案正确将其读作在当时经营和市场假设下，取得的
  goodwill/品牌资产的未来现金流可回收性被材料性下调，而非同额 FY2018 现金流出、
  全部品牌归零、或 2015 合并的精确现金损失。受损 reporting units/brands 还与 2013 Heinz
  acquisition 及 2015 merger 相关，草案据此没有计算 merger IRR 或给减值作单笔交易归因。
- **真实 no-action 的处理合格。** 不合并、保持两家公司各自的品牌、制造、销售与分销
  组织，是宣布时真实存在却未被三份允许文件结算的经营 alternative；交易后暂不回购、优先
  去杠杆也是真实资本选择。草案用这些事实限制“独立路线必然更好/更坏”及资本配置相对回报
  的断言，但没有让反事实未知否定合并后真实发生的实施、合并现金和资产可回收性重置。

## 投资者可用性与反防御性裁决

草案完成了应有的企业判断：成本整合取得实施信用，不能因此取得品牌—客户—渠道经济或
资本回收成功的信用；到 FY2018，原取得资产的未来现金流承载假设已经需要重新承保。它同时
给出最强反方——成本行动可能部分抵消了原本更差的压力，且减值受市场、宏观和测量假设影响——
但该反方只限制归因与精确经济损失，并不消除已观察的资本可回收性信号。

因此，`UNKNOWN` 被正确局部化为 merger counterfactual、品牌/渠道单位经济、整合费用的
精确现金额、减值对 2015 merger 的精确归属、最终交易 IRR 与正常 owner cash。它们没有被
用作“不能判断”的出口。草案也没有把更多披露清单、更多 caveat 或不授予权限误当作成果；
其可迁移问题直接服务于下一家成熟品牌/渠道公司的经营和资本判断。

未发现会材料性改变中央机制、永久损失处理或方向性投资处理的
`DATA_COVERAGE`、`ACQUISITION_MODULE`、`REASONING`、`MODEL` 或 `WRITING` 缺陷。
**ACCEPT。**
