## 2. 一句话结论

古井的历史不是“高端化和全国化已经失败”，而是：**FY2022–FY2024 年份原浆的收入、销量、毛利率与区域扩张曾经共同改善，证明品牌、渠道和执行是真实的；FY2025 收入、销量、跨区域经营和现金同时反转，而存货继续上升，说明此前增长没有形成不可逆的全国化能力。品牌信用可以保留，峰值收入、渠道库存和智能园区投入不能直接资本化为永久定价权。**

## 4. 当前最重要的三项企业判断

### 判断一：年份原浆有真实品牌和价格结构，但不是不受周期影响的永久定价权

**明确判断：`STRONG_BRAND_ECONOMICS / CYCLE_RESILIENCE_BROKEN`。** FY2022–FY2024 收入、销量和毛利率共同上升，说明年份原浆的产品升级不只是提价或渠道压货；FY2025 三项同时下降，证明品牌仍受需求、渠道库存与竞争约束。正确结论是强品牌经济，不是无条件永续增长。

**机制链：** 消费场景和品牌心智 -> 终端动销与复购 -> 经销商补库 -> 销量 × 实现价格/结构 -> 毛利 -> 销售投入 -> 经常利润和现金。

**最强反方：** FY2025 是白酒全行业深度调整，主动控货、降库存和稳价可能牺牲当期收入以保护长期品牌；年份原浆毛利率仍接近85%。该反方支持保留品牌信用，却不能把收入、现金和经销商收缩写成无关噪音。

### 判断二：全国化曾经产生区域收入，却未证明跨周期渠道质量

**明确判断：`REGIONAL_ABSORPTION_PREVIOUSLY_REAL / REPEATABILITY_UNPROVEN`。** FY2022–FY2024 华北、华中、华南收入均增长，华北和华南毛利率较高，说明省外不是只有招商或门店数量。FY2025 华北收入近乎腰斩、三大区同时收缩，显示经销商覆盖、终端动销和渠道库存尚未形成可持续全国化优势。

**机制链：** 经销商开拓和品牌投入 -> 有效终端覆盖 -> 终端动销与补货 -> 区域收入和毛利 -> 应收、合同负债、库存与现金。

**最强反方：** 全国化初期波动大，管理层主动淘汰弱经销商和降低渠道库存可能改善长期收入质量。这个反方要求研究终端动销、渠道库存和价格秩序，而不是仅因经销商减少就下结论；但在缺少这些证据时，也不能继续按 FY2024 峰值外推。

### 判断三：现金和净现金缓冲很强，但库存与园区投入提高了资本纪律要求

**明确判断：`CROSS_CYCLE_CASH_POSITIVE / CAPITAL_ABSORPTION_WEAKENED`。** FY2022–FY2025 每年 group post-capex 代理为正，FY2025 末货币资金约141.9亿元、短期与长期借款合计不足4.5亿元，近端流动性风险低。与此同时，存货由60.6亿元升至107.4亿元，FY2025 现金代理只剩约2.8亿元。强资产负债表不能抹去资本吸收恶化。

**机制链：** 销售回款与预收 -> 生产和基酒储备 -> 库存成熟/周转 -> 智能园区与产能投入 -> 税费和分红 -> 可持续普通股现金。

**最强反方：** 白酒基酒库存具备陈化价值，FY2025 生产量下降16.01%、报表库存量下降34.50%，账面存货上升未必等于滞销成品。正确处理不是把全部库存视为损失，而是要求基酒、半成品、成品、周转和减值与未来销量匹配。

## 5. 管理层、Owner cash 与永久损失

**管理层评价：`MEDIUM_HIGH_BRAND_AND_SCALE_EXECUTION / CONDITIONAL_CYCLE_AND_CAPITAL_DISCIPLINE`。** FY2022–FY2024 产品、区域、利润和现金共同增长，管理层获得真实执行信用；FY2025 反转表明稳价、控货、库存和产能调整尚未证明能保护单位经济。广告费在收入下降时仍增长至约13.5亿元，也要求区分长期品牌投资与低效率流量支出。

**Owner cash：`POSITIVE_CROSS_CYCLE_GROUP_CASH / PEAK_NOT_NORMALIZED`。** 四年投入后现金合计为正且净现金强，不应因维护 capex 未拆而写成 UNKNOWN；但 FY2025 现金显著收缩，正常化不能使用 FY2024 峰值，仍需扣股息和必要库存/园区投入。

**永久损失：`LOW_TO_MEDIUM_CONDITIONAL`。** 净现金、强品牌、高毛利和已有经营现金降低融资损失；真正的损失载体是行业需求下行时继续扩产、库存经济价值低于账面、全国化渠道反复补贴、黄鹤楼等资产回报下降，以及食品质量或品牌事件。净现金只能覆盖财务轴，不能覆盖品牌和资本回报轴。

## 6. 三种经营情景

- **乐观：** 主动控货修复渠道库存和价盘，年份原浆销量、毛利和区域补货恢复；园区产能提高效率，现金重新覆盖投入和分红。
- **基准：** 安徽和华中核心保持高毛利，全国化增速下降；收入低于 FY2024 峰值，库存缓慢消化，集团现金为正但正常盈利中枢下移。
- **悲观：** 终端需求持续弱，渠道去库存和价格倒挂扩散；高销售投入不能恢复动销，库存和产能占用现金，年份原浆及省外毛利继续下降。

## 7. 估值方向与翻转事实

本案不读取价格，不形成正式估值或 BuyBand。

- 年份原浆按跨期销量、实现收入、毛利和销售费用后的经常利润判断，不按单一高毛利率。
- 全国化只对已经形成重复收入、毛利和回款的区域给予价值；经销商数和招商本身不产生溢价。
- 现金与净现金进入安全边际，但正常盈利使用 FY2025 后的周期区间，不使用 FY2024 峰值。
- 智能园区和新增产能只有在单位经常利润、库存吸收和投入后现金改善时获得资本回报信用。

**向上翻转：** 年份原浆在至少两期实现销量、收入、毛利和现金共同恢复；华北/华南的终端动销、价盘和经销商补货改善；库存增速低于销售且无需折价处理。

**向下翻转：** 年份原浆收入和毛利继续下降；广告与渠道投入强度上升而区域收入不恢复；成品或半成品库存减值、价格倒挂扩大；园区投入持续高于增量利润与现金。

## 8. 局部 UNKNOWN，不撤回判断

- 终端动销、经销商库存与真实成交价：限制全国化和价盘因果，不取消区域收入、毛利和经销商收缩方向。
- 基酒、半成品和成品库存分拆及经济价值：限制永久损失幅度，不取消总存货和现金占用上升。
- 维护与增长 capex：限制 normalized owner cash，不取消四年 group post-capex 为正及 FY2025 显著弱化。
- 黄鹤楼及其他业务的完整投入回报：限制资本配置信用，不取消年份原浆核心判断。

## 9. 可迁移课程与近失误

**可迁移机制：** `BRAND_AND_CHANNEL_ACTION -> END_DEMAND -> DEALER_REPLENISHMENT -> VOLUME_AND_PRICE_MIX -> MARGIN_AFTER_SELLING -> INVENTORY_AND_POST_CAPEX_CASH`。

**近失误：**

1. 用高毛利率或品牌排名证明销量和现金不会下滑；
2. 用经销商数量和区域收入增长证明全国化已经不可逆；
3. 把库存全部当风险，或把基酒陈化叙事当成库存全部安全；
4. 用净现金掩盖核心盈利、渠道和新增资本回报的恶化；
5. 因终端动销未披露而拒绝承认 FY2025 的多轴反转。

**下一家公司应问：** 品牌投入究竟守住了终端需求、价格、毛利还是只守住了渠道发货？库存与产能最终能否被重复销量和投入后现金吸收？
