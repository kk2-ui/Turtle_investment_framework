# Teaching Block 003：规模、同边界利润与普通股现金

## 结果

本 block 按冻结顺序完成三个结果已知、商业模式异质的 Teaching，并首次把中国外运 Blind 的真实反馈用于下一批课程：在授予管理层执行信用前，先建立同一责任边界的 `volume/revenue → recurring profit or unit economics` 桥；桥不完整时可以确认规模，但不能把规模直接写成经济改善。

## 中国外运反馈具体改变了什么

中国外运 FY2024 的真实结果是：11 个业务量轴中 10 个不下降，三分部利润却下降约 12%。这没有产生一条已验证方法，也没有改变六轴投资处理类别；它产生的是更窄的研究顺序改变：业务量或收入增长必须先穿过匹配利润或单位经济，之后才授予执行信用。

Block 003 没把这条顺序写成口号，而是分别应用到三个不同经济载体：

1. 中国食品把销量、单箱收入、毛利、费用和其他收益逐层连接。FY2024 量减、收入和毛利改善是真实价格包装执行；经营利润桥仅增长约 0.9%，所以不升级成全面利润兑现。FY2025 销量恢复、毛利率回落，又限制了永久定价权外推。
2. 鄂尔多斯不以主要产品产量替代经济结果。FY2025 电冶收入下降约 11.6%、成本下降约 16.0%、板块毛利回升约 5.4 亿元，足以确认有限低谷修复；多晶硅、化肥和减值仍保留独立负面处理。
3. 招商积余先剔除 2019 年重组并表，再看 2021–2025 年合同、在管面积、物业收入和绝对毛利。规模与利润吸收已经成立；物业毛利率从11.43%降至10.01%，集团现金又不能证明物业 cohort 回款，所以单位经济、回款执行和新增资本回报仍为条件性。

这只是反馈影响研究行为的证据，不是方法优于公平 baseline 的证据。三个案例的结果本来就已知，不能反过来给中国外运规则计算成功率。

## 三项跨案机制课

### 1. 规模、利润和管理层信用是三个状态

销量、产量、合同额、在管面积和收入只证明不同形式的规模。执行信用至少要看到相同责任边界的毛利、经营利润或单位经济；资本配置信用还要再穿过投入后现金。允许规模增长和单位经济走弱同时成立，不能把混合现实压成“增长成功”或“增长失败”。

### 2. 集团现金必须经过资本与归属桥

中国食品的合并现金先扣经常性资产购置，再按65%/35%经济权利和具体法人上游分配；NCI 已宣派股利只解释时点，不能替代留存现金归属，五厂非现金购买对价另在资本配置轴处理。鄂尔多斯需要扣受限资金、电冶少数股东、合规资本和亏损项目追加投入。招商积余只确认集团现金强，物业回款要等分部 OCF、营运资金和 cohort 闭合。已知正现金不写成 UNKNOWN，但也不自动成为业务线回款或 normalized parent owner cash。

### 3. 永久损失来自经济载体，不来自行业标签

低杠杆不消除低回报资本，周期下行也不自动等于永久损失。中国食品的风险在品类毛利、特许关系和母公司访问；鄂尔多斯已有固定资产、在建工程和多晶硅损失，同时存在能源与排放经营权；招商积余的衡阳中航已经确认损失，退出只降低未来尾部风险。每条载体单独更新，不让融资改善覆盖资产损失，也不让局部减值否定仍在创造现金的核心业务。

## 防御性写作验收

三个案例都存在材料未知：中国食品缺品类利润和完整上游现金，鄂尔多斯缺外销量、单位现金成本和设施级许可期限，招商积余缺合同 cohort、来源别利润及并购 ROIC。这些未知没有成为退出理由：

- 中国食品仍被判断为核心装瓶与渠道有条件性执行力，集团现金强但 parent owner cash 未闭合；
- 鄂尔多斯仍被判断为羊绒品牌有韧性、电冶有限修复、已减值项目破坏资本；
- 招商积余仍被判断为规模已转成物业收入和绝对毛利、物业回款尚未证明、单位经济没有提高、遗留地产发生真实损失。

同时，三个案例没有用“敢判断”换取虚假确定性：没有用提价、产量或合同额直接证明资本回报，没有把合并现金直接归给普通股，也没有把局部减值和未知外推成整家公司失败。

## 尚未证明

本 block 全部为 `RESULT_KNOWN` Teaching，只增加结构表示、反例和研究顺序练习。中国外运反馈在三类企业上可被执行，说明课程能够传播一个研究动作；它仍未证明 Agent 在未见结果时会正确识别这些桥，更未证明估值或投资回报改善。下一步必须回到冻结 roster 的下一历史 Blind；只有结果隔离的处理反馈，以及“公平 Baseline 对比显式接收冻结 Method Pack 的 Enhanced”的独立 Historical Holdout，才能提供训练增量证据。
