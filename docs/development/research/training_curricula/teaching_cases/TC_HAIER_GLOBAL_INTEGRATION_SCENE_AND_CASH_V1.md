## 2. 一句话结论

海尔的历史既不是“收购全球品牌天然创造协同”，也不是“并购形成商誉所以价值可疑”，而是：**多年收购形成的海外平台已经连续产生收入、份额、经营效率和集团现金，管理层获得较高但仍有条件的整合信用；三翼鸟的门店零售和成套占比证明渠道与客户吸收，却尚未证明独立平台利润；新的 CCR、Kwikot 收购只有在同边界收入、经常利润和投入后现金出现后，才能获得资本配置信用。**

## 4. 当前最重要的三项企业判断

### 判断一：海外平台已是现实经营引擎，整合信用高于“并表增长”，但收购回报仍不完整

**明确判断：`REAL_GLOBAL_OPERATING_PLATFORM / ACQUISITION_RETURN_CONDITIONAL`。** FY2022–FY2024 海外收入由 1,254.2 亿元升至 1,438.1 亿元；公司在多个区域持续披露份额、产品结构、本地研发和供应链利用改善，集团利润与现金同步上升。这已经超过“买来收入”的最低门槛，支持管理层把 GEA、Fisher & Paykel、Candy 等品牌纳入全球运营体系的信用。

**机制链：** 本地品牌与渠道 -> 产品研发和供应链协同 -> 零售份额、价格结构与产能利用 -> 地区收入和毛利 -> 费用后经常利润 -> 本地再投资与可归属现金。

**最强反方：** 原材料、汇率、加息、区域需求和行业竞争可以独立改变海外毛利；年报没有给出各次收购的累计投入、恒定范围利润和现金回报。因而不能把集团改善全归因于整合，更不能把历史整合成功自动外推给 CCR、Kwikot。

### 判断二：三翼鸟证明了场景渠道吸收，但尚不是独立可资本化的平台

**明确判断：`CUSTOMER_AND_CHANNEL_ABSORPTION_POSITIVE / PLATFORM_ECONOMICS_UNPROVEN`。** FY2023 三翼鸟门店零售额同比增长 84%、成套占比超过 60%、新增近 1,500 个触点；FY2024 成套销售占比为 57%。这支持场景设计、成套销售和交付能力确实改变了客户购买方式，而不是只有概念或 App 上线。

**机制链：** 设计工具与场景触点 -> 获客和方案转化 -> 成套件数、客单价和高端结构 -> 家电毛利和交付成本 -> 复购、服务收入与现金。

**最强反方：** 门店零售额、触点数和成套占比可能只是既有家电收入的渠道重分类；没有三翼鸟独立客户留存、服务收入、增量毛利和资本占用，就不能把它当成第二利润平台。正确处理是给核心家电渠道能力信用，不给平台独立成长价值。

### 判断三：强集团现金支持再投资，但不能替每笔并购的资本回报投票

**明确判断：`STRONG_GROUP_CASH / CAPITAL_ALLOCATION_REQUIRES_ASSET_LEVEL_RETURN`。** FY2022–FY2024 集团 post-capex 代理逐年为正且合计约 437.8 亿元，FY2025 OCF 仍约 260.0 亿元。公司有能力承担制造、数字化和收购投入，近端永久损失不来自现金枯竭。

**机制链：** 成熟品牌经营现金 -> 维护与增长 capex -> 收购现金和整合投入 -> 被收购业务经常利润及现金 -> 可分配集团现金与商誉安全边际。

**最强反方：** 强核心现金可以长期覆盖低回报并购，使合并现金看起来健康而普通股回报被稀释。FY2024 新收购接近年末并表，FY2024 集团利润几乎不能检验其回报；商誉测试依赖长期收入和利润率假设。故强现金只降低融资风险，不自动提高资本配置评价。

## 5. 管理层、Owner cash 与永久损失

**管理层评价：`HIGH_CONDITIONAL_OPERATING_INTEGRATION / CONDITIONAL_INCREMENTAL_ALLOCATION`。** 历史海外平台、多品牌定位、供应链和现金结果支持较高经营整合信用；三翼鸟获得渠道执行信用。新增收购、场景平台独立经济与资本回报仍须结果验证。

**Owner cash：`STRONG_CROSS_CYCLE_GROUP_PROXY / PARENT_NORMALIZATION_OPEN`。** 三年 post-capex 现金稳定为正是实质结论，不因维护/增长拆分缺失而写成 UNKNOWN。未知仅限制 normalized parent owner cash：全球子公司的必要留存、NCI、收购现金、分红和母公司上划没有在本案完整桥接。

**永久损失：`LOW_TO_MEDIUM_CONDITIONAL`。** 降低风险的是多地域、多品类、成熟品牌和强现金；抬高风险的是全球需求与汇率、利率和监管、约 274 亿元商誉、重复收购以及场景平台回报未闭合。最可能的损失不是近端偿债，而是强现金长期覆盖低回报资产和渠道投入，令正常回报中枢下移。

## 6. 三种经营情景

- **乐观：** 海外份额和产品结构继续改善，CCR、Kwikot 在同边界形成经常利润与现金；三翼鸟的成套购买转成更高客单、毛利和服务复购。正常盈利与资本配置信用同时上修。
- **基准：** 全球平台收入温和增长，区域竞争使利润率分化；三翼鸟继续服务核心家电但不给独立平台价值；集团现金强，新收购回报条件性。
- **悲观：** 海外需求、汇率和利率同时压缩利润，新增收购需要持续投入或发生减值；三翼鸟触点增长没有转成增量利润，强核心现金被低回报配置持续消耗。

## 7. 估值方向与翻转事实

本案不读取价格，不形成正式估值或 BuyBand。

- 成熟中国与海外家电按跨区域经常利润和 post-capex 现金承载价值，不按单一份额、门店或奖项。
- 三翼鸟只提高核心渠道/高端结构的质量判断；没有独立经济前，不另给平台倍数。
- CCR、Kwikot 和其他收购只在责任匹配经营结果出现后进入基准盈利；商誉账面值不等于内在价值。
- 强现金降低融资性永久损失，但资本配置仍需按新增投入的边际回报定价。

**向上翻转：** 新收购在恒定范围内实现收入、经常利润和投入后现金共同增长；三翼鸟披露可重复的增量毛利、服务收入或客户留存；海外增长在竞争和汇率变化下仍保持单位经济。

**向下翻转：** 海外收入增长但毛利和费用后利润持续下滑；新收购需要追加资金、发生减值或不能覆盖资本成本；三翼鸟触点和成套占比增长而客单、毛利或现金恶化；集团 OCF 被营运资本或资产处置暂时抬高。

## 8. 局部 UNKNOWN，不撤回企业判断

- 各历史收购的累计投入和恒定范围回报：限制并购资本配置信用，不取消海外平台已经形成的判断。
- 三翼鸟独立客户、利润和现金：限制平台估值，不取消场景渠道吸收。
- 全球子公司必要留存、NCI 和母公司上划：限制 normalized parent owner cash，不取消强集团现金代理。
- 维护与增长 capex：限制现金精度，不取消 FY2022–FY2024 每年 post-capex 为正。

## 9. 可迁移课程与近失误

**可迁移机制：** `ACQUIRED_OR_BUILT_PLATFORM -> CUSTOMER_AND_CHANNEL_ABSORPTION -> SAME_BOUNDARY_MARGIN_AND_RECURRING_PROFIT -> POST_CAPEX_AND_POST_ACQUISITION_CASH -> CAPITAL_RETURN`。

**近失误：**

1. 用并表收入或市场份额直接证明收购创造价值；
2. 用门店数、成套占比或场景案例给平台独立利润倍数；
3. 用强集团 OCF 覆盖单项收购回报和商誉风险；
4. 因平台利润未披露而撤回海外经营、客户吸收和集团现金的明确方向。

**下一家公司应问：** 新平台究竟改变了客户购买、单位经济还是只改变披露口径？强核心现金扣除必要投入和收购资金后，新增资产是否形成可重复回报？
