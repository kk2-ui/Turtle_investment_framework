# China Appliance J2/J3/J4 Read Model V1

> Status: `FIVE_ISSUER_RISK_SET / J2_READ_ONLY / J3_CONTRACT_REQUIRED / J4_NOT_ADMITTED`

## Investor result

The appliance block no longer treats Gree, Midea and Haier as the whole
industry. It now freezes and reconstructs a five-issuer national risk set
across two PIT cutoffs. Hisense Kelon contributes a dual ice-washing/air-
conditioning system; Sichuan Changhong adds a white-goods system that must be
separated from its television, IT and intermediate-product exposure. Neither
is thereby promoted to a product-level causal comparator.

J2 turns the available evidence for all five systems into questions and
competing mechanism threads. J3 does **not** create a forecast: it specifies
the three contracts that a later forecast must independently freeze.  J4
states the current honest answer: no homogeneous product-boundary field set is
available, so there is no comparative panel, causal conclusion, method
transfer, CJO, valuation, report or investment authority.

## Objects and boundaries

```text
five-issuer statutory-PDF risk set
    -> five J2 mechanism-question episodes
    -> J3: separate Decision + Measurement + prefreeze-evidence contracts required
    -> J4: NOT_ADMITTED_MISSING_HOMOGENEOUS_PRODUCT_BOUNDARY
```

The compiled object is a read model only. It rejects prices, outcomes,
settlement data, forecasts, CJO and investment fields. A company cannot be
added merely by name: every issuer×cutoff needs a cutoff-before statutory-PDF
source and a listed-consolidated responsibility boundary. A deep episode also
needs its own page-bound cells and competing mechanism thread.

## Why this is a useful industry universe

The economic improvement is not a larger fake peer panel. It is a wider
starting population from which future research can ask product-specific
questions without survivorship selection. The five systems make distinct
mechanism questions concrete while preserving the product, cash and capital
boundaries that still prevent homogeneous comparison.

The next permitted work is narrow: obtain cutoff-before product, customer,
channel, cash and responsibility-boundary fields for a selected arena.  It is
not permitted to use the present five names as a causal control group or to
read later results.
