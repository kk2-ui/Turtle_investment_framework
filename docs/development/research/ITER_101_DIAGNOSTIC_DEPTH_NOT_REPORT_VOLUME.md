# ITER-101 — 深度是能区分机制的证据，不是报告数或分析模块数

日期：2026-08-21

[Collier（2011）](https://doi.org/10.1017/S1049096511001429) 将 process tracing 定义为围绕既定问题和假设，系统检验具诊断力的证据，并强调描述、因果序列和竞争假设的关系。 [Gavetti、Levinthal 与 Rivkin（2005）](https://sms.onlinelibrary.wiley.com/doi/10.1002/smj.475) 的策略类比研究也指出：经验的广度只有在研究者理解哪些结构特征真的区分“相似/不相似”时才有价值；严格照搬类比会失效。它们共同反对把更多相似材料、更多案例名称或更多分析框图当作理解深度。

对路线图的审阅发现，格力尚没有 P0 的同口径品牌×渠道 sell-out/ASP/价格带历史 release，也没有 normal owner-cash bridge；但 R1 同时列有因果分解、Shapley、行业架构、存量—流量、访谈 episode、reference class 和部分识别。它们大多已经写有触发条件，却在长清单中容易被误读为要并行完成的“深度”。这会把研究资源从唯一能改变 H-A/H-B 的证据上移走。

因此路线图新增“当前关键路径”段：先冻结当期状态和对立机制，随后只补能使 H-A/H-B 在同一口径下分叉的 P0 行业 release 与现金/资本事实，才生成 CJO bridge、3–5 条 FJ 和最强反方，先结算 6–12 月机制信号。其余模块只有能产生一个此前不存在、会改变机制或 owner-cash 判断的可结算观察时才启动。

根因是 `REASONING + WRITING`：计划的丰富性会被误当作行业理解，20 多份同一公司报告会被误当成经验广度。经济影响是可能在没有全渠道竞争分母的情况下，因线上份额、单季毛利或表观 OCF 写出确定中心路径，从而材料性误判竞争持续期、可分配现金与永久损失。禁止以报告份数、案例名、agent 数量、图表或模块完成数提高置信度；相同公司跨期报告仅可加强 PIT 状态编年，不能构成独立参考类或迁移证据。接纳条件是每项新增方法先指出其会区分的 H-A/H-B 箭头、共同 metric/unit/window 与可能改变的经营结论；做不到则明确延后为 `UNKNOWN`。

补充的生产检验是：`rival_hypothesis_pair` 的 `sequence` 不能只是排序标签。所有 `EARLY_MECHANISM` signal 必须排在 `TERMINAL_OPERATING` 之前，且其最晚 `resolution_due` 严格早于第一个终局 signal；同一终局窗口内的多个结果可以并列。否则生产冻结拒绝它。这防止研究者在终局已知后仍把早期信号写进同一机制链。根因是 `REASONING + MODEL`，经济影响是会把不具因果先后关系的终局经营结果误学成渠道、量价或现金机制的“领先验证”。
