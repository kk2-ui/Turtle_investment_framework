# 口子窖结果后情景模型纠错

> correction scope：只修正结果后情景解释，不回写结果前 freeze
>
> independent cross-case audit：`MODEL + REASONING`
>
> outcome、价格与权限：不新增 outcome；价格仍未读；权限不变

## 材料错误

结果前 03 对悲观情景的文字定义包括：

```text
安徽或高档吸收弱化 / 省外反转 / 库存与项目造成资金压力
```

但机械 classification order 只把“安徽或高档材料反转”与“资金或核心吸收压力”映射为
`PESSIMISTIC`，遗漏了“省外材料反转”。因此 FY2019 的 `BASE` 标签与 `0.2450` 粗粒度 scenario
score 来自一个不完整映射，不能用来证明情景判断命中或训练有效。

第二个错误是把强现金带来的融资型下行下降，外推成整个悲观情景从 `15%` 降至 `8%`。高档销量
停滞、半成品库存增长快于匹配高档收入，以及省外只观察一年，仍分别保留品牌、区域和不可退出
资本风险。融资风险下降不能自动取消这些永久损失路径。

## 经济影响

这两项错误会低估区域扩张反转和库存吸收失败的下行权重，可能让方向性估值上修过快。缺失的不是
更多字段，而是风险轴与情景分类之间的一致映射。

禁止假设：

- `BASE` 标签机械命中等于企业判断正确；
- 强 OCF 和零有息债务同时降低品牌、区域和库存风险；
- 一个结果后的精确概率变化本身是训练成果。

## 纠正后的当前判断

原 07--09 的企业结论仍保留：安徽成熟核心偏价格/结构驱动；省外出现早期广度改善；项目与陈化
库存当前自筹能力强但长期吸收待证；方向性价值可小幅上修。

粗粒度下一期概率改为：

```text
OPTIMISTIC   0.30
BASE         0.58
PESSIMISTIC  0.12
```

这些是当前主观判断，不是经验校准后的频率。与结果前相比，乐观增加来自省外收入、销量、毛利和
渠道广度共同改善；悲观只小幅下降，主要因为融资型下行显著降低，但品牌实物吸收、区域重复性和
库存机会成本并未同时消失。

下行风险必须分轴记录：

- `FUNDING_DOWNSIDE`：材料下降；
- `CORE_PHYSICAL_ABSORPTION_DOWNSIDE`：未下降，高档销量已略弱；
- `OUTSIDE_REPEATABILITY_DOWNSIDE`：只小幅下降，一年证据不足以取消；
- `AGED_INVENTORY_AND_FIXED_CAPITAL_DOWNSIDE`：维持中等，资金覆盖不证明资本回报。

## 对训练结论的影响

`REAL_JUDGMENT_FEEDBACK_COMPLETED` 仍成立，因为省外管理层评价、成长选择权处理、核心实体销量
置信、资金风险位置和下一家公司观察权重发生了材料变化。成立依据不是 scenario score 或精确
概率。

以下项目明确降级：

- `0.2450` 仅保留为历史机械输出，不计入方法效用；
- `15%→8%` 被本纠错替代，不计入训练成果；
- before/after confidence 若命题发生变化，不解释为同一命题的校准幅度。

## 后续验收

以后任何情景 freeze 必须做到：书面定义中的每个材料悲观分支都有唯一机械映射；某一风险轴的
改善只更新该轴，除非有责任匹配证据连接到其他风险。若机械标签与连续事实冲突，投资者读数以
连续事实和分轴判断为主，标签不得覆盖它们。

这不是新增全局 gate，而是废弃一次已观察到会误导估值方向的粗粒度 shortcut。不授予
`TRANSFER_VALIDATED`、`METHOD_FROZEN`、Comparative、CJO、正式估值、BuyBand、报告发布或
投资权限。
