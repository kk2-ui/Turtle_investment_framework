## Selection rule

The target had to satisfy, before any target-outcome search:

1. a different issuer from CN:002394;
2. the same export-oriented textile operating arena, so customer, product,
   capacity and cash mechanisms remain economically interpretable without
   claiming a causal peer comparison;
3. a pre-cutoff official annual report showing a named capacity project that
   had already crossed planning and was at or near operating implementation;
4. pre-cutoff product volume, margin, inventory and cash-capital comparables
   capable of testing economic absorption rather than construction alone; and
5. no existing target-company episode, forecast, outcome settlement, price or
   return artifact in the current non-history repository.

CN:000726 is the first directly identified issuer satisfying all five. It is a
large high-end color-woven fabric producer with international production. At
the cutoff, its Vietnam spinning phase II was already operating, garment phase
II had started production, and the 40-million-meter color-woven expansion was
in construction/equipment installation. That makes it a materially different
test from CN:002394: the question is no longer whether management can create a
first capacity milestone, but whether multiple operating and near-operating
projects are being economically absorbed.

This is a reasoned, pre-outcome target selection, not a claim that the companies
are strict causal peers. A repository search before freeze found no current
CN:000726/鲁泰 judgment, forecast, settlement, outcome, price or return artifact.
The target FY2019 announcement metadata, report body, price and return were not
searched or read before this record and the paired pre-outcome freeze.
