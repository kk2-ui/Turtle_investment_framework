# CN:002394 Feedback Learning Note — Enhanced Arm Only

This note is withheld from the Baseline arm. It contains no CN:000726 outcome.

## Source feedback

In the CN:002394 FY2019 prospective development episode, the pre-outcome
judgment correctly treated a named capacity project as a material but unproven
capital choice. Outcome settlement then observed a first physical capacity
milestone. That was enough to raise limited execution credit, but not capital-
allocation credit. The direction-only `OCF−cash-capex` proxy fell from about
RMB `459m` to RMB `203m`, so the cash amount judgment was revised down even
though the balance-sheet buffer remained adequate.

The episode also exposed a measurement defect: several trend judgments had
registered only the outcome-period level, not the same-definition baseline.
This prevented some customer/product trend claims from being cleanly settled.

## Learned rules to apply prospectively

### `LR:CN002394:ECONOMIC_ABSORPTION_AFTER_BUILD`

Once a capacity project has crossed a real construction/operating milestone,
do not keep using another construction milestone as the main success test.
Freeze customer absorption, utilization/volume, unit economics, working
capital, cash conversion and financing consequences. Construction can change
execution credit; only economic absorption can change capital-allocation
credit or justify growth treatment.

### `LR:CN002394:TREND_REQUIRES_COMPARABLE_BASE`

Whenever a judgment uses direction words such as improve, weaken, accelerate,
rebalance or absorb, pre-register both the outcome-period value and a same-
definition baseline or the annual report's explicit comparable change. A
missing comparator limits only the trend claim; it does not block the rest of
the company judgment.

## What would count as a material application

The Enhanced arm must change at least one pre-outcome treatment rather than
merely add fields. Qualifying changes include:

- re-ranking the central question from build completion to economic absorption;
- changing the threshold for management execution/capital-allocation credit;
- changing the base or downside scenario;
- changing owner-cash or permanent-loss monitoring; or
- redirecting the next research action to a more discriminating observation.

More prose, more receipts, more fields, more `UNKNOWN`, or another boundary
gate do not count.
