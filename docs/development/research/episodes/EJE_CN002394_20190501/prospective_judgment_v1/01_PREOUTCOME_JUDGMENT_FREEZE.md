# 联发股份：2019-05-01 结果前企业判断冻结

> 身份：`PROSPECTIVE_DEVELOPMENT_EPISODE / OUTCOME_UNREAD`
>
> 证据上限：FY2014--FY2018 官方年报；当前主要来源
> `CNINFO:002394:ANN:20190422:1206068393`
>
> 禁止输入：FY2019 年报及元数据、cutoff 后公告、价格、回报和后见结论

## 当前最重要的三项企业判断

### 1. 客户与区域入口较分散，但核心色织布的增长已经出现分化

联发拥有纺纱、染色、织造、印染、服装和配套能源/污水处理的一体化产业链，约 `55%` 主营产品出口到三十多个国家和地区，前五大客户只占年度销售额 `7.38%`。这支持真实的国际客户入口和较低的单一客户集中风险，但不能证明客户黏性或定价权。

2018 年纺织服装收入增长 `3.15%`、毛利率升至 `22.67%`；核心色织布收入却下降 `6.54%`、销量下降 `0.60%`，而印染布收入增长 `17.45%`、销量增长 `13.66%`。区域上国内、欧洲、美国收入分别增长 `16.39%`、`23.61%`、`16.50%`，但欧洲毛利率下降 `4.67` 个百分点，其他地区收入下降 `27.68%`。

当前最佳判断是：**联发的全产业链和区域网络正在帮助公司进行产品/地区再平衡，但尚不能证明核心色织布需求和客户经济质量在增强。** 置信度 `MEDIUM`。

经济机制是，设计前移、海外网点和全产业链可以缩短交付并把订单导向印染、成衣或更高附加值产品；只有区域收入、产品销量和毛利共同改善，才能把这种适应能力升级为客户竞争优势。

最强反方是，2018 年的地区和产品变化可能主要来自汇率、关税、低基数或订单在品类之间迁移；欧洲收入增长同时毛利下降，说明收入扩张可能以价格或成本让步换取。

### 2. 新疆家纺扩产是材料性资本选择，不是已经兑现的竞争优势

公司计划投入约 `RMB 400m` 建设新疆高档家纺坯布及配套纱线项目，目标形成每年 `28m` 米家纺坯布能力；另计划投入四千多万元进行污水资源化利用。管理层同时提出加强内销、缩短生产周期、自动化降本和全球生产布局。这是“用资源地生产、产业链延伸和内销平衡来应对成本与贸易风险”的明确选择。

项目在 cutoff 前没有客户吸收、利用率、项目毛利或现金回收证据。新增产能可能降低原料与制造成本，也可能在核心色织布需求分化时增加固定成本和库存。当前给予管理层 `CONDITIONAL / MEDIUM` 的经营适应信用，但**不把新疆项目计为已实现增长、成本优势或 owner cash。**

最强反方是，联发已有完整产业链、低客户集中和相对稳健资产负债表，资源地扩产可能是提前锁定棉花、能源和劳动力优势；若只等待订单完全可见才建设，可能错过认证和交付窗口。

### 3. 现金基础较好，但 2018 年改善含有明显采购时点成分

2018 年经营现金为 `RMB 568.3m`，同比增长 `92.16%`；现金资本开支为 `RMB 109.8m`，简单 OCF 减现金资本开支代理约 `RMB 458.6m`。应收账款降至 `RMB 397.8m`，短期借款降至 `RMB 563.9m`，长期借款接近于零。与 CN:002083 相比，这给扩产留下了更强的现金和融资缓冲。

但公司明确解释，OCF 改善主要因为 2017 年曾在预期原料上涨时增加备货，2018 年棉价平稳、采购现金减少；它不是可直接外推的正常现金创造。利润总额中另有约 `RMB 48.2m` 银行理财、委托贷款等投资收益。当前最佳判断是：**永久损失风险尚不来自迫近的杠杆压力，而来自把一次采购周期带来的现金改善误判为可持续 owner cash，并据此扩大尚未验证的产能。** 置信度 `MEDIUM_HIGH`。

## 三种经营情景

### 乐观

内销、美国和欧洲渠道继续吸收订单，色织布稳定、印染/家纺产品组合改善且区域毛利回升；新疆项目按计划完工并形成可观察运营里程碑；OCF 在不依赖去库存的情况下覆盖资本开支，应收、库存和借款保持受控。管理层信用上调，部分增长选择权可进入正常盈利和 owner-cash 评估。

### 基准

核心色织布需求大致持平或温和下滑，印染、国内和美国市场提供部分抵消；欧洲等区域仍有收入与毛利分化。项目推进但利用率和项目回报未闭环，OCF 从 2018 高位正常化，资本开支增加但资产负债表仍可承受。只承保现有客户入口、产品组合适应和现金缓冲，不支付新增产能增长溢价。

### 悲观

贸易和需求冲击令出口地区及核心产品同步走弱，毛利恶化；新疆项目形成产能和固定成本但客户吸收不足，存货、应收和借款上升，OCF 无法覆盖资本投入。此时资本配置从可承受的选择权转为永久损失来源。

## 投资研究处理

- 正常盈利：不把未验证的新疆项目收益或理财/委托贷款收益机械并入核心纺织正常盈利。
- Owner cash：认可 2018 现金缓冲的存在，但将采购周期正常化；`OCF-capex` 只作方向性代理，不是 canonical owner cash。
- 管理层信用：经营适应 `MEDIUM`，资本配置 `CONDITIONAL`；项目按期建设不能替代项目经济兑现。
- 估值方向：既有业务可获得比现金承压型同行更小的资产负债表折扣，但新增产能不获得增长溢价；若客户、毛利和现金同时恶化，应提高永久损失折扣。
- BuyBand：只允许方向性“等待安全边际”，不输出数值买价。

## 翻转条件

向上翻转要求同一 FY2019 窗口出现组合证据：

1. 核心色织布稳定，或印染/家纺等产品的销量和毛利改善足以形成更优组合；
2. 国内、美国、欧洲等主要市场不是只有收入增长而毛利恶化；
3. 新疆项目出现实际完工、投产或运营里程碑，而非重复计划；
4. OCF、资本开支、应收、存货和借款显示扩产没有吞噬现金缓冲。

若区域收入增长但毛利和现金恶化，只支持“有订单”，不支持竞争优势或管理层经济信用升级。若项目完成但销量、库存和现金没有吸收，管理层资本配置信用下调。
