# 吉比特：2019-05-01 结果前企业判断冻结

> 身份：`JUDGMENT_FIRST_EXTENSION_REPLICATION / FY2019_OUTCOME_UNREAD`
>
> 证据上限：FY2016--FY2018 发行人官方完整年报

## 企业状态与经营矛盾

截至 cutoff，吉比特是已经证明能把长寿端游 IP 转成移动端现金、并建立自主发行能力的高毛利
游戏研发运营商，但仍高度依赖少数核心内容生命周期。它不是“所有新游戏都能复刻《问道》”的
稳定消费品，也不是因研发费用化就天然轻资产。

营业收入 FY2016--FY2018 由 `RMB 1.305bn` 增至 `RMB 1.655bn`，OCF 由 `RMB 792m` 增至
`RMB 905m`。同期现金 capex 由 `RMB 156m` 增至 `RMB 486m`，主要与办公楼和园区有关。
核心矛盾是：管理层能否持续延长核心 IP、推出和运营下一批内容，同时避免把高回报数字资产的
现金过度转换成低回报、不可快速退出的固定资产。

## 当前最重要的三项企业判断

### 1. 管理层已经证明一次材料性的 IP 延寿和自主运营能力，但产品组合尚未证明可重复

《问道》端游 2006 年上线后仍保持相对稳定，管理层在 2016 年把同一 IP 迁移到手游并形成大幅
收入和现金增长。FY2017 收入继续增长 `10.31%`，FY2018 增长 `14.91%`；FY2018 自主运营收入
约 `RMB 494m`、增长 `53.91%`，年报明确主要来自《问道手游》。自主运营毛利率升至
`92.36%`。这说明客户数据、版本迭代、IP 情感和自主发行组合确有经营效果，不只是新游发布。

《不思议迷宫》等代理产品扩展了产品面，FY2018 联合运营收入约 `RMB 948m`、增长 `12.77%`；
但授权运营收入约 `RMB 210m`、下降 `23.94%`。公司没有披露各核心游戏的同口径收入、活跃、
付费率和留存，累计注册用户及 App Store 排名不能证明组合已摆脱《问道》依赖。

当前评价：**核心 IP 延寿与运营执行 `STRONG`，组合可重复性 `MEDIUM_CONDITIONAL`。** 最强
反方是手游行业增长和渠道流量同时帮助了 2016 迁移成功，后续新作生命周期可能远短于《问道》；
这个反方限制成长外推，但不能否定已经持续两年的收入、现金和自主运营改善。

### 2. 费用化 R&D 已被核心经济吸收，不能双扣；新增项目回报仍需责任匹配

R&D FY2016--FY2018 由约 `RMB 193m` 增至 `RMB 244m`、`RMB 287m`，占收入由 `14.79%`
升至 `16.94%`、`17.35%`；研发人数从 200 增至 239、297。研发全部费用化，已在利润和 OCF
中承担。因此当前高毛利和现金是在持续研发之后取得，支持核心研发体系信用。

但不能把全部研发支出资本化为资产，也不能用公司 OCF 证明每款在研或代理游戏有回报。新游戏
只有在责任匹配的留存、付费、收入、贡献利润或退出/减值出现后，才升级成长价值。管理层的
研发和产品配置评价为 **`MEDIUM_HIGH_WITH_PORTFOLIO_CONCENTRATION_LIMIT`**。

最强反方是游戏项目天然高失败率，组合管理的价值来自少数大成功覆盖多数失败；要求每款单独
盈利可能低估期权组合。这个反方允许组合层观察，却不允许把发行数量或累计注册数直接资本化。

### 3. 核心业务现金很强，办公楼和园区正在把轻资产现金转为固定资本

FY2016--FY2018 OCF 分别约 `RMB 792m`、`RMB 809m`、`RMB 905m`；现金 capex 约
`RMB 156m`、`RMB 320m`、`RMB 486m`，所以 `OCF-capex` 仍为正，但由约 `RMB 637m` 降至
`RMB 489m`、`RMB 419m`。维护和增长 capex 未拆，这不是 normalized owner earnings；趋势却
清楚表明固定资产吸收的经营现金越来越多。

FY2018 在建工程约 `RMB 474m`，其中深圳办公楼约 `RMB 291m`、厦门集美园区约 `RMB 183m`；
现金及等价物约 `RMB 508m`，办公楼相关长期借款与一年内到期部分合计约 `RMB 91m`。短期
偿债风险低，但“游戏研发需要办公空间”不足以证明买楼和园区资本回报优于租赁、分红或保留
机动性。

资本配置评价为 **`CORE_DIGITAL_HIGH / REAL_ESTATE_LIKE_DEPLOYMENT_CONDITIONAL`**。永久损失
为 **`LOW_NEAR_TERM_BALANCE_SHEET / MEDIUM_FROM_PRODUCT_LIFECYCLE_AND_FIXED_ASSET_LOCK_IN`**。

## 管理层选择与经济机制

可选路径包括：继续维护《问道》并少量押注新作；加大自主发行；以联运分散产品风险；投资外部
研发团队；或把现金配置到办公/研发园区、金融资产和股东回报。管理层实际选择核心 IP 迭代、
自主与联合运营并行、研发人数上升，同时建设/购买长期办公资产。

经营传导是：内容与 IP → 留存/活跃/付费 → 自主或联运分成后的收入与贡献 → 持续费用化研发
和发行成本 → OCF；资本配置再决定 OCF 是留作产品机动性、分给股东，还是锁入办公地产。游戏
生命周期失败主要先损失 R&D 和获客投入；固定资产配置错误则会把原本可变、可停止的风险变成
长期不可逆资本。

前五客户销售占比 FY2016--FY2018 约 `76.20%`、`81.24%`、`75.19%`，但这些客户可能是平台
和联运方，不等于终端玩家集中。它提示渠道依赖和应收责任，需要平台/产品边界后才能评价议价权。

## 三种经营情景

### 乐观

《问道》端游和手游跨周期保持，至少一款非《问道》产品形成可重复贡献；自主运营收入和研发后
OCF继续增长。园区/办公楼投入见顶，`OCF-capex` 回升且债务下降。届时提高组合可重复性和资本
配置信用，研究有限新产品价值。

### 基准

核心 IP 和少数成熟产品仍提供主要经营基础，新作有成功也有衰退，收入低双位数或更慢增长；R&D 占收入保持高位，
园区 capex 继续压低现金但集团仍自我覆盖。只给核心 IP 与已证明运营平台正常盈利，新游戏和
办公地产不另加成长价值。

### 悲观

《问道》付费和活跃下降且自主运营收入回落，新作未补位，研发人员和发行成本保持高位；办公楼、
园区 capex 或债务继续上升，数字内容现金被不可逆固定资本占用。此时同时下调核心正常盈利、
管理层资本配置信用和永久损失保护。

当前排序：`基准 > 乐观 > 悲观`。

## 估值方向与翻转事实

方向上以费用化研发之后、剔除异常营运资本并扣合理维护资本的核心现金为锚；不把 FY2016 的
爆发增速永久化，不把累计注册用户或榜单排名直接变现，不给未证明新游戏独立增长价值。深圳
办公楼和厦门园区按其可验证经营用途与机会成本保守处理，不因账面固定资产自动加值。本轮不算
正式估值或最高买价。

向上翻转：同定义《问道》核心充值/活跃保持，非《问道》产品形成持续收入或贡献，研发增长不
快于可吸收收入，园区/办公资本见顶且 post-capex 现金回升、债务下降。

向下翻转：核心游戏活跃/充值或自主运营收入材料下降，新作上线后迅速衰退、退出或减值，研发
资源继续增加而组合收入不跟，固定资本和债务继续吞噬现金，或平台政策/渠道条件显著恶化。

## 防御性写作检查

缺少单款游戏收入、留存和付费率没有让公司判断归零。核心 IP 延寿与运营执行强、组合可重复性
条件性、研发已由核心经济吸收、地产式资本配置待证、资产负债表短期安全，都是当前可反驳的
投资判断。局部缺失只限制新游戏价值和产品级归因。
