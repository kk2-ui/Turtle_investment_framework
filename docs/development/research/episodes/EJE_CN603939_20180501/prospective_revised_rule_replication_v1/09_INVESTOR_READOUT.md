# 益丰药房 FY2018：投资者读法

益丰证明了“能快速扩张门店网络”，没有证明“快速扩张已经创造高资本回报”。FY2018 直营店
增加 1,463 家、零售收入增长 43%，医保和会员覆盖继续提高；但综合坪效下降 4.4%，社区店型
效率下降，毛利率略降，销售费用增长快于零售收入。当前应把管理层的部署能力评为强，把单位
经营吸收评为混合。

现有网络能产生现金：OCF 扣全部 capex 仍为正约 `RMB 277m`。但当年并购和其他战略现金支出
约 `RMB 1.291bn`，完整部署后资金端点约 `-RMB 1.014bn`。债务增至 `RMB 789m`，净商誉增至
`RMB 2.733bn`。这不是收购失败证明，却说明管理层选择的扩张速度远超内部现金供给，资本配置
和永久损失折价必须提高。

投资处理是保留现有经营网络的保守价值，不把新建、收购门店、O2O 或处方外流计入基准成长，
也不把 43% 收入增长直接资本化。下一 cutoff 最重要的不是再数门店，而是追踪成熟、自建、收购
cohort 的店级利润和现金回收，以及资金缺口、债务和商誉是否继续扩大。

训练方法本身没有获得正向效用：公平 baseline 会做出同样判断。新规则没有触发，不能因表达
更整齐就称训练有效。
