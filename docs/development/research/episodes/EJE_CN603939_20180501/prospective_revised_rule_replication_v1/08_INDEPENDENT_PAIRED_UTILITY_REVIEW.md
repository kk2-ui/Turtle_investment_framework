# 益丰药房 FY2018 独立 paired utility review

> reviewer：独立于 judgment owner 与 outcome custodian
>
> 事实预算：公平 baseline 与 enhanced 共同使用 `02∪03` 的 FY2018 settlement
>
> 裁决：`NO_MATERIAL_UTILITY`

## 裁决摘要

唯一允许获得学习贡献的干预是 `SIGNED_BOUNDED_UNCERTAINTY`。本次结果没有出现金额不完整但
符号已知的非重叠战略现金事件，四个集团现金端点都是精确 singleton。因此该干预没有激活。

公平 baseline 与 enhanced 都会得到相同的企业判断、投资处理和材料研究行动。Enhanced 的责任
单元和现金表达更结构化，但结构、速度、清晰度、字段数量和规则正确执行均不构成 utility。

本案裁决为：`NO_MATERIAL_UTILITY`。它完成第四个真实反馈闭环，但没有证明修订规则能改善
未见公司的投资判断。

## 结果后最重要的三项企业判断

### 1. 网络扩张执行成功，但当前单位经营吸收转为混合而非继续明确正面

FY2018 总门店由 2,059 增至 3,611，直营店由 1,979 增至 3,442；新增直营店中自建 546 家、
收购并表 959 家，关闭 42 家。零售收入由约 `RMB 4.573bn` 增至 `RMB 6.543bn`，增长
`43.07%`；医保直营店占比由 `68.37%` 升至 `74.96%`，会员销售占比升至 `81.45%`。

这些结果证明管理层能够快速取得门店、完成并表，并把大量门店接入医保、会员和 O2O 系统。
这是真实的部署与客户覆盖能力。

但单位经营结果没有同步改善：

- 直营店综合日均坪效由 `63.88` 降至 `61.05 RMB/m²`，下降 `4.43%`；
- 中型和小型社区店坪效分别下降 `10.25%` 和 `5.44%`；
- 零售毛利率下降 `0.47` 个百分点；
- 销售费用增长 `46.50%`，快于零售收入增长。

因此公司网络结算为
`MIXED_WITH_STRONG_DEPLOYMENT_AND_WEAKER_NEAR_TERM_UNIT_ABSORPTION`。

最强反方是 FY2018 一次性并入大量新区域和新门店，年轻店与收购店的培育期自然会降低综合
坪效；直营门店期末数量也不能直接作全年收入分母。这足以阻止把当前下降写成成熟核心永久
恶化，但不能把收入和门店增长直接解释为扩张经济性已经成功。

### 2. 当前经营网络产生正现金，但收购扩张没有实现集团自我供血

FY2018 合并 OCF 为 `RMB 510.711m`，现金 capex 为 `RMB 233.670m`：

```text
OCF − all capex = +RMB 277.041m
```

当年营运资本净使用现金 `RMB 38.258m`，剔除该影响后的集团方向性端点为：

```text
OCF − working-capital effect − all capex = +RMB 315.299m
```

这支持当前经营网络具有正向现金吸收能力，但两项都不是 normalized owner cash，也不能归因
给成熟店、新店或收购 cohort。

FY2018 收购净现金支出达到 `RMB 1.239bn`，另有 `RMB 52.1m` 非重叠战略投资现金。完整部署
端点分别为：

```text
statutory post-deployment endpoint      = -RMB 1.014bn
post-working-capital funding endpoint   = -RMB 976.116m
```

当前最合理判断是：**现有经营活动可以覆盖当期全口径 capex，但不能覆盖管理层选择的收购和
战略部署规模。**

最强反方是并购现金属于前置投入，行业整合窗口可能使短期负资金端点具有经济合理性；部分收购
实体已经报告正净利润。这可以解释为什么不能立即判定资本误配，却不能证明收购价格、整合资本
和后续现金回报足以覆盖投入。

### 3. 管理层部署能力强，但资本配置信用和永久损失折价应恶化

管理层分层评价为：

- 门店取得和系统部署：`STRONG`；
- 客户覆盖和医保接入：`POSITIVE`；
- 公司网络单位经营吸收：`MIXED`；
- 自建与收购 cohort 回报：`UNPROVEN_WITH_LOCAL_MIXED_SIGNALS`；
- 资本配置：`AGGRESSIVE_UNPROVEN_WITH_HIGHER_FUNDING_RISK`。

546 家公司级自建门店没有单独收入、利润、现金 capex 或回收期。石家庄新兴药房内部 43 家
新店报告累计亏损 `RMB 4.475m`，这是责任匹配的局部负面证据，但不能外推至全部自建门店。

收购实体披露了不同购买日至年末的收入和净利润，一些实体盈利，另一些亏损或盈亏平衡；购买
日期和利润定义不同，也没有统一 OCF 或回收期，因此不能合并成一个“959 家收购店成功率”。

同时：

- 有息债务由零增至 `RMB 789m`；
- 净商誉由 `RMB 694.1m` 增至 `RMB 2.733bn`；
- 票据及应付账款增至 `RMB 2.200bn`；
- 医保应收增至 `RMB 602.5m`；
- 受限现金仍有 `RMB 507.9m`。

FY2017 和 FY2018 连续出现负的完整部署资金端点，FY2018 又伴随债务和商誉材料性增加，已经
满足“重复资金压力＋融资压力”的条件。永久损失判断应由原来的中等收购风险提高到：

```text
LOW_IMMEDIATE_SOLVENCY_RISK /
MEDIUM_HIGH_ACQUISITION_INTEGRATION_AND_FUNDING_PERMANENT_LOSS_RISK
```

这不是“收购已经失败”。没有新增商誉减值、部分收购实体盈利以及 OCF 增长是最强反证。它们
支持保留经营平台价值，却不足以消除收购价格、整合回报和融资结构尚未验证的风险。

## Owner cash 与投资含义

不能把 `+RMB 277m`、`+RMB 315m`、`-RMB 976m` 和 `-RMB 1.014bn` 合并成一个虚假的
owner-cash 区间，因为它们代表不同资本责任边界。

当前投资处理应是：

1. 保留现有经营网络的正向现金创造能力；
2. 不把集团 OCF 直接归因给成熟门店或新增 cohort；
3. 自建门店、收购门店、O2O 和处方外流继续不进入基准成长价值；
4. 对收购扩张、债务、商誉和供应商融资施加更高资本配置与永久损失折价；
5. 不因单期负部署资金直接宣称资本误配，但必须观察其是否继续重复以及收购是否产生责任匹配
   的现金回报。

## 三种经营情景

### 乐观

新增和收购门店在培育期后恢复至成熟网络坪效，销售费用增速低于收入，零售毛利稳定；收购
实体形成可重复 OCF 和合理回收期，完整部署资金端点转为持续非负，债务和供应商融资不再扩张。
届时可以提高资本配置信用，并给予责任匹配的新店和收购 cohort 有限成长价值。

### 基准

公司继续依靠区域密度、医保和会员体系增长，综合坪效逐步稳定但不能证明全部新增 cohort
达到成熟经济性；当前经营网络保持正现金，收购扩张仍需要外部资金。估值只承认保守的现有
网络价值，新建和收购门店维持零或极低期权价值，并保留较高资本配置折价。

### 悲观

综合及社区店坪效继续下降，销售费用、医保应收和库存持续快于收入；收购实体不能形成现金
回报，债务、承兑融资和受限现金继续增加，随后出现关店、处置或商誉减值。此时规模增长应被
视为购买收入，正常 owner cash、管理层信用和估值中枢均需下调。

当前排序仍为 `BASE > OPTIMISTIC > PESSIMISTIC`，但相对 cutoff 前判断，悲观情景权重应提高。

## 方向性估值与翻转条件

估值方向为“保守现有网络价值，新增和收购 cohort 零基准成长价值，并提高收购及永久损失
折价”。不得资本化 `43%` 的零售收入增长，也不得把商誉作为额外价值。本轮不计算正式估值或
最高可接受买价。

向上翻转需要：

- 成熟、自建和收购门店的同口径销售、店级利润、维护资本和 OCF；
- 新建及收购 cohort 在合理培育期达到成熟店经济性和合理现金回收期；
- 完整部署资金端点连续转正；
- 债务、票据融资、医保应收和受限现金相对收入稳定；
- 商誉没有减值或低价退出。

向下翻转包括：

- 综合或成熟店坪效继续下降；
- 销售费用和营运资本占用持续快于收入；
- 完整部署资金缺口、债务和供应商融资继续扩大；
- 收购实体出现持续亏损、关闭、处置或商誉减值。

## 公平 baseline 的结果处理

公平 baseline 获得全部 `02∪03` 事实，且在 cutoff 前已经具备公司网络与 cohort 的责任边界、
集团资金端点不是 normalized owner cash、一期负资金端点不能单独证明资本误配、管理层分层，
以及重复负资金和融资压力可以提高永久损失折价。

面对 FY2018 结果，公平 baseline 会：

1. 把公司网络由明确正面更新为部署强、单位吸收偏弱的 `MIXED`；
2. 保留现有经营网络正现金，但不给新建和收购 cohort 基准成长价值；
3. 看到连续负部署资金、债务和商誉增加，提高资本配置及永久损失折价；
4. 优先研究 cohort 现金回报、并购价格、融资压力和后续减值。

## Enhanced 的结果处理

Enhanced 会把公司网络、自建 cohort、收购 cohort 和集团资金分别结算，并得到与 baseline
相同的企业判断、管理层评价、owner-cash 处理、永久损失等级、情景排序、估值方向和研究议程。

本期不存在 incomplete signed strategic cash term：

```text
incomplete signed event = false
four cash endpoints = exact singleton values
```

所以 `SIGNED_BOUNDED_UNCERTAINTY` 没有改变任何金额、方向或决策。Enhanced 只是更明确地
表达了相同责任边界，不能因此获得 utility。

## Paired utility 裁决

裁决为 `NO_MATERIAL_UTILITY`。因果依据是：

1. 唯一允许获 credit 的 learning intervention 没有激活；
2. 公平 baseline 已经能使用所有材料事实并得到相同投资处理；
3. Enhanced 没有避免一项 baseline 实际会犯的材料错误；
4. Enhanced 没有产生 baseline 不会采取的材料研究行动；
5. 字段、结构、表达清晰度和规则遵循均被明确排除在 utility 之外。

这不是 `HARMFUL`，因为 enhanced 没有丢失已知现金方向、没有让局部 cohort 缺口取消公司
判断，也没有把集团现金归因给某个 cohort 或把一期资金端点写成 normalized owner cash。

这也不是 `MATERIAL_UTILITY`。本案只能说明修订规则在没有适用事件时没有制造额外错误，不能
证明该规则在真正出现 signed incomplete term 时会改善投资判断。
