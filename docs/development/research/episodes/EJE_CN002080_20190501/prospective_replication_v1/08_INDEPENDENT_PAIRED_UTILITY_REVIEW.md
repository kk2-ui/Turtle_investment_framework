## 结果后的最佳企业判断

中材锂膜已经从“客户入口存在、经济吸收未成立”推进到“责任单元商业吸收明显改善，但核心
营业经济仍未完全转正”。这提高了商业化判断，却不足以提高资本配置信用。

- 四条线均已投产，公司披露客户认证和批量供货；具体订单与长期协议没有在合同限定披露中
  得到结算，不能据此判断重复需求。
- 中材锂膜责任边界和 `86.50%` 持股连续。收入由 FY2018 的 `RMB 54.385m` 增至
  `RMB 187.552m`，营业亏损由 `RMB 114.939m` 收窄至 `RMB 52.684m`，净利润由
  `-RMB 43.975m` 转为 `+RMB 25.421m`；OCF 却由 `RMB 87.122m` 降至
  `RMB 20.286m`。核心营业经济改善但仍亏损，净利润和正 OCF 不能单独证明成熟回报。
- 同一 2.4 亿平方米项目累计已付合同款由 `RMB 441.805m` 增至 `RMB 1,018.471m`，未付由
  `RMB 633.630m` 降至 `RMB 56.964m`；与此同时公司启动独立的 4.08 亿平方米二期扩张。
  旧义务接近支付完成，不等于资本已经产生回报或总资本负担消失。
- FY2019 合并锂膜产品收入 `RMB 335.668m`、销量 `180.50m m²`、产量
  `232.57m m²`、期末库存 `56.52m m²`。湖南中锂年内并表使产品同比局部不可比；这些现期
  水平仍然有效，但不能归因给中材锂膜或一期项目。
- 集团 FY2019 OCF `RMB 2.970bn`、现金资本开支 `RMB 2.177bn`，方向性差额
  `+RMB 792.881m`，说明集团仍有承受力。新增五家并表主体限制集团同比，集团现金也不投票
  决定锂膜资本配置。

因此，管理层建设执行维持 `MEDIUM_HIGH`，客户和商业化执行从 `MEDIUM` 提高到“有证据改善”，
资本配置维持 `LOW_CONDITIONAL`。项目永久损失风险仍为 `MEDIUM`，集团为
`LOW_TO_MEDIUM`；风险中心从一期能否建成转向在成熟营业经济尚未成立时继续扩大固定资本。
情景排序维持 `基准 > 乐观 > 悲观`，锂膜仍不进入基准正常盈利或增长价值。

## Baseline 独立结果

公平 baseline 已经知道建成和认证不等于资本回报，也能读取当期产品库存、子公司亏损、项目
义务、扩张事件和集团现金。它虽没有系统冻结 FY2018 同定义比较和组合条件树，仍会合理得到：

1. 建线与客户入口继续兑现，执行信用保持正面；
2. 可比子公司仍有 `RMB 52.684m` 营业亏损，不能用净利润或正 OCF 单独上调；
3. 一期尚有未付义务，且二期已启动；
4. 资本配置维持 `LOW_CONDITIONAL`，不给增长价值；下一步继续研究持续利润、现金和新增扩张
   负担。

Baseline 不是会被“运行良好”、行业增长或客户认证自动说服的稻草人。

## Enhanced 条件树结果

- `product_signal = UNAVAILABLE`：湖南中锂新并表，只使产品同比退出条件树，不取消现期产品
  与其他责任边界判断。
- `subsidiary_signal = POSITIVE`：责任边界连续，营业亏损较 FY2018 明显收窄；净利润转正是
  支持证据，OCF 下降是限制。
- `project_obligation_signal = INCREASED_OR_REPLACED`：一期未付义务下降，但二期属于在原有
  吸收尚未完成时新增的扩张。

实际触发：

```text
PRODUCT_U + SUBSIDIARY_P + OBLIGATION_INCREASED_OR_REPLACED
  -> ALL_OTHER_COMBINATIONS
  -> RETAIN_LOW_CONDITIONAL
  -> UPDATE_SUBSIDIARY_COMMERCIALIZATION_ONLY
  -> WITHHOLD_GROWTH_VALUE
```

这不是因产品口径变化拒绝判断，而是使用可比子公司与同一项目义务继续完成判断。

## 两臂效用裁决

Enhanced 更明确地分开产品、责任子公司和资本合同，组织结论也更快；但它没有避免公平 baseline
会实际犯下的材料性错误，也没有改变资本配置、owner cash、永久损失、情景排序或估值方向。
两臂都维持 `LOW_CONDITIONAL`、不给锂膜增长价值，并继续研究利润、现金和扩张负担。

因此裁决为 **`NO_MATERIAL_UTILITY`**，不是 `HARMFUL`。字段更多、解释更整齐、置信度更高和
速度更快不能冒充企业判断改进。

## 规则收窄

保留 `ECONOMIC_ABSORPTION_AFTER_BUILD` 的窄核心：重资产建成后优先看连续责任单元的核心营业
经济与同一项目资本义务。保留 `TREND_REQUIRES_COMPARABLE_BASE` 作为局部趋势方法，但不能因
一层趋势不可比而终止全案。

本轮新增限制是：若公平 baseline 已掌握当前亏损、资本义务、扩张事件以及“建成不等于价值”，
系统化同定义基线或条件树只有在实际改变投资处理、避免材料性错误或改变材料性下一研究动作时
才有 utility；否则必须记录 `NO_MATERIAL_UTILITY`。

## 最强反方与翻转事实

最强反方是收入约增长 `245%`、营业亏损收窄约 `54%`、净利润转正、一期合同接近付清，二期
可能反映真实订单和规模学习。它目前略弱，因为核心营业利润仍负、OCF 下降、产品增长不能与
责任单元同边界对应，且一期盈利吸收未证明时二期已经启动。

向上翻转需要中材锂膜同边界的销量、库存和单位经济，持续营业盈利，剔除营运资本后仍为正的
OCF，以及二期可识别的订单、良率、资本和回报。向下翻转是责任单元亏损重新扩大、OCF 转负、
库存或应收积压、二期承诺继续增长而提货不跟进，或项目减值和交叉补贴加重。
