# 家家悦 FY2018：独立 paired utility 裁决

> reviewer：`/root/cn603708_paired_review`
>
> 结果：`HARMFUL`
>
> 根因：`MODEL + REASONING`

审阅者先用冻结的公平 baseline 解释结果，再严格执行 enhanced 条件树。裁决不是因为字段少或
口径不全，而是 enhanced 把可确定的负向现金上界错误降成 `UNKNOWN`，弱化了 owner cash、
资本配置和永久损失判断。

## 结果后的最佳企业判断

成熟网络仍有谨慎正面的经营信号：开业两年以上门店收入增长 `2.72%`，会员客流增长
`5.03%`、客单增长 `5.17%`，商业毛利率由 `17.23%` 升至 `17.42%`。维客从 2018-03-01
并表且没有逐字段旧核心桥，因此只能说合并网络继续吸收，不能把改善全部归给胶东成熟核心。

三个新域均已部署，但都没有完成本地经济验证：

- 维客并表十个月收入约 `RMB 559.9m`，净利润仅 `RMB 1.63m`；营业利润和 OCF 未披露，
  净利润不能代投核心营业经济；
- 有机新区域/微型店只有实际开店和管理层定性改善，没有隔离的经营贡献或关闭/减值；
- 收购的青岛物流设施投入使用，但无可归属节省、服务贡献或经营结果；烟台、莱芜和标准化
  工程年末仍未完成。

管理层继续获得门店、收购和物流部署执行信用；资本配置信用则应从 `CONDITIONAL` 下调。
真正材料性结果是扩张后现金吸收明确转负，而不是“新域资料不够”。集团期末货币资金约
`RMB 2.284bn`，短期流动性仍强；永久损失风险来自并购、资本开支、租约、开始举债和未经
验证的新域同时叠加，不是眼前偿债危机。

## Baseline 独立结果

公平 baseline 能读取当前成熟店、会员、毛利、维客、集团现金、并购现金和债务，且本来就
知道门店数不等于价值、合并现金不证明新域回报。它会得到：

1. 合并成熟网络经营谨慎偏正面，维客并表限制旧核心归因；
2. 维客、有机新域和物流均未完成经济承保，不给增长价值；
3. OCF 降至 `RMB 613.5m`，现金 capex 升至 `RMB 764.3m`，`OCF−capex` 为
   `-RMB 150.8m`；
4. 按冻结公式剔除营运资本影响后、收购前代理为 `-RMB 102.2m`，再扣维客收购净现金
   `RMB 218.5m` 后至少为 `-RMB 320.7m`；
5. 有息债务由零变为 `RMB 160m`，未来三年最低租约约 `RMB 902.6m`。

因此 baseline 会下调扩张后 owner cash 和资本配置信用，提高永久损失折价；成熟核心仍单独
保留经营信用。

## Enhanced 唯一机械结果

```text
CORE_U
+ WEIKE_U
+ ORGANIC_NEW_REGION_AND_MICRO_STORE_U
+ NEW_LOGISTICS_U
  -> NEW_DOMAIN_U
+ CASH_U（其他不重叠外部投入未完整披露，冻结规则 U-first）
  -> 保留原成熟核心处理
  -> 新域 conditional、不给增长价值
  -> 只阻止资本配置升级
  -> owner cash 保持 conditional
```

核心和三个新域的 U 都正确局部化，没有阻止公司判断；新域拆分也正确防止维客一个结果替整个
扩张包投票。伤害只发生在 cash。

## 防御性推理错误

设其他不重叠的新域外部现金支出为 `X`。其金额未知，但按定义 `X >= 0`：

```text
OCF - capex                                      = -150.799m
OCF - WC support - capex                         = -102.210m
再减维客收购净现金 218.499m                      = -320.708m
再减其他不重叠外部新域现金 X（X >= 0）           <= -320.708m
```

`X` 只改变“有多负”，不能改变负方向。冻结规则因缺精确值触发 `UNAVAILABLE_FIRST`，把已经
知道的方向也写成 U。它不是谨慎，而是丢失信息：相对 baseline 少给资本配置折价、少提高永久
损失风险，也可能高估正常化 owner cash。

## Utility 裁决

裁决为 **`HARMFUL`**，不是 `NO_MATERIAL_UTILITY`。两臂虽然都不给新域增长价值，但 owner
cash、永久损失和资本配置是独立的材料性投资轴；Enhanced 在这些轴上方向更差。

根因主要是 `MODEL`，次要是 `REASONING`。不是数据不足或 acquisition module 失败；完整
其他支出只会细化负数，已不是决定方向所必需。

## 规则改写

- deployed subdomain/locality 保留：它正确防止单一子域替整个 bundle 投票；
- `ECONOMIC_ABSORPTION_AFTER_BUILD` 和 `TREND_REQUIRES_COMPARABLE_BASE` 继续窄保留；
- aggregate new-domain U 只表示不能整体升级，不能覆盖独立现金与永久损失判断；
- cash `UNAVAILABLE_FIRST` 废弃，改为 **`BOUNDED_UNKNOWN_PRESERVES_DIRECTION`**：先构造可行
  区间；若最乐观上界仍小于零，方向必须为 negative，精确金额继续 unknown。只有未知项可能
  跨越零或改变融资判断时才用 U/MIXED。

该规则只能用于已知符号和责任边界的量，不得给未知金额赋值，也不得追溯改写本轮冻结合同。

## 情景、估值与下一研究

情景仍可为 `基准 > 乐观 > 悲观`，但基准 owner cash 下修、悲观权重上升。成熟核心可保留
正常经营价值；维客、有机新域和物流不进基准增长价值；资本配置和永久损失折价提高。本轮不
计算正式价值或买价。

下一步优先获取维客营业利润、OCF与营运资本，有机新域的独立贡献与关闭，以及青岛物流可归属
节省。补齐其他外部投入只细化负数大小，不再是判断现金方向的必要研究。
