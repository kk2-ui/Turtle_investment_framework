# 恒生电子 FY2018 反馈：投资者读本

## 一句话结论

成熟金融 IT 核心仍在吸收客户和研发投入，新 AI、区块链、云只证明部署、没有证明独立经济；
集团当期经营现金较强，但战略投资几乎耗尽保守 post-WC/capex 现金代理并出现少量债务，资本
配置仍应条件性，而不是因一个正现金数字升级。

## 三项投资判断

1. **核心有效。** 软件收入增长 `23.62%`，五条核心线四升一降，并有多客户签约和上线；保留
   正常盈利与核心研发信用，同时保留监管项目周期反方。
2. **新 options 未被证明。** AI 出现跨客户案例，但纯责任单元的重复收入和营业利润缺失；云
   受限、区块链仍探索、云赢续新客户下降。它们不给独立增长价值，却不拖累已经成立的核心。
3. **资金覆盖是条件性，不是负值或 owner cash。** `OCF−营运资本支持−全 capex` 约
   `+RMB 481m`；扣至少 `RMB 455m` 战略股权现金和其他 `X≥0` 后为 `26.273m−X`，可能跨零。
   新增 `RMB 60m` 债务值得追踪，但单期不足以证明误配或永久损失上升。

## 管理层、永久损失与估值方向

core 执行 `MEDIUM_HIGH`；新增 options 和战略资本配置 `CONDITIONAL`。短期资产负债表风险低，
中期风险来自核心被监管周期削弱、研发资源长期没有商业吸收，以及战略投资反复使用现金和债务。

方向上只给成熟核心正常盈利；不给 AI、区块链、云或战略投资独立成长价值，保留资本配置折价。
不计算正式估值或最高买价。

## 训练方法的诚实结论

Enhanced 正确处理了软件 carrier、局部 UNKNOWN 和跨零区间，没有伤害；但公平 baseline 本来
也会得到同样的投资处理和研究动作。因此本轮是 `NO_MATERIAL_UTILITY`：规则更清楚，不等于
判断更好。真正应留下的是责任边界——已知符号只能支持区间方向，集团资金区间不能冒充业务
回报或 normalized owner cash。
