# 恒生电子 FY2018 独立 paired utility review

> reviewer 与 judgment owner、outcome custodian 独立
>
> 裁决：`NO_MATERIAL_UTILITY`

## 机械结算

### 成熟核心：`POSITIVE_WITH_REGULATORY_CYCLE_LIMIT`

软件收入由约 `RMB 2.578bn` 增至 `RMB 3.187bn`，增长 `23.62%`；五条核心金融 IT 业务中
券商、资管、财富、交易所收入上升，银行 IT 下降。UF3.0 中标招商证券，机构柜台签约 17 家
券商、BOP 新增 14 家券商，近 20 家银行上线交易管理系统。责任边界与同比列可用，冻结条件树
因此给 `POSITIVE`。

这只支持当前商业吸收和 core R&D 信用，不证明跨监管周期定价权或增长率永久持续。银行 IT
的下滑是局部反证，尚未推翻其他四条线和客户部署共同支持的核心判断。

### AI、区块链与云：`DEPLOYED_ECONOMICS_UNAVAILABLE`

iSee 与三家券商合作，多项 AI 产品出现客户案例；但纯 AI、区块链、云的责任边界、重复/维护
收入和营业利润均未单独披露。金融云应用仍受约束，区块链仍在研究探索，云赢网络的新签和续签
客户均下降但没有可判定量级。

所以这些 options 已有部署，不进入独立增长价值。这个局部 unavailable 不下调已经被验证的
成熟核心，也不允许用互联网业务收入或混合子公司净利润替它们投票。

### R&D、合并资金覆盖与资本配置

R&D 由约 `RMB 1.292bn` 增至 `RMB 1.405bn`，占收入由 `48.48%` 降至 `43.05%`，研发人数
由 4,234 增至 4,590。全部费用化研发已在 OCF 中，不能再扣一次。核心吸收支持核心研发信用，
但不证明新增 options 的回报。

FY2018 合并 OCF `RMB 937.083m`，营运资本现金支持 `RMB 309.095m`，全口径现金 capex
`RMB 146.640m`，故单期方向性 `OCF−营运资本支持−全 capex` 为 `+RMB 481.348m`。它不是
core cash 或 normalized owner earnings。

取得控制权的并购净现金为零；增持恒运控股少数股权至少支付 `RMB 455.075m`，另有无法完整
拆分的非重叠外部战略支出 `X≥0`：

```text
post-capex/post-investment funding residual = 26.273m - X
```

最乐观上界为 `+RMB 26.273m`，下界无法建立，因此区间可能跨零。债务由 0 增至 `RMB 60m`，
冻结分类只能是 `MIXED_WITH_FINANCING`，不能写成必负，也不能用 `+RMB 481m` 升级资本配置。

## 结果后的最佳企业判断

- 成熟核心进入正常盈利研究，仍受监管项目周期限制；
- 管理层 core 执行 `MEDIUM_HIGH`，AI、区块链、云和战略资本配置维持 `CONDITIONAL`；
- 单期合并资金覆盖无法确定正负，至少说明已知战略部署消耗了保守现金代理的大部分并出现少量
  债务；这要求研究恒运等责任匹配回报和融资缺口是否重复，但不证明误配；
- 永久损失保持 `LOW_FROM_CURRENT_BALANCE_SHEET / MEDIUM_FROM_CORE_EROSION_R_AND_D_AND_STRATEGIC_ALLOCATION`。

## 公平 baseline 与 enhanced

公平 baseline 已冻结成熟核心吸收、监管周期、新 options 零增长价值、费用化 R&D 处理、营运
资本和当前现金判断，并显式登记外部战略投资现金和债务。面对同一份 FY2018 年报，公平研究者
同样会看到 `RMB 455.075m` 外部战略现金、其他 `X≥0` 和新增 `RMB 60m` 债务，继续研究责任
匹配回报与集团资金覆盖。

两臂最终都得到：

- core 正常盈利保留；
- AI、区块链和云不获独立增长价值；
- 资本配置条件性；
- 单期 funding residual 不改变永久损失等级；
- 下一研究是匹配战略投资回报和融资压力是否复发。

Enhanced 的区间表达更清楚、犯符号错误的风险更低，但本案没有改变投资处理、避免 baseline
实际会犯的材料错误，或产生 baseline 不会采取的研究动作。按照首轮反馈，字段、结构、速度、
清晰度和“规则正确运行”均不算 utility，故裁决 `NO_MATERIAL_UTILITY`。

## 为什么不是 harmful

Enhanced 没有导入物理产能/库存 carrier，没有双扣费用化 R&D，没有让 option UNKNOWN 覆盖
core，也没有为 `X` 发明金额或因果。它正确识别区间跨零，而非复制家家悦的负上界丢失错误。

## 三情景、估值方向与翻转

- 乐观：核心跨监管周期继续替换与续收，新 options 形成跨客户重复经济，战略投资出现匹配回报，
  funding residual 持续为正且债务不扩张；
- 基准：核心增长放缓但嵌入度保留，银行 IT 弱点局部化，options 零独立价值，资金覆盖和资本
  配置保持条件性；
- 悲观：监管需求退潮蔓延至核心，研发资源继续扩张而吸收不跟，云赢弱点扩散，战略投入反复
  吞噬现金并推高债务。

排序 `BASE > OPTIMISTIC > PESSIMISTIC`。估值方向只允许成熟核心正常盈利，不给新增 options
和战略投资单独增长价值，保留资本配置与永久损失折价；不计算正式估值或 BuyBand。

向上翻转需要责任匹配的重复收入/利润、恒运等投资回报、跨周期 post-WC/capex 现金和债务不
持续增加；向下翻转是核心客户流失、研发快于商业吸收、option 续签恶化扩散、连续资金缺口与
债务、减值或退出。

## 权限

本裁决关闭第三条真实反馈，但不授予 transfer validation、method freeze、Comparative、CJO、
正式估值、BuyBand、报告或投资权限。
