## 学习带来的窄变化

CN603708 的 harmful feedback 产生两个结果前修正：

1. 未知量有已知符号时先构造区间，不能因精确金额缺失抹掉方向；
2. 公司现金必须分开“合并 OCF 剔除营运资本支持并扣全部 capex 的方向代理”和“再扣收购后
   的单期融资残差”，两者都不能命名为核心正常 owner cash。

FY2017 已披露数值形成：

```text
合并 OCF - 三项营运资本支持 - 全部现金 capex = +RMB 241.245m
再减取得子公司净现金 RMB 299.447m            = -RMB 58.201m
再减其他未知且非负的战略外部支出 X             <= -RMB 58.201m
```

`+RMB 241.245m` 只是合并方向代理，因为维护与增长 capex 未拆；`<= -RMB 58.201m` 只是单年
集团 post-capex/post-acquisition funding residual，不证明收购回报、研发误配或永久损失。

材料性变化只发生在下一研究：优先检查责任匹配的收购/新产品回报和集团融资缺口是否重复，而
不是再次确认产品发布、headline OCF 或研发规模。资本配置和永久损失在 outcome 前仍保持
条件性，没有被一个年度的存量现金使用提前下调。
