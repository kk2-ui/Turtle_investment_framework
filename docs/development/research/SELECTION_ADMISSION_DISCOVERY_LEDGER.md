## 用途与边界

这是一份 acquisition 台账，不是训练 episode register、结果数据库或投资观点。每一条只基于相应 cutoff 前的官方来源；没有一条获准读取结果期、登记 claim 或形成方向性 learning。它的作用是防止后续 agent 重复把“项目预测、集团财务或事后数字”误认作可冻结的选择样本。

`NO_PRIMARY` 的含义是当前证据不能支撑黄金报告级的竞争机制训练，不是对公司、管理层或后来结果的评价。重新考虑一条线索必须从新的、日期受限的官方 source package 开始；不得把本台账中的拒绝理由倒置为结果解释。

## H1 strict Stage-0 static package

H1 的唯一输入是独立 curator 交付的、无 action/target/final peer/outcome/hypothesis 的 cutoff-before static CNINFO PDF package。它必须按 [strict intake 设计](TURTLE_STAGE0_STATIC_SOURCE_INTAKE_DESIGN.md) 返回 `STAGE0_FEASIBILITY_REVIEWABLE`，并只证明五名控制独立成员、同一机制定义 arena、字段可得性和逐页原件 identity；它不创建 candidate、episode 或 outcome access，也不授权 Agent 搜索、补齐或挑选真实公司资料。

## H2 candidate-decision-screen 的最小 source package

只有 H1 strict Stage-0 成功后，curator 才可一次性提交绑定 H1 receipt 的 action-screen static-PDF extension，交齐下列 action-screen 所需的 cutoff 前原件与字段。它可补入 H1 不允许携带的行动证据，但不得新增 cohort 公司；screen 开始后不得再追加或替换来源：

1. 公司整体、同一合并责任边界的已实施或不可逆行动、真实行动暴露与可执行的最强反方；
2. 三期、非行动机械生成的 D2：销量、出货、活跃客户、复购、渠道库存，或官方独立量价拆分；
3. target 五个行动前年度、同行各三个年度的同口径官方 D3 原始字段与保守 D4 原始字段；裸 D3/D4 数值、非官方来源或不同发行人/边界均不接纳；
4. target D3 与 D4 各自从五年历史机械重建的材料性阈值；行动暴露只作准入规模，不能替代 D4 或项目现金预测；
5. 二至七家 cutoff 前冻结、非同一控制集团的同行面板（目标加同行至少三家总成员）及纳入宇宙、排除理由、基期和不替换规则；
6. 明确的成熟观察窗口、未知边界和 outcome firewall attestation；source、measurement 与 outcome contract 必须能逐字段重建 target/peer 的 D3/D4。

任何缺项都在 acquisition 阶段停为 `NO_PRIMARY`；不得建立 R-105、v3 program 或 outcome package。
