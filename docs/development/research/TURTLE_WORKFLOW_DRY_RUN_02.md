# 研究流程干跑 02：不同措辞会不会伪装成竞争判断？

状态：`METHOD_PREPARATION_TEST / SYNTHETIC / NO_COMPANY_RESEARCH`  
目的：测试机制竞争模板能否阻止“主方 0 至 -5%、反方 -3 至 -10%”这类看似不同、实际大部分区间同时成立的预测。

## 1. 虚拟输入

某公司在 cutoff 前有一个同口径、可用的零售指标。研究者对下一年收入提出两种机制：

- H-A：渠道重配，收入变动 `≥ -5%`；
- H-B：竞争恶化，收入变动 `≤ -3%`。

在收入变动 -4% 时，两种机制都会“预测正确”。若只要求填两条数字，研究者仍可在结果期任意称一方胜利。

## 2. 旧模板干跑：暴露的问题

旧机制实验只要求“至少有一个对方不能同时获胜的观察区域”，但没有要求研究者把该区域写出。嵌套谓词能悄悄通过阅读流程；而当 -4% 出现时，流程也没有将它明确识别为 `MECHANISM_NONDIAGNOSTIC`。

根因：`REASONING`。经济影响是伪分歧会让研究者误以为自己的机制可被验证，进而错误增加中心路径或现金判断的信心。

## 3. 流程修改

机制实验的每个候选信号必须预先写出四种结果区域：

| 区域 | 含义 |
|---|---|
| `A_ONLY` | 只支持机制 A 的可观察结果。 |
| `B_ONLY` | 只支持机制 B 的可观察结果。 |
| `MIXED` | 双方均可解释，不能裁决。 |
| `NEITHER` | 双方皆无法解释，应重开机制或测量边界。 |

并为五种未知原因规定不同动作：

| 未知原因 | 研究动作 |
|---|---|
| `MISSING_OBSERVATION` | 请求或提取缺失观察；不以邻近指标填补。 |
| `MEASUREMENT_MISMATCH` | 先统一交易点/单位/期间/分类；做不到则不比较。 |
| `MECHANISM_NONDIAGNOSTIC` | 寻找不同箭头或撤销该信号；不是再收集同一指标。 |
| `NOT_YET_DUE` | 保留冻结判断并等待；不提前解释。 |
| `PIT_BLOCKED` | 从历史判断验证中排除，或寻找当时版本。 |

## 4. 修改后复跑

上述 H-A/H-B 的 -4% 结果必须进入 `MIXED`；它不支持任一机制。研究者只有找到一个真正产生 `A_ONLY` 与 `B_ONLY` 区域的信号，例如同口径的全渠道相对位置或可分解的量价/费用顺序，才能冻结竞争判断。

若没有这样的信号，正确状态是 `UNDIFFERENTIATED`；不能以更窄、更任意的数值阈值制造区分度。

## 5. 迭代裁决

`MODIFY → RETEST_PASSED`：流程现在明确区分了“有数据但不具诊断性”和“没有数据”。它仍只是在合成情境下证明逻辑完整性；正式方法验证需在结果隔离的历史 PIT episode 中完成。
