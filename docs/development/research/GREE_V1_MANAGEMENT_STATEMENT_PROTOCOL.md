# 格力 V1：管理层陈述的研究协议

状态：`RESEARCH_PROTOCOL / NO_CREDIBILITY_SCORE / NO_CENTRAL_PATH`  
适用：年报、业绩会正式记录、交易所公告和经由原件可复读的管理层表达。  
不适用：把管理层语气、访谈印象或“公司自己也说不清”的缺口伪装成公司经营事实、概率、估值或动作。

## 为什么需要单列

公司不一定掌握全渠道份额、价格实现、经销库存或自身行动的最终经济效果；供应商数据也可能与公司叙述不一致。这是正常的信息结构，不自动意味着管理层撒谎、H-A/H-B 任一方为真，或研究应中止。

关于前瞻披露的实证研究提示一个窄但有用的区分：带方向、量化影响、可随后核验的表达，比无法核验的前瞻语言更有信息价值；见 Bozzolan、Trombetta 与 Beretta 的[研究](https://doi.org/10.1080/09638180802627779)。多信息人报告不一致也不应自动被当作随机误差而平均掉；De Los Reyes 等的[综述](https://doi.org/10.1146/annurev-clinpsy-050212-185617)给出的可迁移纪律是先研究“为何不一致、各自观察到什么”，而不是先消除分歧。

所以本协议只记录陈述**能作为什么对象**，不为管理层或来源打分。

## 四种对象，四种用途

| 对象 | 最小字段 | 研究用途 | 不能做什么 |
|---|---|---|---|
| `ACTION_COMMITMENT` | 动作、决策日、资源/责任边界、原始来源。金额或资金来源未知必须明示。 | 是资本配置或渠道机制链的当期输入；随后查找实际 `ESCALATE / MAINTAIN / DEESCALATE`。 | 动作本身不证明协同、回报、竞争改善或 owner cash。 |
| `MEASURABLE_FORECAST` | metric、单位、比较对象、方向/阈值、期间、条件、允许结果来源。 | 只在 cutoff 前完整具备这些字段时，才可能成为一个 FJ 候选。 | 不能因措辞积极、作者职务高或后来结果好而补写缺失阈值。 |
| `CAUSAL_ATTRIBUTION` | 管理层所称原因、被解释事实、适用范围和可反驳的替代解释。 | `MECHANISM_DISCOVERY`：为 H-A/H-B 都写一条待检验箭头和下一项外部/公司取证。 | 不能作为“为什么发生”的独立验证，也不能直接支持任一机制。 |
| `ASPIRATION_OR_SELF_EVALUATION` | 原话、时间、对象；例如“持续推进”“初步成果”“将提升”。 | 只生成问题或访谈/披露任务。 | 不能进入 FDB、FJ、pair signal、案例证据或管理能力记录。 |

同一陈述可以同时是“动作事实”和“结果归因”，但必须拆为两个对象：前者只验证动作是否发生，后者仍是待检验解释。重复披露、卖方转述或不同场合重复同一措辞不是独立 corroboration。

## 承诺兑现和经济判断是两条不同的学习回路

资本动作有时可以精确结算“是否做了”，却完全不能结算“做得是否经济”。因此每一项 `ACTION_COMMITMENT` 先走一条窄的行动编年：**授权/资源边界 → 实际 movement → 后续用途变化、追加或撤退**。它的结论仅是某个行动事实已经发生、部分发生或未知；不产生“管理层可信度分数”。

只有另一条、在行动发生前就已完整冻结的经济预测链，才可以评价判断：**机制 → metric/阈值/期间/条件 → 后续经营或资本 outcome**。不能因为第一个行动链执行得快，就给第二条链补上关于回报、协同或竞争位置的预测。反过来也不能因后来的用途改变，把原先确实执行的资金动作改写成“没有发生”。

这一区分也有实证上的理由：美国企业样本中，回购可能同时反映管理层激励、资金弹性和多重动机，而不是单一的资本配置信号；见 [Jolls (1998)](https://doi.org/10.3386/w6467) 与 [Brav et al. (2003)](https://doi.org/10.3386/w9657)。它们不是格力的证据，只支持本协议的保守用法：回购完成本身不能证明管理层与普通股股东的长期利益已经一致。

若一个 movement 只影响初始承诺的一部分，必须冻结它的 `scope=PARTIAL` 和来源化的 `affected_fraction_of_initial`；如果覆盖范围不可读，则为 `scope=UNKNOWN` 并明确保守处理。否则“撤退”会被误读成全部项目撤退，或“维持”会掩盖局部用途改变。

## 对“公司说不清”的处理

缺少 metric、比较对象、时间窗口、范围边界或可读结果来源时，登记为 `UNSPECIFIED / UNKNOWN`，并在暂定工作路径中写出最小的后续检查。它不是负面证据：

1. 不能把未说明全渠道份额变成“全渠道份额一定下降”；
2. 不能把未说明返利或经销库存变成零，也不能用供应商零售数据反填公司会计项目；
3. 不能因公司与 AVC/产业在线冲突而平均两个数；应标出销量/销额、sell-in/sell-out、品牌映射、渠道和期间的差异，并检查随后公司量价、费用和营运资本传导；
4. 不披露未来结果不等于预测失败。只有 cutoff 前已完整冻结的 `MEASURABLE_FORECAST` 才可在窗口结束后结算。

这正是 `TENTATIVE_WORKING_PATH` 的角色：保留不一致、指出下一箭头和取证顺序，但不选择中心路径。

## 格力当前的落地顺序

1. 对既有年报中的渠道、格力钛与资本配置表达逐段标注四种对象之一；不要摘录成“管理层看好”摘要。
2. `ACTION_COMMITMENT` 接入既有 `allocation_event` 的“启动承诺 → 后续 movement → FDBREAL/FDBMON”；没有金额/资金来源时保留 `UNKNOWN` 与保守处理，部分 movement 绝不扩大成整个初始承诺。
3. `CAUSAL_ATTRIBUTION` 为 H-A 和 H-B 各生成不同的后续公司传导检查。例如“渠道升级”只有在随后同口径竞争位置、费用和现金的预注册序列出现时才增加诊断力。
4. 只有完整的 `MEASURABLE_FORECAST` 才能进入无价格 CJO 的 FJ 候选；其结果期 observation 仍须符合行业/公司来源、measurement profile 和 PIT 纪律。
5. `ASPIRATION_OR_SELF_EVALUATION` 永远停在问题层，不能因其出现于年报而升级。

## 根因、经济影响与接纳

根因是 `REASONING + DATA_COVERAGE`，部分表现为 `ACQUISITION_MODULE`：把公司有权解释的文字误认成公司已经观察到的经济结果，会让渠道竞争、normal owner cash 和资本配置结论带有虚假的确定性。禁止按管理层语气、报告数量、公司排名、股价或事后结果给陈述加权；禁止在没有完整预测对象时计算“管理层准确率”。

接纳条件是任何将改变格力 H-A/H-B、cash bridge 或资本配置判断的陈述，都能明确归入上表、连到唯一来源/时点，并留下对应的后续 observation 或保守 `UNKNOWN`。达不到时，它仍然有研究价值，但价值是提出更好的问题，而非支持结论。
