# Turtle 企业经营判断训练方案

状态：`ACTIVE_HISTORICAL_TRAINING / RESEARCH_FIRST / NO_PRICE_PROXY`

> 目标不是训练一个更会写报告、预测下一季 EPS 或解释股价的 agent；而是训练一个能同时像经营者、行业专家和长期所有者那样判断企业的研究者。格力只是压力测试台，不是训练计划的中心。

本文件是现有[判断力飞轮](TURTLE_JUDGMENT_FLYWHEEL.md)之上的训练总纲。它不替代既有 PIT、竞争机制、结果采集与学习协议；它规定这些工件共同训练的**对象**是什么。不同决策域如何选择原件、何时停止，见[企业经营判断取证路线](TURTLE_ENTERPRISE_JUDGMENT_SOURCE_ROUTING.md)。正式公司研究、估值和投资行动后置。

运行时通道、抽样、留出、状态上卷及黄金报告接线以[历史优先训练架构](TURTLE_HISTORICAL_FIRST_JUDGMENT_TRAINING_ARCHITECTURE.md)为准。这里的“训练”是判断方法、研究上下文和反馈资产的系统学习，不表示本仓库正在更新基础模型权重。

## 1. 要训练的不是三个人格，而是一条经营因果判断

```text
企业的当前状态
  → 管理层可选决策与实际资源承诺
  → 客户、组织与竞争者的反应
  → 单位经济、现金转换与资本占用
  → 增量资本回报、资产负债表韧性与长期所有者结果
  → 结果复盘改变下一家公司的判断方式
```

| 视角 | 需要回答的问题 | 不能退化成 |
|---|---|---|
| 经营者 | 真正的瓶颈是什么？可选方案、资源、组织能力和激励分别是什么？若我负责，应做什么或不做什么？ | 复述管理层战略口号。 |
| 行业专家 | 客户为何选择、价值链谁有议价权、竞争者为何及如何回应、利润最终落在何处？ | 行业排名、市场规模或静态护城河标签。 |
| 长期所有者 | 增量投入是否改善可分配现金、资产负债表和资本回报；机会成本与永久损失边界在哪里？ | EPS、短期利润率或市场价格。 |

三种视角先汇入同一张**企业经营系统图**，再围绕其中一个 `decision episode` 交叉验证。决策卡不是公司本身，而是对系统关键连接的局部实验。比如“降价扩渠道”不是一个营销事件：经营者要说明为何此时投入、替代方案和组织承受力；行业专家要说明对手、渠道与客户会不会跟随；所有者要说明新增量、价格实现、营运资本和回报是否足以覆盖所占资本。更重要的是，三者要在同一张图中看到：这些变化如何反过来改变产品、库存、渠道信用、融资和下一轮资源选择。

## 2. 核心判断命题

训练的最小命题不是“公司会增长”，而是：

> 在给定状态与约束下，这项决策比可行替代方案更可能改善（或损害）企业的长期经济质量；它会先改变哪些可观察变量，何时应承认判断错误？

“长期经济质量”固定从四个互相约束的面观察：

1. **客户价值与需求质量**：客户为什么购买、复购、流失或转移；不能只看收入。
2. **单位经济与组织执行**：量、价、组合、成本、交付能力、营运资本和质量控制如何共同变化。
3. **行业租金与竞争反应**：谁能模仿、反击、提价、占据渠道或改变规则；不能把公司动作当成行业结果。
4. **资本配置与所有者结果**：新增资本的用途、回收、替代成本、负债韧性和现金可得性；不能把会计利润直接当作可分配现金。

下一季业绩预测可以是其中一个传感器，但从不作为训练目标。它只在能够区分机制时进入观察合同。

## 3. 训练的最小单位：企业经营判断卡

每个 episode 使用一张[企业经营判断卡](../../../templates/research_enterprise_judgment_card.md)。它把现有机制实验卡与微演练卡的内容收拢为七段：

```text
状态与瓶颈
→ 可选决策（包括不作为）
→ 实际决策、资源承诺与激励
→ H-A/H-B 的竞争性因果链
→ 对手/客户/组织的反应
→ 早期经营信号与终局资本后果
→ 结果复盘与下一对象的冻结前改变
```

卡不要求管理层能力打分，也不假装能够观察未发生的反事实。它把判断分为两个不能混淆的问题：

- **决策质量**：在当时信息、约束和可选项下，决策逻辑是否自洽，是否处理了重大下行、资源和激励冲突？
- **经济效果**：后来的经营序列是否支持它通过预写传导链产生作用？若缺少可比对照，只能写 `CONTRIBUTORY / INSUFFICIENT_ATTRIBUTION`，不能宣布“该决策造成了结果”。

这使 agent 能学习企业判断，又不会把幸存者结果或事后管理层解释误当因果证明。

### 3.1 经营归因的五层证据顺序

每张卡在写 H-A/H-B 前，先把已经读到的材料放进下列五层。后层不是“更多材料”，而是对更强经济判断的必要对象；不能由前层的漂亮叙述越级。

```text
1. 状态：哪些约束、技术、政策、客户偏好或行业需求是共同条件？
2. 行动与控制：谁做了什么不可逆承诺；谁实际控制哪个责任单元？
3. 责任单元结果：该单元的收入、利润、营运资本和现金如何变化？
4. 客户/项目桥：哪项买方投入或管理选择，实际改变了哪个客户、产品、渠道或项目？
5. 单位经济与现金：价格、成本、服务责任、回款与资本占用能否在同一对象上闭合？
```

| 已有最高层 | 可以严谨地说 | 仍不能说 |
|---|---|---|
| 1. 状态 | 这是共同背景、必要约束或候选反方。 | 某企业因它而优于对手。 |
| 2. 行动与控制 | 资源承诺、责任边界和可行替代确实存在。 | 承诺已经产生客户或经济效果。 |
| 3. 实体结果 | 正确经济对象的经营状态改善、恶化或混合。 | 变化由该项行动造成。 |
| 4. 客户/项目桥 | 某条机制获得可归属的早期经营支持。 | 单位经济、现金或资本回收已经成立。 |
| 5. 单位经济与现金 | 对该决策的经营经济后果形成有限、带边界的结论。 | 管理层总体优秀、规律已普适或投资一定成立。 |

R-47/R-48 分别把“技术/质量”与“服务影响选择”停在状态层；R-49 把服务网络停在行动层；R-45 把公开集团资料停在错误的责任边界之外；R-46 允许读取受控实体结果，但仍要求客户/项目桥才讨论协同。这一顺序的价值是：`UNKNOWN` 不再只是缺字段，而是明确下一次研究应补哪一层，或应停止。

### 3.2 企业经营系统图：从局部机制回到完整企业

单箭头的严格性是必要条件，却不是公司判断。完整企业不是“客户、组织、竞争、现金”四篇独立小报告，而是一个会相互反馈的系统：客户价值决定产品与渠道的质量，活动系统决定能否以可承受成本交付，竞争者和供应商会重分租金，增长又会通过应收、存货、资本开支和融资反过来改变下一次资源选择。

因此每个新公司/行业研究先建立一张[企业经营系统图](../../../templates/research_enterprise_operating_system_map.md)：

```text
客户/行业状态
  → 产品价值与价格实现
  → 研发、制造、渠道、服务、组织的活动系统
  → 单位经济与竞争回应
  → 营运资本、资本开支与融资
  → 再投资能力和下一次管理选择
```

图中只保留 2–3 条对中心经济问题最关键的反馈回路，并让 H-A/H-B 都覆盖四个系统面。随后每张 decision card 必须声明自己验证这张图的哪一条箭头、哪些系统面仍不能替代。结果出来后只追加“系统重组”记录：哪个连接获得支持、哪个仍未知、因而下一张卡应研究什么。**没有系统图，单机制卡不能升级成公司判断；有系统图，也不能用它填补卡所缺的事实。**

这不是增加一层叙事。它防止两种相反错误：把几十张局部卡拼成“公司很强”，或从一张漂亮卡抽出“扩产/服务/出海总是有效”的格言。R-25 与 R-52 的对比正是例子：它们共同要求现金与资本回收独立结算，却因需求/有效供给和产品经济状态不同而呈现不同的产品结果。系统图让这种条件关系先出现，再决定下一张卡验证什么。

## 4. 两个速度不同、但共享同一语法的学习循环

| 循环 | 材料与节奏 | 训练价值 | 不能声称 |
|---|---|---|---|
| **历史刻意练习** | 中国为主的 archive episode；先冻结 cutoff 前材料，再打开隔离的结果包。海外只做明确的边界/近失效角色。 | 高频训练状态重建、角色反转、反方、测量边界和复盘。 | Turtle 的实时命中、准确率或中国参数。 |
| **真实前瞻验证** | 对结果尚未发生的少量正式 episode 冻结经营信号和结果合同。 | 检验训练后的纪律能否在未知结果环境中保持。 | 单次结果证明判断优势或概率校准。 |

二者共享同一张判断卡、同一 H-A/H-B、同一结果合同和同一误差分类；区别只在结果是否对当前研究者未知。历史练习不能因“结果以后已经存在”而停止，真实前瞻也不能因等待而成为唯一训练来源。

实现上再拆出 `HISTORICAL_HOLDOUT` 与 `HISTORICAL_TEACHING`：前者在方法冻结后只评价、不回写；后者只提供边界与禁止替代。四条通道由 `judgment-training-program.v1` 管理，任何实时通道的 `WAITING_EXTERNAL` 都不得上卷成训练总系统 `blocked`。

## 5. 每次训练的固定动作

### 5.1 先还原经营现实，再读解释

第一遍只接触冻结的状态、行动和量/价/成本/现金事实；先写自己的企业诊断。第二遍才读管理层、原作者或媒体的归因，并把它们视为待检验主张。事实与解释无法隔离时，降为 `CONTEXT_SEPARATION_NOT_ASSURED`，可作教学，不能作为独立判断训练证据。

### 5.2 经营者式的替代方案

每张卡至少比较：实际决策、最强可行替代方案、维持原状。对每一方案写清：需要的资源、组织能力、不可逆承诺、激励冲突、最早失效信号及停止条件。没有可行替代方案的“战略评价”只是复述，不能进入因果判断。

### 5.3 行业专家式的竞争回应

不只问公司能做什么，还问客户、渠道、供应商、竞争者与监管会如何回应。竞争回应不是额外的风险段，而是 H-A/H-B 的必要箭头；若看不到其来源或同一 arena 的结果合同，保持 `UNKNOWN`。

### 5.4 长期所有者式的资本传导

每个关键决策都要写它占用了什么资本、会先影响哪一项现金或资产负债表变量、以及什么观察会否定“增量回报改善”。价格、目标回报和买卖动作不进入本卡；它们只可在公司判断成熟后接入独立投资层。

只要机制涉及渠道、结算或营运资本，现金判断还必须分开 `collection_cash / inventory_cash / supplier_finance / external_financing`。保险、信用证、保理、票据或共管账户不是现金结论，而要分别说明它改变的是损失保护、收款速度、融资可得性还是停发货权；公司对流程的描述也只能是待结果验证的主张。这样，正 OCF既不会被误读为客户回款，也不会因应收仍在增长而抹掉真实的库存周转改善。

### 5.4.1 产能、纵向一体化与新品的独立传导

当实际决策是建厂、扩线、关键部件自制、自动化或新品推出时，不能让“产能、销量、专利、技术合作或总 OCF”直接代表能力。卡必须沿着 `resource_commitment → output_absorption → unit_economics → working_capital_cash → capital_return` 逐段结算；整机/部件、内部/外部销售以及现金来源保持分开。没有项目或责任单元的资本占用、分期/外购等真实替代及两期结果，只能对某条经营传导作结论，不能评价最优资本配置。

对新品，另加一条来源纪律：行动/用户问题的当期原件，必须和未来的采用、单位经济及现金结果来源分离；后验招股书、企业史或成功叙事只能用于候选索引，不能倒推 cutoff 或生成预测。

R-25 与 R-52 给出了一组必须共同保留的状态边界：成熟供给压力下，扩产即使被出货吸收，部件经济也可能恶化；技术路线转换中，即使产品价格下行，成本/性能和客户采用仍可使产品毛利改善。两者都没有让项目现金或资本回收自动成立。故“价格方向”不是 verdict，而是与产品单位经济、应收/存货/应付、资本开支和融资一起冻结的条件。

### 5.4.2 创新能力的训练：从一次产品判断到可学习的经营循环

“做出一个新品”与“形成创新能力”分层处理。前者仍须通过产品采用、单位经济、现金和资本占用来判断；后者还必须观察公司把客户/成本/服务的反馈转化为下一次取舍——扩大、修改、转向或停止——并在另一个预先独立的产品或客户段接受同样检验。

```text
问题与替代 → 试验/资源承诺 → 首批采用与反馈
→ 单位经济/服务负荷 → 下一次保留、修正或停止的选择
→ 第二条独立产品/客户链的有限复现
```

这不是要求公司连续推出成功产品，也不把同一公司两次表现当成独立样本。它只让 agent 学会区分：一次增长到底来自产品、价格、渠道、补贴或需求周期，还是存在一个会从反馈中改变下一次资源配置的经营循环。若只有收费/合同规则、ARPU 与同产品毛利，卡只能得出 `PRODUCT_MONETIZATION_MECHANICS_OBSERVED`；若再有同 cohort 的采用和产品经济，才可得出 `PRODUCT_ECONOMICS_OBSERVED`；没有“反馈 → 下一次选择”的当期证据，不得升级为 `CAPABILITY_OBSERVED`。第二条链也必须保留第一次的失败边界，之后才能由不同中国对象做机制迁移测试。

质量/服务类决策同样不得只读品牌或财务结果。其两条臂是 `quality_or_service_commitment → field_reliability_or_service_demand → per_unit_service_cost_or_liability`，以及 `quality_or_service_commitment → customer_or_channel_choice → price_realization_or_retention`；两者再共同进入现金与资本回报。缺其中一臂，不能称服务投入创造了质量护城河，也不能从一个服务准备金判断它摧毁了经济性。

### 5.5 预演失败与双边结算

冻结前先做 premortem：假定该决策失败，分别写出最可信的失败路径和最早信号。再将其整理成能解释共同事实的 H-A/H-B，而不是乐观/悲观措辞。早期信号只结算一条箭头；终局经营结果才结算较完整的机制，且两者都不能由股价替代。

### 5.6 双环复盘

结果后先保留原卡，再追加两条正交记录：企业经济链的错误位置为 `STATE / DECISION / MEASUREMENT / MECHANISM / TRANSMISSION / ENVIRONMENT`；研究设计的失败位置为 `STATE_REPRESENTATION / MECHANISM / EVIDENCE_ACQUISITION / FINANCIAL_TRANSMISSION / VALUATION_DECISION`。前者不等于后者：例如客户反应不及预期是经济链问题，不自动说明证据采集失败；指标不可重建是测量问题，也不自动说明企业机制为假。复盘必须通过 `LNOTE → method review → learning-application receipt` 改变下一家**不同中国对象**的一个冻结前字段：问题、替代方案、反方、信号、计量合同或停止规则，并由独立 reviewer 确认。仅写“更谨慎”不构成学习。

## 6. 训练组合：按机制与决策类型，而非按公司堆积

训练队列先覆盖下列五个决策域；每一域的公司只是载体：

| 决策域 | 典型经营问题 | 首要结算对象 |
|---|---|---|
| 客户、产品与渠道 | 产品改善、定价、服务、渠道重构是否改变客户行为？ | 交易量、复购、价格实现、渠道质量。 |
| 运营与组织 | 自动化、供应链、门店/产能、组织改造是否改善单位经济？ | 交付、单位成本、质量、周转与现金转换。 |
| 竞争与行业结构 | 扩张、降价、开放/封闭接口会让谁取得租金？ | 同 arena 的量价、份额、让利、库存或渠道反应。 |
| 创新与能力建设 | 研发、品牌、数字化或平台投入是否形成难模仿能力？ | 产品采用、客户留存、交付能力、替代速度。 |
| 资本配置与治理 | 再投资、并购、分红、回购、去杠杆是否提高长期所有者结果？ | 资本占用、回收、现金可得性、资产负债表韧性。 |

一个小批次优先采用 `1 + 1 + 1`：一个 focal、一个只翻转关键中介条件的 near miss、一个只改变外部边界的 replication。三者必须先有结果前的共同条件与同口径结果合同；缺一个，宁可做单卡练习，也不伪造批次。

## 7. 正式研究前必须完成的准备

准备的目的不是建设更厚的框架，而是让第一张卡一开始就能产生干净反馈。对每个新公司，经营系统图是卡片入场前的最小综合面；以下是唯一的准备出口：

| 准备物 | 完成定义 | 不做什么 |
|---|---|---|
| **训练宪章** | 写清本方案的目标、四个经济质量维度、非目标和中国主训练域。 | 不写企业“好坏”评分或价格判断。 |
| **企业经营系统图** | 先界定客户/行业、价值捕获、活动/组织、现金/资本及 2–3 条 material feedback loops；每个 decision card 回链其中一条。 | 不把系统图写成概览性公司史，或用它补全缺失的单卡事实。 |
| **统一判断卡** | 有状态、替代方案、实际承诺、反方、竞争回应、资本传导、结果合同和 learning application 的同一页面。 | 不新增平行账本、概率或模型接口。 |
| **机制—决策分类图** | 用上节五个域标记候选卡，避免同一公司/同一问题无限扩读。 | 不按报告数、知名度或材料多少排队。 |
| **事实/解释双包规则** | 第一遍只交付可量化状态切片；第二遍才交付归因；结果包隔离。 | 不以“我会忽略解释”代替隔离。 |
| **结果合同与误差词典** | 每张可结算卡在 cutoff 前有指标、窗口、允许来源、禁止代理和六类错误归因。 | 不在见到结果后换 KPI、改阈值或补来源。 |
| **独立阅读角色** | curator 负责事实切片，研究者负责判断，红队负责反方，结果 reader 只在冻结后读取结果；同一 agent 若先看到结果，卡必须降级。 | 不把 agent 数量、投票或格式审计当作独立性。 |
| **首轮候选地图** | 至少标出不同决策域的中国候选、近失效/边界候选及其准入缺口；尚未达到合同者留在 `QUESTION_ONLY`。 | 不因准备好地图就进入公司深研。 |

准备完成后立即开始小型 archive 微演练；不再为了“更完美的准备”新增 schema、validator、案例库或公司 chronology。只有首次运行实际暴露材料性失败，才修改公共流程。

## 8. 训练与验证阶梯

| 阶段 | 真正检验什么 | 可以说什么 | 不能说什么 |
|---|---|---|---|
| A. 判断动作 | 能否从事实写出状态、替代方案与非嵌套 H-A/H-B。 | agent 会提出更可检验的问题。 | 判断正确、管理层优秀。 |
| B. 单箭头复盘 | 早期经营信号是否支持、削弱或暴露测量错配。 | 某信号保留、缩小或废弃。 | 整个公司机制获胜。 |
| C. 决策机制 | 终局经营观察是否符合预写的决策—反应—资本传导。 | 本案的传导获得支持、反驳或不可判。 | 决策的严格因果效应或普遍规律。 |
| D. 迁移学习 | learning note 是否改变不同中国对象的冻结前字段，并再次结算。 | 某条件或信号的适用边界变得更清楚。 | 方法已产生一般优势。 |
| E. 真实前瞻 | 未知结果的正式 episode 是否保持同样纪律。 | 有限的外部有效性证据。 | 基准率、胜率或完整投资能力。 |

“提升判断力”的可见证据因此是：更早找到瓶颈、更少把共同现象当因果、更能指出错误在哪一箭头、以及每次复盘确实改变下一题。不是报告篇数、资料页数、信心强度或价格表现。

3. 每张新卡必须先说明它填补的“决策域 × 状态 × 机制叉”，并配一个近失效或边界角色；没有 cutoff 前一手行动和同口径结果合同，保持 `QUESTION_ONLY / NO_PRIMARY`；
4. 对信用/现金主题，直接使用已沉淀的双链，而不是重新从保险、票据、OCF或终端名称推断；
5. 少量真实前瞻 episode 继续作为外部验证，不取代历史训练；其到期后才可能为 `L1+` 提供证据；
6. 公司判断成熟后，才由独立投资层引入估值、价格与行动。

历史教学、档案化结果已知案例和状态图不等待实时 CJO 的结果采集；它们用于训练替代方案、机制边界和测量纪律。生产 CJO 已要求 `post-cutoff outcome acquisition` 的 raw/reader、读取审计和 extraction；只有测试 fixture 可使用合成的手填观察，后者绝不构成实时飞轮反馈或判断力的外部验证。

格力仍是压力测试池：它可用于检查数据噪声、现金边界与竞争机制，但不因历史材料多而抢占训练容量。

## 10. 方法依据

- 过程追踪要求用因果序列中的诊断性证据检验机制，支持“状态—决策—传导—观察”的卡片结构。[Collier (2011)](https://doi.org/10.1017/S1049096511001429)
- 企业的整体性需要活动系统、商业模式、存量/流量反馈与协调行动同时被看见：Porter 强调活动之间的 fit；Teece 将商业模式界定为价值创造、交付与捕获的架构；Sterman 把存量、流量、时滞和反馈用于商业系统；Rumelt 则将策略收束为诊断、指导方针与协调行动。[Porter (1996)](https://hbr.org/1996/11/what-is-strategy)、[Teece (2010)](https://doi.org/10.1016/j.lrp.2009.07.003)、[Sterman (2000)](https://web.mit.edu/jsterman/www/pub.html)、[Rumelt (2011)](https://www.penguinrandomhouse.com/books/208668/good-strategy-bad-strategy-by-richard-rumelt/9780307886231/)。它们支持先画系统、后选关键箭头，不允许用系统语言取代一手经营事实。
- 动态能力框架把企业能力概括为识别、抓住机会与重构资源，支持经营者视角必须落在具体资源承诺与组织变化上。[Teece (2007)](https://doi.org/10.1002/smj.640) [Helfat & Peteraf (2003)](https://doi.org/10.1002/smj.332) 与 [Zollo & Winter (2002)](https://doi.org/10.1287/orsc.13.3.339) 进一步支持把能力看成可形成、分支与从反馈中更新的过程，而非静态护城河标签。
- 专业判断需要有规律的环境和及时、清晰的反馈，支持把长期结果拆成早期机制信号与终局经营结果。[Kahneman & Klein (2009)](https://doi.org/10.1037/a0016755)
- 多重解释、结果偏见防护和刻意练习，支持反方、冻结复盘和“下一题必须改变”的双环学习。[Hirt & Markman (1995)](https://doi.org/10.1037/0022-3514.69.6.1069)、[Baron & Hershey (1988)](https://doi.org/10.1037/0022-3514.54.4.569)、[Ericsson et al. (1993)](https://doi.org/10.1037/0033-295X.100.3.363)

这些文献只支持方法选择，不替 Turtle 证明任何公司结论或判断优势。
