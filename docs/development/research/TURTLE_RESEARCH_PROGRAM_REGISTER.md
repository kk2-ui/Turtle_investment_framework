## 2. 样本选择规则

每个实验开始前选择样本，不以已知的后续经营结果、股价、投资回报或“故事精彩程度”选择。选择记录必须说明：

- 该对象为何暴露目标方法盲点；
- 在当时公开且可取得的最小材料范围；
- 它与格力或前一实验在哪些关键维度不同；
- 若结果已广为人知，如何仅把它作教学/反例而不倒灌为历史判断。

优先选择公开一手材料足够、经济边界清楚、但与格力机制不同的对象。若找不到，实验维持 `BLOCKED`；不得以继续阅读格力替代迁移复验。

若要把对象组成判断力飞轮批次，先按[公司经验积累协议](TURTLE_COMPANY_EXPERIENCE_ACCUMULATION_PROTOCOL.md)确定一个空白机制状态格、其 `NEAR_MISS` 与 `BOUNDARY_REPLICATION`；资料可得性只是三者都能入场的硬门，不是选择理由。显式飞轮批次必须是三家不同公司，近失效除上游中介外保持同一状态，边界复验只改变外部边界条件；配不齐即保持 `BLOCKED`，不以更多格力材料替代。

## 4. 准入与退出

### 准入

实验仅在以下条件同时满足时启动：

1. 方法盲点会材料性影响公司经营、现金、资本配置或永久损失判断；
2. 有一个清楚的反例或旧方法对照；
3. 可写出停止当前对象研究的条件；
4. 若实验初步成功，已有不同对象的复验方向。

### 退出

实验在作出 `RETAIN / MODIFY / REJECT / INSUFFICIENT_TEST` 后结束。研究者随即选择迁移复验、等待缺失数据或关闭该方法；不以“再找一些资料看看”延长实验。

## 5. 本阶段完成定义

研究准备工作完成，不等于任何方法已经被验证。它意味着：

- 研究对象、流程、模板、语言和停止规则已经就位；
- 已有一个不依赖格力持续深挖的实验队列；
- 每个新研究工作都能从方法假设进入，并以方法裁决或保守的 `INSUFFICIENT_TEST` 退出；
- 报告和投资研究不会抢在方法学习之前主导方向。

任何新对象只在满足相应准入条件后启动；当前优先是等待并执行 R-54 的首个客户/竞争反应与现金时钟。它不能生成选择学习；下一条真正的中国选择 episode 仍须在结果前通过 R-07，而不是继续补充格力材料。
