# Turtle 判断力飞轮

状态：`CORE_METHOD / RESEARCH_FIRST / NO_PRICE_PROXY`

目标不是累计报告、案例、数据或“正确观点”，而是让每一轮公司研究都留下一个可迁移的判断改进：下一次更早看见真正的机制分歧、更少把噪声误作因果，并在错的时候知道究竟该改什么。

## 飞轮本体

```text
第一性原理的经济问题
        ↓
竞争机制：同一当前事实的 H-A / H-B
        ↓
少量有方向差异的经营观察 + 结果来源契约
        ↓
冻结：事实边界、反方、选择资格、简单基线
        ↓
结果到来后的逐箭头结算
        ↓
误差归因：事实 / 测量 / 机制 / 传导 / 环境
        ↓
更新问题、信号、反方或停止规则
        ↓
在不同公司、行业、状态中复验条件与断裂
        └────────────────────────────→ 下一轮第一性原理问题
```

它是一个研究—反馈机制，不是报告生产流水线。任何一环的正确产出都可以是 `UNKNOWN`、`NO_PRIMARY`、`NOT_DIAGNOSTIC` 或停止；这些不是飞轮失败，而是避免错误确信的反馈。

按不同决策域把这条机制落到可读原件，见[企业经营判断取证路线](TURTLE_ENTERPRISE_JUDGMENT_SOURCE_ROUTING.md)。

## 每一环具体产生什么

| 环节 | 研究者实际做的判断 | 可沉淀的对象 | 不能偷换成 |
|---|---|---|---|
| 经济问题 | 找到会改变盈利能力、现金转换、资本配置或永久损失边界的一条因果问题。 | 决定性问题、状态向量。 | “这家公司好不好”。 |
| 竞争机制 | 先生成可信机制、说明合并/排除，再让最有信息量的 H-A/H-B 对现有事实给出不同顺序。 | 假设空间筛选、机制链、最强反方、未知箭头。 | 主叙事加风险清单，或把二元 pair 当作世界只有两种解释。 |
| 信号与来源 | 选能让两方分叉的经营观察，并定义交易点、口径、窗口、结果源及结果期的指标—官方披露映射。 | A-only/B-only 观察、source/metric continuity contract。 | 多份相同口径的资料、一个漂亮指标，或到期后以相近 KPI 替换原指标。 |
| 冻结 | 固定当时材料、机制、阈值、候选机制集合和基线。 | PIT episode。 | “我们当初大概是这么想的”。 |
| 经营结算 | 先完整枚举结果期候选源，再从已读 raw/reader 中逐字提取同口径观察；只让该生成物更新对应箭头。 | `SUPPORTS_* / MIXED / NOT_DIAGNOSTIC`。 | 手填实际值、挑选有利首发/修订、股价、总回报或管理层解释。 |
| 误差归因 | 判断错在事实、测量、机制、传导还是环境结构变化。 | append-only learning note、停用/保留规则。 | 以结果好坏评判原研究质量。 |
| 跨对象复验 | 把条件、断裂和信号顺序带到不同对象。 | 结构化类比、近失效条件、方法复盘。 | 复制名家结论、案例结局或估值倍数。 |

## 飞轮如何真正提升判断力

判断力不会因资料增加自动提高；它只通过以下四个累积效应变强：

1. **问题更锐利**：模糊的“竞争力变强/变弱”被压缩成能被后续观察拒绝的机制问题。
2. **选择更诚实**：没有 cutoff 前方向性依据时保留 `NO_PRIMARY`；有中心路径时必须保留候选机制、反方、来源谱系及一个预测不同的简单基线。
3. **反馈更快**：3–5 年的经营终局被拆成 6–12 个月、只结算一条箭头的早期信号；早期错误不再等到故事写完才被发现。
4. **错误可迁移**：结果不覆写原判断，而是把“该信号在什么条件下失效”“哪个结构断裂最关键”带到另一家公司复验。

因此，飞轮的速度不由报告数量决定，而由**高质量、可结算、跨对象的错误反馈**决定。一个没有诊断性的信号或一条被拒绝的档案，也会让飞轮变强：它明确了下次不能再用什么。

## 企业现金判断的两条链

收入、净利和 OCF 都不是“客户现金”或 owner cash 的同义词。凡是把渠道、营运资本或资本承受力作为机制箭头的卡，必须同时回答两条不能互相替代的链：

```text
信用与控制链：
counterparty_chain_identity
  → contractual_control
  → realized_collection
  → independent_verification
  → cash_conversion

现金来源链：
collection_cash / inventory_cash / supplier_finance / external_financing
```

- 保险、信用证、保理、票据、共管账户或知名终端，最多是 `contractual_control` 的候选输入；它们各自究竟改变 `loss_protection / collection_speed / funding_effect / shipment_authority` 的哪一项，必须由条款与结果期观察分别说明。
- OCF 转正必须指出主要来源。`inventory_cash` 可以是货真价实的流动性改善，却不能被写成客户回款；`supplier_finance` 或 `external_financing` 也不能被写成经营自立。
- 同一公司年报对流程的解释只是一条公司主张。只有实际收款、合同期、独立审计或可复读的第三方证据，才能把它提升到 `realized_collection` 或 `independent_verification`。
- 任一中间节点未知时，保留对应的 `UNKNOWN`；不能用后来的坏账、没有坏账、年末现金或股价跳过链条。

这不是额外的财务评分表，而是企业家、行业专家和所有者共用的一个问题：**谁拥有终端现金的权利，现金何时真正到公司，代价由谁承担？** R-21–R-24 的中国渠道案例仅提供这条链的教学边界，尚不构成任何行业参数或方法胜率。

## 产能与能力建设的五段链

重资产、关键部件自制、自动化或新品扩线，也不能以“产能、销量、技术合作”三项跳到经济结论。凡是以扩产、纵向一体化或能力建设作为主机制的卡，必须按此顺序回答：

```text
resource_commitment
  → output_absorption
  → unit_economics
  → working_capital_cash
  → capital_return
```

- `output_absorption` 只问真实需求是否接住新增能力；销量增长并不自动说明价格、成本或回报改善。
- `unit_economics` 必须将整机与部件、内部与外部销售、价格与成本分开；若没有责任单元口径，保持 `UNKNOWN`。
- `working_capital_cash` 必须沿用现金来源拆分；总 OCF、年末现金或融资不能证明项目 owner cash。
- `capital_return` 需要项目/责任单元的资本占用和至少两期结果；缺外购/分期的真实替代及这些资料时，只能评价某一传导箭头，不能判“扩产优于替代”。

R-25 只提供该链的教学边界：空调出货被吸收与压缩机单位经济受压可以同时为真。它禁止把后来行业集中度、技术合资或规模地位改写成资本配置正确。

## 质量与服务的双臂链

更长保修、质量体系、筛检、售后网点或“用户满意”都只是投入/承诺，不是产品可靠性或品牌经济性的证据。质量/服务卡至少要让两条相连、但不可互相替代的臂分别落地：

```text
质量/服务承诺
  → field_reliability_or_service_demand
  → per_unit_service_cost_or_liability

质量/服务承诺
  → customer_or_channel_choice
  → price_realization_or_retention
```

两臂最终才共同连接 `working_capital_cash → capital_return`。如果公司只披露收入、毛利、奖项或总维修费用，不能跳过故障/返修、每台服务成本和客户/渠道选择；若竞争者跟随承诺，还必须把它视为可能的共同成本或机制分界，而非服务差异已获确认。

R-27 的格力压力测试没有通过这个门：动作清楚，产品收入和毛利也可见，但故障率、同定义服务成本和客户响应没有被公开。故它只能完善问题，而不产生“质量取胜”的历史结论。

产品/技术组合则在上述两条臂以外另加 `gross_margin_bridge`：`price_or_mix / unit_cost / channel_and_service_cost / working_capital_cash / capital_return`。R-28 的华帝案例显示，产品级毛利改善能够成立，同时因渠道、采购、自制与销售费用共同变化，仍不足以说明高端化已创造 owner cash。

## 三条运行纪律

### 1. 公司、数据与案例只是燃料

- 格力是压力测试：它暴露噪声行业数据、会计边界、现金质量和资本配置传导的难点；它不占据飞轮中心。
- 20 多份格力材料只在被压缩为有来源谱系的状态/机制 episode 时提供燃料；同一事实的重复转述不增加经验。
- 奥维等行业资料可作为边界清楚的 `SENSOR`；不准确或无同口径定义时保留分歧，不取平均，更不逼出结论。
- 书籍和著名案例只提供候选条件与近失效问题；只有“同期原始机制—独立经营结果”链才可沉淀为外部结构经验。

### 2. 选择、信号、投资结果三层分轨

```text
选择资格：当时为什么可选 H-A，而不是 H-B？
       ↓
机制信号：后来经营观察支持哪条箭头？
       ↓
终局经营：收入、单位经济、现金与资本配置如何实现？
       ↓
（独立投资层）价值、价格、回报与行动
```

信号支持 H-A 不自动证明研究者当时有资格选 H-A；单一选择 episode 也不构成准确率或胜率。市场价格只属于最后的独立投资层，不能倒灌前三层。

### 3. `UNKNOWN` 是控制阀，不是待补充的空白

`MISSING_OBSERVATION`、`MEASUREMENT_MISMATCH`、`MECHANISM_NONDIAGNOSTIC`、`NOT_YET_DUE` 与 `PIT_BLOCKED` 各自对应不同动作。正确动作可以是请求资料、改口径、停用信号、等待或终止，不允许用更多叙述跨过它们。

| P-44 结果暴露边界 | 只有已到期、进入冻结 claim 的结果 source 才可被读取和提取；非 claim 的中间业绩或“脉冲”保持未读，已读则退出判断力学习样本。 | 把不结算的中间结果当背景，同时声称它没有影响后续解释。 |
| P-45 暴露状态的反馈门 | 轻量前瞻结算必须读取与 read audit 对齐的暴露证明；无非 claim 暴露才可产生 learning cards，breach 只保留管线结算。 | 只在文档中写“暴露后不学习”，但仍让程序产出 learning note。 |
| P-46 L5 cohort 预注册 | 多个已选择、未到期的不同公司 terminal FJ 必须在结果前绑定一个完整 selection register cohort；入选、`NO_PRIMARY` 与不可比对象都留下处置，入选单位逐一保留。输出只保留选择结果与相对简单基线的非价格计数。 | 到结果出来后删除不利或不可判定 episode、以 early signal 冒充终局、换聚合口径，或将几个计数写成方法胜率/总分。 |
| P-47 L5 独立身份绑定 | L5 的 `company_cluster_id` 必须来自同一 frozen selection register 的 canonical company cluster；同一公司、case、claim 都只能出现一次。 | 用不同 period 或自由标签把同一公司重复计入“多个独立 episode”。 |
| P-48 selection entry → case 绑定 | 未来 L5 的 selected case 在 freeze 时就要保留与 register 的 entry/company/cluster receipt；cohort 只能消费逐字段一致的 receipt。 | 在结果期将同公司另一个机制、FJ 或 case 重新挂到更有利的 selection entry。 |
| P-49 选择覆盖与方向比较分轨 | L5 同时显示冻结 screen 中的入选、`NO_PRIMARY` 与不可比计数；方向比较仅条件于入选 terminal units，三者不合成方法分数。 | 靠对困难对象弃权来提高条件方向表现，再把它误称为总体判断力。 |
| P-50 `NO_PRIMARY` receipt | 只有同一 frozen register entry 的 `NO_PRIMARY` case 才计作 L5 弃权；无 receipt 的筛除只能是不可比。 | 结果期把任意未研究/不利对象命名为“当时谨慎弃权”。 |
| P-51 `STRUCTURE_FIRST` 类比 | 先独立抽取 target/source 的因果骨架，再写匹配理由、断裂与近失效；无法隔离 source context 时降为问题路由。 | 让品牌、行业名、规模、名家故事或已知结局先决定“为何相似”，再用机制语言合理化。 |
| P-52 类比交接收据 | target/source mapper 只读各自的 cutoff 前 packet；integration 只能对齐已冻结草图，reviewer 记录真实的 context 状态。 | 把“先结构”写在模板里，却在原始阅读中互相灌输 source 故事、结果或期待答案。 |
| P-53 假设空间筛选 | 在选 H-A/H-B 前冻结每个实质候选的配对、合并、暂缓或排除理由；可信但不可分叉的第三机制会退回 `NO_PRIMARY`。 | 静默删去第三机制，再把二元结算伪称为穷尽的公司判断。 |
| P-54 候选位移检验 | 只有能解释共同事实且会改变本轮机制、FJ、取证或选择资格的候选才进入机制空间；其余转为独立问题。 | 以无关担忧制造 `NO_PRIMARY`，或把范围外事项误写为已经证伪。 |
| P-55 环境适用边界 | 只有冻结前已定义、会改变 pair 因果顺序/指标含义/可比性的 break 才关闭旧 episode；正常波动仍由 pair 结算。 | 结果不符后以“环境变了”掩盖机制错误，或把真正制度断裂误算为旧机制的输赢。 |
| 行业数据与格力压力测试 | 训练交易点、来源谱系、口径和 `UNKNOWN` 的处理；数值 FJ 只可由冻结 provider/dataset/语义/映射不变的后续版本结算，冲突源只重开机制。 | 数据更多即机制更真，或格力已是通用样本。 |
| 三对象抽样 | 以一个空白状态格、一个只反转上游中介的近失效和一个只改变边界条件的复验，组成三家不同公司的 pre-outcome 批次。 | 三个“资料多”的公司，或同一公司多季材料，已构成独立样本。 |
| learning note 汇总 | 将已结算错误按公司簇和失败位置变成下轮实验。 | 用 note 数量计算胜率或校准。 |
| learning application | 将成熟 learning note 的改变落实到不同公司的下一张迭代卡，并由 reviewer 核对它确实改变了冻结前字段。 | 写过复盘，或在没有真实跨公司反馈时填空字段，已完成双环学习。 |

## 飞轮成熟的可观察证据

不能用一个总分衡量飞轮。它逐步成熟的证据是：

1. 新研究在结果前就能写出更少、但真正不同的机制和观察；
2. 越来越多冻结信号可按原口径结算，而不是到期后改用代理指标；
3. 早期结果能在终局前指出具体错误位置；
4. 同一错误在不同公司簇中被识别后，下一轮模板、取证顺序或禁用项确实改变；
5. 只有累积多个独立、同定义、相对简单基线有不同预测的 out-of-sample 选择 episode 后，才可讨论校准或相对预测表现。

在此之前，最诚实的状态是：飞轮已在运行、会产生可复盘经验，但尚未证明一般性的判断优势。

## 验证阶梯：流程可信，不等于判断已经更强

每轮都要写明自己所处的最高等级；下一级的条件没有满足时，不得借用本级的完成来作更强主张。

| 等级 | 真正被检验的内容 | 可以得出的结论 | 仍然不能得出的结论 |
|---|---|---|---|
| `L0 流程完整性` | PIT 边界、H-A/H-B、反方、来源和计量合同、冻结、拒绝路径是否按设计运行。 | 系统能拦截已知的伪反馈；`NO_PRIMARY`、`UNKNOWN` 与 `MEASUREMENT_MISMATCH` 会保留下来。 | 信号有用、主路径选对、公司结论正确，或研究者判断更强。 |
| `L1 结果采集完整性` | 到期后能否以完整候选源枚举、raw/reader、读取审计和逐字 extraction 取得冻结指标。 | 该一次经营观察没有靠手填值、相近 KPI 或选择性版本结算。 | 观察本身具有机制诊断性。 |
| `L2 单箭头诊断性` | 同一 pair 的早期/终局 FJ 是否按原谓词给出 `A_ONLY / B_ONLY / MIXED / NOT_DIAGNOSTIC`。 | 哪一条被冻结的箭头暂获支持、削弱或不可判定；可修正信号或测量合同。 | 研究者当时有资格选择 H-A，或同一机制能迁移。 |
| `L3 主路径选择` | `SELECTION_ADMITTED` 的非共同证据、已验证主箭头、双方早期信号和不同简单基线，是否在结果前闭合；随后结果如何。 | 一次主路径选择相对其最强反方和公平基线是支持、反驳还是不可判定。 | 一次命中就是能力、概率或一般性胜率。 |
| `L4 跨公司迁移` | 已结算的 `LNOTE → multi-company review → 不同公司冻结前字段改变`，以及新案的同定义结算。 | 一个具体的错误教训确实改变了下一对象的机制、来源、信号或计量边界，并可检验该改变。 | 改变本身已在所有行业有效，或飞轮已有总体优势。 |
| `L5 方法相对表现` | 多个独立 `L3` episode 与相对简单基线，按结果前冻结的样本边界、聚合规则和全部失败/不可判定分母进行比较；显式飞轮 batch 还须逐一保留 universe 内的 `INCLUDED/EXCLUDED` screen entry。 | 仅在完整登记的非价格经营结果下讨论校准或相对表现。 | 以报告数量、单公司多季、价格/回报、事后案例或隐藏的候选筛选代替方法证据。 |

当前状态：P01–P50 的生产门和定向回归、P-51/P-52 的合成类比输入/交接复测、P-53–P-55 的假设空间与环境边界合成复测、P-56 的真实 pre-outcome 筛查、P-57 的候选重入阻断与 P-58 的准备停止规则，都只属于 `L0`；系统的**架构**为 `L0_READY_TO_WAIT_FOR_REAL_FEEDBACK`，但判断训练不是全局暂停。R-05/R-06 已为未来到期的 `L1` 做好合约，尚无真实 outcome；R-09 至 R-12 已在中国历史材料上实际运行“错误 → 改变下一不同公司卡”的微练习链，但因结果为历史、事实/解释隔离并非独立，仍仅是 `L0` 流程学习，不进入 Turtle 准确率。R-03 以 `MEASUREMENT_MISMATCH` 证明了应当停止，不能充当 `L2` 命中；R-07 仍没有 `SELECTION_ADMITTED` 对象，P-56 也确认不能以表面相似 KPI 拼成飞轮 batch，故尚无 `L3`；没有真实跨公司 review，故 `L4/L5` 都是 `NOT_YET_TESTED`。这不是缺少报告，而是缺少不能用文字替代的未来经营反馈。

这条阶梯把四项研究发现落实为操作纪律：Kahneman 与 Klein 的判断专长前提是可学习规律及迅速、清晰的反馈；Hirt 与 Markman 的多重解释要求反方也能被检验；Baron 与 Hershey 说明后见的好/坏结果会扭曲对当初判断的评价；Ericsson 等人把改造下一任务而非仅回顾上一任务视为刻意练习的核心。它们支持飞轮的验证次序，不替 Turtle 证明任何公司机制或方法优越性。[Kahneman & Klein (2009)](https://doi.org/10.1037/a0016755)、[Hirt & Markman (1995)](https://doi.org/10.1037/0022-3514.69.6.1069)、[Baron & Hershey (1988)](https://doi.org/10.1037/0022-3514.54.4.569)、[Ericsson, Krampe & Tesch-Römer (1993)](https://doi.org/10.1037/0033-295X.100.3.363)。
