# 家电四阶段训练 V2：九阳结果前冻结

本轮按既定 roster 的第二家公司机械选择九阳股份（CN:002242），不是按结果、资料便利或预期成功挑样本。截止日为 2018-09-30；冻结前只使用 2018-04-21 已公开的 FY2017 巨潮静态年报。

投资者在结果前能看到的核心张力是：渠道优化、新零售和门店执行确实发生，食品加工机收入小幅增长；但发行人收入近乎持平、经营现金流高度波动，且子公司处置令同口径桥未闭合。因此行动存在不等于行动成功，产品增长也不等于客户忠诚或 owner cash 改善。

相对上一轮，本轮在结果前新增三项解释纪律：

1. `MISS` 必须区分有利向上偏差、向下不利偏差和幅度不足；
2. 食品加工机必须相对发行人收入至少跑赢 5 个百分点，才能成为产品边界信号；
3. 结果期年报披露的上期比较数必须与冻结基线相符，否则同口径趋势保留 `UNKNOWN`，但不撤销其他字段的机械结算。

当前真实 controller 中 Decision、Route、Measurement、Evidence、Prediction 各 3 条，outcome access、inventory、observation、settlement 均为 0。下一步只能是独立结果前审阅；通过前不得开启 FY2018 outcome access。

本对象只允许机械字段结算、机制视图、教学和研究议程。它不授予方法迁移、Comparative、CJO、估值、报告、BuyBand 或投资权限。
