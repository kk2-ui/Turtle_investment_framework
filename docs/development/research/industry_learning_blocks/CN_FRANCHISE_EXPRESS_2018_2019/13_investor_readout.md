# 快递 Round 8 投资者读出

> 状态：`REAL_FEEDBACK_COMPLETED / NO_MATERIAL_METHOD_ADVANTAGE_PROVED / ARCHITECTURE_REVISION_REQUIRED`
>
> 公司与 cutoff：韵达股份 `CN:002120`，`2019-05-01`
>
> 权限：无方法迁移、Comparative、CJO、估值、报告或投资权限

## 这轮在训练什么

这轮不是预测韵达 2019 年利润，也不是评价它是不是好公司。它测试一个更基础的问题：面对同一批 cutoff 前证据，八维企业判断能否比简单公司趋势阅读少犯材料性错误。

八维依次检查初始条件、已实施行动、执行、客户与竞争响应、单位经济、现金与资本、适应与永久损失、最强反方。它们是问题骨架，不是八项打分，也不要求每项都有答案。

## 结果期实际看到了什么

- 公司快递业务量增长 `43.59%`，市场份额增加 `2.02` 个百分点；这证明规模和份额上升，不证明客户忠诚或定价权。
- 经营现金流增长约 `35.57%`，现金资本开支增长约 `26.15%`，OCF/现金资本开支只落在冻结的稳定区间；总部现金不能自动称为 owner cash，也不能代表加盟商现金质量。
- 资产负债率约增加 `3.67` 个百分点；它是资本结构变化，不单独证明永久损失增加或适应失败。
- 2019 年新增派费收入及对应服务成本，令快递收入/票、单票成本和快递毛利率无法与冻结的 2018 口径直接比较，三个单位经济单元保留 `MEASUREMENT_MISMATCH`。
- 年报披露的投诉指标单位是“每百万件”，冻结合同却使用通用比例，因此投诉变化也局部不匹配，不能进入机械评分。
- 年报描述了网络、自动化和加盟支持，但没有把实施时间唯一定位到 `2019-05-02` 之后；执行事件和加盟网络不利事件继续保持 `UNKNOWN`。

15 个结果单元最终为：`6 OBSERVED / 6 MEASUREMENT_MISMATCH / 3 UNKNOWN`。缺失或错配只影响自己的判断单元，没有拖停整份公司反馈。

六个可评分单元的每个原始数值现在还必须经过页级提取收据：系统重新读取官方 PDF 指定页，从披露 token 机械重算数值，再允许进入 acquisition 和 settlement。仅保留合法页码或 locator 已不够；改动原始数值、单位、页码或来源都会在结算前失败。

## 方法比较真正证明了什么

**本轮没有证明 Enhanced 比 Baseline 更好。** 虽然八维审阅最终没有把网络规模和业务量增长写成执行成功，但冻结的 Baseline 只把它们称为“初步执行信号”，并没有冻结“看到规模增长就判定执行成功”的结果规则。两种方法也没有在结果揭示前分别写明怎样从 settlement 推导执行结论。因此，不能事后把谨慎解释记成 Enhanced 的 `AVOIDED_ERROR`。

八个维度均未证明方法增量：

- 初始条件的全国行业指标被错误绑定到公司合并边界，本轮不可诊断；
- 两种方法面对同一批未定时管理行动，没有差异；执行维度因缺少预冻结的双方法 resolution rule 而不可诊断；
- Baseline 已经保留价格、平台流量和客户结构反方，客户/竞争维度没有增量；
- 单位经济的防错来自共享 Measurement Contract，不应记给 Enhanced；
- Baseline 已经区分总部现金、owner cash 和加盟商现金，现金资本维度没有增量；
- 两种方法都把加盟网络韧性和不可逆损失保留为未知；
- Baseline 已经保留行业需求和价格竞争解释，最强反方没有增量。

因此不能说“八维方法整体胜出”，也不能说它已机械避免了一个 Baseline 会犯的错误。本轮真正证明的是：真实字段可以局部结算；八维能系统暴露责任边界、单位、时钟、现金归属和反方缺口；但“发现了缺口”与“经 A/B 证明方法更好”是两回事。

## 八维为什么仍写入顶层设计

八维被采用，是因为它提供了一套稳定的企业研究问题骨架，防止 Agent 漏掉客户、竞争、单位经济、资本承担、适应和反方，而不是因为本轮 A/B 已证明八维方法具有总体优势。采用的是**研究覆盖标准**，不是“八维已验证”的效果宣称。

下一次真正检验必须更严格也更简单：

1. Baseline 必须是独立冻结的简单公司趋势方法，不能复用 Enhanced 的机制问题和反方；
2. 全国行业、平台、加盟商、公司合并主体和普通股必须使用不同责任边界；
3. mixed-clock flow 必须机器标记 `causal_credit = NONE`；
4. 投诉等运营字段必须冻结准确单位；
5. 单位经济必须先冻结同定义桥；
6. 每条效用结论必须机械引用实际 settlement cell，而不是只引用 settlement ID；
7. Baseline 与 Enhanced 必须分别在结果前冻结 resolution rule；没有规则就只能 `NOT_DIAGNOSTIC`；
8. completion 必须复演 canonical settlement、adjudication、evaluation，并绑定独立 acceptance。

## 投资含义

截至本轮，只能说韵达在 2019 年显示出强规模与份额增长、经营现金扩张和更高资本投入，同时单位经济的同口径方向、加盟商真实经济、客户忠诚、行动效果和永久损失边界仍未被证明。

这不足以形成 CJO、估值或买点，但它改善了下一次研究的顺序：先解决责任边界、单位和同口径，再讨论执行、护城河和 owner cash。
