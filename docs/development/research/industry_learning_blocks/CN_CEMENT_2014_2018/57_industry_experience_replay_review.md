# 中国水泥行业经验层离线回放审阅

> 裁决：`PACK_REVIEWABLE / DRAFT / NOT_TRAINING_READY`
>
> 回放用途：验证行业经验层的对象关系、版本边界和下一样本选择；不评价 Agent 能力。

## 投资者结论

现有水泥训练资产已经能够告诉 Agent：水泥是区域 delivered-market、资本密集且公司责任边界差异显著的行业；海螺、天山、福建水泥、华新和冀东不能因为同属水泥就直接平均比较。它也保留了并购、重组和区域过剩等不同 archetype。

但这些资产还不足以回答真正的行业前景问题：2018 年后的需求、供给纪律、价格、成本和利用率将如何改变行业利润池。当前材料主要训练“怎样不做错比较”，尚未训练“行业未来更可能往哪走”。因此 Pack 必须保持 `DRAFT`，不能进入课程二期的正式行业能力 A/B。

## 根因

### `DATA_COVERAGE`

缺少同一 cutoff 下的官方行业需求、供给、产能、错峰、区域价格和利用率时间序列，也没有把这些行业变量与多家公司量价、成本、现金及资本结果连接起来。

经济影响：无法判断利润改善来自结构性供给纪律、区域集中和成本位置，还是短周期需求、价格与低基数。若直接进入公司承保，Agent 可能把边界纪律误当作行业方向，或者用海螺单家公司结果外推整个行业。

### `ACQUISITION_MODULE`

既有 H1 采集围绕公司年报、责任边界和结果隔离设计，没有形成可重复的行业官方序列采集包。缺口不是再写一个字段，而是把国家统计局、工信部或行业协会资料与相同 cutoff 的公司 cohort 连接起来。

经济影响：每次公司训练仍可能临时搜索两三家同行，行业经验无法稳定积累或版本迭代。

## 不能采用的假设

- 不得用海螺的恢复、现金或成本位置代表整个水泥行业；
- 不得因现有 Context 为 `BOUNDED` 就推断行业没有方向；
- 不得把供给侧改革、错峰或集中度改善写成利润池改善，除非 cutoff 前官方序列和公司分化共同支持；
- 不得把重组、并购或合资造成的总量变化写成经营改善；
- 不得用更多公司名称、更多文字或更多单点指标替代同口径的行业—公司传导。

## 可执行修复

下一轮只补一个可复用行业采集包：

1. 截止日前的水泥需求、产量、固定资产投资或下游活动序列；
2. 产能、淘汰、错峰、区域供需和可取得的价格/利用率资料；
3. 海螺、天山、福建水泥、华新、冀东的同口径量、价、成本、现金和资本字段；
4. 对并购和重组公司保留 perimeter bridge，不能为了可比而删除；
5. 预先冻结行业主路径、最强反方、行业结果来源和公司传导结果来源；
6. 用新资料重新编译 `IndustryUnderwritingContext`，不得手工把 Pack 结论倒灌进去。

## `TRAINING_READY` 接受条件

- Context 不再因为行业需求、供给、竞争或利润池缺失而 `BOUNDED`；
- 至少存在一组同一行业冲击下的异质公司响应比较；
- 行业主路径与最强反方都能由 cutoff-before 资料区分；
- 行业结果和公司传导结果拥有不同且可执行的结算来源；
- Pack validator 派生状态为 `TRAINING_READY`；
- 独立 reviewer 确认行业方向不是由目标公司结果外推。

这些条件满足后，水泥 Pack 才能进入 Course 2B。否则它仍可指导研究和补样，但不能用于宣称行业判断能力正在接受有效验证。
