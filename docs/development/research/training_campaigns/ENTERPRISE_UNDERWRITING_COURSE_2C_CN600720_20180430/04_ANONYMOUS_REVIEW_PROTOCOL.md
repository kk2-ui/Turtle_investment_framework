# Course 2C Fresh Reviewer 匿名裁决协议

> 状态：`FROZEN_BEFORE_ARM_EXECUTION`

Reviewer 第一阶段只接收共同 cutoff 源包和匿名 `Arm A`/`Arm B` Episode/readout。比较行业主路径、区域传导、成熟核心与 cohort 的 component_decisions、正常盈利、owner cash、融资压力、永久损失、价值路线、最强反方和翻转事实；不得以篇幅、字段数或 `UNKNOWN` 数量判优。

第一阶段冻结后，Reviewer 才读取 Pack V3 的允许范围、派生 Context、两层 outcome feedback 与 arm 映射。分别给出：

1. `INDUSTRY_PATH_VERDICT`；
2. `COMPANY_TRANSMISSION_VERDICT`；
3. `OVERALL_UTILITY_VERDICT`；
4. 映射揭示后的方法处置，最高 `TRANSFER_CANDIDATE`。

任何负面或阻断裁决必须说明经济影响、缺失事实、禁止假设、可执行修复、接受条件，并归因于 `DATA_COVERAGE`、`ACQUISITION_MODULE`、`REASONING`、`MODEL` 或 `WRITING`。单一公司轴正结果不授予 `RELEASED`、估值或投资权限。
