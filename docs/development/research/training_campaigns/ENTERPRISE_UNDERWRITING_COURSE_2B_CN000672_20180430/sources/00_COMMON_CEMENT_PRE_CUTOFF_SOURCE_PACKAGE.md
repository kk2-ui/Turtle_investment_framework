# 中国水泥行业 2018-04-30 截止日前共同官方源包

> 两臂共同可见。只提供 cutoff 前全国行业观察和政策原文的可复核摘录；不提供 Pack、同行结论或目标公司结论。

## 需求、价格与利润池

工信部《2017年上半年建材工业经济运行简况》披露：

- 2017 年上半年全国水泥产量 11.1 亿吨，同比增长 0.4%；
- 2017 年 6 月全国水泥出厂均价 321 元/吨，同比上涨 25.5%；
- 2017 年上半年水泥行业主营业务收入 4,598 亿元，同比增长 21%；利润 333.6 亿元，同比增长 248%；销售利润率 7.3%，同比提高 4.8 个百分点；
- 同期官方判断水泥产能过剩矛盾尚未根本解决，行业平稳运行基础尚不稳固。

这些数值共同确认“需求量近乎横盘、全国平均价格和利润池显著恢复”的同期事实。它们不能证明任一区域的 delivered price、任一公司的销量/售价/成本，不能把低基数利润增速外推为长期正常盈利。

## 新增产能、错峰与重组政策

国务院办公厅国办发〔2016〕34 号在 cutoff 前明确：

- 2020 年底前严禁备案和新建扩大产能的水泥熟料项目，并依法依规压减过剩产能；
- 采暖地区在采暖期全面试行水泥熟料错峰生产，其他地区在春节和酷暑伏天倡导错峰；
- 支持联合重组和主动压减竞争乏力产能，提出到 2020 年水泥熟料产量前十家企业生产集中度约 60% 的目标。

政策建立了限制名义新增熟料、阶段性收缩有效供给和提高集中度的候选机制。政策存在不等于执行已兑现；错峰不等于永久退出名义产能；60% 是目标，不是 cutoff 时的实际集中度；全国政策不能直接建立目标公司的竞争优势或 owner cash。

## 截止时最需要区分的两种解释

一种解释是：需求量近乎横盘时，新增产能约束、错峰、环保和行业组织改善收缩了有效供给，使价格恢复并真实扩张行业利润池。竞争解释是：上年低基数、区域性供给扰动和阶段性停窑制造了暂时高利润；未退出的过剩产能会在价格改善后复产，或不同区域因运输半径、竞争者和成本而明显分化。

区分两者需要结果期全国需求/产量、价格、利润，以及目标公司所在区域的售价/销量、单位成本、利用率或产品结构；全国序列不能单独结算公司传导。
