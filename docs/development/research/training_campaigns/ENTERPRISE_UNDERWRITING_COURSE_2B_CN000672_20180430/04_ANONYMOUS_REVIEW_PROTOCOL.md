# Course 2B Fresh Reviewer 匿名裁决协议

> 状态：`FROZEN_BEFORE_ARM_EXECUTION`

Reviewer 先收到共同原始资料和匿名两臂 Episode/读本，不收到作者身份或 arm 映射。第一步只比较 cutoff 当时的投资判断：行业主路径、区域与公司传导、正常盈利、三笔资本账、永久损失、价值路线、最强反方和翻转事实。不得以文字长度、字段数、同行数或 `UNKNOWN` 数量决定优劣。

第一步冻结后，Reviewer 才读取 Pack/Context、行业结果反馈和公司传导反馈，并分别给出：

1. `INDUSTRY_PATH_VERDICT`：哪一臂更好地判断行业利润池及耐久性，或结果为何不可区分；
2. `COMPANY_TRANSMISSION_VERDICT`：哪一臂更好地把行业路径传到上峰的正常盈利、owner cash、永久损失或价值路线；
3. `OVERALL_UTILITY_VERDICT`：`ENHANCED_MATERIALLY_BETTER`、`NO_MATERIAL_UTILITY`、`ENHANCED_WORSE` 或 `INCONCLUSIVE_DATA`；
4. arm 映射揭示后的方法处置：最高 `TRANSFER_CANDIDATE`，或停止扩样并先修被识别的推理/模型缺陷。

任何阻断或负裁决必须说明经济影响、缺失事实、禁止的假设、可执行修复和接受条件，并将根因归类为 `DATA_COVERAGE`、`ACQUISITION_MODULE`、`REASONING`、`MODEL` 或 `WRITING`。一次公司轴正结果仍不能授予 `RELEASED`；Pack 冻结后的未见时期尚须独立验证。
