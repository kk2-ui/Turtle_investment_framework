## 未来独立 curator 的限定任务

每个草案都要求后续 curator 在同一批三份静态报告内逐份完成以下复读，且可拒绝所有线索：

1. 从封面与证券资料页重建 code、历史法定发行人、报告年度、公告日、报告标题和名称连续性；
   `更新后` 标签必须作 controlling-version 决定，不能默认或择优采用。
2. 重建合并范围、子公司、非控制权益、债务及现金责任边界；不把当前 short name 或单一
   产品标签当作合并主体证明。
3. 定位实际披露的业务/产品/分部 carrier，以及三期的经营现金、现金限制、长期资产购建、
   营运资本和融资科目；所有单位、期间和会计口径均须随来源保存。
4. 保留不披露或不可比处的局部缺口；不得从 source metadata 推导正常盈利、维护/增长资本、
   owner cash、永久损失、价值、回报或行动。
