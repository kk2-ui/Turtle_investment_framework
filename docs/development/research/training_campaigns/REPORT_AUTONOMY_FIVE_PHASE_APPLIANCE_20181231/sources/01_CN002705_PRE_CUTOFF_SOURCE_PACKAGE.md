## 业务组件、客户与渠道：原始事实

- 三期年报把公司描述为小家电设计研发、生产和销售企业，并称其为中国小家电出口龙头；列举西式厨房小家电（如电热咖啡壶）、家居护理（如吸尘器）、婴儿电器、个护美容电器等产品方向。[FY2015 p.9](https://static.cninfo.com.cn/finalpage/2016-04-26/1202241491.PDF)；[FY2016 p.9](https://static.cninfo.com.cn/finalpage/2017-04-27/1203402114.PDF)；[FY2017 p.9](https://static.cninfo.com.cn/finalpage/2018-04-27/1204799583.PDF)
- FY2015 年报把小家电行业收入列为 6,190,609,307.37（营业收入 98.15%）；国外销售 5,554,205,528.07（88.06%）、国内销售 753,310,404.22（11.94%）。电热咖啡壶、电热水壶、打蛋机、搅拌机、面包机、多士炉、电熨斗、吸尘器等产品收入逐项列示。[FY2015 pp.10-11](https://static.cninfo.com.cn/finalpage/2016-04-26/1202241491.PDF)
- FY2016 年报称向客户提供市场策略、设计研究、产品实现、模具研制、认证测试和量产技术的一揽子解决方案。[FY2016 pp.9-10](https://static.cninfo.com.cn/finalpage/2017-04-27/1203402114.PDF)
- FY2015 前五大客户合计销售额为 2,410,396,619.07，占年度销售额 38.21%。FY2016/FY2017 的相同字段在本紧凑包中保持 `UNKNOWN`，避免从未逐页复核的表格补写。FY2015 的数据见 [p.13](https://static.cninfo.com.cn/finalpage/2016-04-26/1202241491.PDF)。
