截止日：2018-12-31。本文只使用巨潮资讯网（CNINFO）在截止日前披露的 FY2015、FY2016、FY2017 完整年度报告静态 PDF。金额单位除另注外为人民币元；页码为所链接 PDF 的页码。

## 正式身份与合并边界

- 三期年报封面主体均为“莱克电气股份有限公司”。本包以 CN:603355 和该披露主体识别公司。[FY2015 p.1](https://static.cninfo.com.cn/finalpage/2016-04-26/1202243180.PDF)；[FY2016 p.1](https://static.cninfo.com.cn/finalpage/2017-04-25/1203379379.PDF)；[FY2017 p.1](https://static.cninfo.com.cn/finalpage/2018-04-26/1204791498.PDF)
- 本包采用合并口径。三期财务报告均在“在子公司中的权益”列出子公司名称、经营/注册地、业务性质、持股比例及取得方式。[FY2015 pp.107-108](https://static.cninfo.com.cn/finalpage/2016-04-26/1202243180.PDF)；[FY2016 pp.120-121](https://static.cninfo.com.cn/finalpage/2017-04-25/1203379379.PDF)；[FY2017 pp.126-127](https://static.cninfo.com.cn/finalpage/2018-04-26/1204791498.PDF)
- 合并范围的原始变动：FY2015 新设莱克电气信息科技（苏州）有限公司、持股 70%；FY2016 新设 KINGCLEAN ELECTRIC (ROMANIA) SRL，由天然控股和莱克绿能间接 100% 持有；FY2017 新设苏州莱克米标云商销售有限公司、持股 60%，报告称其当期尚未开展经营活动。[FY2015 p.107](https://static.cninfo.com.cn/finalpage/2016-04-26/1202243180.PDF)；[FY2016 pp.120-121](https://static.cninfo.com.cn/finalpage/2017-04-25/1203379379.PDF)；[FY2017 pp.126-127](https://static.cninfo.com.cn/finalpage/2018-04-26/1204791498.PDF)

## 业务组件、客户与渠道：原始事实

- FY2015 年报称以高速整流子电机为核心技术，围绕吸尘器发展家居清洁、空气净化、水净化等高端清洁电器和园林工具；经营模式为自主品牌与 ODM 结合，国内发展 LEXY 莱克等品牌和线上业务，海外为 ODM 自主研发制造贴牌销售。[FY2015 p.8](https://static.cninfo.com.cn/finalpage/2016-04-26/1202243180.PDF)
- FY2016 年报称国内通过经销商、直营分公司和线上渠道；列出 LEXY 莱克、Bewinch 碧云泉、Jimmy 吉米三个品牌。FY2017 年报同样描述国内“代理+直营”、线上线下共同发展，海外为 ODM 自主研发制造贴牌销售。[FY2016 p.9](https://static.cninfo.com.cn/finalpage/2017-04-25/1203379379.PDF)；[FY2017 p.9](https://static.cninfo.com.cn/finalpage/2018-04-26/1204791498.PDF)
- FY2017 年报将主营产品表述为吸尘器、空气净化器、净水机等绿色小家电和园林工具；并称核心客户为国际知名家电制造商、品牌运营商及区域性领袖企业，产品销售覆盖欧洲、北美、大洋洲、日本以及南美、亚洲、东欧等市场。[FY2017 pp.9-12](https://static.cninfo.com.cn/finalpage/2018-04-26/1204791498.PDF)
- 前五名客户合计销售额及占营业收入：FY2015 1,931,478,000 / 48.25%，FY2016 1,933,537,400 / 44.18%，FY2017 2,272,596,100 / 39.81%。年报以“客户 1…客户 5”列示，并未在这些表中披露名称。[FY2015 p.11](https://static.cninfo.com.cn/finalpage/2016-04-26/1202243180.PDF)；[FY2016 p.14](https://static.cninfo.com.cn/finalpage/2017-04-25/1203379379.PDF)；[FY2017 p.16](https://static.cninfo.com.cn/finalpage/2018-04-26/1204791498.PDF)
