## 业务组件、客户与渠道：原始事实

- 主营产品为塑料空调风叶，分为贯流、轴流、离心三类；业务还包括改性塑料、模具设计/制造及其他精密组件。三期均描述“塑料改性—模具设计制造—塑料空调风叶设计制造”产业链。[FY2015 p.9](https://static.cninfo.com.cn/finalpage/2016-02-05/1201971842.PDF)；[FY2016 p.8](https://static.cninfo.com.cn/finalpage/2017-04-25/1203374495.PDF)；[FY2017 p.8](https://static.cninfo.com.cn/finalpage/2018-04-24/1204697602.PDF)
- FY2017 年报把销售方式列为直销、直接与终端客户签订销售合同，生产方式列为“以销定产”；其说明下游客户的技术规格提出后，公司完成风叶设计、配套模具和改性配方的整合。[FY2017 p.8](https://static.cninfo.com.cn/finalpage/2018-04-24/1204697602.PDF)
- 年报列举格力、美的、志高、TCL，以及大金、松下、富士通将军、三星、LG 为长期客户。[FY2015 p.9](https://static.cninfo.com.cn/finalpage/2016-02-05/1201971842.PDF)；[FY2016 p.8](https://static.cninfo.com.cn/finalpage/2017-04-25/1203374495.PDF)；[FY2017 pp.8-9](https://static.cninfo.com.cn/finalpage/2018-04-24/1204697602.PDF)
- 前五名客户合计销售额及占年度销售额比重为：FY2015 637,853,395.34 / 53.09%，FY2016 642,883,897.73 / 49.48%，FY2017 820,153,797.58 / 52.73%。[FY2015 p.13](https://static.cninfo.com.cn/finalpage/2016-02-05/1201971842.PDF)；[FY2016 p.12](https://static.cninfo.com.cn/finalpage/2017-04-25/1203374495.PDF)；[FY2017 p.14](https://static.cninfo.com.cn/finalpage/2018-04-24/1204697602.PDF)

## 具名项目、并购与融资边界：原始事实

- FY2015 年报称当期受让上海蓝沛新材料科技股份有限公司 3.19% 股权，收购金额 15,007,500；同一报告还称正推进非公开发行股票事宜，拟投向大屏智能触控终端并搭建产品研发集成、产品营销、互联网运营云平台。[FY2015 pp.9-10](https://static.cninfo.com.cn/finalpage/2016-02-05/1201971842.PDF)；[FY2015 p.17](https://static.cninfo.com.cn/finalpage/2016-02-05/1201971842.PDF)
- FY2015 募集资金披露中列出新建塑料空调风叶生产线、年产 5 万吨改性塑料等项目；截至 2015-12-31 尚未使用募集资金 22,720,600。[FY2015 pp.18-20](https://static.cninfo.com.cn/finalpage/2016-02-05/1201971842.PDF)
- FY2016 年报称募集资金累计使用 586,028,700，年末余额为零且账户已全部注销；同年披露工程塑料及风叶研发中心项目终止，节余募集资金永久补充流动资金。[FY2016 pp.16-19](https://static.cninfo.com.cn/finalpage/2017-04-25/1203374495.PDF)
- FY2017 年报称顺威（泰国）有限公司首个海外生产基地建设完成、计划 2018 年全面投产；该报告还披露泰国项目、智能卫浴项目等在前期筹建阶段。[FY2017 pp.9-11](https://static.cninfo.com.cn/finalpage/2018-04-24/1204697602.PDF)
