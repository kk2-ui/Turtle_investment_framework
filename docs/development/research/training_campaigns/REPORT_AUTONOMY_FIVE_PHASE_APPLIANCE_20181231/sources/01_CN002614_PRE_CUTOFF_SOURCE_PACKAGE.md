# CN:002614 奥佳华智能健康科技集团股份有限公司 — cutoff 原始来源包

截止日：2018-12-31。本文只使用巨潮资讯网（CNINFO）在截止日前披露的 FY2015、FY2016、FY2017 完整年度报告静态 PDF。金额单位除另注外为人民币元；页码为所链接 PDF 的页码。

## 正式身份与合并边界

- FY2015 和 FY2016 年报封面主体为“厦门蒙发利科技（集团）股份有限公司”；FY2017 年报封面主体为“奥佳华智能健康科技集团股份有限公司”。本包以 CN:002614 及截止日前最新年报主体名识别公司，不把两种名称当成不同企业。[FY2015 p.1](https://static.cninfo.com.cn/finalpage/2016-04-22/1202216781.PDF)；[FY2016 p.1](https://static.cninfo.com.cn/finalpage/2017-04-25/1203378240.PDF)；[FY2017 p.1](https://static.cninfo.com.cn/finalpage/2018-04-26/1204793945.PDF)
- 本包的财务数字均为合并口径。FY2017 年报的“在子公司中的权益”表列有厦门蒙发利健康科技、深圳佳健康、棨泰健康、OGAWA WORLD BERHAD、OGAWA USA、SVAGO 等，并标示取得方式和直接/间接持股比例；该表是本包采用的合并边界定位。[FY2017 pp.151-153](https://static.cninfo.com.cn/finalpage/2018-04-26/1204793945.PDF)
- 合并边界在期间内发生变化：FY2015 年报列出德国 MEDISANA 相关主体（含 MEDISANA AG）纳入；FY2016 年报列示 MEDISANA AG 85% 且为非同一控制下企业合并；FY2017 年报列示深圳佳健康科技为非同一控制下企业合并。[FY2015 pp.151-155](https://static.cninfo.com.cn/finalpage/2016-04-22/1202216781.PDF)；[FY2016 pp.155-156](https://static.cninfo.com.cn/finalpage/2017-04-25/1203378240.PDF)；[FY2017 pp.150-152](https://static.cninfo.com.cn/finalpage/2018-04-26/1204793945.PDF)

## 业务组件、客户与渠道：原始事实

- FY2015 年报把业务分为出口业务与自有品牌两部分；产品涵盖按摩保健、空气净化。报告称出口产品进入 60 多个国家，并列出 Homedics、Honeywell、日本松下为合作品牌；自主品牌 OGAWA、COZZIA、FUJIMEDIC 覆盖中国、东南亚、香港、台湾、北美及日本。[FY2015 p.11](https://static.cninfo.com.cn/finalpage/2016-04-22/1202216781.PDF)
- FY2016 年报把产品列为保健按摩、健康环境、家用医疗，业务为全球品牌经营和 ODM 出口；报告同时列出五个自主品牌及其区域/渠道：OGAWA 的亚洲高端百货和 Shopping mall、FUJIMEDIC 的日本电视购物和线下量贩、FUJI 的台湾大卖场和百货、COZZIA 的北美家居渠道、MEDISANA 的欧洲 LIDL、麦德龙、Amazon 渠道。[FY2016 pp.11-12](https://static.cninfo.com.cn/finalpage/2017-04-25/1203378240.PDF)
- FY2017 年报列出按摩康复（按摩椅、按摩小电器）、健康环境（空气净化器、新风机）和家用医疗（血压计、血糖仪、血氧计）；仍列全球自主品牌经营与 ODM 出口，并再次列出 Homedics、Honeywell、日本松下等客户品牌。[FY2017 pp.10-12](https://static.cninfo.com.cn/finalpage/2018-04-26/1204793945.PDF)
- 前五大客户合计销售额及占年度销售额比重为：FY2015 998,434,545.42 / 35.27%，FY2016 1,040,729,022.86 / 30.15%，FY2017 1,043,622,412.59 / 24.30%。[FY2015 pp.26-27](https://static.cninfo.com.cn/finalpage/2016-04-22/1202216781.PDF)；[FY2016 pp.27-28](https://static.cninfo.com.cn/finalpage/2017-04-25/1203378240.PDF)；[FY2017 pp.25-26](https://static.cninfo.com.cn/finalpage/2018-04-26/1204793945.PDF)

## 具名项目、并购与融资边界：原始事实

- FY2015 年报称公司在该年末启动收购德国 MEDISANA、在 2016 年初完成；并把 MEDISANA 描述为家庭健康产品和服务提供商。FY2016 合并现金流量表列“取得子公司及其他营业单位支付的现金净额”5,964,081.10，FY2017 同项目为 18,458,724.96。[FY2015 pp.14-15](https://static.cninfo.com.cn/finalpage/2016-04-22/1202216781.PDF)；[FY2016 p.85](https://static.cninfo.com.cn/finalpage/2017-04-25/1203378240.PDF)；[FY2017 p.83](https://static.cninfo.com.cn/finalpage/2018-04-26/1204793945.PDF)
- FY2017 年报称公司已开始筹划年产 100 万台智能按摩椅生产基地建设。[FY2017 p.12](https://static.cninfo.com.cn/finalpage/2018-04-26/1204793945.PDF)
- FY2017 年报披露 2011 年首次公开发行募集资金净额 1,474,992,000.00；截至 2017-12-31，募集资金专户余额合计 487,247,000.00，其中 486,000,000.00 划入保本型理财产品。[FY2017 p.29](https://static.cninfo.com.cn/finalpage/2018-04-26/1204793945.PDF)

## 非经常项目与口径断点：原始事实

- FY2015 年报的非主营业务表把资产减值 3,140,806.63（主要为存货跌价准备）列为“不可持续”。[FY2015 p.22](https://static.cninfo.com.cn/finalpage/2016-04-22/1202216781.PDF)
- FY2016 年报称资产减值损失增长与商誉减值、信用账期延长计提坏账及子公司存货跌价准备有关；附注列示商誉减值损失 34,443,206.08。[FY2016 p.21](https://static.cninfo.com.cn/finalpage/2017-04-25/1203378240.PDF)；[FY2016 p.140](https://static.cninfo.com.cn/finalpage/2017-04-25/1203378240.PDF)
- FY2016 采用《增值税会计处理规定》：将若干税费自“管理费用”重分类至“税金及附加”，当年调增/调减各 5,338,679.50，比较数据未调整；FY2017 的政府补助、资产处置收益列报按新准则/格式变更，报告给出相关重分类金额。三期均披露无重要会计估计变更。[FY2016 p.115](https://static.cninfo.com.cn/finalpage/2017-04-25/1203378240.PDF)；[FY2017 p.115](https://static.cninfo.com.cn/finalpage/2018-04-26/1204793945.PDF)
