## 当前最重要的三项企业判断

### 判断一：生产与项目执行强，但经济吸收仍是条件判断

**当前判断。** 公司已经证明能在多个国家和矿种推进收购、建设、投产与增产，经营执行评价为强。这个评价只覆盖部署和产出，不自动证明新增吨位具有更好的全周期资本回报。FY2025 核心矿产品单位销售成本上升，使“低成本优势继续扩大”不能作为当前确定结论。

**机制。** 资源控制、找矿、建设和选冶能力推动矿石处理量与金属产量；只有新增产量同时维持或改善同口径单位销售成本和矿产品毛利，项目部署才完成经济吸收。商品价格上涨可以提高利润，却不能替代成本、品位、剥采比和利用率的验证。

**最强反方。** FY2025 成本上升可能只是新收购矿山过渡、项目爬坡和产品组合变化；随着新设备、扩建和协同完成，单位成本可能回落。若如此，当前的谨慎会低估真实工程与整合能力。

**翻转事实。** FY2026 在并购和权益口径完成桥接后，矿产铜与金产量同时增加，且匹配产品单位成本不再恶化或明确改善，将把判断升级为真实经济吸收。只有已经披露的定义、期间或责任边界与冻结定义冲突且无法桥接，才结算为 `MEASUREMENT_MISMATCH`；口径可比或已桥接但核心产量/单位经济未披露或方向不明，保持局部 `UNKNOWN`，不能凭另一轴替代。若可比产量上升但成本继续恶化，只能保留为 `VOLUME_ONLY`；若核心产量和单位经济同时恶化，则下调经营执行。

### 判断二：集团现金能力真实增强，但 normalized parent owner cash 尚未闭合

**当前判断。** FY2025 合并 OCF 扣除购建固定资产、无形资产及其他长期资产现金后仍为显著正数，说明集团当前有真实内部融资能力。然而维护性与增长性资本没有充分拆分，收购现金显著增加，集团现金的母公司可达性和少数股东权利也没有完全闭合。因此当前可确认的是正向的 group post-organic-capex proxy，而不是 normalized parent owner cash。

**机制。** 矿山毛利和营运资本形成 OCF；维持矿山安全、剥离、尾矿、选冶和资源接续所需资本先于可分配现金；并购和扩建决定剩余现金被再投入多少；子公司、合营安排和少数股东决定其中多少最终属于普通股股东并能上游到母公司。

**最强反方。** 公司披露的现金、融资渠道和近年 OCF 足以覆盖当前投入，且部分新增资本是高回报增长资本。若把所有长期资产支出和收购都视为维持负担，会系统性低估成长型矿业公司的 owner cash。

**翻转事实。** FY2026 若明确拆分 maintenance/growth capital、集团 post-capex proxy 与扣除 NCI distributions 后的 post-NCI-claim proxy 均保持正向、少数股东边界闭合且母公司取得现金的路径有证据，才可上调 normalized parent owner cash。若 post-NCI-claim proxy 不为正、maintenance 被延后或 parent access 被阻断，则不能升级。收购支付另列为 post-allocation burden；它若令该代理不为正，表示本期资本配置负担不利，但不自动上调永久损失，仍要等待所购资产的增量现金与资金期限载体。

### 判断三：近期流动性不是首要危机，但永久损失仍受项目与资本承诺约束

**当前判断。** FY2025 现金及现金等价物约人民币 612 亿元，短期借款与一年内到期非流动负债合计约 583 亿元，合并 OCF 强，且流动资产超过流动负债；这些事实不支持把公司写成迫近的流动性困境。另一方面，跨境矿权、许可、地缘事件、项目停产、资源品价格、矿山复垦义务和持续的大额资本配置都可能造成不可逆价值损失。永久损失判断为 `LOW_TO_MEDIUM_CONDITIONAL`，而不是由当前利润或现金一票消除。

**机制。** 可用现金、承诺授信和完成再融资覆盖短债，决定公司能否在低周期避免被迫融资或出售；矿权有效性、持续运营、减值和复垦支出决定资本是否永久受损；商品价格影响缓冲，但不能修复失去的矿权或错误收购。

**最强反方。** 全球资产分散、低成本矿山、强 OCF 和多渠道融资可能已经将单一项目风险充分分散，当前条件性折价过高。相反，合并报表现金可能位于不能自由上游的子公司，短债与新项目承诺也可能比表面流动比率更紧。

**翻转事实。** 不受限现金与具约束力的可用融资持续覆盖一至两年到期债务，且没有材料矿山停产、许可损失、项目减值或复垦准备不足，可局部下调永久损失。任何未覆盖的期限缺口、材料矿权/停产事件、重大减值或复垦准备侵蚀都优先结算为风险上升，不能因另一载体改善而稀释成 `MIXED`；正 OCF 也不能覆盖这些载体。

## 管理层与执行评价

当前评价为：**生产部署强，资本价值兑现有待继续验证。**

两期材料显示管理层能够推进多项目建设、矿产增量、跨境收购和融资，FY2025 还完成重大管理层交接。管理层信用的正面依据是可观察的产量、投产和现金能力，而不是计划措辞。约束是：单位成本上升、并购现金增加、合并范围变化和领导层切换，使项目回报、整合质量与资本纪律尚不能从一期高利润中分离。

FY2026 对管理层的检验不是“是否宣布更多项目”，而是新旧项目的产量、单位经济、现金和期限是否同时兑现。

## Owner cash 处理

当前只承认两个分层结论：

1. 合并集团 OCF 减长期资产现金投入的方向性代理为正；
2. 上述代理减 NCI distributions 后才是 post-NCI-claim proxy；
3. post-NCI-claim proxy 再减现金收购只用于观察本期 post-allocation burden；
4. normalized parent owner cash 为 `UNKNOWN / NOT_YET_UNDERWRITTEN`。

维护资本、增长资本、现金收购、NCI distributions、受限现金和母公司可达性必须分列。normalized parent owner cash 至少要求 post-NCI-claim proxy 为正、maintenance adequate、parent access evidenced 且 NCI scope closed；post-allocation 不为正只形成局部资本配置负担，不跨轴判定永久损失。group proxy 为正但 post-NCI 未知、post-NCI 为正但 post-allocation 未知，或 maintenance、parent access、NCI 任一仍 open/unknown，均结算为 `POSITIVE_GROUP_PROXY_SCOPE_OPEN`，不得升级 normalized parent owner cash。任何一个局部未知只限制对应 owner-cash 主张，不撤回已经观察到的集团现金能力，也不能由正集团现金自动降低永久损失。

## 结果前反例

- 表面产量上升但并购口径未桥接，经营 cell 必须是 `MEASUREMENT_MISMATCH`；核心产量未知时保持 `UNKNOWN`，不得从单位成本或毛利倒推出方向。
- group post-organic-capex proxy 为正但被 NCI distributions 消耗，不能升级 normalized parent owner cash；post-NCI 为正但收购令 post-allocation 不为正，只标记局部 allocation burden adverse。
- 任何未覆盖流动性、材料资产损失或预计负债侵蚀都优先把永久损失结算为风险上升，即使另一载体改善也不得降为 `MIXED`。
- 经营口径已可比或已桥接，但某一轴未披露或方向不明，只能保持 `UNKNOWN`，不能改写成 mismatch 以逃避局部结算。
- group proxy 为正但 post-NCI 未知、post-NCI 为正但 post-allocation 未知，或 maintenance、parent access、NCI 任一 open/unknown，统一保持 scope-open，不得升级 owner cash 或传播到永久损失。

## 永久损失处理

当前没有证据支持迫近的偿债危机，但也不将高利润、现金余额或授信总额视为无条件安全。永久损失的主要载体依次是：

- 近端债务与真正可动用流动性的错配；
- 重大项目停产、许可或地缘损失；
- 并购或建设资本发生材料减值；
- 复垦、闭矿和环境义务被低估；
- 子公司/NCI 边界使集团资源不能服务普通股股东。

每个载体局部结算。一个载体改善不能替其他载体投票。

## 三种 FY2026 经营情景

### 乐观情景

新增项目按计划爬坡，铜、金的同口径产量上升，核心单位成本稳定或改善；OCF 足以覆盖维护与有纪律的增长资本，收购资产开始贡献可识别现金；近端债务由不受限现金和完成融资覆盖，没有材料项目损失。此时上调正常盈利能力和管理层资本执行，对资本密集与永久损失的折价局部收窄。

### 基准情景

产量继续增长，但品位、剥采、人工和新项目过渡使单位成本维持压力；集团 post-capex proxy 仍正，收购与扩建继续吸收较多现金；流动性可管理，但 maintenance、parent access 或 NCI 仍有局部未知。此时维持“经营强、owner cash 条件性、永久损失中低但需折价”的判断。

### 悲观情景

商品价格正常化与单位成本上升同时发生，新项目延误或收购资产未达到经济产出；OCF 扣长期资产投入后显著收窄或转负，近端债务覆盖恶化，并出现材料停产、许可损失、减值或复垦负担上修。此时下调正常盈利能力和管理层资本配置评价，扩大永久损失折价。

这些情景不分配伪精确概率；FY2026 只按冻结的三个 outcome cell 结算。

## 不带证券价格的估值方向

当前估值处理是方向性的：

- 可持续矿产量与同口径单位经济同时改善，才上调 normalized earnings 区间；
- 高商品价格或并购扩表带来的利润增长不直接外推为正常盈利；
- maintenance、增长资本、NCI 和 parent access 未闭合时，owner-cash 转换保持折价；
- 期限、许可、减值和复垦风险决定永久损失折价，不能由单期 OCF 消除。

本工件不读取证券价格，不计算价值区间、最高可接受买价或投资动作。
