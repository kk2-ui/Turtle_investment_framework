## 当前结论

训练已经产生真实效果，但效果比“完整方法有效”窄得多：

```text
直接纠正企业判断                 1  口子窖
发现有害推理规则                 1  家家悦
Enhanced 与公平 baseline 同处理  4  中材科技、恒生电子、益丰药房、激成投资
TRANSFER_VALIDATED               0
```

真实成果是：系统能发现自己过度悲观或错误擦除风险，并把公司判断沿经营、现金和永久损失分别更新。
没有证据支持“字段更全、分类更细、责任边界更整齐”本身提高投资判断。

## 第六轮新增的公司认识

激成投资 FY2022 将结果前的“重开选择权”上修为真实酒店经营恢复：八家固定酒店中六家同时出现
occupancy、ADR 和同物业本币 RevPAR 改善；酒店分部收入由约 `HK$380.4m` 上升至
`HK$1,331.0m`，受控酒店 recurring EBIT 由约 `-HK$238.8m` 转为 `HK$100.2m`，pre-D&A
由约 `-HK$88.6m` 转为 `HK$245.0m`。武汉仍是量升价降，纽约只是重开后的不可比低基数，因此
不能直接承保完整正常周期利润率。

集团当期现金也真实改善：综合 OCF 扣 reported capex、OCF 外现金利息和 NCI 股息后，一期方向
代理约为正 `HK$191.8m`。维护资本是否充足、集团现金能否上游到母公司仍未知，所以该数不是
normalized parent owner cash。

经营亏损风险下降，但永久损失风险仍由资金期限主导：约 `HK$1,359.3m` 银行债在一年内或按要求
偿还，存款及现金总额约 `HK$1,341.3m` 且可用/受限未拆；两笔贷款继续依赖覆盖至到期日的契约
豁免，没有披露已完成或具约束力的再融资。当前结论是：

```text
酒店经营执行                     上调
资本、维护与再融资执行           条件性
当前集团现金                     正向
normalized parent owner cash     尚未承保
永久损失                         中等、条件性
```

## 为什么第六轮仍是零方法效用

公平 baseline 事先已经知道：重开不等于经济吸收；ADR、partial year、税、融资、联营和减值需要
分开；OCF-capex 不是 parent owner cash；maintenance、NCI、契约与抵押不能被正现金跨轴消除。
面对 FY2022 的强同向酒店恢复和持续 waiver，两臂都会：

- 上修酒店经营，而不直接外推正常周期利润；
- 承认正集团现金，而不升级 normalized parent owner cash；
- 保留澳门物业为混合缓冲；
- 维持再融资与永久损失折价；
- 把 maintenance、parent access 和完成再融资列为同一下一研究动作。

Enhanced 的八物业向量和 first-match 让解释更清晰，却没有改变管理层、现金、永久损失、情景、
估值方向或研究行动，故为 `NO_MATERIAL_UTILITY`。这项诚实的零结果比“又成功验证一次规则”更重要。

## 六轮后应保留的企业推理

### 1. 行动/部署不等于经济吸收

建设、开店、上线、收购、重开只是执行起点。客户量价、责任单元经营结果、现金和资本回报要分层
评价。这个原则是普通经营判断，不再包装成已验证 transfer 方法。

### 2. 已知方向不能被 UNKNOWN 擦除

若 `known negative endpoint - X, X≥0` 的最乐观端点仍为负，就必须保留负方向；若区间可跨零才
保持 mixed。家家悦证明 UNKNOWN-first 会真实低估资金和永久损失风险；恒生电子证明不能把跨零
区间强写成负。

### 3. 一个轴不能替另一个轴投票

核心强、集团现金正、融资压力下降或公允价值增加，都只能更新匹配轴。它们不能自动证明新项目
有回报、parent owner cash 已闭合、品牌/库存风险下降或永久损失变低。

### 4. 公平 baseline 必须真的公平

Baseline 获得同一事实预算和普通投资者能力。Enhanced 只有在结果前冻结了 baseline 不会采取的
材料处理，并由相关结果支持时才有信用。四次 `NO_MATERIAL_UTILITY` 表明：强 baseline 往往已经会
作出正确的经营桥和现金边界；继续与它比较模板完整度没有训练价值。

## 运行时奖励已经怎样改变

本轮不再重构顶层训练架构，而是修真正执行链上的奖励：

- 缺披露不再默认给 GG 固定折价；只有已观察的经济损失载体才能折价；
- 市场价格、股本、DPS 或估值输入不可用时，只关闭对应估值和动作，不伪造数字、不撤回企业判断；
- 自动同行只是候选；责任边界、生命周期、会计口径和期间未验证时不能生成分位或 PE 中位数；
- 删除报告篇幅、引用比例、固定来源调用次数和 Ch11 关键词等会奖励扩写/重复检索的完成门；
- UNKNOWN 必须绑定当前处理、经济后果和可结算翻转事实，不能独自完成研究或读者主题；
- 缺失信息不自动创建研究任务，只有会改变当前判断的 fragile leap 获得预算；
- decision utility 当前没有可机械比较的材料投资处理载体，因此新增结果字段、概率差异、
  OBSERVED 结果和 reviewer 积极标签都只能 `NOT_DIAGNOSTIC / NONE`；
- Forecast 弃权不再获得 coverage 学习；预测正确、与 baseline 相同或无法识别错误时也不制造 policy；
- 只有同维度、同期限的真实 modal 错判、零概率事件被实现，或 baseline 确实纠正 enhanced 错误时，
  才形成局部 Forecast error signature；
- bound Frozen CJO 直接确定性生成唯一公司判断研究产物，不再先写十五章自由结论再与 canonical 摘要
  并列；无行动、无状态变化和局部 UNKNOWN 可以自然呈现，不逼 Agent 补字段。

这些修复共同改变了最安全策略：少判断、弃权、扩写、补 gate、写 reviewer 标签和重复搜索都不再自动
获得完成或学习信用。

## 仍未证明

- 没有一条完整 Enhanced 方法获得 prospective transfer validation；
- 一次口子窖纠偏不能证明跨公司普适；
- 六个案例没有使用价格与回报，不能证明实际投资收益改善；
- 吉比特与泛微网络 outcome 仍因浏览器任务空间被用户接管而封存，不能算反馈；
- 运行时 validator、测试和确定性报告只能证明已知奖励错位被移除，不能代替未来未见案例的判断表现；
- 不授予 Comparative、CJO 方法冻结、正式估值、BuyBand、报告发布或投资权限。

## 下一轮应怎样更有信息量

下一 paired episode 应优先选择经营轴真实冲突的公司：部署或客流上升，但价格、经常性经济、现金、
maintenance 或资金期限恶化。结果前不仅冻结字段预算，还要冻结 baseline 与 enhanced 各自会采取的
材料判断和下一研究行动。若两臂仍相同，继续记零；不要用更多字段、概率或 gate 追求一次“成功”。
