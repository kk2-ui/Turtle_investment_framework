## 跨案例经营规律

### 1. 部署不是经济吸收

五家公司共同支持把管理层评价拆成四层：

```text
建设 / 开店 / 并购 / 上线
    → 客户采用与收入吸收
    → 责任单元利润和现金
    → 投入资本回报与普通股价值
```

中材科技跨过前两层但尚未跨过后两层；益丰跨过网络部署但 cohort 单位吸收混合；恒生的新增
技术已有案例部署却没有独立经济；家家悦扩张执行存在但集团资金负担已经出现。只有口子窖省外
同时观察到收入、销量、毛利和渠道广度改善，才允许从“待证选择权”上调为“早期经营证据”。

这不是要求每家公司收集同一套字段，而是要求证据沿本公司经济机制向后传导。

### 2. 强核心不能替新行动投票

成熟业务现金可以延长新行动的试错期，也可能让低回报资本更久不暴露。中材科技与家家悦最能
说明这一点：集团支付能力强并不能证明锂膜二期或新域扩张值得投入。对投资者而言，短期流动性
安全与长期资本配置风险必须同时存在，不能互相抵消。

### 3. 现金未知要先判断可行区间

- `known negative endpoint - X, X≥0`：最乐观结果仍为负，方向是负，只有金额未知；
- `small positive endpoint - X, X≥0`：可能跨零，方向保持 mixed；
- 单期合并资金端点不自动成为 normalized owner cash、业务回报或资本误配证据。

家家悦触发第一种情况，恒生电子触发第二种。益丰进一步显示，当负部署资金重复并伴随债务、
商誉和融资压力时，才足以提高资本配置与永久损失折价。

### 4. 一个风险轴改善不能替其他轴改善

口子窖强现金只降低融资型下行；它没有证明高档实体需求、省外重复性或库存资本回报。下一期
情景因此修正为 `乐观 30% / 基准 58% / 悲观 12%`，而不是旧的 `30% / 62% / 8%`。

同理，产品未披露只降低产品归因置信，不能自动下调集团现金或永久损失；单个产品退出也不能
自动证明组合失败。更新必须沿责任匹配的机制轴传播。

## 当前管理层判断

本轮没有得出“优秀管理层”或“糟糕管理层”的统一标签。更有用的结论是：

- 中材科技：建设执行可信，资本回报纪律尚未证明；
- 家家悦：网络扩张执行可信，新域资本配置已出现现金反证；
- 恒生电子：成熟核心研发与交付可信，新技术商业化和战略投资回报未证明；
- 益丰药房：部署和整合速度强，收购 cohort 经济及资金纪律需要更高折价；
- 口子窖：安徽经营与资金能力强，省外执行信用上调，库存和固定资本回报仍条件性。

这比单一“管理层能力分数”更接近投资问题：管理层在哪一层有证据、在哪一层仍可能毁损价值。

## 研究行为已经怎样改变

1. 先冻结公平 baseline，不故意做弱对照。
2. 只选可能改变管理层信用、owner cash、永久损失、情景或估值方向的最少经营载体。
3. 结果不再按“字段结算成功”评分，而是问判断是否过度乐观、过度悲观或遗漏相反机制。
4. `UNKNOWN` 必须变成局部的基准处理和可结算翻转事实，不能成为整家公司结论。
5. `missing_information` 不自动获得下一轮研究预算；材料缺口必须绑定当前主张、区分证据和经济
   后果。
6. 只有结果前两臂真实存在材料判断/处理差异，且结果支持该差异，才允许记训练效用；结构更全、
   表达更清楚和规则正确运行均为零效用。
