# 四轮反馈后的训练方向修正

> campaign：`JUDGMENT_FIRST_12H_20260828`
>
> 状态：`STOP_TEMPLATE_UTILITY_SEARCH / START_DIRECT_JUDGMENT_CALIBRATION`

## 结论

四个前瞻闭环的结果是：

| 公司 | 结果 | 真实反馈 |
| --- | --- | --- |
| 中材科技 | `NO_MATERIAL_UTILITY` | 公平 baseline 本来就不会给未盈利项目成长价值 |
| 家家悦 | `HARMFUL` | `UNKNOWN-first` 擦掉了已知的负现金上界 |
| 恒生电子 | `NO_MATERIAL_UTILITY` | 公平 baseline 本来就会分开成熟核心、新选择权与集团资金 |
| 益丰药房 | `NO_MATERIAL_UTILITY` | 唯一新干预没有激活，两臂对经营、现金和永久损失处理相同 |

累计为：

```text
MATERIAL_UTILITY       0
NO_MATERIAL_UTILITY    3
HARMFUL                1
```

因此不能声称 judgment-first enhanced 模板已经提高未见案例的投资判断。唯一被真实错误支持的是
一个窄修正：金额未知但符号已知时，必须保留可证明方向。它应作为普通推理修复保留，不再被包装
成等待“transfer validation”的完整方法。

## 问题在哪里

四轮实验不断把一个已经很强的公平 baseline 与更结构化的 enhanced 比较。Enhanced 大量增加
责任单元、字段和表达，但在结果前通常没有冻结一个它会作出、而 baseline 不会作出的材料判断。
结果后两臂自然相同，系统只能证明自己更整齐。

这是 `REASONING + MODEL` 问题，不是数据量问题：训练对象仍然偷偷从“企业判断是否准确”滑回
“方法是否遵守规则”。经济损失是不能知道管理层、owner cash、永久损失和估值方向的真实判断
哪些对、哪些错，也无法校准 Agent 在证据不完美时应有多大信心。

禁止的补救是再增加一个准入 gate、再要求更多字段，或挑一个结果后看起来能让规则成功的公司。

## 训练行为立即改变

从扩展 roster 第一名口子窖开始，不再为每家公司制造一个新的 enhanced 模板。改为直接冻结
当前企业判断的可结算预测：

1. 三项最重要企业判断分别给出方向和置信概率；
2. 对会改变投资处理的关键机制给出互斥结果分类；
3. 三种经营情景给出合计 100% 的概率，而不只排序；
4. 结果前明确每个结果会怎样更新管理层、owner cash、永久损失和方向性估值；
5. custodian 只结算冻结指标；fresh reviewer 评价判断是否命中、过度自信或过度保守，并具体
   修改下一家研究行为。

这不是要求 Agent 编造精确概率。概率迫使它暴露当前真实倾向，让 `UNKNOWN` 无法免费替代判断；
局部资料不足仍可降低置信度，但不能取消公司级概率和投资含义。

## 口子窖为什么适合下一轮

口子窖的反馈前判断已经冻结，且 FY2019 结果仍未读取。它包含三个可直接校准的争议：

- 高档产品的收入、销量和毛利能否继续共同吸收，而非只靠价格；
- 省外收入改善会不会转成销量与渠道广度，还是继续由结构和清理驱动；
- 陈化库存和工业园资本能否在剔除营运资金支持后继续由企业现金覆盖。

这些判断直接影响全国化成长价值、管理层资本配置信用、owner cash 和永久损失，不需要
Comparative 或正式估值才能学习。

## 对防御性写作的约束

- 不能用“终端动销未披露”拒绝判断高档和省外趋势；必须给当前方向与概率；
- 不能把公司级收入增长直接称全国化成功，也不能因省外局部混合把安徽核心取消；
- 不能把预收和库存一概写成好或坏；必须说明它们在品牌吸收与现金逆转中的双重作用；
- 结果后必须指出哪项判断错、为什么错、下一家公司会少看或多看什么，不得只写字段已结算。

## 权限边界

这次修正不改变 PIT、结果隔离、责任边界或独立 custodian/reviewer。它不修改 J2/J3/J4 adapter，
不授予 Comparative、CJO、正式估值、BuyBand、报告发布或投资权限，也不标记 transfer validated
或 method frozen。
