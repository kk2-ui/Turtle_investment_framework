# CN601598 结果前独立审阅

## 最终裁决

**ACCEPT**

本审阅只使用盲包中的 FY2021–FY2023 官方年报及结果前判断。未读取 FY2024、价格、回报、父工作区或旧报告。机械合同验证结果为 `valid=true`。

## 两轮 RETURN 与修复

第一轮识别出两项材料问题：

1. `DATA_COVERAGE / ACQUISITION_MODULE / REASONING`：2023 年三分部剔除投资收益后的利润同比增加约 4.34 亿元，而物流业财政补贴同比增加约 9.27 亿元；两者责任边界未对齐，原稿却把利润改善主要归因于单位经济性并给出估值方向 `UP`。这可能高估正常盈利和管理层执行。
2. `REASONING / MODEL`：原现金 cell 让 NCI、母公司上划或维持/扩张任一缺口触发整 cell 空更新，从而可能吞掉已观察的集团现金损失、信用损失和净现金收缩对 permanent loss 的影响。

修订后：

- 企业判断明确区分“报表盈利韧性已观察”和“补贴前商业经济归因混合”。正常盈利由 34–36 亿元收窄并下调为 28–34 亿元条件区间，估值方向改为 `UNCHANGED`；补贴分部归属未知只限制商业归因，不撤回报表韧性。
- 现金 cell 先以各自一致的口径结算集团现金与持续损失载体，再结算 parent owner cash。NCI、parent access 或资本开支性质未知时，owner cash 保持 `COUNT_CONDITIONALLY`；连续负集团现金、持续信用损失与净现金收缩仍可独立把 permanent loss 收紧或阻断。
- 现金流量表实际购建长期资产支出与分部资本性支出被保留为两套独立代理，禁止跨期切换或混算。

第二轮复验发现正集团现金但 owner scope 开放时缺少唯一分类，以及完整闭合、parent owner cash 低于 20 亿元时仍追查不存在的边界缺口。最终修订新增 `POSITIVE_GROUP_PROXY_OWNER_SCOPE_OPEN`，并把完整闭合后的研究动作改为调查真实现金转换原因。

## 最终材料性结论

- 当前三项企业判断明确、可反驳，没有以 UNKNOWN 退出：报表盈利有韧性但商业归因混合；正常盈利为 28–34 亿元条件区间；低杠杆降低近端永久损失，但 parent owner cash 只条件计入。
- 权益法利润有底层经营和实际分红支持，但未被直接当作现金；无法按责任边界分配的补贴增量没有被永久资本化。
- 三情景、管理层评价、owner cash、永久损失、估值方向和翻转事实均有明确当前处理。
- `LOCAL_UNKNOWN` 与 `MEASUREMENT_MISMATCH` 只限制对应主张。正现金开放边界、持续集团现金损失、商业归因未证均有可达、唯一的局部分支。

在本次限定范围内，未发现仍会材料改变投资结论、正常盈利、owner cash、永久损失或中心解释的问题，故予以 **ACCEPT**。
