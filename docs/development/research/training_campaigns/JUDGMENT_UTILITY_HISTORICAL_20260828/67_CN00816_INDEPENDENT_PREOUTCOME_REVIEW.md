# CN00816 Blind V3 最终独立审阅

## 结论：ACCEPT

V2 最终审阅指出的两项实质问题均已关闭。V3 的 J1 不再让并购减值经未调整归母利润跨轴改变经营判断；J3 对利润贡献、经营现金贡献只披露一项或两项同时披露的情形均可唯一执行。反例得到其声明的轴向量，`UNKNOWN` 仍只停留在缺失字段所属轴。没有发现会 materially 改变投资结论、永久损失判断或中心解释的剩余问题。

本次审阅只读取 V3 的 `PREOUTCOME_JUDGMENT.json`、`EXECUTION_RECEIPT.json`、指定的 V2 最终审阅，以及 2022/2023 两份官方年报；未读取 FY2024 结果、价格、回报、网络或其他文件，也未修改项目文件。

## 关键核对

### J1：并购减值已隔离，真实经营恶化没有被隐藏

`j1_adjusted_parent_profit` 只加回年报明示计入当期损益、且能由披露直接确定归母影响的并购相关商誉或合约权利减值；FY2024 与 FY2023 使用相同口径。若减值已确认但归母影响无法直接计算，仅利润子条件成为 `UNKNOWN`，规则明确禁止估计税务或非控股权益影响，也禁止改用受减值影响的报告归母利润触发该利润分支。

这项隔离没有删除 J1 应承担的经营恶化：基础物管收入及毛利率、非关联贸易应收和一年以上账龄仍可独立触发或限制 J1；调整后归母利润仍包含并购业务及其他业务的正常经营结果，只排除责任归属 J3 的明示并购资产减值。若减值达到重大阈值，则由 J3 `NEGATIVE` 承担永久资本损失信号。因此，同一减值不会重复压低 J1 和 J3，也不会使基础物管利润率或客户回款恶化消失。

R1 的事实因此唯一得到 `[POSITIVE, POSITIVE, NEGATIVE]`：J1 使用可直接计算的责任匹配归母利润，J3 由重大并购减值触发，J2 不受影响。

### J3：单指标、双指标及分化情形均确定

`profit_return` 与 `operating_cash_return` 已分别定义为单项重大被收购业务的当期实际贡献除以现金代价，均禁止自行年化；未披露项为 `UNKNOWN`，不是零。

- 只披露一种贡献且该贡献小于或等于零时，“所有已披露贡献均小于或等于零”直接触发 `NEGATIVE`，未披露的另一项不参与比较。因此 R7、R8 均唯一得到 `[POSITIVE, POSITIVE, NEGATIVE]`。
- 两项均披露且一项回报至少 10%、另一项低于 5%，或两项贡献一正一负时，`j3_return_divergence` 成立。它明确阻断低回报恶化分支，也阻断 `POSITIVE`，在没有重大减值或其他独立充分负面事件时进入 `MIXED`。因此 R9 唯一得到 `[POSITIVE, POSITIVE, MIXED]`。
- 单独披露的低于 5%正回报，只有在同一业务、同一指标对应的经营证据恶化时才触发负面；利润率恶化不能替经营现金回报匹配，经营现金恶化也不能替利润回报匹配。其余已披露但未达正负阈值的情形进入 `MIXED`，而不是事后择优取指标。

J3 的 `NEGATIVE` 仍按第一顺位保留重大并购减值、全部已披露贡献不为正、匹配恶化的低回报，以及“继续大额收购但既有重大收购仍无任何贡献披露”等独立充分事实。双指标分化只在无这些其他独立充分负面事件时保留为 `MIXED`，不会遮蔽已实现的资本损失。

### 反例与局部 UNKNOWN

R1-R9 及三条逐轴缺失反例均能按有序首配规则得到声明向量。特别是：单年集团经营现金流只改变 J2；关联违约只改变 J2；并购减值及被收购业务贡献只改变 J3；基础物管毛利率缺失只使 J1 为 `LOCAL_UNKNOWN`。每轴均先检查已披露的充分负面事实，再检查完整正面与混合条件；缺失字段不会跨轴传播，也不会覆盖另一轴已经披露的充分事实。

## 年报语义核对

2022 年报披露首置服务现金收购代价人民币 4.50 亿元、商誉人民币 2.49122 亿元、合约权利人民币 0.862 亿元，以及自收购日起综合利润贡献人民币 0.23688 亿元。2023 年报维持该商誉账面值，披露截至年末未出现相应减值，并在期后事项中披露润物嘉业现金代价人民币 3.238 亿元，同时明确当时无法提供进一步收购资料。这些披露支持 V3 将并购资产损失和单项被收购业务贡献留在 J3，并把未披露回报保留为局部未知；不存在需要依靠 FY2024 结果或额外假设才能执行的材料性口径缺口。

结论为 **ACCEPT**；无需再修改主体企业判断、三轴结算规则、反例或 UNKNOWN 处理。
