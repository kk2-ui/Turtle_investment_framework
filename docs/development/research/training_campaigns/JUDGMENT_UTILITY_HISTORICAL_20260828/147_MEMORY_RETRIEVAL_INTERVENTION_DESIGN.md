# 从提示词规则到可检验的训练记忆：下一轮 Holdout 的干预重构

## 已观察到的根因

天坛、立讯与东方财富的结果前配对都没有形成可归因的 Enhanced 经济处理差异。东方财富最具诊断性：Baseline 在没有 V4 的情况下已经把 TTFund 平台活动与金融电子商务分部的收入隔开，并拒绝把活动直接计为手续费、正常盈利、owner cash 或轻资本估值信用。Enhanced 使用 V4 后的实质处理相同。

这不是“Baseline 太好”或“需要更严格的 gate”。它表明把一条本来已进入 judgment-first 宪法与普通合格研究行为的规则再放入 Method Pack，不能构成有效训练干预。继续寻找一个 Baseline 恰好犯错的公司，或者把 Baseline 人为写弱，都会把结果导向伪验证。

## 新的训练对象

下一次增强组不再只是读更多行为规则，而是使用**受限的、机制相关的 Teaching retrieval memory**。这是训练系统实际可以拥有的记忆：已知历史案例经策展后留下的机制、反例、经营—现金传导和翻转条件；它不是目标公司的结果、估值、价格、买卖指令或字段清单。

Holdout 的隔离含义保持不变：目标公司及其结果窗口对 Baseline、Enhanced、memory curator 和 reviewer 都不可见。隔离不等于清除 Agent 从其他企业历史案例学到的机制。Enhanced 得到的正是待检验的“训练后状态”；Baseline 没有得到该状态。

## V5 的最小可检验干预

1. 选择未见 company cluster，selector 只可见结构元数据和 cutoff 前报告身份。
2. 独立 memory curator 在不读目标公司报告、目标结果或价格的条件下，从已完成 Teaching 库选择最多两张机制卡：一张同机制案例和一张 near miss。每张卡只能包含当时经营矛盾、管理选择、客户/经营反应、现金/资本传导、最强反方及“不可套用”的边界；不能传递案例结局数字或目标公司答案。
3. Baseline 与 Enhanced 接收完全相同的目标公司 cutoff-before 报告、工具和在线研究预算。Baseline 不接收机制卡；Enhanced 在同样的目标公司研究预算之外带着已冻结的训练记忆进入任务。这是训练状态的处理变量，不是额外的目标公司数据优势。
4. 两个 arm 都必须先写当前企业判断及其经济处理。只有**实际完成的** outputs 在正常盈利、owner cash、永久损失、估值方向或 rank-one research action 上存在材料差异，才可在不修改任一 arm 的前提下揭示结果。
5. 结果 custodian 仍只结算已冻结、与处理差异相连的经营或现金 cell。独立 reviewer 只判断：结果是否支持该材料差异，是否应改变下一案例的检索/判断行为。它不把某一案例结果扩张成方法有效或迁移验证。

## 防止新的防御性写作

- Mechanism card 不是新 gate：卡片不完整或相似案例不存在时，Agent 仍须完成目标公司的当前判断。
- 卡片不得成为“UNKNOWN”的替代形式。它必须改变或反驳一个明确的当前处理，否则不是 active memory。
- 不奖励卡片数、相似度分数、引用数、字段数、篇幅、置信语气或更少 UNKNOWN。
- 如果 Baseline 与 Enhanced 再次等价，结果继续封存；结论是本次 memory intervention 没有可检验增量，不是目标公司没有价值，也不是方法被验证。
- 只有一个已冻结的 memory retrieval 确实改变另一未知公司的结果前处理、随后又得到结果支持，才允许标记 `TRANSFER_CANDIDATE_CREATED`。仍不得标记 `TRANSFER_VALIDATED`。

## 为什么这比 V4 更接近中心目标

中心目标不是让 Agent 更会说“口径一致”，而是让它在不完整证据下借助已学到的企业机制，形成更有用、可反驳的经营与资本判断。V5 让干预变量从项目全局已经要求的通用纪律，变成可定位的跨案例机制记忆；同时保留 Baseline 的公允性、Holdout 的结果隔离和对材料经济处理差异的要求。

这是一项下一轮训练设计，不是验证结论。V4、V5、任何 Teaching 数量或任何单一盲判断都不授予 CJO、正式估值、BuyBand、报告或投资权限。
