# CN600161 天坛生物 FY2024 Holdout 投资者摘要

## 一句话判断

FY2024 明确强化了天坛生物“新增供给已被销售和正常利润吸收”的判断，但没有证明这些利润已完整转成上市公司母公司可自由支配的现金；因此维持 `POSITIVE_CREDIT / RAISE / COUNT_CONDITIONALLY / MAINTAIN_CONSTRAINT / UP`，其中 `UP` 仅为无价格的内在价值方向。

## 投资者真正需要知道的三件事

1. **经营吸收比结果前基准预想更强。** 血制收入约增 16.48%，实际销量增 10.05%，归母扣非净利润约增 37.52%；报告营业利润率约 42.40%，扣除结算列明的正向非经常项目后仍约 41.45%。折旧、研发与库存负担存在，但没有吞掉销售和利润改善，故 `normal earnings=RAISE`、管理层经营执行保留正面信用。
2. **现金没有同步兑现。** 集团 OCF 约 8.20 亿元、购建长期资产现金约 10.67 亿元，group cash proxy 约负 2.48 亿元，较上年下降约 15.64 亿元。应收、存货、采浆资金占用和应付款下降是已观察载体，但负值未达到冻结的结构性 adverse，成都蓉生 post-capex、必要留存和母公司净支持仍未闭合，所以只维持 `owner_cash=COUNT_CONDITIONALLY`，不跨轴改成 permanent loss 收紧或价值 `DOWN`。
3. **质量结果只是“没有观察到负面事件”。** 检查、许可证、再注册和 100% 自检/批签发合格率支持 `QUALITY_NEUTRAL_RESIDUAL`，不支持永久护城河升级。严重召回、跨期停产、重大 GMP 或许可证损害仍是明确翻转事实。

## 最强反方与应对

最强反方是：强利润可能部分来自销售费用下降、阶段性需求或产品组合，而库存增加约 10.25 亿元、经营现金大降可能预示未来消化压力。当前反方不足以否定 favorable，因为销量、收入、归母扣非利润和保守利润率同时通过冻结阈值；但它足以禁止把 FY2024 利润率永久化，并要求下一观察期同时验证销售持续性和库存/应收转现。

## 三情景

- **乐观：** 高盈利平台延续，库存与应收转成现金，资本开支回落，NCI/母公司上划闭合；owner cash 可升级为母公司可计入，`UP` 得到进一步支撑。
- **基准：** 高基数后增长放缓，但正常盈利仍高于结果前基准；现金转换逐步改善但 parent scope 仍 open；五项 treatment 维持不变。
- **悲观：** 阶段性需求/费用贡献消退，销量、利润率和归母扣非转弱，库存与应收继续吞噬现金；若形成结构性 cash adverse 或核心质量许可事件，则相应下调 normal earnings、停止计入 owner cash、收紧永久损失并转为 `DOWN`。

## 原判断复盘

原判断准确之处是：提前识别了经济吸收、拒绝线性外推现金、严格区分 group/NCI/parent cash，并将质量风险绑定到真实事件载体。主要不足是低估 FY2024 经营上行幅度，也没有在三情景中显式突出“强利润 + 弱但非结构性现金”的正交组合。

结果后 treatment code **无材料变化**；材料变化是证据结构：经营吸收置信度显著增强，而 owner-cash 闭合仍被阻止。下一轮训练应显式交叉经营吸收与现金转换两条轴，但该反馈仅在本案退休后使用，不得倒流改变本案。
