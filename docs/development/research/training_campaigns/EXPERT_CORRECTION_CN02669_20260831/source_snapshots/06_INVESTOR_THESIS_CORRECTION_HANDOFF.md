## 1. 为什么重开

根因分类：`MODEL + REASONING + WRITING`。

此前模型已正确计算出五年固定终值条件价`P_XIRR_FIXED_TERMINAL_5=HKD2.642317860`，但把它放在了主要研究价的位置。该数字固定第五年成交价为HKD3.682572210；这不是独立的收购价、合同回收价、法律终值或已有催化剂可支持的未来市场价格。因此，算术正确不等于该价格可以指导买入。

经济影响是材料性的：把条件终值当作行动终值，会让投资者把市场确认假设误认为已经由经营价值或现金流证明。当前HKD3.45在基础路线仍不合格，但“最高可买价”不能再被伪装成一个可执行的精确数字。

## 3. 原始投资者论点怎样被公平检验

中海物业的正方论点不是“央企背景所以现金一定归普通股”，而是以下链条同时成立：

1. 母体项目、品牌和招标资源持续提供较低获客成本与相对高质量的项目来源；
2. 城市公共服务和智慧工程在成熟后产生可以回收的利润与现金，而不是持续占用营运资本；
3. 留存资金最终以普通分配、注销式回购、净现金或可复算的高回报项目服务普通股；
4. 市场在三至五年内对上述改善给出可验证的成交价格。

第一项有部分支持，后三项尚未闭合。模型现在并列呈现母体支持与现金约束，而不是预设任何一条获胜：关联业务收入和资源可能支持项目供给；同时，年末应收同系及其他关联公司RMB805.644m、集团现金与上市公司单体现金的巨大差异、未汇出利润的税务附注，以及逐实体上游时间表未知，都限制普通股现金的可达性。

## 4. 缺失事实与禁止假设

以下事实缺失时，独立审阅不得把条件价升级为行动价：

1. 城市和智慧工程项目按cohort披露或可重建的成熟利润、账龄、验收与实际回款；
2. 普通股增量留存的具体用途及增量现金/利润回报；
3. 主要境内实体的上游限制、可分配储备、最低现金与实际汇出时间表；
4. 能独立支持五年HKD3.682572210成交价的催化剂、收购、合同现金回收或法律终值证据。

禁止假设包括：把集团现金全部当作上市普通股可分配现金；把关联方支持自动当作少数股东保护；把持有五年当作市场必须确认价值；以及把`P_LONG`、固定终值反解价和折价延续压力价平均成一条价格。

## 5. 独立审阅任务与接受标准

独立审阅者应从原始披露、模型输入和投资者港币现金流复核，而不是依赖作者叙述或旧`PRICE_IDENTITY_ACCEPTED_WITH_EXISTING_DATA_LIMITS`结论。

接受标准：

1. 复算长期、业务价值退出、无新增市场确认和有限确认四条回报路线，确认币种、税费、股数和时间一致；
2. 复算HKD2.642317860在固定HKD3.682572210期末成交价下为10%XIRR，且确认该终值没有独立行动证据；
3. 复算HKD2.231347447时终值随相对折价变为HKD3.017760903，确认它只是一条压力路径；
4. 核验母体支持、关联现金占用、单体现金、未汇出利润税项和上游未知项的事实锚点；
5. 判断新的`INVESTOR_THESIS_ACCEPTANCE`是否完整、公平地呈现强正方论点与永久损失路径；
6. 在缺少第4节事实时，保持`PRIMARY_ROUTE_UNKNOWN`和行动价`UNKNOWN`，不得因反解公式闭合而签发黄金或买入结论。

本交接不构成独立验收，也不把候选升级为正式黄金报告。
