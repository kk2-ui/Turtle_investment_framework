# 中海物业（02669.HK）：现金还在，新增长还没有证明回报

## 00. 三分钟看清这家公司

中海物业（02669.HK）是中国建筑体系旗下的港股物业管理平台，1986年在香港起步，已有近40年服务历史。2025年末，公司在管面积约4.78亿平方米，覆盖内地144个以上城市及港澳地区，服务超过1,800个项目，员工38,042人。

2025年，公司实现收入RMB149.60亿元、归属普通股利润RMB13.67亿元，年报由安永审计并获无保留意见。按系统同口径的51家港股物业公司样本，收入、归属利润和ROE分别处于86.7%、91.5%和88.6%分位，规模和盈利已在第一梯队；毛利率却只有20.5%分位。这是读懂公司的起点：它不是一家尚未形成规模的小物业商，而是一家规模很大、净利效率仍高、基础利润率却正在承压的龙头。[source: E02669-AR2025 pp.34-46; audited statements pp.82-83]

**中海物业不是一家濒临破产或利润失真的公司。真正的问题是，旧住宅项目的低获客成本正在被城市公共服务、智慧工程和更长回款周期稀释，而数十亿元留存现金能否公平地成为普通股价值仍未证明。**

未来五年的物业行业不会失去需求，却会失去过去那种由新房交付推动的轻松增长。新住宅项目减少，存量社区和老旧小区托住基础服务，医院、学校和城市空间成为新订单来源。利润却不会随面积自然增长：住宅调价困难，公共项目受招投标和地方财政约束，工程项目还要先投入、后验收。中海正在从最熟悉、获客成本最低的业务，走向需求稳定但资本回报更不确定的业务。

这也是为什么公司有价值，却不一定值得按任何价格买。2026年8月11日收盘价为HKD3.45。按照历史分红、现金上游约束和近年资本回报推演，三年、五年税费后年化回报分别为 **3.87%和3.92%**，都低于10%。五年若直接按模型经营价值HKD3.6010成交，现价XIRR只有3.49%；若不加入新的市场确认、保留当前相对定价关系，则为4.35%。两条都不是买入建议，而是先把“生意值多少”和“市场愿意怎么交易”拆开。

本报告采用两条回报路线，但此刻**不指定主要行动价格**。长期所有者路线只看一年可以重复的现金分配和有效留存，不假设卖出股票；由于留存质量和现金可达性尚未长期闭合，它只能给出条件区间。有限期限路线把三至五年股息、税费、经营价值、现金实现和届时卖价放在同一组实际日期现金流里。五年是城市项目成熟、回款和资本配置的观察窗口，不是承诺五年必卖；现有证据也不足以支持一个固定的五年市场卖价。因此，`P_LONG`、按业务价值退出和固定终值反解价都保留为不同的条件诊断，主行动价为`UNKNOWN`，不能为了填表硬选一个数字。

### 从开发商项目到普通股现金

中海物业的价值链从项目来源开始。关联开发商交付住宅，物业公司取得长期服务合同，分散业主持续缴费，区域团队用人员、分包和系统履约，经营现金最后才进入分红、留存或集团资金安排。城市公共服务则从投标开始，经过人员和设备前置、考核、验收与结算，机构客户付款后才形成现金；智慧工程还多一层硬件采购、施工和质保。三条链都叫物业服务，却有不同的获客成本、毛利、营运资本和普通股现金速度。[source: E02669-AR2025 pp.34-46, 121-133]

公司过去的循环是：母体低成本供给项目，区域密度降低单位成本，履约记录又帮助第三方拓展，更多项目继续摊薄后台费用。今天的核心取舍变成增长、服务质量和资本回报不能同时最大化。退出低价项目会减少面积但保护现金；继续拿公共项目能维持收入，却可能增加应收和启动投入；智慧工程可能提高效率，也可能把轻资产服务变成项目承包。报告因此把面积增长降为观察指标，把项目利润、回款和增量资本回报放到裁决位置。

### 乐观与悲观叙事怎样裁决

乐观叙事是“央企母体持续拿地，公共服务空间巨大，规模龙头会自然胜出”；悲观叙事是“地产下行、地方财政和人工成本会让物业利润持续归零”。现有证据只支持中间判断：成熟住宅和母体核心城市项目提供收入底部，主动退出亏损项目也证明管理层会取舍；毛利、经营现金和新增业务回报下降又说明规模不会自动形成价值。以后应由成熟合同利润率、城市项目回款、智慧工程验收现金、关联应收和每一元新增项目资本带来的税后利润裁决，不能用面积、母公司土地储备或行业空间代替。[source: E02669-AR2025 pp.34-49, 121-133]

## 01. 公司发展、身份与当前生意

**第一幕，1986至2015年：母体开发住宅，中海物业取得低成本项目入口。**

中海物业不是2015年上市时突然出现的一家公司。它1986年在香港成立，最初的任务就是服务中海地产开发的住宅项目；1991年进入内地以后，又把香港形成的物业管理标准复制到广州、上海等城市。早期扩张并不需要像独立物业公司那样逐个竞标获客。开发商建成住宅，中海物业接管项目，住宅交付后再由成千上万的业主长期支付物业费。母集团承担了最昂贵的获客环节，公司则积累人员、流程、品牌和区域密度。

这解释了上市时看似矛盾的两组数字：约89.3%的在管面积来自控股股东及关联开发项目，但超过八成收入由集团以外客户支付。项目来源高度依赖母体，不等于每天的营业收入由母体输血。只要住宅已经交付入住，保安、保洁、维修和客服就不会因为地产销售转弱而立即消失。中海早期的经济优势，是低获客成本与长期服务需求的结合，而不是关联方直接支付利润。[2015年上市资料](https://www.hkexnews.hk/listedco/listconews/sehk/2015/1023/ltn20151023050.pdf)

这里的“母体”还要拆开。中海物业的直接控股股东是中海集团，最终控制人是中国建筑；通常被投资者称作“母公司”的中海发展，则是同一控制体系内最重要的开发商和项目来源方，并非中海物业的直接母公司。中国建筑决定集团资本纪律和控制边界，中海发展决定新盘交付、关联服务和部分应收质量。把三者混成一个名字，会同时误判经营依赖和治理风险。

**第二幕，2017至2023年：通过小型平台和公开投标证明第三方获客能力。**

2015年采用介绍方式上市，没有向市场募集新资本。这一点很重要：上市没有突然改变公司的生产能力，却把留存利润怎样使用的问题交给了独立上市公司的董事会。2017年以RMB1.90亿元收购中信物业，2019年取得武汉平台，2020年进入更多医院、政府和交通设施，2022年再收购广州利合。这些交易规模不大，目的更像购买区域团队、客户关系和项目管线，而不是用巨额资本购买当期利润。

到2022至2023年，这条外拓路线第一次证明自己不只是故事。2022年第三方新拓项目超过一半；2023年新项目70.6%来自第三方，年末第三方在管面积达到40.5%。同年收入约RMB130.9亿元、归属利润约RMB13.45亿元、经营现金流约RMB15.05亿元，三者仍同步增长。公司已经能离开母集团的项目管线参与市场竞争，而且当时新业务尚未明显破坏现金转换。

**第三幕，2024年：主动退出低效面积，首次把项目质量放在规模之前。**

真正的转折不是“第三方变多”本身，而是第三方项目的类型继续变化。2024年公司主动退出4,450万平方米亏损或低效项目，包干制毛利率升至14.0%，说明项目筛选确实能改善利润；同年经营现金却先于利润转弱。2025年新增项目中85.1%来自第三方，68.4%为非住宅，城市空间占49.5%。医院、学校、政府物业、市政环卫和智慧工程需要投标、前置团队、设备、验收及更长回款，它们与成熟住宅不是同一种合同。[source: E02669-AR2025 pp.34-46]

**第四幕，2025年至今：城市与工程扩张开始接受利润、回款和资本回报检验。**

所以2025年的收入增长而毛利、利润和经营现金同时下降，不应只看成一个偶然坏年份。它是公司从“母体送项目、分散业主长期付费”迁移到“自己竞标、先投入再等待机构客户验收”的结果开始显现。公司过去创造价值的能力是真实的，未来增长却必须重新证明；面积仍然重要，但已不能代表同样的每股经济价值。[source: E02669-AR2025 pp.34-46, 121-133]

## 02. 行业未来：新房退潮以后，物业公司靠什么增长

物业行业正经历的不是需求消失，而是利润池迁移。过去二十年，新房交付不断创造新小区，开发商指定或推荐的物业公司几乎在住宅建成时就获得客户。中海物业尤其受益：母体开发项目降低了获客成本，住宅交付以后，收费对象又从开发商变成大量分散业主。地产开发和物业服务因此曾经一前一后地增长，却不是同一种周期。

**新房带来的行业顺风正在明显减弱，但中海自身的项目管线没有简单消失。** 2025年全国住宅新开工和竣工面积分别下降19.8%和20.2%；2026年前五个月又分别下降23.4%和25.0%。新开工减少会在未来数年逐渐传导为更少的新增交付，首先影响开发商输送的新住宅项目，其次影响交付前服务、案场、车位和其他地产链业务。[国家统计局2025年房地产数据](https://www.stats.gov.cn/sj/zxfbhjd/202601/t20260119_1962324.html)；[国家统计局2026年1至5月房地产数据](https://www.stats.gov.cn/sj/zxfbhjd/202606/t20260616_1963950.html)

中海发展却在行业收缩期逆周期补充核心城市项目。2025年它取得35幅地，新增总建筑面积499万平方米、权益面积445万平方米，权益地价约RMB924.2亿元；其中73.9%的权益地价投向香港、北京、上海、广州和深圳。年末土地储备面积下降12.4%，因此反映的是竣工和销售快于补库，并不等于停止拿地。2026年前七个月又取得约140.8万平方米权益建筑面积、投入权益地价约RMB216.0亿元；仅7月便在深圳、太原、北京和香港取得5幅地。同期前七个月合约销售额增长13.2%，销售面积下降12.6%，显示母体正在用更少的面积集中于价格更高的核心城市项目。[中海发展2025年年报](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0424/2026042402430.pdf)；[中海发展2026年7月经营更新](https://www.coli.com.hk/NewsCenter/Info?itemid=5926)

这对中海物业是缓冲，不是新的高增长保证。2025年中海发展新增土地的总建筑面积只相当于中海物业年末在管面积约1%，而且从拿地、开发、预售到交付接管通常跨越数年；同系项目也不等于每幅地必然由中海物业承接。它的积极意义主要是保留一批核心城市、获客成本较低的未来住宅项目，并带来交付前服务机会。全国新盘总量下降仍会压低行业增量，中海发展的逆周期拿地则使中海物业的关联项目来源更可能是“增长放慢、质量改善”，而不是直线消失。

这并不意味着基础物管会随地产一起萎缩。房屋一旦交付，保洁、安保、设备维护和客服便成为重复发生的需求。2025年城镇人口仍增加1,030万，城镇化率升至67.89%；“十四五”期间全国改造老旧小区超过24万个，覆盖居民超过4,000万户。未来的基础盘将更多来自已经入住的社区、老旧小区和城市更新，而不是不断增加的新楼盘。[国家统计局2025年人口与城镇化数据](https://www.stats.gov.cn/sj/zxfb/202601/t20260119_1962330.html)；[“十四五”老旧小区改造进展](https://www.zyshgzb.gov.cn/n1/2025/1013/c461089-40581002.html)

但存量需求稳定，不代表利润率稳定。住宅物业费调整需要业主协商，部分前期住宅、保障房和老旧小区还受政府指导价约束；人工、分包和维修成本却不会等待调价。老旧小区常见“收费低、收缴率低、服务标准低”的循环，改造完成只能说明有人需要服务，不能说明服务商能够获得高回报。[老旧小区物业长效机制案例](https://www.bjsjs.gov.cn/gongkai/zcwj/202512/t20251225_757285.shtml)；[住宅物业收费定价边界](https://www.moj.gov.cn/pub/sfbgw/flfggz/flfggzdfzwgz/202308/t20230809_484245.html)

成本端也没有随地产退潮而自动变轻。2025年全国规模以上企业社会生产和生活服务岗位平均工资增长约2.9%。中海自己的员工人数和员工成本下降，直接经营成本却仍增长8%，说明它已经通过人员和组织调整消化了一部分工资压力，剩下的毛利损失更多来自分包、项目组合和启动成本。未来成熟住宅能否守住利润，关键不是宏观工资是否停止上涨，而是每个区域能否用密度和流程效率覆盖工资与分包增长。[国家统计局2025年工资数据](https://www.stats.gov.cn/sj/zxfbhjd/202605/t20260515_1963707.html)

因此，成熟住宅市场会出现一种与汽车零部件不同的竞争。麦格纳的工厂如果长期赚不到资本成本，弱者最终无力更新设备，退出会帮助幸存者恢复利润；物业公司的主要投入是人员、关系和营运资本，低回报竞争者可以依靠地方资源、母体支持或低价投标长期留下。物业需求为中海提供收入底线，却没有替它提供利润率回归保证。成熟项目的价值只能来自区域密度、收费纪律、单位成本和主动退出亏损合同。

**行业第二个增长方向是公共服务，但它受到地方财政约束。** 医院、学校、政府物业、市政环卫和城市空间的需求不会随着住宅销售同步消失；与此同时，2025年全国一般公共预算收入下降1.7%，地方一般公共预算支出只增长0.2%，土地出让相关收入继续下降。地方政府会继续购买必要服务，却会更在意投标价格，也可能拉长考核、结算和付款周期。公共服务给物业公司的是更稳定的合同需求，以及更重的应收和更薄的资本回报，这两面必须同时看到。[财政部2025年财政收支](https://bgt.mof.gov.cn/zhuantilanmu/rdwyh/ysbgjyszx/202601/t20260130_3982923.htm)

同行比较不能只看“城市空间”四个字。华润万象生活同时拥有购物中心品牌、租户生态和高毛利商业运营，它可以证明公共空间服务不必天然亏损，却不适合给中海的政府、学校、医院和环卫合同定正常利润率。更接近的参照是机构与公共物业占比较高的招商积余、特发服务和保利物业。

招商积余2025年非住宅基础物管毛利率为10.15%，特发服务综合物管为8.00%、政务服务为12.77%；保利物业公共及其他物业收入达到RMB32.97亿元，但没有单列该业务毛利率，公共客户账期通常为30至90天。这些资料共同支持的不是一个精确点，而是一个约8%至13%的成熟毛利率观察区间。继续扣除总部费用、信用损失和维护投入并计税后，约3%至6%的普通股经营利润率更适合作为中海城市业务的保守边界。中海当前采用3.5%，仍在区间低端；它没有因此获得成长溢价，因为自己的项目利润和现金尚未披露。[招商积余2025年报](https://disc.static.szse.cn/download/disc/disk03/finalpage/2026-03-14/aefe8a10-4907-435f-b815-35ed83a3f03f.PDF)；[特发服务2025年报](https://disc.static.szse.cn/disc/disk03/finalpage/2026-04-21/23d2e6a2-cad8-4fc9-aa12-fc784abb66ad.PDF)；[保利物业2025年报](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0430/2026043001632.pdf)

**第三个方向是智慧工程，它更接近项目生意而非软件订阅。** 标准模块和平台能够重复使用，确实有可能降低长期人工成本；硬件采购、定制开发、施工、验收和质保又会反复占用现金。行业数字化可以提高基础物管效率，却不保证承接智慧工程本身赚钱。中海只有在旧项目完成验收收现、新项目毛利覆盖研发和履约成本以后，才能把这部分增长视作价值。

未来五年，行业会从“谁的面积增长最快”转向“谁能把存量合同、公共项目和技术投入变成现金”。对中海而言，成熟住宅是盈利底座；城市公共服务是有条件的增长；智慧工程仍处在证明阶段。地产下行减少了母体提供的低获客成本项目，地方财政又压住公共项目价格和回款。公司若能守住成熟业务、退出亏损合同并让新项目在三年内成熟，行业迁移会带来第二条增长曲线；若只是用更多应收换取收入，规模增长会继续稀释每股价值。

时间上，前两年最可能看到的是旧住宅新增放慢、公共项目继续并表、利润和现金仍有波动；第三至第五年才会看清2024至2026年拿下的城市项目究竟是爬坡还是低回报。到那时，行业总需求大概率仍在，决定中海价值的却是三个更窄的问题：基础合同有没有守住约12%的利润池，公共项目回款能否接近成熟同行，智慧工程能否停止用合同资产解释现金缺口。这是报告采用五年持有期的经营理由，而不只是估值方便。

这幅前景既不是行业衰亡，也不是必然复苏。它意味着中海仍可长期经营，但投资回报更依赖管理层选择合同、回收现金和分配资本的能力。价格需要为这种不确定性留下余地，后面的估值不会预先计入行业全面恢复。

## 03. 商业模式、护城河与增长质量

先把公司向谁卖什么说清楚。年报把2025年约RMB149.60亿元收入分成四项；这四项是会计披露口径，不等于四种相同的生意。

|---|---:|---|---|---|

为了判断长期价值，还要把会计口径重新拆成三种主要的现金形成方式。物业管理服务里面同时装着成熟住宅、商业物管和新扩张的城市公共服务，它们不能共用一个利润率；非居民增值服务里面既有交付顾问，也有智慧工程，不能把整项都当成软件；居民增值服务依附于既有社区入口，估值中把它放在成熟服务底座，而不另给一条独立的高增长曲线。以下拆分只是解释经济机制，不会增加或重复任何收入和利润。

### 成熟住宅与商业物管：先收经常性物业费，再承担全部现场成本

包干制可以写成一个直观公式：**可收费面积 × 合同单价 × 实际收缴，减去人工、保洁、保安、维修和分包成本。** 2025年物业管理收入的97.9%来自包干制，而包干制面积占84.3%。合同使收入具有重复性，却没有把收入和利润永久锁定：项目可能到期或退出，物业费可能收不齐，工资和分包成本也可能在单价不动时上涨。

这类业务真正的优势来自区域密度和项目筛选。同一区域项目越集中，管理人员、供应商和维修资源越容易共用；退出长期亏损项目也能释放人员和营运资本。过去六年包干制毛利率约为10.9%、10.8%、10.6%、12.7%、14.0%和12.4%，均值约12.1%。2023至2024年的改善证明成本和退出工具有效，2025年的回落又说明这些工具没有形成永久提价权。合理起点是守住约12%的利润池，而不是把14.0%当作必然恢复目标。

居民增值服务是这张社区网络上的附加利润，而不是另一个面积故事。2025年收入下降12.0%，毛利率却由25.5%升至34.0%，说明少做低效零售和营销、增加社区资产管理等高毛利服务，可以在收入缩小时提高利润。它验证了“客户入口可以变现”，却没有证明每个社区都能持续提高人均消费。

### 城市与公共服务：先中标和配置资源，后考核、结算和收款

医院、学校、政府物业、市政环卫和城市空间通常由机构客户付费。公司中标后要先配置项目经理和专业团队，部分合同还有设备、保证金、联合体和分包；收入随履约确认，现金则要等考核、结算和付款。2025年城市空间收入增长24.8%至RMB24.30亿元，证明公司能拿项目，却没有披露相应毛利、启动资本和累计回款。[source: E02669-AR2025 pp.37, 40-46]

中海自己的公开合同已经能说明这门生意怎样赚钱和亏钱。中南大学项目每年约RMB978万元，合格投标价只相差约4.3%，价格权有限；北京协和医院转化医学楼三年约RMB3,180万元，55,955平方米配置164人，合同金额与公告中的月度“折合人工费”乘服务期接近，说明医院物业首先是人员配置和效率生意，但这一采购口径不是工资或项目成本；青岛城阳三年RMB8.04亿元项目则由联合体承接，至少45%的预算需分包给中小企业，并按日、季、年考核，低分会扣款甚至退出。中标额看起来很大，真正的利润却由人员、分包、保证金、考核和付款速度共同决定。[中南大学项目](https://www.ccgp.gov.cn/cggg/zygg/zbgg/202501/t20250116_24078107.htm)；[北京协和医院项目](https://www.ccgp.gov.cn/cggg/zygg/zbgg/202408/t20240821_22955582.htm)；[青岛城阳项目](https://ggzy.qingdao.gov.cn/c/TradeDetals-ZtbShow/155003-5070-1-2-0/14af2f96-c723-4599-8b25-9563bebffc59-B03CE5B6FC1D2D3C2D5FCEBC39AA2406.html)

公共设施项目通常应在12至24个月看到成熟迹象，市政环卫和综合城市服务可以延长到18至36个月。第二年应看到应收强度停止上升，第三年应看到续约、接近成熟同行的回款和正累计利润。联合体中标额不能直接视作中海收入：分包、垫资和利润分配没有披露时，只能把合同当作项目能力证据，不能当作高回报证据。

### 智慧工程与非居民项目：软件可能复用，硬件、施工和验收仍会占钱

公司提供咨询、定制软件、智能硬件、系统集成、施工和运维，并不是收取订阅费的纯软件公司。平台和标准模块可以重复使用，理论上能够摊薄研发；定制开发、硬件采购、施工、验收和质保却会反复占用人员和现金。[中海物业智慧科技业务](https://www.copm.com.cn/zhwy)；[华为与中海物业智慧园区合作](https://www.huawei.com/cn/news/2019/7/huawei-copl-smart-campus-agreement)

2025年非居民增值服务毛利率由13.1%降至7.2%，分部利润由RMB1.465亿元降至0.638亿元。管理层提到研发投入和摊销，但全集团无形资产摊销只有RMB0.224亿元；即使全部归给智慧工程，也解释不了约RMB1.14亿元的毛利缺口。前期投入是真实因素，却不能替价格竞争、港澳低毛利工程和项目组合承担全部解释。只有旧项目完成验收收现、新订单毛利覆盖研发和履约成本，软件复用才真正属于股东。[source: E02669-AR2025 pp.37, 43-46, 121-133]

### 护城河不是“面积大”，而是项目来源、区域密度和履约信用能否留下利润

中海的母体项目曾显著降低获客成本，央企身份和履约记录有助于争取公建项目，区域密度也能节约现场成本。这三项是真实优势，但都不是网络效应或普遍定价权。母体项目会随开发交付变化，公建项目仍要投标，业主也不会因为公司在另一座城市管理更多面积而接受更高物业费。

所以三类主要业务虽然都能增长，对股东的含义并不相同：成熟物管要守住收费、收缴和单位成本；城市服务要证明成熟后的资本回报；智慧工程先要止损并收现。公司已经证明能够获客和履约，尚未证明新增项目普遍具有高回报。增长价值不能归零，也不能在现金证据出现前提前计入。

## 04. 治理、控制权与资本配置

中海物业的控制链同时提供资源和约束。中海集团直接及通过全资公司合计控制约61%的股份，最终控制人为中国建筑；中海发展是同系开发商和主要业务伙伴。2025年仍有57.3%的在管面积来自中国建筑及中海体系，但当年新增项目85.1%来自第三方。这两组数字说明，公司已经能够外拓，却还没有脱离集团形成的存量项目、品牌、投标资源和结算关系。

母体自身的状态会沿三条路径传导。第一是项目供给：中海发展2025年合约销售额下降19.1%，收入下降9.2%，归属利润下降18.9%，年末土地储备面积下降12.4%；但它同年仍取得35幅地，权益地价约RMB924.2亿元，位居行业前列。2026年前七个月销售额又增长13.2%，并新增约140.8万平方米权益建筑面积。它的财务状况仍显著好于多数民营开发商，净负债率34.2%、利息覆盖2.8倍，并不支持短期断裂判断。更准确的结论不是“母体停止送项目”，而是全国交付总量下降之中，中海发展以核心城市逆周期拿地为中海物业保留了一条较优质、但需要数年转化且规模有限的关联住宅管线。[中海发展2025年年报](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0424/2026042402430.pdf)；[中海发展2026年7月经营更新](https://www.coli.com.hk/NewsCenter/Info?itemid=5926)

第二是客户和回款。2025年来自中国建筑、中海集团、中海发展及其他关联公司的物业和增值服务收入合计约RMB16.47亿元，约占总收入11%；年末应收同系公司及其他关联公司款项约RMB8.06亿元，其中同系贸易应收有RMB2.22亿元账龄超过一年。集团信用降低了突然违约的概率，却不能消除结算拖延和普通股资金被占用。母体分析不能停在“央企不会倒”，还要看关联收入是否按时变成现金。[source: E02669-AR2025 pp.203-205, 218-219]

第三是资本配置。中国建筑规模大、融资能力强，并公开强调市值管理、分红、ROE和现金流质量，这提高了集团重视股东回报的可能性；但它不是中海物业现金必须按某个比例分出的法律承诺。相反，同一控制体系也能发起关联收购、财务公司存款和项目协同。对普通股东真正有意义的证据，是中海物业继续提高普通分配、注销式回购，或用可复算的项目回报证明留存资金创造了价值。[source: E02669-AR2025 pp.203-205, 210-220]

这些选择并不是由一个抽象的“央企体系”自动作出。张贵清2020年2月起任董事长，负责董事会和战略；他做过地产开发、营销、区域公司总经理和中海宏洋CEO，擅长的是集团协调、项目和区域扩张。肖俊强2023年2月升任CEO，长期从事物业运营，做过北京物业总经理、人力资源负责人、总裁助理和副总裁，负责经营目标与日常执行。CFO甘玉辉有超过38年会计、审计和财务经验。往下一层，李振西负责内地物业运营，刘洪兴负责增值服务和工程管理。成熟项目利润、城市项目回款、智慧工程止损和集团现金用途，因此都有可以追责的管理线。[董事会成员](https://www.copl.com.hk/en/board)；[高级管理层](https://www.copl.com.hk/en/manager)

| 肖俊强，CEO | 长期物业运营经验，能够执行项目筛选和组织调整 | 新项目成熟后能否同时交出利润、回款和续约 |
| 甘玉辉，CFO | 财务、审计和资金管理经验 | 大额境内现金能否通过分配或高回报用途服务普通股 |

现任董事长与CEO组合从2023年才正式形成，不能把公司上市以来全部增长都记在他们名下。更公平的成绩单从这里开始：2023年，公司明确提出发展城市空间综合服务，当年第三方新项目占70.6%，收入、利润和经营现金仍同步增长；2024年主动退出4,450万平方米项目，包干制毛利率由12.7%升至14.0%，归属利润增长12.5%，但经营现金已经从约RMB15.05亿元降至重述后的RMB13.38亿元；2025年继续退出项目并扩大城市空间，收入增长6.0%，归属利润和经营现金却分别降至RMB13.67亿元和RMB11.53亿元。管理层证明了能拿项目、能清理亏损合同，尚未证明新组合能恢复资本回报。

2025年董事长仍把“综合城市空间服务运营商”列为长期方向，并将住宅、非住宅和创新增值服务作为三大板块。这意味着新业务拥有集团资源和明确负责人，也意味着利润与现金恶化不能全部归咎于一次外部冲击。城市服务扩张是管理层主动选择，今后应以成熟项目毛利、续约、营运资本和累计回款接受检验，而不是只展示中标额和面积。

激励也要区分“有绩效约束”和“与普通股完全一致”。执行董事薪酬包含与集团结果及个人表现相关的奖金；2025年利润转弱时，张贵清绩效奖金由RMB120万元降至95万元，说明业绩并非无关，肖俊强奖金由RMB87万元小幅升至90万元，又说明它并不与每股价值机械同步。截至2025年末，董事及CEO没有披露持有中海物业股份，张贵清只持有2万股中海发展；历史股权激励也来自中间控股公司。管理层有职业声誉、奖金和集团考核约束，却缺少有分量的中海物业持股。[中海物业2025年年报](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0429/2026042900389.pdf)

所以这里的管理层结论是：**物业运营能力已经得到证明，资本配置可信度仍属中等，对中海物业少数股东的直接利益一致性偏弱。** 保守判断采用35%普通分配、只认可一半超额现金，并用最近两年的低端增量回报处理新投入，已经包含了这种不确定性；不能再另加一个模糊的“管理层折价”，否则会重复扣减。

市场对资本配置的敏感性有公开证据。2023年10月，公司提出以不超过HKD9.50亿元收购同一控制体系内的服务公司，初始对价约17.54倍历史盈利；公告后首个交易日股价相对基准下跌约16.5个百分点、成交量约为事前均值13.8倍。交易终止后首个交易日相对基准上涨约8.1个百分点。这不能证明单一因果，却说明股东高度关注集团现金会怎样使用。[收购公告](https://www1.hkexnews.hk/listedco/listconews/sehk/2023/1011/2023101100990.pdf)；[终止公告](https://www1.hkexnews.hk/listedco/listconews/sehk/2023/1229/2023122900644.pdf)

这次反应之所以重要，不是因为一项取消的交易决定公司价值，而是它暴露了普通股东最在意的问题。公司账上有大量现金，日常业务又不需要重型厂房；如果现金只是沉淀，股东得到的回报有限，如果现金进入估值不低的关联收购，股东还要承担新增项目回报不及预期的风险。市场真正担心的不是现金是否存在，而是现金在谁的控制下、最终为谁创造价值。

最近三年的资本成绩单比口号更有用。2023至2025年归属普通股利润合计RMB42.24亿元，经营现金流RMB39.96亿元，普通股现金分配及回购约RMB15.16亿元。也就是说，利润中的大约三分之一明确回到了股东，剩余大约三分之二留在公司。同期普通股权益增加RMB26.76亿元，说明留存并未在会计上消失。

这些留存去了哪里？公开可识别的固定及无形资产新增约RMB4.05亿元，2025年合同资产比2024年增加约RMB3.26亿元，2023至2025年现金及银行结余增加约RMB11亿元。剩余部分还穿过应收、应付、其他营运资本、收购和币种重述。各项不能硬拼成一条精确等式，但数量级已经说明：大部分留存进入现金、普通股权益和营运资产，并没有被大型并购迅速花掉。这反对“留存全部毁值”，却仍不能证明每一元都值一元。

2017年以来公开可识别的平台收购及增资合计约RMB3.12亿元，相对累计利润并不大。旧平台多数只看得到入场价格：中信物业约14.9倍历史盈利，广州利合约11.2倍，武汉中建物业的价格则低于当时现金。它们说明管理层并未普遍高价抢规模，却仍不能证明并表后的长期现金回报。

2025年中建物业提供了一个更接近可跟踪 cohort 的样本。中海向目标公司增资RMB3,900万元取得70%，资金留在目标公司而不是付给卖方；目标约有17个项目，2024年收入RMB8,878万元、税后利润RMB483万元、贸易应收RMB3,425万元。把2024年税后利润按70%权益比例折算后除以增资额，入场收益观察约8.7%；把公告所列2023年至2025年9月年化平均税后利润同样按70%折算，约13.5%。这个区间横跨10%至12%的资金成本，说明交易既不是明显毁值，也没有证明高回报；贸易应收相当于2024年收入的38.6%，这不是逾期率或已经损失的现金，更不能冒充增资后的项目ROIC。投资者必须等2026至2028年的利润、应收和经营现金，才能评价这笔新增资本的真实回报。[中建物业增资公告](https://www1.hkexnews.hk/listedco/listconews/sehk/2025/1224/2025122400711.pdf)

管理层2024年主动退出亏损项目，是资本配置成绩单中的正面记录。它表明公司愿意放弃收入和面积来改善利润，而不是只追求排名。2025年继续扩张以后，回款和公司总量资本回报又转弱，说明退出工具有效但不足以抵消新业务的资本压力。管理层到底是在把组合换得更好，还是不断用新低回报项目替换旧低回报项目，要看未来两三年的累计现金，而不是单年新增面积。

2019年以来书面普通派息政策约为归属利润30%。十年名义普通股息没有下调，2024、2025年普通派息率约35.8%和41.9%；但境内未汇出利润的大额税务附注和长期现金沉淀，又反对把集团现金全部视作五年内可分配。保守判断采用35%分配率，30%作压力，42%作较好情形；特别股息和小额回购不外推。

因此，35%的普通分配并不是随意给出的保守比例，而是介于30%书面政策和最近约42%实际分配之间。对存量现金只认可一半，则反映另一项不同判断：公司有十年持续分红记录，现金可达性不可能为零；大额未汇出利润和关联配置风险又说明不能按面值计算。治理没有触发立即否决，但现金只有通过分红、注销式回购或高回报投资，才会持续提高普通股每股价值。

## 05. 经营与财务趋势

2021至2024年，收入、毛利和利润大体同向增长；2025年收入继续增至RMB149.60亿元，毛利降至22.47亿元，归属利润降至13.67亿元，经营现金流降至11.53亿元。把公司缩成每RMB100收入，2024至2025年毛利由16.6降至15.0，营业利润由14.3降至12.2，归属利润由10.7降至9.1，经营现金由9.5降至7.7。

员工人数和员工福利开支并未上升，直接经营成本却增长8.0%，所以毛利率下降不能只归因工资。业务组合、分包、新项目爬坡和定价至少共同作用。居民增值服务同时出现收入下降、毛利增加，进一步否定“所有业务都受同一行业冲击”的简单解释。

2025年贸易应收增加带来约RMB4.00亿元现金占用，合同资产增加约RMB3.27亿元；合同资产通常预计一年内结算，但预计结算不是已经收现。下一年度若顺利验收回款，2025的一部分恶化属于时点和爬坡；若合同资产继续积累并伴随减值，低回报增长将成为主解释。[source: E02669-AR2025 pp.128-133]

| 年度 | 收入（RMB亿元） | 归属利润（RMB亿元） | 经营现金流（RMB亿元） |
|---|---:|---:|---:|
| 2022 | 109.00 | 10.94 | 10.45 |
| 2023（后续重述） | 130.90 | 13.45 | 15.05 |
| 2024（重述） | 141.13 | 15.14 | 13.38 |
| 2025 | 149.60 | 13.67 | 11.53 |

利润仍有现金支撑，但2025年的规模、利润和现金背离必须进入保守估值。下一年度的项目利润和回款会决定它是暂时爬坡还是经营结构恶化。

## 06. 现金能力与普通股可得现金

这一节要回答的不是“账上有多少钱”，而是正常经营一年产生的钱怎样穿过维护投入、少数股东、分红和留存，最后成为普通股股东可以收到或认可的价值。

公司现金能力不能简化为经营现金流减资本开支，也不能把全部留存当作毁值。经营驱动模型生成的正常普通股盈利为RMB896.980百万元，第一年按35%分配RMB313.943百万元。原公司总量再投入代理为RMB365.442百万元，先扣已经进入维护成本的RMB51.016百万元；主情景又已经在owner earnings中扣除RMB137.713百万元经常回款负担，因此未来再投入还要排除这一次重复，最终只有RMB176.713百万元进入增量回报。余下资金中80%形成新增现金，20%用途无法解释而暂不计值。每一元只能进入分配、经营价值、新增现金或损失一次。[source: E02669-AR2025 pp.121-133, 203-205]

先看第一年资金流水。这里的总额仍是人民币公司口径；只有实际分配和每股价值进入投资者回报时，才按RMB0.90/HKD换算一次。

| 第一年资金归宿 | RMB百万元 | 为什么这样处理 |
|---|---:|---|
| 正常普通股owner earnings | 896.980 | 已扣正常税、经济维护、回款负担和少数股东盈利，是资金总入口 |
| 普通分配 | 313.943 | 35%介于约30%书面政策与近两年较高实际派息之间 |
| 去重后的可识别再投入 | 176.713 | 同时排除维护投入和已经扣入owner earnings的回款负担 |
| 新增现金 | 325.059 | 分配及可识别再投入后的剩余中，80%暂归入现金 |
| 用途无法解释 | 81.265 | 暂不计值，不用“其他”掩盖未知资金用途 |

这张表告诉我们，RMB583.037百万元留存没有被整体按零处理。真正需要判断的是：RMB176.713百万元再投入能保留多少价值，RMB325.059百万元新增现金中多少最终服务普通股，以及RMB81.265百万元未知用途是否继续存在。三项分别计算，不能用一个“增长率”代替。

经常性现金底可以用GG单独观察：

```text
正常化普通股经营盈利 AA                  RMB 896.980百万元
普通分配率 M                                      35%
股息税及收取摩擦 Q                              10.27%
经常性净回购或特别分配 O                         0
全年固定收款费用 F                         RMB 0.0328亿元
经常性净现金                              RMB 278.417百万元
按HKD3.45市值计算的GG                         2.73%
```

GG回答“不卖股票，每年大致有多少净现金到手”。它不计经营增长、留存现金或未来卖价，且同一股息已经进入完整XIRR，不能再相加。完整回报高于GG不代表虚构增长，而是公司价值和未来出售价格也会变化。

每股换算也应一步一步做。RMB3.758亿元税费后分配，先除以32.8396亿股，得到每股人民币现金；再除以RMB0.90/HKD，得到每股港币约HKD0.0942。用HKD3.45买入，才得到2.73%的现金收益率。经营层没有反复换汇，港币只是投资者实际收付现金的统一计量单位。

2022至2025年经营现金流约为累计归属利润的94.8%，说明利润大体真实。最近三年留存约RMB27亿元，普通股权益增加约RMB26.8亿元；2021至2025年集团现金增加约RMB27.9亿元。留存没有大面积消失，却也没有全部回到股东手中。[source: E02669-AR2025 pp.82-83, 121-133]

现金底约2.73%，不是买入回报上限。未来回报取决于未分配本金能否保值及最终进入普通股价值。

## 07. 资产价值与资产负债表

物业公司没有大量厂房，资产负债表却不是可以略过的附表。它记录了公司是否先替客户垫钱、收入能否开票收现、供应商是否在为扩张融资，以及集团现金究竟停在哪个法律实体。对中海来说，资产负债表比固定资产规模更能解释增长质量。

先看营运资产。2025年贸易应收与合同资产合计RMB33.54亿元，相当于当年收入的22.4%；2024年约为RMB27.81亿元和19.7%。一年间占收入比例上升2.7个百分点，与经营现金转弱方向一致。审计师把应收、合同资产和酬金制项目垫款的可收回性列为关键审计事项，相关净额约占总资产27%；贸易应收减值率又从8.6%升至11.1%。这不是已经发生的坏账结论，却说明公司的“轻资产”越来越多地表现为客户信用资产。[source: E02669-AR2025 pp.128-133]

合同资产尤其需要分清。它主要代表公司已经履约但尚未取得无条件收款权的金额，2025年由RMB1.52亿元升至RMB4.77亿元。管理层预计通常一年内结算，只能说明合同期限，不等于现金已经到账。若2026年合同资产转成应收并收现，2025恶化部分属于项目爬坡；若合同资产、长账龄应收和减值继续同步上升，城市服务与工程增长就在消耗股东资本。[source: E02669-AR2025 pp.128-133]

负债端也不能简单视作免费资金。2025年贸易应付约RMB26.31亿元，代管物业临时收款约RMB11.52亿元。供应商账期可以缓冲应收占用，代管款则在经济上属于业主或项目运营，不是可自由分配的股东现金。应收与应付必须配对观察：若应收增长只是被同期限应付覆盖，资本压力较轻；若客户回款继续拉长而公司仍需向员工和供应商付款，现金转换会继续下降。

关联余额把资产负债表与母体连接起来。年末应收同系公司RMB6.31亿元、应收其他关联公司RMB1.74亿元；同系贸易应收中约RMB2.22亿元已超过一年。中海发展和中国建筑体系的信用质量让这部分比弱民营开发商应收更可靠，但“最终能收”与“及时收现”仍是两件事。集团若以较长结算周期占用物业公司现金，会降低普通股资本回报，即使账面不发生违约。[source: E02669-AR2025 pp.203-205, 218-219]

再看生存能力。24个月压力测试只把RMB34.36亿元现金等价物当作首日流动性，定期存款因具体释放日期未闭合而不计；在不续借、经营现金和回款受压、或有项目全额调用的联合情形下，期末合并流动性仍约RMB37.27亿元。近期破产风险较低，永久损失更可能来自多年低回报配置。[source: E02669-AR2025 pp.121-133, 230-235]

2025年集团现金及银行结余RMB62.71亿元。先扣RMB0.13亿元受限现金及相当于一年经营现金流的RMB11.53亿元经营底线，超额现金约RMB51.04亿元。上市公司本部现金和应收子公司款只是集团现金中的法律实体备忘，不能重复相加；董事会关于境内未汇出利润的税务附注又说明上游并非自动。[source: E02669-AR2025 pp.121-133, 210, 230]

保守判断只认可超额现金一半最终通过分红、回购或有效投资服务普通股，即RMB25.52亿元。30%和75%分别作为治理压力与较好资本配置情形。50%不是管理层承诺，也不是五年内分掉一半，而是长期经济实现折价。合并现金还包含子公司少数股东的经济索取；公开资料不足以按实体拆出这部分现金权利。由于少数股东利润与分配相对集团现金规模很小，本版不再机械扣一笔估计值，而让50%现金实现折价吸收这项边界；若以后披露材料性的少数股东现金权利，必须重算普通股可达现金。[source: E02669-AR2025 pp.203-205, 210-220, 230-235]

调整后的有形资产价值约RMB0.83/股。折算时对应收、合同资产、车位存货等分别打折，并把应付及代管款作为完整索取权；它只用于极端经营恶化时的资产压力检查。它不是重置公司客户关系、团队和组织能力的完整NAV，也不与持续经营价值相加。

资产负债表给出的结论有两面：现金和低债务足以排除近期流动性破产，应收、合同资产和关联结算却显示增长正在变重。存量现金是普通股潜在价值，也是治理折价的来源；未来一年最重要的不是现金余额又增加多少，而是新增项目能否把合同资产和关联应收变成可分配现金。

## 08. EPV 与现有经营机器

EPV要回答的是：不为未来增长付钱，只把现有客户、团队和合同维持下去，一年究竟能留下多少普通股经济盈利。旧模型先给全公司一个正常盈利，再把城市和智慧工程扣掉，成熟服务便自动成为剩余项。这样算术能够对上，商业逻辑却没有闭合，因为占绝大部分价值的成熟服务并不是由收入、成本和回款生成的。

本版改为从经营驱动向下计算。2025年RMB149.599亿元收入先按公司披露拆为物业管理RMB117.290亿元、居民增值RMB12.186亿元、非居民项目RMB19.398亿元和车位RMB0.724亿元。城市空间收入RMB24.302亿元从物业管理收入中单列后，成熟基础物业收入为RMB9,298.826百万元，也就是约RMB92.99亿元。管理面积4.776亿平方米只说明运营规模；公司没有披露收费面积、同项目单价和收缴率，因此模型不会用管理面积乘一个虚构单价来制造收入。

成熟基础物业的利润从包干制毛利率开始。主情景采用公司2025年披露的12.4%，并单独保留酬金制净额列报带来的毛利抬升；它不是把14.3%的物业管理混合毛利率直接贴给每一个成熟项目。居民增值按2024年25.5%毛利率正常化，不永久外推2025年34.0%的组合改善；智慧工程及非居民项目保持2025年7.2%的受损毛利率。销售及管理费用、信用减值、公允价值损失、税、维护投入高于折旧的部分和少数股东索取，再按披露收入比例分配一次。居民增值与成熟物业不共用第二份费用，也不会各自再扣一遍总营运资本。

回款必须另走一座桥。2025年贸易应收和合同资产分别吸收现金RMB4.002亿元和RMB3.272亿元，合计RMB7.274亿元；其他应付及营运资本项目提供约RMB4.520亿元资金，现金流量表最终显示的净营运资本吸收是RMB2.754亿元。主情景只把其中一半视作会重复发生的回款负担，即普通股盈利再扣RMB-137.713百万元。这里展示较大的应收占用是为了识别风险，不会再扣第二次。若2026年回款恢复，这项扣减可下降；若完整持续，则应使用压力情景。

计算结果不再是残差：成熟基础物业贡献RMB614.335百万元，居民增值贡献RMB182.864百万元，城市公共服务贡献RMB62.686百万元，智慧工程及非居民项目贡献RMB24.861百万元，车位业务贡献RMB12.234百万元。车位的RMB17.6百万元披露值是税前分部利润，不是毛利；模型只从这里继续扣税、维护与少数股东归属并处理回款，不再分摊第二次共同成本。三台估值机器中，“成熟基础”把成熟物业、居民渠道和车位放在一起，合计RMB809.433百万元；城市与智慧工程分别保持独立要求回报。全部相加得到普通股正常owner earnings **RMB896.980百万元**，不是模型输入。

这仍是`DATA_LIMITED`经营代理，不是项目cohort已经闭合。收费面积、同项目费率和收缴率，主动退出与自然到期的拆分，各业务人工与分包，以及项目期后回款仍为`UNKNOWN / MONITOR_ONLY`。因此12%、14%和16%的资本化要求回报不是精确WACC，而是对成熟服务、城市合同和项目工程风险逐步提高的保守要求。

三项经营盈利按各自要求回报资本化后，经营价值为RMB7,348.411百万元。再加入保守认可的一半超额现金、扣银行和租赁索取，今天的普通股价值约 **HKD3.3005/股**。现价HKD3.45略高于该值，因此接下来的“市场确认”不是额外上涨奖励，而是对当前小幅溢价怎样消化的期末价格假设。

三项关键驱动的27格联合矩阵给出边界：普通股正常盈利从RMB637.327百万元到RMB1,182.732百万元，现价五年XIRR从1.15%到6.81%。固定各格现价路径的期末成交价后，10%买价从HKD2.31到HKD3.01；若让候选买价同时改变期末相对折价，压力价从HKD1.73到HKD2.79。这张表告诉我们，成熟包干毛利、回款持续性和城市项目成熟可以共同改变买价，但联合有利边界仍没有让HKD3.45达到10%。

## 09. 未来五年，公司与股东如何赚钱

现在可以把“公司有价值”和“股票能否获得10%回报”连接起来。HKD3.3005是今天对现有经营与部分现金的判断；它不会自动成为五年后的卖价。五年间，公司会分红、继续投入、积累现金，也可能损失一部分已有盈利。先推演公司的价值怎样变化，再判断市场可能怎样定价，最后把所有港币现金按日期计算，才能得到买入回报。

未来经营价值最难的参数，是留存资本能赚多少。公司没有披露项目批次投入和回收，不能直接计算城市或智慧工程的增量ROIC；但公司总量数据至少提供了一个保守起点。2023至2025年税后经营利润只增加约RMB0.1539亿元，同期2024、2025年综合投入上限合计约RMB8.8157亿元，因此：[source: E02669-AR2025 pp.34-46, 121-133]

```text
(2025税后经营利润 - 2023税后经营利润)
/ 2024至2025综合投入上限
= (13.7108 - 13.5570) / (4.4691 + 4.3466)
= 1.7452%
```

扣除折旧摊销后的净投入分母会得到约2.04%。保守情景取1.7452%的低端，不是认为公司长期只能赚1.7452%，而是不愿在证据出现前把爬坡中的城市项目按成熟同行估值。这个短窗口可能低估仍未成熟的新项目，也可能准确揭示低价扩张；未来项目利润和回款会决定往哪个方向修订。

智慧工程5%衰减是另一项独立判断。它只作用于RMB24.861百万元既有盈利；1.7452%则作用于未来综合再投入。前者问既有工程业务是否继续恶化，后者问新增资本产生多少盈利。把5%直接从1.7452%里减掉，会把两个不同基数的判断错误拼成一个负增长率。

第一年RMB896.980百万元普通股经营盈利中，约RMB313.943百万元形成普通股分配。原RMB314.426百万元综合再投入已经包含营运资本；主情景的RMB137.713百万元重复回款负担既然已在owner earnings扣过，就必须从再投入锚中再剔除，剩余只有RMB176.713百万元进入未来增量回报。余下资金主要形成新增现金，并有一小部分用途暂时无法解释。这样推演五年，普通股价值从今天约HKD3.3005增加到三年约HKD3.4803、五年约HKD3.6010。

价值增加不等于股东已经取得。现价HKD3.45高于主模型今日价值，模型若维持今日价格相对价值的比例，五年终值约HKD3.7642，税费后XIRR为4.35%。若五年内把当前溢价消化一半，终值约HKD3.6826，XIRR反而降到3.92%；若完全按届时HKD3.6010的模型价值成交，XIRR约3.49%。因此“市场确认”在本版是负贡献，不是公司之外的额外收益。HKD3.45达不到10%并不依赖一个悲观折价假设，反而是在不消化当前溢价时也明显不足。

### 先看长期所有者路线：不卖股票时，一年经济所得有多少

长期所有者路线要回答的是：如果不预设三年或五年卖出，正常经营一年产生的现金和有效留存，相对今天付出的价格有多少回报。它不把存量超额现金一次性当作年度收益，也不加入期末市场重估。

正常普通股owner earnings为RMB896.980百万元。换成投资者熟悉的每股港币，需要分两步：

```text
RMB896.980m / 3,283.96046m股
= 每股人民币owner earnings

RMB0.27252 / RMB0.90每港币
= HKD0.3035/股
```

这HKD0.3035不是现金股息。35%普通分配扣除10%股息税、收取摩擦和固定费用以后，投资者每年真正收到约HKD0.0942/股。其余owner earnings由管理层继续配置，必须根据用途分别认可。

以下表格展示为什么长期路线只能给区间。低、中、高三档都使用同一经营驱动输出和35%分配；变化的只有总量增量回报边界，以及新增现金最终服务普通股的比例。

| 长期条件 | 可识别再投入认可价值 | 新增现金认可价值 | 留存合计认可 | 留存认可比例 | 现价税后港币经济回报 | 10%条件价格 |
|---|---:|---:|---:|---:|---:|---:|
| 低端：1.7452%增量回报，新增现金认30% | RMB21.937百万元 | RMB97.518百万元 | RMB119.455百万元 | 20.49% | 3.90% | HKD1.35 |
| 条件中点：1.7452%增量回报，新增现金认50% | RMB21.937百万元 | RMB162.530百万元 | RMB184.467百万元 | 31.64% | 4.54% | HKD1.57 |
| 条件高端：2.0384%增量回报，新增现金认75% | RMB25.622百万元 | RMB243.794百万元 | RMB269.416百万元 | 46.21% | 5.37% | HKD1.85 |

以中点为例，税费后现金分配为RMB278.417百万元，加RMB21.937百万元再投入认可价值，再加RMB162.530百万元新增现金认可价值。三项相加后除以32.8396亿股，再按RMB0.90/HKD换算，得到每股年度经济所得。用HKD3.45现价相除，长期税后港币经济回报为4.54%；再用10%目标回报反推，条件中点价格为HKD1.57。

可识别再投入的认可价值不是把投入本金全部加回。RMB176.713百万元再投入只按1.7452%至2.0384%的观察增量回报，分别对成熟物管、城市服务和工程业务的12%、14%和16%资金要求折算。换句话说，投入一元而长期只能赚远低于资金成本的回报，这一元不能按一元计值。新增现金也没有全部按面值认可，因为集团现金上游和普通股可达性仍未闭合。用途无法解释的资金在三档都取零。

事实、判断和影响应当分开：收入、披露毛利、费用和现金流是事实；12.4%成熟毛利、半数净营运资本吸收持续及3.5%城市owner margin共同构成主情景；1.7452%至2.0384%来自2023至2025年公司总量观察，不是项目永久回报；30%、50%和75%现金认可是治理判断，不是法律承诺。正因为后几项不能证明长期稳定，`P_LONG`的正式身份是 **HKD1.35至HKD1.85的条件区间**，不能选中点冒充精确价值。[source: E02669-AR2025 pp.121-133, 203-220]

即使取条件高端，现价长期经济回报也只有5.37%，没有达到10%。以后若城市项目成熟回报接近资金成本、现金通过持续分红或注销式回购到达普通股，整个区间会上移；若短窗口回报继续下降或现金进入低回报关联配置，区间会向低端甚至更低移动。

### 再看有限期限路线：三年和五年分别回答什么

三年和五年路线不是把长期回报再加一遍，而是另一种持有政策。投资者在2026年8月买入，随后按半年和年末日期收到港币股息，扣10%股息税和收款费用；期末按模型假设的市场价格卖出，再扣交易费用和印花。实际日期年化回报率，英文缩写为XIRR，就是使这些不规则日期现金流折现值等于零的年化回报。

三年给公司较短的验证窗口。保守情景现价XIRR为3.87%，这条现价路径推演出的三年期末成交价为HKD3.5854。保持这个期末价不变，达到10%的三年参考买价为HKD2.92。

五年更接近本案的经营证据周期，因为2024至2026年取得的城市项目通常需要二至三年才能观察成熟利润、回款和续约，也给资本分配留下连续记录。先按第五年模型业务价值HKD3.6010出售，现价XIRR为3.49%；再按“不增加市场确认”的退出关系出售，现价XIRR为4.35%。两条都低于10%，并且都不需要凭空加入新的市场溢价。

模型也计算了一条有限确认条件路径：现价HKD3.45对应第五年成交价HKD3.6826，现价XIRR为3.92%。把这个成交价固定后，达到10%反解出的买价为HKD2.64。算术上它是正确的，经济身份却只能是“如果第五年真能按这个市场价格成交”。这个价格没有独立收购价、合同现金流、法律终值或已验证催化剂支撑，因此不是行动价。

还有一条更严格的压力路线。若把候选买价降到HKD2.23，又假设这项更低买价代表更深的期初相对折价，并让该折价延续到第五年，期末成交价会随之降到HKD3.0178。这条路线同样得到10% XIRR，但它同时改变了买入价和卖出价，所以只能称为“折价延续压力价”，不能冒充固定期末价格下的最高买价。两者没有谁更精确，只是回答的问题不同。

市场确认只作用于期末成交价格，不改变公司经营盈利、分红或新增现金。不增加市场确认时，五年XIRR为4.35%；消化一半当前溢价时降至3.92%，变化为-0.42个百分点。三年同样从4.35%降至3.87%，变化为-0.48个百分点。负号说明估值回归在本版拖累回报，不能把它解释为公司多赚了一笔钱。

### 四种回报必须分层

中海尚未证明自己拥有经济特许权，所以书中的经济回报是重要诊断，却不能单独裁决买入。下面四项使用不同分子，不能相加或互相替代。

| 回报身份 | 当前口径 | 本报告怎样使用 |
|---|---:|---|
| 股东现金回报 | **税后2.73%** | 35%分配扣股息税和收取费用；只回答不卖股票时每年实际收到多少现金 |
| 书中经济回报 | **税前4.25%至5.72%；税后港币3.90%至5.37%** | 现金分配加有效留存，不含存量现金一次性兑现和市场重估 |
| 有限确认条件回报 | **五年税费后XIRR 3.92%** | 股息、再投入、现金归属和固定期末市场价进入同一港币现金流；目前只作条件诊断 |
| 估值回归贡献 | **五年-0.42个百分点** | 有限确认XIRR减去不增加市场确认的XIRR；负号表示当前溢价消化拖累回报 |

回报来源在本版不再用几个百分比拼接。税后现金分配先按实际日期进入现金流；留存再分别进入未来经营盈利、被认可新增现金和暂不计值用途；最后才由期末市场价格决定能否出售。这样可以看到公司经营与留存怎样改变价值，也能看到当前小幅溢价消化带来的负贡献，而不会把经营增长、现金和估值变化重复相加。

### 我最终应该看哪个价格？

**目前不应该看一个“最终价格”，因为它是`UNKNOWN`。** 问题不在反解函数，而在投资者尚未证明该走长期所有者路线，还是该走有限退出路线。长期不卖时，`P_LONG`的HKD1.35至HKD1.85回答“不卖股票、只靠一年可重复经济所得，什么价格才有10%”；它不计存量现金兑现和出售，且留存认可与现金可达性还是条件判断。

需要五年退出的投资者，先看第五年业务价值HKD3.6010对应的3.49%，以及不增加市场确认对应的4.35%。这两条均不通过，说明不能把“市场终会重新评级”当作基础收益来源。HKD2.64回答的是另一件事：在期末成交价固定为HKD3.6826时，今天最多能付多少。它保留为有限确认条件价，必须先出现后文列出的催化事实，才可能升级为可执行路线。

HKD2.23回答的是更严格的折价延续压力：买价下降会同时压低期末相对定价。三年固定终值参考价HKD2.92只给较短验证窗口。三种价格不平均，也不从其中挑一个包装成安全边际行动价。

## 10. 两条情景与最强反方

现价并不只对应一个市场故事，但新经营模型改变了价格含义。主情景今日价值为HKD3.3005，低于HKD3.45现价；因此现价不再代表市场已经把经营盈利大幅打折，而是对主模型价值保留了一点溢价。只有把成熟毛利、回款持续性和城市成熟度放入27格联合矩阵，才知道这点溢价是否合理：矩阵中的五年XIRR范围为1.15%至6.81%，联合有利边界仍未达到10%。

最强看空解释是：成熟物管继续因续约降价和成本压力衰退；城市服务在招投标、设备和应收中长期只赚低于资金成本的回报；智慧工程合同资产转不成现金；集团现金继续沉淀或进入关联配置。公司仍能运营和分红，普通股却缓慢损失价值。永久损失情景五年回报约-2.99%，说明低破产风险不等于低永久损失风险。[source: E02669-AR2025 pp.34-49, 128-133, 203-220]

最强看多解释不是“面积继续增长”，而是五段修复同时发生：成熟包干制利润稳住，退出低价项目释放利润和营运资本，城市项目第三年达到成熟利润并回款，智慧工程止损收现，集团现金通过分红、回购或高回报用途证明归属。完整修复时五年回报约12.26%，能达到要求。

这两个反方之间，三类业务逐步正常化仍只有8.40%。这说明单靠城市项目成熟或智慧工程止损不够；现价要求公司同时改善经营和资本配置。若把第五年成交价条件固定为HKD3.6826，HKD2.64可以达到10%，但这不是基本情景的行动价，而是用来衡量“催化事实究竟值多少钱”的条件数。若还要求相对折价延续到第五年，则压力价为HKD2.23。

按当前HKD3.45达到五年10%，在分配、现金实现和期末定价规则不变时，五年期末市场价格需要达到HKD4.9891/股，对应届时普通股模型价值约HKD4.8786/股。三类业务经营价值需要达到保守路径的1.51x，相当于多出RMB461.229百万元可持续普通股经营盈利。这不是预测，而是把“公司还需要改善多少”改写成可验证门槛。

当前“不买”对合理情景稳定，未来可以由更低价格或更强事实改变。风险不是股票波动，而是留存本金多年不能产生足够普通股价值。

## 11. 催化与价值实现

本案没有麦格纳式的行业强制恢复，价值实现只能来自公司可观察的行为：[source: E02669-AR2025 pp.34-49, 121-133, 203-220]

1. 成熟基础服务在一至两个续约周期内保持约12%的包干制毛利率，同项目提价和单位成本改善可见；
2. 退出项目后6至18个月，区域利润、应收和人员强度改善，而不是被同类低价新项目填回；
3. 城市公共服务在18至36个月内达到约90%回款、稳定续约和正累计利润；
4. 智慧工程在12至18个月内把合同资产转为应收并收现，单独盈亏和研发投入可观察；
5. 普通派息率持续在35%至42%，或现金通过注销式回购、特别分配及高回报投资证明归属。

短期股价反应不是催化证据。2024年主动退出公布后市场一度正面反应，2025年业绩后60日又明显落后，说明市场会等待利润、回款和现金用途形成连续记录。研究应跟踪经营事实，而不是猜下一次公告日涨跌。

每条恢复机制都有期限和证伪条件。没有这些事实时维持保守路径；事实兑现时提高再投入回报、分配率或现金实现，而不是直接加一个“催化溢价”。[source: E02669-AR2025 pp.121-133, 203-220]

### 投资者论点验收：母体既提供资源，也可能占用现金

中海体系不是单向利好。它的支持面很具体：品牌和央企履约记录降低获客与投标摩擦，开发项目和同系机构仍提供服务收入及潜在交付管线，集团信用也降低了客户突然失约的概率。它的索取或约束面也同样具体：2025年关联服务收入是真实业务，期末同系及其他关联方应收约RMB8.06亿元；上市公司母体现金仅RMB0.28亿元，而合并口径现金RMB62.71亿元，普通股分红还要取决于子公司分派、法定储备和税务安排。母体支持因此不能自动折算成每股现金，合并现金也不能自动当作五年内可得特别股息。[source: E02669-AR2025 pp.203-205, 210, 218-219, 230]

| 要验证的投资者论点 | 现在能看到什么 | 仍缺什么，达到后才可改变价格身份 |
|---|---|---|
| 长期持有能靠经营和留存达标 | `P_LONG`为HKD1.35至HKD1.85，现价回报3.90%至5.37% | 项目级回报、子公司上游安排和留存用途连续闭合；否则长期路线只是条件区间 |
| 五年按经营价值退出可达标 | 第五年业务价值HKD3.6010，现价XIRR3.49% | 成熟物管稳住、城市项目累计利润和回款、智慧工程收现，且结果足以把经营价值本身抬高 |
| 五年固定市场终值可达标 | 固定HKD3.6826终值时，HKD2.64可反解至10% | 不可只引用现价。必须有独立现金回报、交易机制或连续经营证据解释这一终值 |
| 母体资源会服务普通股 | 项目来源、同系业务和信用支持已观察到 | 关联应收按期收回，普通分配、注销式回购或可复算高回报投入使现金真正到达普通股 |
| 母体不会把价值转成体系内用途 | 关联收购曾被市场明确质疑并终止 | 不发生低回报关联配置，或逐项披露并在投后证明回报；不能用“央企支持”抵销这个风险 |

因此，当前结论不是“永远不买”，而是“基础情景不合格，原始正方论点仍可验证”。最重要的翻转不是账面减值或面积增长，而是：城市项目达到18至36个月的累计利润、回款和续约门槛；智慧工程合同资产转成现金；以及董事会让普通股可观察地分享现金或高回报再投入。只有这些条件与第五年市场成交价之间形成证据链，固定终值条件价才可以被提升为可执行路线。[source: E02669-AR2025 pp.34-49, 128-133, 203-220]

## 12. 结论，以及什么会改变判断

中海物业已经完成从关联住宅项目向第三方和公共服务扩张，证明了获客与履约能力；它还没有证明新项目能复制旧模式的利润、回款和资本效率。现任团队有长期物业运营和财务经验，2024年主动退出也表明管理层有修复工具；但城市服务扩张同样是这支团队的主动选择，而管理层几乎没有中海物业持股。运营能力已经证明，能否把留存本金变成每股价值还没有证明。

HKD3.45略高于主模型今日价值，而条件长期回报只有3.90%至5.37%，五年按业务价值成交也只有3.49%。现价不能只靠等待市场醒来；公司必须改善经营或资本配置。固定现价路径已给出的第五年成交价反解出HKD2.64，但它依赖一个没有独立催化证据的成交价，不能称为主要研究价。HKD2.23则是同时压低期初和期末相对估值的压力价。两者都保留，不取代`UNKNOWN`的行动价结论。[source: E02669-AR2025 pp.121-133, 203-220]

结论决策卡把两种持有政策再核对一次：

| 项目 | 结论 |
|---|---|
| 回报通道 | `DUAL_ROUTE / PRIMARY_ROUTE_UNKNOWN` |
| 长期不卖 | 税后港币经济回报3.90%至5.37%；`P_LONG`为HKD1.35至HKD1.85 |
| 三年退出 | 现价XIRR 3.87%；固定终值10%参考价为HKD2.92 |
| 五年业务价值退出 | 第五年业务价值HKD3.6010，现价XIRR 3.49% |
| 五年无新增市场确认 | 现价XIRR 4.35%；只作退出压力测试 |
| 五年有限确认条件 | 固定HKD3.6826期末成交价时，10%反解价为HKD2.64；非行动价 |
| 五年折价延续压力 | 买价HKD2.23、期末成交价HKD3.0178时达到10%；只作压力边界 |
| 市场确认影响 | 五年有限确认相对不增加确认的XIRR变化为-0.42个百分点；负号表示当前溢价消化 |
| 最终价格 | `UNKNOWN`。HKD2.64为催化成立时的条件价；HKD2.23为压力价，不平均其他路线价格 |
| 当前判断 | 公司可继续研究，HKD3.45未达到10%要求 |
| 翻转事实 | 项目资本回报和回款闭合、成熟利润稳定、现金通过分红回购或高回报用途证明归属 |

以下事实触发重算：新的完整收盘价；年度或中期利润与现金；城市项目利润和回款；智慧工程合同资产收现；普通派息政策、特别分配、回购、关联收购；成熟包干制毛利率连续变化。重算改变价值与回报，但不自动给出仓位或交易动作。[source: E02669-AR2025 pp.34-49, 121-133, 203-220]

当前结论为“公司可研究，价格未达要求”。安全边际主要来自更低价格，其次来自成熟业务、项目回款和资本配置逐项证明。
