## 业务承载、客户与行业传导载体

- FY2015 主营是照明产品的生产、研发和销售，产品分为传统照明和 LED 照明；销售以代理商为主，并建设批发、专卖店、工程商照、电商和零售渠道（PDF pp.9--10）。
- FY2016 在照明主业上增加电工板块，将照明与电工并列为发展方向；LED 产品更新快，部分订单尤其出口订单以销定产（PDF pp.9--10）。
- FY2017 披露照明、电工、汽车照明三大板块；LED 光源/灯具、传统光源及开关是主要产品，渠道仍包括流通批发、专卖店、工程商照、电商/零售和机动车灯（PDF pp.9--10）。
- 公司将行业描述为传统照明萎缩、LED 渗透后增速放缓、下游结构性产能过剩和竞争激烈；这是发行人同期行业叙述，不是独立行业事实，也不能单独证明公司拥有定价权（FY2015--FY2017 各年业务概要 PDF pp.9--10）。

## 合并责任边界与组件拆分

- 三年均为佛山电器照明股份有限公司合并报表。FY2016 新增佛山照明智达电工科技有限公司，持股 51%；FY2017 仍并表（FY2016 PDF p.26；FY2017 PDF pp.28--29）。电工组件因此不能回填到传统或 LED 照明组件。
- 年报列示佛山禅昌、佛山泰美、佛山电器照明新光源、南京佛照、佛山照明（新乡）、佛山照明灯光器材等子公司；其收入、现金、借款和资本支出没有逐项与三大板块勾稽（各年财务附注）。
- FY2017 处置青海佛照锂能源开发有限公司全部股权，处置收益进入非经常性项目；不能把该处置收益或投资现金流当成照明经营盈利（PDF pp.7、19）。
