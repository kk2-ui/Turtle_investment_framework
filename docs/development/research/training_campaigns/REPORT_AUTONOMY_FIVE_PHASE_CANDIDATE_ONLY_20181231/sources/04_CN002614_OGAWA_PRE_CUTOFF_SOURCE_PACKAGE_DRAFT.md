## 仍待独立复核的限制

- **身份桥：** FY2015/FY2016 与 FY2017 的名称/简称展示不同。后续来源登记必须有封面
  locator，证明每一个来源属于拟定同一发行人；不能借本草案把身份问题视为已解决。
- **业务可比性：** 三年披露中的产品、地区、渠道、子公司或分部口径是否可直接并列，必须
  逐项验证；不完整或变化的口径应保留为 `MISMATCH`/未决。
- **资本和现金缺口：** 若没有项目级现金、销量、维护金额或责任单元投入资本，后续应只对
  相应成分作条件处理，不能从合并现金流推导出项目级回报。

本草案没有选择、冻结或训练该发行人。其唯一作用是让下一道独立复取证能从三份明确的官方
静态源开始，并把不确定性留在正确的事实边界上。
