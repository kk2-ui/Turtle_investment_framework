## 投资者结论

结果支持了一条非防御性的条件判断：上海家化在 cutoff 时确有成熟品牌和渠道带来的盈利基础，
但这不等于新品、营销、线上和渠道投入必然形成增量 owner cash。FY2019 的收入和利润继续
增长；FY2021 后品牌、渠道和外部环境的压力使收入/利润能力不再沿 FY2016–FY2019 的路线
线性上升，FY2023 收入约 65.98 亿元、归母利润约 5.00 亿元。合理处理是承保成熟核心的
条件化现金，不预付“品牌组合和投放必然高回报”的增长信用。

这也否定了相反的机械规则：固定资产较轻不表示没有现金责任，更不表示消费品牌不存在
永久损失路径。品牌相关性、产品组合、投放效率、促销、渠道库存和应收的变化可以先侵蚀
经济利润，再表现为合并现金的压力。

## 结算

| 预先命题 | 结果裁决 | 经济含义 |
| --- | --- | --- |
| 成熟品牌和渠道是条件化盈利基础 | `SUPPORTED` | FY2019 仍增长，且后续公司并未进入生存/融资式断裂。 |
| 品牌/渠道扩张必须由产品、费用、周转与现金共同证明 | `SUPPORTED` | FY2021/FY2023 没有支持把 FY2016–FY2019 的增长简单外推为所有 cohort 的正常能力。 |
| 低固定资产投入不等于低经济资本责任 | `SUPPORTED` | 后续压力的解释仍须落在品牌、渠道与营运资本/费用效率，而非以低 capex 免除现金检验。 |
| 品牌组合和线上投放会自动高回报 | `NOT_CONFIRMED / NARROW` | 收入和利润未形成线性复利，增长业务应继续按具体客户和单位经济承保。 |
| 当前已经失去生存能力 | `REJECTED` | 公司保持经营与盈利能力；永久损失应表述为品牌/渠道经济被侵蚀的条件风险，而不是完整企业失败。 |

## 当前 Agent 的训练收获

五个 self replay 共同形成一条更细的研究顺序：

```text
先找企业真实的核心现金引擎
→ 区分增长、渠道、收购或救助的资源责任
→ 让客户、单位经济、营运资本和现金决定升级或降级
→ 再判断普通股是否保有该经济权利
```

上海家化特别证明：这不是重资产或困境企业的规则。对于消费品牌，营销、促销、库存、应收、
平台费用和组织投入也可成为资本责任；但这些责任必须由当前公司证据承担，不能由贵人鸟或
玲珑的结论代替。

本次仍是已知先前反馈的 current-Agent self run，故不创建 `TRANSFER_CANDIDATE`、
`TRANSFER_VALIDATED` 或 `METHOD_VALIDATED`，也不授予 CJO、正式估值、BuyBand、黄金报告或
投资权限。
