# 课程一期：Current-Agent 自训练读出

> 状态：`BEHAVIORAL_RULE_REINFORCED / OUTSIDE_METHOD_VALIDATION_NOT_GRANTED`

## 这次实际训练了什么

当前 Agent 已在两个结果隔离完成后才揭示结果的公司上，直接生成并验证完整
`EnterpriseUnderwritingEpisode`：广州酒家和玲珑轮胎。前者是品牌食品与渠道/基地扩张，
后者是周期性、资本密集的国内外制造。两案共享的不是公司结论，而是研究时必须区分的经济
问题：

```text
成熟业务的维护后 owner cash
!= 全部长期资产支出后的资金压力
!= 增长资本投产后的回报
```

广州酒家的结果显示强合并现金与扩张业务的边际毛利承压可以并存；玲珑的结果显示成熟核心
可以跨过周期恢复，而建设资本和新增海外项目仍未自动形成回报。因此，该规则帮助当前 Agent
避免两个相反的防御性错误：不能因扩张尚未证明就宣布全公司现金为负，也不能因合并增长或
短期现金好看就给扩张预先记功。

## 当前 Agent 的可复用行为

在下一家资本重要的公司中，先做出公司级判断，然后按这个顺序补充最有区分力的事实：

1. 找到成熟核心、爬坡 cohort 和尚未运营项目各自的责任边界；
2. 对爬坡 cohort 依次追踪客户吸收、利用率、价格/毛利、营运资本、全资本支出与后续回报；
3. 将周期、原料、客户或贸易冲击写入利润池和现金机制；
4. 维护资本尚未拆分时保留条件判断，仍继续形成正常盈利、永久损失和价值路线结论。

这不是额外的字段、准入公告、Comparative 或冻结门槛。它也不是“扩张都可疑”的口号：若
当前公司证据显示新增 cohort 已形成客户、单位经济和资本后现金，Agent 必须让它进入承保，
而不是为保持谨慎而继续拒绝。

## 什么尚未证明

两次都由当前会话的同一 Agent 完成，且 Agent 已知顺丰的先前负反馈。因此它们能训练并检查
当前推理行为，不能证明独立模型、独立基线或方法总体优于普通研究。状态仍为：

- `TRANSFER_CANDIDATE = 0`
- `TRANSFER_VALIDATED = 0`
- `METHOD_VALIDATED = 0`

也不授予 CJO、正式估值、BuyBand、黄金报告发布或投资权限。

## 下一轮训练的选择规则

继续选仓库零命中、结果尚未读取的历史公司，优先选择能挑战而不是重复本规则的结构：
例如轻资产服务、高转换现金但低资本开支、或成熟业务被新产品侵蚀的公司。训练仍以完整
Episode 和结果后错误定位为单位。若结果显示“资本三账”没有改变研究处理，应诚实标记为
无材料增益并改进推理，而不是再加控制层或把 `UNKNOWN` 扩大成公司结论。
