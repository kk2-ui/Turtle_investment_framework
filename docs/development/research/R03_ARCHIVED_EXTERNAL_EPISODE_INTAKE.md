# R-03 外部历史判断档案 intake

状态：`PRE_RESEARCH_METHOD_PREP / NOT_A_TURTLE_BACKTEST`

目标：让书籍和历史案例提供可检查的**结构经验**，而不是用已知结局、名家声望或报告数量制造“判断力已经提高”的错觉。

## 1. 接纳对象

唯一可以从 `QUESTION_ONLY_ROUTING_CARD` 升为 `ARCHIVED_EX_ANTE_EXTERNAL` 的对象，必须同时有：

1. 一份在目标结果发生前发表、可定位日期和原件的外部判断；
2. 原作者对当时状态、所选机制及至少一个经营指标/方向/窗口的明确表达；
3. 一个与原判断分开的、可复读的后续经营结果来源；
4. 一张按同一经济问题写成的强反方或近失效案例卡，且它不是靠结果期文字倒填；
5. 结构匹配、断裂条件和目标公司未来可观察序列。

任何一个缺失，候选停留为 `QUESTION_ONLY_ROUTING_CARD` 或 `OUTCOME_SELECTED_TEACHING_CASE`。书、回忆录、课件、二手报道和后来采访可以帮助定位原件，但不能取代第 1 项。

### 1.1 结果前计量重建合同

在打开 outcome package 前，候选还必须冻结一份 `metric-reconstruction contract`：

- 原作者谓词的指标、单位、调整项、窗口和必要/充分关系；
- 将来可读取的官方结果指标、文件 locator 与期间覆盖；
- **结果通道证明**：cutoff 前已存在一份发行人常规披露，证明该指标（或已完全列明的同一 GAAP 重建）会在结果窗口的同类官方文件中重复出现；登记该既有文件 locator、未来文件类型与披露节奏。竞选材料、一次性 investor deck 或“该页附有 reconciliation”本身不构成重复结果通道；
- 两者之间允许的转换或重分类，以及明确禁止的替代（例如不能用全年总分部利润倒推作者定义的季度 core bridge）；
- 口径在观察窗口内变更时的停止规则。

结果期若没有同定义、同窗口的官方序列，记录 `MEASUREMENT_MISMATCH`。局部方向相符或一项共同前提实现，都不能把不匹配的复杂谓词补结算为成功或失败。

## 2. intake 顺序与结果隔离

```text
既有路由卡提出问题
        ↓
先查询已拒绝候选登记；同一主体/时期/争论不得仅因材料更多而重开
        ↓
先读取并摘录当时的外部原件
        ↓
冻结：原作者判断、明确的 UNKNOWN、我们的结构化反方
        ↓
再读取独立结果源
        ↓
只沉淀：状态向量 / 机制条件 / 断裂条件 / 信号顺序
        ↓
为未来目标公司设计其自身的可结算观察
```

研究者现在已知道案例结局时，仍可完成这条档案，但必须标为 `ARCHIVED_EX_ANTE_EXTERNAL`：它检验外部判断的设计和结果链，不检验 Turtle 的盲测能力。原文没有写出的反方、阈值或因果箭头只能标 `UNKNOWN`；不能因为结果已知而把它们补得更漂亮。

候选登记的作用是防止便利性重入，而非自动封杀新证据。每张候选卡都要有稳定的 `entity / actor / cutoff / question` 身份；开始新一轮原件阅读前，先查[外部候选复筛](R03_ARCHIVED_EXTERNAL_CANDIDATE_SCREEN_20260821.md)。若已是 `NO_ADMISSION`，只有**此前未读、仍在 cutoff 前**的原件能重开，而且它必须直接补足原判断的指标、窗口或重复官方结果通道；更多争论、估值页、治理材料或结果期披露都不是重开理由。

## 3. 两类产出严格分开

| 产出 | 可沉淀 | 绝不可以声称 |
|---|---|---|
| `ARCHIVED_EX_ANTE_EXTERNAL` | 原作者当时的机制与预测、结果、状态向量、可迁移条件和断裂。 | Turtle 预测成功、Turtle 校准提高、一个可用于概率的基准率。 |
| `OUTCOME_SELECTED_TEACHING_CASE` | 机制问题、可能反例和数据边界。 | 任何预测测试、近失效的验证性支持或迁移胜负。 |

一个真正的 R-03 迁移实验还需要目标公司自己的、结果未知时冻结的 H-A/H-B 与后续观察。外部档案只能改善其问题、反方和信号设计；它不能替代目标公司的证据或结算。

## 4. 最小登记字段

使用[结构化类比与近失效卡](../../../templates/research_analogy_transfer_note.md)，每条候选至少登记：

- 外部原件发表日、原件 locator、当时 cutoff 与作者身份；
- 原作者明确写出的当前事实、机制选择、指标/方向/窗口，及其未写出的 `UNKNOWN`；
- 独立结果源、其 cutoff 前的重复结果通道证明、口径连续性和结果期边界；
- 同一经济问题下的近失效反例与唯一关键断裂；
- 三个以上匹配维度、一个目标公司断裂条件和一个不同的未来观察；
- `QUESTION_ONLY / ARCHIVE_INTAKE / TRANSFER_CANDIDATE / NOT_TRANSFERRED` 裁决。

不得登记目标价、估值倍数、股票回报、作者声望或“最后赚了/亏了”作为可迁移字段。

## 5. 验收与停止规则

本准备工作成功，不是找到很多案例，而是能在一条候选上明确区分以下三种结果：

- `ACCEPTED_EXTERNAL_CHAIN`：原始判断、独立结果和结构反例都在，允许沉淀条件与信号顺序；
- `TEACHING_ONLY`：结果已知但找不到合格当时原件或原作者没有可结算表达，保留问题而不形成经验；
- `REJECTED_AS_NARRATIVE`：只剩名声、书中故事或终局，停止继续查该候选。

首轮只处理一个来自既有路由卡的候选和一个近失效反例。若两者任一只能是叙事，停止扩大阅读范围，记录缺口后换候选；不以补充更多格力材料或更多书籍替代。

## 6. 与判断力的验证关系

本 intake 直接训练的是**迁移能力**和**机制辨别**：研究者能否把一个已知故事压缩成可被未来公司反证的条件与断裂。它的验证方式是：以后在不同目标公司的 `LIVE_FORWARD` 或合格选择 episode 中，预先写出的适用/不适用条件是否对应到不同经营信号。

在此之前，R-03 的正确状态是“档案准备已开始，真实迁移验证待结果”，而不是“案例已经证明方法有效”。
