# R-71｜中国制造多层时钟合成：经营判断是一个 D1–D5 向量，不是一条“成功／失败”故事

状态：`KNOWN_OUTCOME_TEACHING / MULTICLOCK_SYNTHESIS / NO_SELECTION_SCORE / TEACHING_APPLICATION_FROZEN / INDEPENDENT_REVIEW_PENDING`。

R-71 不新增公司结论，也不重新结算任何历史结果。它把已经结束的中国制造教学卡放在同一张企业系统图上，检验我们是否仍在用一个漂亮的收入、毛利或 OCF 数字替代整项企业判断。答案是不能。

本合成服务于下一张**不同公司**的冻结卡：它必须同时看见决策实施、外部反应、单位经济、现金转换和资本回收边界。历史材料只能训练这个分层；不计入选择准确率、方法胜率、公司评价、价格或回报。

## 1. 统一企业系统与时钟

```text
D1 决策实施
  → D2 客户／竞争反应
  → D3 单位经济（量 × 价格／组合 × 成本／渠道费用）
  → D4 AR／存货／预付／客户预收／AP 的现金转换
  → D5 增量资本、外部融资与资本回收
```

这不是要求每一层同一天得到答案。D1 先发生；D2 与 D3 可能在随后一两个报告期显现；D4 要把现金来源拆开；D5 最慢，而且在公开材料不足时必须永久保留 `UNKNOWN`。所谓“企业经营得好”只能是这五层在明确范围内的向量，不能被压成一项总分。

## 3. 多层读法如何改变训练

### 3.1 先后顺序是信息，而不是缺口的借口

R-25 的 D1 与 D2 已发生，D3 对部件路径却给出反向信息；R-28 与 R-29 的 D3 先改善，D4 仍受渠道费用、存货或供应商融资影响；R-21 与 R-24 又显示 D4 可以分别因信用恶化或库存周转而走向相反方向。因而：

```text
收入／销量改善   ≠ 客户现金改善
毛利改善         ≠ 渠道后的利润改善
OCF 转正         ≠ owner cash 或资本回收
决策实施         ≠ 管理者选择已经正确
```

这四个不等式不是悲观假设，而是来自不同公司、不同决策域的已结算边界。它们让研究者在结果尚未到达时，预先声明哪个层在什么时候、以什么来源和反方可被观察，而不是等年报结果出来后选择有利数字。

### 3.2 “多机制”不是把所有故事都写进去

每张卡都必须容纳产品、价格、成本、渠道、营运资本和资本约束；但它仍只有一个可检验的问题。正确结构是让 H-A 和 H-B **各自穿过同一 D1–D5 图**：

| 层次 | H-A 示例 | H-B 示例 | 允许的结算 |
|---|---|---|---|
| D1 | 已有可审计资源承诺与停止权。 | 行动只是口号、框架或不具可归属的实施。 | `IMPLEMENTED / NOT_IMPLEMENTED / UNKNOWN` |
| D2 | 客户／渠道的同一责任单元采用或交付先改善。 | 观察只是行业或集团总需求，不能识别该动作。 | 主／反／不可诊断 |
| D3 | 价格／组合、成本和渠道费用按预先口径联合改善。 | 量增被降价、返利、服务或成本侵蚀。 | 仅结算已指定箭头 |
| D4 | AR、存货、预付、客户预收、AP 和外部融资的现金来源与机制一致。 | OCF 主要来自库存释放、应付融资或外部资金，不能证明动作。 | 现金来源分解，不以 OCF 单值裁决 |
| D5 | 同一责任单元的增量资本、税后现金与可行替代可比。 | 项目／资本边界缺失或与集团混合。 | `CAPITAL_RETURN_UNKNOWN` 是有效终点 |

未知不能被其它层填补。反过来，D5 暂不可读也不阻碍早期经营学习，只阻止资本回收或最优管理者结论。

## 4. 已写入下一轮的冻结字段

R-71 的有效产出不是增加案例数量，而是下一张不同公司卡在读深前必须带着下列字段。它们分别来自上表的真实失败模式：

1. `D1_ACTION_AND_STOP_RIGHT`：原件须说明谁承诺什么资源、何时开始，以及何种条件下停止／调整；没有这一项，不把管理层表态写成决策。
2. `D2_UNIT_ADOPTION_OR_DELIVERY`：必须是公司行动所对应产品、渠道或客户单元的采用／交付，而不是行业销量或集团收入。
3. `D3_GROSS_MARGIN_BRIDGE`：先冻结 `price_or_mix / unit_cost / channel_or_service_cost`，防止用毛利率单点替代产品或渠道经济。
4. `D4_CASH_ORIGIN_BRIDGE`：分别登记 `collection_cash / inventory_cash / supplier_finance / external_financing`；未分解时 OCF 只作背景。
5. `D5_CAPITAL_BOUNDARY`：登记责任单元资本、结果窗口和替代；没有公开数据时，事前冻结 `CAPITAL_RETURN_UNKNOWN`，不追读集团故事。
6. `RIVAL_SEQUENCE_AND_STOP`：H-A/H-B 对 D2、D3、D4 必须有不同的先后顺序；若同一观察两方都接受，立即降为 `NO_PRIMARY`，而不是由结局挑选主路径。

上述约束尚未因为写在本文件就成为“学习闭环已验证”。R-78 已将六项字段迁移到 Ford 这一不同公司的**历史教学冻结**，并仍等待独立 reviewer 只核对“字段在结果读取前已实际改变”。这证明约束能够改变输入，不能证明选择能力、方法普适性或中国企业适用性。只有另一家中国公司的结果前冻结具备本地行动、方向性选择依据、公平基线与可结算反方，并完成相同复核，才可登记为正式 `learning application`。

## 5. R-71 的当前搜寻结论

本轮先试探了钱江摩托的 2026 渠道改革线索。可由完整 CNINFO 枚举和 source package 读取的 2025 年报与 2026Q1，只给出门店优化背景、国内大排量销量压力、公司级收入和现金；搜索发现的单份 2026-05 投资者活动记录没有进入同一完整法定公告 inventory，因而不能承担 `D1_ACTION_AND_STOP_RIGHT`。该线索停在 `SOURCE_SCREEN / NO_PRIMARY`，不创建公司判断或未来结果合同。

这是一次有用的停止：它没有以“重点门店”“全渠道”或公司级 OCF 代替可冻结行动。下一候选仍限定在**产品、渠道、组织或信用治理**，但须从可完整物化的 action 原件开始；不能回到扩产、客户框架、预付款或单一毛利筛选。

## 6. 结论与停止条件

- 根因：`REASONING + DATA_COVERAGE + ACQUISITION_MODULE`。公开材料更常给出行动宣言、总收入、单期毛利或 OCF，而不是同责任单元的 D2–D5 链。
- 经济影响：若跳过该链，会材料性高估正常盈利、owner cash、资本回收和管理决策质量，或因一个负面层次错误否定另一个已成立的经营箭头。
- 缺失事实：下一家中国公司的可枚举 action 原件、同责任单元的采用与价格成本、现金来源和资本边界；不得把 Ford 的经销商金融、劳工制度或结果迁移为中国事实。
- 禁止假设：行业销量、公司名气、总收入、毛利、OCF、经销商数量、投资者问答、后续结果、证券价格或回报可以替代五层中任一层。
- 可执行处置：以 R-78 的独立 reviewer 作为教学迁移的收据；下一张中国卡仍须先完成 `ACTION / STATE_AND_RIVAL / MECHANISM_OUTCOME / CAPITAL_AND_CASH` 四格，缺 action 或 D2–D4 的同边界结果通道立即停止。
- 验收：R-78 reviewer 只能确认第 4 节字段在 outcome body 读取前存在；下一不同中国公司的冻结附件还须逐项引用第 4 节字段，且其 H-A/H-B 在 D2、D3、D4 的来源、窗口和禁止代理不同。只有后者才允许讨论 `SELECTION_ADMITTED`。
