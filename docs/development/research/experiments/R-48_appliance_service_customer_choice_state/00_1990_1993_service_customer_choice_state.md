# R-48：1990–1993 家电服务——客户已经把售后服务纳入选择，企业经济仍需另证

## 身份与范围

`RESULT_KNOWN_TEACHING / S3_CUSTOMER_CHOICE_STATE / SERVICE_IS_MATERIAL / NO_COMPANY_OR_RETURN_VERDICT`

R-47 已把早期技术/质量识别为广泛存在的 S2 条件。R-48 只推进一格：当供给转松、耐用品进入使用期时，售后服务是否已经是客户选择的一部分？它不把服务网络或广告语写成企业能力，也不评价任何品牌。

## 同期的需求侧证据

[1990 年消费者来信汇集](https://rmrb.zhouenlai.info/人民日报（1946-2003）/1990/04/1990-04-24.htm)记录多种冰箱在故障后出现远距离维修、零件缺失、厂商/商家相互推诿和长期无法使用等情形。它不是行业故障率统计，也不能代表任一家公司的平均质量；它说明“修得好、修得及时、由谁承担”已经是产品使用价值的一部分。

[1993 年消费者协会等的 14 城抽样调查](https://www.rmrb.zhouenlai.info/人民日报（1946-2003）/1993/08/1993-08-15.htm)则给出更明确的选择状态：在产品质量基本相同情况下，60% 的受访者在品牌选择中看重售后服务；若一方价格适中但需要送修，另一方价格稍高却提供上门维修，95.4% 表示选择后者。调查同时显示消费者实际得到的商家/厂家维修与其期望存在缺口。

## 正确的机制边界

```text
可靠性 + 服务可得性/履约
→ 客户购买或复购选择
→ 服务成本、备件、网络与渠道责任
→ 价格实现、回款、营运资本和现金
```

这两份材料只支持第一段的行业状态：服务可能是客户选择的显著变量。它们不能跨过后面三段，原因是没有单一公司的：

- 同产品/同地区服务承诺、真实到场/修复与客户选择；
- 每台服务、备件和保修成本，及渠道/厂家谁承担；
- 价格、应收、库存和经营现金的责任单元结果。

故结算应为：

```text
SERVICE_MATERIAL_TO_CUSTOMER_CHOICE: OBSERVED_AT_MARKET_STATE_LEVEL
ANY_ONE_BRAND_SERVICE_ADVANTAGE: UNKNOWN
SERVICE_NETWORK_UNIT_ECONOMICS_AND_CASH: UNKNOWN
```

## 对下一张卡的约束

在 S3 研究某个品牌的服务/质量动作，必须以这里的市场状态作为共同背景，而非主路径选择证据；该公司的选择资格须来自非共同的服务履约或客户结果。结果合同至少覆盖一项客户/服务信号和一项服务成本或现金信号。没有第二项时，最多是 `CUSTOMER_CHOICE_SIGNAL`。

## 本轮结论

`RETAIN_AND_NARROW / SERVICE_IS_A_CUSTOMER_VARIABLE_NOT_A_MOAT / SERVICE_COST_AND_CASH_REQUIRED`

根因：`REASONING + DATA_COVERAGE`。若把消费者偏好、网点数量或服务口号直接写成某企业的护城河，会材料性高估价格实现、客户留存、服务负担与现金；若忽略服务，又会低估耐用品客户选择的真实约束。缺失的是企业级履约、成本、回款和现金资料。禁止以调查偏好、投诉、奖项、品牌、后来存续、股价或回报补足。验收是在不同公司取得同口径“服务履约/客户选择 + 服务成本或现金”的成对观察；否则只保留市场状态。
