# R-05 迁移复验计划

R-05 的完整复盘必须等待结算；但为缩短反馈周期，可并行启动一个独立、实时冻结的复验对象，前提是它不使用 R-05 的结果来选择机制、阈值或对象。下一个对象必须满足：

1. 不属于咖啡/餐饮连锁，避免把行业知识误当作方法有效；
2. 在截止日前持续披露一个分离的客户频次、销量或留存代理指标，且能在约 6–12 月按同一口径重读；
3. 当前状态至少可由两条机制解释，而不是单纯业绩预测；
4. 其官方结果来源在冻结前已经通过通用取得路径验证；
5. 不用股价、总回报、事后著名案例或报告数量筛选。

如果找不到这样的对象，R-05 的正确状态是 `REPLICATION_PENDING`；不以对 Starbucks、格力或书籍案例的持续增读替代。
