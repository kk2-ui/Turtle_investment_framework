# R-87｜海容冷链 2026 印尼基地投产：实际工厂不等于已验证的客户—现金—资本链

状态：`PRE_OUTCOME_ENTERPRISE_SYSTEM_SCREEN / NO_PRIMARY / NOT_FROZEN / NO_SELECTION_SCORE / NO_POST_CUTOFF_OUTCOME_READ`。

R-87 是 R-86 七项冻结约束在一家不同中国制造企业上的第一次实际应用。它检验：海容冷链的印尼基地已经建设、开业并开始运营，且公司同时披露了海外需求、客户合作、产品、营运资本和子公司数据时，能否选择“本地化供货已形成可持续的客户吸收和资本回收”这条主路径。

结论是**不能**。印尼项目已跨过 D1 的“实际设施投产”门，但披露没有把该工厂、具体产品和客户／终端 cohort 连成一个可对照的 D2，也没有该责任单元的量价成本、现金来源与资本回收。此时把工厂、H1 总收入、印尼制造子公司的首期收入／利润，或集团营运资本变化拼成一条成功故事，会制造并不存在的选择依据。

本卡不评价海容冷链、管理层、印尼项目或其证券。`2026-08-15` 是 cutoff；没有读取该日后的业绩、公告、价格、估值或回报。

## 2. 已证实的企业系统，而非完整判断链

```text
印尼基地建设、设备安装、人员配置和投产
  → 某一地区、某类产品、某批客户实际改由该厂接收并采用
  → 该工厂的量 × 价格／组合 × 制造、物流、服务成本
  → 该工厂订单的应收、库存、预付、应付与经营现金
  → 该项目的增量资本、替代用途和税后现金回收
```

## 4. 两条机制都能容纳当前事实

```text
H-A：本地化供货逐步形成可复制的海外客户与资本回收
已投产的印尼工厂
  → 东南亚及其他区域客户以该地供货下单、交付和复购
  → 物流／关税／制造成本和组合改善
  → 同一订单的营运资本转为项目自由现金
  → 增量资本获得回收

H-B：需求、贸易政策、组合和启动期营运资本仍主导结果
工厂投产与美国政策变化、区域需求、国内策略和多产品客户投放并行
  → 合并销量／子公司首期收入不能定位到某一客户迁移
  → 价格、成本、汇率和工厂爬坡可同时改变利润
  → 原材料、应收和库存先吸收现金
  → 项目资本回收保持未知
```

H-A 不应因工厂确已投产而被自动选中；H-B 也不能因 H1 合并经营现金为负而自动胜出。双方都能容纳已经披露的需求、销量、子公司损益和营运资本。没有被行动影响的客户 cohort 和同口径基线，二者并没有在 cutoff 前给出方向相反、可登记的预测。

## 5. 准入裁决与停止条件

- **根因：** `DATA_COVERAGE + REASONING`。公开材料已足以确认一次真实海外生产实施，也足以暴露产品、客户、现金与资本不能混用；不足的是印尼责任单元的客户采用、单位经济、现金与资本链，以及可选择的反方分叉。
- **经济影响：** 若将工厂投产、总销量、子公司首期利润、集团 OCF、固定资产或境外资产直接写成“本地化成功”，会材料性高估海外项目正常盈利、owner cash 和资本回收，并低估关税、汇率、需求、产品组合和营运资本造成的永久损失风险。
- **缺失事实：** 同一工厂的客户／订单／产品／区域 cohort 与对照、量价成本和利用率、订单级营运资本与现金、实际项目投入及替代用途／回收记录；同时还需一个已实施、可停止的国内策略动作，才可与工厂项目共同讨论。
- **禁止假设：** 工厂开业等于客户迁移；需求恢复等于工厂获得订单；头部客户合作、设计产能、子公司收入／利润、合并销量／毛利／OCF、固定资产或境外资产等于项目经济或资本回收；关税影响消除、汇率、季节性或原材料采购可被忽略；后续报告可以倒灌为当前选择依据。
- **可执行处置：** 关闭 `R-87 / NO_PRIMARY / NOT_FROZEN`，不建 FJ、不登记结果合同、不计入选择准确率或方法复制。不要为这一家公司继续补读当前材料。只有一个新的 cutoff 前官方源同时提供可区分的项目／客户 cohort、同口径基线、工厂单位经济、订单现金与资本边界，并令 H-A/H-B/简单持续基线给出不同可结算观察，才可作为新的 episode 重筛。
- **接纳标准：** 至少一条 `ASYMMETRIC` 事实将已实施的印尼 D1 接到具名或可定位的 D2；D3、D4 和 D5 必须属于同一责任单元。否则即使后续合并业绩上升，也保持 `NO_PRIMARY`。

## 6. 本轮对飞轮的贡献

R-87 没有增加一个“出海成功／失败”标签。它实际检验了 R-86 的约束能否在遇到一家公司同时给出工厂、产品、客户叙事、子公司利润、营运资本和资本资产时阻止研究者拼故事。答案是可以：**D1 已成立，D2–D5 仍不成立为同一条可选择链。**

下一候选应继续避开“新增海外产能”的同类表面题材，转向已实施的产品、渠道、组织或信用治理决定，并先找可定位的客户／竞争 cohort，再读合并财务资料。
