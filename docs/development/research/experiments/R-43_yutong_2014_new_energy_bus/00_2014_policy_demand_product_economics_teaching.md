# R-43：宇通 2014 年新能源客车——政策驱动的销量，何时才是企业经营能力？

## 身份与范围

`RESULT_KNOWN_TEACHING / CHINA_MANUFACTURING_POLICY_DEMAND_BOUNDARY / MIXED_OPERATING_OUTCOME / NO_COMPANY_OR_INVESTMENT_VERDICT`

本卡从白电转入商用车，训练中国制造业里常见但不能靠抽象“政策受益”回答的问题：政策和采购环境能够创造需求窗口；企业的产品、供应链、服务与现金能力决定能否把窗口变成长期经济结果。它不评价宇通、补贴政策、新能源汽车或证券。

## 当时状态、资源选择与竞争机制

[宇通 2014 年年报](https://money.finance.sina.com.cn/corp/view/vCB_AllBulletinDetail.php?id=1682606&stockid=600066)描述：国内大中型客车总销量同比下降 6.2%，但公交车受公共交通与新能源推广政策支持而略增；公司报告大中型客车国内销量增长 4.6%，新能源客车销量 7,405 台、同比增长 90.02%。公司称其一面推广新能源公交客车，一面研发面向团体/旅游市场的纯电产品。报告还预期将继续抓住新能源补贴和“一带一路”机会。

| | H-A：产品/系统能力把政策窗口转成可经营的客户价值 | H-B：政策/采购环境创造的需求主导，销量不能代表独立经济能力 |
|---|---|---|
| 机制链 | 研发/整车系统匹配 → 运营客户接受 → 交付与服务可控 → 单位成本、质保、回款和资本回收 | 推广政策/采购预算 → 订单与销量 → 产品/服务/电池成本及回款未必可持续；政策、客户结构和会计补贴可解释多数结果 |
| 对 2014 的预测差异 | 新能源产品在非共同的运营表现、服务成本、价格/毛利与回款上也应形成可识别改善 | 即使销量快增，收入、毛利、服务责任或现金也可与增长脱钩 |

年报中的“技术领先”“市场认可”是发行人解释，不能作为 H-A 的选择证据；政策环境、产品销量和公司整体增长是双方共同事实。

## 已知后续经营观察

[上交所 2016 年问询回复](https://static.cninfo.com.cn/finalpage/2016-04-21/1202212002.PDF)为 2015 年结果提供了重要的拆分：公司称新能源客车增长较快，导致超出标准质保期的电池、电机、电控等服务费增加；销售费用中的售后服务费增加 2.27 亿元，预计负债中的售后服务费年末增加 1.81 亿元。公司还称海外整车服务费按海外收入 2%预提、国内按国内整车收入 1%预提，并说明个性化订单的延期质保在售价中考虑。

这些不应被解释成产品失败：服务准备增加可能反映销量、合同承诺和产品结构，而不是实际故障或损失。它们也不能被忽略：销量上升本身尚未穿过全生命周期服务负担、客户运营效果、单位毛利和回款。

故本卡结算为：

- `DEMAND_AND_DELIVERY / SUPPORTS_BOTH_OR_NONDIAGNOSTIC`：销量和行业相对表现既可与能力相容，也可由政策/采购环境解释；
- `SERVICE_LIABILITY / RISK_SIGNAL_ONLY`：服务准备实际扩大，要求后续产品级服务成本/故障/价格与现金观察；
- `UNIT_ECONOMICS_AND_CASH / UNKNOWN`：现有材料没有同一新能源责任单元的毛利、回款、营运资本和资本占用。

## 可迁移判断

```text
政策或采购窗口
→ 企业是否获得订单（不是终点）
→ 运营客户的使用价值与服务责任
→ 产品级价格、成本与质保负担
→ 回款、营运资本与资本回收
```

这条链同时适用于补贴、国产替代、政府采购、行业准入与基础设施周期；但政策的具体制度、客户类型和结算规则必须当作中国情境变量，不能被抽象成全球通行的“需求增长”。

## 对下一轮的约束

政策/准入/采购拉动的制造案例，冻结前必须区分：

1. 政策造成的可得市场或订单资格；
2. 企业自身产品、交付、服务或成本的非共同经营证据；
3. 至少一个产品/项目级服务或质量信号，以及一个回款/营运资本/资本信号。

若只有销量或份额，保持 `DEMAND_SIGNAL_ONLY`；若只有利润，也需分出补贴、成本、服务准备和客户回款，不得跳到能力或资本回报。

## 本轮结论

`RETAIN_AND_NARROW / POLICY_DEMAND_IS_NOT_ENTERPRISE_ECONOMICS / SERVICE_LIABILITY_MUST_FOLLOW_DELIVERY`

根因：`REASONING + DATA_COVERAGE`。把政策环境下的销量、收入或份额直接写为公司竞争力，会材料性高估正常盈利、服务负担、现金转换和资本回收；反过来把服务准备增加直接写为质量失败，也会错判正在增长的合同义务。缺失的是新能源责任单元的价格、原材料/电池/制造成本、故障/实际服务支出、客户回款、营运资本和资本占用。禁止以政策标签、公司“领先”叙述、总利润、总 OCF、补贴、股价或回报补足。验收是下一张政策驱动制造卡在行动前冻结政策资格、非共同经营证据、服务信号和现金信号四者；缺一项只做状态教学。
