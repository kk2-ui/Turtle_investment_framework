# R-46：美的—库卡 2016–2017——控制权与实体报表齐备后，怎样仍不把增长写成协同？

## 身份与问题

`RESULT_KNOWN_TEACHING / CROSS_BORDER_CONTROLLED_ENTITY / MIXED_OPERATING_SIGNAL / NO_DEAL_RETURN_OR_COMPANY_VERDICT / NO_TURTLE_BACKTEST`

这是 P-93 的下一不同主体复验。R-45 说明少数股权与 carve-out 使“公开目标集团”无从代表中国买方的资本后果；本案控制权和目标实体报表均已具备，因此训练门槛提高为：**同一实体的业绩和现金，是否能证明收购带来的客户/经营协同？**

## 控制权、行动与竞争机制

[美的 2016 年报](https://static.cninfo.com.cn/finalpage/2017-03-31/1203240657.PDF)披露，2017 年 1 月 6 日交割后，美的以约 37.07 亿欧元取得库卡 94.55%股权；库卡[2017 年报](https://www.kuka.com/-/media/kuka-corporate/documents/ir/general-meeting/2018/kuka-annual-report-2017.pdf?rev=6dc9f693901f4c53972ee37c28d9f3ef)也确认自该日起为美的集团内由库卡管理的子集团。因此，收入、营运资本和现金流的责任单元确为库卡，而非“美的海外业务”或不受控的被投企业。

| | H-A：美的的中国/制造资源转化为库卡可归属经济改善 | H-B：行业需求、既有项目/投资及库卡自身产能约束主导，收购尚未显出可归属经济后果 |
|---|---|---|
| 可检验链 | 控制权与具体合作投入 → 库卡中国客户/项目、产品或服务的非共同增长 → 毛利/产能/营运资本改善 → 经营现金和资本回收 | 即使库卡收入增长，也可以与全球自动化周期、收购前订单/产品、投资和项目执行同时存在；若直接合作/中国项目没有单独结果，就不能归因于美的 |
| 已知行动 | 94.55% 控制；库卡称拟扩充上海能力、规划顺德机器人园区 | 这些是计划和资源承诺，不是客户、单位经济或现金结果 |

不以收购价格、集团股价或后来地位作为 H-A 的证据。

## 2017 年实体结果：可以读，但只能分箭头结算

库卡年报给出同一实体、同一口径的 2016–2017 观察：

- 销售收入由 29.489 亿欧元增至 34.791 亿欧元（+18%），但 EBIT 由 1.272 亿欧元降至 1.027 亿欧元，利润率从 4.7%降至 4.3%；年报把约 4,000 万欧元的影响归于欧洲系统业务的产能瓶颈与修复措施。
- 经营现金流从 -960 万欧元改善至 9,200 万欧元，年报归因于贸易营运资本增量由 1.645 亿欧元降至 2,480 万欧元；自由现金流却由 -1.068 亿欧元进一步降至 -1.357 亿欧元，受投资现金流影响。
- 对美的集团的已披露关联交易仅为库卡向美的提供 200 万欧元货物和服务、美的向库卡提供 0；这只说明直接交易桥尚小，不能排除间接渠道、制造或治理效果。
- 同一报告引用国际机器人联合会的全球工业机器人销量 +18%，故库卡收入增速本身不能识别中国买方带来的增量。

正确的教学结算是：

```text
CONTROL_AND_TARGET_ENTITY_ACCOUNTING: OBSERVED
TARGET_REVENUE_GROWTH: OBSERVED_BUT_NONDIAGNOSTIC
TARGET_MARGIN_AND_FREE_CASH_FLOW: WEAKER_OR_MIXED
DIRECT_MIDEA_KUKA_TRANSACTION_BRIDGE: SMALL_OBSERVED
MIDEA_TO_KUKA_CUSTOMER_OR_UNIT_ECONOMIC_SYNERGY: UNKNOWN
ACQUISITION_CAPITAL_RETURN: UNKNOWN
```

这不是说收购失败。收入、利润和现金现在落在正确实体上，却仍需要把 `行业 → 客户/项目 → 单位经济 → 现金` 的归因链补全；控制权只消除了会计对象错误，不能消除竞争机制的替代解释。

## 与 R-45 的交叉复验

```text
R-45: 无同一受控实体的结果合同 → 不读集团结果来判交易
R-46: 有同一受控实体的结果合同 → 仍需非共同客户/项目桥，才可将结果归因于收购
```

这两步是企业家/行业研究所需的连续能力：先知道钱、控制与责任落在哪里；再知道经营变化由谁、哪项客户价值和哪个执行环节造成。

## 下一轮约束

收购后第一年的目标实体卡，除控制图和实体级财务外，还必须冻结：

1. 一个可识别的买方投入/治理/技术或渠道动作；
2. 该动作对应的目标实体客户、订单、产品/服务或项目 KPI，且与行业基线可区分；
3. 单位毛利/项目成本或服务负担，以及应收、库存、经营现金中的至少一项；
4. 行业需求、既有积压订单、收购前投资和一次性整合成本的替代路径。

若只有实体整体收入、利润和现金，可学习经营状态，却只能停在 `NONATTRIBUTABLE`；不能做协同、管理者或交易回报判决。

## 本轮结论

`RETAIN_AND_NARROW / ENTITY_ACCOUNTING_IS_NECESSARY_NOT_SUFFICIENT / CUSTOMER_BRIDGE_BEFORE_SYNERGY`

根因：`REASONING + DATA_COVERAGE`。在本案中，把控制权、实体收入增长或某一项现金改善直接写成美的协同，会材料性误判库卡的正常盈利、现金承受力和美的资本回收；反过来将利润率/自由现金流走弱直接写为收购失败，也会把既有投资、营运资本和系统项目产能问题误归因。缺失的是美的投入与库卡中国客户/项目、价格成本、服务、回款的连续连接。禁止以控制比例、集团营收、行业增速、关联交易金额、股价或回报补足。验收是在另一已控制实体中，行动—客户/项目—单位经济—现金四段均有同口径合同；否则只保留本卡的归因边界。
