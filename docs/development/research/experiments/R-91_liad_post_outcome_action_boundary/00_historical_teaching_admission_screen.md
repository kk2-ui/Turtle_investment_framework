# R-91｜利亚德 2026 年业绩说明会：事后战略叙事不能倒推为事前选择判断

状态：`HISTORICAL_TEACHING_SCREEN / NO_PRIMARY / NOT_FROZEN / NO_SELECTION_SCORE / OUTCOME_EXPOSED`。

R-91 检验一个容易使研究显得“有判断”、实则破坏训练的来源形态：管理层在已披露年度经营结果后，回溯说明战略转向、项目取舍和调价，并把它们与利润改善连在一起。这样的材料可以用于训练研究者区分行动叙事、同期结果和并发解释；它不能被重写成一项结果前已经可以选择的企业判断。

本卡不评价利亚德、管理层、LED 行业、技术路线或证券。它也不否定“以利润为中心”的转向可能有经营价值；本卡仅裁决目前找到的原件不能承载一条事前选择结论。

## 2. 原件实际提供的事实，和它没有提供的事实

原件称公司从 2025 年起提出“以利润为中心”，减少低毛利、收款不佳且有风险的业务；在传统商显 LED 屏同质化竞争和价格战激烈的背景下，主动放弃毛利率低、回款风险高的项目。它又称公司于 2026 年初发布调价通知，并陈述 2026 年将扩大海外市场、压缩不达标子公司、推进回款与结算、继续研发和应用拓展。

同一份原件没有把 FY2025 的经营变化归为单一原因。公司并列列出减值压力缓解、境外高毛利市场突破、Micro LED 放量和持续降本增效；有关利润改善、订单和毛利率的陈述均已发生在其解释之后。下表因此只记录它能训练的证据边界，不把后来的解释提升为行动效果。

| 层次 | 已知、但已结果暴露的陈述 | 不能倒推的缺口 |
|---|---|---|
| D1 决策/实施 | “以利润为中心”、减少高风险低毛利项目、年初调价、后续的组织与回款措施。 | 没有一份在 FY2025 结果前可取得、可定位到项目/客户/产品的行动 package；也没有开始日、负责人、资源范围、预算、批准阈值、停止或回转权。 |

## 3. 为什么事后来源不能形成 H-A 的选择依据

```text
H-A：利润中心转向和项目纪律改善了客户质量、单位经济、现金与资本回收
低毛利/高风险项目退出与定价纪律
  -> 客户和渠道组合改善、竞争者需要作出针对性让步
  -> 同一单元量价成本费用改善
  -> 更短回款和更低营运资本占用转为经营现金
  -> 释放或重配资本获得可观察回收

H-B：并发市场、会计和技术/区域组合变化主导已知结果
减值压力缓解、海外高毛利市场、Micro LED 放量、降本增效及行业价格竞争
  -> 盈利、订单、毛利率和现金可以同时变化
  -> 无法由集团/事后叙事分配给项目取舍或调价
  -> 项目现金与资本回收仍不可知
```

这里的问题不在于 H-A 必然错误，而在于原件在解释时已知 H-A 和 H-B 都可容纳的结果，且自己提供了多项并发解释。它没有在结果前让 H-A、H-B 和公平简单基线对同一个 D2-D4 观察给出不同预测。把后来看到的“扭亏”“毛利率改善”或订单，反写为 H-A 的事前胜出，会把教学材料伪装成选择判断样本。

## 4. 裁决、停止条件与可重开路径

- **根因：** `REASONING + DATA_COVERAGE`。不是再增加解释性材料的问题，而是拟使用的来源本身已在 FY2025 与 2026Q1 结果揭盲后回溯归因；同时缺少可归责 D1 package、客户/竞争 cohort 和 D3-D5 同单元桥。
- **经济影响：** 若将事后归因当作事前判断，会材料性高估项目取舍和调价的可复制性，错误归因利润改善、现金转换和资本回收，并低估减值、产品/区域组合、技术放量和竞争环境的替代解释。
- **缺失事实：** 结果前、带日期的一手行动 package；受影响项目/客户/渠道 cohort 与反方；同单元量价成本费用、订单现金与资本回收边界；以及在当时能分叉 H-A/H-B/简单基线的未来观察合同。
- **禁止假设：** FY2025 扭亏、FY2025 或 2026Q1 毛利率变化、Micro LED 订单、海外市场、年初调价、集团回款措施、后续工厂或管理层对“利润中心”的解释，能够替代事前冻结或证明客户吸收、现金质量、资本回收和选择正确。
- **可执行处置：** 关闭 `R-91 / NO_PRIMARY / NOT_FROZEN`；不建立 future judgment、简单基线、结果合同、选择准确率或学习复制。仅把本卡作为“先验与事后说明必须分离”的历史教学边界。
- **接纳标准：** 只有取得一份在相关结果前发布、可定位到特定项目/产品/客户的行动原件，并在同一 cutoff 前冻结停止权、客户/竞争 cohort、D3-D5 责任单元、H-A/H-B/简单基线的分叉预测，才可为一个**新的** episode 重新申请准入。不得用本 2026 年说明会反向补足这些字段。

## 5. 对飞轮的实际约束

R-91 把“事后管理层解释”固定为可教、不可选的材料类别。下一候选的第一项检查不是故事是否完整，而是行动原件是否先于待结算的结果，并且能否在读取结果前写出客户/竞争反应、单位经济、现金和资本的不同预测。做不到时，应当像本案一样留下明确的 `OUTCOME_EXPOSED` 拒绝记录，而不是把叙事扩写成判断力。
