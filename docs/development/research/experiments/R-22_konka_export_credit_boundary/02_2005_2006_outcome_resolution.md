## 3. 对企业家判断的实际学习

1. **风险工具与现金工具不是同一个概念。** 出口信用保险可能改变部分违约损失，却不自动提前现金到账、限制新增发货或降低库存资金占用。
2. **客户分散不能取代现金桥。** 公司整体前五销售商占比低于长虹，但 2004–2005 OCF仍为负；因此“集中度下降”只能是风险维度的一项信息，不是现金结论。
3. **OCF 也必须追问来源。** 2006 的正数不能略过应收/库存扩大和应付增加。经营者必须识别客户付了钱、供应商延后收钱，还是两者兼有。
4. **这不是“保险无用”或“海外增长错误”。** 本案没有保单条款、理赔、海外客户集中度或逐客户收款资料，故不能估计保险的损失保护，也不能对海外扩张作总判断。

## 4. 飞轮更新

R-21 之后的正/近失效寻找没有产出一个可宣称“信用治理使现金显著不同”的成功对照；它反而给出更窄、更重要的边界复验：

`credit_governance_visibility` 必须拆为 `loss_protection / collection_speed / funding_effect / shipment_authority` 四项。任何案例若只披露“保险、信用证、票据或保理”之一，最多可支持其中一项的候选机制；若没有条款和现金时点，则不能结算其余三项。

根因：`REASONING + DATA_COVERAGE`。若把保险、低集中度或正 OCF任一单点理解成客户现金恢复，会误判正常盈利、营运资本和融资依赖；若因两年现金不佳便宣布保险或出口扩张无效，又会超过未披露的保单/客户事实。缺失事实是各海外客户的授信与收款、保单范围/免赔/理赔、库存归属和应付条款；禁止用没有巨额坏账、年末现金、收入、价格或回报填补。

本案最终判断：`EARLY_MECHANISM = SUPPORTS_RIVAL_FOR_LIQUIDITY`；`TERMINAL_OPERATING = MIXED / NOT_DIAGNOSTIC_AS_CUSTOMER_CASH`；`RISK_TRANSFER_EFFECT = UNKNOWN`；`SELECTION = NO_PRIMARY_FOR_MANAGER_SELECTION`；`DECISION_LOGIC = UNKNOWN`；`TOTAL_COMPANY_ECONOMICS = UNKNOWN`。
