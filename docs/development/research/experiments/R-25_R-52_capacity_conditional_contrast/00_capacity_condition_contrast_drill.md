# P-102：R-25 与 R-52 的条件对比练习——从两个扩产故事抽取可迁移的判断边界

## 身份与目的

`METHOD_TRAINING_EXPERIMENT / RESULT_KNOWN_TEACHING / CONDITIONAL_CONTRAST_ONLY / NO_COMPANY_OR_METHOD_SUPERIORITY_VERDICT`

本卡不重新裁决美的或隆基，也不把后一案当作前一案的“成功反例”。它测试一个更窄的训练动作：在两张已经独立结算的中国制造扩产卡之间，能否抽取**条件化的因果骨架**，而不把表面相同的“扩产”或结果已知的规模感迁移为规律。

其学习依据是 Gentner、Loewenstein 与 Thompson 的 *Learning and Transfer: A General Role for Analogical Encoding*（2003，DOI [10.1037/0022-0663.95.2.393](https://doi.org/10.1037/0022-0663.95.2.393)）：在其谈判实验中，比较两个案例比逐一学习更有助于抽取可迁移结构。该实验对象不是企业研究，故它只提供“比较是值得在 Turtle 内部检验的训练干预”这一假设，不证明会提高投资或公司判断。

## 前置纪律：先独立，再比较

两张原卡必须保持各自的 cutoff、事实边界和结算不变：

- [R-25：美的 2004 扩产与部件链](../R-25_midea_2004_capacity_chain_teaching/02_2005_2006_outcome_resolution.md)；
- [R-52：隆基 2015–2016 单晶扩产](../R-52_longi_2015_capacity_customer_cash_teaching/00_2015_2016_monocrystalline_capacity_teaching.md)。

这里不得把 R-52 的结果补入 R-25 的原卡，或反过来。只有在两卡各自已经完成 `resource_commitment → output_absorption → unit_economics → working_capital_cash → capital_return` 的独立结算后，才允许写下面的对照。这样避免“先觉得两个案例相像，再用另一案的结果重写本案”。

## 对照的单位不是公司，而是同一个经营问题

共同问题为：**一项制造产能/产业链资源承诺，在价格与需求变化中何时只增加产出，何时显示产品经济改善；什么时候仍不能评价资本回收？**

| 因果位置 | R-25：美的空调/压缩机 | R-52：隆基单晶硅片/组件 | 可以保留的结构，不可以迁移的参数 |
|---|---|---|---|
| 外部状态 | 成熟空调市场供给压力，行业销量近乎持平。 | 技术路线转换，单晶有效供给偏紧；产品价格仍下行。 | 先定义需求/有效供给与价格—成本状态；行业名或景气标签不够。 |
| 资源承诺 | 整机多基地扩能、压缩机能力/合资。 | 硅片/组件扩能、工艺导入和下游延伸。 | `resource_commitment` 必须与具体产品/责任单元相连。 |
| 产出吸收 | 整机销量和收入仍增长。 | 两类产品产量、出货和产销率增长。 | 出货可以结算吸收箭头；不是项目回报。 |
| 产品经济 | 压缩机量增但外部收入下降、毛利率降 9 个百分点。 | 在价格下降中，硅片/组件收入和毛利率均提升。 | 价格方向本身没有 verdict；须读同产品的价格、成本、组合和毛利。 |
| 现金与资本 | OCF 受业务剥离、存货/应收/应付共同影响。 | OCF 为正但应收占用大，固定资产投资与外部融资很大。 | 集团 OCF 不等于扩产 owner cash；资本回收须有项目/责任单元资本和现金。 |

## 本次抽取的条件化 schema

```text
外部需求/有效供给 + 客户对成本/性能的反应
→ 某产品产能的实际吸收
→ 同产品价格 × 成本 × 组合的单位经济
→ 应收、存货、应付与资本支出的现金传导
→ 只有责任单元增量现金与替代路径齐备，才谈资本回收
```

从两卡共同保留的不是“扩产应该/不应该”，而是：

1. 出货增长只能支持 `output_absorption`；
2. 价格下降不能单独否定产品经济，价格上涨也不能单独肯定它；
3. 正 OCF、集团现金或融资能力均不能替代 `working_capital_cash` 与 `capital_return`；
4. 判断在何种状态下扩产的产品经济可能改善，至少需要读到产品级的价格、成本/毛利和吸收，而不是行业排名或管理层口号。

R-25/R-52 的差异只提出候选调节条件：成熟供给压力与技术路线转换/有效供给约束，可能让“出货 → 单位经济”这段分叉。它们不证明这一个条件穷尽了原因，也不使光伏参数可用于空调、工程机械或格力。

## 作为训练干预如何被验证

下一张**不同公司的中国制造扩产/关键部件/自动化**卡，先按下列两种方式在结果前各写一次，并冻结其差异：

| 版本 | 允许材料与输出 | 成功的最小可观察差异 |
|---|---|---|
| A：单卡基线 | 只读该公司的 cutoff 前材料，写常规 H-A/H-B。 | 可以提出一条机制，但未必显式识别状态调节项。 |
| B：条件对比训练 | 同样的目标材料；额外只读本卡的四项不变量和两个条件格，不得读取 R-25/R-52 的公司结局叙述。 | 在冻结前明确：`需求/有效供给`、`产品价格—成本`、`产品级吸收`、四类现金来源与资本回收缺口；并令 H-A/H-B 对其中至少一项产生不同观察。 |

验证不比较文笔，也不按后来股票/回报打分。结果期仅检查：

1. B 是否比 A 多出一个**真正不同且可结算**的产品经济或现金观察，而非多一段解释；
2. 若结果显示该观察不可判，B 是否在 cutoff 前已把正确边界留为 `UNKNOWN`，而不是拿集团 OCF 或行业数据替代；
3. 若该观察有诊断性，是否让 B 更早定位在 `状态 / 吸收 / 单位经济 / 现金 / 资本` 的哪一箭头失效；
4. 只有跨不同公司完成这一比较，才可将结果写入 learning note；一张卡或两张历史卡绝不构成“对比训练提高判断力”。

没有合格的下一对象时，本卡的正确状态是 `DESIGN_READY_NOT_LIVE_TESTED`。它不是暂停，而是避免把两个事后案例直接升格为方法优势。

## 本轮结论

`RETAIN_AS_CONDITIONAL_CONTRAST_DRILL / NO_TRANSFER_VERDICT_YET`

根因：`REASONING + MODEL`。若案例逐张累积，agent 很容易从 R-25 学成“扩产有害”，或从 R-52 学成“技术领先即可扩产”，两者都会材料性误判正常盈利、现金转换和资本回收。缺失的是下一不同公司的、结果前冻结的 A/B 对比及同定义经营结算。禁止用已知结局、价格/回报、案例数量或案例主角的后续地位衡量训练有效性。验收是 B 在新对象上实际改变一个冻结的经济问题或结果合同，并在后续结算中显示该改变有/无诊断性；此前仅是可复核的训练设计。
