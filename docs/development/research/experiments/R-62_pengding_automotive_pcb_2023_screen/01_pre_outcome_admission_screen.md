# R-62｜鹏鼎控股 2022–2023：汽车／服务器 PCB 扩产的多层时钟筛查

状态：`PRE_OUTCOME_SCREEN / NO_PRIMARY / NOT_FROZEN / OUTCOME_BODY_UNREAD`。

这个筛查不是判断鹏鼎控股的技术、客户质量、汽车电子前景或募投项目回报。它只问：截至 `2023-03-30`，已投产的车载电池板、客户认证和拟建设的汽车／服务器 PCB 项目，是否已经形成一条可被同主体 D1–D5 时钟和公平反方结算的企业决策链。结论是**尚未形成**；它提供了很好的“入口事实”，但不能被升级为训练中的选择判断。

## 2. 已有的真实入口，和仍断开的企业系统

可行性报告明确：项目由全资子公司宏恒胜电子科技（淮安）实施，建设期两年；总投资 `RMB1.12bn`，其中拟用募集资金 `RMB0.80bn`，产出同时包括新增汽车 HDI `138` 万平方英尺和服务器板 `200` 万平方英尺。它的第 5 年收入、净利润和 IRR 是公司项目模型，不是实际经营事实。

年报另披露：15 万尺车载电池板于 2022 年投产并获多家主流客户认证；汽车 ADAS L2 产品已量产，L3 仍在技术验证。可是披露的产品口径把“汽车、服务器用板及其他用板”合在一起：2022 年收入约 `RMB314.2m`、同比 `+44.02%`，只占集团收入 `0.87%`。它没有给出该口径的成本、毛利、销量、客户订单或项目实施主体的现金桥。

## 3. 为什么不冻结 H-A／H-B

“认证与扩产会带来可吸收的高端汽车板量产”与“认证／项目模型不能穿透为项目现金、且产品组合和周期会主导集团结果”都与 cutoff 前材料相容。前一方向的项目 IRR、市场规模和管理层竞争力表述不是非共同方向性事实；后一个方向也不能仅由小业务占比推断。由于 D2–D4 没有同一责任单元的结果合同，任何后来汽车／服务器合并收入、集团毛利、OCF 或资本开支都不能公平裁决其中一方。

R-62 因而不建立 FJ、selection baseline、教学 outcome firewall 或 near-miss 身份。它是 `NO_PRIMARY` 的筛查关闭，不是“扩产失败”或“公司不具能力”的结论。

根因分类：`DATA_COVERAGE + REASONING`。这里不缺项目金额或公司叙事；缺的是将认证、产线、客户吸收、单位经济、营运资本与项目资本回收连接为同口径责任单元的原始字段。若用集团收入、OCF、公司模型 IRR 或后续景气填补，将材料性误判正常盈利、owner cash 与资本配置。

禁止假设：

- 获得认证、项目审批、资本开支计划或公司 IRR 就证明客户持续吸收或项目回报；
- 汽车／服务器合并收入可替代汽车 HDI 的单位经济；
- 集团 OCF、总毛利或行业需求可替代项目现金桥；
- 后续业绩、价格或回报可以补出 cutoff 时不存在的竞争机制。

下一个同类候选必须在 cutoff 前保留项目主体、项目专属客户／订单或量产接口、同产品量价成本、责任单元现金桥和实际资本范围；否则继续在结果期前关闭。
