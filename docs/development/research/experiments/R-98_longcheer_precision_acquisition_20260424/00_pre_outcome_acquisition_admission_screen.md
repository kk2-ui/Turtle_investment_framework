# R-98｜龙旗科技 2026 精密金属件收购：同一终端市场不等于已可验证的垂直协同

状态：`PRE_OUTCOME_ACQUISITION_SCREEN / NO_PRIMARY / NOT_FROZEN / NO_SELECTION_SCORE / OUTCOME_BODY_UNREAD`。

R-98 筛查一家中国智能产品 ODM 对两家精密金属制造公司各收购 `60%` 股权的资本配置动作。交易有明确的卖方、现金对价、付款安排、目标公司历史财务资料和 DCF 预测，较通常的“聚焦主业”公告完整得多。它仍不能成为企业判断选择样本：公告没有把目标公司的既有北美客户、龙旗的品牌客户、具体散热/金属件 SKU、订单、价格、成本、营运资金和收款连接为同一交易链。因此，未来目标公司或集团的收入、利润和并表现金都不能区分“收购带来 ODM 协同”与“既有单一客户订单或独立经营延续”。

本卡不判断龙旗科技、目标公司、管理层、交易价格或任何证券。它只冻结截至 `2026-04-24T00:00:00+08:00` 能否对“本次收购会产生增量经营经济性”作出可结算选择。6 月完成公告及其后的公司结果、价格和回报均未读取。

## 3. 竞争机制、基线与选择证据审查

共同事实是：龙旗以现金取得用于消费电子散热/结构件的目标公司控制权；目标 A 在收购前因一名未具名北美客户而出现显著利润增长；母体和目标都面向消费电子，但披露没有证明任何客户、项目或订单重叠。

```text
H-A：收购形成可验证的 ODM--精密件一体化
龙旗取得控制权并把目标零件导入其 ODM 项目
  -> 同一品牌/项目接受组件组合与供货安排
  -> 目标销量/价格/成本随龙旗项目而改善
  -> 订单应收、库存和采购现金转化为可归属自由现金
  -> 增量现金回收收购及维护资本

H-B：目标的既有客户关系和独立供货经济性主导结果
收购前北美客户、原有订单和目标自身经营延续
  -> 目标收入/利润可继续变化，但没有已证实的龙旗项目导入
  -> 任何并表结果同时包含原有客户、消费电子周期和目标自身成本变化
  -> 集团现金无法分出收购协同、目标独立现金或母体其他投入
  -> 收购资本回收仍不可归因

简单基线：目标公司按收购前披露的客户关系、订单和独立经营计划继续经营；
不假定龙旗客户导入、内部采购替代、协同毛利或增量现金已经发生。
```

H-A 所需的客户导入是一个合理的**机制问题**，不是可选主路径。目标 A 的北美客户、龙旗列示的品牌客户、相同终端类别、卖方 DCF 以及管理层“协同”表述，都能同时被 H-A 和 H-B 解释：它们没有指出同一客户或同一项目，也没有给出不同的未来结算区域。目标 A 的预测收入在 2026 年反而低于 2025 年，说明预测本身不是“收购后协同必然加速”的方向性证据；它同样不能证明 H-B 正确。

因此，截止日前不存在可填写进选择表的、彼此独立且只支持 H-A 或 H-B 的证据行。没有合格选择证据时，任何“协同有效”或“高价收购错误”的中心选择都会把行业相邻性、DCF 输入或单一客户集中度误当作前瞻判断力。

## 4. 准入裁决与停止条件

- **裁决：** `NO_PRIMARY / NO_ELIGIBLE_ECONOMIC_FJ / NOT_FROZEN`。本对象可保留为资本配置—组件制造的机制发现材料，但不能登记为 `JUDGMENT_SELECTION_EPISODE`、选择准确率、方法复制或学习样本。
- **根因：** `DATA_COVERAGE + REASONING`。不缺交易文件或管理层叙事；缺的是把 H-A/H-B 置于同一客户/项目、同口径量价成本、订单现金和资本边界中的结果前观测与可结算来源。把两家公司处在相邻产业链误作客户关系，是行动—经济传导的推理越界。
- **经济影响：** 若把并表、目标历史利润或 DCF 自由现金流称为收购协同，可能把既有单一客户订单、消费电子周期和母体其他投入错配为公司资本配置能力，材料性高估正常盈利、现金转换与资本回收；反方向地，也不能由客户集中这一项断言交易失败。
- **缺失事实：** 目标零件与龙旗特定客户/项目的事前供货关系或可验证导入承诺；项目级数量、实现价格、材料/加工成本、竞争/替代供应商；目标客户应收、库存、采购和收款；收购付款的资金来源、资本替代用途以及可以在结果期独立重建的税后现金回收指标。
- **禁止假设：** 同一终端行业、龙旗客户名单、目标 A 的北美客户、卖方 DCF、目标历史利润、交易交割、未来并表收入/利润、集团经营现金或任何价格/回报，可替代一条收购后且可归属的客户—单位经济—现金链。
- **可执行处置：** 关闭 `R-98`，不建立结果合同、condition inbox 或未来 judgment claim；不读取 6 月交割及其后经营结果来补写当前机制。后续只把这一约束用于选择下一候选。

## 5. 对训练飞轮的新增约束

一宗同时具有对价、付款、目标历史财务和 DCF 的制造业收购，仍可能只有 `ACTION_SETTLEMENT_ELIGIBLE`。对“垂直协同”准入，下一轮至少须在 cutoff 前同时具备：

1. 可识别的客户或项目连接，使被收购责任单元与收购方既有业务的关系不是行业相邻性；
2. 该连接的量/价/成本或明确停止权，令 H-A、H-B 和简单基线对同一未来观察给出非嵌套预测；
3. 可在结果期由官方披露重建的订单现金、营运资本和资本回收边界，而不是仅靠合并报表或卖方 DCF。

这不是提高资料数量门槛。它要求每一份额外材料实际改变客户传导、单位经济、现金归因或资本回收中的一项；否则应保留 `UNKNOWN` 并换样本。
