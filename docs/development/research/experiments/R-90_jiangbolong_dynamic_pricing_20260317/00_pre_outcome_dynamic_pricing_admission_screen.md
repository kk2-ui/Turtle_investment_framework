# R-90｜江波龙 2026 年动态定价：行业周期下的价格响应不是可选择的管理机制

状态：`PRE_OUTCOME_ADMISSION_SCREEN / NO_PRIMARY / NOT_FROZEN / NO_SELECTION_SCORE / OUTCOME_BODY_UNREAD`。

R-90 检验一个在周期行业中很常见、也很容易被高估的表述：公司称其会依据供需和客户订单动态调价，且在供应偏紧中拥有产品能力和原厂合作，是否已经足以选择“管理层可把供给优势转成持续客户吸收、现金和资本回收”这一路径。

结论是否定的。截止日前原件确认了行业供需、公司产品能力、原厂合作和动态定价程序；它没有确认一项具有开始日、产品和客户范围、授权资源、价格幅度、停止/回转权的实际 D1 行动，更没有一条可与反方分叉的客户观察。把本轮存储周期的价格、出货或任何后续财务变化归为公司的定价判断，会把行业状态和企业选择混为一谈。

本卡不评价江波龙、管理层、存储价格、产品能力或其证券。没有读取截止日后的公告、经营结果、价格、估值或回报。

## 3. 两种完整解释都能容纳当前资料

```text
H-A：公司能力和供应协同将行业紧张转化为可持续客户价值
主控/固件/封测能力与原厂合作
  -> 具名终端客户以更高价值产品持续下单
  -> 价格/组合优于晶圆、制造与服务成本的变化
  -> 同一订单的营运资本转成经营现金
  -> 产品和供应能力的增量资本获得回收

H-B：外部存储周期与客户订单结构主导，动态定价只是适应
AI 需求、HDD 短缺、原厂扩产时滞和晶圆价格
  -> 行业范围内价格/订单同时变化，客户可转换来源或采购时点
  -> 公司价格、出货和毛利同时受供给、产品组合与库存周期影响
  -> 营运资本先吸收或释放现金，资本回收仍未知
```

在 cutoff 前，二者都预期公司会观察供需、订单和价格，并可能调整报价；因此“动态定价”是 `COMMON`，不是 `ASYMMETRIC` 或 `RIVAL_ACCOMMODATION_REQUIRED` 事实。原件没有使 H-A、H-B 或简单的行业调整持续基线对同一未来 D2、D3、D4 观察给出不同预测。研究者不能仅因 H-A 更吸引人便冻结为中心路径。

## 4. 准入裁决与停止条件

- **根因：** `REASONING + DATA_COVERAGE`。官方双入口来源已完成，缺口不是再找行业资料，而是把行业状态/响应程序误当成了特定管理行动；公开资料又没有同单元客户、单位经济、现金和资本事实。
- **经济影响：** 若将价格周期、供应偏紧、合作或未来出货写为公司定价能力，会材料性高估正常利润的持续性、库存与应收的现金转换，以及供应链/产品投入的资本回收，并低估存储周期反转和客户采购调整的永久损失风险。
- **缺失事实：** 已执行的价格/产品/客户 package 及其责任人、资源和停止权；受影响客户 cohort 与对照、报价接受/交付/竞争回应；量价成本费用桥；订单现金桥；可归属资本与替代用途。
- **禁止假设：** 行业供需偏紧、晶圆涨价、原厂合作、头部客户、批量出货前夕、动态定价、总收入、总毛利、总 OCF、库存、外部融资或后续业绩可以替代上述事实。
- **可执行处置：** 关闭 `R-90 / NO_PRIMARY / NOT_FROZEN`；不建立 future judgment、简单基线、结果合同或方法复制。下一轮不再把“依行业/订单动态定价”的答复列为 D1 线索，除非同一 cutoff 前原件同时给出实际 package、受影响 cohort 和可结算反方分叉。
- **接纳标准：** 至少一项 `ASYMMETRIC` 或 `RIVAL_ACCOMMODATION_REQUIRED` 事实把已实施、可停止的 D1 连接到同一责任单元 D2；H-A、H-B 与公平简单基线须对预注册 D2、D3、D4 观察给出不同预测。D5 仍须有实际资本范围和替代路径，否则不得形成 `SELECTION_ADMITTED`。

## 5. 对飞轮的实际约束

R-90 将“行业状态 -> 公司动态响应”明确标为不可选择的共同事实。它不否定企业能力可能使 H-A 成立；它只要求研究者在结果开放前先找到客户和竞争方不能以同样方式解释的行动接口。下一候选继续优先寻找可定位的产品、渠道、组织或信用治理 package，并在读取集团财务前确认其客户/竞争 cohort 和同单元观察通道。
