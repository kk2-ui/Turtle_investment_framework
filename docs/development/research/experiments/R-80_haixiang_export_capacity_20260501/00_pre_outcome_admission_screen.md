# R-80｜海象新材 2026 全球产能调整：企业系统信息充分，仍不能把复苏故事选成主路径

状态：`PRE_OUTCOME_ADMISSION_SCREEN / NO_PRIMARY / NOT_FROZEN / NO_SELECTION_SCORE / OUTCOME_BODY_UNREAD`。

R-80 检验的是一间出口制造企业面对美国溯源限制、越南产能、订单生产、产品组合、信用保险与现金压力时，资料丰富是否已经足以选择“全球产能网络会修复经营”的主路径。它不是对海象新材、其证券或管理层能力的结论；未读取 2026H1 或之后的结果。

结论是**在结果前停止**。两份截至 `2026-05-01` 的 CNINFO 法定原件足以把企业系统拆开，但没有一项新、已实施且可归责的经营资源配置，能让“越南产能／数字化使客户和经济性修复”与“贸易限制和资产占用持续压制经营”产生非任意的不同预测。不能因为材料丰富、海外客户知名、信用保险或单季利润为正而选择其中一方。

## 1. 截止日前可确认的企业状态

| 层次 | 结果前事实 | 不能据此推出 |
|---|---|---|
| D1 决策／实施 | 2025 年公司称已上线 ERP、MES、BI 与 OA 系统；2023Q3 越南子公司曾为配合美国海关原材料溯源而协助客户提交资料、召回在途产品并大幅减产。2026 年“按客户需求调整产能、盘活闲置资产”仍是经营计划。 | 数字系统、过去的减产应对或未来计划已经形成新的客户承诺、产能利用率改善或止损权。 |

## 2. 竞争机制为何仍不能被选择

```text
H-A：全球网络恢复
越南订单转移 + 数字化协同 + 按订单生产
  → 关键客户持续下单与交付恢复
  → 产品组合／成本和营运资本改善
  → 已投产资本逐步得到回收

H-B：贸易约束与资本占用持续
美国溯源／区域贸易风险 + 低利用率／越南亏损 + 客户应收与汇率周期
  → 客户与订单不能稳定穿透到交付
  → 价格、组合、费用和现金继续承压
  → 既有海外资本仍需吸收资金
```

H-A 与 H-B 都能容纳“越南利用率恢复、但收入／SPC／Q1 利润现金走弱”：前者可说是初期恢复的组合不完整，后者可说转移订单未证明目标市场或经济性。反过来，H-B 也能容纳部分越南订单恢复。要选择 H-A，需有未观察到的、同口径海外客户再认证／订单／交付和价格实现；要选择 H-B，则需把当期混合产品与汇兑结果误写成长期机制。两种补写都不允许。

公平基线也不存在。原件未将美国／欧盟／其他区域、越南／中国基地、直接客户／贸易商订单、产品价格／成本及现金分别连续披露；因此不能以公司总收入、某个产品毛利、信用保险或集团 OCF 构造“维持现状”的可结算反事实。

## 3. 停止判断

- **根因：** `REASONING + DATA_COVERAGE`。D2–D5 的状态资料很完整，真正缺的是一个截止日前已实施、可归责且能让 H-A/H-B 对同一结果变量出现相反预测的 D1→D2 接口。
- **经济影响：** 若把越南利用率、数字化上线、客户名气、保险或正利润直接写成复苏，会忽略贸易障碍、产品组合、汇兑、应收与海外资本占用，材料性误判正常盈利、owner cash 与永久损失边界。
- **缺失事实：** 新产能／数字系统与具体客户订单、区域交付、价格／成本、回款和资本使用之间的责任链；以及同口径的区域／基地基线。
- **禁止假设：** 经营计划等于实施；信用保险等于实际回款；订单生产等于客户持续吸收；越南利用率、集团现金或一个产品毛利可代表贸易限制下的责任单元经济；未来中报可以回写选择依据。
- **可执行处置：** 关闭 R-80，不建未来 FJ、不读取结果期。只有一个新 cutoff 前的官方来源同时给出具体已实施资源动作、客户／订单归属、区域／基地产品经济和现金／资本口径，并使主反机制的预测与公平基线不同，才允许新的 episode 重新筛查。
- **接纳标准：** 至少一条 `ASYMMETRIC` 当前事实连接可验证的 D1→D2 箭头；D2、D3、D4 的未来观测都归同一责任单元，D5 明确资本范围。否则继续为 `NO_PRIMARY`。

## 4. 飞轮作用

R-80 是“公司不能靠单一指标看清”的正例：同一套原件既有客户与订单流程、三个产品的量价成本、应收保险与收汇周期、现金流、海外工厂资本和外部制度冲击。它训练研究者把这些层同时保留，而不是选一项漂亮指标替代全局；但在没有可选择的 D1→D2 因果接口时，完整描述仍不产生判断胜负。
