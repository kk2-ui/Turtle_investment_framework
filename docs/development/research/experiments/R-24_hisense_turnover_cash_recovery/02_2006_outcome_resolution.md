# R-24：2006 年结果复盘——库存周转能修复现金，但不等于客户现金已改善

前置冻结卡：[2005 年海信电器渠道结算变化与周转现金恢复卡](01_2005_pre_outcome_cash_recovery_card.md)。

状态：`RESULT_KNOWN_TEACHING / POSITIVE_OPERATING_BOUNDARY / NO_MANAGER_VERDICT`。

| 观察 | 2006 年结果 | 对机制的意义 |
|---|---:|---|
| 海外主营收入 | 21.60 亿元，同比 +24.91%。 | 经营现金改善并非由海外销售收缩造成。 |
| 合并 OCF | +1.847 亿元。 | 与 2005 的 -1,108 万元相比转正。 |
| 存货 | 16.74 亿元，同比 -20.00%；现金流调节表显示存货减少带来 3.912 亿元现金。 | 支持周转/库存释放是现金恢复的重要传导。 |
| 经营性应付 | 现金流调节表为 -4.724 亿元。 | 现金改善不是由增加经营性应付、延后付款所支撑。 |
| 应收账款/票据 | 应收账款 +11.69% 至 4.67 亿元；应收票据 -3.32% 至 9.98 亿元。 | 不能称为客户信用或回款已经全面改善。 |

来源：[海信电器 2006 年年度报告](https://finance.sina.com.cn/stock/company/sh/600060/9_10.shtml)。该报告把 OCF改善解释为加速资金周转、降低库存占用和加快应收周转；本复盘将该解释保留为公司归因，并只以可读的库存、应收/票据、应付和 OCF数值结算。

## 逐箭头结算

| 冻结箭头 | 结算 | 原因 |
|---|---|---|
| 周转修复能否恢复经营现金 | `SUPPORTS_PRIMARY_FOR_INVENTORY_CASH_RECOVERY` | OCF转正，存货显著下降，且应付没有提供正向现金支撑；海外收入仍增长。 |
| 客户信用/票据是否已恢复 | `NOT_DIAGNOSTIC` | 应收账款上升、票据仅小幅下降，缺逐客户结算与实际收现资料。 |
| 是否评价具体管理决策 | `NO_MANAGER_VERDICT` | cutoff 前没有能与简单延续基线严格区分的库存、信用或责任人授权。 |
| 公司总经济性 | `UNKNOWN` | 产品结构、技术投入、国内外渠道与资本配置不能由这一条现金桥裁决。 |

## 飞轮更新

R-24 是 R-21–R-23 的必要正向边界：**营运资本现金修复可以来自库存周转，在应收/票据尚未全面改善时发生；它既不是“客户信用治理成功”，也不是“收入增长天然有害”。**

今后的现金结算至少区分 `collection_cash / inventory_cash / supplier_finance / external_financing` 四个来源。只有各项同时列出，才可说任何一项经营动作改善了 owner cash。

根因：`REASONING + DATA_COVERAGE`。只看 OCF正数会把库存释放误认成客户回款；只看应收仍上升又会漏掉真实的库存现金释放。两种错误都会误判正常盈利、流动性和永久损失。缺失的是逐客户回款、库存责任单元和截止日前硬授权；禁止用管理层归因、海外收入、价格或回报填补。验收是下一张可选择的现金卡在结果期先分解上述四种现金来源，再评价信用/渠道或管理动作。
