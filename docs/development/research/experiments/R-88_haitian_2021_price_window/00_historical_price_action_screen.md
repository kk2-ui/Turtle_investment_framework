# R-88｜海天味业 2021 调价：实际价格动作不能由跨越行动前后的全年表结算

状态：`HISTORICAL_TEACHING_SCREEN / NO_PRIMARY / NOT_FROZEN / NO_SELECTION_SCORE / OUTCOME_EXPOSED`。

本卡不评价海天味业、调味品行业或其证券。它只检验一个容易造成高估的判断：当公司在年末实际提价、又披露全年产品收入、成本、经销商预收款和经营现金时，研究者能否把这些合并成“定价权已经验证”。结论是**不能**。

本案的结果已经公开，故只可作为历史教学筛查，不是 Turtle 的盲测，也不计入选择准确率、校准、方法复制或公司结论。

## 1. 两份已阅读材料和时间边界

- [部分产品价格调整公告（2021-031，2021-10-13；公司公告原件镜像）](https://pdf.dfcfw.com/pdf/H2_AN202110121522215494_1.pdf?1634067245000.pdf=)：公司决定调高酱油、蚝油、酱料等部分产品的出厂价，主要产品幅度 `3%–7%`，新价格自 `2021-10-25` 实施。公告同时明确市场销售和未来业绩影响不确定（p.1）。
- [2021 年年度报告（公司官网）](https://static.haday.com/zh-cn/img/pdf/periodical-reports-download-report-2021.pdf)：结果期的公司官方年报，披露全年产品、销售模式、成本、合同负债、经营现金和集团资本资料（pp.15–19、144）。

`2021-10-25` 至年末最多只有 68 个日历日，约为全年 `18.6%`。这不是调价后销售、收入或现金的比例：经销商库存、订单、发货、回款和收入确认可能都使实际暴露更短或与日历时间不同。全年表中至少约 `81.4%` 的日历期在新价格生效前；因此不能把全年同比当作调价后的 outcome。

## 2. 可确认的 D1，与不可确认的 D2–D5

| 时钟 | 可读事实 | 不能结算的理由 |
|---|---|---|
| D1 决策／实施 | 部分产品的出厂价调整、品类范围、幅度和生效日均已明确。 | 公告未列 SKU、地区、经销商／零售终端 cohort、旧价与实际执行覆盖，也没有调价后可停止或回调的规则。D1 是一项真实但边界较粗的价格动作。 |
| D2 客户／竞争反应 | 年报有全年产品销量、地区和线上／线下销售模式；公告明确市场销售会受影响。 | 没有受调价 SKU 的经销商补货、终端 sell-out、消费者复购、渠道去库或竞争对手价格反应。全年销量也混入生效前绝大部分期间，不能说明客户接受或拒绝提价。 |
| D3 单位经济 | 年报的酱油、调味酱、蚝油收入分别为 `141.88`、`26.66`、`45.32` 亿元；相应毛利率同比变动为 `-4.47`、`-4.68`、`-0.75` 个百分点。产品直接材料成本全年分别同比 `+20.29%`、`+17.07%`、`+12.18%`。 | 收入、成本、销量和毛利均是全年累计值，不能拆出调价后量、实际实现价格／折扣、产品组合、渠道返点或调价后的原料／物流成本。毛利率下降不证明价格动作无效，也不能用收入增长证明价格权。 |
| D4 营运资本／现金 | 年末预收经销商货款约 `46.19` 亿元；全年经营活动现金净额 `63.24` 亿元，同比 `-9.02%`。 | 预收货款是全公司经销合同的客户现金，不是受调价产品或调价后订单的现金；集团 OCF 混合所有品类、渠道、采购、营运资本和时点。它不能被解释成经销商接受了本次提价，也不能被解释成提价失败。 |
| D5 资本回收 | 年报列有多项扩建、工艺优化等集团资本项目。 | 没有本次价格动作的增量资本、维护资本、渠道资本、替代用途或税后自由现金回收边界。提价本身不自动产生可计量的资本回收 verdict。 |

## 3. 为什么全年结果没有裁决力

```text
H-A：有限提价被渠道与终端吸收
部分 SKU 在 2021-10-25 实施新出厂价
  → 受影响经销商／终端维持采购、售出与复购
  → 调价后实现价格抵消部分同一产品的成本压力
  → 同一订单的库存、应收／预收与经营现金改善
  → 价格动作提高可回收的责任单元现金

H-B：库存、时点、成本和并行动作足以解释全年数
调价发生在年末，且只覆盖部分产品
  → 年度销量、收入和渠道现金主要来自生效前订单／库存
  → 原料、能源、运费、产品组合、地区和线上投入共同改变毛利
  → 经销商预收款和集团 OCF 仍是全公司交易点
  → 全年资本项目与价格动作没有可归属关系
```

两条机制都能容纳年报中的收入增长、销量增长、成本上升、毛利率下降、合同负债和 OCF。后者不是一个较悲观的措辞，而是同一份原件的计量边界。因此年报只能确认**存在成本压力和集团全年结果**，不能在 D2–D5 上支持任一条机制。

## 4. 准入裁决与下一轮约束

- **根因：** `DATA_COVERAGE + REASONING`。行动日期和全年聚合窗口不能对齐；更缺少受影响产品、渠道 cohort 和订单现金的共同交易点。
- **经济影响：** 把 `3%–7%` 的实际提价、全年收入或预收经销商货款写成价格权，会材料性高估正常盈利、现金转换和成本冲击下的竞争韧性；反过来把全年毛利率下降写成调价失败，也会错误低估管理动作。
- **禁止假设：** 日历期占比等于调价暴露；经销商预收等于终端接受；全年销量／收入／毛利率／OCF等于调价后价格—数量—成本桥；原料、能源、运费、产品创新、渠道裂变、地区和线上投入可以忽略；资本项目自然属于一次价格动作。
- **可执行处置：** 关闭 `R-88 / NO_PRIMARY / NOT_FROZEN`，不建 FJ、不登记结果合同、不计分。不要为证明结论继续追补更多全年叙事或第三方解读。
- **重新准入条件：** 只有在一手来源能把已调价的 SKU／渠道 cohort 的实际执行日、同口径调价前后价格与销量、同产品成本、订单现金以及价格动作的资本边界连成一条链，且能让 H-A/H-B/简单延续给出不同观察时，才以新 cutoff 建立 episode。

本卡将 R-86 的七项冻结字段具体收紧为一个执行要求：对价格、收费或信用条款动作，`baseline_metric_definition` 必须写出**生效日、实际暴露曲线和不可混入的行动前累计期**；`affected_customer_or_project_cohort` 必须区分出厂客户、渠道库存和终端客户；`unit_economics_bridge`、`cash_origin_bridge` 与 `capital_scope_and_alternative` 必须属于同一受影响交易链。它没有增加新的模板字段，只排除了用行动跨越期的全年合并表伪造 D2–D5 结算。
