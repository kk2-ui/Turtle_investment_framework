# R-52：隆基 2015–2016 单晶扩产——产品经济改善，不等于资本回收已成立

## 身份与范围

`RESULT_KNOWN_TEACHING / CHINA_MANUFACTURING_TECHNOLOGY_CAPACITY_BOUNDARY / PRODUCT_ECONOMICS_OBSERVED / CAPITAL_RECOVERY_UNKNOWN / NO_TURTLE_BACKTEST`

R-52 是对 R-25 的**状态边界复验**，不是“隆基扩产成功”的故事。R-25 的美的处在成熟空调的供给压力中：整机扩产被出货吸收，但部件收入/毛利承压，集团 OCF 也不能归给项目。本案换到技术路线转换和单晶产品有效供给偏紧的状态，检验同一条链是否仍需要逐段成立：当产品售价下跌时，真实的客户价值、成本下降和产能吸收能否留下产品级经营证据；即使可以，能否直接写成资本回收？

## 截止日前的状态、实际承诺与竞争机制

以 2016-03-25 披露的 [2015 年年度报告](https://money.finance.sina.com.cn/corp/view/vCB_AllBulletinDetail.php?id=2272228&stockid=601012) 为 cutoff。该报告原载上交所；这里使用可读取的原文镜像，不把镜像本身当作公司以外的独立证据。

当时可见的共同状态是：公司引述 2015 年中国新增光伏装机 15.13GW、同比增长逾 30%，并称高效单晶的替代优势正形成市场共识。它同时披露本公司已从硅片向组件与电站延伸，故后续集团结果不可能天然等于硅片扩产的结果。

实际资源承诺是可识别的：西安 1.15GW 切片、无锡 850MW 切片、银川 1.2GW 拉晶项目推进；2015 年末单晶硅片/组件产能分别为 5GW/1.5GW，管理层计划在 2016 年进一步升至 7.5GW/5GW。公司还设立硅片、乐叶光伏、隆基能源、乐叶能源四个事业部。2015 年报告称硅片非硅成本同比下降 20.78%、组件成本已与多晶基本持平，并记录了组件客户/订单，但这些都是发行人当时的披露，不能单独选择主路径。

| | H-A：技术成本与客户价值使扩产得到经营吸收 | H-B：行业/政策需求和同时向组件、电站延伸主导，扩产的独立经济性仍未被隔离 |
|---|---|---|
| 传导链 | 工艺降本/性能改善 → 客户采购与产品产销 → 硅片、组件的价格—成本经济性 → 营运资本与资本回收 | 市场增长/供给约束/业务组合 → 出货和收入；固定资产、应收与融资先扩大，集团结果不能识别扩产的增量回报 |
| 结果期应见的分叉 | 产品售价下行时，产品毛利和产销仍能维持/改善；但仍需现金与资本占用同步闭合。 | 即使销量和集团利润改善，也可能缺产品级价格/成本、客户可归属或项目现金；融资和营运资本可遮蔽回收。 |

本卡的 cutoff 前材料没有一项独立、非共同事实足以从 H-A/H-B 中选择“扩产本身”为主路径。因此它是结果已知的传导教学，不计作 Turtle 的前瞻选择或管理层总 verdict。

## 2016 年结果：先结算产品，再拆现金

[2016 年年度报告](https://static.cninfo.com.cn/finalpage/2017-03-11/1203150577.PDF)记录，年底单晶硅片价格较 2015 年底下降 14%、组件价格下降 35%；这排除了把结果简单归给名义售价上升。

在同一报告内，可读取的产品级观察是：

- 单晶硅片出货 15.18 亿片、产销率 106.71%；单晶组件出货 2,340.8MW、产销率 97.68%。硅片产量同比 +121.89%，组件产量同比 +178.67%；年底硅片/组件产能 7.5GW/5GW。
- 硅片收入同比 +98.45%、毛利率 28.16%，同比提高 6.63 个百分点；组件收入同比 +126.29%、毛利率 27.20%，同比提高 7.89 个百分点。公司同时披露硅片非硅成本同比下降 33.98%。
- 合并 OCF 为 5.36 亿元、同比 +46.96%，但净利润为 15.51 亿元；现金流调节表显示经营性应收项目增加占用 22.09 亿元，存货减少提供 3.00 亿元，经营性应付增加提供 2.39 亿元。同期购建固定资产、无形资产和其他长期资产支付 20.82 亿元，筹资现金净流入 50.01 亿元，原因含定增、公司债和长期借款。

这给出的是有限、分层的结算：

| 冻结箭头 | 结算 | 为什么 |
|---|---|---|
| 产能是否出现真实产品产出与销售 | `SUPPORTS_PRIMARY_FOR_OUTPUT_ABSORPTION` | 两个产品均有产量、出货/产销率与扩大的制造能力；这不是精确项目利用率，也不是单一基地的因果效应。 |
| 价格下行时是否仍出现产品经济改善 | `SUPPORTS_PRIMARY_FOR_PRODUCT_UNIT_ECONOMICS` | 硅片、组件收入和毛利率均提升，且公司披露成本下降；但产品组合、客户结构、行业供求和一体化同时变化，不能把全部改善归给某一扩产项目。 |
| 合并 OCF 是否证明新增产能已经形成 owner cash | `NOT_DIAGNOSTIC_AS_CAPACITY_OWNER_CASH` | OCF 为正但显著低于净利润，经营性应收大幅占用；存货与应付也共同改变。它不是项目/产品单元现金。 |
| 是否可判断扩产优于外购、慢扩或其他资本用途 | `CAPITAL_RECOVERY_UNKNOWN` | 缺项目资本、折旧、税、独立营运资本、可行替代和责任单元现金；大量外部融资进一步阻止把集团现金余额误作回收。 |

## 与 R-25 的边界：不是“扩产好/坏”，而是条件改变了哪一段

```text
R-25（成熟供给压力）：扩产 → 出货仍增；部件量增但收入/毛利承压；现金不可归因。
R-52（技术路线转换/有效供给偏紧）：扩产 → 产品产销与毛利改善；现金和资本回收仍不可归因。
```

两案共同否定两个偷懒结论：

1. `产能被出货吸收 = 增量资本回报成立`；
2. `价格下降 = 产品经济一定恶化`。

它们也不产生相反的万能规律。R-52 的改善与单晶技术成本、性能、客户采购、行业有效供给、向组件延伸和融资同时发生；这些是本案的条件，不是可移植的“扩产参数”。

## 对下一张产能卡的冻结前约束

同类决策必须在读取结果前分别登记：

```text
产品/技术的客户价值与外部状态
→ 实际产能或不可逆承诺
→ 产品级出货（不是集团收入）
→ 同产品价格、成本、毛利/单位经济
→ 应收、存货、应付、资本开支和外部融资
→ 项目/责任单元的资本回收
```

若只能读到前三项，最多结算经营吸收；若有产品毛利但无现金/资本，最多结算产品经济；没有替代路径与责任单元资本数据，永远不能评“企业家扩产决策正确”。

## 本轮结论

`RETAIN_AND_CONDITION / PRODUCT_ECONOMICS_CAN_IMPROVE_DURING_PRICE_DECLINE / CASH_AND_CAPITAL_REMAIN_SEPARATE`

根因：`REASONING + DATA_COVERAGE`。把高出货、上升毛利或正 OCF写成扩产成功，会材料性高估正常盈利的可持续性和资本回收；把光伏产品降价写成扩产失败，又会错过成本/性能—客户采用这一经营链。缺失的是基地/产品责任单元的资本占用、客户/产品价格、独立营运资本和替代路径。禁止用行业热度、公司战略叙述、集团利润/现金、后来规模、价格或回报补足。验收是在下一对象的 cutoff 前就冻结产品级产销、单位经济、四类现金来源和资本回收合同，并以不同主体复验这些条件；此前不报告扩产“方法胜率”。
