# R-56｜从混合结算到下一轮约束：学习边界

状态：`METHOD_LESSON_CANDIDATE / REPLICATION_REQUIRED / NOT_A_METHOD_WIN`。

## 这一次真正学到什么

R-56 没有证明“一体化扩产有效/无效”，也没有证明研究者判断更准。它只暴露了一个可迁移的研究错误：把企业系统中不同层的改善，压缩成一个公司“经营变好”的结论。

FY2010 同时出现了产能实施、模块销量增大和正 OCF；但产品价格下降、AR/库存/预付占用现金、客户预收/AP/其他应付提供反向作用，且没有产品级成本或责任单元回报。这种组合若没有 D1–D5 时钟，最容易被误写成“规模成功”或“融资依赖失败”。

## 下一轮必须实际改变的冻结字段

下一张扩产相关案例若声称是 R-56 的 replication，必须在读取结果前把下列约束写入其结果合同；只写“更关注现金”不算应用。

| R-56 暴露的缺口 | 下一张卡的冻结前强制改变 | 未满足时的动作 |
|---|---|---|
| 下游销量可能只是内部转移 | D2 必须标明 external sell-out、客户交付或内部工序转移的可辨识字段；若披露没有该边界，D2 预先标为 `NOT_DIAGNOSTIC`。 | 不能用销量/收入裁决客户吸收。 |
| 合并毛利不能代表产品经济 | D3 预先列出同产品收入、成本或毛利的官方字段；没有就明示 `PRODUCT_ECONOMICS_UNKNOWN`。 | 不得用合并 margin 或行业 ASP 代替。 |
| OCF 可由多个流动资产/负债项共同形成 | D4 必须逐项列 AR、库存、预付、客户预收、AP、其他应付以及非现金项；局部箭头与总 OCF 必须分开结算。 | `MIXED` 保留，不能强选机制。 |
| 资本投入与融资并存不等于回报 | D5 必须有责任单元资本、税后现金结果和替代路径；否则预先声明 `CAPITAL_RETURN_UNKNOWN`。 | 不评价资本配置优劣。 |

## 可审计的应用门

这不是已有正式 LNOTE 的应用：R-56 是 archived external、`NO_PRIMARY`，且尚没有不同公司的 target episode。只有一个不同公司、预冻结地写入上表四项变化、并由独立 reviewer 核对其实际字段与 locator 后，才可登记为 `R-56-LEARNING-APPLICATION`。该 replication 的结果即使再度 `MIXED` 或 `MEASUREMENT_MISMATCH`，也仍是有效方法反馈；不能用价格、终局规模或作者信心关闭学习。

根因分类：`REASONING + MODEL`。修复不是增加一堆报告或新评分，而是让下一次选择和结果合同在阅读前真的发生变化。经济影响是避免将一段规模增长误判为正常盈利、owner cash 或资本回报，从而错误评估永久损失。
