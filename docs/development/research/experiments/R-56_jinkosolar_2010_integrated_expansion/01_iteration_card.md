# R-56｜2010 晶科一体化扩产的企业系统判断微演练：迭代卡

状态：`SCOPED_EXPERIMENT / ARCHIVED_EX_ANTE_EXTERNAL / OUTCOME_UNREAD / NOT_FROZEN_AS_SELECTION`。

## 方法假设

- 反馈等级：`ARCHIVED_EX_ANTE_EXTERNAL`。本次只表示研究者在冻结前未读取 FY2010 的业绩正文；不表示 Turtle 当时作过真实预测，也不计入准确率或概率校准。
- 当前盲点：把制造业扩产写成“规模、出货或融资是否增加”的单点故事，遗漏客户—价格/成本—营运资本—外部融资的先后关系；尤其容易把 IPO 后的现金余额误作经营自立。
- 本轮步骤：应用 P-102 的条件化扩产骨架，将一项资源承诺拆成 `客户/需求状态 → 实施 → 产品交付 → 单位经济 → 营运资本/现金 → 资本吸收` 六层；任何一层不可重建均不得由相邻层替代。
- 训练能力：`问题界定 / 机制辨别 / 测量辨别`。
- 最高可声称等级：`L2 单箭头诊断性`。本轮明确**不能**声称 L3 主路径选择、管理层总能力、资本回报、方法胜率、估值、价格或回报。
- 预期避免的经济错误：将产品需求回升、产能建成、融资成功或合并收入增长误读为一体化扩产已经形成正常 owner cash 或资本回收。
- 经济边界：`正常盈利 / 现金转换 / 资本配置 / 永久损失`。

## 有界实验

- 对象：JinkoSolar Holding Co., Ltd.；2010-05-13 IPO 前的垂直一体化产能扩张。
- 决定性问题：面对已出现的应收—客户预收—资本支出压力，新增硅料/硅片/电池片/组件能力会先形成可自我供血的产品经济，还是继续依赖营运资本与外部融资？
- 允许的 cutoff 前材料：唯一已读一手来源为 [2010-05-13 Form 424B4](https://www.sec.gov/Archives/edgar/data/1481513/000119312510120053/d424b4.htm)。它显示：截至 2009-12-31 有 440 多个客户；计划在 2010 年末把 wafer/module 提至约 500MW、cell 提至约 400MW；预计以约 4,500 万美元 IPO 净募资扩张全链产能；2009 OCF 为负，且公司将其主要归为应收增加和第三方客户预收减少。精确 locator 见[候选筛选](00_archived_pre_outcome_candidate_screen.md)。
- 结果防火墙：FY2010 Form 20-F（filed 2011-04-25）只以 filing identity 登记；尚未打开其正文、XBRL、新闻、二手摘要、价格或后续年度材料。
- 明确不研究：IPO 定价、股票表现、光伏行业终局、公司长期优劣，或将全公司融资能力写成项目资本回报。
- 公平的旧方法对照：只用“危机后需求恢复 + 客户数多 + 获得 IPO 融资”推断扩产成功。该对照公平，因为它只使用同一 cutoff 前常见事实；它也正是本轮要拒绝的规模叙事。

## 假设空间与退出

| 解释 | 会位移什么经济判断 | 当前处理 |
|---|---|---|
| H-A：一体化、回收硅料和客户覆盖使产能逐渐自我供血 | 产品交付后，价格承压下的成本/毛利与现金转换共同改善。 | 保留为竞争机制。 |
| H-B：信用与资本占用先于经济吸收 | 产能和客户数可增长，但 AR、客户预收、库存和 CAPEX 先使外部资金继续填补缺口。 | 保留为竞争机制。 |
| H-C：复苏/补贴推动的需求吸收 | 出货甚至毛利改善可主要来自行业需求/政策，而非 H-A 的一体化经济；它会削弱把经营结果归给扩产的能力。 | 保留为 material third mechanism；因此本案不得进入 `JUDGMENT_SELECTION_EPISODE`。 |

退出条件：

1. FY2010 结果无法以同一合并口径重建 OCF、第三方客户预收、AR 和至少一个产品产能/交付字段；
2. H-C 仍能同样解释所有可获得的结果，无法把一个观察收窄到具体箭头；
3. 结果期定义变化使 2009 与 2010 不可比；
4. 只能看到集团融资与资产增长，不能看到责任单元资本回收。

发生任一项即关闭为 `MEASUREMENT_MISMATCH / NOT_DIAGNOSTIC / CAPITAL_RETURN_UNKNOWN`，不补读更多结果期材料来修故事。
