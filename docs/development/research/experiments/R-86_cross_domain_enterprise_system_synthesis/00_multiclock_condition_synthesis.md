# R-86｜跨域企业系统复盘：同一条飞轮，五种状态，五个不同的断点

状态：`RESULT_KNOWN_TEACHING / MULTI_DOMAIN_SYSTEM_SYNTHESIS / NO_SELECTION_SCORE / NO_METHOD_WIN_RATE`。

本卡不是新公司报告，也不是把宇通、长城、美的—库卡、隆基和丰田排成优劣顺序。它是一次**跨状态复盘**：将五个已经独立记录的既知结果教学对象放到同一条 D1–D5 飞轮中，检查哪些判断可以迁移，哪些只能留在行业／时期条件内。

来源对象：

- [R-43 宇通 2014 新能源客车](../R-43_yutong_2014_new_energy_bus/00_2014_policy_demand_product_economics_teaching.md)
- [R-50 长城—哈弗 2013–2014](../R-50_great_wall_haval_2013_brand_focus/00_2013_2014_brand_product_cash_teaching.md)
- [R-52 隆基 2015–2016 单晶扩产](../R-52_longi_2015_capacity_customer_cash_teaching/00_2015_2016_monocrystalline_capacity_teaching.md)
- [R-46 美的—库卡 2016–2017](../R-46_midea_kuka_2017_controlled_entity/00_2016_2017_controlled_entity_teaching.md)
- [R-85 丰田 2010 质量应对](../R-85_toyota_quality_response_20100217/00_historical_teaching_admission_screen.md)

这些对象的结果已知，所以本卡只训练机制识别、证据边界和下一轮研究行为；它不能证明选择能力、管理层胜率或任何投资回报。

## 1. 先保持同一飞轮，再承认状态不同

```text
当时的客户／竞争／制度约束
  → D1 管理层实际资源动作、责任与停止权
  → D2 客户、经销商、项目、供应商和竞争者实际反应
  → D3 量 × 价格／组合 × 制造／履约／服务成本
  → D4 应收、存货、预付、应付、准备金与外部融资的现金转换
  → D5 责任单元增量资本、替代路径与资本回收
  ↺ 现金与客户反馈改变下一次 D1
```

跨域比较的目的不是要求五个行业披露同一种 KPI，而是要求每个 KPI 回答同一个问题：**它位于哪一箭、属于哪个责任单元、相对哪条反方具有诊断性？**

## 2. 五个对象的可见层与断点

| 对象／状态 | D1 实际动作 | D2 能观察到什么 | D3 单位经济 | D4 现金转换 | D5 资本回收 | 可迁移的最小教训 |
|---|---|---|---|---|---|---|
| 宇通：政策驱动新能源客车 | 新能源公交推广、研发不同运营场景产品 | 新能源销量增长，但政策／采购与产品能力共同作用 | 超出标准质保期的电池、电机、电控服务费增加，产品级价格成本桥不足 | 新能源责任单元回款与营运资本不足 | 资本占用和回收未知 | **订单或政策资格只是 D2 入口；生命周期服务负担必须跟着交付结算。** |
| 长城—哈弗：品牌与品类聚焦 | 哈弗独立品牌、网络调整、SUV 产品升级并行 | SUV 与车型销量增长，品类景气、既有 H6 和新车型也同时存在 | 业务单元价格、折扣、渠道成本未单独闭合 | 集团 OCF 受存货、应收、应付共同影响 | 品牌聚焦资本范围未知 | **产品／品类结果不能自动归因于品牌组织动作；现金来源先于品牌判断。** |
| 隆基：技术路线与扩产 | 硅片／组件扩产、工艺降本、事业部和下游延伸 | 产品产销与产能扩大 | 价格下降时硅片／组件毛利率提高，支持产品经济但不是项目回报 | 应收占用、存货／应付与融资共同变化 | 项目现金和替代路径未知 | **价格方向没有单独 verdict；产品经济改善仍不等于资本回收。** |
| 美的—库卡：控制权与整合 | 取得控制、上海／顺德能力规划，库卡保留自身管理 | 目标实体收入增长，但全球自动化周期和既有订单共同存在 | EBIT／利润率受欧洲产能瓶颈影响，直接关联交易很小 | 目标实体 OCF 改善但 FCF 变弱，贸易营运资本与投资现金混合 | 收购资本回报未知 | **控制权和实体报表是必要边界，不是协同归因的充分条件。** |
| 丰田：召回与质量治理 package | 技术修复、经销商维修、区域质量官、全球质量委员会和反馈流程同时实施 | 没有受影响／已修复客户 cohort；后续销量受车型、激励、汇率、地震供应链混合 | 召回／安全措施成本与保修成本可见，但无法拆出二月 package | 没有质量 package 责任单元现金桥 | 质量治理没有独立资本边界 | **行动明确、结果已知，仍可能因为 bundle 与外部冲击不可分而不能归因。** |

五案的共同结果不是“战略都不可信”，而是：D1 越复杂，越需要在冻结时先写清责任单元和断点；后续漂亮数字不能反向修补缺失的 D2–D5。

## 3. 哪些规律可以迁移，哪些不能

### 3.1 可以迁移的判断纪律

1. **先找实际权利，再找结果。** 品牌独立、收购控制、召回委员会、产能投资或政策资格，只有在明确谁能决定资源、影响哪个客户／项目、何时可以停止时，才是 D1；公告、计划和“抓住机会”不是实施本身。
2. **D2 必须是外部主体的行为。** 出货、收入、销量或公司声称的市场认可不能替代客户、经销商、运营方或竞争者的可定位反应。政策采购和召回维修尤其容易把管理目标误写成客户反应。
3. **D3 要保留量、价／组合、成本和服务负担。** 价格下行可以与成本下降共存；销量增长可以与毛利下降共存；服务准备增加可以是交付责任扩大，也可以是质量风险。单点毛利或单点销量不能判整个经营机器。
4. **D4 必须说明现金从哪里来。** OCF 转正可能来自存货释放、应付增加、处置、外部融资或季节时点；集团现金不能代表产品、品牌、目标实体或召回 package 的 owner cash。
5. **D5 是最严格的出口。** 只有资本责任单元、税后现金结果、替代用途和退出／再投资权都可见，才可谈资本回收；其余结论必须停在 `CAPITAL_RETURN_UNKNOWN`。

### 3.2 不能迁移的表面相似

| 表面相似 | 不能直接迁移的原因 |
|---|---|
| 都是“扩张／资源投入” | 隆基的技术路线转换与美的成熟供给压力，客户价值和价格—成本状态不同；同一出货增长的含义不同。 |
| 都是“聚焦／组织重构” | 哈弗品牌独立、库卡控制权和丰田质量委员会的作用对象分别是客户选择、目标实体治理和安全责任；不能用后来规模统一证明。 |
| 都有“客户／市场接受”叙事 | 宇通的政策采购、长城的 SUV 品类和丰田的车主信心不是同一 cohort，也没有相同结果定义。 |
| 都有“现金改善或成本变化” | 宇通服务准备、美的—库卡贸易营运资本、隆基融资和丰田召回成本属于不同责任单元；不能互相补洞。 |
| 都是中国／日本制造龙头 | 国家、制度、渠道、产品生命周期和外部冲击不同；公司名气与后续存续不是边界条件。 |

## 4. 这次复盘对“判断力”的具体贡献

判断力不是在五案结尾给出五个成功／失败标签，而是能在结果前回答四个更窄的问题：

```text
这项动作改变了谁的约束？
谁的行为会先变？
哪一项价格／成本／服务负担会随之分叉？
现金和资本在同一责任单元里何时、以什么来源到达？
```

若第四问不能回答，前三问即使有部分事实，也不能升级为长期经济判断。反过来，若只有 D4 变化，也不能倒推 D1 正确；必须回到箭头序列。

## 5. 写入下一张不同公司的冻结字段

这不是新增框架，而是对已有 R-25/R-52 对比、R-71 多层合成和 R-85 bundle 约束的**实际应用收据**。下一张不同公司卡在读结果前必须新增或明确冻结以下字段：

| 冻结字段 | 本次复盘修正了什么 | 缺失时的处置 |
|---|---|---|
| `action_bundle_components`：每个并行动作、日期、责任人、资源和停止权 | 丰田、长城和宇通的多个动作不能被压成一个“战略” | `BUNDLE_NOT_SEPARABLE`；不做动作归因 |
| `affected_customer_or_project_cohort`：客户／项目范围、状态和外部行为 | 政策销量、SUV 增长和召回目标不是客户反应 | D2=`NOT_DIAGNOSTIC` |
| `baseline_metric_definition`：行业／同品类／未受影响 cohort 的同口径定义 | 没有公平基线就不能把延续、行业共同变化和行动影响分开 | 不选择主路径 |
| `unit_economics_bridge`：量、价、组合、制造／服务成本、质保／返利 | 价格下降、毛利改善和服务准备都可能有相反解释 | D3 只结算已识别箭头 |
| `cash_origin_bridge`：AR、库存、预付、AP、准备金、处置、融资 | OCF 是结果，不是现金来源 | D4=`CASH_ORIGIN_UNKNOWN` |
| `capital_scope_and_alternative`：责任单元资本、替代用途、退出权、回收期 | 集团现金、收购价和固定资产余额不能代表资本回收 | D5=`CAPITAL_RETURN_UNKNOWN` |
| `external_shock_and_confounder_calendar`：政策、地震、汇率、周期、同时推出事项 | 结果期冲击不能事后归给管理动作 | 冲击覆盖窗口的结算降级为 `MIXED/NOT_DIAGNOSTIC` |

合格的前瞻选择案例还要额外满足：至少一项 cutoff 前的非共同事实，对主机制、最强反方和简单延续基线导出不同的同口径未来观察。R-43、R-50、R-52、R-46、R-85 都没有满足这项准入，因此本卡不把它们伪装成选择判断训练。

## 6. 方法复盘与停止条件

- **方法结论：** `RETAIN_AND_NARROW`。D1–D5 多层时钟和状态条件比较值得保留；它提升的是“知道哪里不能下结论”的能力，以及在下一家公司更早定位缺失箭头的能力，不是产生一个万能评分。
- **根因：** `REASONING + DATA_COVERAGE`。旧的单案例阅读容易把跨层事实串成一个故事；跨域比较暴露了状态、责任单元和外部冲击的边界。
- **经济影响：** 若忽略这些边界，会把政策销量、品牌成长、产品毛利、实体收入、召回成本或 OCF 错写成长期经营质量，材料性高估正常盈利、owner cash 与资本回收，或错判永久损失。
- **禁止假设：** 不以结果已知、品牌／公司名气、市场份额、价格、短期业绩、集团 OCF 或案例数量衡量飞轮有效性；不把五案组成统计样本。
- **停止条件：** 本卡完成后不再为这五家公司追加材料。下一步只能做一张不同公司的 pre-outcome screen，且先检查本节七个冻结字段；任一缺失就关闭为 `NO_PRIMARY`，不以更多报告补洞。

## 7. 验证方法：真正检查行为是否改变

本卡的训练干预尚未活测。下一不同公司应保留两个案前版本：

- **基线版：** 只按目标公司原始材料写 H-A/H-B；
- **条件比较版：** 在不读取结果的前提下，使用本卡七个冻结字段和 R-25/R-52 的产品经济约束。

结果期比较的不是篇幅或叙事评分，而是：

1. 条件比较版是否更早识别 `BUNDLE_NOT_SEPARABLE`、D2 cohort 缺失或 D4 现金来源混合；
2. 它是否提出了一个基线版没有的、可机械结算的同口径观察；
3. 当证据不足时，它是否更早保留 `UNKNOWN`，而不是借集团数字填充；
4. 若出现真实方向性分叉，是否能把分叉定位到 D1→D2→D3→D4 的某一箭，而不是把全局结果归给一项决策。

只有在不同公司上完成一次这样的案前行为比较和结果复盘，才可写 learning note；本卡自身不证明训练方法有效。

## 8. 结论

五个跨域对象共同支持一个谨慎但可操作的第一性原理：**长期企业能力不是“做过正确战略”，而是把客户约束转成可停止的资源动作，并让外部交易、单位经济、现金和资本回收按顺序反馈回来。**

这个定义既能容纳政策、品牌、技术、并购和质量危机，也解释为什么同一家公司会在一层做对、另一层做错。它不替代逐案研究；它把下一案的起点从“公司故事”改成“哪条传导链已经有事实、哪条仍是 UNKNOWN”。
