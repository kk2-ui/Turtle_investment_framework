# R-92｜聚胶股份 2024 年墨西哥暂停与马来西亚新建：同日公告不等于可归责的资本迁移

状态：`HISTORICAL_TEACHING_SCREEN / NO_PRIMARY / NOT_FROZEN / NO_SELECTION_SCORE / OUTCOME_EXPOSED`。

R-92 检验一个看似完整、但很容易被叙事拼接放大的资本配置事件：公司同日公告暂停墨西哥卫材热熔胶生产基地，并批准建设马来西亚基地。两项决定都是真实的董事会和股东会行动，却不能仅凭同日性被写成“避开贸易风险、将客户和资本成功转移到马来西亚”的企业判断。

本卡不评价聚胶股份、管理层、海外建厂、贸易政策或证券。它只训练一项可迁移的边界：停止一项资本承诺、批准另一项资本承诺和后来发生生产认证，须在资金、客户、单位经济、现金和资本回收五个层次逐一连通，才可能成为同一项选择的经济后果。

## 2. D1 确实发生了什么

2024-08-28，董事会和监事会审议暂停墨西哥生产基地项目；该项目原定首期总投资 `20,105.00` 万元，其中超募资金 `17,321.00` 万元、自有资金 `2,784.00` 万元。暂停公告同时明确，截至披露日尚未开设项目募集资金专户，亦未实际使用超募资金投入墨西哥；原计划的 `17,321.00` 万元继续留在超募资金账户，未来只有在新项目或资金支付需要时，另行申请并履行审议程序。

同日的另一项议案批准马来西亚卫材热熔胶基地，预计总投资 `10,616.84` 万元，其中超募资金 `9,544.08` 万元、自有资金 `1,072.76` 万元；项目设计产能为 `6` 万吨/年，预计建设期 `11` 个月。项目原件将这笔资金列为独立的新项目授权，且称具体增资和借款金额由管理层后续按当地资本金规则、战略规划和业务需要决定。

因此，D1 可以写为两项有范围、金额和批准程序的资本动作：一项未开始的墨西哥承诺被暂停，一项马来西亚项目获批。不能写为资金、客户或生产已经从墨西哥转移到马来西亚：两份原件没有声明马来西亚的 `9,544.08` 万元来自被暂停项目的 `17,321.00` 万元，也没有给出项目、客户或资产的交接清单。

## 4. 为什么不能建立选择判断

```text
H-A：暂停墨西哥并建设马来西亚，使公司避开贸易风险并以更接近客户的基地取得更好经济性
墨西哥项目暂停 + 马来西亚项目建设
  -> 被定义的客户/产品从原供货路径迁移并完成认证
  -> 同一订单的价格、成本、物流和关税改善
  -> 订单现金减去营运资本和基地资本开支后实现回收

H-B：两个独立资本决定均受共同的贸易、市场与公司规划不确定性约束
地缘政治、关税/贸易壁垒、市场需求和海外开拓
  -> 客户、订单和基地利用率可以变化，且不由“墨西哥改马来西亚”唯一解释
  -> 项目测算、集团结果或后续认证无法分配到两项决定之间
  -> 暂未投入的资本与新基地资本各自仍需独立结算
```

cutoff 前只有 H-A 的管理层愿景和 H-B 也可容纳的共同外部状态；没有一项 `ASYMMETRIC` 或 `RIVAL_ACCOMMODATION_REQUIRED` 的 D1→D2 事实。H-A、H-B 和“保留现金、以后再评估”的简单基线，也没有针对同一客户/产品/责任单元 D2-D4 观察给出可机械结算的不同预测。因此研究者不能把项目金额、同日公告或后续任何集团表现升级为选择依据。

## 5. 裁决、停止条件与迁移约束

- **根因：** `REASONING + DATA_COVERAGE`。行动与金额已可确认；缺失的是把两项资本决议变成一个经济责任单元的资金、客户和结果链，而不是更多关于海外市场或管理层战略的文字。
- **经济影响：** 若误称为地理产能成功转移，会材料性高估贸易风险规避、客户吸收、现金转换和项目资本回收，也会掩盖未投墨西哥资本与马来西亚新资本分别承担的永久损失风险。
- **缺失事实：** 项目间资金/资产/人员交接；受影响客户和产品 cohort、认证与订单；同单元量价成本费用；订单到现金桥；已投资本、替代用途、重启/退出规则与税后回收。
- **禁止假设：** 同日董事会决议、同日股东会批准、未投专户余额、海外收入占比、设计产能、项目测算、预计回收期、预测 ROI、后续工厂进度、集团业绩、价格或回报能够证明资本已迁移或 H-A 成立。
- **可执行处置：** 关闭 `R-92 / NO_PRIMARY / NOT_FROZEN`；不建立 future judgment、简单基线、结果合同、选择评分或学习复制。它只作为“资本地理替代必须先证明迁移接口”的教学边界。
- **接纳标准：** 另一个不同公司的真实选择 episode，必须在结果前同时冻结：可执行的停止/重启权、源地和目标地的资金与责任单元映射、具名客户/产品/订单或认证 cohort、同口径 D3-D4 和 D5 资本合同，以及 H-A/H-B/简单基线的不同预测。缺一项即不得把两个资本动作称为替代配置。
