# R-37｜1984–1992 冰箱竞争：质量、服务与产品状态的教学筛查

状态：`RESULT_KNOWN_TEACHING / STATE_REPERTOIRE / NO_TURTLE_BACKTEST / NO_SURVIVOR_VERDICT`

## 这轮训练的问题

中国早期家电竞争常被讲成“最后活下来的公司重视质量和服务”。这不是一个可用结论：它把不同品类、阶段、产权边界和后来结果混成一种管理美德。本筛查只问一个更窄的问题：

```text
在供不应求、产能快速扩张、随后转向买方市场的冰箱状态中，
管理层为了质量、技术吸收或维修能力而主动放弃当期产量/利润时，
这些投入还必须通过什么中间环节，才可能成为长期经济能力？
```

这是一张结果已知的教学卡。它训练“从真实管理选择中拆机制与边界”，**不**用于声称 Turtle 当时预测了哪家公司，也不回答哪几家“活了下来”。

## 当时状态，而不是公司排名

中国家用电器协会对 1980 年代的概述表明，行业当时以引进先进技术和装备、建设整机与零部件厂为主；冰箱压缩机项目亦被列入重点建设。这只是状态背景，不能代替公司事实。[中国家用电器协会](https://www.cheaa.org/contents/116/8685.html)

本轮三个公司材料指向同一状态张力：短期产量和已有设备可带来即时利益；但随着竞争、产品状态和已有存量用户变化，质量、维修、产品功能与渠道服务开始成为约束。三者不是同口径的对照组，更不是 near-miss；各自只提供一个不同的管理选择切片。

## 训练出的机制，而不是“质量为王”

```text
技术/质量/服务资源承诺
  → 可验证的可靠性或维修响应
  → 同一客户或渠道的选择、价格/留存/销售质量
  → 同一产品的服务成本、营运资本和现金转换
  → 在产品组合仍匹配新市场状态时，才可能形成持续经济后果
```

其中最后一条是 R-37 新增的边界：`reliability/service capability` 与 `product-market-state fit` 不是同一变量。后者变化时，即使前者存在，企业仍可能必须改变产品、价格或组织；相反，产品短期热销也不能说明服务/可靠性已改善。

## 两种竞争解释及当前可用性

| 解释 | 可观察的后续序列 | R-37 当前能否结算 |
|---|---|---|
| H-A：质量/服务投入形成可持续经营优势 | 故障/维修响应改善先出现，随后同产品客户/渠道选择、价格实现或留存改善；服务成本受控，现金不靠应付或一次性释放。 | 否。现有材料没有同一产品的故障、客户选择、服务成本和现金连续口径。 |
| H-B：卖方市场中的质量/服务投入不足以抵抗产品/结构变化 | 产品滞销、功能/价格/渠道变动先成为主要约束；企业仍需产品组合或组织重置，且质量服务观察无法解释现金。 | 仅有与此相容的状态信号，不能裁决。1992 的改组与产品调整不能倒推 1987 选择无效。 |

故本卡固定为 `NOT_DIAGNOSTIC_ON_H-A_H-B`。教学价值在于拒绝把“正确方向的管理选择”误记为“已验证的长期经营判断”。

## 对下一张合格卡的资料要求

1. **技术吸收路径**：行动当期的合同/董事会/厂志原件，以及至少两个后续、同主体的质量或生产效率观察；设备、标准、培训与持续技术支持必须分开定位。
2. **服务路径**：同产品的故障/返修、维修时效或每台服务成本，外加客户/渠道选择或价格实现；服务网点、奖项和单封表扬信不替代这些指标。
3. **产品状态路径**：产品/容量/价格/渠道的同口径变化，避免把产品滞销误当成服务失效，也避免把服务投入误当成产品适配。
4. **现金路径**：同一责任单元的营运资本、服务支出和资本投入；不得以总公司 OCF、销量、产值、排名、股价或后来存续替代。

满足前述四项中的任一完整链条，才可新建 `OUTCOME_CONTRACTED_EPISODE`。否则本轮在此停止，不继续补写公司史。

## 本轮结论

`RETAIN_AS_STATE_REPERTOIRE / QUALITY_AND_SERVICE_ARE_COMPLEMENTS_NOT_VERDICTS / NEXT_CASE_REQUIRES_PRODUCT_AND_CASH_BRIDGES`。

根因：`DATA_COVERAGE + REASONING`。若把真实的停产、维修投入和技术吸收直接写成“质量护城河”或“幸存者能力”，会把产品状态、客户选择和现金转换遗漏掉，进而错误推断正常盈利、资本回报和永久损失。缺失事实是同产品的可靠性—服务成本—客户选择—现金连续链。禁止用后来品牌、总产值、短期销售、媒体赞誉、股价或企业存续补足。验收标准是下一候选在结果前已定位上述同口径指标与原始来源；缺失则仍为教学筛查。
