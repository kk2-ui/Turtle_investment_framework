# R-68｜应流股份 2025–2026 核能材料扩产：实施与需求已可见，仍不足以选择主路径

状态：`PRE_OUTCOME_SCREEN / NO_PRIMARY / NOT_FROZEN`。

R-68 是对 R-67 停止条件的压力测试：若扩产不止有授权，而已有实际资金投入、既有客户导入、产品级量价成本和在手订单，它是否已经可以成为一个“客户驱动扩产”选择判断？答案仍是否定的，但缺口已经收窄到一个可复用的计量问题：**必须把已签订单按交付时点对应到旧产能和新增产能；不能用“在手及预计订单”的混合量替代。**

这不是对应流股份、证券价格、估值、回报或管理层能力的结论。它也不否定项目可行性，只拒绝在截止日前把尚未分离的订单、排产和现金结果强行选为主路径。

## 3. 为什么看似最强的“79.51% 覆盖率”不能成为选择依据

R-67 之后的筛选要求是：D1 已实际进入运营接口，同时在 cutoff 前有客户的非共同方向性反应。R-68 确实跨过了前半段，也拥有比一般扩产公告强得多的 D2 和 D3 资料；但它仍缺关键的**增量**连接。

| 可见事实 | 可以支持什么 | 不能支持什么 |
|---|---|---|
| 2024 年利用率 98.38%，当前在手订单 2,249 吨 | 企业已在既有产能上有真实客户/产品活动，不能把项目写成纯绿地故事。 | 没有订单交期，不能判断这些订单是否只需未来数年的原有 765 吨产能。 |
| 2027 年“订单覆盖率” 79.51% | 它是公司对项目潜在产能吸收的情景说明。 | 分子 4,867 吨明确包括 2,249 吨在手订单和 2,618 吨“新取得未录入系统订单以及预计取得的重大客户示范订单”。因此它不是 2027 年 firm-order coverage，更不能反向用来选择 H-A。 |
| 已进入三大核电客户供应链、向多个核电项目供货 | 客户准入、产品资格和历史交付是真实 D2 基础。 | 客户准入并不指向新增产线的排产、数量、价格、账期或现金；H-A/H-B 都可以容纳该事实。 |

可以写出两条机制，却无法在 cutoff 前公平选边：

| 候选机制 | 对已知事实的解释 | 为什么未获主路径资格 |
|---|---|---|
| H-A：客户约束驱动的扩产 | 既有认证、接近满产、实际在手订单和 D1 已投入资本，意味着新增智能产能将被已验证的客户需求吸收，再依次显现在目标产品的交付、单位经济和现金上。 | 一旦剔除 2,618 吨预计订单，公开材料没有给 firm orders 的交付年表；因而不能证明旧产能无法承接，或未来新增产能已获客户承诺。 |
| H-B：核电项目时点与现金约束使“订单量”不能等于新增产能回收 | 已有订单/认证可反映当前项目周期和原有能力；重大工程统筹交付、长生产周期、国央企审批回款和三主体分工，可能使新增设备的交付、价格与现金晚于或弱于项目模型。 | 这不是“核能客户不存在”的断言，也不把资本投入本身当作失败。它只指出当前材料不能把历史客户链升级为新增容量的经济回收。 |

公平基线是：**仅承认 2,249 吨在手订单、765 吨既有年产能和已经实现的产品单位经济；不把预计订单、模型收入/IRR或未披露的排产归给新增产能。**在该基线下，H-A 与 H-B 的不同结果仍是未来才会发生的现象，缺少 cutoff 前的非共同方向性事实，故不能选择 H-A。

## 4. 本轮应用的飞轮约束与新停止条件

R-64/R-65 要求把组织/资本行动和客户—现金传导拆开；R-66 要求五类数据不是并列存在而是同一链条；R-67 要求扩产先跨过实际 D1 和项目专属 D2。R-68 在这些约束下不再停在“项目尚在筹备”，而是进一步暴露一个真正可迁移的缺口：

> 对扩产的选择判断，必须有截止日前、按**firm / estimated**拆分并按交付窗口映射的目标产品订单；只有其中的 firm 部分在预定窗口实质超出旧产能，或客户明确为新增产线承诺数量，才是 H-A 与 H-B 的非共同方向性证据。

这条约束已经改变下一家公司读取的冻结前字段：`firm_order_definition`、`delivery_window`、`existing_capacity_allocation`、`incremental_capacity_allocation`、`customer/project locator` 必须同时存在。没有它们，即使 D1、客户认证、产品毛利和集团现金资料都很丰富，也停在 `NO_PRIMARY`。

## 5. 结论与处置

- 根因：`DATA_COVERAGE + REASONING`，不是报告数量或写作问题。
- 经济影响：若把混合订单覆盖率升级为选择依据，会将当前客户资格、估计订单、计划产能与未来现金混为一个机制，材料性高估正常盈利、项目现金转换和资本回收，或在反方向上把建设期现金占用误判为客户需求不存在。
- 缺失事实：在手订单的 firm 定义和逐年交付安排、其对应的旧/新增产能、针对新增产线的客户数量/价格/账期；随后才是三主体的产品现金桥和项目自由现金。
- 禁止假设：
  - “在手及预计订单”或 79.51% 是 firm 的 2027 年 coverage；
  - 现有客户准入、98.38%利用率或实际 D1 投入自动证明新增产能有客户承诺；
  - 项目模型 29.08%毛利、17.87%IRR 或 6.77 年回收期是实际经济结果；
  - 合并应收、存货、OCF、现金或借款能替代三主体/目标产品的现金转换；
  - 后续交付结果可以倒灌为 cutoff 前的选择理由。
- 可执行处置：关闭 `R-68 / NO_PRIMARY / NOT_FROZEN`。它不进入选择判断的 calibration、回测或 learning 胜负统计；其 source package 可作为未来验证“firm-order-to-capacity mapping”资料是否首次出现的参考，但不能靠继续读更多同类文件而重开。

R-68 的价值不是为扩产下结论，而是把下一轮的准入门从“有项目、有客户、有订单”提高为“已实施项目与**时间对齐的 firm 增量客户承诺**相连接”。
