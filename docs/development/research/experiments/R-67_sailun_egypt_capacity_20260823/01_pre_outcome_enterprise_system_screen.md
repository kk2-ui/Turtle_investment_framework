# R-67｜赛轮轮胎 2026 埃及扩产：资本授权不是经营选择样本

状态：`PRE_OUTCOME_SCREEN / NO_PRIMARY / NOT_FROZEN`。

## 3. 为什么不能选择“海外本地化已成立”或“资本追逐过度”

这两条机制可被正确写出，却不能从当前资料中选边：

| 候选机制 | 当前可见基础 | 选择门为何未通过 |
|---|---|---|
| H-A：当地化网络已经将客户需求转成可复制的资本回收 | 公司有既有海外网络、海外车企项目定点/批量供货、全球渠道及正的集团经营现金；项目声称可改善交付、物流和贸易壁垒应对。 | 对埃及项目而言，客户事实没有指向工厂/产品/订单，所有经济效果仍是公司推演；H-B 无须放弃任何已确认的埃及机制箭头便能容纳这些资料。 |
| H-B：对市场、关税和规模的乐观预期先带来资本承诺，项目尚未获得经营验证 | 两次大额资本方案相隔不足两月，且第二项目仍待批准；埃及现有项目也仍在推进。 | 资本承诺本身不是客户拒绝、价格恶化或现金失效，也不能从“更大”推断过度投资。它需要未来同一项目的客户、产品、现金和资本证据才能成立。 |

因此，H-A/H-B 的分歧仅在**尚未发生的结果**上，而非 cutoff 前的非共同方向事实。把可研 IRR、预计收入、全球项目定点或集团 OCF 用作 H-A 的选择依据，会把管理层预测、其他基地的客户行为或合并现金替代为项目事实；反过来，把资本金额与审批风险用作 H-B 的选择依据，也只是把谨慎偏好写成判断。

## 4. R-66 的实际应用与本案停止条件

R-66 强制要求一个完整企业系统中的五层必须由同一决策链相连，而不是五类数据各自存在。R-67 把这一约束落实为：

1. 每项海外客户事实必须有埃及主体、产品和交付/订单 locator；没有就只作行业/公司背景；
2. 预计项目 IRR、预计收入和董事会投资额均只记在 D1/D5 的**假设/承诺**栏，不能进入 D2–D4；
3. 集团 OCF 只说明集团现金状态，不作为埃及项目 owner-cash；
4. 在至少一个真实客户/交付接口及同项目单位经济、营运资本和资本支出出现前，禁止建 FJ 或等待结果“替它选边”。

这次没有把检查清单变成形式主义：它直接阻止了把一份看似完整、且非常适合写“出海故事”的材料误登记为企业判断样本。

## 5. 结论和下一候选的准入条件

- 根因：`DATA_COVERAGE + REASONING`。
- 经济影响：若强行选择，会把全球化资产配置错当成经客户验证的正常盈利与现金能力，继而高估资本回收并低估海外建设的永久损失风险。
- 缺失事实：埃及主体已实施的建设/量产、项目专属的客户/订单/价格或交付、产品级成本桥、项目营运资本和实际资本支出/自由现金。
- 禁止假设：
  - 股东会通过、预计收益或可研敏感性等于经营实施或回报；
  - 其他海外基地的客户项目自动迁移至埃及；
  - 集团收入、OCF、应收或存货能够替代新项目现金；
  - 审批尚未完成、资本金额大就等于过度投资；
  - 后续业绩可以倒灌为 2026-08 的选择依据。
- 可执行处置：关闭 `R-67 / NO_PRIMARY / NOT_FROZEN`。下一批候选只筛选**已经跨过 D1 的运营决定**：至少一项实际运营接口在 cutoff 前已发生，且客户/竞争对其给出可归属反应；随后才读取该责任单元的单位经济、营运资本和资本回收材料。绿地/筹备阶段公告不能作为下一批入口。

R-67 不是“海外扩产无效”的证据，而是一个严谨停止点：没有 D2–D5，同一笔资本的经营意义仍是 `UNKNOWN`。
