# R-77｜格力 1997 渠道治理：档案来源筛选，不以幸存者叙事构造企业机制

状态：`ARCHIVAL_SOURCE_ELIGIBILITY_SCREEN / NO_PRIMARY / NOT_FROZEN / NO_SELECTION_SCORE / OUTCOME_BODY_UNREAD`。

R-77 是对“1990 年代中国家电竞争中少数企业留下来”这一极有价值、但也最容易被后见之明污染的素材做一次**来源准入**。它不构成格力研究重启，不评价格力经营或证券，也不从后来行业格局反推 1997 年某项渠道政策正确。

结论是停止在档案筛选：目前只有可定位的第三方历史公告索引、后来的公司叙事和行业背景；没有取得可审计的同期公司决策原件和连续法定报表。因此不能可靠冻结渠道治理的行动范围、竞争反方或 D1--D5 的任何结果合同。

## 1. 本轮查找范围与已确认的边界

本轮只寻找 1996-01-01 至 1999-12-31 的同期档案，目标是定位下列最小原件组：

1. 1997 年前后由公司或法定披露明确的渠道／销售组织决策、日期、适用范围、授权与停止权；
2. 同一会计主体至少两份连续年报，能读到销售／毛利或费用、应收或存货、经营现金及资本承诺／退出；
3. 独立行业背景，用于说明竞争环境而不是代替公司机制。

通过 CNINFO 历史公告端点，对 `000651`、组织号 `gssz0000651` 在上述期间作 `fulltext` 完整枚举；返回零条记录。该结果只表明**当前 CNINFO connector 的历史覆盖不能取得该段资料**，不等于当时没有法定披露。

可检索到一个第三方历史公告索引，列出 `1997 年年度报告摘要`（披露日 1998-01-20）、1997 年中报和 1996 年年报摘要；但其下载链接现返回并非原披露文件的页面，且索引本身不能证明原始文件完整性、页码或传输链。它只能用作寻找法定档案的 locator，不能作为 `DOC`、事实或机制证据。

[中国家用电器协会的行业历史回顾](https://www.cheaa.org/contents/116/8685.html)可作为**环境**线索：1990 年代保护减少、计划产品属性退出、供给过剩和外资进入使价格与竞争条件发生改变。它不提供格力的特定渠道决定、经销商行为、现金或资本事实。

## 2. 为什么尚不能建立 D1--D5 企业系统

| 时钟 | 合格的 1997 渠道治理案例应有的同期事实 | 当前状态 |
|---|---|---|
| D1 决策实施／停止权 | 组织、经销商规则或渠道合同；生效日期、范围、责任与终止／纠偏条件。 | `MISSING_PRIMARY_ACTION` |
| D2 客户／竞争反应 | 渠道覆盖、交付、终端售出或经销商反应，并能与价格战／行业需求区分。 | `MISSING_CHANNEL_OUTCOME_CONTRACT` |
| D3 单位经济 | 同口径价格、折扣／返利、渠道费用、产品成本或毛利桥。 | `MISSING_UNIT_ECONOMICS` |
| D4 营运资本与现金 | 应收、存货、预收／经销商保证金、回款与 CFO 的来源桥。 | `MISSING_CASH_SOURCE_BRIDGE` |
| D5 资本回收 | 渠道系统投入、资产／营运资本占用、退出成本与回收边界。 | `MISSING_CAPITAL_BOUNDARY` |

在上述空格存在时，任何“销售公司”“区域经销商”“价格战”或后来“渠道模式”的描述，都可同时兼容至少三张图：渠道治理改善、行业出清／需求变化主导、或价格及赊销换来表面增长。没有同期公司原件，不能选择其中任何一张图，更不能设计公平基线或可结算反方。

## 3. 根因、经济影响与停止规则

- **根因：** `DATA_COVERAGE + ACQUISITION_MODULE`。现行公开连接器未覆盖 1996--99 年的格力法定披露；目前找到的镜像索引没有可核验的原件链。将后来的管理层叙事或行业史升级为公司当时的选择依据则会额外引入 `REASONING` 错误。
- **经济影响：** 用“最终只剩几家龙头”或后来的渠道故事填补此处，会把行业幸存、宏观出清、价格竞争和融资／营运资本变化误写成一项企业决策的客户反应、owner cash 或资本回收；这正是训练飞轮要避免的虚假企业能力归因。
- **缺失事实：** 同期公司决策文件、完整／可审计的法定年报，及渠道责任单元的 D2、D3、D4、D5 同口径字段。
- **禁止假设：** 存活等于当时渠道决策正确；后来的采访、内部刊物或二手历史文章可倒灌为 1997 年依据；第三方索引／下载文件就是原始法定披露；行业集中、总收入、集团现金、价格或回报可替代分层机制。
- **可执行处置：** 关闭 R-77，不读取任何结果期材料。只有定位到有日期、出版者／交易所或公司存档元数据、页码可复读的同期原件，才能重开为 `ARCHIVAL_SOURCE_INTAKE`；随后仍须先获得同一主体的两期会计报表和 D1--D5 映射，才考虑教学冻结。
- **接纳条件：** 不是“再找到几份报告”，而是取得上述最小原件组，并可在读取任何后续结果前写出相互竞争的渠道／需求／信用机制、不同于持续基线的预测，以及逐层的停止条件。缺任一项仍为 `NO_PRIMARY`。

## 4. 方法学习：历史素材的价值在于边界，而不是结局

R-77 保留的不是“格力渠道成功”结论，而是一个可迁移的档案纪律：早期行业史可以帮助选择**问题**，不能替代当时企业的行动、反方和计量。今后中国家电历史教学优先选法定披露可连续取得、能够让一个决策穿过 D1--D5 的公司／时期；若档案覆盖不足，就保留为 `UNKNOWN`，而不是由今天看见的行业格局补齐。
