# R-01 机制实验室：列报边界与经济残差

状态：`EVIDENCE_READ / METHOD_BOUNDARY_RESOLVED`。以下仅裁决列报边界，不构成关于美的经营质量的判断。

## 共同待解释事实

FY2023 原报告的营业成本/销售费用为 `273,481,373 / 34,880,875` 千元；FY2024 年报比较数为 `276,409,404 / 31,952,844` 千元。两条差额均为 `2,928,031` 千元，且页 125/198 给出相同的保证类质保费重分类解释。两个行项目之和同为 `308,362,248` 千元。

因此，这个差额是 `FACT`：FY2023 的这两个列报项目不能与 FY2024 前的原报行项目直接同比。

## 竞争解释

### H-A：主要是列报边界变化

会计准则适用、分类规则或比较数重述改变了原有行项目的位置或标签。表观同比变化中的主要部分不代表实际资源消耗、售价、产品质量或渠道激励的改变。

本轮 H-A 得到直接支持：原文给出变更对象、适用时点、比较数处理和相等的两端金额。它只能解释这 29.28031 亿元在成本/费用之间的迁移，不能解释超出口径影响的残差。

### H-B：即便存在列报变化，仍有独立经营变化

H-B 仍为 `UNKNOWN`：同一期间仍可能发生售后质量、返利、渠道、产品组合或制造效率变化。会计变更只解释明确映射的 FY2023 比较数；FY2024 实际经营变化仍须由独立经营观察验证，不能默认归零。

### H-M：混合状态

本对象对 FY2023 两个行项目有完整调节，但对真实质保履约和现金没有调节。因此结论是 `PRESENTATION_BOUNDARY_RESOLVED / ECONOMIC_RESIDUAL_UNKNOWN`，而非“全部为会计变化”。

## 本轮的判断动作

```text
表内变化
  ├─ 原文是否明确口径/比较数变化？ ─ 否 → 不能以 R-01 解释；保留经营待检验
  └─ 是
      ├─ 是否有变更范围和量级？ ─ 否 → MIXED / RESIDUAL_UNKNOWN
      └─ 是 → 从表内变化剔除已解释部分；仅对剩余部分另建经营机制
```

这个流程的目标不是把每个数字“调平”，而是保护未知：会计事实、管理层因果解释和研究者的经济推断必须分开保存。
