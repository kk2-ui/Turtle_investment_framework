# R-64｜蒙牛—雅士利：FY2014 五层时钟教学结算

前置冻结卡：[2013 年收购、独立平台与企业系统](01_2013_pre_outcome_enterprise_judgment_card.md)。

状态：`OUTCOME_RESOLVED_FOR_TEACHING / NO_PRIMARY / NO_TOTAL_TRANSACTION_VERDICT`。

本页只读取预登记的 FY2014 雅士利年度报告，并以蒙牛 FY2014 年报确认雅士利的并表贡献。它不评价蒙牛、雅士利或中国婴配粉行业“最终成功/失败”，不读证券价格、回报或后来发展，也不把已知结果伪装成 2013 年的判断能力。

## 1. 先定位谁的结果、哪项行动、什么时间

雅士利 FY2014 年报显示：2014 年收入为 `RMB2.816bn`，低于 FY2013 的 `RMB3.890bn`（`-27.6%`）。其中雅士利品牌配方奶粉收入由 `RMB2.661bn` 降至 `RMB1.833bn`（`-31.1%`），施恩品牌由 `RMB660.5m` 降至 `RMB437.9m`（`-33.7%`），营养产品约由 `RMB546.2m` 降至 `RMB533.8m`（`-2.3%`）。这些是目标主体的同口径产品观察，而不是蒙牛集团的收入替代。

同一报告把销售下降同时归于两组原因：婴幼儿配方奶粉行业增长放缓，及雅士利自 2014 年上半年开始进行销售渠道梳理和营销改革，令经销商和消费者需要时间适应。主要雅士利配方奶粉在一、二、三线城市的销售均下降。后者是一个有独立时间点的**新行动**，不能被倒写成 2013 年收购本身已完成的渠道协同。

来源：[雅士利 FY2014 年报](https://www.hkexnews.hk/listedco/listconews/sehk/2015/0429/ltn20150429510.pdf)；蒙牛报告仅确认雅士利对其合并收入 `RMB2.816bn`、合并毛利 `RMB1.464bn` 的贡献，[蒙牛 FY2014 年报](https://www.hkexnews.hk/listedco/listconews/sehk/2015/0429/ltn20150429558.pdf)。

## 2. 按五层时钟结算

| 时钟 | FY2014 可观察事实 | 正确结算 | 为什么不能再走一步 |
|---|---|---|---|
| D1 决策实施 | 2013 年控制权交易已完成；雅士利 2014 年上半年开始渠道梳理和营销改革。冻结时的要约文件则同时表明保留其独立经营平台。 | `CONTROL_COMPLETED / OPERATING_INTEGRATION_UNOBSERVED`；2014 渠道改革是 `NEW_DOWNSTREAM_ACTION`。 | 控制权完成不显示采购、质量、产品、定价、分销和营销已被统一经营；把 2014 新行动记回原交易会改变因果对象。 |
| D2 客户/竞争反应 | 配方奶粉销售在各城市层级均下降；报告称行业增长放缓，且经销商/消费者在适应渠道与营销改革。 | `WEAKER_OUTPUT / MIXED_NOT_DIAGNOSTIC`。 | 销售下降真实，但行业、消费者/经销商适应和新行动可以共同解释；没有目标层面的协同接口或竞争对照来判 H-A/H-B/H-C。 |
| D3 单位经济 | 毛利从约 `RMB2.080bn` 降至 `RMB1.445bn`，毛利率从 `53.5%` 降至 `51.3%`。报告同时披露原料奶粉平均成本上升，并自 2014H1 用积分模式替换免费赠品，致部分成本从销售/分销费用转入销售成本；销售及分销费用虽下降约 `20.6%`，但占收入比由 `35.8%` 升至 `39.3%`。 | `PRODUCT_ECONOMICS_WEAKER / CLASSIFICATION_AND_COST_MIXED`。 | 毛利率与费用率方向都可观察，但成本分类、原料成本、产品/渠道重配与收入下滑共同存在；不能把它写成收购损害经营，或由一条费用线宣布协同失败。 |
| D4 营运资本与现金 | OCF 为 `RMB264.457m`，高于 FY2013 的 `RMB140.877m`。同年现金流桥包含存货减少 `+RMB161.672m`、应收增加 `-RMB12.427m`、预付款增加 `-RMB42.433m`、应付下降 `-RMB68.575m`。 | `POSITIVE_OCF / NOT_DIAGNOSTIC_AS_OWNER_CASH`。 | 经营现金为正并不等于持续现金经济改善：存货释放是重要来源，而预付增加和应付下降同时吸收现金；没有理由把该现金归因于蒙牛资源或交易协同。 |

## 3. 整体机制的正确边界

```text
D1：控制权已完成；经营整合未被观察到
D2：客户/渠道输出走弱，但行业放缓与新渠道行动混杂
D3：产品经济走弱，成本与分类变动使传导不可归因
D4：OCF 为正，营运资本桥不支持 owner-cash 结论
D5：资本回收未知
H-A / H-B / H-C：没有一条完整机制获得公平裁决
```

这不是一句“协同失败”。它是更有价值的经营训练：交易使资本和治理边界发生变化，但原合同保留独立平台；随后在结果期出现的渠道重整本身又成为新的 D1 决策。若不为每个行动重新编号，并按客户、单位经济、现金和资本边界分别读取，研究者极易把一段收入下滑或一段正 OCF 错归到最初的收购。

## 4. 写入下一不同公司冻结卡的有效约束

R-64 不产生选择准确率或方法胜率，但保留以下对下一家不同公司的输入约束：

1. **交易控制与经营接口必须分开登记。** 每个采购、产品、质量、渠道、营销、定价或售后接口都要有控制主体和实际日期；没有接口的，只能结算 `CONTROL_COMPLETED`。
2. **结果期新增经营改革必须成为新行动。** 它不能被收购、扩产或组织变更的原始机制“吸收”；若不能分开，原机制结算为 `NOT_DIAGNOSTIC`。
3. **单位经济必须同时保留成本分类和销售投入。** 毛利、COGS、销售/分销费用或促销模式任一口径变化，都先解释定义与实际成本，再谈传导。
4. **正 OCF 需要完整营运资本桥。** 存货释放、应收、预付、应付的相反箭头必须并列；正现金流不能升级为 owner cash。
5. **收购资本回收需要责任单元合同。** 没有交易资本、后续投入、税后自由现金和替代路径的同边界比较时，结论只能是 `CAPITAL_RETURN_UNKNOWN`。

根因分类：`REASONING + DATA_COVERAGE`。缺失的不是更多年度报告，而是一个把 2013 交易资源、2014 新渠道行动、外部客户响应、同口径产品成本和责任单元资本回收连为同一因果链的结果前合同。禁止用收入、毛利、单年 OCF、集团并表、购买价、公司名气、价格或回报填补。下一张收购/整合候选若没有上述五项中的至少 D1 实际接口、D2 可分叉证据、D3 同产品口径、D4 完整现金桥与 D5 责任单元边界，应在结果前停止为 `NO_PRIMARY`。
