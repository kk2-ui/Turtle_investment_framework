# R-64｜蒙牛—雅士利 2013：收购、独立平台与经营系统的结果前教学卡

状态：`RESULT_KNOWN_TEACHING_ONLY / NO_PRIMARY / CURRENT_RESEARCHER_RESULT_EXPOSED`。

本卡把 2013 年蒙牛取得雅士利控制权当作一个完整企业系统，而不是一笔“并购成功/失败”故事。研究者在建立本卡时已知 2014 年结果；因此它只训练机制、证据边界和五层经营时钟，不进入 Turtle 的选择判断、准确率、概率、估值、股价或回报轨道。

## 2. 先还原企业系统，而不是从收购价或收入开始

```text
婴幼儿配方奶粉的品质、监管、渠道与消费者信任压力
  → 蒙牛取得雅士利控制权，并以外部融资承担交易资本
  → 要约文件所称的产品、采购、分销、质量与营销资源能否实际接入
  → 经销商、消费者与竞争者对品牌、渠道和产品组合的反应
  → 雅士利配方奶粉的收入 × 毛利 × 销售投入
  → 存货、应收、预付、应付与经营现金
  → 交易资本及后续投入能否形成可辨认的责任单元回报
```

要约文件说明，雅士利从事婴幼儿配方奶粉及营养产品；2012 年归属于目标集团的历史税后利润约为 `RMB470.5m`。文件列出可能在产品创新、上游采购、分销销售、质量和营销上探索协同，但同一文件也明确目标是维持雅士利在婴幼儿配方奶粉领域的**独立经营平台**。这两类事实必须并列保存：控制权和资源主张存在，不等于采购、渠道、定价、产品、营销或售后已变成一个共同经营系统。

### 当时真正的经济问题

蒙牛获得一家具备配方奶粉品牌、产品和渠道基础的目标公司后，能否在不损害其独立平台和消费者/经销商关系的前提下，使产品、采购、质量和渠道资源形成可重复的单位经济与现金转换；还是控制权主要停留在资本和治理层，且行业放缓、监管/信任压力与渠道调整主导了经营结果？

| 候选路径 | 状态 → 决策/资源 → 经营传导 | 需要被证明的条件 | 最早会使其失效的事实 |
|---|---|---|---|
| H-A：受控资源协同形成经营改善 | 控制权完成，且采购、产品、质量或分销资源以可观察的方式接入雅士利 → 经销商/消费者接受不受损 → 目标主体的产品收入、单位经济和现金共同改善。 | 不只是母公司持股，而是目标主体的端到端经营接口、外部客户/渠道和同产品经济同时可见。 | 销售或渠道改变没有可识别的协同接口；改善只来自存货释放、行业回升或会计/费用分类。 |
| H-B：独立平台使交易没有形成可检验的共同经营系统 | 控制权与融资资本存在，但原文件所称独立平台限制了可观察的经营整合 → 雅士利仍主要受其自身产品、渠道和行业状态驱动。 | 后续经营变化不能合理分配给蒙牛资源，而不是仅仅没有“协同”文字。 | 同主体出现明确、可追溯到采购/渠道/产品接口的外部交易和成本改善。 |
| H-C：行业与后续渠道调整主导 | 行业增速放缓、消费者/经销商适应和雅士利后续渠道/营销改革 → 收入、毛利和营运资本变化可在没有交易协同成立的条件下发生。 | 结果期能定位独立于 2013 年交易的行业/渠道干扰。 | 在没有行业或新渠道行动解释的情况下，目标主体的多层经营观察同步、持续改善。 |

### 为什么本案仍是 `NO_PRIMARY`

截止日前能看到的是控制权、管理层的潜在协同主张和独立平台承诺；这些事实都可同时兼容 H-A、H-B 与 H-C。没有一条结果前、非共同且有方向的经营事实可以公平地选择 H-A，也没有不同于朴素延续基线的同指标预测合同。因此本案可以教学地结算已冻结的箭头，却**不能**以 2014 的结果反写“当时就应选择哪条路径”。

## 3. 五层时钟和结果合同

R-58 的约束在本案被保留：控制权、经营接口、产品经济、现金桥和交易资本必须拆开。R-64 进一步预先规定：若结果期出现新的渠道重整，它必须作为新的 D1 决策，不得倒灌为 2013 年收购的实施效果。

| 时钟 | cutoff 前基线 | FY2014 只允许的观察 | 可作出的最强结算 | 禁止替代 |
|---|---|---|---|---|
| D1 决策实施 | 要约完成；文件称可探索协同，同时保持雅士利独立经营平台。 | 目标主体中采购、产品、质量、分销、营销等接口何时、由谁实际接管；每个后续重组有独立行动日期。 | `CONTROL_COMPLETED` 或具体接口的 `IMPLEMENTATION_OBSERVED`。 | 母公司并表、董事会控制、协同愿景或后来渠道改革。 |
| D2 客户/竞争反应 | 目标已有配方奶粉与营养产品、品牌和分销网络；没有可归属交易的客户/渠道基线。 | 同一目标主体按产品、渠道/城市层级披露的销售，以及渠道调整、行业放缓和消费者/经销商适应的解释。 | 客户/渠道输出的方向；没有接口时为 `NOT_DIAGNOSTIC`。 | 蒙牛集团收入、品牌名次、行业总量、价格或管理层乐观表述。 |
| D3 单位经济 | 只能冻结 2012 的历史利润和产品平台；不能从交易文件推导协同利润率。 | 雅士利同主体配方奶粉/营养产品的收入、毛利、毛利率、销售及分销费用，并同时保留成本和分类变化。 | 产品经济方向，且仅在传导完整时归因。 | 集团毛利、净利润、EPS、单项销售费用或管理层指引。 |
| D4 营运资本与现金 | 交易资本来自买方层面；目标的正常现金质量未知。 | 雅士利 OCF 及存货、应收、预付、应付等完整变化桥。 | `CASH_ARROW_OBSERVED`；有营运资本释放时不得称 owner cash。 | 年末现金、融资现金、交易对价、单年 OCF 或净利润。 |
| D5 资本回收 | 买方承担交易资本与外部融资；目标仍是独立披露主体。 | 交易资本、后续投入与目标责任单元税后自由现金之间是否存在同边界、同期间的可比合同。 | 资本吸收可观察；无责任单元合同则 `CAPITAL_RETURN_UNKNOWN`。 | 将并表、收购对价、2014 收入、OCF、股价或后来市值相除。 |

停止规则：若结果源只显示集团指标、改变产品/法人定义、没有完整营运资本桥，或把新的渠道行动混为 2013 收购，结算立即降级为 `MEASUREMENT_MISMATCH` 或 `NOT_DIAGNOSTIC`；不以更多报告补足。

## 4. 结果后附页与本卡的边界

本卡在结果期只指向 [FY2014 结果复盘](02_fy2014_outcome_resolution.md)。该附页可以结算已冻结的 D1–D5 观察，却不可以修改本卡的 `NO_PRIMARY` 身份、补造选择基线，或将任何结果写成交易总经济性结论。

根因分类：`REASONING + DATA_COVERAGE`。最大风险不是“材料不足以写一份收购报告”，而是把控制权、母公司资源主张、后来渠道改革、产品销售和正经营现金拼成同一条协同链。那会材料性高估正常盈利、owner cash 和收购资本的永久损失保护。缺失的是结果前非共同方向证据、可识别的经营接口、交易责任单元自由现金和真实替代路径；禁止用公司名气、行业故事、股价或短期回报替代。
