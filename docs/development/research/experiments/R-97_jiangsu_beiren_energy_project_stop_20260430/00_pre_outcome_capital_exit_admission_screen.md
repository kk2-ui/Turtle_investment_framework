# R-97｜江苏北人 2026 终止综合能源项目：减值与退出计划不是资本回收

状态：`PRE_OUTCOME_CAPITAL_EXIT_SCREEN / NO_PRIMARY / NOT_FROZEN / NO_SELECTION_SCORE / OUTCOME_BODY_UNREAD`。

R-97 检验一个更接近企业家资本配置的问题。江苏北人计划终止已经运营、连续亏损的工商业储能项目，并出售项目公司股权或储能柜资产，把资金转回智能制造主业。项目已有收入、毛利、资产减值和累计亏损，不是纯粹的董事会计划；但股东会尚未批准，买方、交易价、付款、项目级客户现金和资金再投向均未知。把“停止一个亏损项目”直接写成减少永久损失或资本配置正确，会把**账面减值、董事会意图和真实资本回收**混为一谈。

本卡不评价江苏北人、工商业储能、管理层或其证券。2025 年储能结果仅作为 2026 年退出决定的行动前基线；未读取 cutoff 后的股东会、资产转让、经营结果、价格、估值或回报。

## 3. 对立机制与简单基线没有可选择的增量内容

```text
H-A：批准并出售能止损，释放资本给核心主业
股东会批准 + 合格买方以可接受价格成交
  -> 储能柜/项目公司不再占用资金与管理资源
  -> 避免未来经营、整改和信用损失
  -> 售款净额进入可用现金并支持核心主业

H-B：退出意图不能克服买方、价格和现金障碍
股东会审批或交易进程延迟，资产仍在运营
  -> 潜在买方继续观望或要求折价
  -> 存量项目仍承担经营、合规和客户信用风险
  -> 追加减值/现金占用使实际回收低于账面状态

简单基线：没有新交易事实时，项目继续处于运营/待售状态，
不假定出售、现金回收或核心主业再投资已经发生。
```

在 cutoff 时，外部资产持有方观望和过往处置低于预期只能支持 H-B，也恰好等同于简单基线；它不能说明研究机制比“不预设成交”的持续基线增加预测内容。H-A 所需要的买方、价格和现金事实不存在。故无论选择 H-A 还是 H-B，都会分别成为无证据乐观或把基线伪装成判断力，不能建立 `SELECTION_ADMITTED`。

## 4. 准入裁决与停止条件

- **根因：** `DATA_COVERAGE + REASONING`。法定 source package 已完整；缺的不是更多行业叙事，而是使退出区别于持续基线的交易对手、定价和项目现金事实。历史减值和退出意图不能代替这些事实。
- **经济影响：** 若把账面减值、董事会同意或“聚焦主业”写成资本回收，会材料性低估出售折价、交易延迟、继续运营损失、融资/担保与客户信用风险，并可能虚增核心主业可获得的再投资资本；反过来，也不能把历史亏损当成退出必然失败。
- **缺失事实：** 股东会批准；具名/可验证的买方或竞价；转让价格、付款条件、交易成本、税费和债务/担保解除；项目公司客户/园区 cohort、价格/利用率/成本和回款；出售后资金实际可用性与明确替代用途。
- **禁止假设：** 项目已建成、历史收入/毛利、累计亏损、减值、净资产、董事会决议、合并 Q1 现金、核心业务改善或“聚焦主业”可替代成交、回收或再投资事实。
- **可执行处置：** 关闭 `R-97 / NO_PRIMARY / NOT_FROZEN`，不建立 future judgment、简单基线、结果合同、反馈项目或 condition inbox。单独等待股东会并不会补齐客户、买方、价格、项目现金和再配置事实。
- **重新准入条件：** 只有新的 cutoff 前同时出现已生效的退出授权、可识别交易方/竞价和价格/付款边界、项目客户与现金基线、以及能使 H-A/H-B/简单基线对同一资本回收观察给出不同预测时，才可建新的退出 episode。

## 5. 对训练飞轮的实际约束

R-97 将资本配置的学习对象从“是否承认损失”推进到“是否把资本真正从错误用途收回”。今后的项目退出、关停、减值或业务收缩，必须分开冻结：生效授权、客户/买方反应、项目单位经济、项目现金与交易后资本回收。任何一层尚未出现，都不能由董事会措辞、账面减值或集团现金流替代。
