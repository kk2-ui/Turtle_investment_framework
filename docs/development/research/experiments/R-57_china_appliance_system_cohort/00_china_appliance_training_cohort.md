# R-57｜中国家电企业系统训练批次：先建立机制语料，而非倒推幸存者

状态：`TRAINING_COHORT_PREPARED / KNOWN_OUTCOME_TEACHING_CORPUS / NOT_A_METHOD_EVALUATION`。

## 研究问题的重写

“为什么早期中国家电竞争中只剩下少数全国性龙头”不是一个可以直接回答的因果句。它没有定义品类、年份、存活标准、样本 universe 或反事实；若从今天仍大的公司反推当年“做对了什么”，会把幸存者偏差、地域边界、上市主体变化和后来的行业集中度写成管理能力。

本批次将它改写为可训练、但不夸大的问题：**在不同的中国耐用消费品竞争状态下，一项企业决策经由哪些层次影响客户、单位经济、现金和资本回收；哪些层次能够被当时/后来的原始资料分别观察？**

这不是一家公司的无限深挖，也不是“报告数量”项目。它是一个有止损规则的既知结果训练语料：用于让研究者学习企业系统的分层与反方，不能计入 Turtle 的前瞻命中、选择准确率或方法胜率。

## 共同企业系统

```text
行业制度、需求、技术与供给状态
  → 管理层的组织 / 产品质量服务 / 产能部件 / 渠道资源承诺
  → 客户、经销商、供应商与竞争者反应
  → 价格 × 成本 × 组合的单位经济
  → AR、库存、预付、客户预收、AP 的现金转换
  → 增量资本、外部融资与可验证的资本回收
```

每个案例都须逐层作答 `OBSERVED / NOT_DIAGNOSTIC / MEASUREMENT_MISMATCH / UNKNOWN`；任何一层不能由下一层或集团总规模替代。资本回收只有在有责任单元资本、税后现金结果与可行替代时才可判断。

## R-25 的系统演练：一个箭头成立，不代表整项决策成立

R-25 直接展示企业家与投资者必须同时持有的多层判断：

| 层次 | 已知结果 | 训练裁决 |
|---|---|---|
| D1 资源承诺 | 多基地空调与压缩机能力形成。 | `IMPLEMENTATION_OBSERVED`；不是回报。 |
| D2 客户/竞争 | 2005–2006 空调销量与收入增长，且行业供给压力存在。 | `SUPPORTS_PRIMARY_FOR_OUTPUT_ABSORPTION`；不用约数计算假利用率。 |
| D3 单位经济 | 压缩机销量增长；2006 年含内部销售收入仅小幅增长、外部收入下降、整体毛利率降约 9 个百分点。 | `SUPPORTS_RIVAL_FOR_COMPONENT_UNIT_ECONOMICS`；自制部件没有自动转成可见经济优势。 |
| D4 现金转换 | 2005 OCF 主要受业务剥离释放营运资金影响；2006 有库存/应收占用和应付支持。 | `NOT_DIAGNOSTIC_AS_CAPACITY_OWNER_CASH`。 |
| D5 资本回收 | 没有项目级资本预算、外购反事实、基地利用率或责任单元现金回报。 | `CAPITAL_RETURN_UNKNOWN`。 |

这个案例的价值恰在于它不能被压成“美的扩产成功/失败”。经营者可完成实施并获得终端产品吸收，同时在一个关键部件上遇到价格竞争；投资者必须继续追问现金与增量资本是否得到回报。

## 历史语料、盲测与真实前瞻的分工

| 轨道 | 输入 | 允许学什么 | 不允许声称什么 |
|---|---|---|---|
| 已知结果语料 | R-17/R-18/R-25/R-27/R-30。 | 机制拆解、证据口径、常见混淆和企业系统的多层时钟。 | 研究者准确率、方法胜率、对任何公司的投资结论。 |
| 结果前档案盲测 | 如 R-56：先隔离结果，后按冻结合同读取。 | 单箭头的诊断性、测量合同是否足以避免事后拼接。 | 单案外部有效性、概率校准或总管理能力。 |
| 真实前瞻 | 已冻结且未到期的公司机制信号。 | 在真实约束下的采集、结算和 learning-application。 | 用价格/短期回报裁决经营判断。 |

三轨共同服务同一目标：形成一名能看见企业系统、承认未知、并让下一次研究真的改变的研究者；它们不以报告数量替代经验。

## 从 R-56 继承的下一道入场门

后续中国家电或制造业 case 在 cutoff 前要为下列层次预登记一个可读字段，或明确冻结为 `UNKNOWN / NOT_DIAGNOSTIC`；后者不阻断研究，但限制可以声称的层级。只有 D2–D4 至少各有一项可结算、且 D5 的未知边界已写明时，才可成为 R-56 的不同公司 replication：

1. `D2`：外部客户交付与内部工序转移的边界；
2. `D3`：与同一产品交付相连的价格、成本或产品级毛利；
3. `D4`：AR、库存、预付、客户预收、AP、其他应付及非现金项目的完整现金桥；
4. `D5`：责任单元资本、税后现金结果与真实的分期/外购/不投资替代；若公开材料没有，预先冻结 `CAPITAL_RETURN_UNKNOWN`。

缺 D2–D4 中任何必需的可结算观察时，仍可进入既知结果的 `BOUNDARY_TEACHING`，但不得被包装成 R-56 的有效 replication；D5 缺失则仍可研究其它层次、但资本结论永久缺席。两种情况都不得因为企业名气、材料多或后来仍存活而继续扩读。

## 结束规则与下一步

本批次到此结束，不再为同一家公司增加材料。下一步仅做一个新的、不同公司的 pre-outcome screen：候选必须先填补上述 D2–D5 的一个可结算格，并携带一个表面相似但上游中介不同的 near-miss。若公开一手资料不能满足，就明确留在 `NO_PRIMARY`，转选其它制造业；不让数据缺口中断整个训练飞轮。

根因分类：`REASONING + DATA_COVERAGE`。旧方法会把幸存者、产能、品牌或一个漂亮现金流直接写成企业能力；本批次的修复是把案例扮演的训练角色、可结算层次和不能声称的结论预先分开。经济影响是避免高估正常盈利、owner cash 和资本配置，从而低估永久损失。
