# R-99 | 耐普矿机 2026 Aidarly 铜矿合同：历史上曾披露进展，不等于当前销售合同可结算

状态：`PRE_OUTCOME_CONTRACT_OBSERVABILITY_SCREEN / NO_PRIMARY / NO_ELIGIBLE_ECONOMIC_FJ / NOT_FROZEN / NO_SELECTION_SCORE / OUTCOME_BODY_UNREAD`。

R-99 检验一个比普通海外扩产更接近真实经营链的对象：耐普矿机与哈萨克斯坦 Aidarly 铜矿签订设备、耐磨备件、安装调试和两年现场维修服务合同。合同具名客户、产品、交付时限和付款里程碑；公司也有“设备切入、备件和服务深化客户”的既有经营模式。它仍不能进入前瞻机制探针或选择样本，因为截至 cutoff 没有可预注册、且可从官方结果期来源重建的 Aidarly 项目交付、验收、收款、单位经济或资本回收观察。

本卡不判断耐普矿机、Aidarly 铜矿、哈萨克斯坦市场、管理层、合同价值或任何证券。它只记录截至 cutoff，当前合同是否具备足以冻结一条经济判断的结果可观测性。任何 2026 年 7 月 4 日及以后关于该合同的结果正文、价格、估值和回报均未读取。

## 3. 竞争机制可以提出，不能被当前来源结算

```text
H-A：装备切入在 Aidarly 形成可验证的备件/服务关系
具名铜矿合同和本地服务能力
  -> 按时发货、安装与验收，客户在实际工况下采用产品
  -> 设备进入后产生同一客户的备件/服务复购与可观察的单位经济
  -> 合同应收、服务成本和营运资本转化为可归属现金
  -> 增量服务与库存资本得到回收

H-B：一次性项目销售或执行摩擦主导结果
新客户项目的交付、现场调试、验收和服务要求
  -> 合同可收款或确认收入，但不形成可识别的复购/服务经济性
  -> 项目成本、验收和跨境营运资本吸收现金
  -> 集团或产品总额无法区分该合同、其他客户和海外布局
  -> 该合同的资本回收不可判断
```

H-A/H-B 都能容纳“签订合同”“90% 付款条款”和公司既有的设备--备件--服务叙事。前者所需的客户采用和复购、后者所需的项目成本/现金压力，在 cutoff 前均未出现方向性观察；简单基线只能是“不对单一合同的长期经济性作公司特有判断”。更关键的是，现有官方来源没有承诺在未来以 Aidarly 项目身份披露这些分叉。即使后续合并收入、应收、OCF 或产品收入改善，也不能机械结算为 H-A 或 H-B。

## 4. 准入裁决与停止条件

- **裁决：** `NO_PRIMARY / NO_ELIGIBLE_ECONOMIC_FJ / NOT_FROZEN`。本案不创建 CJO、结果合同、due inbox、学习 note 或方法复制任务。
- **根因：** `DATA_COVERAGE + REASONING`。合同材料对 D1 和付款条件很精确，但没有项目级 D2--D5 结果来源；将早年超大型 EPC 的预付款更新推断为当前普通设备销售合同的持续披露机制，是证据外推错误。
- **经济影响：** 若把合同金额、发货前 90% 条款或公司总现金当作客户接受和现金回收，可能高估新客户拓展、备件粘性、正常盈利和海外资本配置；也不能因项目销售一次性而反向断言执行失败。
- **缺失事实：** 已签约时可预注册的 Aidarly 交付/验收/收款官方来源；客户/项目级采用或复购；同合同的量价成本与服务成本；订单营运资本；增量资本、替代用途和税后现金回收。
- **禁止假设：** 2019 年 EPC 的进展披露、合同金额、付款安排、历史大客户、哈萨克服务布局、管理层的积极影响表述、合并收入/应收/OCF/资本开支、后续业绩、价格或回报，可替代项目级结果合同。
- **可执行处置：** 关闭 R-99，不仅等待 300 日交货或两年服务期。对当前合同，结果到来后才出现的自愿披露不能回填为当时可预注册的结算来源；它最多帮助下一项独立 episode 的来源可得性筛查。

## 5. 对训练飞轮的新增约束

在海外设备/备件合同上，先做**同公司、同合同形态的结果可观测性测试**，再讨论客户粘性机制。至少比较两份历史的相近销售合同及其后续官方披露；工程总包的项目级预付款更新不能自动推广至普通设备销售。若未来资料只能提供公司、地区或产品合并指标，正确输出是 `NO_ELIGIBLE_ECONOMIC_FJ`，而不是把详细合同条款伪装成可结算判断。
