# R-18：美的 1997 年事业部制——组织改造的资料准入筛选

状态：`RESULT_KNOWN_TEACHING / MEASUREMENT_MISMATCH / NO_TURTLE_BACKTEST`

本对象的价值不在于重述“美的后来成功”，而在于检验一个对企业家判断很核心、也最容易被事后业绩掩盖的问题：当规模增长超过集中管理的处理能力时，分权、利润中心和市场导向，是否真的改善了组织的资源配置与客户响应？

它承接 R-17 的学习：短期转好、集团规模或管理者名望，均不能替代对组织动作、责任边界和经营后果的逐箭头观察。

## 1. 已可确认的状态与行动

美的公司官方时间线记录，1997 年实行事业部制；其将此称为现代组织架构的基础。[公司时间线](https://www.midea.com.cn/zh/about-midea)  中国共产党新闻网转载《人民日报》的企业报道也描述了当时的状态：上市后规模高速增长暴露集中管理弊端；1997 年推行事业部制，意在从生产型企业转向市场型企业。[《人民日报》回顾](https://cpc.people.com.cn/n1/2019/0121/c64387-30579249.html)

可用的、但仍过粗的机制是：

| 竞争机制 | 当时必须成立的传导 | 不能用作替代 |
|---|---|---|
| H-A：分权提高经营响应 | 产品事业部获得清晰的客户、产品、供应、预算与责任边界 → 更快调整产品/渠道/成本 → 各业务的量价、费用或现金质量改善。 | “实行事业部制”、集团总销售额、后来出现职业经理人。 |
| H-B：组织图变化而非经营能力 | 权责仍留在中心，或增长来自行业周期、扩产、渠道投入/会计边界；组织改造没有形成可持续的单位经济或现金改善。 | 1998 年单一销售额、后来行业地位或创始人声望。 |

1997 年经审计的上市公司合并报表确实显示，主营收入从 1996 年的 24.99 亿元降至 1997 年的 21.76 亿元，主营业务利润从 0.881 亿元增至 0.985 亿元，净利润从 0.916 亿元增至 1.286 亿元；但该报告没有说明事业部制实施月份、各事业部权责、产品/渠道经营指标，故它是**状态背景**，不是组织改革的早期结果。[1997 年年度报告](https://pdf.dfcfw.com/pdf/H22_AN201202240003328725_1.pdf)

## 2. 结果资料显示的边界

公司官方时间线称 1998 年“全球营收超过 50 亿元”；1999 年公司年报列示的 1998 年主营业务收入则为 36.42 亿元，并按家电品类合计同数。这两个数字很可能属于不同的集团/上市公司边界，不能直接相减、计算增速，或归因为 1997 年组织改造。[公司时间线](https://www.midea.com.cn/zh/about-midea) [1999 年年报](https://finance.sina.com.cn/special/annual/2000-03-31/26153.html)

已找到的 1997 年年报还显示，当年合并口径营运资金变动受资产、资本、长期负债和投资的大额变化影响；报表采用当时的“财务状况变动表”格式，不能把其中任一净额简化为今天定义的经营现金流。因此，目前没有可与组织动作同口径连接的 `事业部 → 库存/应收/费用率/经营现金` 结果序列。

| 所需结果 | 当前可见观察 | 训练结论 |
|---|---|---|
| 组织动作存在 | 公司官方和人民日报回顾均指向 1997 年事业部制。 | `ACTION_REPORTED` |
| 上市公司 1996–1997 的经营状态 | 有审计合并财务表。 | `STATE_OBSERVED` |
| 组织动作后的可比业务经济 | 1998 数字的主体边界不同，且无事业部级责任、库存、应收、费用或现金链。 | `MEASUREMENT_MISMATCH` |
| 分权确实造成长期 owner-cash 改善 | 无法从现有材料识别。 | `UNKNOWN` |

所以 R-18 不是“美的事业部制成功”的历史回测，更不贡献 agent 判断准确率。它的合格教学结论只有一条：**组织变革的结果不能由集团销售额或单一利润期裁决，必须先锁定经营主体和责任单元。**

## 3. 这次筛选怎样改变训练方法

R-18 将 R-17 的 `operating_control` 拆成可采集的四个、缺一不可的字段：

1. `decision_right`：产品、渠道、价格、采购、预算由谁决定；
2. `accountability_unit`：利润、库存、应收、质量和资本占用归属于谁；
3. `incentive_and_exit`：负责人如何被奖惩、替换或约束；
4. `boundary_consistency`：行动前后的公司、集团、事业部和产品口径怎样连续。

今后的组织类候选，只有在**行动前材料**同时定位至少两项权责字段，并在**结果包**中对同一责任单元取得两期同口径经营数据，才允许进入 `OUTCOME_CONTRACTED_EPISODE`。这不是增加文书要求；它防止把宏观增长、并表变化或集团扩张误判成经营者的组织能力。

## 4. 升级需要什么，而不需要什么

根因：`DATA_COVERAGE + ACQUISITION_MODULE + REASONING`。可访问的早年上市年报证明历史财务文件并非必然不可得；真正缺的是 1997 年行动时点的分权/责任材料，以及 1998–1999 年按相同主体和责任单元披露的经营、营运资本或现金结果。

经济影响：如果把 1998 年 50 亿元的集团说法和 36.42 亿元的上市公司收入混用，研究者会把合并边界或产能扩张造成的变化，错写成组织分权改善了正常盈利或可分配现金。对长期所有者而言，这恰好会高估管理能力、低估资本占用和永久损失风险。

重新准入条件：

1. 1997 年或紧邻时点的原始董事会/公司文件，至少说明两个 `decision_right / accountability_unit / incentive_and_exit` 字段；
2. 结果期两次同一法人或同一事业部的披露，至少包含收入/毛利或费用率之一，另加库存/应收/现金之一；
3. 一份冻结前结果合同，明确采用集团还是上市公司边界，禁止跨边界代理；
4. 可行反方：维持集中制或只增加营销投入为何会使上述同口径指标呈现不同顺序。

未满足时，保留为教学层并转向下一个 arena；不得用研究报告、后来回忆、品牌排名、股价或回报填补。
