# R-93｜中信重工 2026 年高端耐磨材料基地：待股东会批准且尚无客户分叉的前瞻候选

状态：`PRE_OUTCOME_CANDIDATE / PENDING_D1_APPROVAL_AND_D2_ADMISSION / NOT_FROZEN / NO_SELECTION_SCORE / OUTCOME_BODY_UNREAD`。

R-93 是一个真实前瞻候选，而不是事后教学案例。它的价值在于练习正确地保留 `PENDING`：官方文件给出了可追溯的募资调整、产能约束、订单背景和行业反方，但在 cutoff 时，项目仍待股东会批准，而且没有足以让客户/竞争反应分叉的 cohort。把它提前称为“扩产判断”或提前拒绝为“没有故事”，都会损失信息边界。

本卡不评价中信重工、管理层、耐磨材料、矿业周期或证券；也不读取 cutoff 后的结果期材料。

## 2. cutoff 前可使用的条件事实

原件拟调减面板盒体项目 `14,300.00` 万元，并终止此前尚未投入募集资金的高端耐磨智能化改造项目；计划把前者调减资金和后者余额合计 `29,952.92` 万元，投向拟设全资子公司的山西高端耐磨材料基地。新项目规划年产 `5` 万吨、建设期 `24` 个月、总投资 `94,335.00` 万元，其中其余资金由公司自筹。

同一原件称，现有 `3` 万吨/年耐磨衬板产能趋于饱和，2025 年耐磨衬板生效订货超过 `4.5` 万吨、同比增长 `13%`，2026 年上半年新增生效订货同比增长 `34%`；也称产品已出口澳洲和南美并与国内知名矿山企业有长期合作。它同时明确下游矿业投资放缓、原材料价格波动和项目建设进度会影响效益。

这些是候选的条件事实，不是中心路径支持。订单总量、出口地区、长期合作和产能趋紧没有定义受新基地影响的客户、产品、规格、订单、转换成本或对手回应；项目金额、设计产能和建设计划也不是未来客户、单位经济、现金或资本回收。

## 4. 反方没有被当前资料排除

```text
H-A：产能瓶颈、工艺和交付改善将使新基地获得可持续客户价值
获批并实施新基地
  -> 受限客户/产品完成认证、下单并获得更可靠交付
  -> 同一订单的价格、成本、交付与服务经济改善
  -> 订单现金覆盖营运资本和新增基地资本

H-B：矿业投资、材料价格和行业周期共同驱动订单与项目效果
矿业投资周期、原料价格、市场竞争与客户拓展
  -> 现有订单、新增订单和利用率均可能变化
  -> 即使订单增长，亦不能分配给新基地、工艺或交付改善
  -> 项目现金与资本回收仍待独立观察
```

现有订单增长、产能紧张和长期合作可同时满足 H-A、H-B 及“延续现有产能/不建设新基地”的简单基线。没有 `ASYMMETRIC` 或 `RIVAL_ACCOMMODATION_REQUIRED` 事实，也没有对同一未来 D2-D4 观察的不同预测；因此不得建立 future judgment 或将本案计入选择能力。

## 6. 对飞轮的约束

R-93 将“董事会方案”与“D1 已实施”分开，也将历史订单总量与新项目可归责客户反应分开。后续候选即使已有资金、产能和订单背景，也必须分别冻结 `approval_or_effective_date`、`implementation_receipt`、`affected_customer_product_cohort`、`rival_or_substitute_response`、`unit_economics_scope`、`cash_origin` 与 `capital_return_scope`；任何一项缺失都维持 `PENDING` 或 `NO_PRIMARY`，不以项目规模或预期收益填补。
