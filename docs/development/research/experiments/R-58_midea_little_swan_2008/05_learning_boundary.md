# R-58｜控制权与经营协同：学习边界与下一轮约束

状态：`BOUNDARY_TEACHING_COMPLETE / NOT_A_METHOD_WIN / REPLICATION_REQUIRED`。

## 与 R-56 的差异：这次不是缺产品表，而是缺因果拆分

R-56 的主要 D3 失败是产品成本/毛利缺失；R-58 在冻结前实际写入了同主体洗衣机收入、成本和毛利，结果也可同口径读取。这证明“把 R-56 暴露的字段强制写进下一张卡”有实际作用：它避免了把合并毛利或行业 ASP 误作产品经济。

但它没有验证一条完整的学习应用，更没有证明方法更准。R-58 同时暴露一个更高层的企业系统问题：控制权、组织分权、产品组合、园区产能、资产剥离、政策需求与现金管理能够共同改善表观业绩。即便产品表和现金桥都完整，仍可能无法把改善归给最初的控制权决策。

## 下一张“控制权—协同”卡必须怎样改变输入

| R-58 暴露的边界 | 下次冻结前的硬改变 | 未满足时的正确动作 |
|---|---|---|
| 控制权不是一体化 | D1 分别登记控制权、管理/系统迁移和真实流程接口，不把董事/股权变更当经营实施。 | 只结算 `CONTROL_OBSERVED`，不推协同。 |
| 经营改善可由多个共同原因产生 | 至少有一条 H-A 专属的采购、渠道、供应或客户交易观察，并与 H-C 宏观/政策/组合解释给出相反预期。 | `NO_PRIMARY` 或 `NOT_DIAGNOSTIC`，不强选机制。 |
| 产品经济也可能只是组合变化 | 同产品收入、成本、价格/单位或产品组合必须齐备，并明确哪些属于协同、哪些是产品重配。 | 仅记录产品经济方向，不归因。 |
| 正 OCF 可掩盖应收、应付和处置影响 | D4 必须同时登记经营性应收、存货、预付、客户预收、应付、其它应付和非现金/处置项；总 OCF 与营运资本箭头分开。 | 结算为 `MIXED`，不得称 owner cash 改善。 |
| 收购资本没有责任单元回报 | D5 必须有被收购/整合单元的资本投入、税后现金和真实替代路径。 | 永远保留 `CAPITAL_RETURN_UNKNOWN`。 |

## 对训练飞轮的真实贡献

本案不写入方法胜率或 LNOTE，因为它既不是 `SELECTION_ADMITTED`，也没有一个可结算的 H-A/H-B 主路径。它提供的是下一轮 case-selection 的负约束：若候选只有“控制后收入/毛利改善”，必须先停在 `NO_PRIMARY`；只有在 cutoff 前能找到一条机制专属、与宏观/组合反方可分叉的事实，才允许进入选择训练。

根因分类：`REASONING + MODEL`。改进不是添加更多案例卡或评分，而是使下一个进入训练飞轮的冻结合同真正改变：把决策、实施、客户、单位经济、现金和资本回收拆开，并让控制权协同与宏观/重配路径接受同样严格的可观察检验。
