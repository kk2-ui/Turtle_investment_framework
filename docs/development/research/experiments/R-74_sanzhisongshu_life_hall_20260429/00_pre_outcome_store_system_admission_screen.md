# R-74｜三只松鼠“生活馆”新店型：先有试点，不等于已经有可选择的零售系统判断

状态：`PRE_OUTCOME_ADMISSION_SCREEN / NO_PRIMARY / NOT_FROZEN / OUTCOME_BODY_UNREAD / NO_SELECTION_SCORE`。

R-74 是一次中国消费制造—零售接口的入场筛选，不是公司研究或对生活馆商业模式的结论。它专门检验一个常见误判：企业已经开出一批新店、提出产地直供／冷链／自有品牌和组织重构，是否就足以预测新店模型能带来客户采用、单位经济、现金和资本回收。答案是否定的。

## 1. 截止日前来源和可观察动作

只使用 CNINFO `relation` 的完整日期枚举和其唯一的 [2026-04-29 投资者关系活动记录](https://static.cninfo.com.cn/finalpage/2026-04-29/1225257544.PDF)。未读后续半年度报告正文、任何结果期经营材料、价格或投资回报。

该记录披露：公司在 2025 年孵化“生活馆”新店型，以平价社区超市定位，在皖南初步布局并持续调优，已有 33 家门店；它计划以“产地直供＋区域冷链＋自有品牌”支撑店型，并继续搭建标准化体系。记录也给出公司层面的 2026Q1 收入和利润，并称生活馆“市场反馈良好”。

这些是有价值的 D1 线索：一个实体新店型已经实际开出，且公司提出了相应的供给和组织安排。它们仍不是完整的管理决策合同。

## 2. 两张企业系统图，以及为何不能选主路径

| 层次 | H-A：试点可复制的社区零售系统 | H-B：局部试点／并发 package，尚未证明可复制经济 |
|---|---|---|
| D1 决策实施 | 小规模门店试点让产地直供、区域冷链和自有品牌可以共同缩短供给、改善商品结构。 | 33 家门店只表明 pilot 已发生；开店、选址、价格、商品、供应链和组织同时变化，资源量、授权、试点边界和停止权未知。 |
| D2 客户反应 | 同店交易、客单、复购、损耗或开业 cohort 随后改善，且可与未改造／新开门店区分。 | “市场反馈良好”只是发行人叙述；没有同店、交易、复购、覆盖社区或独立客户指标。 |
| D3 单位经济 | 自有品牌、采购、冷链损耗、店租人工、补贴和价格共同形成可重复的店级贡献。 | 公司级利润同时受线上电商、线下分销、年货节和其他产品／组织动作影响；不能归给生活馆。 |
| D4 现金转换 | 新店库存、供应商结算、预付／租赁及收款节奏可构成可追溯的现金桥。 | 公司级 CFO 和存货不能识别生活馆；试点还可能以总部存货、供应商账期或外部投入支撑。 |
| D5 资本回收 | 单店改造／开店资本、成熟 cohort 的税后现金和替代方案可比较。 | 33 店数量、后续加盟计划或集团资本开支均不等于试点资本回收。 |

截至截止日，没有哪一条非共同方向性事实能在 H-A 与 H-B 间作公平选择。既有 33 店与“反馈良好”可以同时符合两张图；公司级 Q1 利润则受多个已披露的业务与季节因素影响，不能作为 D2 或 D3 的代理。

结论：`NO_PRIMARY`。本卡不能冻结 H-A／H-B、不能建立选择基线，也不能把未来任何公司级业绩读作“生活馆验证”。

## 4. 这次停止如何改善下一轮输入

R-74 不是在说试点规模小就没有研究价值，而是把新店型的最小研究合同写清：

```text
试点门店／开业 cohort 与对照门店
  → 同店交易、客单、复购、损耗
  → 商品毛利 - 冷链损耗 - 店租人工 - 履约/营销补贴
  → 店级库存、AP、租赁和顾客收款
  → 单店增量资本与成熟 cohort 现金回收
```

下一个相近对象必须在**结果前**提供上述链条中的行动边界，至少一个客户／交易指标和一个店级经济或现金指标；若产品、价格、补贴、选址和供应链同步变化，只能结算 package，不得给某一项管理行动归因。它还必须有一个可行的反方和不同于简单延续的公平基线。

## 5. 根因、经济影响和停止条件

- **根因：** `DATA_COVERAGE + REASONING`。官方记录提供了事实性的试点存在，却没有责任单元经济与现金的结果合同；将管理层“反馈良好”当客户证据会把叙述误当数据。
- **经济影响：** 若把门店数或公司级利润归因于新店型，会材料性高估可复制销售、单位贡献、owner cash 和资本回收，也会把管理动作错误计入选择能力。
- **缺失事实：** 开店 cohort、D2 客户行为、D3 店级量价成本费用、D4 现金来源、D5 资本回收和 H-A/H-B 的非共同方向性依据。
- **禁止假设：** 门店数量、区域布局、全国供应链、公司级收入／利润／OCF、管理层反馈、未来加盟、品牌名气、价格或回报可以替代上述事实。
- **可执行处置：** 停止读取本案结果期，不新增研究模板；下一候选只从其 action 原件和同单元 D2–D4 公共结果通道同时可得的对象中选取。
- **验收：** 只有未来新卡在 cutoff 前已经冻结试点/对照、客户指标、店级经济/现金来源、资本边界、竞争反方及停止条件，才可从 `NO_PRIMARY` 升至 `SELECTION_ADMITTED`。
