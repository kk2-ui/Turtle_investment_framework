# R-47：1984–1991 冰箱技术与质量——为何不能用“后来只剩三家”来选择当时的机制？

## 身份与范围

`RESULT_KNOWN_TEACHING / S2_STATE_REPERTOIRE / COMMON_CONDITION_SCREEN / NO_INDIVIDUAL_COMPANY_VERDICT / NO_TURTLE_BACKTEST`

这不是海尔、上菱、扬子或万宝的成功史比较，更不回答后来谁留下。它只回答一个案前问题：在供给建立和快速扩张期，**引进先进线、强调工艺纪律和报告质量/效益改善，是否已足以作为某一家企业的可选择机制？** 同期原件显示答案是否定的。

## 同一状态下的并行事实

- 1986 年[《人民日报》对青岛电冰箱总厂的调查](https://www.rmrb.zhouenlai.info/人民日报（1946-2003）/1986/09/1986-09-08.htm)记录：1984 年与利勃海尔签约，引进 1,942 条 DIN 标准和关键设备，实行破坏性抽检；报道口径的返修率为 4.5‰，并有内外销订单。
- 1991 年[上菱报道](https://rmrb.zhouenlai.info/人民日报（1946-2003）/1991/06/1991-06-19.htm)记录：1985 年引进三菱制造技术和电脑控制工艺，随后消化、改造；报道同时给出产量、利润和同比增长。
- 同年[扬子报道](https://www.rmrb.zhouenlai.info/人民日报（1946-2003）/1991/09/1991-09-13.htm)记录：1985 年建厂时已有自动化程度高的引进线，并把工艺纪律、工人训练和质量意识列作管理动作；报道其 1990 年经济效益和 1991 年上半年增速。
- 1989 年[万宝报道](https://rmrb.zhouenlai.info/人民日报（1946-2003）/1989/02/1989-02-13.htm)还记录了相反状态：质量批评后停产整顿三个月、补充技术人员，报道说产品质量和用户信任恢复。

这些是当时不同公司的行动和新闻报道口径，不能直接横向比较返修率、利润或增长；它们足以证明的是：`先进技术/质量投入/早期效益` 并非一个仅由后来龙头拥有的稀缺解释。

## 正确的竞争机制空间

| | H-A：可迁移的组织吸收与质量—服务经济 | H-B：S2 的共同引进、短缺需求与报道口径足以解释早期表现 |
|---|---|---|
| 不可省略的链 | 标准/设备 → 同厂工艺与可靠性 → 用户选择、维修负担与渠道回款 → 周转/现金 → 在 S3 过剩后的再投资能力 | 技术线、行政资源、卖方市场和行业需求均可带来产量、利润或媒体认可；进入 S3 后才可能显出产品匹配、服务、渠道信用和资本纪律的分叉 |
| 本轮能结算什么 | 多家企业确有技术/质量动作，故它们是 S2 的共同或广泛可得条件 | 没有同定义的客户选择、故障/服务成本、应收/库存和现金，不可在此选择 H-A，也不可把 H-B 写成质量无关 |

因此，本轮只输出：

```text
TECHNICAL_IMPORT_AND_QUALITY_DISCIPLINE: COMMON_OR_WIDELY_AVAILABLE_S2_CONDITION
EARLY_REPORTED_QUALITY_AND_EFFICIENCY: NOT_CROSS_COMPANY_COMPARABLE
LATER_COMPETITIVE_SURVIVAL_EXPLANATION: NO_PRIMARY
```

## 这如何改变“早期家电竞争”的研究方式

不从“为什么只剩少数品牌”入手，而从一个可被反驳的状态问题入手：

```text
S2 共同技术/质量投入
→ 哪家将其变为可观察的可靠性与服务责任？
→ 供给转松后，哪家仍获得客户选择而非仅靠短缺？
→ 哪家在价格、渠道信用和库存压力下保有现金与再投资能力？
```

下一个家电 case 必须位于 S3，且至少有一项非共同事实（产品使用价值、服务责任、渠道合同/回款或资本约束）与同口径结果合同。否则不准用“技术引进”“砸冰箱”“质量意识”或后来存续来为某家公司挑选主机制。

## 本轮结论

`RETAIN_AND_NARROW / QUALITY_IMPORT_IS_NOT_A_SURVIVOR_EXPLANATION / STATE_BEFORE_HERO_STORY`

根因：`REASONING + DATA_COVERAGE`。若把后来存续反推为早期某家公司独有的技术/质量选择，会材料性误判企业的客户黏性、服务成本、营运资本和资本回收；若把多家同期技术引进看作完全无意义，也会错过它可能是必要但不充分的能力前提。缺失的是同定义的可靠性/服务成本、客户选择、渠道回款和 S3 现金表现。禁止用后来品牌地位、媒体赞誉、不可比返修率/利润、股价或回报补足。验收是下一张 S3 案在冻结前明确哪些 S2 条件为共同条件，并给出一个新的非共同的客户或现金分叉。
