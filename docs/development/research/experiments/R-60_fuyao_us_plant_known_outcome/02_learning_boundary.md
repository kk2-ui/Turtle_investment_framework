# R-60｜学习边界：跨境绿地建厂不能压缩成单一成功叙事

状态：`R38_CONSTRAINT_SUPPLEMENT / NOT_A_METHOD_WIN / NOT_AN_INDEPENDENT_REPLICATION`。

## 本案实际保留的约束

R-60 的有效产物不是“福耀美国项目好或坏”的结论，而是一个未来案例的输入约束：企业家式判断必须从资本动作开始，却不能停在资本动作。下一张相近卡的五层时钟要有不同的、可到期的责任单元证据。

| 本案暴露的断点 | 下一张冻结卡必须预先改变的字段 | 未满足时的动作 |
|---|---|---|
| 容量、投入和项目边界随时间演化 | 每次批准/扩建均登记范围、产能口径、预算、币种、实际投入和变更理由；任何一个不可映射，D5 停在 `MEASUREMENT_MISMATCH`。 | 仅记录资本实施，不计算超支率或资本回报。 |
| “支持 OEM/ARG”不是客户反应 | D2 只接受同主体客户认证、订单、交付、续单、份额或实际 sell-out 之一；写明 H-A/H-B 的相反预期和观察窗。 | `NO_PRIMARY`，不把管理层市场描述当机制选择依据。 |
| 收入与首年亏损解释不唯一 | D3 必须取得同厂量、价、成本和至少一个效率或固定成本驱动；单一收入/净利润只允许 `RAMP_OUTPUT_OBSERVED`。 | `NOT_DIAGNOSTIC`，不评价当地竞争力。 |
| 合并现金掩盖项目现金 | D4 必须有同厂营运资本和 OCF/现金税口径；集团 OCF只能标环境背景。 | `TARGET_CASH_UNKNOWN`。 |
| 大额资本支出无法衡量回收 | D5 必须有责任单元的投入资本、税后现金和预设资本回收窗口/替代路径。 | `CAPITAL_RETURN_UNKNOWN`，不以收入、EBIT、股价或集团 ROE 代替。 |

## 和先前教学案例的迁移关系

R-56 已显示产能和销量不能替代现金转化与资本回收；R-58 则显示控制权、组织调整和同产品毛利不能自动构成协同因果。R-60 把这两种限制带入跨境绿地建厂：即使目标责任实体已经出现收入和亏损，全球化建厂仍可能同时混合范围扩张、认证/客户、制造爬坡、融资、集团产品组合与区域经济环境。

这不是对任何公司的泛化结论，更不是“海外一定困难”。可迁移的仅是研究顺序：先辨认决策和实际执行的边界，再观察外部客户接口，再判断单位经济，最后才讨论现金与资本回收。

## 对训练飞轮的地位

本补充不可写入 selection-learning note，也不计为历史盲测、方法胜率或独立 replication。它与 R-38 合计只占**一次**已知结果教学。其作用是为不同公司的一次未来冻结提供待应用的约束。只有当下一家不同公司的截止日前卡明确列出 R-38/R-60 的引用、实际修改的 D2–D5 字段、反方和停止条件，并在结果期完成独立结算后，才能说该约束真正进入训练飞轮。

根因分类：`MODEL + REASONING`。如果只把这个案例归档为“海外扩张成功/失败”，训练得到的是结局记忆；如果把上述约束写进下一张卡，训练才可能改变研究者在结果前要求什么事实、拒绝什么代理、以及何时保留未知。
