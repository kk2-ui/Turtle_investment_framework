# R-31：TCL 2000 年 KPI 责任制——“制度存在”不等于“责任单元结果可归因”

状态：`RESULT_KNOWN_TEACHING / SOURCE_TIER_MISMATCH / NO_TURTLE_BACKTEST`

本筛选不评价 TCL 的总体经营史，也不评价 KPI 制度好坏。它服务于一个更窄的训练问题：**当公司清楚披露了责任书、考核、审计和奖惩，研究者能否据此判断分权或绩效制度改善了经营？**

答案是不能，除非能把每一项权责与同一责任单元的经济结果连接起来。

## 1. 可确认的组织制度，和它实际证明的内容

TCL 2004 年首次公开发行招股说明书回顾：集团自 2000 年 10 月导入 KPI 管理体系；集团总裁每年与被考核单位总经理签订经营目标责任书和奖惩条款；目标包括销售收入、利润总额、周转及管理指标；存在月度排名、中期述职、年终审计和按考核结果确定经营班子薪酬的流程。[TCL 招股说明书，第 162–163 页](https://static.cninfo.com.cn/finalpage/2004-01-05/16445545.PDF)

这足以确认以下内容：

| 字段 | 能否确认 | 可确认的最窄含义 |
|---|---|---|
| `accountability_unit` | 部分 | 主要事业部和子公司是考核对象。 |
| `incentive_and_exit` | 部分 | 收益与考核/述职挂钩；但未披露失败阈值、具体退出或替换记录。 |
| `result_measurement` | 是 | 销售、利润、周转及管理指标经内部审计、考评确定。 |
| `decision_right` | 否 | 文件没有逐项说明价格、采购、信用、预算、产品与用工由谁决定。 |
| `unit-to-metric mapping` | 否 | 文件没有列出某位总经理的责任书指标与某一份公开财务报表的一一对应。 |

所以它是“激励与考核制度存在”的一手原件，不是“分权已经提高经营质量”的证据。

## 2. 为什么看似充分的财务资料仍不能结算

同一招股书还列示了若干子公司的 2000–2002 年财务资料。例如，TCL 王牌电器（惠州）有收入、成本、营业利润和净利润序列；惠州 TCL 电器销售有限公司也有另一套收入、成本、费用、利润及资产负债表序列。[同文件，第 219–221 页](https://static.cninfo.com.cn/finalpage/2004-01-05/16445545.PDF)

但这不能生成“绩效责任制 → 单位经济/现金改善”的结论：

1. 招股书是在 2004 年发布，已经暴露 2000–2003 年结果；它不能被倒当作 2000 年的冻结前行动原件；
2. 制度适用于“主要事业部和子公司”，而财务表是若干制造或销售法人，二者没有一一映射；
3. 制造法人和销售法人分属不同经营环节。把二者相加或挑其中利润较好的一个，都不能代表一个负责人的完整量、价、费用、应收、库存与现金后果；
4. 目标含“销售、利润和周转”不等于相应负责人拥有调价、授信、采购、库存或资本开支的决策权；
5. 同期资料未披露两期、同一责任单元的经营现金或完整营运资本链，不能把利润变化升级为 owner-cash 改善。

这不是微小文件瑕疵。若把审计过的子公司利润直接归给 KPI 责任制，会混淆产品周期、销售与制造法人边界、业务组合和内部转移安排，进而高估管理系统带来的正常盈利与资本效率。

## 3. 两种竞争机制与本轮可结算性

| 机制 | 必须观察到的链 | 当前状态 |
|---|---|---|
| H-A：权责一致的经营单元提高资源配置 | 明确的决策权和预算/信用/价格边界 → 同一单元的量价、费用或周转改善 → 同一单元的现金或资本占用改善。 | `UNTESTABLE`：缺 unit-to-metric mapping 与同口径现金结果。 |
| H-B：考核制度只形成目标管理，结果主要由外部或其他单元决定 | 指标/薪酬存在，但权责不完整、生产与销售拆分，或结果与周期/产品/渠道的变化一致。 | `NOT_EXCLUDED`：现有材料无法排除。 |

因此，本卡不是 `OUTCOME_CONTRACTED_EPISODE`，也不应用于任何“组织能力已验证”或“判断准确率”统计。它是一个有用的反例：**看起来成熟的绩效制度与审计数据，仍可能缺少能裁决经营机制的最关键接缝。**

## 4. 对训练流程的新增约束

R-18 的组织四字段继续有效；R-31 追加一项不能省略的桥接：

```text
责任书/考核对象
  → 可核查的决策权（价格、采购、信用、预算、产品、人员中的至少两项）
  → 同名责任单元的损益与营运资本/现金口径
  → 两期可比的经济结果
```

`accountability_unit` 和公开法人财务表名称相似，不能视作完成了这条桥。必须由行动前的原件明确映射，或由同一时期的法定披露、董事会材料或可审计责任报表交叉确认。

## 5. 根因、边界与重新准入

- 根因：`DATA_COVERAGE + ACQUISITION_MODULE + REASONING`。现有一手文件覆盖了制度和部分法人结果，却没有可复核的“负责人—决策权—责任指标—公开结果”映射；而行动披露本身晚于结果期。
- 经济影响：若跳过此门槛，会把行业周期、销售/制造法人分工或会计边界造成的利润变化误归给组织设计，错误提高对正常盈利、现金转换和资本回报的判断。
- 禁止假设：KPI、责任书、内部审计、利润表存在，自动等于经理拥有相关决策权；一个法人利润表等于该经理的责任结果；或公司后来的规模/股价证明早期制度有效。
- 重新准入条件：在结果揭示前取得 (a) 至少两项被授予的 `decision_right`，(b) 负责人或责任书与公开/可审计经济单元的一一映射，(c) 两期同边界的收入/毛利或费用，加一项应收/库存/经营现金观察，(d) 与 H-A/H-B 不同顺序的冻结结果合同。

在此之前，下一轮应转向能从行动原件直接看到产品采用、客户选择或项目经济结果的创新能力候选；不继续堆叠“事业部制”公司史。
