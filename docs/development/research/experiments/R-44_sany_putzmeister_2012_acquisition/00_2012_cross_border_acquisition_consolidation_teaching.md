# R-44：三一 2012 年收购普茨迈斯特——全球收入增长，是协同还是合并范围？

## 身份与范围

`RESULT_KNOWN_TEACHING / CROSS_BORDER_ACQUISITION_BOUNDARY / CONSOLIDATION_VS_ECONOMIC_EFFECT / NO_DEAL_RETURN_OR_COMPANY_VERDICT`

本卡训练重资产制造业最易被名气、全球排名与合并收入遮蔽的问题：收购一个拥有技术、品牌和渠道的外国实体，何时真正改善客户、单位经济与可得现金，何时只是把原有海外业务并入报表？它不评价三一、普茨迈斯特、交易价格、管理层或证券。

## 交易时点、主张和竞争机制

2012 年 1 月的[交易公告/公司发布](https://www.sanygroup.com/news/725.html)显示，三一与中信产业基金签署协议收购普茨迈斯特 100% 股权；4 月交割后的[公司发布](https://www.sanygroup.com/news/807.html)称德国管理团队将负责中国以外混凝土机械业务整合，并给出 2012 年销售 7 亿欧元、2016 年 20 亿欧元的经营目标。三一 2012 年年报则将交易定义为获取产品组合、研发、国际运营、营销和服务能力的协同。

| | H-A：技术/渠道/组织的经济协同 | H-B：并表和行业周期主导，协同尚未被证明 |
|---|---|---|
| 传导 | 收购与保留的当地经营能力 → 客户/渠道与产品组合真正互补 → 同一混凝土机械单元的收入、成本/毛利、服务与回款改善 → 资本回收 | 海外收入在收购当年即可因并表增加；行业下行、汇率、融资、销售方式和原有被收购资产可同时改变集团数据，而不会产生协同或资本回收 |
| 当时可区分的未来观察 | 被收购实体或可比业务的独立订单/收入、毛利、服务、应收与现金优于其自身基线，且与收购的技术/渠道链相连 | 只有国际收入、排名、集团份额或公司对“开局良好”的解释；应收/融资扩大而实体经济结果不可拆分 |

交易目标、行业地位与公司对协同的表述都是主张，不是 H-A 的已验证选择证据。

## 已知经营观察与正确结算

三一[2012 年年报](https://vip.stock.finance.sina.com.cn/corp/view/vCB_AllBulletinDetail.php?id=1121106)称普茨迈斯特销售、利润等指标“明显改善”，但没有在公开年报中给出被收购实体的独立收入、毛利、服务成本、应收与现金表，因此这一句只能登记为 `ISSUER_OUTCOME_CLAIM`。

2013 年年报提供了更有诊断力、但仍不充分的共同结果：

- 国际地区收入同比增长 155.18%；
- 混凝土机械收入同比下降 2.53%，成本增长 7.63%，毛利率下降 6.07 个百分点；
- 应收账款同比增长 32.46%，年报明确归因于“合并普茨迈斯特转入及销售方式影响”；
- 财务费用同比增长 68.28%，年报归因于借款利息和汇兑损失增加；经营现金流增加被解释为销售回款较好和采购支出减少，而非普茨迈斯特现金贡献。

## 与 R-38 的交叉复验

R-38 的福耀美国项目要求“项目归属 × 经济阶段”：资本/在建工程与集团库存不能代替项目回收。R-44 在不同企业和交易形态中保留同一原则，并增加会计边界：

```text
交易/控制权取得
→ 合并范围与资产负债表变化
→ 被收购实体的客户/产品/服务经济
→ 同一责任单元现金与资本回收
```

第二步可以立即显著，第三、四步仍可能完全未知。全球排名、海外收入、资产并入、管理团队保留或一条管理层的“指标改善”都不能跨越这个断点。

## 对下一轮的约束

跨境并购卡在冻结前必须分别定位：

1. 交易现金、债务/承担义务、取得的控制权及独立实体；
2. 至少一项收购前可识别、收购后可同口径读取的实体级客户/经营指标；
3. 实体级或可隔离的应收、库存、服务负担和经营现金；
4. 把合并范围、会计重估、汇率、融资及行业周期列为独立替代机制。

不能满足第 2–3 项时，仅能结算 `CONSOLIDATION_OBSERVED`，不得作“协同/国际化/资本配置成功或失败”的判断。

## 本轮结论

`RETAIN_AND_NARROW / CONSOLIDATION_IS_NOT_SYNERGY / ENTITY_CASH_REQUIRED_FOR_DEAL_JUDGMENT`

根因：`DATA_COVERAGE + REASONING`。若把海外收入、全球排名、合并资产或管理层对利润改善的叙述当作协同，会材料性误判交易的正常盈利、现金承受力和资本回报；若把整体毛利下降或利息增加直接判作交易失败，也会把行业下行与融资环境误归给并购。缺失的是被收购实体的连续收入、单位经济、服务、应收/库存、现金和资本占用。禁止以并表规模、品牌声誉、公司目标、总 OCF、价格或回报补足。验收是下一张跨境并购卡拥有该实体的收购前后同口径经营与现金合同；否则只保留本卡的合并边界。
