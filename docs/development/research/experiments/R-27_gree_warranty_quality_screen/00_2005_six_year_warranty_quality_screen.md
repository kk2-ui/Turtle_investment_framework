# R-27：格力 2005 年六年免费包修——质量/服务策略的边界筛查

状态：`SOURCE_SCREEN / RESULT_KNOWN_TEACHING / GREE_PRESSURE_TEST / NO_MANAGER_VERDICT`。

格力在这里仍只是压力测试，不是训练中心。这个对象的价值在于：它有清楚的服务承诺和连续法定报表，却仍不足以把“更长保修”写成质量能力或经济优势已经验证。

## 可读的动作和结果

- 2005-03 的当时报道记载，格力自 2005-01-01 起对新购家用空调实行整机六年免费包修；此前行业整机包修最长约三年。[同期报道](https://finance.sina.cn/sa/2005-03-15/detail-ikkntiak8828825.d.html)
- [2005 年年报](https://finance.sina.com.cn/stock/company/sz/000651/9_11.shtml) 也记录这一动作：空调收入 176.26 亿元、毛利率 18.62%，同比提升 2.17 个百分点；但只把维修费与运输、租赁、佣金、广告并列为随销售增长的营业费用，未给质保成本、返修率或服务单元利润。
- [2006 年年报](https://finance.sina.com.cn/stock/company/sz/000651/9_12.shtml) 显示空调收入 231.14 亿元、毛利率 18.23%（同比 -0.39 个百分点）；年末“预计售后服务费”余额 8,978 万元，说明来自历史售后服务费及销量增长的估计。该余额不是 2005 的维修费，也不是每台真实保修成本。
- 2007 年一份市场评论称美的、志高、海尔等随后给出相近或更长承诺；它只能作为“可能存在竞争跟随”的候选线索，不能替代同口径行业服务成本或客户选择数据。[材料](https://finance.sina.cn/page/aHR0cDovL2ZpbmFuY2Uuc2luYS5jb20uY24vc3RvY2svY29tcGFueXJlc2VhcmNoLzIwMDcwNTE2LzE4MDQzNTk5MTQ0LnNodG1s?from=redirect)

## 为什么不能据此结算“质量取胜”

| 所需机制箭头 | 当前可见 | 缺失/口径问题 | 不能偷换成 |
|---|---|---|---|
| `quality_control → lower_failure_rate` | 公司公开承诺承担更长保修。 | 没有同产品、同期间返修率、故障率、索赔频次或独立质量观察。 | 获奖、技术项目数、服务口号。 |
| `warranty → customer/channel_choice` | 空调收入增长。 | 购机客户为何选择、渠道转化、同业相对价格/服务和竞争者跟随的原始连续数据均缺。 | 总收入或后来份额。 |
| `service_commitment → unit_economics` | 2005–2006 可见产品毛利率和一些维修/预计服务费项目。 | 2005 的维修费、2006 的预计售后服务费余额不是同一会计指标；没有按销量摊销的保修成本。 | 毛利率、营业费用或期末预计负债的单值。 |
| `service_cost → owner_cash` | 合并 OCF有披露。 | OCF同时受销售、库存、预付等影响，未拆出服务政策的现金影响。 | 年末现金、总 OCF、融资。 |

## 冻结后能够保留的最窄结论

六年包修是一项可见、并且会暴露公司未来服务负担的客户承诺；它不能在现有材料下被定性为“质量已经更高”“客户因此选择格力”“服务承诺创造了利润”，也不能被定性为“成本失控”。2005–2006 收入增长、毛利率小幅变化都与产能、渠道、产品、行业成本和整体竞争同时变化。

质量/服务卡要进入企业判断训练，最低需要下列可分离的结果合同：

```text
质量/可靠性投入或服务承诺
→ 同产品故障/返修或服务需求
→ 每台保修/服务成本和责任准备
→ 客户/渠道的价格实现、复购或转换
→ 营运资本与现金后果
```

R-27 的作用是把“六年包修”放到这条链的第一格，而不是把它作为整条链的证据。它也提醒下一次质量候选优先寻找监管抽检、保修索赔、售后网点维修订单、同产品服务准备和渠道/价格实现的连续原件；没有这些，正确产出是 `NO_PRIMARY`。

根因：`DATA_COVERAGE + ACQUISITION_MODULE + REASONING`。法定报告拥有收入、毛利与总现金，却没有按产品/保修期的真实故障、服务成本和客户转换口径；把不同时点、不同定义的维修费和预计服务费硬拼，会把一个顾客承诺虚构为质量和 owner-cash 机制。经济影响是高估品牌/服务投资的正常盈利，或反过来高估长期保修的负债风险。禁止用公司自述、奖项、营收增长、行业后来集中度、价格或回报填补。

验收：下一张质量/服务卡要在 cutoff 前锁定实际承诺与至少一种故障/服务成本度量，并在结果期以同定义的客户选择或价格实现及现金指标结算；若只找到宣传和总财务，保留 source screen，不扩大格力材料池。
