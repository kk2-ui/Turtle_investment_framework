# R-30：2011 年海尔电器售后服务平台——质量/服务双臂筛查

状态：`SOURCE_SCREEN / RESULT_KNOWN_TEACHING / MEASUREMENT_MISMATCH / NO_MANAGER_VERDICT`。

这不是“海尔质量或服务成功”的结论，而是一张高价值的质量/服务取证筛查。它第一次同时找到了实际服务网络承诺、以维修/退货经验估计的保修准备、服务网络规模、服务收入和费用方向；也第一次清楚展示了为什么这些材料仍不能被拼成“售后服务创造了产品护城河”。

## 1. 可读的行动与两条臂

- 2011 年，海尔电器以人民币 2.4 亿元取得青岛日日顺电器服务 100% 权益；目标公司主营家电售后与消费者增值服务。公司将其纳入渠道综合服务，明确把售后网络定位为三大核心网络之一，并披露 5 个呼叫中心、约 8,000 个服务中心及近 10,000 个县乡服务站。[2011 年年报](https://www.hkexnews.hk/listedco/listconews/sehk/2012/0426/ltn20120426409.pdf)，第 11、35、61、71、74 页。
- 同一报告披露洗衣机、热水器提供 1–6 年安装/保修，问题产品可维修或更换；准备金按销量及过往安装、维修、退货经验估计。2011 年新增准备 7.924 亿元、实际动用 5.445 亿元，年末余额 6.914 亿元。[2011 年年报](https://www.hkexnews.hk/listedco/listconews/sehk/2012/0426/ltn20120426409.pdf)，第 133、142、186 页。

这使下列两臂各有一个真实入口：

```text
售后网络/保修承诺
  → 安装、维修、退换等服务需求
  → 准备金/实际动用的服务责任

售后网络/保修承诺
  → 客户或第三方厂商选择服务网络
  → 服务收入、价格或留存
```

但两条臂的经济主体并不相同：准备金属于洗衣机/热水器产品保修，服务网络也为渠道加盟商和第三方厂商提供服务。若不先隔开，后续任何“质量带来服务收入”都只是跨主体拼接。

2012 年年报可见：

## 3. 阻断本卡成为双臂 episode 的事实

1. **合并边界不可作 before/after。** 收购的服务实体与上市公司此前同受海尔集团控制，2011 年报采用共同控制下合并会计，2010–2011 的合并利润、现金流已仿佛该架构一直存在而重述。服务收入比较不能作为收购前后独立效果。[2011 年年报](https://www.hkexnews.hk/listedco/listconews/sehk/2012/0426/ltn20120426409.pdf)，第 99–100 页。
2. **服务收入与产品质量不是同一主体/同一指标。** 2012 年的 10.559 亿元把售后与电商合并；2.186 亿元为关联方交易。服务网点、第三方厂商数和线上“优秀”评价不能替代产品客户的复购、退换、价格或渠道留存。
3. **保修准备金不是可靠性率。** 它包含安装、保修、销量、维修和退货的估计，且准备/动用额没有以同产品销量、同保修代际或单台成本拆分。公司对“质量改善使售后成本下降”的说法是解释，不是独立的故障率观察。
4. **资本和现金仍跨边界。** 渠道综合服务同时含分销、物流、服务、电商和关联交易；总 OCF、毛利率或年末现金都不能回答服务收购的资本回收。

## 4. 复盘与下一张卡的硬条件

根因：`DATA_COVERAGE + ACQUISITION_MODULE + REASONING`。旧研究会因本案信息丰富而将服务网络、质量、第三方厂商、保修准备、费用率和增长收入连成故事；实际可见的会计重述、业务边界和计量混合足以使该故事改变正常盈利、owner cash与资本配置的判断。禁止以奖项、线上评分、网点数、总服务收入、费用率、公司解释、后来的品牌位置、价格或回报补足。

本卡的正确输出是：`QUALITY_SERVICE_ROUTE_PARTIALLY_OBSERVED / NOT_A_PRODUCT_QUALITY_MOAT_TEST`。下一张合格质量/服务卡必须在同一个经济主体内拥有：

1. 当期服务/保修或质量资源承诺；
2. 同产品、同保修代际的故障/返修/索赔或服务工单率；
3. 同口径的每台服务成本、准备和实际支付；
4. 同产品的价格实现、复购、退换或渠道留存；
5. 未被并购/重述或业务合并破坏的结果窗口。

少任何一项，保留为 `SOURCE_SCREEN` 或 `BOUNDARY_ONLY`，不再用“服务重要”或“海尔成功”扩读公司史。
