# R-95｜国瓷材料 2026 氧化锆粉体调价：有生效日的价格决定仍不能替代同一交易链

状态：`PRE_OUTCOME_ADMISSION_SCREEN / NO_PRIMARY / NOT_FROZEN / NO_SELECTION_SCORE / OUTCOME_BODY_UNREAD`。

R-95 检验一项边界更接近可选管理动作的公告：国瓷材料公开决定自 2026 年 7 月 27 日起将氧化锆粉体售价上调约 `10%–40%`。这不是“动态关注市场”的程序表述，公告给出了产品、幅度和未来生效日；但在 cutoff 时，执行尚未发生，而且原件不能把产品范围接到客户、实际价格和数量、原材料成本、订单现金或资本责任单元。因此不能把拟生效的调价写成定价权、利润改善或企业判断正确。

本卡不评价国瓷材料、氧化锆市场、管理层或其证券。未读取 cutoff 后经营结果、价格、估值或回报。

## 1. cutoff 与来源边界

- cutoff：`2026-07-21T00:00:00+08:00`。CNINFO 的公告元数据只提供日期、没有可靠的同日时分；原来的 `2026-07-20T23:59:59+08:00` 因此不能准入该公告。将 cutoff 明确移至翌日零点后重新完整枚举，并确认 7 月 20 日只有本公告、7 月 21 日没有普通公告；这保留了“7 月 20 日全部公开资料均在冻结集内”的边界，不伪造盘中决策时点。
- 普通公告 inventory：CNINFO `300285 / 9900021557`，`fulltext`，`2025-01-01` 至 `2026-07-21`，全量 `247` 条、`9` 页。
- 投资者关系 activity inventory：同一证券、组织与日期边界，CNINFO `relation`，全量 `10` 条、`1` 页。
- 仅阅读三份 cutoff 前的法定披露：
  - [2025 年年度报告](https://static.cninfo.com.cn/finalpage/2026-04-21/1225126921.PDF)，公告 ID `1225126921`；
  - [2026 年第一季度报告](https://static.cninfo.com.cn/finalpage/2026-04-28/1225202237.PDF)，公告 ID `1225202237`；
  - [关于公司氧化锆粉体价格调整的公告](https://static.cninfo.com.cn/finalpage/2026-07-20/1225431974.PDF)，公告 ID `1225431974`。

公告本身称氧化锆粉体生产原辅材料价格持续上涨，公司决定自 7 月 27 日起提高氧化锆粉体销售价格，幅度约 `10%–40%`；同时明确销量影响和新价格持续时间仍不确定（调价公告 p.1）。这提供了成本冲击下的正式价格决定，不能提供执行结果。

## 2. D1–D5 不能被合并为一个价格权结论

| 时钟 | cutoff 前可确认的事实 | 不能跨越的边界 |
|---|---|---|
| D1 决策／实施 | 公司正式公告了产品、幅度和 `2026-07-27` 的生效安排。 | cutoff 是 7 月 21 日，执行日仍在未来；没有已执行报价、受影响 SKU、地区、客户、旧价、折扣规则、授权资源或回转记录。它是 `DATED_PRICE_DECISION_PENDING_EFFECTIVENESS`，不是已观察到的实际价格 package。 |
| D2 客户／竞争反应 | 调价公告提示销量影响不确定。年报显示公司主要以直销销售（2025 年直销占收入 `92.70%`，年报 p.30），并列示了多个包含氧化锆相关材料的业务和用途。 | 没有出厂客户、渠道库存或终端 cohort；没有报价接受、补货、交付、复购、客户替代或竞争者跟进。不同业务中的“氧化锆”不能被假设为公告所称同一粉体、同一客户或同一价格动作。 |
| D3 单位经济 | 年报仅到板块：电子材料、生物医疗和精密陶瓷 2025 年收入分别为 `6.93`、`9.30`、`4.17` 亿元，且毛利率／成本变化不同（年报 pp.30–31）。 | 没有受调粉体的调价前后实际价格、销量、折扣、产品组合、原辅料成本或加工费用。板块全年收入、成本和实物销量也跨越多个产品，不能成为调价的价格—数量—成本桥。 |
| D4 营运资本／现金 | 2026Q1 合并报表显示预付原材料款增加至 `1.80` 亿元；销售收现为 `10.67` 亿元，采购付现为 `6.09` 亿元（Q1 pp.3、11–12）。 | 这些均发生在 7 月 27 日前，且是全集团现金流；没有受调粉体订单的应收、库存、预付、应付或收现路径。既不能把 Q1 的原材料预付当作本次调价原因，也不能把集团收现当作客户接受。 |
| D5 资本回收 | 2026Q1 的购建长期资产现金支出为 `1.67` 亿元（Q1 p.12）。 | 调价公告没有增量资本、维护资本、责任单元、替代用途、停止权或税后现金回收定义。集团资本开支不能自然归给一个尚未实施的价格决定。 |

## 3. 在 cutoff 时，两条完整解释没有可检验分叉

```text
H-A：公司将原辅料压力有效转嫁给受影响粉体客户
明确产品与价格 package 在 7 月 27 日执行
  -> 具名客户／渠道接受新报价并持续采购
  -> 同一 SKU 的实现价格超过数量、折扣和同一原辅料成本压力
  -> 同一订单的营运资本转化为经营现金
  -> 与粉体供应能力相关的增量资本得到回收

H-B：外部原料和需求状态决定，公告不足以表明客户吸收
原辅料上涨和不确定的市场供需
  -> 实际售价、销量和客户采购时点共同变化，客户可延后或改换来源
  -> 板块与集团毛利还受其他氧化锆用途、产品组合和成本共同驱动
  -> 库存、预付和应收先吸收现金，资本回收仍不可归属
```

两条解释都预期公司会发布调价公告，也都可容纳 `10%–40%` 的拟议幅度。没有 cohort、同产品观察或实际执行，H-A、H-B 和“成本冲击下不作公司特有判断”的简单基线对任何可预注册 D2–D4 指标都不能给出不同预测。故不能以管理层“预计积极影响”的陈述选择 H-A。

## 4. 准入裁决与停止条件

- **根因：** `DATA_COVERAGE + REASONING`。官方双入口 inventory 和三份最小法定材料均已完成；缺口不是继续找更多行业叙事，而是调价公告没有同一交易链的实际执行、客户、单位经济、现金和资本事实。把板块或集团合计表连接到“氧化锆粉体”会是归因错误。
- **经济影响：** 若将公告幅度或“积极影响”表述视作价格权，会材料性高估成本冲击下的正常利润与客户留存，并可能把原料预付、库存和集团现金误判为可回收的现金转换；若反过来用后来的板块毛利变化判定失败，也会犯同一归因错误。
- **缺失事实：** 实际执行的 SKU／客户／区域价格 package；调价前后实现价格、数量、折扣和同一原辅料／加工成本；出厂客户、渠道库存与终端 cohort 的接受／替代／竞争回应；该订单的营运资本和收现；相应资本范围、替代用途和回收口径。
- **禁止假设：** 公告生效安排、`10%–40%` 幅度、管理层的积极影响预期、直销比例、板块收入／毛利／销量、Q1 原材料预付和集团经营现金／资本开支可以替代上述事实。
- **可执行处置：** 关闭 `R-95 / NO_PRIMARY / NOT_FROZEN`，不建立 future judgment、简单基线、结果合同、控制面反馈项目或方法复制任务。也不设置仅等待 7 月 27 日的 condition inbox：即使日后证实生效，当前公开材料仍没有 D2–D5 的可诊断观察通道。
- **重新准入条件：** 只能以一个新的 cutoff、独立的官方一手材料证明已执行且可界定的产品—客户/渠道 action package，并在结果前冻结同产品量价成本、订单现金、资本边界及 H-A/H-B/简单基线的不同预测；否则继续保持 `NO_PRIMARY`。

## 5. 对训练飞轮的实际约束

R-95 将“具有公告日期、产品名称、幅度和生效日的调价”与“可评估的企业判断”进一步分开。相比 R-90 的动态响应，本案已经更接近 D1；但一项尚未生效且跨多个材料用途的价格决定仍不能跳过客户 cohort 与同一交易链。下一候选继续优先找已执行、可停止的产品、渠道、组织或信用治理动作；在读集团财务之前，先确认它能产生与最强反方不同的客户和竞争观察。
