# R-79｜TCL–Thomson 2004 全球电视合并：有行动原件，但尚不能把规模叙事升级为企业判断

状态：`PRE_OUTCOME_ADMISSION_SCREEN / NO_PRIMARY / NOT_FROZEN / NO_SELECTION_SCORE / OUTCOME_BODY_UNREAD`。

R-79 检验一个比“某公司后来是否成功”更窄的问题：2004 年 TCL 把自身和 Thomson 的电视业务与资产放入 TTE 的决定，能否在结果前被研究为一条完整的企业系统判断。它不评价 TCL、Thomson、TTE 或其证券；也不使用任何 2004 年中报、年报或后续经营结果。

结论是**停止在结果前筛选**。当时的交易文件证明了一个清晰、重大且有条件的管理行动，但当前可读取的原件不能将该行动接到同一责任主体的客户／竞争反应、单位经济、营运资本现金和资本回收。因此，不能把“全球规模、研发、生产和经销网络”当作方向性选择依据，不能冻结 H-A 胜出，也不能构造公平、可结算的选择基线。

## 2. 可写出的竞争机制，及为何尚不能选择其中一条

当前材料允许提出、但不能选择的两张机制图是：

```text
H-A（规模与互补能力）
TCL 的海外增长 + Thomson 的海外制造／研发／经销资产
  → TTE 在独立治理下整合全球供给与市场接口
  → 更好的客户覆盖、产品／成本协同和现金周转

H-B（规模掩盖的责任单元与经济压力）
成熟电视业务、跨国交接、条件审批和外部贸易限制
  → 资产／组织复杂度或价格压力超过协同
  → 客户、单位经济和现金不能随规模改善
```

它们解释的是同一项管理决定，却都仍兼容当前事实：TCL 的既有海外销量增长既可能是 H-A 的能力基础，也可能只是合并前独立业务；多媒体毛利率下行和美国贸易风险既提示 H-B 的脆弱性，也不能证明 TTE 一定失败。交易公告称会形成长期竞争优势，是当时的管理层／交易方主张，不是 H-A 的验证事实。

公平基线也不能成立。年度报告中的 2004 销量目标明确排除了 Thomson 合资，但它是 TCL 集团自己的销量计划，非 TTE 的同口径客户、价格、成本或现金反事实。把它写成“无合并基线”，会把实体范围、资产边界与客户渠道混为一谈。

## 4. 停止判断

- **根因：** `DATA_COVERAGE + REASONING`。现有一手材料覆盖行动与 TCL 的事前状态，却没有公开、同实体的 D2–D5 计量合同；若用集团销量、毛利或现金将其补齐，会另行引入范围错误。
- **经济影响：** 把全球规模与后续企业质量直接相连，会把跨国交割、客户接受、渠道／价格、整合成本、营运资本和资本可达性压成一个“并购成功／失败”判断，进而错误影响正常盈利、owner cash 与永久损失推断。
- **缺失事实：** TTE 责任单元的实施确认、客户／竞争观察、量价成本桥、营运资本现金来源以及 TCL 普通股资本回收边界。
- **禁止假设：** 交易公告的“长期竞争优势”就是选择依据；合并前 TCL 海外销量或集团经营现金代表 TTE；全集团／多媒体毛利率代表合资单位经济；“不考虑合资”的销量目标是可用反事实；后来经营结果可倒灌补写这些合同。
- **可执行处置：** 关闭 R-79，保持任何结果期正文未读。只有在打开结果期材料**之前**取得一套结果前的 TTE 责任单元度量／传输合同，能同时定义 H-A、H-B、不同于持续基线的同指标预测和 D1–D5 停止条件，才可重新进入历史教学冻结。缺失时不补读结果，也不把它登记为选择训练样本。
- **接纳标准：** 至少一条非共同方向性结果前事实支持主路径而反对最强反方；D2、D3、D4 均有同主体／同口径未来测量来源；D1 交割与运营实施分开到期；D5 明确普通股回收范围。满足前，本案只能保留为“行动可见但企业判断未准入”的反例。

## 5. 对训练飞轮的作用

R-79 不是失败的研究，也不是可计分的判断。它把一个极容易被写成“全球化并购故事”的中国制造素材，保留为一条硬边界：**重大决策、规模和董事会控制权均不自动产生企业判断；只有客户、单位经济、现金与资本回收在同一责任单元连续可测，才有资格训练选择能力。**
