# R-35：中国有赞 2019–2020 按交易收费：产品货币化而非创新能力

**状态**：`RESULT_KNOWN_TEACHING / FEE_MECHANICS_OBSERVED / RETENTION_UNKNOWN / NO_CAPABILITY_CONCLUSION / NO_TURTLE_BACKTEST`

**本卡训练的问题**：在商户 SaaS 中，把固定订阅之外的交易量超额部分改为按交易收云服务费，何时可捕获更高的客户使用价值并改善产品毛利，何时只是价格机制、商户构成与外部需求共同造成的表象？

本卡不是对有赞、SaaS、私域流量或管理层的判断，更不是投资结论。行动与结果都已经公开可知，故只能作历史教学，不能计入前瞻准确率。

## 1. 状态与实际选择

| 项目 | cutoff 前可确认的内容 | 证据与边界 |
|---|---|---|
| 时代状态 | S5：零售数字化与平台服务化；但不能把行业趋势写成客户愿意长期为某一平台加价。 | [中国有赞2019年报，p.9](https://www.hkexnews.hk/listedco/listconews/gem/2020/0331/2020033100021.pdf) 描述门店 SaaS 仍处于产品更新与货币化并行阶段。 |
| 实际资源/定价选择 | 2019年7月起，对 SaaS 合同中规定免费订单数以外的订单收取 cloud service fee。 | 同上，p.9。它是一个**收入/定价机制选择**，不是新技术、客户留存或服务改善本身。 |
| 经营替代 | 维持固定订阅（或不对超额订单收费），把规模价值留给商户以换取采用/续费。 | 这是根据已披露的收费结构推导出的当时可行替代，不是公司披露的管理层反事实。 |
| 成本/现金机制 | SaaS 服务由公司负责提供并支付服务器托管费；多数付费商户签1–3年合同、预付订阅费，云服务费可预付或按需付；渠道佣金为获取合同的增量成本。 | [2019年报，p.183–184](https://www.hkexnews.hk/listedco/listconews/gem/2020/0331/2020033100021.pdf)。这说明收入确认、获客成本和现金时点不可互换。 |

## 2. 竞争机制叉

| 机制 | 可观察传导 | 反证方向 |
|---|---|---|
| H-A：价值捕获/可扩张服务 | 商户交易量增加时愿意支付超额费用；`paid merchant stock + ARPU + subscription gross margin` 同向改善，且主要服务成本增长慢于收入。 | 同定义的留存/续约、商户交易量或定价承受力恶化；或成本与获客投入吞噬增量毛利。 |
| H-B：价格与环境/构成 | 收费本身、商户结构升级、疫情下线上化和产品构成即可提高 ARPU/毛利；年末付费商户存量不说明既有商户接受价格、更不说明续费或客户经济改善。 | 同 cohort 的付费/续约、真实流失、产品级成本与收费关系显示改善并非来自构成/外部需求。 |

两条机制都允许收入和毛利上升。真正的区分必须是同一商户 cohort 的续约/流失、产品/收费归属和服务/获客成本，而不是 GMV、总客户数、总收入或后来名气。

## 3. 已知结果只结算到哪一箭头

2020 年年报给出如下相同业务标签的观察：订阅解决方案收入由约5.936亿元升至10.480亿元；购买 SaaS 产品的付费商户年末数量由82,343升至97,158；每商户订阅解决方案平均收入由7,208.4元升至10,786.0元；该解决方案毛利率由64.2%升至76.0%。公司将毛利率改善归因于每商户收入提高及相关主要成本未同幅增加。[2020年报，p.19–22](https://www.hkexnews.hk/listedco/listconews/gem/2021/0331/2021033100045.pdf)

这足以形成一个窄观察：

```text
变量收费已实施
→ 订阅解决方案的付费商户年末存量、ARPU 与分部毛利率同向提高
→ 与“该收费在短期改善产品货币化/毛利”一致
```

但不能越过以下边界：

| 不能结算的箭头 | 原因 |
|---|---|
| `既有商户愿意续费/长期接受收费` | 82,343与97,158是两个时点的付费商户存量，不是同 cohort 的 renewed、churned 或 retained 定义。 |
| `收费提高了商户自身经营结果` | 公司披露商户 GMV/付费商户数量，但没有同 cohort 的商户利润、复购或流失反事实。 |
| `变量收费是 ARPU/毛利改善的唯一原因` | 2020年同时有疫情推动线下商户数字化、公司减免部分软件服务费、商户结构/产品组合变化；收费机制还会直接影响 ARPU。 |
| `产品经济已成为 owner cash` | 年报确认服务器、渠道佣金与合约成本的边界，但没有该产品的完整获客、研发、服务现金和资本占用序列；集团 OCF 含其他业务和营运资本。 |
| `公司有可迁移创新能力` | 未见“某一客户/成本反馈 → 明确修改、扩大或停止的下一次资源选择”，更没有独立第二条产品/客户链。 |

## 4. 对训练方法的实际更新

R-34 的“有赞最接近完整链”判断需要收紧为：**它是目前最好的产品货币化教学例，而不是创新能力候选。**

新增的判断纪律是：

```text
pricing rule changed
≠ customer adoption or retention
≠ customer value creation
≠ owner cash
≠ repeatable innovation capability
```

如果未来选取同类订阅案例，结果合同至少应分别预注册：

1. 同 cohort 的 `renewed / churned / retained`，而非期末付费商户存量；
2. 同一合同/产品的固定订阅、变量收费、折扣与收入确认；
3. 托管、交付、客服、渠道获客和合同现金的经济边界；
4. 一项由客户/成本反馈触发的、后来实际发生的产品或资源选择。

## 5. 审阅结论

**根因分类**：`DATA_COVERAGE + REASONING`。披露足够说明收费机制、产品级收入/毛利及若干成本责任，却没有同 cohort 留存、客户收益或完整产品现金。若把这些数字写为留存、客户价值、创新能力或 owner cash，长期会高估定价权、正常盈利与资本回报。

**禁止假设**：付费商户期末存量等于续费；ARPU 上升等于客户价值；疫情中的线上化等于产品优势；产品毛利等于可分配现金；收费改动等于组织学习。

**接纳标准**：本卡可保留为 `PRODUCT_MONETIZATION_MECHANICS_OBSERVED` 的历史教学链；只有取得同 cohort 留存、收费/成本与合同现金的同定义结果，并观察到反馈后的独立资源选择，才可重开更高层的采用或能力问题。
