# R-02 红队

状态：`PRE_OUTCOME_RED_TEAM_COMPLETE`。

红队攻击的是把可观察的交易事件或日后总结果偷换为经济判断的做法。

- “交割/控股”只能说明行动链的条件在某种范围内得到满足；它不证明客户、人才、技术、渠道或物流传导。
- “并表后的收入或利润变化”也不能自动支持 H-A：要约文件本身列出机器人、制造、物流三类不同路径，且 KUKA 原有客户、行业周期、既有管理和会计合并均是竞争解释。
- “管理层说要支持独立性”是意图；管理团队、客户购买意向与核心人员稳定在截止日都未被验证。把这种语言当早期经营信号，是用主张验证主张。
- “公司现金很多”同样不能关闭融资承受力问题：FY2015 年报中的货币资金含受限资金，而要约文件又说最终借款结构和财务费用无法量化。
- 从后续报道或任何证券回报倒推一个 2016 年经济预测，属于结果泄漏。本轮只允许结算行动状态；若未来要研究协同，必须换到当时已承诺、可量化且可归属的资本配置事件。

红队放行条件：两份来源卡均把 `FACT`、`ACTION_PLAN`、`MANAGEMENT_CAUSAL_CLAIM` 与 `UNKNOWN` 分开；经济机制没有被伪造为前瞻判断。
