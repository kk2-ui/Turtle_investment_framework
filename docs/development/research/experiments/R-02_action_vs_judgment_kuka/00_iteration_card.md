# R-02 迭代卡：行动实施与经济判断分离

状态：`CLOSED / RETAIN_WITH_FAIL_FAST_GATE / REPLICATION_REQUIRED`  
研究性质：历史 PIT 方法实验；不构成关于美的、库卡或机器人行业的投资结论。

反馈等级：`HISTORICAL_SELF_REPLAY`。该交易结果可能已为研究者或模型所知，因此它只验证行动—经济判断的流程闸门，绝不计入 Turtle 自身预测准确率、校准或独立经验样本。

## 方法假设

- 当前研究方法的盲点：把“管理层完成了一项收购/投资动作”当成“其经济判断已被证实”，或反过来用后续经营结果否定当时动作的执行质量。
- 拟检验的方法步骤：为同一资本配置事件建立两条不可互相替代的链：
  1. `行动链`：授权/要约 → 融资/监管 → 交割/控制权；
  2. `经济判断链`：被收购资产的可迁移能力 → 整合/客户/产品传导 → 可观察经营结果。
- 本轮训练的判断能力：`问题界定 / 机制辨别 / 校正`。
- 实验完成后应新增作出的区分：一项行动可以按承诺完成，而它所依赖的经济机制仍可能未成立、部分成立或尚未到期。
- 预期避免的材料性经济错误：以收购交割、董事会决议、融资完成或管理层语言替代对正常盈利、owner cash、资本配置回报或永久损失的判断。
- 经济边界：`资本配置 / 正常盈利 / 永久损失`。
- 不成立时应看到什么：前述两条链无法从当时文件写出不同观察，或结果期只能给出同一、不可诊断的事实。届时裁决为 `INSUFFICIENT_TEST`，不硬造因果。

## 有界实验

- 实验对象：美的集团对 KUKA Aktiengesellschaft 的要约收购；暂定 PIT cutoff 为 `2016-06-02T00:00:00+08:00`，仅因 2016-06-01 已发布修订要约报告而选取，不按交割、经营或市场结果选取。
- 决定性问题：在当时可读材料中，行动实施与“收购能通过何种机制改善公司经营”的判断能否被写成不同、可结算的链？
- 允许材料（冻结前）：FY2015 年报、2016-06-01 修订要约收购报告及其必要的同日说明；仅限巨潮法定披露。两份均已作为页级一手来源读完。
- 结果防火墙：在前瞻链、反方和早期/终局经营观察冻结前，禁止读取 2016-06-02 后的交割、KUKA 经营、后续年报、新闻、股价或回报资料。
- 已知结果风险：这是历史上较受关注的事件；本实验不得成为准确率、概率或基准率样本，除非后续独立泄漏审阅确认研究者在冻结时未使用结果信息。当前只用于训练过程与结算格式。
- 明确不研究：收购价格是否合理、证券回报、美的整体估值、机器人行业终局，或格力的资本配置结论。
- 当前基线解释：旧读法会把“收购后成为控股股东”当成技术/国际化/协同已经兑现的强证据，或把日后任何好坏结果归为收购正确/错误。
- 基线为什么是公平对照：这是资本配置叙事中最常见的结果偏见与行动—判断混淆。
- 新方法被拒绝或资料不足后的不同动作：保留行动编年，但不把它写进经营机制；换到一个有更明确当时经济目标与可观察结果的事件。

## 前瞻表达

- 行动状态：`ACTION_PENDING`。冻结时只能说要约已经提出、但尚未交割；后续官方公告只能将其结算为 `ACTION_COMPLETED / ACTION_NOT_COMPLETED / ACTION_SCOPE_CHANGED`。行动结算不是经济判断的胜负。
- 经济判断：`NO_ELIGIBLE_FORWARD_JUDGMENT`。管理层给出了三类愿景（制造效率、机器人/B2B 市场、物流），却没有在截止日给出任一条的基准、指标、时间窗、归属边界或可审计阈值；融资成本也明确不能量化。故不得从本对象虚构一个 6–12 月经济预测。
- 新的拒绝门：任何资本配置事件若不能同时写出 `共同事实 → H-A/H-B 两条不同机制 → 同口径的未来观察`，只能保留行动编年和机制假说，不能升级为“被验证的公司判断”。

## 对照与退出

- 最强替代机制：收购动作虽完成，但被收购资产的经营轨迹主要由独立周期、原有管理/客户结构或宏观需求决定，控制权不产生声明中的经济传导。
- 预期会出现的不同观察：待冻结前来源阅读后定义；不得在本卡中预写结果。
- 停止继续深挖当前对象的条件：要约文件只给愿景不给可运行机制，或两条链不能生成不同可观察顺序。
- 迁移复验对象/选择规则：选择非家电、不同类型资本配置事件；保留同样的“动作已完成但经济机制另行结算”结构。

## 结果与方法裁决

- 冻结质量裁决：`ECONOMIC_HYPOTHESIS_UNFREEZABLE`。这不是“协同不存在”的结论，而是当时材料不足以让研究者在不知道结果的条件下写出可结算的协同判断。
- 行动结算：`ACTION_COMPLETED`。2017-01-07 法定公告确认 2017-01-06 已完成股份交割与全部付款，MECCA 合计持股约 94.55%。
- 经济结算：`ECONOMIC_UNFREEZABLE`，不是 `H-A` 或 `H-B` 胜出。完成交割对两条机制都不具诊断性，不能回填本来不存在的经营 FJ。
- 方法裁决：`RETAIN_WITH_FAIL_FAST_GATE`。从此资本配置研究要先分别判定行动与经济命题；无预定义经营传导、指标、归属和窗口时，只能输出行动状态与 `NO_COMPANY_CONCLUSION`，再换样本，而不是持续深挖。
