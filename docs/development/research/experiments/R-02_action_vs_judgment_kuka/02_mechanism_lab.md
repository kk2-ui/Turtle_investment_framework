# R-02 机制实验室：收购动作与经济判断

状态：`ACTION_SETTLED / ECONOMIC_UNFREEZABLE`。以下区分可结算的行动状态与尚不可结算的经济机制；不是关于美的或 KUKA 的事后评价。

## 链一：行动实施

```text
已公告的要约/授权（2016-06-01 前已知）
  → 所需批准、融资与要约条件（结果期逐项满足）
  → 2017-01-06 交割、全部付款、约 94.55% 持股
```

该链只能回答动作是否发生、何时发生、按什么范围发生；不能回答资产是否创造经济价值。结果期只能写 `ACTION_COMPLETED / ACTION_NOT_COMPLETED / ACTION_SCOPE_CHANGED`，不能写“收购正确”。

## 链二：竞争经济机制

```text
收购时的资产/能力与约束
  → 可检验的整合、客户、产品或渠道传导
  → 早期经营信号
  → 终局经营结果
```

共同事实是：美的已有机器人/智能制造布局；拟通过 MECCA 要约 KUKA，最低意图持股 30%，但融资参数、接收股数、客户反应和尽调均不完整。交割不是任何一方的经济胜利。

### H-A：能力迁移形成可归因的经营传导

保留管理与技术能力，并把 KUKA 的自动化/系统能力和美的制造、渠道或物流场景连接起来，先出现一个可识别的联合运营活动，再出现该活动对应的经营改善。

### H-B：控制权取得但没有可归因的企业传导

即使动作完成，KUKA 的经营仍主要由原有客户、周期和独立管理结构决定；人才/客户/文化或跨境摩擦亦可能抵消合作。泛泛的业务宣传或并表收入不足以表明传导成立。

### 冻结裁决：H-A/H-B 不具备可结算前瞻判断

两条假说能解释同一当期事实，却没有可用的、不同的未来观察：要约文件没有预注册任何联合项目的范围、基准、指标、归属或到期日，也明确不能量化融资影响。用以后 KUKA 收入、集团利润或并表数字裁决会把周期、客户和控制权混入协同，构成事后归因。

因此本轮冻结 `NO_ELIGIBLE_ECONOMIC_FJ`；这不是 H-A/H-B 任一方获胜，而是证明研究流程应在此停下，拒绝把管理层愿景升级为公司判断。2017-01-06 的交割结果对两条机制均为共同允许结果，故不改变这一裁决。

## 最小裁决语义

- `ACTION_COMPLETED / ECONOMIC_TERMINAL_PENDING`：动作成立、经济判断尚未到期。
- `ACTION_COMPLETED / ECONOMIC_MIXED`：动作成立，但早期或终局经营观察对 H-A/H-B 混合或不具诊断性。
- `ACTION_INCOMPLETE / ECONOMIC_UNTESTABLE`：动作本身没有按原范围完成，不能假装已检验原机制。
- `ACTION_SETTLED / ECONOMIC_UNFREEZABLE`：行动可被结算，但截止日缺乏预定义经营传导与同口径观察；此状态禁止写“成功并购”或“失败并购”。本对象已经适用该语义。
