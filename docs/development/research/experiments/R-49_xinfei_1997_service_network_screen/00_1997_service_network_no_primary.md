# R-49：新飞 1997–1998 服务网络——服务规模能否进入企业经济判断？

## 身份与范围

`RESULT_KNOWN_TEACHING / S3_SERVICE_SCREEN / NO_PRIMARY / NO_COMPANY_OR_MANAGER_VERDICT`

R-49 是对 P-96 的不同公司应用，而不是新飞的补充公司史。它检验一个很常见的诱惑：已有 24 小时服务网络、数千维修人员和随后经营增长，是否足以把服务写作经营护城河？

## 可确认的行动与边界

[1997 年同期报道](https://rmrb.zhouenlai.info/人民日报（1946-2003）/1997/06/1997-06-06.htm)称新飞在大规模投放无氟产品后建立“绿色通道”，包括 24 小时投诉/监督电话和受训维修站。这个动作与 R-48 的服务影响选择状态一致，但二者都是共同背景，不能构成选择 H-A 的公司特异证据。

一年后的[1998 年同期采访](https://rmrb.zhouenlai.info/人民日报（1946-2003）/1998/03/1998-03-15.htm)记录新飞有 400 多名专职、4–5 千名非专职服务人员；公司负责人明确说，全面了解其服务情况并不容易。该披露反而界定了本案的监测缺口：网络和人数不是履约、修复质量或用户选择。

| | H-A：服务网络提高客户选择，并由成本/回款吸收 | H-B：服务网络是行业竞争的必要投入，规模/增长不能说明其经济效果 |
|---|---|---|
| 所需观察 | 区域/产品的及时修复、客户复购/价格实现；备件、人工、保修成本；渠道责任、应收/现金 | 热线、网点/人数、媒体赞誉，或与产品/行业共同变化的销量、利税、排名 |
| 当前材料 | 有行动、网络规模和可见性缺口 | 没有前一列的任一成对、同口径结果 |

故正确输出：

```text
SERVICE_NETWORK_ACTION: OBSERVED
SERVICE_FULFILMENT_AND_CUSTOMER_CHOICE: UNKNOWN
SERVICE_UNIT_COST_AND_CASH: UNKNOWN
SELECTION_ADMISSION: NO_PRIMARY
```

## 为什么这是有效训练结果

这不是因数据少而暂停。它实际改变了下一轮选择：任何“服务网络”案例，只有在入场前同时具有客户/履约和成本/现金两个结果合同，才可由 `S3_SERVICE_SCREEN` 升级。新飞的销量、利税、品牌或后来变化都不允许补这个缺口。

## 本轮结论

`RETAIN_AND_NARROW / SERVICE_SCALE_IS_NOT_SERVICE_ECONOMICS / NO_PRIMARY_IS_CORRECT`

根因：`DATA_COVERAGE + REASONING`。将服务人员、热线或网络直接升级为护城河，会材料性错判服务成本、价格实现、营运资本与现金；以同期销量/利税填补，又会把产品、环保、渠道和行业共同变化错归给服务。缺失的是服务履约、客户选择、每台成本、责任分担与现金。禁止用网点、人数、品牌、销量、利税、后来存续、价格或回报补足。验收是下一个不同企业的服务卡在结果前锁定“履约/客户 + 成本/现金”双合同；否则停止在 `NO_PRIMARY`。
