# R-42：新飞 1998 年农村经济型冰箱——产品适配与成本改善，谁解释了经济结果？

## 身份与范围

`RESULT_KNOWN_TEACHING / S3_SEGMENT_SHIFT / MIXED_OPERATING_OUTCOME / NO_PRODUCT_RETURN_OR_MANAGER_VERDICT`

本卡训练一个比“产品卖得好不好”更完整的问题：当制造商为新客户群简化功能、降低价格并适应使用环境时，后续销量和利润改善能否归给产品判断，还是与供应链成本、管理与周期同时发生？它不评价新飞整体、农村市场、供应商管理或后来公司命运。

## 当时的选择与两条机制

[《人民日报》1999-07-12 对新飞的报道](https://cn.govopendata.com/renminribao/1999/7/12/1/)回顾其 1998 年面向农村市场的经济型冰箱：相对非经济型，功能有所简化、价格低约 400 元，同时采用宽温度带、宽电压带和宽湿度带以适应农村使用情境。报道同时描述原材料/零配件竞争供货和管理，称原材料、零配件价格同比下降约 5%。

| | H-A：产品—场景—成本的可吸收组合 | H-B：产品采用与经济改善被共同变化混淆 |
|---|---|---|
| 对农村市场机会的理解 | 可负担价格与环境适应缺一不可；在不失去关键使用价值时简化功能，能打开新客户且不必牺牲整体经济性 | 销量可能随市场、渠道、品牌或促销变化；利润/利税改善可主要由材料采购、总体管理或其他产品驱动 |
| 管理选择 | 定义目标客户的功能下限与环境约束；以采购/制造成本承接降价 | 仅用降价或推广拉动；或将全公司成本节约误归为某个产品决策 |
| 应有的结果序列 | 该产品在目标客户中成为可观份额，且其价格、成本/服务、回款或现金有独立桥 | 产品销量可以增加，但若无产品级成本、渠道与现金，不能判其自身经济性 |

## 已知结果如何结算

报道称，1998 年经济型冰箱销量约占公司全部销量 40%；单台价格降低约 400 元，但公司利税较上年上升约 12%。这些是有价值的联合观察：目标产品并非边缘投放，而“降价”与集团层经济结果可以同时出现。

但同一来源同时列出材料和零配件成本下降约 5%，并把严格管理、供应商分级、付款信誉等作为背景。没有产品级价格实现、单位材料/制造/保修成本、渠道折扣、应收存货或现金，也没有未推出该产品的相同区域对照。因此合理的结算是：

`CUSTOMER_ABSORPTION / SUPPORTS_H-A_PARTIALLY`；

`UNIT_ECONOMICS_AND_CASH / MIXED_NOT_DIAGNOSTIC`。

它支持“细分使用条件与产品取舍值得进入机制空间”，不支持“农村冰箱是利润增长的原因”或“降价仍然提高了该产品的资本回报”。

## 与 R-41 的边界复验

R-41 的 1989 美菱是把家庭食物储存约束翻译为冷冻室规格；R-42 的新飞面对的则是农村客户的支付能力与环境适应。这不是重复的“用户导向”：

```text
R-41：具体储存约束 → 规格差异 → 早期选择
R-42：支付能力 + 使用环境 → 功能下限/价格 + 供应链成本 → 细分采用与经济问题
```

两个案例共同说明产品判断必须匹配具体客户和状态；R-42 额外表明，产品渗透与利润同时变好时，仍须把采购/生产成本从产品价值中剥离。它是 P-89 所要求的“规格不再是唯一分叉”在不同客户状态的复验。

## 对下一轮的约束

新产品或低价产品卡必须冻结：目标客户的具体限制、为之放弃的功能、价格变化、产品级成本/服务替代，以及至少一项回款/营运资本观察。若公司只公布产品销量占比和总利润，即将“客户采用”与“经济结果”分开结算，后者为 `MIXED / NOT_DIAGNOSTIC`。

## 本轮结论

`RETAIN_AND_NARROW / SEGMENT_CONSTRAINT_TO_PRODUCT_COST / ADOPTION_IS_NOT_PRODUCT_RETURN`

根因：`REASONING + DATA_COVERAGE`。若把产品销量占比与集团利税同步改善直接归给产品，会忽略采购成本、总体管理、渠道与其他产品变化，材料性误判单位经济、现金转换和资本回收；若只看降价，也会漏掉产品在特定使用环境下的真实客户价值。缺失的是产品级量价、成本/保修、渠道/回款、营运资本与资本占用。禁止以总利税、品牌、后来份额、股价或回报补足。验收是下一张细分产品卡能在冻结前把客户约束、功能取舍、价格、产品级成本和现金观察分别定位；否则只结算客户采用。
