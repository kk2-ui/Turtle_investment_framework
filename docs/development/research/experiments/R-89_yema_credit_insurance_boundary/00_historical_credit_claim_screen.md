# R-89｜野马电池 2020 年客户拒付与出口信用保险：先行赔付不是已验证的收款权

状态：`HISTORICAL_TEACHING_SCREEN / NO_PRIMARY / NOT_FROZEN / NO_SELECTION_SCORE / OUTCOME_EXPOSED`。

本卡不评价野马电池、一次客户纠纷或其证券。它只检验一个信用治理中常见而危险的推理捷径：公司收到出口信用保险的赔款，是否就证明此前的信用控制把客户信用转成了可归属于公司的现金。结论是**不能**。

结果已经公开，因此本案只可作为历史机制边界，不是 Turtle 的盲测或真实前瞻选择；不得计入选择准确率、校准、方法复制或公司结论。

## 1. 已读一手材料与确定事实

- [2024 年年度报告（巨潮资讯，2025-04-28）](https://static.cninfo.com.cn/finalpage/2025-04-28/1223347363.PDF)：公司将境外电池销售购买出口信用保险列为常设风险应对；截至 2024 年末，境外客户应收账款为 `281.06` 百万元，其中一年以内约 `281.00` 百万元。报告亦把 `15.52` 百万元“出口信用保险赔款”列为其他非流动负债，而非经营收入或已实现经营现金。
- [2025 年年度报告（巨潮资讯，2026-04-27）](https://dataclouds.cninfo.com.cn/shgonggao/hsomarket/2026/20260427/6d892b32b13f4a19957d47a82359f35d.PDF)：披露 `2020-06` 公司与 `L'Image Home Products Inc.` 发生争议、对方拒付货款；公司向中国出口信用保险公司报案，后获未付货款 `70%`、即 `15,521,886.81` 元先行赔付。中国出口信用保险公司取得代位求偿权；若最终仲裁裁定公司违约，保险方将不予理赔并收回先行支付款。该款在 2025 年末仍列于其他非流动负债。

这些材料能确认一项事后应收风险处置和一个单一客户名称；它们没有给出保险投保、限额设定、发货许可、合同 P/O、账期、保险除外、客户信用变化或仲裁终局的结果前证据。

## 2. D1-D5 结算边界

| 时钟 | 可确认事实 | 为什么不能升级为经营判断 |
|---|---|---|
| D1 决策／实施 | 客户于 `2020-06` 拒付后，公司报案；公司长期购买出口信用保险。 | 已知的具体动作是违约后的索赔，不是结果前可比较的授信、订单、发货或保险限额选择；没有替代动作、权限边界或执行质量材料。 |
| D2 客户／竞争反应 | 一个具名客户拒付。 | 没有该客户对应订单、产品、验收、争议原因、合同权利或其他客户 cohort；不能把客户违约归因于公司信用治理或市场竞争。 |
| D3 单位经济 | 无同订单收入、折扣、成本、退货或损失资料。 | `70%` 仅是保单赔付比例，不是产品毛利、可实现价格或整笔订单的经济回收。 |
| D4 营运资本／现金 | 保险方先行支付 `15.52` 百万元，但公司持续作为其他非流动负债列示。 | 该现金仍以最终仲裁和代位追偿为条件；会计列报本身说明它不能被当作无条件、可归属的应收回收或 OCF。集团应收、销售收现或 OCF 都不能替代该法律条件。 |
| D5 资本回收 | 无该客户或该保单的资本占用、保费对价、替代用途或自由现金资料。 | 无法判断保险安排是经济上有利的资本配置，更不能外推为企业长期 ROIC。 |

## 3. 不能选择 H-A 的原因

```text
H-A：出口信用保险把客户违约转成公司可收回现金
客户拒付
  → 保险方赔付
  → 公司保留无条件现金、损失受到实际约束

H-B：先行赔付仍受合同与仲裁结果约束
客户拒付
  → 保险方代位并先行支付
  → 若仲裁认定公司违约，赔付可被收回
  → 在终局前，公司无法将该款确认为自己的经营回收
```

现有两份年报直接保留 H-B：赔款连续列为其他非流动负债，且披露保险方可收回款项。没有结果前的保险合同或客户权利材料可以让研究者在 `2020-06` 比简单基线作出非共同的方向选择；截至 2025 年末也没有可结算的仲裁终局。因此，本案既不能把“买了保险”判为信用治理成功，也不能把客户拒付判为管理失败。

## 4. 准入裁决和下一轮硬约束

- **根因：** `DATA_COVERAGE + REASONING`。缺失的是信用权利链和终局可归属性，不是更多集团财务数据或第三方解读。
- **经济影响：** 若将先行赔款当作已实现收款，会材料性高估营运资本安全、正常现金转换和损失保护；若将客户拒付当作治理失败，则会忽略合同、保险与争议事实的未决边界。
- **禁止假设：** 购买保险等于有效授信；`70%` 先行赔付等于公司最终拥有 `70%` 现金；代位求偿不影响公司权利；集团 OCF、期末应收或之后业务增长能替代该笔法律和会计结算。
- **可执行处置：** 关闭 `R-89 / NO_PRIMARY / NOT_FROZEN`，不建 FJ、不登记结果合同、不计分，也不以更多年报追补“成功/失败”叙事。
- **下一家不同公司冻结约束：** 对信用保险、保理、回购或托收类动作，`loss_protection` 必须逐项写明**投保/额度/发货的结果前决策日、受影响客户或订单 cohort、保险人与公司各自的付款和追偿权、会计归属、终局触发条件**；`cash_origin_bridge` 必须区分无条件客户收款、可返还先行款和筹资。只有主机制、最强反方与简单基线会对同一终局观察给出不同预测，才可申请 `JUDGMENT_SELECTION_EPISODE`。

本约束继承 R-23 的教训但收紧了一个具体漏洞：信用工具的存在、甚至一次到账，都不能替代公司对现金的无条件、可审计索取权。
