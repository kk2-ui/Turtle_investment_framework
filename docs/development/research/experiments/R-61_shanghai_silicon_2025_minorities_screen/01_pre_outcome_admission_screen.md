# R-61｜沪硅产业 2025：已并表 300mm 子公司的少数股权收购筛查

状态：`PRE_OUTCOME_SCREEN / NO_PRIMARY / NOT_FROZEN / OUTCOME_BODY_UNREAD`。

这不是对沪硅产业、半导体硅片景气或该笔交易好坏的结论。它只检验一个看起来很像“扩产—整合—效率提升”的资本事件，是否真的形成一个可按 `D1 → D2 → D3 → D4 → D5` 研究的**新经营决策**。结论是否定的：法定材料清楚表明，交易是收购三家既有控股子公司的少数股权；合并范围、营业收入和利润总额在交易前后不变。因此不能把后来经营变化归因为这次取得 100% 股权。

## 2. 交易的经济边界

最终交易报告书第 19–20 页的模拟口径明示：收购的是新昇晶投 `46.7354%`、新昇晶科 `49.1228%`、新昇晶睿 `48.7805%` 的少数股权；三者交易前已经是上市公司控股子公司。交易完成后持股升至 100%，但“合并财务报表范围未发生变化”；同一报告在摊薄分析中进一步说明，交易前后上市公司营业收入和利润总额不变。标的仍处于产能爬坡、尚未盈利，是持股归属而非经营边界变化。

公司称完全持股将有利于管理整合、协同和效率提升。这是管理层的未来主张；它没有构成一个已实施的新客户、产品、产线、成本或营运资本过程，不能被当作对主路径的非共同方向性事实。

| 多层时钟 | 入场所需的事件 | 已读材料的最窄事实 | 裁决 |
|---|---|---|---|
| D1 决策实施 | 新的经营控制、资源流程或责任单元接口 | 原本已是控股子公司；此次改变的是剩余权益归属，合并范围不变。 | `FAIL`：没有可归因于本交易的新经营实施。 |

## 3. 为什么不建立 H-A／H-B、前瞻判断或教学结算

此处的两种表面叙事——“完全持股会释放协同”与“只是财务归属调整”——不能形成一场公平的选择判断：前者没有在 cutoff 前留下与后者方向相反、且可由 D2–D5 同主体结果裁决的实施事实。后续的集团收入、利润、现金、产能利用率或股东权益变化都会同时受到既有控股关系、行业周期、既有爬坡和其他经营决策影响。

因此 R-61 不冻结主／反机制、不读取 outcome body、不建立 FJ、不进入选择判断、历史教学样本、near-miss 或 replication。它是一次合格的**准入拒绝**，不是一个负面案例。

## 4. 研究教训与下一道门

根因分类：`REASONING + MODEL`，不是 `DATA_COVERAGE`。三份法定原件已足以确定交易与经营边界；继续收集更多报告只会增加叙事密度，不会补出 D1。

经济影响：若把“从控股到全资”和会计上的少数股东权益变化误当作新的经营控制，后续集团利润、亏损收窄、现金或估值变化都会被虚假归因于并购协同，材料性扭曲正常盈利、owner cash 与资本配置判断。

禁止假设：

- 持股升至 100% 自动等于新控制、新协同或新经营效率；
- 合并口径、少数股东损益、发行股份／支付现金或交易对价能代替 D2–D4；
- 标的当前亏损证明交易失败，或后续盈利证明交易成功；
- 后续行业景气、股价或回报可填补本交易缺少的因果接口。

下一候选只有在 cutoff 前同时具备：可定位的新经营资源／责任单元实施、客户或竞争的可观察接口、同单位经济与现金桥，以及能与最强反方分叉的计量合同，才可进入冻结。否则应像 R-61 一样在结果期前停止。
