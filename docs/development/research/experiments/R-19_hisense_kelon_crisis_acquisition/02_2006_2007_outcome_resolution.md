# R-19：2006–2007 结果复盘——收入恢复不是危机整合的经济裁决

前置冻结卡：[2005 年企业经营判断卡](01_2005_pre_outcome_enterprise_judgment_card.md)。

状态：`RESULT_KNOWN_TEACHING / OUTCOME_RESOLVED_FOR_MECHANISM / NO_TOTAL_ACQUISITION_VERDICT`

本复盘只回答冻结卡中的一个窄问题：过渡性控制权和预付款安排，是否已经显示出**不依赖补贴、资产处置或持续外部资金的经营现金恢复**。它不裁决海信收购科龙的全部价值，也不使用任何价格、回报或后来的品牌地位。

## 2. 逐箭头结算

| 冻结箭头 | 预先承诺的判据 | 结果 | 结算 |
|---|---|---|---|
| 早期机制：商业循环恢复 | 收入恢复同时至少一项营运资本或经营现金质量改善，且补贴/一次性项目不承担全部经济效果。 | 2006 披露收入约 65.65 亿元且 OCF 为正；但营业利润、扣非净利润为负，且净利润含 7,000 万补贴，审计保留。 | `MIXED / EARLY_OPERATING_RESTART_PLAUSIBLE`。有恢复信号，不能判自立。 |
| 终局经营：两年自立 | 不靠新增救助而跨两年维持/改善正常经营和现金质量。 | 2007 营业利润、扣非净利润及 OCF 均为负；归母净利主要受资产处置损益抬升，审计仍保留。 | `SUPPORTS_RIVAL_FOR_SELF_SUSTAINING_RECOVERY`。 |
| 资本后果：危机资金桥被真实现金循环替代 | 需要交易现金、预付款余额/回收、债务处置、应收/库存/应付和可比 OCF。 | 现有摘要未提供以上整套桥接。 | `NOT_DIAGNOSTIC / INSUFFICIENT_ATTRIBUTION`。 |

这里的 `SUPPORTS_RIVAL` 只针对 H-B 所说的“短期资金桥与非经常项目不足以证明自立恢复”。它**不**证明 H-B 的每一个因果细节（例如供应商没有恢复信用），更不等于“收购一定错误”。

## 3. 经营者、行业专家与长期所有者分别学到什么

| 视角 | 能保留的判断 | 不能越级的结论 |
|---|---|---|
| 经营者 | 在供应、生产和渠道共同断裂时，控制权以外的短期营运资金安排可以先创造恢复窗口。 | 不知道该窗口是否由组织、供应商信用或终端需求真正接住。 |
| 行业专家 | 白电危机中，代理定价权、营销费用、经销商与供应商信用是不同变量；“重新发货”不足以代表渠道/产品竞争力。 | 不将收入或品牌延续解释成渠道网络已修复。 |
| 长期所有者 | 净利润必须拆为营业利润、补贴、资产处置和现金；跨年观察比单年扭亏更有诊断力。 | 不能由 2006/2007 摘要估算收购回报、协同价值或永久损失总额。 |

## 4. 反馈：下一张危机/整合训练卡被强制改变什么

这不是泛泛的“以后更谨慎”。下一张**不同中国公司**的危机收购、救助或整合题，在冻结前必须加入四项实际字段：

1. `bridge_funding_terms`：资金是预付款、借款、担保、补贴还是股权；谁承担费用、谁拥有定价/渠道权；
2. `recurring_earnings_bridge`：营业利润/毛利到净利之间的补贴、处置、减值、重组和债务项目；
3. `cash_conversion_bridge`：经营现金与应收、库存、应付、预付款的同口径桥接，不能只填 OCF 单值；
4. `two_period_persistence`：至少两期结果都要求 `正常经营 + 现金/营运资本`，一年的正现金或账面扭亏不得作为终局。

根因：`REASONING + DATA_COVERAGE`。此前危机案例的常见错误是把控制权交易、收入恢复或净利转正直接写成管理能力；而本案显示同一报表中，营业利润、扣非利润、补贴/处置和现金会给出相反信号。经济影响是若不拆桥，会高估救助后正常盈利与 owner cash，低估营运资本、历史负债与会计处理造成的永久损失。

禁止假设：

- 2006 的正 OCF 必然来自商业信用修复；
- 2007 的归母净利代表持续经营盈利；
- 负营业利润必然证明所有接管安排毫无价值；
- 后来的资产注入、品牌存续、价格或证券回报可回填本案。

本案最终判断：`DECISION_LOGIC = CONTRIBUTORY / INSUFFICIENT_ATTRIBUTION`；`EARLY_MECHANISM = MIXED`；`TERMINAL_OPERATING_SELF_SUSTAINABILITY = SUPPORTS_RIVAL`；`TOTAL_ACQUISITION_ECONOMICS = UNKNOWN`。
