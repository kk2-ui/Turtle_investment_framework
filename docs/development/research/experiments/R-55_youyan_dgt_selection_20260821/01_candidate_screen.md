# R-55：有研硅收购 DGT——选择筛查，不冻结主判断

状态：`PRE_OUTCOME_SCREEN / NO_PRIMARY / NOT_FROZEN`。

这是一项中国制造业企业决策筛查，研究的问题不是收购是否“讲得通”，而是有研硅收购控股股东 RST 持有的 DGT 70% 股权后，能否把上游硅材料与下游刻蚀设备部件连接成**独立、可持续的经营引擎**。本文件不构成公司结论、投资结论或对管理层能力的评价。

## 截止日与读入边界

- 截止日：`2026-08-21T23:59:59+08:00`。
- 法定一手源完整枚举：上交所公告 196 份；只选择并读取收购公告、交割公告、2025 年年报和 2026 年中报四份。源包与读取回执位于当前研发分支的 `output/research/experiments/r55_youyan_dgt_selection_20260821/`。
- 不读取 2026-08-21 之后的业绩、任何证券价格、回报、估值或二手材料。

## 已确认的企业事实与竞争叉

**决策。** 交易是从控股股东 RST 收购 DGT 70%，而非向独立卖方收购；DGT 在收购后仍有 RST 30% 持股。2025 年公告称对价 119,138.82 万日元，采用资产基础法，原因是原材料价格波动大且 DGT 无法及时向下游传导；收益法不是最终估值依据。见 `SSE:...:4MT8` 第 9–10 页。

**管理主张。** 公司将其表述为补足下游部件加工、取得客户资源、拓展海外市场；但 2025 年年报仍将 DGT 的独立采购和销售体系写为收购后的待建事项。见 `SSE:...:4MT8` 第 14–15 页及 `SSE:...:WCEG` 第 16 页。

**截至冻结的责任单元状态。** 2026H1 披露 DGT 营收 11,167.37 万元、毛利率 1.77%，同时披露与 RST 及其同控方的应收款较 2024-09 增加，而应付/其他应付款仍为大额余额；RST 仍为 DGT 银行借款提供担保。见 `SSE:...:TG0E` 第 35–36 页。该报告亦说明本交易为同一控制下合并、同比数据重述，集团营收/利润不能归因于 DGT。见第 6 页。

由此可写出的两条完整、但尚未选中的机制是：

| 假设 | 机制链 | 真正的分界观察 |
|---|---|---|
| H-A：协同开始转成独立经营能力 | 客户认证与下游加工能力 → 直接客户、独立采购/销售 → 较高且可持续的单位经济 → 关联方资金/担保依赖下降 | 同定义的 DGT 销售、毛利、直接客户转换与 RST 往来共同改善。 |
| H-B：产业链叙事未越过经济边界 | 客户/供应商/融资仍嵌在 RST 关系中，成本波动又难传导 → 低毛利与营运资本依赖延续 → 集团合并增量掩盖责任单元质量 | 销售可以增长，但若毛利、直接客户转换、关联往来/担保未同步改善，不能把增长解释为协同。 |

## 为什么本轮不得选择 H-A 或 H-B

`NO_PRIMARY` 不是“没有观点”，而是拒绝伪造公平基线。

收购协议的 2025–2027 累计营收与毛利承诺（累计营收 1,411,892.41 万日元、累计毛利 178,700 万日元）是卖方补偿/奖励条件，不是一个披露了年度、半年度、同币种同口径的 DGT 经营基线。将其 12.66% 的三年累计比率直接当作 2026H1 1.77% 毛利率的“正常水平”，会把交易谈判条款伪装成已验证经营事实。

同时，已读的 2025 年年报没有给出可与 2026H1 一一重建的 DGT 2025 单体收入、毛利和关联往来序列；2026H1 又是合并后的第一个、且受同一控制重述影响的半年度。因而本轮不能为“全年恢复”或“持续低迷”设定一个不同于朴素延续、又能在未来官方披露中同定义结算的公平阈值。

## 方法判断

- 根因：`DATA_COVERAGE + REASONING`。缺的是责任单元同定义的历史基线，不是报告数量，也不是对收购动机的更多转述。
- 经济影响：若把集团营收增长、三年业绩承诺或单期 1.77% 毛利率直接做成主判断，会把合并会计、卖方激励或短周期成本波动误判为收购的正常盈利、owner cash 与资本配置质量。
- 禁止假设：
  - 销售增长等于客户关系已直接化；
  - RST 担保或关联余额存在等于一定发生利益输送；
  - 三年累计承诺的平均毛利率等于任一半年度的可结算基线；
  - 集团中报增长可以归因给 DGT；
  - 以后披露的结果可以补写本截止日的方向性选择。
- 可执行处置：本 case 关闭为 `NO_PRIMARY`，不补读材料来“凑”主判断。下一轮应选择一个在截止日前同时披露责任单元历史基线、可分辨的管理决策事实和未来同定义披露窗口的中国制造 episode；或将 DGT 作为**历史教学 episode**，另设早于结果的截止日和完整 metric-reconstruction contract。
- 接纳标准：新的选择 episode 必须在冻结前同时有（1）独立于交易奖励的同定义基线；（2）H-A/H-B 方向相反且不共享的当前经营事实；（3）决策实施、客户/竞争、单位经济、现金、资本后果的分层结果合同。缺任一项只能为 `NO_PRIMARY`。

本筛查训练的不是“收购好或坏”的答案，而是企业判断在**责任单元、现金依赖与合并口径**不足时应当停止选择的能力。
