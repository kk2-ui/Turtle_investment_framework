# R-50：长城—哈弗 2013–2014——品牌独立、产品聚焦与现金为何必须分开？

## 身份与范围

`RESULT_KNOWN_TEACHING / CHINA_MANUFACTURING_PRODUCT_FOCUS / PARTIAL_OPERATING_SUPPORT / NO_BRAND_CAUSALITY_OR_CAPITAL_RETURN_VERDICT / NO_TURTLE_BACKTEST`

本卡换出家电与并购，测试 P-98 的五层证据顺序能否用于中国汽车：2013 年哈弗独立品牌并继续聚焦 SUV，后来销量很强；这到底是品牌组织决策创造的客户价值，还是 SUV 需求、既有 H6 与新车型共同推动？

## 状态、行动与竞争机制

[长城 2013 年报](https://static.cninfo.com.cn/finalpage/2014-05-31/64088077.PDF)确认，2013 年 3 月公司提出将哈弗打造为独立品牌，并称网络仍在调整；同年 SUV 销量 420,302 辆、同比 +50.13%，而轿车销量仅 +3.11%。年报同时称 H6 的性价比/口碑、M4 的细分定位、SUV 市场的热烈反应，以及产品升级共同影响销量。

| | H-A：品牌聚焦把产品、网络与客户选择组织成 SUV 经济 | H-B：SUV 行业需求、已有 H6/M4 与新车型主导；品牌独立本身尚未可分离 |
|---|---|---|
| 可检验链 | 独立品牌/网络资源 → 对目标 SUV 客户的选择、价格或渠道改善 → 车型/业务单元的成本、营运资本与现金改善 | 即使 SUV 与收入增长，仍可由品类景气、既有车型口碑、同时推出的产品和网络调整解释；轿车资源重配还可改变集团混合 |
| 当期事实 | 品牌独立、网络调整、车型升级和 SUV 增长均真实存在 | 这些多项动作在同一时期发生，不能由一项品牌动作选择 H-A |

## 2014 年实体结果：经营状态与归因分开

[长城 2014 年报](https://financialfilings.com/filings/great-wall-motor-company-limited-1/annual-report/2015/40146195/)给出连续、同一集团口径的后续观察：

- SUV 销量 523,208 辆、同比 +24.48%；H6 销量同比 +47.20%，新推出 H2/H1/H9 也有早期市场接受信号；但轿车销量下降 57.42%。报告明确全国 SUV 品类增速高于其他品类，且竞争加剧。
- 集团营收增长 10.24%，归母净利下降 2.21%，经营活动现金流净额下降 32.56%。
- 年报的现金流调节显示，存货和经营性应收增加，经营性应付也增加；故经营现金变化不能归属为哈弗品牌、某一款车，或客户回款质量的单一结果。

正确结算：

```text
SUV_PRODUCT_PORTFOLIO_AND_CUSTOMER_RESPONSE: PARTIAL_OPERATING_SUPPORT
HAVAL_BRAND_SEPARATION_AS_CAUSAL_DRIVER: NONATTRIBUTABLE
GROUP_PROFIT_AND_CASH_CONSEQUENCE: MIXED_AND_NONATTRIBUTABLE
CAPITAL_RETURN_OF_BRAND_FOCUS: UNKNOWN
```

这并非否认聚焦策略。它说明“独立品牌”是行动层，SUV 车型/客户的销量是部分早期经营层，而集团收入、利润与现金仍混入产品组合、行业景气和营运资本。要评价企业家的取舍，研究还需 Haval 责任单元的价格、折扣/渠道成本、车型开发和产能资本、应收/库存与现金合同。

## 对下一轮的约束

品牌/品类聚焦卡必须预先拆开：

```text
品牌/组织动作
→ 特定产品与客户/渠道选择
→ 车型或业务单元的价格、成本、服务与营运资本
→ 现金和增量资本回收
```

产品销量可以帮助定位客户方向，但不能代替价格实现；集团现金必须按存货、应收、应付和资本开支分解。若产品和组织动作并发而没有 pre-registered counterfactual/同类对照，品牌效应保持 `NONATTRIBUTABLE`。

## 本轮结论

`RETAIN_AND_NARROW / PRODUCT_FOCUS_DIFFERS_FROM_BRAND_CAUSALITY / CASH_SOURCE_BEFORE_CAPITAL_JUDGMENT`

根因：`REASONING + DATA_COVERAGE`。把 SUV 销量、品牌独立或集团收入写成品牌决策成功，会材料性高估客户选择、正常盈利和资本回收；把利润/OCF 下降直接写成聚焦失败，也会混淆新车型、市场竞争、存货、应收和应付。缺失的是哈弗责任单元的价格/渠道、单位成本与资本占用、现金资料，以及与未独立品牌的可比路径。禁止用公司口号、SUV 行业增长、集团利润/OCF、品牌后来的地位、股价或回报补足。验收是在另一聚焦/品牌决策中，冻结前获得产品客户信号和业务单元经济/现金的成对合同；否则只结算经营状态。
