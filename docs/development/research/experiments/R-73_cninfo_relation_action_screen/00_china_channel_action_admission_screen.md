# R-73｜巨潮“投资者关系活动记录”接入后的中国渠道决策筛选

状态：`SOURCE_ACQUISITION_IMPROVED / PRE_OUTCOME_ADMISSION_SCREEN / TWO_NO_PRIMARY / NO_SELECTION_SCORE / OUTCOME_BODY_UNREAD`。

R-73 不是一份公司报告。它验证一个更前置的问题：上市公司已经在交易所法定披露页面发布的“投资者关系活动记录”，能否先被完整枚举、再被当作截止日前行动原件筛选；以及这些行动原件是否真的足以启动一个企业判断 episode。

答案分两层：来源接入已完成；两个候选都不准入。这个结果比把“渠道调整”“新品”或“组织升级”写成已经具备判断力的样本更有价值。

## 1. 这次修复的来源边界

CNINFO 的公司页面将普通公告和“调研／投资者关系活动记录”分成不同的查询 tab。旧采集器只请求 `fulltext`，所以它能完整列普通公告，却会把同一公司在官方披露页面上单独列出的 action 原件漏出。这不是模型推理或文风问题，而是 `ACQUISITION_MODULE` 的实际缺口。

本次只增加 `relation` 这一官方查询 tab：它仍按公司代码、组织 ID、日期区间和全部分页取得元数据；仍要求同一证券／组织、日期边界、公告 ID、标题及原附件 URL；仍把 PDF 原件与 reader text 落入 PIT 源包。它不把访谈、新闻、当前网页文字或管理层的空泛表态升级为事实。

因此它解决的是“先看见官方行动原件”，不是降低准入条件。后续卡仍必须有 `D1` 可审计实施、同责任单元的 D2–D4 结果合同、竞争反方、公平基线和停止条件。

## 2. 筛选原则：先完整来源，再问企业系统

这轮只读截至 2026-08-23 的 CNINFO `relation` 完整枚举；未读两个候选的半年度报告正文、后续业绩、价格或回报。对每一条行动线的准入按如下顺序判断：

```text
官方行动原件
  → D1 谁以何种资源／权限实施、何时开始、何时可停止
  → D2 同产品／渠道／客户单元的未来采用或交付口径
  → D3 价格／组合、单位成本、渠道／服务费用的桥
  → D4 收款、库存、供应商融资和外部融资的现金桥
  → D5 责任单元资本与停止条件
```

任何一步不能用总收入、总毛利、总 OCF、经销商或门店数量、管理层乐观语句、行业景气或结果期信息替代。

## 3. 候选一：三雄极光——明确的经营压力，不是可冻结行动

CNINFO `relation` 枚举到唯一一份当期记录：[2026-04-29 投资者关系活动记录](https://static.cninfo.com.cn/finalpage/2026-04-29/1225257327.PDF)。发行人描述 2025 年毛利率下降与项目渠道价格竞争、原材料压力有关，并称将优化竞争、产品／价格策略、产能整合和渠道覆盖。

这组事实支持“外部竞争与成本压力正在发生”的状态诊断，却没有把一个可执行的 D1 决策冻结下来：没有具体价格／渠道 package 的开始日、责任单元、资源承诺、量化目标、停止／回转权或覆盖范围。随后可得到的公司级收入、毛利或 OCF 即使变化，也不能告诉我们是价格、产品、项目渠道、成本、产能整合还是行业需求导致。

| 门 | 结论 | 为什么不能跨越 |
|---|---|---|
| D1 | `NOT_ACTION_IDENTIFIED` | “不断提高”“根据市场调整”“持续推进”是计划性表述，不是可审计实施。 |
| D2 | `NO_UNIT_OUTCOME_CONTRACT` | 未披露项目渠道、产品或价格单元的未来采用／中标／交付口径。 |
| D3 | `NO_PRICE_COST_FEE_BRIDGE` | 总毛利可同时受项目价格、产品组合、材料、生产效率影响。 |
| D4–D5 | `NO_CASH_OR_CAPITAL_BOUNDARY` | 应收、库存、资本开支和项目／渠道行动没有同一责任单元映射。 |

结论：`NO_PRIMARY`。不因其“价格竞争”故事完整、材料易得或照明行业熟悉而继续扩写。

## 4. 候选二：洽洽食品——有真实组织动作，仍没有同边界结果合同

CNINFO `relation` 完整枚举到三份当前记录，其中 [2026-05-19 活动记录](https://static.cninfo.com.cn/finalpage/2026-05-19/1225315248.PDF) 明确说公司在 2026 年把即时零售、零食连锁部门升级为一级组织；同一记录也说明传统渠道受变化冲击、新渠道会影响品牌商利润，并提出小包装、不同渠道定价与费用率、产品创新和供给匹配。较早两份记录是 [2026-04-22](https://static.cninfo.com.cn/finalpage/2026-04-22/1225143164.PDF) 和 [2026-05-06](https://static.cninfo.com.cn/finalpage/2026-05-06/1225280789)。

这比三雄极光更接近 D1：组织层级确已调整，而且问题空间不是单一销量，而是渠道迁移、产品、定价、费用、原料和毛利的联动。但它仍不能成为 `JUDGMENT_SELECTION_EPISODE`。

| 门 | 观察到的事实 | 准入判定 |
|---|---|---|
| D1 | 即时零售、零食连锁升级为一级组织。 | `IMPLEMENTED_BUT_SCOPE_INCOMPLETE`：没有披露授权、专属预算、考核、开始前后单元边界或停止／回调条件。 |
| H-A/H-B | H-A 可为“专门组织＋适配包装／供给让新渠道增长且提升整体经营质量”；H-B 可为“新渠道议价和费用结构使增长无法穿透利润与现金”。 | 两者都兼容已披露的渠道增长、传统渠道下滑和利润压力；没有一个截止日前的非共同方向性事实可公平选择主路径。 |
| D2 | 公司没有冻结未来即时零售／零食连锁部门的收入、订单、复购、单店或交付定义。 | `NO_SAME_UNIT_D2_CONTRACT`。公司的总收入或新渠道“增长较快”不可替代。 |
| D3 | 资料明确不同渠道定价、费用率和利润率不同，且原料、产品组合并发。 | `NO_D3_MEASUREMENT_CONTRACT`：没有渠道级 price/mix、单位成本、渠道费用的同口径未来观察。 |
| D4–D5 | 只存在公司级现金及一般性经营叙述。 | `NO_D4_D5_BOUNDARY`：不能把总 OCF、货币资金或未来产能当作组织动作的现金／资本回收。 |

结论：`NO_PRIMARY / NO_SELECTION_ADMISSION`。这一停止不是否定组织调整可能有价值，而是拒绝把一个真实管理动作和未来的公司级财务结果拼成“研究者当时选对了”的样本。

## 5. 对飞轮的实际输入改变

R-72 的 `BUNDLE_CONFOUNDING_RULE` 加上 R-73 的来源实践，要求下一中国公司卡在读取行动后先填写：

1. 行动是产品、渠道、组织、信用治理中的哪一个，谁有资源与停止权；
2. H-A/H-B 对 D2、D3、D4 的相反序列是什么；
3. 是否有**同责任单元**的未来公开指标，而不是“新渠道增长”“效率提升”等总括叙述；
4. 产品／价格／补贴／渠道费用／原料和营运资本是否并发，若是则默认只结算 package；
5. 缺任一项立即 `NO_PRIMARY`，不再仅因官方材料可得而下载更多报告。

这已改变下一轮的来源入口：候选先调用普通公告和 `relation` 两个正式 inventory，再决定是否打开正文。但 learning application 尚未由下一家不同公司实际冻结并独立 reviewer 确认；R-73 不把自己登记为该闭环已经完成。

## 6. 根因、影响、处置与验收

- **根因：** `ACQUISITION_MODULE + REASONING`。来源枚举遗漏官方活动记录；而“有行动原件”又容易被误当作已拥有竞争机制和五层结果链。
- **经济影响：** 漏读会把真正管理动作排除在筛选外；反过来，若把组织升级或渠道叙事直接接到总毛利／OCF，会材料性误判正常盈利、owner cash、资本回收和管理质量。
- **缺失事实：** 两公司都缺行动责任边界、D2 同单元指标、D3 分解、D4 现金来源和 D5 增量资本。洽洽还缺能在当时选择 H-A 而非 H-B 的方向性事实。
- **禁止假设：** 官方 PDF、部门升级、终端增长、经销商数量、总收入、总毛利、总 OCF、库存叙述、行业竞争、公司名气、价格或回报即可替代上述缺失。
- **可执行处置：** 关闭两家公司，不再追加结果期正文；下一轮优先找披露渠道／客户单元 KPI、产品／价格／费用口径和行动责任边界的中国公司。普通公告与 relation inventory 必须共同完成。
- **验收：** 对新候选，两个 CNINFO inventory 都能完整分页和物化；D1、D2、D3、D4、D5 分别有预先指定的来源／窗口／禁止代理；H-A/H-B 均有可结算且不同于公平基线的预测。任何缺口均保持 `NO_PRIMARY`。
