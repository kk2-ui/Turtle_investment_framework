# R-03 档案 intake 控制筛查：Berkshire / Coca-Cola（1988）

状态：`CONTROL_REJECTION / TEACHING_ONLY / NO_OUTCOME_READ`

用途：这是对新 intake 门的反向压力测试，不是可口可乐的研究、不是投资判断，也不登记为 Turtle 或外部的合格 episode。选择它是因为“著名、同期原件存在、后来结局广为人知”正是最容易让研究者放松准入的情形。

## 可得的同期原件

- 作者：Warren Buffett，Berkshire Hathaway；目标公司之外的投资者。
- 可见时间信息：发行方将其标为 “Chairman's Letter - 1988”，正文使用 1988 年度数据和年末持仓表；该 HTML 原件本身未给出可核验的发表日。因此本筛查不把它当作已完成的严格 cutoff 证明。
- 原件：[Berkshire Hathaway 1988 Chairman's Letter](https://www.berkshirehathaway.com/letters/1988.html)。
- 原件直接支持的最窄事实：Berkshire 在 1988 年作出 Coca-Cola 的大额买入，写明预期长期持有，并在一般性语境中说明会集中于少数有长期信念、可理解的企业。

## intake 逐项筛查

| 准入条件 | 控制对象的状态 | 为什么 |
|---|---|---|
| 同期、可定位的外部原始判断 | `PARTIAL` | 有按 1988 年标记的原件，且作者不是目标公司；但页面未给出发表日，未满足严格时间戳要求。 |
| 目标公司当时状态与所选经营机制 | `FAIL` | 这封信披露了买入和持有意图，但没有说明 Coca-Cola 的客户选择、渠道、成本或资本配置如何传到未来经营结果。 |
| H-A/H-B 或最强反方 | `FAIL` | 原文没有为 Coca-Cola 写出可与主张竞争的替代机制。不能用后来常见的“品牌护城河”叙述补入。 |
| 指标、方向、口径和窗口 | `FAIL` | “长期持有”不是经营指标、方向阈值或可结算窗口。 |
| 独立结果链 | `NOT_READ` | 按控制设计不读取结果；前三项已足以拒绝，因此没有理由再用结局修补原判断。 |

## 裁决与方法更新

裁决：`TEACHING_ONLY / NOT_ARCHIVED_EX_ANTE_EXTERNAL`。

这个对象可以保留一个问题路由——“长期持有意图背后究竟是哪条可观察的客户选择与竞争机制？”——但不能形成状态向量、近失效证据、经验频率或任何“作者/方法预测正确”的记录。

本控制筛查使 R-03 的准入规则新增一条可操作表述：**外部作者的真实持仓、一般性信念或事后声望，不能替代公司层面的可结算预测语法。** 若原件只表达了行动或持有意图，先按 R-02 的“行动不等于经济判断”处理；不再为它寻找有利结果。

下一步不是扩大可口可乐阅读，而是在既有路由卡和公开档案中寻找同时具备“公司机制 + 对立解释 + 经营指标/窗口”的外部原件。找不到时，正确产出仍是 `QUESTION_ONLY`。
