# R-20：2005–2006 结果复盘——正经营现金流也可能只是退出式现金转换

前置冻结卡：[2004 年 TCL—汤姆逊彩电整合判断卡](01_2004_pre_outcome_enterprise_judgment_card.md)。

状态：`RESULT_KNOWN_TEACHING / OUTCOME_RESOLVED_FOR_MECHANISM / NO_TOTAL_TRANSACTION_VERDICT`。

本复盘只检验冻结的经营命题：资产合并是否已变成由 TTE 自己控制、能穿过技术转换和价格竞争的持续经营系统。它不把 2005/2006 的结果外推为 TCL 集团、跨境并购或中国企业全球化的总体结论。

## 3. 这张边界卡真正训练的判断

1. **交易文件中的控制权，与经营系统中的控制权不同。** 资产合并后仍可能由原方掌握销售、营销或服务；在这之前，不能让协同机制承担完全责任，也不能把失败/成功全部归于收购。
2. **技术范式会改变成本优势的经济身份。** 2006 年报明确描述 CRT 向平板/数字转换及价格压力；旧产品的制造规模不自动迁移为新产品的品牌、研发、供应链和渠道优势。
3. **OCF 必须解释成一座桥。** 2006 的正 OCF 与存货、应收和应付的同时变化共存；在持续亏损、重组和产品线收缩中，它更可能首先表示现金占用释放，而不是 owner-cash 已恢复。

## 4. 对飞轮的新增约束

R-19 已要求 `bridge_funding_terms / recurring_earnings_bridge / cash_conversion_bridge / two_period_persistence`。R-20 在不同公司和不同市场状态下验证了这四项确实改变结论，并新增一项：

5. `operating_control_completeness`：明确记录产品、采购、销售、营销、售后、定价和渠道各由谁控制，及何时实际转移。只有这些环节与 H-A 的传导相匹配，利润/现金序列才是对该机制的公平测试。

下一个不同中国公司的整合、渠道接管或能力收购卡，必须在结果前逐项写出五项字段；若控制权仍在过渡期，结算只能评价已完成的箭头，不能将集团总收入、一次性 OCF 或后来的组织重组裁决为初始决策能力。

根因：`REASONING + DATA_COVERAGE`。若把 2006 的 OCF 单独作为“现金恢复”，或把 2004 年的控制性资产合并理解为 2004 年即拥有全链条商业控制，就会误判正常盈利、现金转换和整合的永久损失边界。缺失的事实是 TTE 内原汤姆逊业务逐项现金和营运资本归属、交易资本的逐项用途、以及无合并反事实；禁止从总体销量、规模、年末现金、后来品牌位置、价格或回报补足。

本案最终判断：`EARLY_MECHANISM = MIXED_WITH_RIVAL_SIGNAL`；`TERMINAL_OPERATING = SUPPORTS_RIVAL_FOR_ORIGINAL_INTEGRATION_PATH`；`CASH_CONVERSION = NOT_DIAGNOSTIC_AS_OWNER_CASH`；`DECISION_LOGIC = NO_PRIMARY`；`TOTAL_TRANSACTION_ECONOMICS = UNKNOWN`。
