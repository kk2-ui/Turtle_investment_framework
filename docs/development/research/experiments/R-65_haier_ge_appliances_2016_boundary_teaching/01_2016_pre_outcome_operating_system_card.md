# R-65｜海尔—GE Appliances 2016：独立运营是否仍能形成经营接口

状态：`RESULT_KNOWN_TEACHING_ONLY / BOUNDARY_REPLICATION / NO_PRIMARY / CURRENT_RESEARCHER_RESULT_EXPOSED`。

R-65 是 R-64 的跨公司边界复验，不是“海尔收购成功”的故事。两案在交易后都保留目标的当地管理/独立运营安排；本案检验的只是一个更窄问题：**独立运营本身不是整合已发生或未发生的证据，必须逐项查验采购、研发、供应链、渠道和服务的真实经营接口。** 研究者已知 2016–2017 的结果，故不进入选择准确率、估值、价格或回报。

## 2. 完整企业系统与竞争机制

```text
北美成熟家电客户、零售/工程渠道、当地制造与品牌信任
  → 海尔取得 GEA，并保留本地管理和日常经营
  → 是否把全球采购、研发、供应链和渠道资源接到当地经营系统
  → 零售商、工程渠道和消费者的产品/服务选择
  → GEA 产品收入 × 价格/成本/组合 × 销售投入
  → GEA 的应收、库存、应付和可得现金
  → 交易现金、债务融资和责任单元资本回收
```

| 机制 | 组织设计 → 客户/竞争 → 经济后果 | 最怕的事实 |
|---|---|---|
| H-A：有边界的整合能保留当地客户系统并接入全球能力 | 本地团队保留产品/客户反应速度，全球采购、研发、供应链和渠道平台有可观察的双向接口 → 外部渠道、产品和效率改善。 | “协同”只停在愿景、会议或集团合并；没有接口、客户/渠道或目标主体经营变化。 |
| H-B：独立运营使交易主要停留在资本和治理层 | 本地团队继续运行，但全球能力没有转化为目标主体可验证的采购/产品/渠道工作 → 任何结果主要是 GEA 原有经营或宏观状态。 | 存在明确的经营接口，并与目标主体外部产品、渠道或成本观察在时间上相连。 |
| H-C：北美行业/原有目标经营主导 | GEA 原有品牌、客户、制造、行业周期和竞争可单独解释销售及盈利变化。 | 即使控制行业/原有基线后，接口出现顺序与目标主体经营变化仍可辨认。 |

### 为什么仍然不能选择主路径

交易前的客户基础、品牌、制造资产、当地管理和“协同”愿景可同时支持三条机制。文件中“首年 EPS 增厚”的管理层预期不是非共同经营事实，更不能代替公平基线。因此本卡固定为 `NO_PRIMARY`：它只训练组织接口如何被检查，不把后续表现倒灌成海尔在 2016 年已正确选择 H-A。

## 3. R-64 的实际应用：五层时钟合同

R-64 的有效约束在本卡中变成可检查字段，而不是一句“保持独立”。

| 时钟 | cutoff 前基线 | 2016–2017 只允许的观察 | 上限与禁止替代 |
|---|---|---|---|
| D1 决策实施 | 控制权完成；日常经营仍由当地团队负责，董事会与全球平台可提供战略/资源。 | 每一采购、研发、供应链、渠道、产品或服务接口的主体、日期和实际落地；结果期新增营销/产品行动单独编号。 | 可结算 `OPERATING_INTERFACE_OBSERVED`；不以并表、董事会、口号或管理层留任代替。 |
| D2 客户/竞争反应 | GEA 已有零售、工程和服务网络；不能把品牌遗产当客户持续选择。 | 目标主体的新增零售/工程渠道、同产品客户/渠道指标及独立来源的竞争反应。 | 公司自述的份额或促销结果至多是 `COMPANY_REPORTED_OUTPUT`。 |
| D3 单位经济 | 交易文件给出 2014 GEA 收入和 EBITDA 的历史量级，但没有按产品的价格、成本、组合或销售投入合同。 | 同一目标主体的产品收入、价格/成本/组合、销售投入与经营利润。 | 只有收入或并表净利时，最高为 `OPERATING_OUTPUT_OBSERVED`。 |
| D4 营运资本与现金 | 交易资本与买方融资明确，GEA 单独营运资本/现金基线未冻结。 | GEA 自身的 OCF 与应收、存货、应付、预收和融资桥。 | 海尔合并 OCF、年末现金、债务融资或收购带入的资产负债表都不替代。 |
| D5 资本回收 | 买方以现金购买资产，交易说明给出约 `US$5.4bn` 基础对价；无责任单元自由现金/替代路径。 | 实际交易资本、后续投入、目标单元税后自由现金和可行替代方案的同边界关系。 | 交易完成、并表利润、商誉、股价、集团 ROE 或后来的品牌地位均不允许。 |

停止规则：若 D1 只有独立运营描述、D2 只有母公司口径、D3 没有产品成本/费用、D4 只有合并现金或 D5 没有责任单元回报，必须保留相应 `UNKNOWN/NOT_DIAGNOSTIC`；不得因 R-64 的相反表面结局而硬作近失效裁决。

## 4. 结果附页的合法用途

冻结后的 [2016–2017 结果复盘](02_2016_2017_outcome_resolution.md) 只检查接口是否真实存在、输出能否归属、现金与资本边界是否仍缺失。它不得把这张边界卡写成“独立运营应该保留”或“跨境收购方法成功”。

根因分类：`REASONING + DATA_COVERAGE`。如果把独立管理等同于没有整合，就会错失 D1 的真实组织设计；如果以集团收入、并表净利或公司自述份额补 D2–D5，又会材料性高估正常盈利、owner cash 和交易资本回收。缺失的是结果前非共同方向证据、外部客户反应、产品成本桥、GEA 独立现金流和责任单元回报；禁止以公司名气、价格或回报填补。
