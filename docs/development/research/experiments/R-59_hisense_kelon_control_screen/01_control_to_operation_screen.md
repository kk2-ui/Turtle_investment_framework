# R-59｜海信—科龙 2005–2006：控制权与紧急销售代理的边界筛查

状态：`SCREENING_ONLY / NO_PRIMARY / NOT_FROZEN / OUTCOME_BODY_UNREAD`。

本筛查检验 R-58 的下一道入场门：一个看似拥有控制权、关联营销接口、产品与现金资料的中国家电对象，是否真的能支持“控制权转为经营协同”的结果前判断。结论是否定的；这不是停止研究，而是防止把一段危机救助和后来的恢复写成收购协同。

## 4. 筛查结论与可迁移教训

R-59 不是 R-58 的 boundary replication，也不应继续用更多后来年报补洞。它有一个很具体的训练价值：**关联方代理、预付款、产品所有权转移和短期回款恢复可以比正式控制权更早发生；如果不先画出时间和经济边界，研究者会把救助性交易、危机去杠杆或旧会计异常误写成收购后的经营能力。**

根因分类：`REASONING + DATA_COVERAGE`。这里不缺公司故事或法定文件，缺的是控制完成后的、与代理救助/历史异常隔离的同主体产品、客户与现金起点。强行继续会材料性误判正常盈利、owner cash 和资本配置，也会把“控制权”错误当作企业系统改善。

禁止假设：

- `26.43%` 协议、董事更替或关联代理自动等于经营控制已发挥效果；
- 代理销量、经销商回款、预付款或年度 OCF 证明客户采用或协同；
- 后续资产重组、集团注入、品牌规模、价格或回报可以填补这个时间/实体边界。

只有另一对象在正式控制**之前**已经能冻结控制完成日、持续经营接口、同产品外部客户/单位经济、完整现金桥与资本责任单元，才可作为 R-58 的近失效或边界复验。R-59 到此关闭，不读取结果期。
