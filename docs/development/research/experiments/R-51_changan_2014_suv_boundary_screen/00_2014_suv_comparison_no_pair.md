# R-51：长安 2014 自主乘用车——为什么不是长城—哈弗的近失效？

## 身份与范围

`RESULT_KNOWN_TEACHING / CASE_SELECTION_BOUNDARY / NO_PAIR / NOT_A_R50_COUNTERFACTUAL`

R-51 不是对长安的经营判断。它检验 R-50 是否能便利地拿另一家自主车企作为“同周期 SUV 对照”。答案是不行：共同的行业状态不足以构成近失效，经济对象和上游机制必须也保持可比。

## 共同条件与不可比条件

[长安 2014 年报](https://www.changan.com.cn/uploadfile/2015/0416/20150416071127407.pdf)披露：长安自主品牌狭义乘用车销量 76.9 万辆、同比 +39.4%，公司也经历产品结构调整与中国自主品牌竞争。这足以作为 R-50 的**行业背景复验**：当时自主品牌与 SUV/产品结构的变化不是长城独有。

但同一份年报同时明确：其“公司及下属合营、联营企业”的产销、统计口径收入和利润混入多个不同经济单元，且归母利润大增的重要原因包括长安福特投资收益。它没有提供可与哈弗品牌/车型、网络调整和集团现金作同一机制结算的责任单元桥。

| 近失效所需条件 | R-51 实际状态 |
|---|---|
| 与 R-50 同样的品牌独立/资源重配动作，且只翻转一个上游中介 | 自主品牌增长与产品调整存在，但品牌、产品、渠道、合资和组织边界均不同。 |
| 可比的同一产品/客户结果 | 仅有自主乘用车聚合销量，不能映射至哈弗 SUV 的产品—客户机制。 |
| 可比的单位经济与现金 | 长安合资/联营及投资收益混入集团利润；无同一责任单元的现金对照。 |

## 本轮结论

`RETAIN_AND_NARROW / SAME_CYCLE_IS_NOT_SAME_MECHANISM / NO_PAIR_IS_A_VALID_SELECTION_RESULT`

根因：`REASONING + DATA_COVERAGE`。若仅因同在 2014 年中国自主车市增长就把长安和哈弗拼成反例，会材料性误判产品/品牌机制、正常盈利与现金，并把合资投资收益误作产品聚焦的结果。缺失的是同一行动、可比责任单元、同口径产品/客户和现金合同。禁止用宏观同周期、总销量、集团利润、排名、价格或回报补足。验收是另找只改变一个上游中介且具有同层级经济数据的对象；此前 R-50 只能保留单卡教学身份。
