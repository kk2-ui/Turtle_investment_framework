# R-06 迁移与结算计划

- FY2027 Q3 可作为约 3 个月的脉冲观察，但不裁决持续性；若读到，仅追加为 `NONDIAGNOSTIC`。
- FY2027 Q4 是约 6 个月早期结算，FY2028 Q2 是约 12 个月延续结算。二者必须从 Walmart 自有 `corporate.walmart.com` HTML 或 `stock.walmart.com` IR PDF 的首次结果包取得。
- R-06 结果完成后，与 R-05 作方法比较：不是比较哪个公司更好，而是比较餐饮与零售中“同口径客户交易量两次持续”是否是有诊断力的共同训练对象。
- 两个对象任一出现定义变化、两期方向相反或共同持续正值，都只更新信号选择规则；不能据此计算准确率、基准率或概率。
- R-03 的结构化类比仍不因 R-06 启动而解锁；它需至少一个有结果的 `LIVE_FORWARD` episode，且另有真实结构断裂反例。
