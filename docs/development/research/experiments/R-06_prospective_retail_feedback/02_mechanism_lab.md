# R-06 机制竞争实验：全渠道增长是否转为持续交易

状态：`FROZEN_REAL_FORWARD / EARLY_PENDING / TERMINAL_PENDING`。

## 共同问题

Walmart U.S. FY2027 Q2 可比交易量同比 `+1.5%`，同时电商销售 `+24%`、电商对同店贡献约 `510bp`。这既可能是便利性/市场平台改善，也可能与价格投入、药房通缩、品类及其他共同因素同时存在。现有事实不允许在两者之间直接归因。

## H-A：全渠道便利性形成较稳定的客户交易改善

```text
门店履约、配送、市场平台与会员便利性
  → 更多可服务场景/更低交易摩擦
  → 可比客户交易在独立后续季度保持为正
  → 电商增长不只是一季与价格投入并存的表观现象
```

必要可观察箭头：FY2027 Q4 与 FY2028 Q2 的 Walmart U.S. 可比交易量同比均大于 `0%`，且公司定义延续。

## H-B：当前交易量与增长由共同/短期因素支撑，尚不能证明持续关系

```text
价格投入、通胀/监管、品类和当期活动等共同因素
  → 当前同店与交易量增长可与电商增长同时出现
  → 便利性机制的独立因果份额无法由 Q2 推出
  → 至少一个后续可比季度的交易量回到非正
  → 当前增长不能被外推为稳定的客户频次或单位经济性
```

必要可观察箭头：两个后续季度中至少一个 Walmart U.S. 可比交易量同比 `<=0%`。

## 不进入本实验的传导

关税退款、价格投资、广告、会员、市场平台、利润率、库存、现金流和管理层长期战略都是机制发现或替代解释，不是此轮裁决物。R-06 只判定“当前正交易量是否持续”这一箭头；即使 H-A 得到支持，也不证明任何一个单独动作是原因。
