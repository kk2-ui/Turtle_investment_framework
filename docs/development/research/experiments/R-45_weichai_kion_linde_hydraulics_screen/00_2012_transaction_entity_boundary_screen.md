# R-45：潍柴—凯傲/林德液压 2012——公开目标集团，是否就足以结算中国收购方的经营判断？

## 身份与范围

`RESULT_KNOWN_TEACHING / CROSS_BORDER_PARTNERSHIP_SCREEN / NO_PRIMARY_FOR_DEAL_RETURN / NO_TURTLE_BACKTEST`

本卡不是另一份“潍柴国际化成功”的报告。它是 R-44 后的不同主体复验：目标集团有公开、连续的年报，是否已能把中国买方的交易控制权、被控制实体的经营与现金回收分开？答案是仍不能，因此它训练的是**何时拒绝一个看似数据充分的并购故事**。

## 当时交易对象：两个不同的经济单位

凯傲当时的[2012 年交易披露](https://www.kiongroup.com/cn/Press/Press-Releases/Press-Releases-Detail.html?id=GIBRALQJGRABSVSCZSNMMFZW&title=DGAP-News%3A+Weichai+Power+und+KION+Group+gehen+langfristige+strategische+Partnerschaft+ein&type=corporate)与其[2012 年债券年报](https://www.kiongroup.com/KION-Website-Main/Investor-Relations/Reports-Presentations/2012-Reports-Presentations/2012-Reports/KION_Group_Bond-Report-2012.pdf)可共同确认：2012 年 12 月 27 日，潍柴通过增资取得凯傲控股公司 25%股权（4.67 亿欧元），并取得新拆分的林德液压 70%（2.71 亿欧元）；凯傲保留 30%。后续项目包括发动机、部件、网络与中国叉车业务合作，但仍须另行落实项目协议。

所以本案从一开始就是两个责任单元：

```text
潍柴对凯傲：少数股权 + 战略合作
潍柴对林德液压：70% 控制权 + carve-out 后的独立实体
```

把凯傲集团看作潍柴“收购并控制的目标”会直接改变要研究的经济对象，是第一处不可接受的偷换。

| | H-A：合作/控制权形成可归属的实体经济 | H-B：资本结构、原有凯傲周期和报表边界解释可观察结果 |
|---|---|---|
| 真正需要观察 | 林德液压收购前后的收入、客户/产品或服务、应收/库存、经营现金与资本占用；或能隔离的潍柴—凯傲合作项目 | 凯傲集团的收入、现金、IPO/再融资、原有品牌和行业周期均可变化，但不说明潍柴项目或林德液压经济回报 |
| 当时已知的中间条件 | 交易、70% 控制、长期供应安排与合作项目 | 少数持股并不等于凯傲控制；项目仍待实施；交易也重塑凯傲资本结构 |

## 结果期公开资料为何仍不可裁决

凯傲的[2013 年报](https://www.kiongroup.com/KION-Website-Main/Investor-Relations/Reports-Presentations/2013-Reports-Presentations/2013-Reports/KION-Group-Annual-Report-2013.pdf)确实给出了连续集团级数据：2013 年经营现金流 3.361 亿欧元、自由现金流 2.026 亿欧元，低于 2012 年的 4.140 亿及 5.181 亿欧元；年报同时明确 2012 年自由现金流受出售液压业务的 2.597 亿欧元流入影响，2013 年还发生 IPO、债务再融资及与出售液压业务有关的一次性税款。它也披露 2013 年凯傲向林德液压购买货物/服务 1.141 亿欧元、对其销售 0.170 亿欧元。

这些材料有价值，因为它明确**不能**这样结算：

- 凯傲集团现金不是潍柴控制下的凯傲现金，更不是林德液压现金；
- 2012 年现金改善包含出售林德液压收到的现金，不能被倒写成合作已经提高经营现金；
- 2013 年的采购/销售额证明存在交易关系，却没有给出林德液压独立的收入、毛利、服务/质量、营运资本或经营现金；
- IPO、资本增加和债务再融资是凯傲资本结构事件，不是潍柴合作项目的经营结果。

因此正确输出为：

```text
TRANSACTION_AND_ENTITY_BOUNDARY: OBSERVED
KION_GROUP_OPERATING_AND_CASH_SERIES: OBSERVED_BUT_NONATTRIBUTABLE
LINDE_HYDRAULICS_ENTITY_ECONOMICS_AND_CASH: UNKNOWN
WEICHAI_KION_PROJECT_EFFECT_OR_DEAL_RETURN: NO_PRIMARY
```

## 对 R-44 的真实应用

R-44 的约束不是“找一份目标集团年报”即可解除，而是：**每一笔交易先画控制权地图，再为受评对象取得连续、同口径的责任单元经营与现金。** R-45 按该规则在结果已经可见时仍拒绝结论；这正是训练飞轮需要的可观察行为改变，而非资料不足时的停摆。

本案应保留的链为：

```text
交易条款/控制权
→ 少数持股集团 与 受控 carve-out 实体
→ 各自可归属的客户/经营结果
→ 各自现金、资本占用与回收
```

只有最后两段落在同一实体上，才可能讨论企业家的资源配置后果；集团规模、全球排名、合作公告或股价均不能代替。

## 下一轮准入要求

若继续研究这类交易，下一张卡须在打开结果前同时定位：

1. 买方对每个受评实体的控制权、取得时间、交易现金与债务/或有义务；
2. 被控制实体的收购前后同定义收入/订单与单位经济或服务责任；
3. 被控制实体的应收、库存、经营现金与资本占用；
4. 少数股权被投企业的业绩、融资与市场周期作为独立背景，不得替代 1–3。

缺任一项，状态是 `NO_PRIMARY`，而不是再扩大阅读凯傲或潍柴年报。

## 本轮结论

`RETAIN_AND_NARROW / PUBLIC_TARGET_REPORT_IS_NOT_ENTITY_ECONOMICS / CONTROL_MAP_PRECEDES_OUTCOME_READING`

根因：`REASONING + DATA_COVERAGE`。将公开目标集团年报、凯傲现金或合作往来直接归因于潍柴的资本配置，会材料性错判交易后的正常盈利、现金承受力与资本回收。缺失的是林德液压/可隔离合作项目的连续经营和现金资料。禁止以集团收入、IPO/融资、出售所得、供应关系、品牌声誉、股价或回报补足。验收是在一个不同交易中，先完成控制权地图，再读到同一受控实体的前后经营和现金合同；否则该规则只训练“正确不下结论”。
