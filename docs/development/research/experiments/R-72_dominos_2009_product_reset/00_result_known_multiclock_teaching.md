# R-72｜Domino’s 2009 产品重置：客户反应、经济与现金必须沿不同的时钟结算

状态：`RESULT_KNOWN_TEACHING / OUTCOME_EXPOSED_NOT_A_BLIND_TEST / NO_SELECTION_SCORE / CROSS_INDUSTRY_BOUNDARY`。

本卡是跨行业的、已知结果教学材料，不是一次历史盲测，也不评价研究者是否在 2009 年作出了正确选择。结果期资料在本轮研究前已暴露；因此它只能训练企业系统的机制边界，不能计入选择判断、方法胜率、公司总体质量、证券价格或投资回报。

它检验一个更窄的问题：当企业同时改变核心产品、价格促销、广告和担保时，怎样避免把强劲客户反应误写为“单一产品决策已经被证明正确”，以及怎样把经营、现金和资本分别停在证据真正到达的位置。

## 1. 证据范围与历史防火墙

结果前材料只使用两份 Domino’s 官方投资者关系发布：

- [2009 年第三季度业绩（2009-10-13）](https://ir.dominos.com/news-releases/news-release-details/dominos-pizza-announces-third-quarter-2009-financial-results)：美国国内同店销售持平，并定义了同店销售和 `free cash flow = CFO - capex` 的口径。
- [核心披萨配方重置公告（2009-12-16）](https://ir.dominos.com/news-releases/news-release-details/celebrating-50th-year-dominos-pizza-gives-itself-makeover)：新面饼、酱料和奶酪自 12 月 27 日起在美国门店推出；同一公告也披露密集广告、全国试吃、两份中号两种配料披萨 `$5.99` 的引介优惠及退款保证。

结果期只使用两份同一发行人的官方发布：

- [2010 年第一季度业绩（2010-05-04）](https://ir.dominos.com/news-releases/news-release-details/dominos-pizza-announces-first-quarter-2010-financial-results)。
- [2010 财年业绩（2011-03-01）](https://ir.dominos.com/news-releases/news-release-details/dominos-pizza-announces-2010-financial-results)。

工作包中结果前和结果期源包均为 `COMPLETE`；但本卡的 `OUTCOME_EXPOSED` 标签意味着该完整性不能倒转为盲测资格。没有价格、总回报或其后品牌故事进入任何结论。

## 2. 截止日前的企业动作与竞争机制

### D1：可观察的实施不是一个“新品”点事件

12 月公告说明的是一个全系统 package：核心配方全国切换、广告投放、试吃、低价引介和“满意否则退款”保证同步发生。它可结算为 `IMPLEMENTED_PACKAGE`；不能被缩窄为“只改变口味”。

Q3 的美国国内同店销售为 `0%`，可作为最简单的延续基线：如果动作没有形成额外的国内可比门店反应，随后同口径增长不应系统地高于这一持平状态。它是较早一个季度、而动作在 12 月末上线，故只是一条公平的描述性 continuation baseline，不是能隔离反事实的因果估计。

### 同一现象的两张完整机制图

| 层次 | H-A：产品质量重置是主要客户驱动 | H-B：真实的 package 反应，但不能归因于配方本身 |
|---|---|---|
| D1 实施 | 配方改变解决了既有质量／口味问题；传播让客户得知。 | 配方、低价、广告、试吃与保证联合刺激试用；没有哪一项在当时被单独随机或分区域展开。 |
| D2 客户／竞争反应 | 国内同店交易／销售在首个完整季度显著高于 `0%`，并随后保持正增长。 | 同样可发生；优惠价格、广告和退款保证本身也预期会提高试用与交易。 |
| D3 单位经济 | 同店增长可穿透至系统经营利润率，商品成本与渠道费用不吞噬改善。 | 价格／促销、广告基金、商品成本、供应链销量和其他门店／国际因素共同塑造报表，产品本身的量价成本不能由合并口径识别。 |
| D4 现金转换 | 重复顾客与门店交易带来可持续、可归因的经营现金。 | CFO 可能为正，但营运资本内部来源、债务交易和整个加盟／供应链系统边界未拆开；不能称作产品的 owner cash。 |
| D5 资本回收 | 增量产品、营销和门店资本的税后现金回收高于替代方案。 | 没有动作专属投入、加盟商投入、反事实或长期责任单元资本资料；资本回收仍未知。 |

这不是“成功 vs 失败”的叙事。H-B 允许整个 package 产生真实客户反应；它反对的是把事后强劲销售归给披萨配方这一单一箭头。

## 3. 多层时钟的历史结算

| 时钟 | 预先应问的事实 | 官方结果观察 | 可结算范围 | 不允许跨越的结论 |
|---|---|---|---|---|
| D1 决策实施 | 配方及其商业化是否真正在全美上线？ | 12 月 27 日开始在美国所有门店改用新配方；优惠、广告、试吃及保证同步。 | `IMPLEMENTED_PACKAGE`。 | 不把实施本身写成消费者已经认可或产品单独有效。 |
| D2 客户／竞争反应 | 国内可比门店是否超过 `0%` 延续基线？ | 2010Q1 国内同店销售 `+14.3%`；2010Q4 `+6.3%`、全年 `+9.9%`。 | `SUPPORTS_CUSTOMER_RESPONSE_TO_PACKAGE`，且初期反应后仍有年度正增长。 | 不以这些数字裁决“口味是唯一／主要原因”；公司自己的结果文字也同时归因于消费者反应和广告。 |
| D3 单位经济 | 客户反应是否至少没有立刻被合并经营经济吞没？ | 2010Q1 总经营利润率 `28.3%`，上年同期 `27.6%`；总收入增长 `18.4%`。发布同时说明供应链商品成本较高、供应链量和国内外同店销售等共同影响。 | `EARLY_PACKAGE_ECONOMICS_NOT_WORSE_IN_REPORTED_AGGREGATE`。 | 不由总利润率推出披萨的价格／组合、单位食材成本、加盟商利润或广告费用后的产品贡献。 |
| D4 营运资本与现金 | 现金来自顾客回款，还是库存／供应商／融资及集团项目？ | 2010Q1 CFO `$32.590m`、capex `$5.146m`；2010 全年 CFO `$128.325m`、capex `$25.421m`。Q1 只有汇总营运资本变化，未给动作专属 AR／库存／应付桥；两期均伴随重要债务交易。 | `CASH_GENERATION_OBSERVED / CASH_ORIGIN_INCOMPLETE`。 | 不把公司定义的 FCF、正 CFO 或债务偿还写成产品改革的 owner cash。 |
| D5 资本回收 | 新配方／营销／店铺系统的增量资本是否回收？ | 全年资本开支主要披露为技术投入，另有债务回购；没有本动作投入、加盟商资本、可比替代或责任单元现金回报。 | `CAPITAL_RETURN_UNKNOWN`。 | 不以门店净增、债务回购、总公司 FCF、股东回报或品牌后来地位作 D5 替代。 |

早期顾客响应和较长的年度正同店销售让“客户对 package 有响应”成为有效经营学习；它们不自动结算任何配方单独、现金来源或资本配置判断。这正是多层时钟的用途：不能因 D2 强就跳过 D3–D5，也不能因 D5 未知否定 D2 已经观测到的事实。

## 4. 对企业家式判断的训练含义

1. **从客户问题到系统动作。** 管理者不是只推出产品，而是在同一时间改变产品、沟通、价格和风险承担。研究应先把这组动作列为一个 package，再问哪个箭头仍可隔离。
2. **把“反应发生”与“为什么发生”拆开。** 同店销售显著高于持平基线，说明有客户／交易反应；但价格优惠、广告和保证同时发生，说明“产品质量是原因”的选择判断没有得到公平检验。
3. **把报表利润还原到单位经济。** 总经营利润率没有恶化只是早期系统信号。它不替代产品价格、食材／履约成本、加盟商与广告基金经济。
4. **把现金的存在和现金的来源拆开。** CFO 减 capex 可以是可用观察，但不能压扁营运资本构成、融资与动作专属投入；产品或渠道改善不能仅凭 FCF 获得 owner-cash 结论。
5. **把未知保留在最慢的时钟。** 没有责任单元资本与反事实，D5 为 `UNKNOWN` 是正确结算，不是研究不完整的借口。

## 5. 中国制造与跨行业的迁移边界

Domino’s 的美国本地加盟体系、公司供应链、餐饮高频交易、两份 `$5.99` 披萨优惠及其广告／退款机制，都不是中国家电或制造企业可直接复制的制度和经济环境。它不能支持“降价加广告就能修复品牌”或“产品重置总能带来长期经济价值”的规则。

可迁移的只是研究动作：

```text
客户反馈／质量问题
  → 产品、渠道、价格、服务承诺的具体 package
  → 同责任单元的客户采用／交付
  → 量、价格／组合、单位成本、渠道／服务费用
  → AR、存货、预付、客户预收、AP 与外部融资的现金来源
  → 增量资本与替代方案下的回收
```

因此下一张**不同中国公司**的产品／渠道冻结卡必须在结果前实际改变下列字段：

- `D1_ACTION_AND_STOP_RIGHT`：行动的责任人、资源、上线和停止／调价权；
- `D2_UNIT_ADOPTION_OR_DELIVERY`：同一产品、渠道或客户单元的采用／交付，不用行业销量或公司总收入替代；
- `D3_GROSS_MARGIN_BRIDGE`：事先分开 `price_or_mix / unit_cost / channel_or_service_cost`；
- `D4_CASH_ORIGIN_BRIDGE`：收款、存货、供应商融资和外部融资逐项设定，禁止用一项 OCF；
- `D5_CAPITAL_BOUNDARY`：动作专属资本、窗口、替代与 `UNKNOWN` 停止条件；
- `BUNDLE_CONFOUNDING_RULE`：若产品与折扣、广告、渠道补贴或保证同步，结算默认只回答 package，除非结果前已有可比的分期／地域／单元差异设计。

该引用未来必须出现在不同公司的结果前冻结字段中，并经独立 reviewer 确认；本文件本身不构成已经闭合的 learning application。

## 6. 结论、根因与停止条件

- **本卡保留的结论：** 已观察到一个全国实施的商业 package 及显著、随后仍为正的国内可比门店客户反应；早期汇总经营利润率未恶化，经营现金存在。
- **本卡拒绝的结论：** 新配方单独造成销售增长；产品单元经济、客户现金来源、加盟商经济或资本回收已经被证明；管理层总体正确或值得投资。
- **根因：** `REASONING + DATA_COVERAGE`。并发产品、价格、广告与保证使因果归属不可识别；公开结果只给合并／系统口径，缺动作专属单位经济、营运资本和资本边界。
- **经济影响：** 若把 D2 或总 FCF 直接写成产品与资本决策正确，将材料性高估正常盈利、owner cash 和资本回收，也会把一个可复制的研究限制误作可复制的商业答案。
- **缺失事实：** 各干预项的差异暴露、产品专属量价成本、加盟商／公司分层的现金桥、动作资本、替代方案与长期责任单元回收。
- **禁止假设：** 管理层归因等于事实；同店销售等于产品质量因果；总利润率等于产品单位经济；CFO/FCF 等于 owner cash；债务回购、门店数量、后续品牌地位、价格或回报等于资本回收。
- **停止条件：** 不再补读结果期以寻找“终局成功”。R-72 已完成其教学任务；下一步只可在不同中国公司的结果前文件中检验第 5 节的冻结约束是否真实改变研究输入。
