# R-26：九阳 2005 年商用豆浆机——产品创新候选的拒绝记录

状态：`SOURCE_SCREEN / RESULT_KNOWN_TEACHING / NO_PRIMARY / CONTEXT_SEPARATION_NOT_ASSURED`。

这是一张有意停止的产品创新候选，不是一张失败案例。它避免把“新产品后来有销量”或“公司后来成为品类龙头”误学成产品判断已经验证。

## 已定位材料

九阳 2008 年 [首次公开发行招股说明书](https://static.cninfo.com.cn/finalpage/2008-05-15/39735740.PDF) 追述：

- 商用豆浆机为 2005 年推出的新产品；2006 年起公司加大营销投入；
- 该产品 2005、2006、2007 年销量分别为 88、588、1,534 台，产销率分别为 60%、67%、104%；
- 文件描述商用客户的容量、速度和产品系列需求，并列示研发项目。

这些数字说明该对象有“B2B 新品引入 → 需求/服务接受 → 产销”这一可研究形状；它们**不**构成 2005 年决策时点的事实包。招股书在 2008 年一次性同时暴露了当时的行动、后续结果和发行人归因，无法切开研究者对结果的接触。

## 方法学习

产品创新不是“推出—销量增长”两段故事。可进入正式或历史自回放的新品卡，至少要在结果前定位：

```text
具体用户痛点与替代方案
→ 被承诺的产品/服务/渠道资源
→ 首批可观测采用（订单、复购、退货、服务负荷之一）
→ 同一产品的单位经济
→ 营运资本和资本回报
```

R-26 只证明候选具有未来可检索价值；不对 2005 年九阳的产品选择、商用豆浆机价值或公司能力作任何结论。若以后找到当年的一手决议/发布、客户合同或当期经营材料，必须新建切断结果的卡，不能回写本页。

根因：`ACQUISITION_MODULE + REASONING + DATA_COVERAGE`。后出的招股书把行动、结果和成功叙事放在同一文本；直接用它训练会让 agent 先知道销量，再把产品主张设计为“可预测的事实”。经济影响是高估新品的正常盈利、服务成本和资本效率，并把幸存者叙事误传为企业家判断。缺失的是同期行动、客户采用、单品单位经济与现金的原始材料；禁止用后来的市场地位、专利、总收入、证券价格或回报补足。

验收标准：只有隔离出 cutoff 前原件和预先定位的同指标结果来源，且至少一条客户采用信号与一条单位经济/现金信号可分开结算，才可从 `NO_PRIMARY` 升级。否则转向另一产品、质量或组织候选。
