# ITER-102 — 行业架构图应解释价值如何被攫取，不是把产业链重画一遍

日期：2026-08-21

Jacobides、Knudsen 与 Augier 在 [2006 年关于 industry architectures 的原始论文](https://doi.org/10.1016/j.respol.2006.09.005) 中把行业架构界定为塑造分工和价值攫取的行业级模板，并将互补性、要素流动性与瓶颈位置作为解释攫取能力的变量。这给 Turtle 的行业深度提供了一个有用但很窄的补充：不是列供应商—厂商—经销商，而是问渠道、安装/售后、产品标准或补贴接口的控制权变化，是否会使 H-A/H-B 出现不同的可观察后果。

格力当前没有同口径全渠道/价格带 sell-out，也没有经销返利、库存归属或安装服务的控制权证据。此时画一张“家电产业链图”只会把公司自述和常识涂成机制，不能确认格力在何处攫取或失去价值。因此路线图保留行业架构图作为受 `analogy_transfer_card` 约束的试验：只有五项结构字段（分工、接口控制、互补资产、要素流动性、价值攫取节点）都可由事实或 `UNKNOWN` 表达，而且图能新增一个会显著削弱对方的 FJ，才允许启动。

根因是 `DATA_COVERAGE + REASONING`。若把垂直整合、品牌、线上排名或经销网络直接当作接口控制，经济影响是会材料性高估渠道护城河、正常利润持续期与 owner cash；反向也可能将渠道数字化夸大为护城河已经失效。禁止从产业链图、行业名称、公司自述或一个渠道排名推出价值攫取、ASP、返利、现金或 H-A/H-B verdict。接纳条件是每个架构节点都链接当前事实/UNKNOWN，且主反机制各自给出一个原本没有的不同观察；当前格力未满足，模块保持 `UNKNOWN`，P0 release 仍是优先级更高的工作。
