## 取证边界与方法

只读取两类材料：

- CNINFO 的 `hisAnnouncement/query` 历史公告官方 metadata，查询日期被显式限制为 `2015-01-01~2018-12-31`，并只保留标题完全为 `YYYY年年度报告` 的记录；
- 该 metadata 所指的 CNINFO 静态 PDF 年报，以及现有 `00_PRE_SELECTION_COHORT_EXPOSURE_LEDGER.json`。

每条以下来源的 `source id` 是 CNINFO `announcementId`；`carrier` 是其同一 metadata 指向的静态 CNINFO PDF。公布日期按 `Asia/Shanghai` 正规化。除已在欧普条目隔离记录的无日期页面触发外，未打开或使用 2019 年及以后的年报、价格、估值、回报、结果、既有目标报告或外部模型 API；该触发没有进入任何判断或来源表。
