# Phase 10 收益与选股评估契约

> 状态：`DESIGN / NOT_YET_ELIGIBLE`  
> 目的：在已有历史冻结契约之上，定义如何分别检验黄金报告标准、推荐个股和买点。本文不把当前九份候选或首个压力案例当成有效收益样本。

## 结论先行

当前试点只能回答“冻结和结算围栏是否工作”。九份候选均为
`INELIGIBLE_NO_HISTORICAL_VINTAGE`，因此现在不能回答推荐个股未来收益是否好，也不能据此改
`P_LONG`、要求回报率、资本化率或买点规则。

当前模型记忆登记为 `UNCONTROLLED / EXPLORATORY / ENGINEERING_DIAGNOSTIC_ONLY`，所以即使未来完成工程 replay，也不能作严格回测、校准或生产选股声明。只有部署级 attestation 支持的 `CONTROLLED / STRICT` case 才可能进入模型记忆受控候选池；当前 validator 尚未开放该路径，且未来仍须满足本文件的宇宙、对照组和 holdout 条件。

后续必须注册两个相互关联但不合并的实验：

1. **标准校准实验**：以点时报告冻结输入检验 `REPORT_COVERAGE` 和
   `MODEL_FORECAST_ERROR`，只据此改证据门、未知项门和模型字段要求。
2. **收益/选股实验**：以同一冻结时点的完整候选宇宙（包括 `NO_BUY`、被拒绝、停牌、退市、
   收购和失败样本）检验 `INVESTMENT_RETURN_OUTCOME`。首个压力案例和用户临时指定案例必须
   带 `PURPOSEFUL_STRESS_CASE`/`USER_SELECTED_CASE` 标签，不得进入无偏总体胜率或参数校准。

三本账不互相抵消：报告覆盖通过但收益差，不等于报告标准失效；收益好但覆盖或模型预测失败，
也不等于黄金报告通过。

经营预测的预注册、年报发布时间走步、重述和口径漂移规则见[经营预测与年报走步结算设计](PHASE10_OPERATING_FORECAST_SETTLEMENT.md)。收益结算不得跳过这本经营账，或以股票回报替代经营判断的检验。

## 预注册单位和流程

最小单位是 `case-vintage`（发行人、冻结截止时间、报告版本的组合），不是公司当前快照。
在看到冻结后的资料和价格前，登记以下内容：

- 候选宇宙的生成规则、纳入/排除理由和当时可见的全量名单；
- `eligible_case_count` 与 `calibration_eligible_case_count`：前者只代表历史资料齐备，后者未来还必须是部署级 attestation 支持的 `CONTROLLED / STRICT / MODEL_MEMORY_CONTROLLED_CANDIDATE`，并且仍需本文件的跨发行人、跨 cutoff 和 holdout 审查；
- 报告版本、证据截止时间、路由（`LONG_TERM_OWNER`、`FINITE_XIRR`、`DUAL`）和动作；
- 观察窗口（例如 1 年、3 年；长期所有者路线不得强行用固定退出价）；
- 执行日规则（冻结后首个可交易日，或预注册的限价触发窗口）；
- 主要终点、次要终点、基准、币种、税费、费用、滑点和公司行动处理；
- 买点候选规则的唯一版本。允许报告多个价格身份，但不能在结算后挑选最有利的一个。

先冻结全部输入和 `calibration_ledger`，再打开 cutoff 后资料。对每个 cutoff 依次完成：

1. 预注册并采集截止日前的官方来源、原始行情和公司行动；
2. 生成并独立审阅冻结报告；质量失败版本照样保留；
3. 打开后续官方披露，按发布时间走步结算预测、`UNKNOWN`、年报版本变化和公司行动；
4. 结算净回报、相对基准和未成交状态；
5. 只在开发集提出规则变化，在时间和发行人均未参与设计的验证集复验。

## 收益结果的可执行定义

### 执行价格

价格身份与报告估值身份分开。默认入口是冻结后首个实际可交易日的原始未复权开盘价，且记录
交易所、时区、交易日、行情文件版本和成交状态。若预注册限价买点，则记录：

- 触发价格、有效期限、成交判定（盘中最低价触发不能假设成交，除非规则明确允许）；
- 未触发/停牌/涨跌停/流动性不足的 `NO_FILL` 状态；
- 未成交资本在同一期间的现金或基准机会成本。

未成交样本不能从分母删除，也不能按零价或最后收盘价结算。窗口内始终无可执行价格时，投资账为
`INCOMPLETE`，而不是人为制造亏损或收益。

### 公司行动、税费、币种

行情使用原始未复权 OHLCV，公司行动单独记账。分红、送转、配股、要约、合并、退市、停复牌和
法律现金回收必须逐项记录；不能用后复权序列代替，也不能把无法确认的回收默认为零。

每笔现金流均记录毛额、适用税率、交易费用、净额、币种和来源。税费采用交易日实际有效的官方
规则，且在实验注册时固定处理口径（包括 A 股卖出印花税、港股印花税/交易征费及股息预扣税，
不能把港股默认税率机械套用到 A 股）。跨市场组合先在本地币种结算，再按预注册的 FX 来源和日期
转换到基准币种；基准必须使用相同币种和现金流口径。

长期停牌、退市、收购或失败案例保留在分母。只有官方现金/股份对价或法律终局已可确认时才结算；
否则投资结果标为 `PARTIAL`/`INCOMPLETE`，同时照常结算报告覆盖和经营预测。

### 基准和指标

基准按市场和冻结时点预注册（例如 A 股沪深 300；港股使用预注册的港股宽基），不得事后挑选表现
最好的指数。至少报告：

- 净总回报（价格、现金分派、税费、费用、FX）；
- 同期基准净总回报和超额回报；
- 1 年/3 年的年化回报或 IRR（现金流不足时为 `NOT_CALCULABLE`）；
- 最大回撤、负回报比例、未成交比例和有效持有时间。

组合结果须同时给出等权和预注册的风险/流动性约束版本，并按发行人聚类给出不确定性；单一
案例或单一市场上涨不能称为选股能力。

## 如何检验“推荐个股”

收益实验的分母是冻结时完整的可覆盖宇宙，而不只是后来被选中的股票。至少比较：

1. `BUY`/可执行推荐组合；
2. 同一宇宙的 `HOLD`、`WAIT`、`NO_BUY` 及被报告门拒绝的对照组；
3. 预注册市场/行业基准和等权全宇宙组合。

`WAIT`/`NO_BUY` 必须定义现金或基准替代，不得把“没有买”当成缺失。只报绝对收益会把市场 beta、
行业暴露和幸存者偏差误判为选股能力。主要终点应是净超额回报和回撤，绝对回报、命中率和持有期
作为次要终点，并保留所有案例而不删除坏结果。

当前 `historical_backtest_settlement.v1` 已包含并校验 `execution`、`corporate_actions`、
`cash_flow_ledger`、`benchmark_identity`、`fill_status` 和逐笔净现金流字段。缺口是没有真实冻结 case、官方行情/公司行动/基准来源账本或结算对象；在这些资料到位前，投资结果仍为 `INCOMPLETE`/`NOT_CALCULABLE`，不能报告选股能力或更好的买点。

## 如何检验“更好的买点”

买点是策略变量，必须与选股变量分开。冻结时同时登记一个基准执行和有限数量的候选触发规则：

- **立即执行**：首个可交易日开盘；
- **估值触发**：价格不高于冻结时已登记的 `P_XIRR`/`P_LEGAL`/条件价格，固定有效窗口；
- **分批执行**：固定比例和固定时间间隔，不能根据后来最低价调整。

每条规则的主要比较是相对立即执行的净超额回报和最大回撤；同时报告成交率、等待时间、现金机会
成本和在未成交情况下的完整组合收益。只因事后回看最低点而重写阈值属于前视偏差。

买点规则只能在开发集更新。每次通用默认值变化至少满足现有交接门槛（10 个已结算观察、3 家
发行人、2 个 cutoff），随后用 12 个未参与设计的 case-vintages 复验；这 12 个不能用于再次调参。
结果应按时间滚动或按发行人留出，避免同一发行人的相邻年份同时出现在训练和测试中。

## 标准是否“进步”的判据

标准改进不能以回报单一指标定义。接受一项候选变更至少需要：

- `REPORT_COVERAGE`：材料性主张支持率、未知项保留率和来源版本错误率不恶化；
- `MODEL_FORECAST_ERROR`：预注册的方向命中率/误差或阈值校准在留出集改善，且永久损失漏报不增加；
- `INVESTMENT_RETURN_OUTCOME`：若声称收益改进，必须净超额回报和风险指标在留出集同时满足预注册门，
  并标明这是探索性关联而非因果证明；
- 任何一个维度无法结算时保持 `UNKNOWN`/`NOT_CALCULABLE`，不得用另一维度补偿。

24 个 case-vintages（六类经济机制、每类四例）只足够做首轮工程校准；在样本达到交接规定的
24 例前，不能宣称黄金标准或选股规则有效。每次报告都要同时写明发行人数、cutoff 数、可结算比例、
未成交/停牌/退市数和留出集定义。
