## 1. 阶段目标

Phase 08验证Turtle能否自动形成完整、正确、可复核并具有资深投资判断深度的价值投资报告，而不是只证明管线能运行或账本能闭合。资深判断至少要求报告从证据中选择中心路径，说明为什么该路径比竞争解释更可能，并把可证伪判断冻结到未来披露节点；并列情景和敏感性不能替代这项工作。

黄金报告必须围绕少数决定价值的产业经济、公司位置、利润/现金形成与长期回报变量形成连续论证。复杂工程和模型在后台服务判断；摘要、评分、章节数量、字节数或排版不能替代洞见。

## 3. 不可妥协的黄金内容契约

所有黄金公司报告必须回答仓库根 `GOALS.md` 第3节列出的共同问题，并保持：

```text
已接纳证据
  → VERIFIED事实与明确UNKNOWN
  → accepted judgments
  → 中心路径与可证伪前瞻判断
  → 确定性模型输入和结果
  → 正常利润、普通股现金、价值与回报
  → 永久损失、最强反方和翻转条件
  → 连续读者报告与render-only HTML
```

关键经营驱动若只出现在文字中、没有生成正常利润并传播到路线适配的普通股现金、V0/VN、期末价、主要回报和主要研究价格，不得接纳为黄金。

## 4. 接纳门

`CONTENT_GOLD_ACCEPTED`至少需要：

1. 完整读者报告与材料性来源索引；
2. 事实、判断、模型输入和结果属于同一经济口径；
3. 普通股索取权、NCI、债务、内部债权、外部资产和现金可达性闭合；
4. 正常利润、owner cash、维护资本、留存价值和终值无重复计值；
5. 估值路线适配公司，不机械平均NAV、EPV、SOTP、GG、DCF或回报结果；
6. 3/5年现金流、终值、税费、币种、价格和要求回报身份明确；
7. 最强反方、永久损失、UNKNOWN与翻转证据足以防止错误行动；
8. 报告选择证据支持的中心路径，或明确说明为何只能保持 `UNKNOWN`；
9. 至少 3—5 项决定性前瞻判断具有方向/范围、时域、领先信号、竞争解释、反证和结果传播；
10. 历史 PIT 判断只能在冻结后通过追加事件结算，当前判断具有到期日；
11. 独立判断、内容和数字审阅没有未关闭的材料性阻断。

机器门只能证明可复核性和硬错误状态，不能自动授予洞见优秀。作者不能自签，局部PASS不能替代完整案例接纳。

## 5. RETURN质量

任何RETURN必须写明：

- 根因：`DATA_COVERAGE`、`ACQUISITION_MODULE`、`REASONING`、`MODEL`或`WRITING`；
- 对结论、永久损失、估值、回报或中心论点的经济影响；
- 缺失事实和禁止假设；
- 可执行修复；
- 可复核接受标准。

数据量、期间或字段不足时先修公共采集模块、schema或validator，再交给模型和写作层。公开证据确实不可得时使用保守区间、降级主张或保留UNKNOWN；只有仍可能翻转结论时才阻断。

审阅返回使用独立的 `golden-report-review-return.v1`，不得把独立盲评对象或读者报告当作修复工作单。开放问题按责任层确定性分流：`DATA_COVERAGE` 进入公共采集/schema，`ACQUISITION_MODULE` 进入采集实现，`REASONING` 回到 `UnderwritingThesis`，`MODEL` 回到确定性模型，只有 `WRITING` 可以直接进入 reader writer。任一材料性上游问题尚未验收时，不生成章节改写目标；公开数据不可得时以上述保守范围或 `UNKNOWN` 关闭，不以文案填补。

reader writer 只接收同一 Episode、已接纳的确定性结论和普通投资语言的修订指令。原始根因标签、缺失事实清单、验收标准、状态码、对象 ID 和内部价格身份不得进入 writer payload；它们只留在修复工单、模型或技术附录。读者覆盖门必须拒绝明显的审阅面板与内部身份，同时允许 NAV、EPV、owner cash 和自然语言不确定性。

## 7. Phase 08完成定义

Phase 08只有同时满足以下条件才能完成：

1. 七类机制责任由接纳的Golden Set覆盖；
2. G1.5证明行业经验与宏观传导对格力判断产生材料性提高；
3. 公司报告能够区分敏感性与中心判断，历史 PIT 结果结算不显示系统性事后解释；
4. 公司、行业、基准率和宏观层权限经G2裁决；
5. Golden Set v1与Industry Experience Pack v1同步冻结；
6. G4统一入口复现冻结对象的经济身份和决定性结论；
7. G5未见公司和未见未来时期均通过；
8. 用户完成一次集合级投资体系与产品方向审阅；
9. GOALS、长期路线图、dashboard、运行手册和实际工件状态一致。

G6完成前不得因History中的旧盲评、旧BENCHMARK状态、旧黄金指纹或旧handoff提前进入Phase 09或一般化Phase 10运行。
