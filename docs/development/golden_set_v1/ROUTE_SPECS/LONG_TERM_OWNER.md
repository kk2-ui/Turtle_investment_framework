# 路线规范：长期所有者回报

## 适用

适用于无明确经营终点、正常盈利可跨周期维持、分红和留存可到达普通股且不依赖五年估值回归的企业。典型候选为格力、中国食品、海螺；鄂尔多斯B可采用双通道而不能自动继承本路线。

## 必须计算

```text
正常 Owner Earnings
- 普通股现金分红
= 留存资金
留存资金 × 有证据约束的认可比例 q
现金分红 + 认可留存价值
-------------------------------- = 长期股东经济回报
当前价格
```

必须分别报告税前/税后、币种、股息税、汇率、维护资本和 q 的影响，并反解 `P_LONG`。五年 XIRR只能作为退出压力测试，不能单独否决长期路线；但长期回报低于要求回报时，不能用“永远不卖”掩盖低回报。

## 禁止

- 将单年股息率称为长期回报；
- 将 q 当作增长率；
- 把未来市场确认加进长期经济所得；
- 把未闭合的金融资产、联营分红或母公司支持自动当作普通股现金。
