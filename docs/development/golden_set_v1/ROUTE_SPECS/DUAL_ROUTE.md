# 路线规范：双通道

## 适用

适用于同时存在可持续经营现金流和有限期限/市场价格不确定性的公司，例如 B 股、控股平台、周期企业或存在资产确认路径的企业。

## 必须排序

报告必须指定主路线和辅助压力测试，说明排序依据。若证据不足，使用 `PRIMARY_ROUTE_UNKNOWN`，分别列出 `P_LONG`、`P_XIRR_FIXED_TERMINAL`、`P_DISCOUNT_PATH`或 `P_LEGAL`，不能取平均，也不能选择较低价格冒充最终答案。

## 结论模板

- 长期持有者：看可持续现金、有效留存、税费/汇率后的 `P_LONG`；
- 必须退出者：看匹配期限的税费后 XIRR 和固定终值条件价；
- 两条路线若结论不同，必须明确这是持有政策差异，而不是模型冲突；
- 任何路线都要列出失效条件和可观察指标。
