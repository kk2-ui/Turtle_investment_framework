# 路线规范：有限期限 XIRR

## 适用

适用于 REIT、特许经营、法律期限、资产处置、重组、项目退出或主要价值依赖市场确认的案例。期限必须来自法律、租约、资产寿命、已知处置安排或明确的投资政策，不得机械统一为五年。

## 必须计算

按实际日期列入买入费用、股息税、交易费用、汇率、分派、债务偿还、终局现金、期末业务价值和期末市场价格。至少同时给出：零确认/无估值回归、有限确认和完全确认（如有证据）的 XIRR，以及达到目标回报的最高买价。

## 价格身份

`P_XIRR_FIXED_TERMINAL`固定已独立证据支持或由当前路径明确生成的期末价格；`P_DISCOUNT_PATH`允许候选买价重新改变期末折价，二者不得混称或平均。法律期限案例必须另列 `P_LEGAL`，并把清算税费、NCI、BOP/债务顺位和最后存续日按实际时间计入。

## 禁止

- 把当前市场价推导出的未来卖价称为业务价值；
- 把条件市场确认写成确定催化剂；
- 用长期 q 或永续增长替代有限期限现金流；
- 在终局年度机械扣除完整全年成本而不按存续期或清算成本解释。
