# Golden Set v1：共同内容契约（G2 裁决版）

> 适用范围：九份候选及后续所有 Golden Set 案例。  
> 状态：`G2_ADJUDICATED / NOT_YET_FROZEN`

## 1. 报告必须共同回答的问题

每份报告可以有不同章节，但必须让读者能够复述：公司如何赚钱、现金如何到达普通股、正常盈利如何建立、价值路线为何适配、回报来自哪里、什么会导致永久损失、当前价格在什么条件下合格。

## 2. 价值链和证据身份

```text
官方证据 -> 已验证事实或 UNKNOWN -> 研究判断 -> 确定性模型 -> 价值/回报 -> 行动边界
```

正文每个材料性数字必须能回到来源或模型输入；来源索引不能代替正文对经济含义的解释。事实、代理、研究判断和情景必须显式区分。

## 3. 普通股现金与价值守恒

报告必须分别列示：

- 合并利润与归母利润；
- 经营现金流与普通股 owner cash；
- 现金、受限现金、实体最低现金和可上游现金；
- 少数股东索取、内部债权抵销和外部投资资产；
- 维护资本、扩张资本、项目资本和一次性清算成本。

任何资产或收益只允许沿普通股价值桥进入一次。若证据不足，使用范围或 `UNKNOWN`，不得用账面净资产、资源量、注册资本或关联方投资收益直接代替可得现金。

## 4. 正常盈利和资本配置

正常盈利必须回答：历史窗口为何代表正常状态、峰值/谷值如何处理、费用率和产品结构怎样影响利润、维护投入是否重复扣除、联营收益如何转现金。使用 `q` 时必须解释留存用途、历史证据、上下界、是否可能耗尽偿债空间，以及 q 变化对价值和回报的传播。

## 5. 回报通道和价格身份

报告必须选择 `LONG_TERM_OWNER`、`FINITE_XIRR`或`DUAL_ROUTE`，并指定主路线；证据不足时写 `PRIMARY_ROUTE_UNKNOWN`，不能用较低价格掩盖路线不确定。

价格至少分为：今日业务价值、未来业务价值、期末市场价格、`P_LONG`、`P_XIRR_FIXED_TERMINAL`、`P_DISCOUNT_PATH`、`P_LEGAL`和安全边际行动价。由当前买价反推未来折价路径得到的价格，只能是条件政策诊断。任何主价格都必须说明它依赖的终值、税费、币种、期限和兑现条件。

## 6. 最强反方和翻转条件

每份报告至少列出一个具名的最强投资者正方情景，并逐项给出可核验条件；同时列出基础、压力和联合有利情景。不得把联合有利情景写成预测或概率。结论必须说明当前价格在各路线下合格、不合格、观察或未知。

## 7. 接纳语义

| 状态 | 含义 |
|---|---|
| `PASS` | 仅代表限定审阅范围通过 |
| `ACCEPT_WITH_DATA_LIMITED` | 候选模型/报告在公开证据边界内可继续使用；仍非正式 Golden |
| `CONTENT_GOLD_ACCEPTED` | G1材料性阻断关闭、完整案例包和独立审阅齐备，才可进入 G3 候选集合 |
| `GOLDEN_SET_FROZEN` | G3集合级冻结后才可使用 |

任何单一审阅、读者版通过、模型算术通过或状态自报都不能单独提升到后两级。
