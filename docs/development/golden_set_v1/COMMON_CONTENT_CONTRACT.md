# Golden Set v1：共同内容契约（G2 裁决版）

> 适用范围：九份候选及后续所有 Golden Set 案例。  
> 状态：`G2_ADJUDICATED / NOT_YET_FROZEN`

## 1. 报告必须共同回答的问题

每份报告可以有不同章节，但必须让读者能够复述：未来行业利润池最可能怎样变化、公司如何赚钱和适应、现金如何到达普通股、正常盈利如何建立、价值路线为何适配、回报来自哪里、什么会导致永久损失、当前价格在什么条件下合格。

## 2. 行业未来主张

每份报告必须在 `EnterpriseUnderwritingEpisode` 的 `Situation Model` 内形成一条
`IndustryFutureThesis`。它不是行业资料摘要，而是价格前的方向性判断，至少连接：

```text
适当时域内最可能的行业 regime 与最强竞争解释
  -> 需求 / 供给 / 竞争 / 价格 / 成本 / 监管 / 融资导致的利润池变化
  -> 目标公司的客户、产品、区域、渠道、产能和资本结构暴露
  -> 公司已经采取或现实可采取的适应动作
  -> 正常盈利、owner cash、永久损失、价值路线和当前价格处理
  -> 最早的翻转观察
```

行业现状、趋势清单、同业数据、三组并列情景或监控指标不能单独关闭本项。报告必须说出
哪条路径当前更可能以及为什么；没有校准基准率时使用定性置信和保守范围，不得填入无
来源概率。只有仍可信的竞争 regime 会材料性改变投资处理、且现有证据不能区分时，才
允许在结构化判断层保持 `NO_PRIMARY`；读者正文不得照抄该状态码，而要说明当前为什么
不能选择主路径、两条解释的共同下界、不为哪项未来能力付费，以及什么事实能完成区分。
多行业控股公司按材料分部判断，不强行制造共同周期。

## 3. 价值链和证据身份

```text
官方证据 -> 已验证事实或 UNKNOWN -> 研究判断 -> 确定性模型 -> 价值/回报 -> 行动边界
```

正文每个材料性数字必须能回到来源或模型输入；来源索引不能代替正文对经济含义的解释。事实、代理、研究判断和情景必须显式区分。

## 4. 普通股现金与价值守恒

报告必须分别列示：

- 合并利润与归母利润；
- 经营现金流与普通股 owner cash；
- 现金、受限现金、实体最低现金和可上游现金；
- 少数股东索取、内部债权抵销和外部投资资产；
- 维护资本、扩张资本、项目资本和一次性清算成本。

任何资产或收益只允许沿普通股价值桥进入一次。若证据不足，使用范围或 `UNKNOWN`，不得用账面净资产、资源量、注册资本或关联方投资收益直接代替可得现金。

## 5. 正常盈利和资本配置

正常盈利必须回答：历史窗口为何代表正常状态、峰值/谷值如何处理、费用率和产品结构怎样影响利润、维护投入是否重复扣除、联营收益如何转现金。使用 `q` 时必须解释留存用途、历史证据、上下界、是否可能耗尽偿债空间，以及 q 变化对价值和回报的传播。

## 6. 公司价值、回报通道和行动价格

结构化模型先选择一条与公司机制适配的公司价值路线，例如正常化经营价值加已认可资产、
EPV、SOTP、有限寿命 NAV 或法律现金瀑布。它先回答“普通股大致值多少”。三年或五年 XIRR
紧随其后，回答“按今天价格买入、在指定日期按明确终值出售，年化回报是多少”。长期所有者
回报是不预设出售时的交叉检查，不与五年执行路线争夺公司身份。

非法律案例的五年基准终值采用未来业务价值；市场价格相对价值的关系延续只作市场实现速度
替代，有限重估只在具名经营或资本配置事实成立时作条件上行。期末卖价含有判断，不构成拒绝
选择公司价值路线或撤回行动价的理由。模型须展示基准终值、实体压力终值、当前价格的回报和
以基准终值反解的最高研究价格。

模型和技术附录至少区分：今日业务价值、未来业务价值、期末市场价格、长期所有者回报交叉
检查、固定终值下的有限期限回报价、价格/价值关系延续路径、法律期限价和基准最高研究价格。
内部字段身份只留在模型和技术附录；读者正文使用普通投资语言。任何最高研究价格都必须说明
终值、税费、币种、期限和兑现条件。

### 6.1 单一行动价格门

对于已建立公司价值路线的普通经营案例，**当前价格是否不高于基准期限内达到要求回报的最高
研究价格，是新建仓位的唯一价格门**。不得再要求压力情景也达到同一回报率，不得把基准研究价
与压力研究价取较低值，也不得在基准回报通过后增加一个独立的“现金权利通过”布尔门。

现金、NCI、债务、营运资本和资产处置权必须在上游普通股价值桥中处理：能够进入基准价值的
部分进入一次；证据不足但经济上合理的部分保留为具名范围或条件上行。它们不能既压低公司价值，
又在执行层作为第二次否决。若这些项目导致公司价值路线本身无法成立，应将案例标为承保覆盖
不足并补模型，不能把资料不足写成“现价太贵”。

实体压力用于回答永久损失和仓位大小，不是第二条买价。压力回报低于要求回报、甚至为负，
本身都不能推翻已经通过的基准买价；它应降低初始仓位、收紧监测或明确加仓条件。只有压力揭示
一个经济上可达的生存失败、债权瀑布击穿或普通股索取权断裂，才可以取消买入资格，且报告必须
把这一机制说清，不能以“压力研究价更低”代替原因。

同一不确定性只允许沿一个经济载体进入基准。除非有互不相同的事实机制，不得同时用现金认可
折扣、owner cash 折扣、持续营运资本负担和更高资本化收益率重复惩罚同一风险。压力情景可以让
相关变量共同恶化，但不能反向把联合压力冒充基准。

可复用的确定性动作映射由 `scripts/golden_action_policy.py` 提供。它明确区分：价格尚未通过、
基准承保未完成、通过后有限仓位，以及真正的普通股索取权/生存失败。

## 7. 最强反方和翻转条件

每份报告至少列出一个具名的最强投资者正方情景，并逐项给出可核验条件；同时列出基础、压力和联合有利情景。不得把联合有利情景写成预测或概率。结论必须说明当前价格在各路线下合格、不合格、观察或未知。

## 8. 接纳语义

| 状态 | 含义 |
|---|---|
| `PASS` | 仅代表限定审阅范围通过 |
| `ACCEPT_WITH_DATA_LIMITED` | 候选模型/报告在公开证据边界内可继续使用；仍非正式 Golden |
| `CONTENT_GOLD_ACCEPTED` | G1材料性阻断关闭、完整案例包和独立审阅齐备，才可进入 G3 候选集合 |
| `GOLDEN_SET_FROZEN` | G3集合级冻结后才可使用 |

任何单一审阅、读者版通过、模型算术通过或状态自报都不能单独提升到后两级。
