## 3. 跨报告共同裁决

### 3.1 已确认的共同不变量

1. **事实、判断、模型和结论单向传播。** 读者版不能成为模型输入，HTML不能另造数字。
2. **现金存在不等于普通股可得。** 必须分别说明合并现金、实体现金、受限现金、可上游现金、可分配现金和实际分派。
3. **NCI、内部债权和外部资产只能进入价值桥一次。** 资产价值、会计利润和现金索取权必须分层。
4. **正常盈利必须由业务驱动建立。** 周期企业不能把峰值利润永久化；消费企业不能把毛利率变化与费用率脱钩；项目企业不能把项目资本沉淀当作普通股现金。
5. **`q`是留存价值认可比例，不是增长率。** 单一公司只能给出事实约束的范围或明确的基础判断。
6. **未来成交价和业务价值不同。** 由当前价格反推出的终值只能是条件价格，不得自动成为主要研究价。
7. **长期回报、有限期限XIRR和估值回归必须分层。** 企业类型决定主要路线，投资者持有政策决定辅助路线。
8. **联合敏感性不能写成概率。** 有利联合情景只证明结论可翻转，不证明翻转会发生。
9. **`UNKNOWN`必须保持可见。** 不得以保守归零隐藏缺失事实，也不得把资源量、账面资产或规划产能直接变成普通股价值。
10. **局部审阅不是集合接纳。** `PASS`、`ACCEPT_WITH_DATA_LIMITED`和读者深度通过都不能越过 G3 冻结门。

### 3.2 必须保留的路线差异

- REIT/特许期限：以法律剩余现金流和终局顺位为核心，不能使用无限期 `P_LONG`替代。
- 控股平台：先闭合实体现金、NCI和内部债权，再决定是否有可用的 SOTP 主价格。
- 重资产周期：用跨周期正常盈利、经济维护和供需退出验证，不能用股息年化。
- 成熟消费制造：长期 Owner Earnings 为主，但金融资产、回购和留存用途需单列。
- 项目型公司：项目资本库存和现金回收是主变量；关联订单不能直接视为现金。
- 矿业：逐矿产量、成本、寿命、替代资本和联营现金必须同时进入有限寿命模型。
