# Turtle x Graham 项目简报

## 1. 项目一句话

把 Turtle Investment Framework 从“通用龟龟估值框架”升级成“以《价值投资：从格雷厄姆到巴菲特》为方法底座的框架”，同时保留 Turtle 现有的 GG 计算严谨性、数据管线和报告工程。

## 1.1 这次改造的本质

这次不是换一套术语，而是把框架的判断顺序改掉：

- 先判断公司属于哪一类
- 再决定用什么估值语言
- 再判断增长是否创造价值
- 再判断护城河是否足够持久
- 最后才给安全边际和仓位

## 2. 你真正想解决的问题

你不是想把 Turtle 变成一本书的摘要。

你要的是：

- 让框架先理解“什么是好生意、什么是有效增长、什么是永久损失”
- 让估值不再只在 `GG / DDM / 倍数` 之间打转
- 让 `GG` 保持它原本的可计算、可回溯、可保守化特性
- 让书里的思想变成框架的变量、公式、门槛和 prompt 结构
- 让后续自动化分析更稳，而不是更会说话

## 2.1 你希望 Claude 先理解的整体框架

Claude 需要先把 Turtle 理解成一个“价值路由器”，不是一个“估值公式库”。

它要先明白：

- `GG` 不是总入口，只是某一类公司的计算语言
- `DDM` 不是万能估值器，只适合分配稳定、口径可信的场景
- 资产价值、盈利能力价值、成长价值不能混成一个结论
- 护城河和衰减必须前置，否则增长会被误判
- 中国市场必须额外处理治理、兑现、关联交易和价值陷阱

## 3. 你的原始痛点

你已经明确指出了一个核心问题：

- `GG` 和 `DDM` 都不完整
- 对经济特许权公司，应该用回报率去估算，而不是只盯着单一倍数
- 对没有经济特许权的公司，资产价值和盈利能力价值更重要
- 中国市场里，很多公司还要额外考虑价值陷阱、治理和兑现能力
- 现有框架容易“讲得通”，但不够“算得通”

## 4. 目标状态

迁移完成后，Turtle 至少应该做到：

1. 先判断公司属于哪一类：
   - 资产价值主导
   - 盈利能力价值主导
   - 成长价值主导
   - 价值陷阱主导

2. 再决定估值主线：
   - 先资产价值 / EPV
   - 还是先回报率 / 资本配置

3. 再把“增长”拆成可计算来源：
   - 有机增长
   - 再投资回报
   - 衰减
   - 管理层资本配置

4. 再给出清晰的动作：
   - 买入 / 观察 / 排除
   - 仓位上限
   - 需要继续验证什么

5. 再保留 GG 式的严谨输出：
   - 每个数字都能回溯
   - 每个公式都能复算
   - 每个结论都有证据和否决门
   - 每个结果都能分层到 `reported / normalized / conservative / adjusted`

## 6. 这次迁移要保留什么

- 数据管线
- 变量化思路
- 可回溯计算
- 保守化规则
- 否决门 / 风险门
- 现有报告结构中的工程化能力

## 7. 这次迁移要改变什么

- 把“好公司”的定义改成书里的经济特许权标准
- 把“增长”改成“增量资本回报是否超过资本成本”
- 把“护城河”改成更严格的竞争优势与衰减判断
- 把“安全边际”改成回报差 + 衰减 + 价值陷阱
- 把“研究策略”改成信息层级和证据权重
- 把“先算再说”改成“先分流再计算”

## 8. 书带来的方法升级

### 8.1 资产价值

- 持续经营企业不能只看账面值
- 要看再生产成本
- 应收、存货、预付、递延税等都要重新判断

### 8.2 盈利能力价值

- EPV 仍然重要
- 但资本成本必须保守估计
- 高杠杆不能被当成低成本资金

### 8.3 成长

- 增长不是免费午餐
- 只有高于资本成本的增量回报才增值
- 低回报增长会毁值

### 8.4 好生意

- 品牌不等于护城河
- 先发不等于护城河
- 真正关键是能不能长期挡住竞争侵蚀

### 8.5 衰减

- 护城河不是永恒的
- 必须把衰减看成安全边际的一部分

### 8.6 资本配置

- 留存收益值不值钱，取决于管理层怎么用
- 价值创造因子要进入框架

## 9. 你希望 Claude 理解的核心判断

- 对经济特许权公司，用回报率框架比单纯终值法更稳
- 对非特许权公司，资产价值和盈利能力价值更关键
- 中国市场的治理、兑现和价值陷阱必须单独加权
- Turtle 不该只做“估值器”，还要做“分流器”
- 最终要输出的是可执行的框架，而不是文学化总结
