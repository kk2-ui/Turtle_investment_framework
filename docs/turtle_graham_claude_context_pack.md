## 这份文档的用途

这不是书摘，也不是代码说明。它是给 Claude 的第一层上下文，目的只有一个：

- 先让它理解你的真实目标
- 再让它理解 Turtle 现在是什么
- 然后让它理解这次迁移为什么不是“换个说法”，而是“换一套判断引擎”

## 1. 你真正要解决的问题

你不是要把 Turtle 改成一本书的总结器。

你要解决的是：

- 以前总在 `GG`、`DDM`、倍数之间打转，但它们都不够完整
- 对经济特许权公司，核心应是回报率和再投资质量，而不是只看单一倍数
- 对非特许权公司，资产价值和盈利能力价值应优先于成长叙事
- 对中国市场，公司“看起来便宜”不等于“真的便宜”，价值陷阱、治理、兑现能力都必须单独处理
- Turtle 需要保留 GG 式的计算纪律，而不是变成只会讲道理的分析器

## 2. 这次迁移的总目标

把 Turtle 的方法底座改成《价值投资：从格雷厄姆到巴菲特》的逻辑，但保留现有工程骨架。

一句话版本：

- 先分流，再估值
- 先判断价值来源，再选公式
- 先判断增长是否增值，再谈成长
- 先判断护城河和衰减，再谈长期回报
- 先做风险折价，再给仓位

## 3. 这不是要改成什么

不要把这次迁移理解成下面这些东西：

- 不是把 Turtle 改成书摘整理器
- 不是把 `GG` 改名成别的术语
- 不是把估值写得更文学
- 不是用一套新话术替换旧话术
- 不是一次性推倒重来

更准确地说，这次是：

- 保留数据管线
- 保留可计算和可回溯
- 重写概念底座
- 重排判断顺序
- 重建变量之间的关系

## 4. 当前 Turtle 的基本结构

你现在的框架不是白纸，它大体已经是：

1. 数据采集
2. PDF / 定性提取
3. 因子化分析
4. 估值与安全边际
5. 报告输出与审计

现有核心因子大致是：

- 因子2：穿透回报率粗算
- 因子3：穿透回报率精算
- 因子4：估值与安全边际

现有框架的强项不是“概念”，而是：

这次迁移要做的是把书里的方法，嵌进这套工程结构里。

## 5. 书对 Turtle 的方法升级

### 5.1 价值不是一个公式

书的核心不是“哪一个公式最对”，而是：

- 不同公司有不同的主价值来源
- 资产、盈利能力、成长，不该混成一个口径
- 倍数法和 DCF 都只是表达方式，不是总入口

### 5.2 增长不是自动加分

增长只有在新增资本回报高于资本成本时才创造价值。

所以对 Turtle 来说，增长应该先回答：

- 这笔增量资本投下去，回报率是多少
- 这笔回报是否高于资本成本
- 这是不是低回报扩张

### 5.3 护城河必须前置

护城河不是估值后的修饰词，而是决定增长能不能进入价值的前提。

### 5.4 风险不是波动

风险的核心是永久性资本减损，再加上：

- 经济特许权衰减
- 治理和兑现失败
- 价值陷阱
- 结构复杂和财务粉饰

### 5.5 研究不是信息越多越好

研究资源应该优先放在真正影响价值判断的地方：

- 这家公司到底属于哪一类
- 现金回报能不能算清
- 增长能不能增值
- 护城河能不能持续
- 中国市场里有没有明显陷阱

## 7. 目标判断链条

Claude 需要先理解的不是某个公式，而是这条链：

1. 这家公司是什么类型
2. 主价值来源是什么
3. 应该先用哪种估值语言
4. 增长是否创造价值
5. 护城河是否真的能保护回报
6. 护城河会不会衰减
7. 中国市场里的陷阱要打多大折扣
8. 最后才是动作和仓位

## 8. 新旧框架的关键改写

| 旧问题 | 新问题 |
|---|---|
| `GG 还是 DDM？` | 这家公司属于哪条价值路由？ |
| `增长快不快？` | 增量资本回报是否高于资本成本？ |
| `护城河强不强？` | 护城河是否足以让增长进入价值？ |
| `便宜不便宜？` | 回报差、衰减和陷阱折价后还剩多少安全边际？ |
| `买不买？` | 属于通过、观察、还是排除？ |

## 9. GG 严谨性必须保留的东西

无论概念怎么改，下面这些必须保留：

- `reported / normalized / conservative / adjusted` 四层
- 每个结论都要能回到具体变量
- 每个变量都要能回到公式
- 每个公式都要有输入、默认值和例外
- 不能把资产价值和收益价值重复相加
- 算不出来就标 `⚠️ 数据不可用`
- 不允许用口号填补数据洞

## 10. 中国市场必须额外处理的东西

Claude 需要默认中国市场有更高的陷阱概率，尤其是：

- 治理折价
- 关联交易和资金占用
- 应收扩张和渠道压货
- 高资本开支带来的低回报扩张
- 账面利润和股东回报脱钩
- “看起来便宜”但长期回报很差

这意味着：

- 价值陷阱不是附加项，而是必检项
- 资产价值也要考虑可兑现性
- 盈利能力价值要考虑正常化和资本成本
- 成长价值要考虑衰减和兑现

## 11. 迁移后建议形成的目标架构

### 11.1 路由层

先把公司分成几类：

- 资产价值主导
- 盈利能力价值主导
- 特许权成长价值主导
- 特殊情景 / 催化主导
- 价值陷阱主导

### 11.2 计算层

再决定用什么算：

- 清算 / 重置成本
- EPV
- 回报率拆解
- 分部价值
- 风险折价和仓位上限

### 11.3 审计层

最后必须保留：

- 数据来源
- 口径锚定
- 反证检查
- 否决门
- 风险清单
