# Turtle 行业知识库

这是 Turtle 的 canonical 行业机制库，不是聊天记忆，也不是估值参数表。

使用路径：官方原始证据 -> 单家公司洞察候选 -> 跨主体、跨期间复核 -> 已结算的跨公司机制检验 -> 行业机制卡 -> 新公司研究的取证问题。机制卡只能提示应当查什么、可能的替代解释和适用边界；每家公司仍必须用自身 `OBS` / `DOC` 证据验证，不能把机制卡当作公司事实、估值参数、概率或自动投资结论。

三层身份必须分开：`CANDIDATE` 是一家公司直接证据支持的待检验事实；`CORROBORATED` 是跨公司或受限跨期的报告证据复核；`MECHANISM_READY` 还要求至少两个独立公司集团的已结算支持 episode、至少一个已结算反例或适用边界，以及非机制作者的逐 episode 独立复核。`NOT_DIAGNOSTIC` 可以保留，但不计作支持、反例或边界。任何一层都不授予公司事实、模型参数、概率或投资动作权限。

候选位于 `candidates/`，机制位于 `mechanisms/`。候选和机制分开保存，避免单篇报告的发现被自动晋升为行业结论。默认目录可用 `TURTLE_INDUSTRY_KNOWLEDGE_DIR` 覆盖，便于隔离研究或测试。
