# 因子1C：增量增长检验（Marginal ROIC Test）— v2.10

> 本文件为 Phase 3 执行器的参考文件。Agent 3 在因子1B完成后、因子2开始前执行本模块。
>
> **定位**：框架只检验了存量资本回报（ROE/GG > II），但未检验增量资本回报。
> 本模块填补这个缺口：新增一单位资本能否带来高于资本成本的回报？
> 如果增长来自低回报方向（非主业多元化），增长本身会毁灭价值。

**指令**：基于因子1A/1B的定性结论和 data_pack 的财务数据，完成增量ROIC检验。

---

## 步骤1：历史增量ROIC计算

```
若收入连续≥2年下滑（负增长）：
  → 标记"⚠️ 无法计算增量ROIC（收入下滑期，增量资本为负或零）"
  → 跳至步骤2，基于行业分类和历史教训做定性判断

若收入增长：
  Δ归母净利润(3年) = NP_t − NP_{t-3}
  Δ投入资本(3年) = (Capex_t + Capex_{t-1} + Capex_{t-2}) − (Capex_{t-3} + Capex_{t-4} + Capex_{t-5})
  // 简化: 用3年累计Capex变化作为投入资本变化的代理
  
  增量ROIC = Δ归母净利润 / Δ累计Capex
  
  判断：
    增量ROIC > II×2 → 增长强力创造价值
    II < 增量ROIC ≤ II×2 → 增长创造价值
    0 < 增量ROIC ≤ II → 增长不创造价值（回报低于门槛）
    增量ROIC < 0 → 增长毁灭价值（投入越多亏越多）
	
	**增长来源归因前的非经常性清洗（v2.29，强制）**：

在计算增量ROE/ROIC之前，必须先将归母净利润中的非经常性项目剥离：
```
核心归母净利润 = GAAP归母净利润 − 资产处置收益 − 异常股息收入 − 其他一次性项目
```

若核心归母净利润与GAAP归母净利润偏差>20%→强制标注"⚠️利润含重大非经常性项目，增长归因可能被扭曲"，并同时展示GAAP口径和核心口径的归因结果。若核心口径下增量ROE降至负值→因子1C结论"增长毁灭价值"。

**增长来源归因（v2.23，强制）**：
	增量ROE/ROIC的判断必须区分"增长来自哪里"——利润率提升驱动的增长与收入量价扩张驱动的增长有本质区别：
	
	计算公式：
	  归母净利润增量 = 收入增量 × 归母净利率_avg + Δ归母净利率 × 收入_avg
	  = [量价扩张贡献] + [利润率改善贡献]
	
	判断规则：
	  - 若利润率改善贡献 > 60%：标注"⚠️ 增长主要由利润率提升驱动（非收入扩张）。利润率有天花板（已接近历史高位X.X%），此类增长不可持续外推。"
	  - 若利润率改善贡献 > 60% + 收入CAGR < 3%：增量ROE判定**自动降一级**（如"增长强力创造价值"→"增长创造价值"，"增长创造价值"→"增长不创造价值"）
	  - 若量价扩张贡献 > 60%：增量ROE判定正常使用，标注"增长由收入扩张驱动，可持续性更高"
	  - 若无法拆解（数据不足）：标注"⚠️ 增长来源无法归因，增量ROE判定可信度降级"
	
	此归因结果传递至因子4——若增长主要靠利润率提升，DPS g_base 应向下修正 0.5-1.0pct。
```

**格力适用**：收入连滑2年→无法计算→跳至步骤2



**非经常项目扭曲归因的排除规则（v2.34）**：
若增长归因中，利润率改善贡献>100%或某单项非经常项目占比>50%:
  → 标注"⚠️增长归因被非经常性项目主导，不可用"
  → 强制用核心利润重做归因；若不可得→声明"数据不足以做归因，跳过"
  → 不得用已知含噪音的数据触发裁决

## 步骤2：增长方向分类（基于因子1B护城河和数据）

将公司近5年的Capex/投资按方向分类：

| 增长方向 | 判断标准 | 有护城河？ | 格力示例 |
|---------|---------|:---:|------|
| **A. 主业扩产** | 收入增长来自核心产品，Capex投向现有生产线/渠道 | ✅ 有 | 空调产线自动化升级、海外工厂 |
| **B. 主业相关延伸** | 与核心业务有协同（供应链/渠道/技术复用） | 部分 | 压缩机外销、智能装备(模具/机器人) |
| **C. 非主业多元化** | 进入不相关行业（收购/新设），无协同 | ❌ 无 | 格力钛(银隆)收购、手机业务 |

**数据来源**：
- data_pack_report SUB（子公司明细）— 识别C类投资的规模和结果
- data_pack_market §9（主营业务构成）— 判断B类/非主业收入占比趋势
- data_pack_market §8（行业竞争）— 判断A类是否有扩张空间

---

## 步骤3：增量ROIC vs II 判断

```
对每个增长方向，结合历史证据判断：

A. 主业扩产：
   - 若因子1B护城河为"优质"或"中性" → 假设增量ROIC > II
   - 若因子1B护城河为"负面" → 标注"护城河收窄，主业增长回报存疑"
   
B. 主业相关延伸：
   - 需查看历史回报。若相关延伸业务毛利率<主业-5pct → 假设增量ROIC = II×0.8
   - 标记"相关延伸回报不及主业，需关注规模拐点"

C. 非主业多元化：
   - 默认假设增量ROIC < II（除非有明确反证）
   - 若历史上已发生商誉减值/投资亏损 → 判定"大概率毁灭价值"
   - 标记"⚠️ 非主业多元化历史上回报<II，未来增长可能稀释整体价值"
```
