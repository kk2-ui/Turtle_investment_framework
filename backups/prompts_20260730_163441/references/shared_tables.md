## 支付率计算规则

```
支付率 = 年报同币种计算：各财年股息总额(报表币种) / 归母净利润(报表币种)
数据来源：data_pack_market §6 股息历史 + §3 归母净利润

⚠️ 禁止使用 yfinance 的 payoutRatio、dividendRate、trailingEps 字段
⚠️ 必须使用同币种数据（报表币种股息 / 报表币种利润）

支付率序列：过去3~5年逐年计算
支付率均值 M = 近3年均值
支付率锚定值 = 承诺支付率（若有明确承诺）；若无承诺则使用 M（近3年均值）

注销型回购 O = 过去3年年均注销型回购金额（百万元），来源 §15
稀释净效果 = 回购减少股本 − 新发行增加股本
```

## 穿透回报率公式

```
港股：
  穿透回报率 = [基准值 × 支付率锚定值 × (1 − Q) + O] / 当前市值
  其中 Q = 股息税率（小数，如10%=0.10，20%=0.20）

A股（长期持有，Q=0）：
  穿透回报率 = [基准值 × 支付率锚定值 + O] / 当前市值

其中：
  因子2 基准值 = C（归母净利润，报表口径）→ 输出 R%
  因子3 基准值 = AA（真实可支配现金结余）→ 输出 GG%

⚠️ 税基差异说明：
  Q 指股东层面收到股息时的到手税负
  公司层面的企业所得税、境内利润上划预提税等，已反映在 C/AA 中，不再重复扣减
  因子2 对报表利润 C 征税（粗算，快速近似）
  因子3 对真实可支配现金 AA 征税（精算，保守底线）
  两者偏差 HH = R − GG 是粗算/精算方法论差异的正常结果
  HH 通常在 1-3 pct 范围内；若 |HH| > 3 pct 需调查成因
```

## 门槛值 II 计算公式

```
Rf = data_pack §14 无风险利率

港股门槛 = max(5%, Rf + 3%)
A股门槛 = max(3.5%, Rf + 2%)
美股门槛 = max(5%, Rf_US + 3%)（Rf_US = 美国十年期国债收益率）
```

### 品牌溢价折扣（v2.26 新增）

当以下条件**全部**满足时，II可下调0.5-1.0pct：
1. 因子1B护城河评级 = "优质"（顶级品牌护城河）
2. 定价权验证 = "极强"（渠道价差>50%或提价后需求未受抑制）
3. 毛利率连续3年 > 80%（行业Top 1%水平）
4. ROE连续5年 > 25%
5. 零有息负债

调整幅度：满足3项→下调0.5pct；满足4项→下调0.75pct；满足5项→下调1.0pct
调整后II不得低于Rf+1pct（下限保护）。调整理由须在报告子类判断段显式标注。

## 跨币种处理规则

穿透回报率公式中所有项必须使用同一币种：

```
基准币种 = data_pack_market 报表币种（§头部标注）

- 报表币种 = HKD → 市值用港元市值（§1 直接取值）
- 报表币种 = USD → 市值用美元市值（§1 直接取值）
- 报表币种 = CNY 但股价为 HKD：
    市值 = 港元市值 / 汇率（取 §1 或 data_pack 头部汇率）
    转换为人民币市值后计算
- 报表币种 = CNY 但股价为 USD：同理，使用汇率转换

少数股东口径修正（v2.22）：
  当少数股东占比 > 10%（读取 §17.2 少数股东占比）：
    因子3 归母口径GG = [AA × (1 − 少数股东占比) × M × (1−Q) + O] / 市值
    因子4 少数股东折扣（已有）= g_base × (1 − 少数股东折扣系数)
    两个因子必须使用一致的少数股东占比数据源（§17.2 少数股东占比）
    详见 factor3_穿透回报率精算.md §10b-少数

⚠️ 禁止混用：如用人民币利润除以港元市值（可导致 5-10% 计算偏差）
```

## 估值方法选择指南（v2.24）

> ⚠️ **核心规则**：资产基础法（NAV/清算价值）和收益法（GG/DCF）是两套独立估值视角，**不可简单相加**。现金产生的收益已包含在 AA 中，单独加回每股净现金 = 重复计算。详见 `factor4_估值与安全边际.md` §6.0。

### 按企业特征选择估值方法

| 企业特征 | 首选方法 | 交叉验证 | 不适用方法 | 说明 |
|:---------|:-------:|:--------:|:---------:|:-----|
| **正常盈利，GG > II** | 纯收益法（GG反推） | DDM阶梯买入 | — | 现金贡献已内含，不另加回 |
| **正常盈利，GG < II** | DDM阶梯买入 | 资产基础法（底线参考） | 纯收益法 | GG不达标时不可反推出价 |
| **深度破净（PB<0.7），重资产** | 资产基础法 | 纯收益法（验证持续经营） | — | 清算价值视角为主 |
| **大量超额现金（>市值30%）** | SOTP | 纯收益法 | — | 唯一可合法"相加"的场景 |
| **轻资产高ROE** | 纯收益法 | DDM | 资产基础法 | 资产价值对轻资产无参考意义 |

### SOTP（分部加总）触发条件

SOTP 是唯一可以合法"相加"的估值方法，但仅在以下条件全部满足时使用：
1. 存在可分离的**非经营资产**（闲置土地、持有待售股权、超额现金）
2. 非经营资产不产生经营现金流（即其收益未包含在 AA 中）
3. 超额现金 = 总现金 − 运营现金需求（收入的 5-10%）
4. 港股需使用归母口径（× (1 − 少数股东占比)）

**SOTP 公式**：
```
总股权价值 = 经营业务价值（纯收益法，AA_adj不含超额现金收益） + 非经营资产价值（归母口径）
```

### 三种方法的适用边界

| | 纯收益法 | 资产基础法 | SOTP |
|:--|:------:|:--------:|:---:|
| 核心问题 | "能赚多少钱？" | "清算值多少？" | "分拆卖值多少？" |
| 数据需求 | AA序列、M、Q、II | 归母权益、总股本 | 超额现金、非经营资产清单 |
| 适用企业 | 持续经营盈利 | 重资产/破净/困境 | 有明确非经营资产 |
| 能否与AA相关？ | 直接使用AA | 不涉及AA | 调整AA后使用 |
| 与其他方法相加？ | **不可** | **不可** | **仅加非经营资产** |

## 因子2/4回购处理差异（v2.32）

```
因子2粗算R: O = 年均注销型回购金额(百万元)，直接计入分子 → 即时回购视角
因子4 DDM: g_base从DPS历史CAGR推导，回购通过减少股本间接贡献DPS增速
           DPS_cap_B中已包含回购注销贡献项(0.5-2%)
差异处理: 若因子2的O显著>0但因子4的g_base未显式包含回购贡献
         → 标注"注意：回购对DDM的影响在Cap_B中部分体现，未在g_base中显式计入"
         → 若回购持续且规模大(O>归母净利润×5%)，乐观g_opt可加回O/(市值×M)作为额外项
```

## 用户组合上限（Portfolio Cap）

> **定位**：这是用户级别的组合管理参数，不影响框架内部分析逻辑。所有仓位输出在最终展示时乘以 PORTFOLIO_CAP_PCT。

| 参数 | 默认值 | 来源 | 说明 |
|:---|:---:|:---:|------|
| PORTFOLIO_CAP_PCT | 5% | `.env` | 每只个股最高占组合比例 |

**换算公式**：
```
实际组合占比 = 框架仓位% × (PORTFOLIO_CAP_PCT% / 100)
```

**示例**：
- 框架仓位上限 30% → 实际组合占比 = 30% × 10% = 1.5%
- DDM P5 触发仓位 15% → 实际组合占比 = 15% × 10% = 0.75%

**单只股票覆盖**：可在该股票的 `threshold.json` 中设置 `portfolio_cap_pct` 字段覆盖默认值：
```json
{ "portfolio_cap_pct": 8 }
```

**仓位输出强制格式**：所有包含仓位的表格必须双列显示（框架仓位 + 组合占比），投资论点卡中直接使用组合占比作为目标。
