## 定位与指令

> **定位**：仅 R5（经济特许经营）激活。回答"在当前价格买入，预期年化回报率是多少，够不够门槛"——这是书解决"买点问题"的核心。用**预期回报率对比资本成本**，而非估内在价值再对比价格。

**指令**：三段式回报分解（现金 + 有机增长 + 积极投资），用 V/M 加权增长回报，迭代求 r_b2，安全边际扣减 decay_rate。全程保守。原书公式已核校（0050/0053/0054/0056）。

### 三段式回报分解（第8章核心，0050）

```
预期年化回报 R_total = 现金回报 + 有机增长回报 + 积极投资回报

① 现金回报 = D / M                          （股息率 + 注销回购收益率）
② 有机增长回报 = g × (V/M)                   （增长按 价值/市值 加权，0056 公式6 精神）
③ 积极投资回报 = 增量ROIC 相对 r* 的超额 × 再投资比例
                = (增量ROIC − r*) × 留存率 × (V/M)   （仅护城河内增长创造，VCF>1 时为正）

其中 V = 内在价值（R5 取 EPV + franchise_value 的增长贡献，或 EPV 上沿）
     V/M = 内在价值 / 市值（>1 表示低估，放大增长回报）
```

### 迭代求 r_b2（0053/0054，收敛判据）

```
原书链条（已核）：
  r_b = D/M + g                         （基础回报率，V=M 假设）
  r   = D/M + g × (V/M)                 （真实回报率）
  r − r_b = g × (V/M − 1)               （公式6：低估带来的额外回报）
  V/M ≈ r_b / r*                        （用基础回报率/门槛近似估内在价值比）
  r_b2 = D/M + g × (r_b / r*)           （代入迭代一次）

迭代收敛判据（新增，补 GG 精算缺口）：
  第0轮 r_b0 = D/M + g
  第n轮 V/M_n = r_b(n-1) / r*
        r_bn  = D/M + g × V/M_n
  收敛：|r_bn − r_b(n-1)| < 0.1pct  → 停，取 r_bn
  最多迭代 5 轮；若 5 轮未收敛（g 接近 r* 时发散）：
    → 标"⚠️ g 接近 r*，迭代发散，增长价值不可靠"，改用 r_b0（不加权）保守处理
  边界：V/M 上限封顶 3.0（避免极端低估假设放大回报到失真）
```

## 关卡 ①b 半衰期 → 衰减率（补 GG 精算最大缺口：输入端）

> §6.5-B 只给了"半衰期→衰减率"查表，没说半衰期怎么来。这里补输入端：从财报可观测的护城河耐久性代理量估半衰期。

```
半衰期 = 竞争优势（超额回报 ROIC−r*）衰减到一半所需年数。越长越稳。

估法（能算则算，否则代理量近似 + ⚠️）：
优先级1（有≥5年 ROIC 序列）：
  超额回报_t = ROIC_t − r*
  拟合超额回报的年衰减比例 δ = 1 − (超额_近期/超额_早期)^(1/年数)
  半衰期 = ln(2) / ln(1/(1−δ)) ≈ 0.69/δ
  （若超额回报不降反升 → 半衰期视为长档 ≥50年，δ→0）
优先级2（无稳定 ROIC 序列，用护城河代理量打分）：
  按四维打分定半衰期档（每维 长/中/短）：
    毛利率稳定性（5年波动<2pct=长 / 2-5pct=中 / >5pct=短）
    市占率趋势（升=长 / 稳=中 / 降=短）
    franchise_type（网络/需求护城河=长 / 成本优势=中 / 无=短）
    行业结构（寡头稳定=长 / 分散竞争=短）
  多数长→半衰期50年；多数中→30年；多数短→18年，标 ⚠️ 代理估计
优先级3（数据极缺）：
  按 moat_rating：强=40年 / 中=25年 / 弱=15年，标 ⚠️ 粗估

衰减率 decay_rate = 72 / 半衰期（%）（§6.5-B 72法则，已核）
  半衰期≥80年→0.9% | 50年→1.4% | 36年→2% | 25年→2.9% | 18年→4%
  ⭐ 半衰期 ≤25年（decay≥2.9%）→ 强制从回报率中扣减 decay（护城河不够持久）
```

```
g 缺（无稳定增速）：
  优先2：用收入 3-5 年 CAGR 与盈利 CAGR 的较低者，标口径
  优先3：g = min(名义GDP增速, 行业增速) 保守近似，标 ⚠️

禁止：留空任何一段回报。缺 → 该段给保守近似或设0 + ⚠️。
```

## 关卡 ③ 边界情形

| 情形 | 触发 | 强制处理 |
|---|---|---|
| g ≥ r* | 增长率≥资本成本 | 迭代发散，用 r_b0 不加权 + 标"⚠️ 高增长假设不可持续，回报估计上限失真" |
| g > 15% 或 >> 名义GDP | 增速过高 | 按 §6.5-E 增长合理性，截断到 min(15%, 名义GDP×1.5) + 标 |
| 增量ROIC ≤ r*（VCF≤1） | 增长不创造价值 | 积极投资回报=0，标"增长仅维持不增值"，回标 Factor1.5 是否该降 R4 |
| 半衰期短（≤25年） | decay≥2.9% | 安全边际强制扣 decay（见④），护城河溢价打折 |
| 派息率>75% | factor3 步骤10 | 增长再投资少，g 主要靠外延，标"内生增长弱" |
| franchise_value≤0 | EPV≤AV | 不该进 R5，回标 Factor1.5 路由错误 |

## 关卡 ④ 强制敏感性 + 安全边际（decay 接入）

```
安全边际（原书 0058，已核）：
  safety_margin = r_b2 − r* − decay_rate
    >0 且 ≥ §6.5-A 地板(3-4pct) → 买点成立
    0 ~ 地板 → 灰区，回报勉强覆盖资本成本+衰减，边际不足
    <0 → 当前价格下预期回报不足以补偿资本成本与护城河衰减，不买

三档回报（禁止单点）：
  悲观 = D/M + g_low × (V/M_low) − decay_high，减 3 段中不确定项
  基准 = r_b2 主算法 − decay_base
  乐观 = D/M + g_high × (V/M_high) − decay_low
  区间 = [悲观, 乐观] vs r*

临界价格：令 safety_margin = 0 反解市值 M_crit
  → 目标买入价 = M_crit / 总股本 × (1 − 现金保护折扣)（对齐 factor4 买入价梯度）
```

## 关卡 ⑤ 裁决联动（三视角，Q3 定案）

```
R5 三视角统一裁决（权重）：
  ① 回报拆解层（本执行器）    权重 ~60%（主）：safety_margin vs 地板
  ② GG 层（factor3 穿透回报） 权重 ~20%（辅，Q3 降权）：GG vs II 交叉验证
  ③ Asset 层（Phase3 AV）     权重 ~20%（兜底）：AV/市值 下行保护

裁决规则：
  三视角同向达标 → 买入信号强
  回报拆解达标但 GG 不达标 → 标"回报靠增长，现金回报弱，需增长兑现"
  回报拆解不达标 → 即使 GG 高也不买（R5 买点以回报拆解为准）
  Asset 层是安全垫，不单独触发买入

仓位：safety_margin 越厚 + 护城河越持久（半衰期长）→ position_cap（保留5%上限，关联 position-limit-per-stock）
传递字段：R_total 三档、r_b2、safety_margin、decay_rate、半衰期、临界买入价、三视角裁决
```
