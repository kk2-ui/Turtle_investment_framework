# 因子2：穿透回报率粗算（Top-Down）— 详细计算步骤

> 本文件为 Phase 3 执行器的参考文件。Agent 3 在执行因子2时按需加载本文件。金额单位统一为百万元。

## 定位

基于报表利润的自上而下快速近似，用于早期筛选。若粗算回报率已远低于门槛，则直接否决，不进入因子3精算。

**指令**：读 data_pack_market.md 原表，逐步计算。仅对通过因子1的标的执行。使用模块〇锚定的利润口径和现金口径。

## 步骤0：方法论适用性前置检查（v2.20 新增）

因子2 用归母净利润(C)近似可分配现金，假设"净利润≈可分配现金流"。**当 OCF 与 NP 严重背离时，这个假设不成立，因子2 的方法论适用性存疑。**

### 0.1 OCF/NP 背离检查

```
OCF = §5 经营业务现金净额（最新年度）
NP  = §3 归母净利润（最新年度）
OCF/NP = [值]

判断：
  OCF/NP > 2.0 → "OCF远高于NP，净利润严重低估真实现金生成能力。因子2(C-based)可能显著低估穿透回报率。"
  OCF/NP < 0.5 → "OCF远低于NP，利润含大量非现金项目或应收堆积。因子2可能高估回报率。"
  0.5 ≤ OCF/NP ≤ 2.0 → "OCF与NP基本匹配，因子2方法论适用。"
```

**这不是否决门**——无论 OCF/NP 多少，因子2照常计算。但该比率决定了因子2结果的可信度权重：

| OCF/NP 区间 | 因子2可信度 | 处理 |
|:---:|:---:|------|
| 0.7-1.5 | 高 | 正常使用 |
| 0.5-0.7 或 1.5-2.0 | 中 | 标注"OCF/NP偏离，建议以因子3为准" |
| <0.5 或 >2.0 | 低 | 强制标注"因子2方法论在此标的上适用性存疑，因子3为必要步骤" |

### 0.2 特殊行业豁免

以下行业默认因子2可信度为"低"（无论OCF/NP多少），因子3为强制步骤：
- 重资产制造（折旧 > NP×50%）：折旧扭曲NP与OCF的关系
- 房地产/建筑：营运资金波动极大
- 金融/保险：现金流定义与实业不同

> 案例参考：中国食品(00506) OCF/NP=3.75x → 因子2 R远低于因子3 GG(HH=-4.64pct)，若仅看因子2会错过。中海物业(02669) OCF/NP≈0.84x → HH≈0.01pct，因子2近似有效。

**中期数据参考**：
若 §3 含中期列（如 2025Q3），额外计算：
  年化归母净利润 = 2025Q3 × 4/3 = [值] 百万元（C_ann）

资本开支/折旧比率（过去5年中位数）= [值]（F = E/D 中位数）

  轻资产行业（软件/平台/品牌消费品）：系数 = 0.7 ~ 1.0

> 若 HH > 2pct，应分析成因：G系数选择偏乐观 vs 因子3投资性购买X1未在因子2中体现。

3. 输出 G 敏感性表：
   | G 值 | 假设含义 | OE（百万元） | R（%） | vs II（X.XX%） |

判断规则：
- 自由现金流过去3-5年是否持续为正？
- 融资活动现金流是否持续为正（持续借债）？
- 派息后现金储备是否仍在净增长？

```

注意：分配能力否决与因子1B模块六（管理层评价）是独立判断：
  - 模块六评估管理层的资本配置*意愿和质量*（是否损害价值）
  - 步骤2评估企业的现金流*生成能力*（能否产生可分配现金）
  - 管理层评价"合格"不能豁免分配能力否决
  - 反之，分配能力通过也不能豁免管理层否决
  - 两者均通过方可继续
```

## 步骤4：否决门判断

```
Rf 从 data_pack §14 读取。
门槛 II 按因子4规则计算：
  港股 = max(5%, Rf + 3%)
  A股 = max(3.5%, Rf + 2%)
  美股 = max(5%, Rf_US + 3%)

粗算快速否决规则：

① 若 R < Rf（无风险利率）→ 直接否决，不进入因子3
   理由：粗算回报率连无风险都跑不赢，精算不可能逆转

② 若 Rf ≤ R < II × 0.5（不足门槛一半）→ 直接否决，不进入因子3
   理由：因子3的现金质量修正通常在 ±2pct 以内，无法弥补如此大的差距

③ 若 II × 0.5 ≤ R < II → 标注"因子2粗算边际不达标"，继续进入因子3
   理由：因子3的现金分析可能修正（如扣除项中成长性支出占比高）

④ 若 R ≥ II → 正常通过
```

## 回购O值置信度规则（v2.6）

回购金额O必须按执行阶段打折，不得将未执行回购当作已执行使用：

| 执行阶段 | O值折价系数 | 标注 |
|---------|:--------:|------|
| 已执行完成 | ×100% | "O值置信度：高" |
| 正在执行中（有进展公告） | ×70%（按公告进度） | "O值置信度：中" |
| 已公告未开始执行 | ×50%（历史执行率折扣） | "O值置信度：低，仅为公告值×50%" |
| 仅董事会预案 | ×30% | "O值置信度：极低，仅为预案值×30%" |

同时必须在因子2输出中计算：
```
GG_no_O = GG − O×折扣/市值  // 若回购不执行，GG会降至X.XX%
```
