# 资产价值 / 重置成本执行器（Magna 流水线）

> **Phase 3 产出**。Greenwald 三价值来源里**最可靠的锚**。逐项把资产负债表调到"竞争对手今天重建这盘生意要花多少钱"。
> 上游：§4 资产负债表、Factor1B（是否持续经营/清算情景）、Phase 2 EPV（做 AV↔EPV 勾稽）。下游：Phase 4 路由（护城河判定）、R1/R2/R4 主估值。
> 母版 `_executor_template.md`；路线图 `docs/turtle_graham_deepening_roadmap.md`。单位百万元。
> **全局原则**：拿不到精确数据给近似估算 + 方法 + ⚠️，绝不空着。重置成本是本框架数据缺口最大处——**能估则估、否则给账面近似 + ⚠️，绝不留空**（Q2 定案 + 用户 2026-07-30 加强）。

---

## 定位与指令

> **定位**：算"重建同等生意的成本"= 资产价值（AV）。竞争均衡下无护城河公司，内在价值 ≈ AV。它是估值的地板，也是判护城河的第二条腿（EPV vs AV）。
> **上游依赖**：§4 各资产/负债行项；Factor1B 的持续经营 vs 清算判断、行业属性。
> **下游消费**：Phase 4 Factor1.5（EPV/AV 差额 → 护城河 → 路由）；R1 清算价值（NCAV）；R2 重置成本主估值；R4 资产地板。

**指令**：区分两种口径——**持续经营用重置成本（含无形资产重建）**，**清算用变现价值（仅有形、打折）**。逐项调整，不用无依据系数硬凑。全程保守。

## 关卡 ①b 主计算 A：有形资产重置（逐项）

```
货币资金        = 账面 ×1.0
应收账款        = 账面 − 额外坏账折扣（一年以上应收占比高→多扣5-15%，同 factor3 步骤2）
存货            = 账面 × 行业系数
                  快消/标准品 ×0.9-1.0；时尚/科技（易过时）×0.5-0.7；大宗 ×0.9
固定资产        = 重置净值：
                  优先 用原值 × (1−累计折旧率) × 通胀因子   （通胀因子≈重置期物价累计，默认1.1-1.3）
                  或   用净值 × 通胀因子（数据简时）
                  专用设备（难变现）清算口径再 ×0.3-0.5
投资性房地产    = 公允价值（若披露）否则账面 ×0.8
长期股权投资    = 上市部分按市值；非上市按账面（标"未做可回收折扣"）

有形资产重置合计 = Σ 上述
```

## 关卡 ①c 主计算 B：无形资产重置（Magna 案例三类，散户数据缺口最大）

> Greenwald 麦格纳案例：护城河生意的无形资产（客户关系、品牌、组织资本、研发、牌照）在资产负债表上几乎为零，但重建它们要花真金白银。持续经营口径必须重建；清算口径全部归零。

```
三类无形资产重建（能估则估，否则近似+⚠️，绝不空）：

(1) 客户关系 / 市场地位：
    重建成本 ≈ 达到当前收入规模所需的累计获客投入
    可算法：近3-5年销售费用中"获客部分" × 重建年数(通常1-3年SG&A)
    数据缺口降级：
      优先1：有销售费用明细 → 获客部分 × 1-3年
      优先2：仅有总销售费用 → 销售费用 ×50% × 2年 近似，标⚠️
      优先3：连销售费用都无 → 收入 ×(行业获客率 消费15%/工业5%) 近似，标⚠️

(2) 品牌 / 产品组合：
    重建成本 ≈ 累计品牌广告投入的现值
    可算法：近5年广告/品宣费 累加（或销售费用×品牌占比）
    降级：无明细 → 收入 ×(消费5-10%/工业1-2%) × 3年 近似，标⚠️
    无品牌型生意（代工/大宗）→ 品牌重置 = 0

(3) 组织资本 / 研发 / 牌照：
    研发：近5年研发费用累加 ×(仍有效比例，默认按半衰期衰减)
    牌照/特许：若有政府牌照壁垒 → 按取得成本或行业交易价估，无数据标⚠️给区间
    组织资本：员工培训/系统 ≈ 1年SG&A的一部分，粗估，标⚠️

无形资产重置合计 = (1)+(2)+(3)
  ⚠️ 强制标注：本项散户数据缺口最大，值为估算区间而非精确数。报告给 [低, 高] 区间。
```

## 关卡 ② 数据缺失降级阶梯（口径级）

```
持续经营口径（有护城河/正常经营）：
  AV_going = 有形资产重置 + 无形资产重置 − 负债合计
  无形部分数据缺 → 按①c 三级降级给近似区间，绝不设0（除非确认无品牌/无研发/无客户壁垒）

清算口径（R1 distress/衰退）：
  AV_liq = 货币 + 应收×0.8 + 存货×(0.3-0.6) + 固资×0.3-0.5 + 投资×市值 − 负债全额
  无形资产 = 0，商誉 = 0
  ≈ NCAV 加严版（NCAV = 流动资产 − 全部负债）

口径选择：
  Factor1B 判持续经营 → AV_going 为主，AV_liq 为地板
  Factor1B 判 distress/清算 → AV_liq 为主（对应 R1）
禁止：任何资产项留空。缺明细 → 给近似 + ⚠️。
```

## 关卡 ③ 边界情形

| 情形 | 触发 | 强制处理 |
|---|---|---|
| 重资产制造（麦格纳型） | 固资占比高 + 无形薄 | 重点核固资重置通胀因子；无形小额；AV 接近有形重置 |
| 轻资产品牌/软件 | 无形为主、固资薄 | 无形重建是 AV 主体，必须走①c 三类，标区间 |
| 商誉巨大 | 商誉/净资产>30% | 持续经营下商誉不直接计入 AV（重建成本另算），标"账面商誉 X 不等于重置价值" |
| 数据极缺 | 无附注、仅合并报表 | AV = 账面净资产 × 调整系数 + ⚠️"重置成本不可精确，退回账面净资产近似"（Q2 底线） |
| 周期底部资产减值 | 近期大额减值 | 用减值前原值重估，标"减值或为周期性，重置成本高于账面" |
| 净现金壳 | 现金≈市值 | AV 主要是现金，标注大股东占用风险（关联 factor3 步骤13） |

## 关卡 ④ 强制敏感性 / 置信区间

```
AV 三档（无形资产估算不确定性主导）：
  AV_low  = 有形重置(保守系数) + 无形重置(降级下沿，可能0) − 负债
  AV_base = 有形重置(基准)     + 无形重置(中值区间)         − 负债
  AV_high = 有形重置(足额通胀) + 无形重置(上沿)             − 负债
  区间 = [AV_low, AV_high]，无形数据越缺区间越宽（如实反映不确定性）

每股 AV = AV / 总股本；AV/市值比
必输：清算口径 AV_liq 作为绝对地板（R1 参考）
```

## 关卡 ⑤ 裁决联动

```
① 护城河判定（传 Phase 4，与 EPV 勾稽）——本执行器的头号用途：
   EPV_op / AV 比值（Q2 迁移计划 §VII 情形A/B）：
     情形A EPV ≈ AV（0.8-1.2）→ 无护城河，竞争均衡 → 内在价值取 AV，路由 R2/R3
     情形B EPV > AV（>1.2）    → 有护城河，特许经营价值 = EPV − AV → 路由 R5
     情形C EPV < AV（<0.8）    → 管理层毁灭价值/衰退 → 路由 R4，估值取 AV 打折
② 安全边际：AV/市值 >1 → 市价低于重建成本（强下限保护）
③ 清算保护：AV_liq/市值 → R1 distress 的绝对安全垫

仓位联动：AV 提供下行保护强度 → 影响现金保护折扣（factor4 买入价梯度）
传递字段：AV_going(low/base/high)、AV_liq、EPV_vs_AV_ratio、每股AV、AV/市值、护城河初判
```
