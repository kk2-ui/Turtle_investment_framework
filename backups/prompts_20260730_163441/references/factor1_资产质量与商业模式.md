### 模块三：竞争格局与护城河

分析项：
- 市场结构：[垄断 / 寡头 / 垄断竞争 / 充分竞争]

- 护城河分层分析（两层递进结构）：

  **第一层：非技术性护城河（商业壁垒）**
  逐一判断（存在/不存在，强/中/弱）：
  - 规模效应 | 网络效应 | 转换成本 | 无形资产（品牌/专利/牌照） | 成本优势

  **第二层：技术性护城河（数据与算法壁垒）**
  逐一判断（存在/不存在，强/中/弱）：
  - 数据资产壁垒：是否拥有难以复制的专有数据集？数据是否形成正反馈循环（Data Flywheel）？
  - 核心算法/模型壁垒：是否存在长期迭代的算法系统（推荐/搜索/定价/风控等），新进入者即使获得同等数据，复制调优周期是否≥2年？
  - 履约/供应链系统壁垒：是否建立了高度定制化的实时履约系统？极端场景（峰值/异常）下的稳定性是否经过验证？
  - AI/前沿技术投入：是否有基于自有业务闭环数据训练的AI能力？先发优势是否构成壁垒（竞争对手能否获取同等质量的训练数据）？

  > 注：并非所有企业都具备技术性护城河（传统制造业/消费品第二层可能为空），框架兼容"第二层不适用"的情况。

  **两层交互关系判断**：
  - 技术层是否强化了商业层？（如：数据壁垒↑转换成本，算法↑网络效应）
  - 商业层是否反哺技术层？（如：规模效应→更多训练数据→更强算法）
  - 若形成闭环飞轮：标注"复合护城河"
  - 技术护城河持久性依赖条件：研发投入占比是否稳定？若削减，预计几年内侵蚀？

- 定价权验证：是否有主动提价记录，提价后客户流失率
- 产业链位置：面对上下游的议价能力
- 护城河侵蚀风险：过去5年是否有变窄迹象，竞争对手的进攻维度（商业层 vs 技术层）

**"租来的护城河"专项检查（v2.23，强制）**：
当护城河核心依赖品牌授权/特许经营权/牌照等外部授予（非自有的）资产时，必须执行以下检查：

| 检查项 | 数据来源 | 判断 |
|:-------|:--------|:----:|
| 授权/牌照的有效期限 | 年报/公开信息 | 剩余年限：[X]年 / 无固定期限 |
| 续约历史与续约条件 | 公开信息 | 续约频率、是否涉及重新谈判条款 |
| 授权方战略意图变化风险 | 公开信息 | 授权方是否在其他市场改变合作模式（如加大直营） |
| 续约失败对公司的影响 | 财务数据 | 授权相关收入占比 [X]%，若失去授权对盈利的影响 |
| 替代授权的可行性 | 定性判断 | 是否存在备选方案 |

**判断规则**：
- 若授权剩余年限 < 5年 + 授权收入占比 > 50%：**强制在风险清单中将"续约风险"列为"高影响、低概率"首位风险**，护城河评级降一级
- 若授权剩余年限 < 5年 + 授权收入占比 30-50%：标注"⚠️ 续约风险需关注"，不自动降级但必须在模块八风险清单首位列出
- 若授权剩余年限 ≥ 10年 或 无固定期限（如百年品牌授权体系）：标注"续约风险低"，不降级
- 若授权方为政府/监管机构（如金融牌照、电信牌照）：标注"政策性牌照，续约风险取决于监管框架"，不自动降级
- 若授权数据不可获取：标注"⚠️ 授权期限数据缺失——'租来的护城河'评估不完整，这是分析盲区"

**护城河定量绑定规则**（必须基于数据，独立于估值水平）：

护城河评级必须绑定至少一项定量数据：
- 品牌/渠道护城河 → 市场份额（近 3 年趋势）+ 毛利率与竞对差值
- 规模护城河 → 固定资产周转率 + 单位成本优势
- 牌照/专利护城河 → 专利数量 + 许可壁垒
- **自动降级规则**：若市场份额连续 2 年下降，护城河评级自动降一级（如"优质"→"中性"→"负面"）
- **禁止估值驱动**：护城河评级不得因为股价下跌或 GG 升高而自动上调

**护城河/价值陷阱 → 仓位上限绑定**（因子4引用）：
| 护城河评级 | 价值陷阱评级 | 仓位上限 |
|:---------:|:---------:|:------:|
| 负面 | 任意 | 50% |
| 任意 | 高 | 50% |
| 中性/一般 | 中 | 70% |
| 优质 | 低 | 标准（100%） |

输出：`[优质 / 中性 / 负面]`

**护城河vs价值陷阱的概念区分（v2.30）**：
护城河是相对概念（比同行强多少），价值陷阱是绝对概念（即使最强也不够好）。海螺是最低成本水泥厂（护城河中性偏正面），但行业萎缩中即使"最佳"也不够好（价值陷阱高）。强制在结论中区分两者：
```
护城河评级：[X] → "海螺是[行业内]最佳的[水泥厂]，但'最佳'在行业下行中也不够好。"
价值陷阱评级：[X] → "即使你是最优秀的玩家，整个游戏的回报率也在下降。"
```
  附注：护城河类型 = [非技术] xxx + [技术] xxx（若第二层不适用则标注"不适用"）
  附注：是否构成复合护城河飞轮 = [是/否]
  附注：定量绑定数据：{市场份额趋势/毛利率差/其他}
