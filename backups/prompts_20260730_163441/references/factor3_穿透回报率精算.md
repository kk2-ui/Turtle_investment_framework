```
营业收入 = [值] 百万元（S）
应收账款净变动 = [值] 百万元（T）（增加为正，减少为负）

保守处理规则：
  应收账款净增加 → 扣除（收入未收到现金）
  应收账款净减少 → 加回（收回了以前的钱）
  预收款/合同负债净增加 → 不加回（对应未来交付义务）
  预收款/合同负债净减少 → 扣除（消耗了以前预收的现金）
  例外：高确定性预收模式（白酒等）可将净增加加回，需标注理由

真实现金收入 = S - T的净增加部分 - U的净减少部分
收款比率 = 真实现金收入 / S

判断：收款比率是否长期接近1？
  若长期 < 1 → 说明原因，进入应收账款footnote核查
```

## 步骤4：经营性现金支出还原

> **§17.4 预计算加速**：若 data_pack_market §17.4 存在，直接引用逐年 W1/W2/W3/W4/W 合计。LLM 仅需审核资本化利息是否需要还原（W4a 调整）。若 §17.4 缺失，从原始数据手动计算。

逐年计算：

```
### 步骤4-bis：AP超额融资驱动的AA占比检测（v2.41，强制）

当应付账款(AP)/营业成本或应付账款周转天数(DPO)相对历史/行业基准显著拉长，且最近年 `AP超额融资贡献/AA > 30%` 时，强制拆解AA来源。

**核心原则**：AP随业务规模扩大而同比例增长是正常营运资本伴随效应，不能全部视为延迟支付供应商。只有 AP/成本 或 DPO 超过历史/行业基准后的“超额部分”，才可视为供应商融资贡献。

```
AP_ratio_t = AP_t / 营业成本_t
DPO_t = 平均AP_t / 营业成本_t × 365
平均AP_t = (AP_t + AP_{t-1}) / 2

baseline_ratio = 历史稳定期AP/成本中位数；若有可靠行业数据，用行业中位数交叉验证
正常AP_t = 营业成本_t × baseline_ratio
超额AP存量_t = max(0, AP_t − 正常AP_t)
AP超额融资贡献_t = max(0, 超额AP存量_t − 超额AP存量_{t-1})

AA = [经营驱动部分] + [AP超额融资贡献]
经营驱动 = AA − AP超额融资贡献

简化复核式：AP超额融资贡献 ≈ max(0, ΔAP − baseline_ratio × Δ营业成本)
```

强制输出表：

| 年份 | AP | 营业成本 | AP/成本 | DPO | 基准AP/成本 | 正常AP | 超额AP存量 | 本年超额AP融资贡献 | 占AA比例 |
|------|----|---------|--------|-----|------------|--------|-----------|------------------|---------|
| 20XX | | | | | | | | | |

若 `AP超额融资贡献/AA > 30%` → 强制标注：

→ DDM/GG裁决必须同时展示"报表口径"和"AP超额融资调整后"两个版本。

→ 若 `AP超额融资贡献/AA > 50%`：裁决必须以AP-adjusted GG为基准（而非同时展示两个版本后折中）
  - 若AP-adjusted GG < II → 裁决不得高于"观望"（禁止"偏向买入"/"强烈买入"），无论原始GG多高
  - 理由："超过一半的AA来自付款周期相对基准拉长形成的供应商融资，非公司核心盈利能力。在付款周期可持续性被验证之前，保守投资者应假设超额AP融资贡献不可持续。"
→ 若剔除后GG<II→强制标注"GG达标依赖营运资本周期改善。若付款周期回归历史/行业基准→GG将降至X.X%且低于II。"（营运资本周期逆转风险）
```

**CV>50%中位数 vs 结构性跃升判定（v2.27，强制）**：
当CV>50%触发中位数规则但前低后高可能反映结构性改善（而非波动噪音），执行以下判定：

结构性跃升三条件（满足≥2即成立）：
- (1) 后段(近3年)均值 / 前段(早期)均值 > 3x
- (2) 后段连续≥3年未回落到前段水平
- (3) OCF/营收比率后段均值 ≥ 前段均值的1.5x

判定为结构性跃升 → 覆写CV规则，使用AA_2y，标注"⚠️v2.27结构性跃升"
判定为波动噪音 → 仍用中位数
若存争议(后段<3年)→输出双基准GG区间:"GG∈[X.XX%, Y.YY%]，建议置信区间处理"

数据完整性得分仅反映"字段是否可获取"，不反映"获取后是否需大量估算"。若AA计算中大量依赖替代估算（如W2用SGA替代、X1保守设0），即使字段完整，追加0.3-0.5pct：

```
满足≥2项→追加估算折价0.3-0.5pct：
  - W2员工支付使用利润表SGA替代(非CF原始字段)
  - X1投资性购买因数据缺失保守设为0
  - V1/V5仅依赖单一CF行项(无附注交叉验证)
GG_effective = GG_raw − 数据完整性折价 − 关联交易折价 − 估算依赖折价 − 验证偏差折价
```

**关键估计联合误差传播表（v2.26，强制）**：

GG 依赖多个估计参数的链条（AA基准选择→M→Q→折价→λ）。单个敏感性无法反映联合不确定性。必须输出以下联合误差表：

| 参数 | 保守 | 基准 | 乐观 | GG_保守 | GG_基准 | GG_乐观 |
|:-----|:---:|:---:|:---:|:---:|:---:|:---:|
| **AA基准** | AA_all/median | AA_excl | AA_2y | X.XX% | X.XX% | X.XX% |
| **M(支付率)** | M−3pct | M | M+3pct | — | — | — |
| **数据折价** | +1pct | 基准 | 0（无折价） | — | — | — |
| **λ** | NP比例法×0.5 | NP比例法 | NP比例法×1.5 | — | — | — |
| **Q税率** | 20% | 10% | 0% | — | — | — |

**联合极值**（以上五项同时取保守/乐观）：
```
GG 联合保守 = X.XX%（AA取低+M取低+折价+1pct+Q=20%）
GG 联合乐观 = X.XX%（AA取高+M取高+折价=0+Q=0%）
GG 置信区间 = [X.XX%, X.XX%]，宽度 = X.XXpct

裁决稳健性判断：
  若联合乐观 < II → "GG在所有合理假设下均低于II，裁决稳健"
  若联合保守 > II → "GG在所有合理假设下均高于II，裁决稳健"  
  若区间跨越 II → "GG对假设敏感，建议以灰区处理而非二进制裁决"
```

**禁止**：在输出GG点估计时不附带此联合误差表。GG=3.71%这样的孤立数字在v2.26框架中不再充分。

**关联交易透明度折价（v2.24）**：
此项为独立折价，与上述 fields 完整性折价**累加**（不取max），理由：关联交易透明度影响的是"归母利润中有多少真正属于小股东"这个独立风险维度。

```
关联交易折价 = 因子1B模块六输出的「关联交易透明度折价」%（0-5%）
  // 来源：data_pack_report.md §P4 自检表 → 因子1B模块六评估 → 传递至因子3

GG_effective = GG_raw − 数据完整性折价 − 关联交易透明度折价 − 验证偏差折价
  // 两项累加，关联交易折价上限 1.5%（v2.24修订：3-5%太激进，对正常企业不公允）
  // 央企/国企背景可再下调 0.2-0.3pct
  // 总折价上限：数据完整性(3pct) + 关联交易(1.5pct) = 4.5pct
  // 实际中：数据完整性通常 < 1pct，关联交易 0.3-1.0%，总折价 < 2pct
```

**估算依赖型数据的额外折价（v2.35）**：

折价基于估算依赖程度，不基于字段缺失。标注"⚠️估算依赖折价=+X.XXpct"。

若 data_pack_report.md 中无 §P4 自检表（旧版提取）→ Agent 根据可用关联交易信息自行评估，折价取 0.5-1.5%（标注 "⚠️ 关联交易透明度折价为主观估计"）。
```

### 步骤13b：关键估计联合误差传播（v2.31 强制）

**定位**：GG 依赖多个估计参数（AA、M、Q、λ、数据折价），单个敏感性不足以反映联合不确定性。本步骤强制输出五参数同时浮动的 GG 范围。

**五参数定义**：
| 参数 | 悲观值 | 基准值 | 乐观值 |
|:---|:---|:---|:---|
| AA (百万) | AA_all (全期均值) | AA_selected (步骤7选定) | AA_2y (近2年均值) |
| M (%) | M − 1σ (降低) | M (支付率锚定) | M + 1σ (提高) |
| Q (%) | 20% (港股通) | 用户Q | 0% (直投) |
| λ | λ_conservative | λ_neutral | λ_optimistic |
| 数据折价 | 全额折价 | 基准折价 | 0 (无折价) |

**联合范围计算**：
```
GG_min = [AA_pess × M_pess × (1−Q_pess) + O] / 市值 − 折价_pess
GG_max = [AA_opt × M_opt × (1−Q_opt) + O] / 市值 − 折价_opt
```

**强制输出**：
```
GG 联合范围: [GG_min]% ~ [GG_max]%
基准 GG: [GG_base]%
II: [II]%

联合范围 vs II:
  全悲观 GG_min = [X.XX]% vs II = [X.XX]% → [达标/不达标]
  全乐观 GG_max = [X.XX]% vs II = [X.XX]% → [达标/不达标]
  覆盖率: 乐观组合 [达标/不达标], 悲观组合 [达标/不达标]

结论: GG基准[X.XX]%在[GG_min]%-[GG_max]%范围内,
      [若非全档达标]乐观组合仍需[条件]才能达标→灰度决策
      [若全档不达标]全参数组合均不达标→确定性否决
```

## 步骤7 v2.7：AA计算强制使用OCF（不再用净利润替代）

**旧版问题**：当OCF数据不可用时，AA直接用归母净利润→完全忽略OCF波动→严重失真
**v2.7 规则**：

```
优先级1（OCF可用）：
  AA = OCF − Capex − 非经常性调整(V_deduct)
  // OCF和Capex从 pdf_sections_{year}.json 的 financials 字段读取

优先级2（OCF可用但Capex缺失）：
  AA = OCF − (D&A × G) − 非经常性调整  // 用因子2的G系数估计Capex

优先级3（OCF不可用）：
  AA = 归母净利润 × min(1.0, 近3年OCF/NI均值) − Capex − 非经常性调整
  // 用历史OCF/NI比率修正净利润，避免直接用净利润
  // 标注"⚠️ OCF不可用，AA基于净利润×修正系数(0.XX)"

优先级4（OCF和Capex都不可用）：
  AA = 归母净利润 × 0.7  // 保守折扣
  // 标注"⚠️ 无OCF/Capex数据，使用推测值(净利润×0.7)"
  // 禁止将此场景下的AA标注为"保守"——标注为"推测"
```

**禁止**：直接用归母净利润作为AA（除非优先级4且已标注"推测"）。如果 OCF > 0 且属于 financials 字段，必须使用优先级1。

## 步骤7 v2.8补充：AA高波动时的基准值选择

**规则**：若AA序列（近5年）变异系数CV > 50%：
```
CV = std(AA序列) / mean(AA序列)
若CV > 0.50 → 使用中位数(median)替代均值(mean)作为基准值
标注："⚠️ AA波动大(CV=XX%)，取中位数YY,YYY百万元代替均值ZZ,ZZZ百万元，更保守"
```

中位数不受极端值（如格力2023年50,188或2024年24,148）拉偏，是更稳健的基准选择。

## 步骤10 v2.9补充：λ下限规则

**问题**: NP比例法(如格力17%)比历史OCF-based λ(1.76)低10倍，会完全抹掉AA对收入的敏感性
**规则**: 
```
λ = max(NP比例法, 历史λ_median × 0.5)
其中：
  历史λ_median = 过去3年中符号一致的年份的ΔAA/Δ收入的中位数
  若有≥2年符号一致→取这些年的中位数作为历史λ基准
  若全部符号不一致→用NP比例法（无历史锚）
下限 = 历史λ_median × 0.5  // 不能比历史敏感性的一半还低

格力例: 历史λ≈1.76(2年符号一致), 下限=0.88
       λ = max(0.17, 0.88) = 0.88
       标注: "λ=0.88(v2.9下限校准, 历史λ_median=1.76×0.5)"
```

## 步骤10 v2.11补充：λ下限系数0.5的理由

**为什么是0.5而非0.6或0.4**：
- 0.5是保守折中——保留了历史敏感性的方向信息(历史λ证明AA对收入确实敏感)
- 同时给了50%折扣反映"Capex处于周期底部时结构性关系可能变化"
- 若取0.6→折扣太小，忽视了Capex可能回升的结构性风险
- 若取0.4→折扣太大，过度否定历史关系
- 0.5在数学上等价于"历史中位数的一半"，有直观解释性
