## 一、行业成熟度衰减系数

DPS CAGR 不能直接外推，必须乘以行业成熟度衰减系数：

| 行业类型 | 衰减系数 | 示例 |
|---------|:-------:|------|
| 成熟消费 / 公用事业 / 稳定红利 | 0.6-0.8 | 食品饮料、电力、高速 |
| 弱周期制造 / 防御消费 | 0.7 | 家电、日化 |
| 高分红制造 | 0.7 | 家电、汽车零部件、工程机械（连续3年派息率≥40%+FCF/NP≥80%） |
| 成长期行业 | 0.8-1.0 | 新能源、半导体 |
| 周期行业 | 保守处理 | 不直接外推高 DPS CAGR，需保守假设 |

**格力电器适用**：弱周期制造 → **衰减系数 = 0.7**

## 二、DPS 增速三档推导（通用）

### 2.1 DPS CAGR 基期异常检测

**基期候选集**：报告期前推 1/2/3/4/5 年，计算 5 个 CAGR 值（至少 2 年，推荐 3 年）。

**异常检测**：
- 若基期 DPS 为近 N 年最低值 → 标记"⚠️ 基期异常低（原因：XXX），CAGR 可能偏高"
- 若基期 DPS 为近 N 年最高值 → 标记"⚠️ 基期异常高（原因：XXX），CAGR 可能偏低"

**DPS连续下降警告（v2.36）**：
若DPS连续≥3年下降：
  → 强制输出："⚠️ DPS已连续[N]年下降([Y1]→[Y2]→[Y3]→[Y4])，
    即使GG达标，市场对'股息连续下降'的负面情绪可能延缓估值修复。
    DDM假设g_base在当前水平企稳——若FY[X+1]继续下降，DDM年化将降至约[X.X]%，但仍>II。"
  → 在DDM敏感性分析中，增加"DPS再降10%"的情景（而非标准的±10%收入波动）

**基期选择优先级**：

| 优先级 | 方法 | 适用条件 |
|:---:|------|---------|
| a | 近 3 年 CAGR（报告期往前推 3 年） | 基期非异常低/高（默认优先） |
| b | 近 2 年 CAGR | 若近 3 年基期异常低/高，标注原因 |
| c | 水平法（均值对比） | 若近 2 年基期仍异常：DPS_mean_3y = mean(DPS_{t-2}, DPS_{t-1}, DPS_t)。若 DPS_t ≈ DPS_mean_3y（平台期）→ 基础 g = 0~1%（平台假设）；若 DPS_t > DPS_mean_3y → 基础 g = (DPS_t/DPS_mean_3y - 1) 年化 |
| d | 禁止单年增长率冒充 CAGR | 至少 2 年 |

**输出格式（强制包含）**：
```
DPS CAGR = X.X%（基期YYYY DPS a.bc → 报告期YYYY DPS d.ef，N 年；
基期是否异常：是/否（原因）；备选口径：YYYY→YYYY 为 X.X%）
```

**毛利率/利润率企稳仅一年数据的谨慎处理（v2.36）**：
若毛利率企稳/改善仅基于最近1年数据（n=1），在g_base推导中：
  → 强制输出："⚠️ 毛利率企稳仅1年数据——若FY[X+1]毛利率继续下行至[X.X]%，
    AA将降至[X]M，GG降至[X.X]%，安全边际从+[X]pct缩至+[X]pct。仍>II——但置信度需下调。"
  → g_base不做数值调整，但外推可信度自动降一档

**校验规则**：
1. 若 DPS CAGR > 归母净利润 CAGR + 5pct，自动报警：
   "⚠️ DPS CAGR 显著高于利润 CAGR（DPS=X.X% vs NP=Y.Y%），需检查派息率是否持续提升"
2. 若基期 DPS 为近 5 年最低或最高，自动标注：
   "⚠️ 基期 DPS X.XX 为近 5 年最X值，CAGR 可能偏高/偏低"

### 2.1b 支付率超上限检测（在基础增速计算前）

**子类派息率上限**：

| 子类 | 上限 | 适用 |
|------|:---:|------|
| 民企（含高分红制造） | 50% | 格力、美的、福耀等 |
| 央企消费 / 稳定红利 | 60% | 中国食品、华润等 |
| 央企周期 | 55% | 神华、海油等 |
| 防御高派（净现金） | 60% | 长和、港灯等 |

**分支逻辑**：

1. **若当前派息率 > 子类上限**：
   - 标记"⚠️ 派息率已超上限（当前 X.X% > 上限 Y.Y%），无释放空间，未来可能回吐至上限"
   - 回吐幅度 = (上限 / 当前派息率 - 1)。格力例：50%/57.9% - 1 = -13.7%
   - **DPS 基础 g 不能直接用"CAGR × 衰减 × 折扣"**，改用拆分法：
     ```
     DPS_g_base = EPS_g + 回购注销贡献 + 支付率回吐贡献（为负）

     其中：
       EPS_g = 收入增速 × 净利率变化调整（保守取 0~1pct）
       回购注销贡献 = 近 3 年股本缩减 CAGR
       支付率回吐贡献 = (上限/当前派息率)^(1/N) - 1（为负或 0）
     ```
     若 EPS_g 不确定性高（如收入连续下滑），则 DPS_g_base 取 0~1%（平台假设）或保守负值

2. **若当前派息率 ≤ 子类上限 - 5pct**：
   - 正常走"DPS CAGR × 少数股东折扣 × 衰减"
   - 派息率释放为正向贡献，计入乐观档

3. **若当前派息率 ∈ (上限-5pct, 上限]**：
   - 正常走 CAGR 路径，但不计派息率释放贡献（已接近上限）

### 2.1c DPS动量检验 + 增速可持续性（v2.32，强制）

**DPS连续下降的动量标注**：
当DPS连续≥3年下降时，即使支付率稳定（DPS下降仅因EPS下降），市场通常对"股息连续下降"产生负面的动量预期。必须独立于增速检验，标注DPS动量：

```
DPS动量趋势：[FY2021→FY2025]: X.XXX→X.XXX→X.XXX→X.XXX→X.XXX（连续N年下降，累计降幅X%）
  若连续≥3年下降→标注"⚠️ DPS连续下降可能延缓估值修复：即使GG达标，市场可能因股息惯性而保持谨慎"
  若g_base=0%（假设DPS企稳不再降）→标注"该假设隐含FY2026 DPS≥FY2025，需FY2026中报验证"
  若FY2026 DPS继续下降→DDM年化从X.XX%降至Y.YY%（仍>/≤10%目标）"
```

### 2.1d DPS增速可持续性检验（v2.27，强制）

**定位**：DDM的回报率对DPS增速假设高度敏感，但DPS增速可能来自利润增长（可持续）或支付率提升（不可持续）。必须区分两者。

**强制拆解**：
```
DPS 5年CAGR = X.X%（源自 DPS_{FY0} / DPS_{FY-5} ^ (1/5) - 1）

拆解（近似）：
  归母净利润5年CAGR = X.X%
  支付率变化贡献 = DPS CAGR − 归母净利润CAGR ≈ X.Xpct

可持续性判断：
  若支付率贡献 ≤ 总增速的30% → "DPS增长主要由利润驱动，可持续性高"
  若支付率贡献 ∈ (30%, 50%] → "DPS增长部分依赖支付率提升，标注为'可部分持续'"
  若支付率贡献 > 50% → "⚠️ DPS增长主要靠支付率提升（非利润增长），g_base不可持续！DDM给出的高年化是虚假信号。"
  
  联动处理：
    → 支付率贡献>50%：g_base下调至min(归母净利润CAGR×衰减, g_base×0.5)
    → 在DDM表格旁标注"⚠️ 当前g_base=X.XX%中X.XXpct来自支付率提升，不可持续"
```

**示例（中海物业）**：
```
DPS 3y CAGR = 16.55%，归母净利润3y CAGR = 3.02%
支付率变化贡献 = 16.55% − 3.02% = 13.53pct → 占总增速的82%
→ ⚠️ DPS增长主要靠支付率提升！g_base不可持续。
→ 联动：g_base从9.93%下调至min(3.02%×0.7, 9.93%×0.5)=min(2.11%, 4.97%)=2.11%
→ DDM结论从"当前价可买(12.94%)"变为"需深度回调(2.11%年化)"
```

### 2.1c-ter：DPS连续≥4年下降的强制向下偏离（v2.37）

若DPS连续≥4年下降：
  → **禁止**假设g_base=0%（企稳）。必须分析下降驱动因素：
    - 利润率恶化驱动（毛利率/净利率持续下滑）→ g_base = min(DPS 3y CAGR, -2%)
    - 一次性减计/异常驱动（某年因商誉减值等一次性原因）→ 排除异常年后重新计算
    - 管理层主动控制分红（支付率稳定但EPS降）→ g_base = 归母净利润CAGR × 衰减
  → 标注"⚠️ DPS连续N年下降([序列])→g_base=[X.X]%([原因])"

### 2.1c-quater：盈利预测的强制触发条件（v2.39）

当报告使用g_base=0%（平台假设）且满足以下任一条件时，必须回答三个问题：
1. 毛利率连续≥3年下降（如金融街：19.9%→17.4%→16.6%→14.4%→14.2%）
2. 归母净利润连续≥3年下降
3. DPS连续≥4年下降

强制问答：
```
Q1: 毛利率何时企稳？ "仅FY2025微降0.23pp不构成反转证据。需要≥2个季度毛利率≥前值才能确认企稳。"
Q2: 净利润何时停止下滑？ "若毛利率企稳，净利率回升至X%需要收入增速>Y%。当前收入CAGR=Z%，预计FY2026净利≈XXXM。"
Q3: 如果上述假设不成立，DDM年化会降至多少？ "悲观：毛利率再降1pp→AA降至X→GG降至Y→DDM年化降至Z%。"
```
若三个问题均无法用现有数据回答→g_base禁止设为0%，强制取min(3y CAGR, -1%)。

### 2.1d 基础增速

```
正常分支（派息率 ≤ 上限-5pct）：
  g_base = DPS_CAGR（来自 2.1 基期选择规则）x 行业衰减系数 x 少数股东折扣

超上限分支（派息率 > 上限）：
  g_base = EPS_g + 回购注销贡献 + 支付率回吐贡献（来自 2.1b 拆分法）
```

- 少数股东折扣：少数股东占比 < 5% → 1.0；5-20% → 0.95；> 20% → 0.85-0.90
- **禁止**：手填 DPS CAGR、用1年数据写 CAGR、用去重后的市场分红表替代年报股息拆分

### 2.1d B类新业务对g_base的数值惩罚（v2.31 强制，替代原文本警告）

**前提**：仅当因子1C步骤4b输出中存在B类数据且满足条件时执行。

**规则**：
若因子1C输出的B类营收占比>15%且B类毛利率<主业毛利率：
  **强制数值惩罚**：
  ```
  利润率拖累权重 = B类占比% × (主业毛利率% − B类毛利率%) / 主业毛利率%
  惩罚系数 = 0.3 (若B类占比15-25%) / 0.5 (若B类占比>25%)
  g_base_B_adjusted = g_base × (1 − 利润率拖累权重 × 惩罚系数)
  ```
  **输出格式**：
  ```
  B类业务质量调整:
    B类占比: [X]%
    主业毛利率: [X.X]% | B类毛利率: [X.X]% | 差值: [X.X]pct
    利润率拖累权重: [X.X]%
    惩罚系数: [X.XX] (占比[15-25%→0.3/>25%→0.5])
    g_base 调整: [X.XX]% → [X.XX]% (下调 [X.XX]pct)
  ```

  若B类营收占比>30%：额外标注"新业务占比超30%，对远期DPS增速持保守预期。"

不满足前提条件 → 无需输出，g_base无调整。

### 2.2 悲观增速

```
正常分支：g_pess = g_base x 0.5
超上限分支：g_pess = 回吐年化（负值，保守取支付率回吐贡献的100%）
  // 例：回吐贡献=-2.89%/年 → g_pess = -2.9%
  // 与旧版区别：不再取max(...,0)，悲观应有负值情景
  // 注意：支付率超上限时，悲观不应简单 = 基准×0.5
  // 因为悲观假设更差场景，EPS_g 取负值 + 回购，保底 0
```

### 2.3 乐观增速 + DPS 专属上限 B

**两套上限，独立计算**：

**A. 行业收入上限**（仅用于 DCF 永续增长率 g，不用于 DPS 三档截断）：
- 成熟消费/稳定红利：3-5%
- 弱周期制造（含高分红制造）：3-4%
- 成长行业：5-8%
- 周期行业：2-3%

**B. DPS 专属上限**（新增，用于截断乐观 DPS 增速）：
```
DPS_cap_B = 支付率提升贡献 + 回购注销贡献 + EPS 增速贡献上限

其中：
  支付率提升贡献 = ((min(当前派息率+10pct, 子类上限) / 当前派息率)^(1/N) - 1) x 置信折扣
    // 若当前派息率已超上限，此项为 0 或负，不计入 B
  回购注销贡献 = 近 3 年股本缩减 CAGR（若披露回购计划则按计划回购额/市值/N 估算）
  EPS 增速贡献上限 = 行业收入增速上限 A（保守取 A 值，0~4.8%）
```

**乐观增速公式**：
```
g_opt = max(g_base x 1.5, 派息率释放年化（若适用）)
g_opt = min(g_opt, DPS_cap_B)  // 只用 B 截断，不再用行业收入上限 A
```

**目标派息率默认**：

| 企业类型 | 目标派息率 |
|---------|:--------:|
| 央企消费 / 稳定红利 | 60% |
| 央企周期 | 55% |
| 民企 | 50%（当前派息率已超时不再上调） |
| 防御高派（净现金） | 60% |

**置信折扣默认**：

| 企业类型 | 置信折扣 |
|---------|:------:|
| 央企消费 | 0.3 |
| 央企周期 | 0.2 |
| 民企 | 0.1 |
| 治理或关联方复杂 | 再下调 0.05-0.1 |

### 2.4 乐观 < 悲观 自动报警 + 修正

DPS 三档计算完后，强制校验：

```
if 乐观 < 悲观:
   报警："⚠️ DPS 三档乐观 < 悲观（乐观=X.X% < 悲观=X.X%），截断或推导有误，请检查：
   - 乐观是否被行业收入上限 A 错误截断？（应使用 DPS 专属上限 B）
   - 悲观是否因支付率回吐被抬高？（支付率回吐只影响基准/乐观，悲观应用 2.2 超上限分支）
   - 基准 g 是否因支付率超上限被压低？（此时悲观不应=基准×0.5，应用 2.2 超上限分支）"

   修正动作：
   - 乐观档改用 B（DPS 专属上限）重算
   - 若支付率超上限，悲观档用 2.2 超上限分支重算
   - 修正后仍异常 → 在报告中显式标注并降级外推可信度
```

## 三、终点估值：GG 回归

对每个买入价计算 N 年后的终点价格。默认 N = 5。

> **⚠️ 术语区分（v2.38）**：因子3的GG是公司可持续现金回报率（经营回报），
> 因子4的"终点GG"是市场要求的贴现率（定价参数）。两者含义完全不同。
> 为避免混淆，因子4下文统一使用"终点RR (Required Return)"替代"终点GG"。
> 含义不变：终点RR越高 → 估值越保守 → 买点越低。

```
DPS_N = DPS_latest x (1 + g)^N
终点股价 = DPS_N x (1 - Q) / 终点 RR
```

### 终点 RR（Required Return）三档

**必须结合子类判断，不得固定写死**：

**DDM保守模式强制悲观假设（v2.37）**：
"保守模式"必须使用g_pess（悲观增速）和悲观终点GG作为基准，不得使用g_base。
保守模式 = g_pess + 悲观GG，当前价年化≥10%才算保守达标。
基准模式 = g_base + 基准GG，为参考值。
"保守"体现在假设上（用最坏情景），而非仅在结果要求上（10%门槛）。

| 子类 | 悲观 GG | 基准 GG | 乐观 GG | II 门槛 | 说明 |
|------|:------:|:------:|:------:|:------:|------|
| 防御高派蓝筹 | ~6.5% | ~6.0% | ~5.5% | 6.0% | 央企消费/稳定红利 |
| 净现金轻资产红利 | ~6.0% | ~5.5% | ~5.0% | 5.5% | 轻资产+净现金 |
| 高分红制造 | ~7.0% | ~6.5% | ~6.0% | 6.5% | 连续3年派息率≥40%+FCF/NP≥80%+成熟制造 |
| 弱周期制造红利 | ~7.0% | ~6.0% | ~5.5% | 6.0% | 一般弱周期制造 |
| 周期高派 | ~9.0% | ~8.0% | ~7.0% | 8.0% | 资源/航运等 |
| 高少数股东占比标的 | 各档 +0.5pct | — | — | 各档+0.5pct | 下调门槛，须解释传导折扣 |

**高分红制造判定条件**（三项全满足）：
1. 连续 3 年派息率 ≥ 40%
2. 自由现金流/净利润 ≥ 80%（近 3 年均值）
3. 行业为家电/汽车零部件/工程机械等成熟制造

与普通"弱周期制造"的区别：高分红制造因分红确定性溢价，门槛 II 上调 0.5pct（投资者对确定性分红要求略高），但终点 RR 基准也上调 0.5pct（反映分红+回购双渠道回报）。DPS 专属上限 B ≈ 3-5%（支付率 50-60% + 回购 1-2% + EPS 0-1%）。

## 三-B、价值陷阱排查（独立于估值水平）

**核心原则**：价值陷阱评估必须独立于估值水平。GG 升高或股价下跌不得自动降低风险评级。

逐项检查（仅调用前序因子结论，基于最新财报数据，不做新分析）：

**护城河vs价值陷阱的概念区分（v2.35）**：
护城河是相对概念（比同行如何），价值陷阱是绝对概念（回报能否达标）。
两者可共存——海螺是"最好的水泥厂"（护城河中性偏正面），但"最好"
在行业下行时也不够好（GG=-1.46%低于II=3.75%）。必须显式标注此区分。


| 序号 | 陷阱特征 | 数据来源 | 判断标准 | 结果 |
|------|---------|---------|---------|------|
| 1 | 现金流趋势性恶化 | 因子3结余序列 | 连续≥2年下降且降幅>15% | [存在/不存在] |
| 2 | 护城河正在收窄 | 因子1B模块三 | 非技术层侵蚀判定为"负面"，或技术层被颠覆 | [存在/不存在] |
| 3 | 行业结构性衰退 | 因子1B模块四 | 终端需求不可逆萎缩（非周期性波动） | [存在/不存在] |
| 4 | 分配意愿存疑 | 因子3分配意愿 | 判定为"弱" | [存在/不存在] |
| 5 | 管理层损害价值 | 因子1B模块六 | 判定为"损害价值"或"观察期" | [存在/不存在] |

**AP依赖触发价值陷阱升级（v2.41）**：
当因子3输出 `AP超额融资贡献/AA > 50%` 或 `AP-adjusted GG < II-2pct` 时→价值陷阱评级自动+1级（低→中，中→高）。
理由: "AA显著依赖付款周期相对历史/行业基准拉长形成的供应商融资。若付款周期回归基准，GG将从X%降至Y%→价值陷阱特征。"
若同时满足 `AP超额融资贡献/AA > 50%` + 毛利率连续≥3年下降→强制升至"高"，标注"⚠️ 双重价值陷阱信号:AP超额融资依赖+毛利率下行"。

**量化预警阈值（v2.27，强制）**：
定性判断辅以量化数据，增强"低风险"判定的说服力：

| 预警项 | 量化阈值 | 当前值 | 触发？ |
|:-------|:------:|:-----:|:----:|
| 毛利率侵蚀 | 连续2年下降且累计>3pct | [X.X%→X.X%] | [是/否] |
| 收入萎缩 | 连续2年下滑且累计>15% | [X%] | [是/否] |
| 支付率下降 | 连续2年下降且累计>5pct | [X%→X%] | [是/否] |
| OCF/NP趋势 | OCF/NP<0.5 且连续2年下降 | [X.XX] | [是/否] |

**联动规则**：
- 若量化预警≥2项触发 + 定性检查≥1项存在 → 价值陷阱评级强制升至"中"
- 若量化预警≥3项触发 → 价值陷阱评级强制升至"高"
- 若量化数据不可得（如港股毛利率数据缺失）→ 标注"量化预警数据不足，仅依赖定性判断"

**评分规则（最差项决定）**：

**GG<II×0.6自动升级（v2.39）**：
若GG < II × 0.6（即回报率不足门槛的60%），无论定性检查结果如何：
  → 价值陷阱评级自动升至"高"
  → 标注"⚠️ GG仅为门槛的[X]%——即使无任何陷阱特征，极低回报本身已构成价值陷阱"
  → 仓位上限额外减半（叠加其他约束之前）
  → 此规则独立于定性检查，为GG过低时的兜底保护

**评分规则（最差项决定）**：
```
综合评级 = 各项的最高分（最差的一项决定整体评级），不得取平均分掩盖单项风险
  存在项数 ≥ 2 项 → 高
  存在项数 = 1 项 → 中（标注风险点）
  存在项数 = 0 项 → 低
```

**限制**：
- 价值陷阱评级不得因为 GG 升高或股价下跌而自动降级
- 若价值陷阱评级为"中"或"高"，在 Exec Summary 的"核心风险"段必须显式列出
- 若护城河判定为"负面"或价值陷阱为"高"，仓位上限不得超过 50%
- 若护城河为"一般"或价值陷阱为"中"，仓位上限 70%
- **护城河中性+价值陷阱中软折扣（v2.28）**：若护城河="中性"且价值陷阱="中"，即使规则不强制降仓，施加0.8x审慎软约束。标注"⚠️护城河收窄+价值陷阱中等→仓位软折扣20%"

## 三-C、便宜程度分档（JJ → 仓位上限校验）

安全边际 JJ = GG − II，按 JJ 绝对值分档，作为 DDM 阶梯买入仓位分配的**独立上限校验**：

| JJ 范围 | 便宜程度 | 框架仓位上限 | 实际组合占比(×PORTFOLIO_CAP_PCT) | 说明 |
|:-------:|:------:|:---------:|:-------------------------------:|------|
| JJ > 5pct | 极度便宜 | ≤ 100% | ≤ CAP% | GG 远超门槛，安全边际充裕 |
| 2pct < JJ ≤ 5pct | 便宜 | ≤ 70% | ≤ 0.7×CAP% | GG 显著高于门槛，但需保留缓冲 |
| 0 < JJ ≤ 2pct | 略便宜 | ≤ 30% | ≤ 0.3×CAP% | 安全边际薄，仅轻仓参与 |
| JJ ≤ 0 | 不便宜 | 0%（否决） | 0% | GG 不达标，不建仓 |

> PORTFOLIO_CAP_PCT 来自 `.env`，默认 5%。实际组合占比 = 框架仓位上限 × PORTFOLIO_CAP_PCT%。

### 三-C-bis：分歧强度与灰度仓位（v2.31 强制）

**触发条件**：GG < II（三-C 分档为"不便宜"） 但 DDM 存在年化≥8%的合格档位 且 资产安全垫评级≥中。此时三视角裁决出现方向性分歧，不得简单取 0% 仓位。

**灰度仓位表**：
| 分歧强度 | 条件 | 灰度仓位 | 附加条件 |
|:---|:---|:---|:---|
| 弱分歧 | GG_opt ≥ II 且 DDM基准年化≥10% 且 资产≥中 | 观察仓 ≤2%组合占比 | 股价触及P4以下 |
| 中分歧 | GG−II > −2pct 且 DDM悲观年化≥8% 且 资产≥中 | 观察仓 ≤1%组合占比 | 股价触及P5以下 |
| 强分歧 | GG−II ≤ −2pct 或 DDM全线不合格 | **0%（回避）** | — |

**裁决输出格式**：
```
三视角统一裁决:
  经营回报层(GG): [达标(GG≥II) / 灰区(GG_opt≥II>GG_base) / 不达标(GG_opt<II)]
  DDM层: [当前价可买(存在合格档) / 需等回调 / 全线不合格]
  资产层: [高(净现金≥80%+PB<1) / 中 / 低(净负债或商誉>权益)]
  
  分歧强度: [无分歧(全Pass/全Fail) / 弱 / 中 / 强]
  灰度仓位: [≤X%组合占比] 或 [0%回避]
```

**资产层"强" vs GG层"不达标"的论证要求（v2.34）**：
当资产层评级为"强"但GG<II时，禁止仅凭规则直接给0%。
必须输出：
```
资产厚≠安全边际的原因：
  ① 可释放性：[国企控股/大股东控制/无催化剂]
  ② 资产质量：[现金是否经营必需]
  ③ 历史证据：[资产折价长期存在是否收敛过]
```

**AA/DDM口径优先级（v2.35，AA与DPS方向相反时强制）**：
因子3的AA是"可持续可支配现金"口径，因子4的DPS是"当期公告分红"口径。
当两者冲突（AA为负但DPS为正）时：
  裁决以因子3的可持续口径为准——当期分红可消耗存量现金，但长期不可持续。
  裁决不基于当前DPS的高低，而基于AA是否支持当前分红水平。
  必须在裁决中标注："AA口径：[-X.XX%] | DPS口径：[Y.YY%] | 裁决以AA为准"

**护城河收窄 vs GG达标的张力消解规则（v2.36）**：
当护城河评级为"中性/收窄中"但裁决为"买入"时，必须输出：
```
护城河收窄是相对概念（比同行差多少），GG达标是绝对概念（回报够不够）。
当GG-II > +3pct时，护城河收窄的仓位惩罚被GG安全边际覆盖。
本标的：GG-II = +[X.XX]pct [>/≤] 3pct → [惩罚被覆盖/惩罚保留]
```
若GG-II ≤ +3pct → 护城河收窄惩罚正常生效（0.8x折扣）
若GG-II > +3pct → 护城河惩罚被覆盖，仓位按标准规则
此规则旨在消解"护城河不好为什么还买"的逻辑张力。

**催化剂清单与重评触发条件（v2.39，裁决为"观望"或"回避"时强制）**：
当最终裁决为"观望"或"回避"时，必须输出明确的催化剂清单和重评触发条件：
```
重评触发条件（满足任一项即可重新评估）:
  ① [财务指标]: [具体数值阈值] (如"AP增量正常化至<AA的30%")
  ② [经营指标]: [具体数值阈值] (如"毛利率连续2季度回升至>15%")  
  ③ [治理信号]: [具体行为] (如"公司公告特别分红或回购计划")
  ④ [价格触发]: [具体价格] (如"股价跌至[N]元以下，GG被动升至>II")

当前进展: [X]/[N]项已触发 → 裁决维持不变
预计重评时间: [下期年报/中报/季报]发布后（约[月份]）
```

**与 DDM 仓位的关系**：
- 本分档提供仓位**上限**，DDM 阶梯买入提供仓位**分配**
- 若 DDM 阶梯仓位总和 > 本上限 → DDM 仓位必须等比缩减至上限
- 若 DDM 阶梯仓位总和 ≤ 本上限 → 按 DDM 阶梯执行

**仓位上限→结论语言映射（v2.6）**：
仓位上限直接决定最终结论的措辞，防止"30%仓位写偏向买入"的矛盾：

| 仓位上限 | 结论语言 |
|:------:|------|
| ≤30% | "观察（轻仓可考虑）" |
| 30-70% | "偏向买入（中等仓位）" |
| >70% | "买入（标准/重仓）" |

## 三-D、资产价值安全边际交叉验证（v2.22 新增）

> **定位**：在完成 DDM 收益层面的安全边际分析（三-C）之后，用资产负债表数据提供第
> 二道独立的"底线保护"检查。资产价值分析不修改 GG/DDM 计算的数值，但可能下调仓位上限。
> 仓位上限最终取"三-C 便宜程度分档"与"三-D 资产安全垫"的**孰低值**。

### 3D.1 净现金覆盖率（所有标的强制）

```
公式：
  广义净现金 = 现金及等价物 + 交易性金融资产 + 其他流动金融资产 - 总有息负债
  净现金/股 = 广义净现金 / 总股本
  净现金覆盖率 = 广义净现金 / 当前市值 x 100%

数据来源：
  广义净现金 = 因子3 步骤9 输出 net_cash_mm
  总股本 = data_pack_market S1
  当前市值 = data_pack_market S1
```

**分档标准**：

| 净现金覆盖率 | 含义 | 仓位影响 |
|:----------:|:----:|:--------:|
| >= 80% | 现金垫极厚 | 仓位上限可上调一档 |
| 50% ~ 80% | 现金垫充裕 | 无调整 |
| 20% ~ 50% | 有一定现金垫 | 无调整 |
| 0% ~ 20% | 现金垫薄 | 无调整 |
| < 0% | 净负债（无现金垫） | 无调整，标注 |

> 当净现金覆盖率 >= 80% 时，便宜程度分档（三-C）的仓位上限可上调一档
> （例如从 <= 70% 升至 <= 100%），因下行风险已被现金充分覆盖。
> 此规则必须在报告结论中显式标注原因。

### 3D.2 PB 估值区间（可选，基于数据可用性）

**执行条件**：满足以下任一条件时执行——
1. 当前 PB < 1.5x
2. 行业为金融/地产/周期/制造（非轻资产）
3. S17 存在历史 PB 数据

**跳过条件**：轻资产成长行业（如互联网、SaaS）且 PB > 5x，标注PB分析无参考意义。

```
数据来源：
  每股净资产 bps = data_pack_market S17 或 Tushare fina_indicator.bps
  当前 PB = S1 pb_ttm 或 当前股价 / bps
  历史 PB 序列 = S17 中 PB 历史数据（5-10 年）
```

**分档标准**：

| PB 条件 | 资产估值状态 | 仓位影响 |
|:-------:|:---------:|:--------:|
| PB < 0.7 | 低于保守清算价值 | 价值陷阱非高时仓位上限可上调一档 |
| 0.7 <= PB < 1.0 | 低于账面价值（破净） | 标注破净，检查资产质量 |
| 1.0 <= PB < 历史P25 | 低于历史低位 | 资产估值偏低 |
| 历史P25 <= PB <= 历史P75 | 合理范围 | 无调整 |
| PB > 历史P75 | 高于历史高位 | 标注PB处于历史高位 |

### 3D.3 商誉/无形资产集中度（所有标的强制）



**分档标准**：

| 商誉集中度 | 风险 | 对 PB 可靠性影响 |
|:---------:|:----:|:---------------:|
| < 10% | 低 | PB 可靠 |
| 10% ~ 30% | 中 | PB 需折扣 10-20% 后参考 |
| >= 30% | 高 | PB 参考价值显著下降 |

> 若商誉集中度 >= 30% 且当前 PB < 1.0：强制输出警告：
> 商誉占净资产XX.X%，账面价值存在虚高风险。即使PB<1.0，实际资产质量可能低于账面值。建议检查因子1对商誉减值的评估结论。

### 3D.4 资产安全垫综合评级（强制判断）

取 3D.1-3D.3 三项中最差一项作为综合评级：

| 条件 | 评级 |
|:----|:----:|
| 净现金覆盖率 >= 80% 或（PB < 0.7 且商誉集中度 < 10%） | 强 |
| 净现金 20~80% 且 PB < 0.7；或 PB < 0.7 但商誉集中度 10-30% | 中 |
| 净负债 或 PB > 历史P75 或 商誉集中度 >= 30% | 弱 |
| 轻资产/高PB行业，PB分析无参考意义 | 不适用 |

**与 DDM 仓位整合规则**：

```
最终仓位上限 = min(三-C 便宜分档上限, 三-D 资产安全垫上限修正, 流动性修正, 大股东现金折价修正)

**小盘流动性强制上限（v2.37）**：
若日均成交 < HKD 5M (约520万HKD=50万USD):
  框架仓位上限 = min(原上限, 20%)
  实际组合占比 = min(原占比, 2.0%)
  理由: "微盘股(日均成交<5M)建仓/退出冲击成本显著，仓位必须进一步压缩"
若日均成交 < HKD 2M:
  框架仓位上限 = min(原上限, 10%)
  实际组合占比 = min(原占比, 1.0%)

资产安全垫评级对仓位的影响：
  强   -> 仓位上限可上调一档（若净现金覆盖率>=80% 且 3D.4b未触发大股东现金折价）
  中   -> 仓位上限按三-C 执行
  弱   -> 仓位上限下调一档（如从 70% 降至 50%）
  不适用 -> 仓位上限完全按三-C 执行

大股东现金折价修正（3D.4b）：
  触发 → 即使净现金覆盖率>=80%，也不得上调仓位
  小股东有效净现金/市值 < 20% → 仓位上限下调一档

流动性修正（3D.4c）：
  严重不足(>日均量×10) → 仓位上限减半
  偏紧(>日均量×5) → 仓位上限 × 0.7
  充裕 → 无调整
```

### 3D.6 边界精度规则（v2.26 新增）

## 三-E、三视角统一裁决（v2.25）

> **定位**：GG（经营回报）、DDM（到手现金回报）、资产价值（下行保护）回答不同的问题，有天然的决策层级。
> GG 决定"值不值得拥有"，DDM 决定"什么价格买"，资产价值决定"买多少"。
> 三者不是并列投票关系，不能简单加分。

### 决策层级

```
第一层（准入）：经营回报(GG) — 这个生意值不值得做股东？
  ├─ GG ≥ II + 1pct → 合格，正常进入第二层
  ├─ II − 1pct ≤ GG < II + 1pct → 灰区，进入第二层但仓位受限
  └─ GG < II − 1pct → 不合格，停止。资产再厚也不是买入理由（除非有明确催化剂）

第二层（定价）：DDM — 什么价格买才划算？
  ├─ 当前价 DDM 年化 ≥ 10% → 当前价可买
  ├─ N 档内达标 → 等回调至合格起始价
  └─ 全 6 档不达标 → 任何价格都不划算，停止

第三层（仓位）：资产价值 — 下行保护有多厚？
  ├─ 强（净现金≥80% 或 PB<0.7）→ 仓位 100%（GG和DDM允许的范围内）
  ├─ 中 → 仓位 70%
  └─ 弱 → 仓位 50%
```

### 定性评分校准锚点 + 交叉验证（v2.39，强制）

0-10分量表标杆锚点：10=格力(GG>>II,当前价可买); 7=中国食品(GG~II,等回调); 5=中海(GG<II,0%仓位); 3=海螺(GG为负,回避); 0=资不抵债+欺诈。

**评分锚点的交叉验证（v2.39）**：完成评分后，必须用独立数据验证：
```
若评分≥7（买入区域）：GG是否≥II+2pct？DDM保守年化是否≥10%？若任一不满足→评分-1
若评分4-6（观望区域）：AP-adjusted GG是否<II？若满足→评分-0.5（通用校准：原始GG达标但AP-adjusted GG<II，说明评分被一次性营运资本改善抬高）
若评分≤3（回避区域）：PB是否<0.5或净现金>市值？若满足→评分+0.5（资产保护软化裁决）
```
此验证打破"定性→定量"的自我强化循环，确保评分不会被AP超额融资等一次性因素抬高。

### 定性评分校准锚点（v2.36，强制）

## 五、每档年化回报计算

对每个买入价 P_i，分别计算悲观/基准/乐观三种情景：

```
税前股息率_i = DPS_latest / P_i
税后股息率_i = 税前股息率_i x (1 - Q)

未来 N 年 DPS 序列：DPS_t = DPS_latest x (1 + g)^t  (t = 1, 2, ..., N)

累计税后股息 = Σ_{t=1}^{N} DPS_t x (1 - Q)

终点股价 = DPS_N x (1 - Q) / 终点_RR

总回报 = (终点股价 - P_i + 累计税后股息) / P_i

年化回报 = (1 + 总回报)^(1/N) - 1
```

## 八-B、年化收益拆解（GG + PE 回归）

**目的**：将预期年化回报拆解为两部分——经营回报（GG）+ 估值回归（PE变化），帮助投资者理解收益来源。

**公式**：
```
预期年化 ≈ GG + (合理PE − 当前PE) / 当前PE / N

其中：
  GG = 精算穿透回报率（经营回报）
  合理PE = min(1/终点GG基准, 行业PE中位数)
    // v2.6: 取理论PE与行业中位数的较低者，防止选择性地使用理论上限
    // 行业PE中位数来源：data_pack_market 或 WebSearch（标注来源）
  当前PE = 当前市值 / 归母净利润
  N = 持有年数（默认 5）
```

**输出三情景**：
```
当前 PE = X.Xx，GG = X.XX%

若 N 年后 PE 不变 → 年化 ≈ GG = X.XX%（纯粹经营回报）
若 N 年后 PE 修复到合理值（1/终点GG_基准 = X.Xx）→ 年化 ≈ GG + (合理PE − 当前PE) / 当前PE / N = X.XX% + X.X% = X.XX%
若 N 年后 PE 恶化到 X.Xx（悲观假设）→ 年化 ≈ GG − X.X% = X.XX%

结论：[标的]当前收益以经营回报（GG X.XX%）为主，PE 修复是额外期权，PE 恶化是额外风险。
```

**解读规则**：
- 若 PE 修复贡献 > GG 的一半 → "当前收益严重依赖估值回归，风险较高"
- 若 PE 修复贡献 < GG 的三分之一 → "当前收益以经营回报为主，PE 变化影响有限"
- 若 PE 不变情景年化 ≥ 10% → "即使没有估值修复，经营回报已足够，安全边际高"

### 8B.1 PE回归产业逻辑论证（v2.21，强制）

**目的**：防止机械套用"PE回归合理值"假设。Agent必须说明PE修复的现实基础。

**强制输出以下三段论**：

**（一）当前PE vs 合理PE的方向判断（v2.24，替代旧"PE被压缩"假设）：

首先计算合理PE（含增长）：PE_growth = 支付率 × (1−Q) / max(II − g_conservative, 0.5%)

### 6.0 方法论约束：资产价值与收益价值不可相加（v2.24）

> ⚠️ **核心规则**：资产基础法（净资产/清算价值）和收益法（GG/DCF）是两套独立的估值视角，分别回答不同的问题。**两者不可简单相加**——相加会导致重复计算。

#### 为什么不能相加？

1. **现金产生的收益已包含在 AA 中**：GG = AA × M × (1-Q) / 市值，其中 AA（真实可支配现金结余）包含了公司全部经营现金流，现金产生的利息收入/投资收益自然在其中。若再单独加回每股净现金 → 现金被计算了两次（一次作为收益来源，一次作为资产）。

2. **两种方法回答不同问题**：
   - 收益法（GG/DCF）："这家公司未来能为我赚多少钱？"
   - 资产基础法（NAV）："这家公司现在如果清算，值多少钱？"
   - 两个问题的答案不能相加，正如你不能同时"继续经营"又"清算资产"。

3. **反例教学**：
   ```
   公司有100万现金，年利息3万，GG=8%（已含3万利息折现）

   ❌ 错误：经营价值500万 + 现金100万 = 总价值600万
      → 3万利息被折现进500万，又加了100万现金本体 → 重复计算

   ✅ 正确：纯收益法估值 = 500万（已内含现金贡献，不需另加）
   ```

#### 三种正确的估值视角（选择其一，不混用）

| 方法 | 公式 | 适用场景 | 关键约束 |
|:-----|:-----|:---------|:---------|
| **纯收益法（GG反推）** | 内在价值 = AA_归母 × M × (1-Q) / II | 持续经营、正常盈利企业 | **默认方法**。现金贡献已内含，不需另加。 |
| **资产基础法（NAV）** | 每股净资产 = 归母权益 / 总股本 | 重资产破净、清算参考 | 仅作底线参考，不反映盈利能力。不与GG混用。 |
| **SOTP（分部加总）** | 经营业务价值 + 非经营资产价值 | 有明确可分离的非经营资产 | **唯一可"加"的场景**。非经营资产必须是不产生经营现金流的资产。 |

#### SOTP（分部加总）使用条件

SOTP 是唯一可以合法"加"的估值方法，但需满足严格条件：

**可加项**（非经营资产，不产生经营现金流）：
- 闲置土地/房产（不产生租金收入或租金已剥离）
- 持有待售的子公司股权（不纳入合并经营）
- 超额现金（超出日常运营所需的部分）

**不可加项**（已产生经营现金流，已在 AA 中）：
- 营运现金（日常周转所需）
- 经营性子公司的资产
- 产生租金/利息收入的资产

**超额现金估算**：
```
运营现金需求 ≈ 营业收入的 5-10%
超额现金 = 总现金 − 运营现金需求
⚠️ 港股须使用归母口径：超额现金_归母 = 超额现金 × (1 − 少数股东占比)
```

**SOTP 示例**（中国食品 00506.HK）：
```
超额现金（归母口径）≈ 1,840M CNY
经营业务价值 = AA_adj × M × (1-Q) / II
             = 1,012 × 0.498 × 0.80 / 0.07
             = 5,760M CNY
总股权价值 = 5,760 + 1,840 = 7,600M CNY
每股 = 7,600 / 2,797 = 2.72 CNY

⚠️ 与纯收益法（2.21 CNY）相差 23%，SOTP 偏乐观。
   建议使用纯收益法作为主锚，SOTP 为辅助参考。
```

### 6.4 PB 档位解读

| PB 区间 | 档位 | 资产保护程度 | 标准解读 |
|:------:|:----:|:-----------:|:---------|
| **< 0.5** | 深度破净 | 极端保护 | 市场对公司资产定价仅账面值X%。需警惕：深度破净往往是市场对资产质量或盈利前景的强烈负面判断。 |
| **0.5–0.8** | 显著破净 | 较强保护 | 股价低于每股净资产，提供一定下行缓冲。常见于重资产行业或周期性低谷。 |
| **0.8–1.2** | 接近净资产 | 一般保护 | 股价围绕净资产波动，资产价值对股价有一定锚定作用，但不构成显著安全边际。 |
| **1.2–2.0** | 溢价交易 | 有限保护 | 市价显著高于净资产，资产价值对下行保护的参考意义有限。估值主要依赖盈利和增长。 |
| **> 2.0** | 高溢价 | 无保护 | 资产价值分析对当前估值参考意义极低。股价主要由盈利、品牌等无形资产驱动。 |

### 6.5 NCAV（净流动资产价值）解读

NCAV 是 Graham 深度价值指标。**对正常盈利企业，NCAV 通常远低于股价，不构成买入信号。**

| 比较 | 判定 | 解读 |
|:-----|:----:|:-----|
| 股价 < NCAV × 0.67 | 极端低估 | Graham经典标准。市场对流动资产的定价仅为清算价值的2/3。 |
| 股价 < NCAV | 低于清算价值 | 股价低于净流动资产。但实际清算成本、资产折价可能大幅削减回收价值。 |
| 股价 > NCAV | 正常 | 符合正常盈利企业特征。市场为持续经营能力和盈利能力支付了溢价。 |

⚠️ **重要限制**：
- NCAV 假设流动资产可按账面值变现，实际清算通常有 20-50% 折价
- 不适合轻资产企业（流动资产占比低）——此时 NCAV 为负是正常的
- **GG 或 DDM 不满足买入条件的标的，NCAV 达标也不应作为买入理由。资产价值仅作参考。**
- **禁止将 NCAV（或每股净现金）与 GG 反推的经营价值相加。** 两种方法代表不同估值视角，相加会导致现金贡献被重复计算（现金产生的收益已包含在 AA 中）。详见 §6.0 方法论约束。
