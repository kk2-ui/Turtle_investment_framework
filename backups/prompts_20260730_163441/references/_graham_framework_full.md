# 格雷厄姆–格林沃尔德估值框架（完全版 · 综合派 canonical）

> 忠于 Bruce Greenwald《价值投资：从格雷厄姆到巴菲特（第2版）》，叠加 GG（现金兑现）视角，
> 以"综合派"作为唯一裁决哲学。lite 版（`_graham_framework_lite.md`）是本文的执行子集；
> 本文覆盖 **为什么这么算、边界在哪、什么时候不这么算**，含推导与算例。

## §0 理念脊梁 · 为什么是这套框架

**格林沃尔德的核心断言**：绝大多数 DCF 是自欺——终值假设吞掉了 60%+ 的估值，而终值恰恰最不可知。
他的解法是把估值按**可知程度分层**，从最硬（资产）到最软（成长）：

```
资产价值 AV   （最可知：资产负债表上摆着）
   ↓
盈利能力价值 EPV （次可知：正常化盈利 / r*，不含任何增长假设）
   ↓
成长价值      （最不可知：只有护城河内才算数，否则记 0）
```

三层之间的**大小关系本身就是信息**——它告诉你这门生意的竞争性质（见 §4）。这是格林沃尔德最深的一招：
估值过程同时是一次商业定性诊断。

**为什么再叠一层 GG（综合派）**：格林沃尔德算的是"内在值 IV"——生意本身值多少。
但 A 股/港股大量公司 IV 不假，**兑现不了**：利润留存后被大股东侵占、被低效再投资烧掉、被治理黑洞吞掉。
GG 视角只认"真正到小股东手里的现金"。二者**不是同一问题的两个答案，是两个正交问题**：
- 格林沃尔德：这门生意值多少？（IV）
- GG：其中多少会兑现给我？（V_cash + 留存的兑现信用 λ）

综合派用一条确定性公式把两者合成 V_final（见 §6），闭掉"定性与定量打架时听谁"的逻辑环。

**唯一裁决哲学（记住这一行）：**
```
V_final = V_cash + λ × (IV − V_cash) = IV × [分红率 + λ×(1−分红率)]
```
λ=1 纯格林沃尔德（留存全算数）；λ=0 纯 GG（只认分红）；中间由三因子确定性打分。

## §1 数据归一 · 正常化盈利 E_norm

**为什么必须正常化**：EPV = E/r\* 是永续资本化，把当期盈利放大 1/r\* ≈ 15–20 倍。
若 E 含一次性收益或处于周期顶部，误差同样被放大 15–20 倍。E_norm 的全部功夫，就是让被资本化的那个数
代表"中周期、正常竞争、正常税负下每年能持续赚到的归母利润"。

**逐项调整（顺序做，每项留痕数字）：**

**① 去一次性损益**
判据：不会年年发生的，全去掉。资产处置损益、减值/转回、诉讼赔偿、一次性政府补贴、重组费用、
公允价值变动损益、债务重组收益。
- 边界：某些"经常性的非经常项"要保留——如每年都有的稳定政府补贴（本质是经营性），
  用近 3–5 年均值而非当期值。判据是**可持续性**，不是会计科目名称。

**② 去周期（仅强周期业务）**
强周期（资源/化工/航运/地产/面板）不能用当期利润率。做法：
```
E_norm = 一个完整周期(5–10年)的平均营业利润率 × 当期收入 × (1−正常税率) − 少数股东损益
```
- 为什么用"平均利润率 × 当期收入"而非"平均利润"：收入随规模增长，直接平均历史利润会低估当前体量。
- 边界：周期未走完一轮（次新股/新行业）→ 用同业跨周期利润率替代，标 `⚠️估算`。
- 弱周期/无周期（消费/公用/软件）→ **跳过本项**，防止把稳定盈利错误"周期化"削平。

**③ 税率归一**
用正常化有效税率（近 3–5 年均值，或法定税率）重算税后。
剔除：税收优惠到期跳变、一次性递延所得税确认/转回。
- 边界：高新/西部大开发等**长期确定**的优惠税率可保留（它是这门生意的持续特征）；
  只剔"一次性"和"即将到期"的部分。

**④ 折旧 ↔ 维持性资本开支校正（格林沃尔德特别强调）**
账面折旧是历史成本口径，≠ 维持现有产能所需的真实再投入。
```
若 维持性capex > 折旧（重资产老化/涨价）→ 用维持性capex替代折旧，压低 E_norm
若 维持性capex < 折旧（轻资产/折旧激进）→ 反向上调 E_norm
维持性capex ≈ 总capex − 增长性capex；粗估可用 折旧 × (当期固定资产/历史平均) 校正
```
- 为什么重要：EPV 的隐含假设是"零增长永续"，那就必须扣掉**维持**产能的钱，不能扣扩张的钱。
  这一项做错，重资产公司 EPV 会系统性高估。

**⑤ 费用化 ↔ 资本化还原**
R&D、品牌广告若当期全额费用化但实为多年受益的长期资产（特许经营常见）→ 按经济寿命摊销回来，抬高 E_norm。
反向：把经营费用违规资本化的（虚增利润）→ 费用化打回。
- 边界：只对**确实形成持续竞争资产**的支出做还原（可口可乐的广告 = 品牌资产；打价格战的促销费 ≠ 资产）。

**⑥ 归母口径**
一律扣少数股东损益，落到**归母**。EPS = 归母 E_norm / 总股本。
- 陷阱：合并报表利润含并表子公司 100% 利润，但母公司只享有其持股比例 → 少数股东损益必须扣净。

> 产出：**E_norm（归母正常化利润）**。EPV、λ 的 ①VCF、GG 闸门全部基于它，绝不用当期净利润。

**关键利率（先定死，全程复用）：**
- **r\*** = 资金成本。所有折现、所有价值分母都用它。取值：权益成本或 WACC，A 股成熟公司常取 8–10%。
- **II** = 穿透回报率门槛（你要求的最低回报）。**只用于 §6 GG 兑现闸门，绝不进任何折现分母。**
- 为什么必须区分：II 通常 < r\* 或 ≈ r\*，若误把 II 当折现率放进 V_cash 分母，会把 V_cash 推高越过 IV，
  令 λ 反号（护城河越强估值越低）——这是本框架最隐蔽的 bug，见 §6 铁律。

## §2 AV · 资产价值（从资产负债表出）

思想：资产价值是估值的"地板"，最硬。逐项把资产调到"当前公允/重置口径"，减全部负债 → AV（归母）。

**两种口径，看路由用哪个：**

**清算口径**（R1 困境用）——"今天把公司拆了卖，小股东拿回多少"：
| 资产 | 调整 |
|---|---|
| 现金及等价物 | 按面值 100% |
| 应收账款 | 打折（按账龄，通常 70–90%） |
| 存货 | 打折（可变现净值，通常 50–80%，过时存货更低） |
| 固定资产 | 按变现价（二手设备/土地评估价，常远低于账面） |
| 商誉 / 无形资产 | **归零**（拆散后不值钱） |

**重置口径**（R2/R3/R5 持续经营用）——"新进入者复制这堆资产要花多少钱"：
- 含账面**未体现**的重置成本：品牌需多少年广告投入才建成、客户关系、牌照、分销网络。
- 这是格林沃尔德的关键洞察：R2 判断（EPV≈AV）里的 AV 必须是**重置成本**，
  因为竞争均衡点是"新进入者复制成本 = 现有盈利资本化"，用账面 AV 会误判。

**减项**（两口径都减）：全部有息负债 + 经营负债 + 少数股东权益 → **归母 AV**。

## §3 EPV · 盈利能力价值（从利润表出）

```
EPV(基础) = E_norm / r*                （零增长永续资本化）
EPV(调整) = EPV(基础) + 超额现金/非经营性资产 − 净有息负债
```

**为什么是 E_norm / r\*（推导）**：永续零增长现金流 CF 的现值 = CF/r\*（几何级数求和，
增长率 g=0）。EPV 刻意设 g=0，因为增长价值最不可知，单独在 §5 处理，且只有护城河内才给。

**为什么要加超额资产、减净负债**：E_norm 是**经营**盈利资本化，只反映经营资产的价值。
账上趴的超额现金、可供出售金融资产、投资性房地产等**非经营资产**没进 E_norm，要按公允价值单独加回；
有息负债是股东价值的减项，要扣。
- 边界："超额"现金 = 总现金 − 经营所需现金（约收入的 1–3%）。别把经营周转金也当超额加回。

> EPV 假设**不增长**。这是特性不是缺陷：它给出"假设这门生意永远维持现状值多少"的硬锚，
> 再用它和 AV 比大小做诊断（§4）。

## §4 枢纽 · EPV↔AV 对比定护城河，选路由

**为什么 EPV 和 AV 的关系 = 竞争性质诊断（全框架最深的一招）：**

- **EPV ≈ AV**：市场是竞争性的。任何超额回报都会吸引新进入者，直到盈利资本化 = 复制资产的成本。
  这是**无护城河**的经济学签名。
- **EPV ≫ AV**：现有资产赚的钱，远超新进入者复制这些资产该有的回报。
  这**只可能**因为存在阻止新进入者的壁垒——即护城河。但必须能说清壁垒来源，否则是数据错误或迟早被抹平。
- **EPV < AV**：管理层把好资产做出了低于其重置价值的回报——**在毁灭价值**。

| 路由 | 触发条件 | 经济含义 | 取 IV |
|---|---|---|---|
| **R1 困境** | 持续亏损 / 资不抵债 / E_norm≤0 | 生意毁灭价值，看能拆出多少 | **AV 清算** |
| **R2 可复制** | EPV ≈ AV(重置)，±20% | 竞争把利润磨平到重置成本 | **AV 重置** |
| **R3 稳定无护城河** | EPV ≈ AV，经营稳定 | 赚合理回报但不超额 | **EPV** |
| **R4 毁灭价值** | EPV < AV（明显） | 管理层做亏好资产 | **min(AV×折价, EPV)** |
| **R5 特许经营** | EPV ≫ AV(>20%) **且能说清壁垒** | 护城河，超额回报可持续 | **EPV + 成长** |
| **R6 复杂/多业务** | 各板块模式异质 | 无法整体估 | **分部 SOTP** |

**R2 vs R3 的区分**：两者都是 EPV≈AV，但 R2 取 AV（资产更硬、盈利可能刚好周期性等于），
R3 取 EPV（盈利稳定，就认盈利）。稳定性存疑时取 min，从保守。

**R5 的硬门槛（防止把周期顶/数据错误误判成护城河）：**
EPV≫AV 但**说不清壁垒从哪来**——是品牌？成本优势？网络效应？牌照特许？高转换成本？——
一律**降级 R3**。护城河四来源之外找不到解释的超额回报，等于没有护城河。
- 反面例子：某周期股在景气顶 EPV 远超 AV，但那是周期而非壁垒 → 必须先在 §1-② 去周期，去掉后 EPV 通常回落到 ≈AV。

**R4 的处理**：EPV<AV 说明"清算比经营更值钱"，但清算往往拿不到（管理层不会自己解散）。
取 min(AV×折价, EPV) 反映"资产值钱但兑现不了"的双重折价，且 §7 裁决再降一级。

**R6 分部 SOTP**：每个业务板块单独走 R1–R5 得各自 IV，加总，减集团层净负债与管理成本。
控股集团、多元化平台适用。

## §5 成长价值（仅 R5）

**为什么只有 R5 才给成长价值（格林沃尔德的反直觉结论）：**
增长要靠再投资，再投资要花钱。在**竞争性行业**（无护城河），新增投资的 ROIC = r\*，
则 NPV = 投资×(ROIC−r\*)/r\* = 0——**增长不创造价值，只是把钱从左口袋换到右口袋**。
只有护城河内，新增投资 ROIC > r\*，增长才创造正 NPV。

```
成长价值 = Σ 护城河内增量投资 × (ROIC − r*)/r*  的折现
         （或用两阶段 DCF 的成长段，g 不得超过护城河可持续年限）
IV(R5)   = EPV(调整) + 成长价值
```
- 边界：成长段年限 ≤ 护城河半衰期（§6-②）。护城河撑不了那么久的增长，不能一直按超额回报算。
- 其余所有路由：**成长价值 = 0**，IV 即路由取值。R1–R4、R6 不给成长（无护城河的增长记零，防烧钱扩张被算成价值）。

## §6 λ 兑现合成（综合派 · 唯一裁决哲学，本框架最重的一层）

**问题**：§1–§5 得到 IV = "这门生意内在值多少"。但内在值 ≠ 到小股东手里的值。
留存利润要不要算数，取决于能否持续兑现、护城河多久、管理层是否截留。λ 就是"留存部分的兑现信用折扣"。

**唯一合成公式（推导）：**
```
分红率  = min(dps / EPS归母, 1.0)     —— dps>EPS 记 1.0，标"分红超盈利⚠️"（吃老本）
V_cash  = 分红率 × IV                  —— 已变成现金到手的那部分，兑现确定，信用=1
留存部分 = (1 − 分红率) × IV            —— 留在公司，兑现不确定，给 λ 信用
V_final = V_cash + λ × 留存部分
        = 分红率×IV + λ×(1−分红率)×IV
        = IV × [分红率 + λ×(1−分红率)]
```
语义端点：λ=1 → V_final=IV（留存全算数，纯格林沃尔德）；λ=0 → V_final=V_cash（留存全不算，纯 GG）。

> ⚠️ **铁律（本框架最隐蔽的错误来源）**：V_cash 与 IV **必须同用 r\* 折现**。
> II 只进下面的兑现闸门，**绝不作 V_cash 的折现率**。
> 证明为什么会出错：若写成 V_cash = 分红率×E_norm/II，而 II<r\*，则 1/II>1/r\*，
> V_cash 会大于同口径 IV，令 (IV−V_cash)<0，λ 越大 V_final 越小——护城河越强反而估值越低，完全反了。

**λ 打分（基准 0.5，三项相加，clip 到 [0,1]，每项必须写出理由不能只打分）：**

| 因子 | 含义 | +档 | −档 |
|---|---|---|---|
| **① VCF** | 价值创造，≈ (ROIC−r\*) 相对强弱 | ≥1.3 → +0.25；1.0–1.3 → +0.10 | 0.7–1.0 → −0.10；<0.7 → −0.25 |
| **② 护城河半衰期** | 壁垒还能撑几年 | ≥30年 → +0.15；15–30 → +0.05 | 8–15 → −0.05；<8年 → −0.15 |
| **③ 治理/截留** | 管理层是否把钱还给股东 | 干净+高分红 → +0.10 | 侵占迹象/少数股东>30%且吝啬 → −0.25 |

```
λ = clip(0.5 + ① + ② + ③, 0, 1)
```
- ① 是定量（龟龟喂）；②③ 是定性（大鱼喂）。这就是"大鱼喂闸门、龟龟喂骨架、λ 做裁决"的落点。

**GG 兑现闸门（全框架唯一用到 II 的地方）：**
```
GG_base = 分红率 × E_norm / II          （只做门槛判断，不进 V_final）
若 GG_base 隐含价值 < II 门槛线 → λ 封顶 0.3
```
含义：连穿透回报率门槛都够不着的兑现能力，留存价值最多给 30% 信用。

**特殊路由**：R1/R2/R4（AV 系）不走 λ——它们本就不承认盈利能力，IV 即终值，V_final=IV。
R3/R5 走完整 λ。R6 分部各自算 V_final 再加总。

## §7 安全边际 → 裁决

```
MOS = (V_final − 现价) / V_final
```
| MOS | 裁决 |
|---|---|
| ≥ 40% | 买入 |
| 15%–40% | 观察 / 逢低 |
| −15%–15% | 持有（合理定价） |
| < −15% | 卖出 / 排除 |

**叠加约束**：
- **单只个股最高仓位 5%**（硬约束，MOS 再高也不破）。
- R1/R4（价值毁灭系）即使 MOS 达标，**降一级**处理（买入→观察）——因为兑现路径不可靠。
- 分红超盈利⚠️（分红率被 clip 到 1.0）→ 复核可持续性，吃老本的高分红不可外推。

## §8 算例（两个端点，验证 λ 语义）

**算例 A · 高分红超派型（λ 语义端点：分红率≈1 → V_final≈IV，λ 影响被压缩）**
- 设 IV=100，dps/EPS=0.95 → 分红率=0.95，V_cash=95。
- 即便 λ 很低（=0.2）：V_final = 95 + 0.2×(100−95) = 96。
- 即便 λ 很高（=0.9）：V_final = 95 + 0.9×5 = 99.5。
- **结论**：几乎全额分红时，兑现已确定，λ 怎么变都逼近 IV——公式行为正确（现金到手不需要信用）。

**算例 B · 低分红 + 弱护城河（λ 语义端点：λ 主导，重罚留存）**
- 设 IV=100，分红率=0.15 → V_cash=15，留存=85。
- λ 打分：① VCF=0.6(<0.7)→−0.25；② 半衰期 6 年(<8)→−0.15；③ 少数股东侵占→−0.25。
  λ = clip(0.5−0.25−0.15−0.25,0,1) = clip(−0.15,0,1) = 0。
- V_final = 15 + 0×85 = 15。现价 30 → MOS = (15−30)/15 = −100% → **排除**。
- **结论**：IV 看着 100，但留存全兑现不了、只分了 15，真实价值就是 15。λ=0 把"纸面内在值"打回"现金现实"——
  这正是 A 股大量"看着便宜实则价值陷阱"公司的正确处理。

**对照**：同样 IV=100、分红率=0.15，但换成强护城河干净治理（①+0.25 ②+0.15 ③+0.10）→
λ=clip(0.5+0.5,0,1)=1.0 → V_final=100。留存被充分信任，回到纯格林沃尔德。
**同一个 IV，因兑现能力不同，V_final 从 15 到 100** —— 这就是综合派相对纯格林沃尔德/纯 GG 的增量。

## §9 心智模型

> **三块价值比大小定性质，一次分红率算到手，一层 λ 折兑现信用，最后一个 MOS 下裁决。**
> 全程 r\* 折现，II 只守闸门。说不清壁垒不给护城河，无护城河的增长记零，价值毁灭系降级处理。

**与旧结构的映射**：大鱼定性 → 喂 R5 壁垒门槛 + λ②③；龟龟定量 → 喂 E_norm/AV/EPV + λ①；
λ 合成 = 两者打架时的唯一裁决规则（旧结构缺的那条）。
