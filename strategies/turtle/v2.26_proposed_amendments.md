## 修订一：控股折价捕捉型——资产价值例外路径

### 问题

控股折价捕捉型标的（如天津发展 00882.HK，净现金/市值=285%，PB=0.17x）：
- 因子3 GG=4.02% << II=8.00% → 按规则 "不合格→回避"，仓位上限0%
- 但SOTP每股价值4.26 HKD（中性，含40%折价），较当前价+107%上行空间
- 净现金6,291M已超总市值2,210M

**根本矛盾：** GG衡量"可持续现金回报"，对控股公司适用性有限。投资逻辑是折价收敛的资本利得，而非现金分红。

### 建议

在 `factor4_估值与安全边际.md` 三-D 资产价值安全边际交叉验证 中增加例外路径：

```
3D.6 控股折价例外路径（新增）

触发条件（全部满足）：
  (a) 子类 = "控股折价捕捉型"
  (b) 净现金/市值 > 100%（净现金足以覆盖全部市值）
  (c) PB < 0.5（深度破净）
  (d) GG < II（不合格）

处理规则：
  - GG层由"不合格"提升至"灰区"（允许进入第二层裁决）
  - 仓位上限 = min(正常仓位×0.5, 30%)
  - 必须标注"⚠️ 例外路径适用——基于资产价值的安全边际例外"
  - 毕业条件：GG改善至II-2pct以内 或 催化剂兑现

  GG层原为不合格 → 例外路径提升至灰区 → DDM层+资产层正常查表
```

## 修订二：顶级品牌溢价折扣

### 问题

极致品牌标的（如贵州茅台 600519.SH）：
- 因子1B评分8.5/10（全库最高），护城河"优质"，定价权"极强"（渠道价差+88%）
- GG=3.47%仅低于II=4.50%约1.03pct
- 临界收入倍数1.17x（增17%即可翻越），5年收入CAGR 12.3%
- 但因II-1pct边界=3.50%，GG=3.47%被划入"不合格"而非"灰区"

**根本矛盾：** II=4.50%是通用门槛，但顶级品牌的确定性溢价未在门槛中体现。一个91%毛利率、49%净利率、零负债、具定价权的生意，与一个普通生意不应使用相同门槛。

### 建议

在 `shared_tables.md` 门槛值 II 计算公式 中增加品牌溢价调整：

```

品牌溢价调整（新增，v2.26）：

当以下条件全部满足时，II可下调0.5-1.0pct：
  1. 因子1B护城河评级 = "优质"（顶级品牌护城河）
  2. 定价权验证 = "极强"（渠道价差>50%或提价后需求未受抑制）
  3. 毛利率连续3年 > 80%（行业Top 1%）
  4. ROE连续5年 > 25%
  5. 零有息负债

调整幅度：
  满足3项 → 下调0.5pct
  满足4项 → 下调0.75pct  
  满足5项 → 下调1.0pct

调整后II不得低于Rf+1pct（下限保护）
调整理由须在报告子类判断段显式标注
```

## 修订三：HH偏差→因子3权重映射

### 问题

因子2 R值的OCF/NP假设在不同标的上准确度差异大：
- 格力电器 HH=+0.78pct（偏差小，因子2近似有效）
- 中国食品 HH=-4.64pct（偏差大，因子2不适用）
- 当前规则仅标注"因子2方法论适用性存疑"但无量化结论映射

### 建议

在 `factor3_穿透回报率精算.md` HH偏差决策矩阵 中增加结论映射：

```

HH偏差→因子3权重映射表（新增v2.26）

| HH绝对值 | 因子2可信度 | 对因子3的影响 | 最终裁决中因子3的权重 |
|:--------:|:---------:|:------------:|:-------------------:|
| < 1pct   | 高         | 交叉验证参考 | 50%（与因子2对等）  |
| 1-3pct   | 中         | 正常使用      | 70%（因子3为主导）  |
| 3-5pct   | 低         | 因子3为唯一有效| 100%（因子2不参与裁决）|
| > 5pct   | 不适用     | 因子2方法论失效| 100%（标注"因子2不适用"）|

当因子2权重=100%时：三-C便宜程度分档基于GG而非R，因子4 DDM以GG为唯一回报基准
```

## 修订四：灰区边界触发标注

### 问题

当前灰区条件为 `II-1pct ≤ GG < II+1pct`。但分析发现茅台GG=3.47%距II-1pct=3.50%仅差0.03pct，被判为"不合格"。这种"极薄边界"情况在二进制裁决中产生误导。

### 建议

在 `factor4_估值与安全边际.md` 三-E决策层级 中增加细化规则：

```

边界精度规则（新增v2.26）：

当GG与II或II±1pct边界的差距 < 0.1pct时：
  1. 裁决中必须显式标注"GG在边界±0.1pct内，本裁决对GG假设极度敏感"
  2. 建议输出"若GG改善XXpct，裁决将从X变为Y"的敏感性说明
  3. 强制参考GG置信区间：若区间的上沿或下沿跨越边界，应视为"灰区"而非"合格/不合格"
```
